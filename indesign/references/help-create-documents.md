# Create New Documents, Open Indesign Documents, Create Documents With Presets, Create Multi Page Spreads ...

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

## Overview

Covers: Create new documents; Open documents; Create documents with presets; Create multi-page spreads; Change document setup, margins, and columns.

## Create new documents

Start new projects with templates from Adobe Stock or with blank presets.

Starting options in InDesign include Adobe Stock templates with ready-to-use assets and blank document presets with predefined dimensions and settings. Templates become editable INDD files that can be customized like any other InDesign document. Presets supply predefined layouts for tasks such as business cards, brochures, or device-specific designs.

### Create a document from a preset

Choose File > New > Document.

Use Saved, Print, Web, or Mobile to choose a preset from the available options.

In the right panel, adjust the document name, dimensions, page count, margins, columns, bleed values, and any other preset settings as needed.

Refine the preset details as needed to make a custom document.

Change the preset details as needed to create a custom document.

Choose Create.

### Create a document from an Adobe Stock template

Adobe Stock templates provide ready-made layouts that can be customized for print, web, or mobile projects. Templates open as editable InDesign documents and are ready for immediate customization. Downloading templates requires an Adobe account that has Stock access. InDesign may ask for Adobe Fonts activation so text elements render correctly.

Choose File > New > Document.

Use Print, Web, or Mobile as the category tab.

Browse available templates, or search for specific templates.

Choose a template thumbnail, then choose See Preview for a larger view.

Choose Download so Adobe Stock can license the template.

Read the licensing terms, then complete the transaction with your account credits or entitlements.

Confirm the licensing terms again and finish the transaction using account credits or entitlements.

After licensing finishes, choose Open to open the template in InDesign.

If Adobe Fonts activation is requested, choose Add so all required typefaces are available. The template opens as a standard InDesign document. Downloaded templates are added automatically to the Stock Templates library in the CC Libraries panel, where more templates can be searched.

## Open documents

Use Adobe InDesign to open local, cloud, and recent documents.

Opening documents and templates in InDesign follows the same pattern as other applications. A template opens automatically as a new, untitled document. InDesign assigns file extensions by file type:

- INDD: document files
- INDT: template files
- IDMS: snippets
- INDL: libraries
- INX: interchange files
- IDML: markup files
- INDB: book files

### Open a document from your computer

Choose File > Open, then choose one or more documents.

Choose the needed open mode:

- Normal (Windows) or Open Normal (macOS): opens the document.
- Original (Windows) or Open Original (macOS): opens the template itself as an editable template file.
- Copy (Windows) or Open Copy (macOS): opens a duplicate of a document or template.

Choose Open.

### Open a cloud document

Launch InDesign.

On the Home screen, choose Your files or Projects.

Choose a document to open it. Cloud documents show a cloud icon on the tab; while you edit, InDesign saves them automatically and maintains version history for each manual save.

### Make cloud documents available offline

Launch InDesign.

On the Home screen, choose Your files, then use the options icon for the cloud document.

In the drop-down menu, choose Sync for 7 days. The selected file is stored locally and can be used for up to seven days without an internet connection. Work can continue while you travel or stay offline, and after reconnection your files update automatically.

### Open recent documents

Choose File > Open Recent.

Choose a document from your recently saved list. To change the size of that list, choose Edit > Preferences > File Handling, then adjust Number of Recent Items to Display. The list can show as many as 30 recent documents.

### Open documents from Adobe Bridge

Launch Bridge from any Creative Cloud app other than Acrobat, then open the folder that contains your InDesign (INDD) file.

Choose the file and double-click it; it opens in InDesign.

### Check your InDesign version

Launch InDesign.

Hold Ctrl and choose Help > About InDesign (Windows), or hold Command and choose InDesign > About InDesign (macOS).

The version details are then available to review.

Note

Files made in earlier versions of InDesign can also be opened. Some third-party plug-ins may add support for other file formats.

## Create documents with presets

Use blank document presets in Adobe InDesign when you need predefined dimensions and settings for a faster design-project start.

Blank document presets provide ready-made size and layout settings for starting new InDesign projects. Categories such as Print, Web, and Mobile group these presets so the starting point is easier to choose. Structural values in presets include page size, orientation, margins, columns, and bleed. Before the document is created, you can change those values to fit the job.

### Customize preset settings before creating a document

Choose File > New > Document.

Choose a category tab: Print, Web, or Mobile.

Review the presets that are available and choose one suited to your project requirements.

In the PRESET DETAILS panel, type a document name.

Change Width and Height by entering new dimensions or using arrow controls.

If the layout calls for it, choose another Orientation (Portrait or Landscape).

Set the starting page count by changing the Pages value.

Choose Facing Pages when you want left and right pages to form spreads; clear it for single-page layouts.

Update Columns, Column Gutter, Margins, and Bleed settings as the design requires.

Use Preview to inspect the document visually, then choose Create.

### Create a document using a preset

Choose File > New > Document.

Choose a category tab: Print, Web, or Mobile.

Look through the available presets and choose the one that fits your project requirements.

Check the preset specifications in the PRESET DETAILS panel.

Choose Create. The new document opens using the selected preset specifications.

### Create a new preset

Document presets store frequently used document settings as templates you can reuse, which supports consistency and cuts setup time. Rather than entering page size, margins, columns, and bleed settings for every new file, apply a preset that already contains your preferred specifications. This helps most with repeat document types, including newsletters, business cards, or marketing materials.

Follow this workflow to add a preset that shows in the Document Presets menu when you create a file. For settings in an already open file, choose File > Document Setup instead.

Choose File > Document Presets > Define.

In the Document Presets dialog box, choose New.

In the Document Preset field, type a clear name for the preset.

For Page Size, choose a standard size from the menu or type custom dimensions in Width and Height.

Enter the page count, choose the page orientation, and set whether the document uses facing pages.

Enter Top, Bottom, Inside, and Outside measurements to define the margins.

Clear Facing Pages when you need Top, Bottom, Left, and Right margin values.

With Facing Pages cleared, set values for the Top, Bottom, Left, and Right margins.

For columns, type the column count in Number and the spacing between columns in Gutter.

Expand Bleed and Slug, then enter measurements for each bleed and slug area.

Choose OK to save the preset, then choose OK again to close the Document Presets dialog box.

You can then find the preset under Document Presets from File > New > Document, inside the New Document dialog box, and use it whenever you create a document.

## Create multi-page spreads

Use the Pages panel in Adobe InDesign to stop page shuffling and group pages into island spreads.

Island spreads are multi-page spreads for specialized layouts, including foldouts. When page shuffling is turned off, InDesign keeps those spreads intact instead of repaginating them. In the Pages panel, brackets around the page numbers identify island spreads.

### Create an island spread within a document

Choose Window > Pages.

Choose a spread.

Open the Pages panel menu icon and clear Allow Selected Spread to Shuffle.

To place new pages in the island spread, open the Pages panel menu icon and choose Insert Pages.

To move an existing page into the island spread, drag that page onto the target spread in the Pages panel.

To bring a full spread into the island spread, drag its page numbers from the Pages panel.

### Create an island spreads across a document

Choose Window > Pages.

Choose the Pages panel menu icon.

Clear Allow Document Pages to Shuffle.

Choose the page that should become a multi-page spread.

Open the Pages panel menu and choose Insert Pages. A spread can contain up to 10 pages. After that limit is reached, the black vertical bar is no longer visible.

### Create a new document with a two-page spread

Documents normally begin with a single page, but Document Setup can make print-layout files open as a two-page spread.

Choose File > New > Document.

Type 2 in the Pages field.

Enable Facing Pages if it is not already selected, so the document uses a spread.

Add any other document settings required.

Choose Create.

### Update an existing document to start with a two-page spread

Choose File > Open and open the document you need to modify.

Choose File > Document Setup.

Type 2 in the Number of Pages field.

Choose OK.

### Create documents with different page sizes

InDesign can use more than one page size in the same document, so individual pages can be resized when needed. Parent page dimensions can be overridden by page sizes, and objects respond according to their anchor points and Liquid Page Rule settings.

Choose the Page tool.

Choose the page, making sure the full page is selected in the layout rather than only in the Pages panel.

In the Control panel, adjust these settings for the selected pages:

- X and Y: position the page horizontally and vertically within the spread.
- W and H: change the selected page's width and height.
- Page size dropdown: choose a preset or Custom for a custom page size.
- Landscape and Portrait: set page orientation.
- Liquid Page Rule: controls how content adapts when the page size changes.
- Objects Move with Page: moves page objects when X and Y values are adjusted.
- Show Parent Page Overlay: shows the parent page boundary over the selected page.

## Change document setup, margins, and columns

Adjust existing Adobe InDesign documents for new requirements by changing page size, orientation, and layout settings.

An existing InDesign document's core structure can be revised, including switches from single pages to facing pages, new page dimensions, or different margin and column layouts. Document Setup changes apply to every page in the document, while margin and column edits can be limited to particular pages, spreads, or parent pages.

### Adjust document setup

Choose File > Document Setup.

Set page size by choosing a preset from the Page Size drop-down menu or typing custom Width and Height values.

Set orientation with the Portrait icon or the Landscape icon.

Use Facing Pages to toggle between single-page and spread layouts.

Change Number of Pages when pages need to be added to or removed from the document. In multi-page documents that already contain content, choose File > Adjust Layout and apply the needed changes so objects are repositioned automatically.

Choose OK.

### Modify margins and columns for pages or spreads

Margin and column changes can apply to selected pages, whole spreads, or parent pages. If settings are changed on a parent page, every document page based on that parent inherits the update. Edits on ordinary pages affect only the selected pages.

Choose Window > Pages.

Choose the spread or pages to modify.

Choose Layout > Margins And Columns.

For Top, Bottom, Left, and Right, enter the distances between margin guides and each page edge. When Facing Pages is selected in Document Setup, Left and Right become Inside and Outside, so you can add extra inside margin space for binding.

Enter the Number of columns for the page layout.

Enter a Gutter value for the spacing between columns.

Choose OK.

### Create unequal column widths

InDesign can build custom column layouts with different widths by manually moving column guides on specific pages or spreads. Use this method for asymmetric layouts or specialized column arrangements.

Go to the page or spread where unequal columns are needed.

Choose View > Grids & Guides and clear Lock Column Guides.

With the Selection tool, drag a column guide to a new position. Column guides are paired and move together so the specified gutter width is maintained. A guide cannot be dragged past a neighboring column guide or beyond the page edge.

### Customize pasteboard and guides

Adjust the colors used for margins, columns, bleed, and slug guides, or choose a different preview background so Normal and Preview modes are easier to tell apart. InDesign can also change the snapping distance, place guides either in front of or behind objects, and define pasteboard size.

Open Edit > Preferences > Guides & Pasteboard (Windows) or InDesign > Preferences > Guides & Pasteboard (macOS).

In the Color section, use the drop-down menus to pick colors. Choose Custom for any menu when you need a custom color:

- Margins: chooses the color used for page margin guides.
- Columns: chooses the color used for the page's column guides.
- Bleed: chooses the color shown for the bleed area defined in the Document Setup dialog box.
- Slug: chooses the color shown for the slug area configured in the Document Setup dialog box.
- Preview Background: chooses the pasteboard color used in Preview mode. Choose Match to Theme Color when the pasteboard should follow the selected theme.
- Smart Guides: chooses the color for temporary alignment lines that appear while objects are moved.

Tip

To change the on-screen paper color, make sure no objects are selected, then double-click the Paper color in the Swatches panel (Window > Color > Swatches).

In Guide Options, configure these settings:

- Snap to Zone: type a pixel value for the snapping distance; larger values produce a wider snap range.
- Guides in Back: choose this option when guides should appear behind objects rather than in front of them.

In Pasteboard Options, type pixel values for Horizontal Margins and Vertical Margins. These settings define how far the pasteboard extends past the page edges, or past the defined bleed and slug areas.

Select OK.
