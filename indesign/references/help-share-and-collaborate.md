## Share for review overview

Learn how Adobe InDesign supports collaboration through shared documents, reviewer feedback, and comment management.

InDesign provides collaboration features for sending documents out through a web link and gathering responses. Reviewers can view the shared file in a browser and comment without having InDesign installed. Those comments are then available inside the InDesign interface, so you can inspect feedback and revise the layout while each discussion remains tied to the relevant design area.

### How the review workflow functions

In a typical InDesign collaboration process, three connected activities support design review.

- Share for review: Make a public (password-protected) or private web review link that lets stakeholders inspect the document and comment from a browser.
- Invite to edit: Give collaborators permission to access a cloud document when they need to open and change the source file.
- Manage feedback: Inside InDesign, review, reply to, resolve comments, and send updates to the same link before the document is finalized.

### When to use which workflow

- Use Share for Review when stakeholders must inspect designs, add visual comments, or approve layouts while leaving the source file unchanged.
- Use Invite to Edit when teammates require direct document access for collaborative editing.
- Use comment management in InDesign when feedback needs to be collected in one place, reviewers need responses, and the document must be updated before publication.

### Benefits for distributed teams

Review links let stakeholders comment on shared documents even when they do not have design software. Keeping comments centralized lowers confusion across versions and helps teams handle feedback across devices and platforms.

## Share documents with review links

Use Share for Review in Adobe InDesign to create shareable links and collect feedback.

Share for Review produces web links for InDesign documents, allowing stakeholders to view the file and comment in a browser. The comments are shown in InDesign, where you can review, reply to, or resolve the feedback. Keeping the discussion in this workflow centralizes comments and reduces problems with file versions.

Use Invite to Edit when collaborators need to modify the document.

### Create a review link

Open the InDesign document, or create a new document.

Select File > Share for Review, and then select Create link.

Choose any permission level:

- Anyone with the link can comment: makes a public link that anyone can open.
- Only invited people can comment: makes a private link that requires email invitations.

Rename the link so separate review rounds are easy to tell apart.

Select Copy to place the link on your clipboard, then send it to stakeholders.

### Update shared content

Use content updates to keep the same link URL and retain all existing feedback, so each revision cycle does not require a new link.

Make your revisions in the shared InDesign document.

Select File > Share for Review > Update content.

Stakeholders can refresh the browser page to see the updates while keeping their comments and annotations.

### Manage review link settings

Choose File > Share for Review.

Open More options, then choose any of these items:

- Link settings: enable comments and share links that are protected by a password.
- Create new review link: make additional links. Setting changes and in-app comments are applied only to the newest review link.
- Delete review link: remove the active link and revoke access.
- Manage review links: open the Review links tab on the Adobe website to see every review link.

In the Share for review dialog box, you can create a new link, manage link settings, or delete a link.

You can also use the Share for review dialog box to create another link, adjust link settings, or remove a link. Tip

- File > Save As removes review comments from the document. Use File > Save when you need comments preserved while saving.
- If review details are unavailable after you upgrade InDesign, reopen the document in the latest version so comment visibility is restored.

## Review a shared InDesign document

Use commenting tools to give feedback on shared design links without needing Adobe InDesign.

When a designer sends an InDesign document for review, you get either a private or public link that opens in a browser for commenting. If the document was updated, refresh the page to view the newest version.

Open the review link with any web browser.

Use the Comments icon to add your comments, then choose Submit.

When signed in with Adobe ID, view comments and use Reply or Resolve as needed.

When signed in as a guest, view comments and use Reply when needed.

Tip

Use annotation tools such as pins, text tools, drawing tools, emojis, and @mentions to leave specific contextual feedback on design elements.

## Manage feedback for shared documents

Use the Review panel in Adobe InDesign to view stakeholder comments, answer them, and resolve them.

After an InDesign document is shared for review, stakeholders can add comments through the review link. In the Review panel, you can see those comments, respond to them, and manage feedback connected to particular pages.

### View and respond to comments

Use Window > Comments > Review to open the Review panel.

When the Review panel opens automatically, the Share for Review dialog stays visible.

Choose a comment from the list to jump to its linked object or page in the document.

Choose Reply, enter your response in the field, and then choose Submit to keep the discussion moving.

### Manage individual comments

In the Review panel, choose the comment that needs management.

Use the available actions:

- Reply: Write a response.
- Resolve : Treat the feedback as handled.

For stakeholder comments or your own replies, open the ellipsis icon and use one of these commands:

- Edit: Change comments you wrote.
- Delete: Remove a comment permanently, including every reply attached to it.
- Mark as read/Mark as unread: Set whether a comment is tracked as read or unread.

### Update your shared document

When stakeholder feedback requires edits, update the review link with the revised document so collaborators see the current design.

Apply your changes in the InDesign document.

Choose Share, then choose Update content in the Share for review dialog box.

Use File > Save for normal saving; that keeps review comments and feedback. File > Save As removes all review comments from the document.

## Edit InDesign documents with InCopy on the web (beta)

Use browser editing to work together in real time on Adobe InDesign text frames.

InCopy on the web (beta) allows writers and editors to change text from a browser while designers continue in InDesign. Real-time sync keeps desktop and web views matched. To avoid concurrent edits, frame locking displays the collaborator's avatar and name, marks the frame in the collaborator's color, and warns InDesign users when they try to edit a locked frame.

Note

- The feature works only with English (North America) and English (International).
- Authors or text editors may create a free Adobe ID for web app access.
- Confirm the email address for the Adobe account at https://account.adobe.com/profile.

### Share your InDesign document for text editing

Start with a new or existing InDesign document.

Use Share in the top-right corner.

Choose Share for text editing.

Choose Save.

When Save to Adobe cloud storage opens, enter a name in Save As, choose Your files, and then choose Save. InDesign changes the document to INDDL format and uploads it to Creative Cloud.

Add collaborator email addresses in the Share document dialog box.

Choose Invite to edit copy. Invitees receive an email link that opens the document in their browser. Another route is File > Share for Text Editing (beta); choose Copy link and send that link to collaborators.

### Edit text in the browser

Use Google Chrome to open the shared document link. If prompted, sign in with your Adobe ID.

Move the pointer over a text frame. The cursor changes to show that the frame can be edited.

Click inside the frame to start editing. Use the bold icon and italics icon to apply text formatting.

- A. Cloud sync status: sync indicator.
- B. Threaded text: thread-flow indicator.
- C. Collaborators present on the document: presence indicator.
- D. Pages panel: page navigation.
- E. Overset text: overflow indicator.
- F. Focus Mode: focused writing view.
- G. Italics text format: italic styling.
- H. Bold text format: bold styling.
- I. Locked frame as the collaborator is working on it: unavailable frame state.

Choose the Focus Mode icon to enter a clean writing view with fewer distractions. Threaded frames indicate how text continues through multiple containers. When content goes beyond the available space, an overset text icon is shown on the frame.

After editing, choose the Go Back icon. Changes sync automatically to the InDesign document.

To send product feedback, choose the Help icon, then choose Submit Feedback.

About real-time sync and sync status

- Real-time sync keeps the desktop app and web aligned.
- Frame locking stops two people from changing one text frame simultaneously.
- Locked frames show the collaborator's avatar, name, and color highlight.
- InDesign shows collaborator presence and alerts users who attempt edits on a locked frame.

Cloud sync status tells you whether web and desktop are matched:

- indicates the desktop app and web currently match.
- signals unsynced changes from the InDesign desktop app on the web side; reload the document.

### Limitations of InCopy on the web (beta)

- Google Chrome is the only supported browser.
- Certain file formats, including BMP, SVG, GIF, PDF, JPG with effects, MP4, may display incorrectly.
- Documents shared from earlier ID beta releases need to be shared again.
- For INDDL files saved in Projects, the web version opens them. To open one in InDesign, right-click the file and choose Move > Your Files.

## View custom fonts

Add custom fonts so they can appear in InCopy on the web (beta).

InCopy web fully supports Adobe Fonts and loads those fonts automatically when a document opens. Text uses desktop-equivalent bold and italic styling and renders with pixel-accurate appearance. If a needed font is unavailable, InCopy uses a default font so the layout remains readable.

Fonts outside Adobe Fonts, such as brand fonts or licensed typefaces, count as custom fonts; collaborators add them to a document to keep designs consistent. Enabling custom fonts helps prevent substitutions that disrupt layout. Upload or install the fonts first, then enable Chrome font access so web rendering uses them correctly.

When collaborators share a document whose custom fonts fail to render correctly in InCopy on the web (beta), use these workarounds.

### Upload fonts to Creative Cloud

Uploading custom fonts to Creative Cloud is the strongest way to make them render correctly across Adobe apps and on the web. After upload, secure sync makes the fonts available wherever you sign in, which reduces font-related collaboration issues.

- Individual users can upload fonts through the Creative Cloud desktop application.
- Enterprise users can upload and share custom fonts from the admin console.

Note

An Adobe InDesign installation may include custom fonts in its Fonts directory. Those fonts still will not be reliably available across machines or Adobe products for the same user unless Adobe Fonts is used to upload and manage them.

### Install fonts in your system and update Chrome settings

Where Creative Cloud upload is not possible, such as personally licensed fonts or organization-restricted fonts, local system installation is another option. This lets you use custom fonts without sharing or redistributing them.

Install fonts on your system.

On Windows, view them in C:\Windows\Fonts (Windows); on macOS, use /System/Library/Fonts or ~/Library/Fonts. The installed fonts then become available in InDesign.

Open Google Chrome browser.

Put chrome://settings/content/siteDetails?site=https%3A%2F%2Findesign.adobe.com into Chrome's URL field.

Within Permissions, find Fonts. Open the Ask (default) dropdown menu for Fonts and choose Allow.

Change the Font permissions in Chrome.

Change the Font permissions in Chrome.

## Invite collaborators to edit cloud documents

Use sharing permissions in Adobe InDesign to give editing access for documents stored in Creative Cloud.

Choose Invite to edit when particular collaborators should change an InDesign cloud document. Share for Review is for gathering comments; this workflow gives stakeholders direct editing ability.

### Invite collaborators from InDesign

Open an InDesign cloud document or create a new one.

Choose File > Invite to edit.

In Add people or groups, enter an Adobe email address or name.

Open Who has access and choose one of these permission levels:

- Only invited people can access : limits access to people invited by email.
- Everyone at <Organization> can view : creates a link available to anyone in the organization.
- Anyone with the link can view : creates a public view link.

Choose Copy to share the link with stakeholders.

### Invite collaborators from Creative Cloud

Launch the Creative Cloud desktop application and choose Files > Files .

On the Creative Cloud website, the equivalent location is Files > Your files.

For the InDesign cloud document, right-click the file and choose Share.

Enter the Adobe email address or collaborator name.

Choose Invite to edit.

Caution

When collaborators are added through InCopy on the web (Beta), they start with view-only access and cannot be promoted to editing access.

## Import PDF comments

Use comments from reviewed PDFs of Adobe InDesign documents to manage feedback inside the layout.

Bring comments from review PDFs back into the original document. In InDesign, you can inspect feedback, accept or reject edits, and monitor each comment's status.

Accurate placement requires the InDesign document to stay unchanged after PDF creation.

Open the InDesign document that should receive imported comments.

Choose File > Import PDF Comments.

Browse to the PDF file that contains comments for this document.

Choose Import comments to add those comments to the document.

You may import comments from more than one PDF for the document. Imported comments appear in the PDF Comments panel.

Review comments and use these actions:

- Toggle resolution status: Use Resolve or Unresolve to track addressed feedback.
- Accept changes: Use Accept to apply suggested edits for Strikethrough Text, Replace Text, and Insert Text comments.
- Remove comments: For comments no longer needed, choose More Options, then Delete.
- Locate comments: Search Comments finds specific feedback.
- Filter comments: Use Filter Comments to show comments by Status (Resolved, Unresolved, Mapped, Unmapped), by Type (Sticky Notes, Underlined Text, Highlighted Text, and so on), by Reviewer, and by PDF Source.

Toggle Show/Hide Comments on Layout to decide whether layout annotations are visible while you work.

## Create and share projects

Set up and manage creative assets with team members by using Projects in Adobe InDesign.

Use a shared Projects workspace to organize documents from Photoshop, Illustrator, Express, and other apps and make collaboration simpler. Shared access helps manage permissions, align teams, and enable real-time co-editing.

On the InDesign homescreen, choose Projects > Create project.

Enter a project name and choose Create.

Add collaborator email addresses; each person receives an invitation email to join the project.

Choose permissions: Can edit or Can comment.

Add a message if needed, then choose Invite.

## Add files to projects

Add existing or new files to a project in Adobe InDesign so related assets stay organized in a shared workspace.

With Projects, multiple files can be grouped and managed in a single place. Move files that already exist or save new files straight into the project so assets remain connected and current.

Choose Projects, and then choose your desired project.

Choose Add > Move files or Create folder.

After choosing Move files, pick files for the project.

New files can also be saved directly to a project from within InDesign.

Choose Move.

For more options, choose the ellipsis icon: Share, Copy link, Rename, Leave, and Delete.
