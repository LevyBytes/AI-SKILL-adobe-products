# Zoom Options

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

Options that control display size.

## Class

> _Read Only_
>
> Number `ZOOM_IN` = 2053990766
>
> Moves the view up to the next preset percentage.
> _Read Only_
>
> Number `ZOOM_OUT` = 2054124916
>
> Moves the view down to the next preset percentage.
> _Read Only_
>
> Number `FIT_SPREAD` = 2053534835
>
> Places the active spread at the center of the window.
> _Read Only_
>
> Number `FIT_PAGE` = 2053534832
>
> Places the active page at the center of the window.
> _Read Only_
>
> Number `SHOW_PASTEBOARD` = 2054385762
>
> Scales the view so the entire pasteboard fits in the window.
> _Read Only_
>
> Number `ACTUAL_SIZE` = 2053206906
>
> Sets zoom to 100%.
