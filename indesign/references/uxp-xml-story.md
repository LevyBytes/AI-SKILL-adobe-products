# Xml Story (part 1)

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

XmlStory represents XML text content still awaiting placement in the layout.

## Class

> _Read Only_
>
> String `BEFORE_PLACE` = beforePlace
>
> Raised before placement of a XmlStory. The event bubbles and can be canceled.
> _Read Only_
>
> String `AFTER_PLACE` = afterPlace
>
> Raised after placement of a XmlStory. The event bubbles and cannot be canceled.
