# PSD, TIFF, GIF, JPEG, and BMP import options

| Tab | Option | Description |
| --- | --- | --- |
|  | Show Preview | Shows the image preview before the graphic is placed. |
| Image | Apply Photoshop Clipping Path | Uses the clipping path embedded in the file. This option appears only when a PSD or TIFF includes a clipping path. |
|  | Alpha Channel | Brings in transparency from the chosen alpha channel. It is available only for files that contain alpha channels. |
| Layers | Show Layers | Sets which layers are visible. Use the eye icon to turn layers on or off; Alt-click (Windows) or Option-click (macOS) hides all other layers. |
|  | Layer Comp | (Photoshop only) Shows the chosen layer comp from the PSD file when layer comps exist. |
|  | Update Link Options | Controls layer visibility:<br><br>- Use Photoshop's Layer Visibility: When the link is updated, layer visibility follows the source PSD file.<br>- Keep Layer Visibility Overrides: The layer visibility choices made during import are retained, even after the link updates. |
| Color | Profile | Sets the source profile for color. Choose Use Document Default or select a profile that matches the source graphic. |
|  | Rendering Intent | Determines how colors are converted for the output device:<br><br>- Perceptual (Images): Keeps continuous-tone image colors visually accurate. Intended for photographic images.<br>- Saturation (Graphics): Keeps color intensity. Intended for solid graphics.<br>- Relative Colorimetric: Maps in-gamut colors exactly. Intended for solid color areas.<br>- Absolute Colorimetric: Keeps exact color values. Intended for solid color areas.<br><br>Bitmap, grayscale, and indexed-color images do not offer this setting. |
