# Set up Google Analytics for published documents

Use Google Analytics with published Adobe InDesign documents.

Create a free Analytics account at analytics.google.com, then supply the Measurement ID during publication of the InDesign document. Connecting Google Analytics leaves the InDesign files unchanged. If cross-domain analytics are not being recorded, configure cross-domain measurement in Admin for the Measurement ID.

For embedded password-protected documents that contain multiple pages, each page change made with the drop-down menu requires entering the password again.
