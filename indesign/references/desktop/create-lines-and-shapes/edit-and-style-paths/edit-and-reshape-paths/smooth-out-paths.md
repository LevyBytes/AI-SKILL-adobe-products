# Smooth out paths

Use the Smooth tool when an existing path, or a section of one, contains too many angles. Smoothing usually reduces the point count, which makes editing, display, and printing simpler.

Choose the path.

Select the Smooth tool.

Drag along the path segment that needs smoothing.

Keep smoothing until the stroke or path reaches the desired smoothness.

To adjust smoothing strength, double-click the Smooth tool and configure these options:

- Fidelity Sets how closely curves track the pointer. Lower values preserve sharper angles, while higher values ignore small movements to create smoother curves. The pixel value range is 0.5 to 20 pixels.
- Smoothness Sets how much smoothing the tool applies. Smoothness can range from 0% to 100%. Higher values make the path smoother.
- Keep Selected Sets whether the path remains selected after smoothing.

Select OK.
