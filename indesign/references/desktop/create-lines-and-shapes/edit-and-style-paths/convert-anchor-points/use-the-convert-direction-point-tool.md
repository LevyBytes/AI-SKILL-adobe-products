# Use the Convert Direction Point tool

Using the Direct Selection tool, choose the path.

From the Pen tool context menu, choose the Convert Direction Point tool.

Put the tool on the target anchor point, then apply the required action:

- From a corner point, pull out direction lines to create a smooth point.
- Select a smooth point to turn it into a corner point without direction lines.
- From a corner point, drag direction lines, release, and then pull one direction line to create a corner point with independent handles.
- From a smooth point, drag one direction line to convert it into a corner point with independent handles.
