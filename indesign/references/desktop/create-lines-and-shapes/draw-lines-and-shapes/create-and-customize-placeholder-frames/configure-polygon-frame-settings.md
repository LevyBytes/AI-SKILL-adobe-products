# Configure polygon frame settings

Double-click the Polygon Frame tool to display the Polygon Settings dialog box.

In Number of Sides, type the value that determines how many sides the polygon uses.

In Star Inset, type a percentage to make star shapes.

At 0%, the result is a regular polygon; higher values (40-50%) make longer, narrower points, while lower values (10-20%) make subtler points.

Choose OK.
