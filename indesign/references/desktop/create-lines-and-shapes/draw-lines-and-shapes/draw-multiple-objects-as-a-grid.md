# Draw multiple objects as a grid

Use this topic to create evenly spaced rows and columns of frames in Adobe InDesign by pressing arrow keys while dragging.

In InDesign, frame-creation tools can build structured grid layouts as you draw by changing rows, columns, and spacing, avoiding the need to duplicate and position each frame by hand.

Choose from these frame-creation tools: Polygon Frame tool, Rectangle Frame tool, Ellipse Frame tool, or Type tool.

After choosing one, drag until the frame starts forming.

With the mouse button still held down, press these keys:

- Right Arrow key: increases the column count.
- Left Arrow key: decreases the column count.
- Down Arrow key: increases the row count.
- Up Arrow key: decreases the row count.

To change gutter spacing between frames, hold down Ctrl (Windows) or Command (macOS) while pressing the arrow keys.

Release the mouse button.
