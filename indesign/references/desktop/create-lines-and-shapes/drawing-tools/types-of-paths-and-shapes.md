# Types of paths and shapes

See how Adobe InDesign uses simple paths, compound paths, and compound shapes, and how these objects differ.

All vector graphics are built from paths, so each shape you draw starts with a path. Knowing how path types behave makes it easier to build complex artwork and manage shape interactions.

Adobe InDesign works with three main path types: simple paths, compound paths, and compound shapes. The types progress from basic to more flexible structures, with each offering a different level of control.
