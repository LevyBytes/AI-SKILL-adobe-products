# Keyboard shortcuts

Use keyboard shortcuts to make Adobe InDesign work faster and improve day-to-day efficiency.

InDesign provides keyboard shortcuts for efficient work, with many shown next to menu commands. Default shortcut sets are available for InDesign, Illustrator, and Photoshop, and you can also create your own sets and share them on the same platform.

In the Keyboard Shortcuts dialog box (Edit > Keyboard Shortcuts), use Show Set to create a printable list for the active shortcut set. This is particularly helpful when working with custom shortcut sets.
