# Change document recovery location

While you work, InDesign writes recovery data automatically to a temporary folder. That data can restore unsaved edits if the application or system crashes unexpectedly.

Recovery files are temporary, and InDesign deletes them automatically when documents are saved or closed normally. Change this preference only when recovery data must be kept in a particular place for backup, performance, or IT policy needs.

Choose Edit > Preferences > File Handling (Windows) or InDesign > Preferences > File Handling (macOS).

In the Document Recovery Data section, choose Browse (Windows) or Choose (macOS).

Go to the folder where InDesign should keep recovery data, and select that folder.

Choose Select (Windows) or Choose (macOS) to confirm the folder.

Choose OK. The updated location is used immediately. Recovery files already in the old location stay there until InDesign no longer needs them.

Tip

Use a local drive location that has enough free space and dependable performance. Network locations can make saves slower or cause recovery to fail when the connection is interrupted.
