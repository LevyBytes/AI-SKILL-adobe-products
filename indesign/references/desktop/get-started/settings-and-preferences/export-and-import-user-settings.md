# Export and import user settings

Exporting and importing User Settings is available in Adobe InDesign.

InDesign can export and import User Settings, which helps users restore customized settings when needed and keeps the setup experience smoother. For the easiest setup, keep settings aligned with the latest version. Available actions include:

- Export User Settings: writes the settings into a file.
- Import and apply User Settings: brings settings in from a file and applies them.
