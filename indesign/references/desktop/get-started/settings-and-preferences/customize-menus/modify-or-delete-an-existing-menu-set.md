# Modify or delete an existing menu set

Open Edit > Menus.

From the Set dropdown menu, pick the menu set that you plan to change or remove.

Choose one of these actions:

- Modify the menu set: Change command visibility or colors as required, choose Save, and then choose OK.
- Delete the menu set: Choose Delete. When unsaved edits exist in the menu set, InDesign asks whether to save those changes before it proceeds. Choose Yes to approve the deletion.
