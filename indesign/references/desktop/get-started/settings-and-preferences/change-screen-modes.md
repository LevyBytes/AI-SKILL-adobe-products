# Change screen modes

In Adobe InDesign, screen modes let you review layouts, present work, or edit while reducing interface clutter.

Several screen modes in InDesign alter only the on-screen view of the document; they do not change the file itself or the final output. Use them for different working contexts, such as editing with the full interface visible, inspecting bleed or slug areas, or showing a clean view without distractions. To turn on a screen mode, choose View > Screen Mode, and then select Normal, Preview, Bleed, Slug, or Presentation Shift + W.
