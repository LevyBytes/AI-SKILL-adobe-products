# Create a custom workspace

Set up the panels, windows, and tools in the arrangement you want to store.

Choose Window > Workspace > New Workspace.

Type a descriptive workspace name.

In Capture, choose Panel Locations to keep the current panel arrangement, or choose Menu Customization to include customized menu sets.

Choose OK. The custom workspace is then listed in the workspace switcher in the Application bar and is also available from Window > Workspace.
