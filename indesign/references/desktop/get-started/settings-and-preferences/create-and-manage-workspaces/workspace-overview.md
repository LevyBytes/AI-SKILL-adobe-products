# Workspace overview

Default InDesign workspace

A. Tabbed Document windows B. Workspace switcher C. Search bar with autocomplete suggestions D. Unified Account Management icon E. Panel title bar F. Status bar G. Tools panel

Default InDesign workspace

- The application frame places the workspace controls into a single window so they operate together. When you resize or move that frame or its contents, the layout adjusts responsively to avoid overlap. Panels stay visible when you switch focus or click outside the application. If several applications are open, arrange them side by side or distribute them across monitors. On macOS, use Window > Application Frame to enable or disable the traditional user interface.
- Across the top, the application bar holds controls such as the workspace switcher, menus (Windows only), unified account management icon, and other application controls. On macOS, this bar appears only when the Application frame is off. Use the Window menu to show or hide it.
- Use the Tools panel to create and edit images, artwork, page elements, and related items. Similar tools are collected together.
- Options for the currently selected object appear in the Control panel.
- The Document window shows the file currently being edited. Document windows support tabs and, in some situations, grouping and docking.
- Panels are used to inspect and change your work. You can group, stack, or dock panels.

InDesign workspaces give windows, panels, and tools a customizable layout so you can build a design environment around your preferences.
