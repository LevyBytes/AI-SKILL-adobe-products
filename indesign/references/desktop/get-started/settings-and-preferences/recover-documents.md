# Recover documents

Automatic recovery in Adobe InDesign can restore unsaved work after unexpected power failures, crashes, or system failures.

Adobe InDesign guards work with automatic recovery by writing document changes to a temporary file apart from the original document. This protection is used when InDesign closes unexpectedly because of power failures, system crashes, or application errors.

InDesign also has an auto-repair mechanism that detects corrupted documents and tries to repair damage caused by internal problems, outside system issues, or disk errors. If repair works, InDesign prompts you to save the recovered document before you continue working.

When InDesign detects document corruption, let the automatic repair finish.

Check any recovered documents that open on their own; their title shows [Recovered] after the filename.

Choose File > Save As to keep the recovered version with the automatically recovered changes included.

After InDesign recovers a document successfully, unsaved changes appear inside the opened file. To reject the recovered changes and return to the last version you saved deliberately, use the History Panel to revert them or close the recovered document without saving, then reopen the original file from disk.
