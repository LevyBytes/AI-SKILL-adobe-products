# Revert to the last saved version

Revert permanently removes every unsaved change, and you cannot undo it afterward. To keep the current work, first create a separate version with File > Save As before you revert.

When the revert finishes, InDesign opens the document again in the condition it had at the most recent save. Edits created after that save point are removed permanently.

Choose File > Revert to remove every change made since the document was last saved.

In the confirmation dialog box, choose Revert.
