# Set Greek type threshold

When the display cannot render very small letters clearly, InDesign may show that text as a muted bar instead. This substitution is greeking type: any type at or under the configured size appears on-screen as placeholder shapes rather than actual letterforms.

Open Edit > Preferences > Display Performance (Windows) or InDesign > Preferences > Display Performance (macOS).

In Adjust View Settings, choose the view setting you want to change.

Enter the point value in Greek Type Below.

Select OK.
