# Set general preferences

Set Adobe InDesign defaults for panel placement, measurement units, and display behavior.

General preferences define basic application behavior, such as how page numbers are shown, how fonts are handled, and how scaling math is calculated. Changes made here affect documents created afterward. For preferences meant only for the document you are editing, open that document before you open the Preferences dialog box.

When no documents are open, choose Edit > Preferences > General (Windows) or InDesign > Preferences > General (macOS).

In the Page Numbering section, use View to choose the page-numbering method used in the Pages panel.

In Font Downloading and Embedding, enter the threshold that triggers font subsetting according to how many glyphs from a font are used. This setting changes font downloading choices in the Print and Export dialog boxes and may reduce file size.

Under When Scaling, choose Apply To Content when scaled text frames should also scale text point size proportionally.

Choose Adjust Scaling Percentage to show both the original point size and the new point size in parentheses during text scaling, which makes transformations easier to track.

Choose OK to store the preferences.
