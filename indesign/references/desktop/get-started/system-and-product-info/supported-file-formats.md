# Supported file formats

Review the file formats Adobe InDesign can open, save, export, and import.

Use this reference to confirm format compatibility before you open documents, import assets, or export InDesign content. Support depends on the operation being performed. Certain formats are intended for opening native documents, while others serve placement or export workflows. For professional publishing, InDesign handles many industry-standard formats across print production and digital distribution. Knowing which formats apply to each operation helps keep exchanges with clients, collaborators, and service providers predictable.
