# Minimum system requirements

- Processor: Snapdragon X Elite X1E-78-100

  - Speed and cores: up to 3.4 GHz, 12 cores
  - With Advanced Vector Extensions 2 (AVX2) Support (20.0 or later)

- Graphics: adapter is Snapdragon X Elite Qualcomm Adreno
- Operating System: 21.0 and later beta builds are supported on Windows 11 version 24H2 (26100.7623). To verify your Windows version, select Window + R, or enter winver in the Run dialog box.
