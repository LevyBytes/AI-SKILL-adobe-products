# Technical requirements for versions 20.2 and later

InDesign Server does not support case-sensitive file systems, removable storage devices, or network drives.1

NOTES:

1. Unsupported virtualized or server-based environments include Citrix Metaframe/Citrix Presentation Server, NVIDIA Grid, plus Microsoft App-V, VMWare, Parallels, and Virtual PC; the list is not exhaustive. "Thin Clients" are server-based environments as well. For virtualized or server-based environments, InDesign has specific technical support boundaries.
