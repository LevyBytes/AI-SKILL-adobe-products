# Deploy packages

Once the package is built and downloaded locally, select a distribution method to install the packaged apps:

- Open the package file directly by double-clicking it.
- Distribute with deployment tools including Microsoft System Center Configuration Manager (SCCM), Apple Remote Desktop, or JAMF Casper Suite.
- Use the command line for deployment on Windows computers.
- Use the Info.plist file for deployment on macOS computers.

For installation or uninstallation error fixes, use the troubleshooting guidance for Adobe app installation issues.
