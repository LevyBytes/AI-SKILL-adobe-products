# Create and deploy InDesign server packages

Use Admin Console to make license packages for Adobe InDesign that support online or offline activation.

Build online and offline activation InDesign Server packages, then deploy them. After deployment, you can remove licenses when machines are retired or when the license must be redeployed. This capability is for Enterprise (Feature Restricted Licensing - FRL) for Adobe InDesign.

Access to Adobe Admin Console and the new FRL SKUs is required. If the FRL SKUs are not available to you, ask your account manager for help.
