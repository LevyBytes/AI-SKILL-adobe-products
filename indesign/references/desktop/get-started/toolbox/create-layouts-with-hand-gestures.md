# Create layouts with hand gestures

On touch-enabled devices, use the Touch workspace and drawing gestures to build layout objects.

The Touch workspace is intended for Windows hardware that supports touch, such as tablets, touchscreen laptops, and touch-capable desktop systems. Files that include objects made in other workspaces still display correctly, though editing is limited to objects supported by the Touch workspace.

Detaching the keyboard from a touch-enabled device switches automatically to the Touch workspace; reattaching it restores the previous workspace. To switch manually, choose Window > Workspace > Touch.

In the Touch workspace, the four main tools are Drawing tool, Type tool, Frame tool, and Shape tool. Drawing tool is unique to this workspace; Type tool creates text frames, Frame tool creates graphics placeholders, and Shape tool creates rectangles, ellipses, and polygons. InDesign turns 16 recognized hand gestures made with the Drawing tool into layout elements.

Create a new document, or open an existing one.

Choose the Drawing tool from the toolbar if it is not already active.

Use the Help icon in the upper-right corner to open the complete gesture reference guide with all 16 available gestures.

Draw any supported gesture directly on the canvas to create its matching element.

Use the panels on the right side of the workspace to refine elements by changing colors, opacity, alignment, and other properties.
