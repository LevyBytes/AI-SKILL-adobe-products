# Rename, delete, or duplicate assets

Choose Window > CC Libraries, then choose the library that contains the assets for renaming, deletion, or duplication.

In the CC Libraries panel, right-click one or more assets.

For one asset, choose Rename, Delete, or Duplicate from the context menu.

When several assets are selected, choose Delete Selected Items or Duplicate Selected Items.

To rename, enter the new name and press Enter.

Note

Removing an asset deletes it from the library, but placed instances already in InDesign documents remain unchanged.
