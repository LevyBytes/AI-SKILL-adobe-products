# Manage project assets with Creative Cloud Libraries

Work with colors, graphics, and styles in InDesign documents, then share those assets with other Adobe apps.

In InDesign, the CC Libraries panel centralizes access to Creative Cloud Libraries and syncs assets across devices when the same Adobe ID is used. From this panel you can create, view, rename, and delete libraries; add, edit, organize, and manage assets; and sort or browse the contents of each library. These tools help keep design work consistent and organized across projects.
