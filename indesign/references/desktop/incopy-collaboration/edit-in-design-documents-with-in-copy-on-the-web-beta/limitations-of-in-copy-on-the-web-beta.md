# Limitations of InCopy on the web (beta)

- Google Chrome is the only supported browser.
- Certain file formats, including BMP, SVG, GIF, PDF, JPG with effects, MP4, may display incorrectly.
- Documents shared from earlier ID beta releases need to be shared again.
- For INDDL files saved in Projects, the web version opens them. To open one in InDesign, right-click the file and choose Move > Your Files.
