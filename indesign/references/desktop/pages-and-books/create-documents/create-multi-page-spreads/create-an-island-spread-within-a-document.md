# Create an island spread within a document

Choose Window > Pages.

Choose a spread.

Open the Pages panel menu icon and clear Allow Selected Spread to Shuffle.

To place new pages in the island spread, open the Pages panel menu icon and choose Insert Pages.

To move an existing page into the island spread, drag that page onto the target spread in the Pages panel.

To bring a full spread into the island spread, drag its page numbers from the Pages panel.
