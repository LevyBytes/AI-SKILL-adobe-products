# Create documents with presets

Use blank document presets in Adobe InDesign when you need predefined dimensions and settings for a faster design-project start.

Blank document presets provide ready-made size and layout settings for starting new InDesign projects. Categories such as Print, Web, and Mobile group these presets so the starting point is easier to choose. Structural values in presets include page size, orientation, margins, columns, and bleed. Before the document is created, you can change those values to fit the job.
