### Additional install/uninstall scenarios

Before use, InDesign Server must be activated. On an online computer, installation triggers activation automatically.

### Using the admin console

### Prerequisite

- When switching from a serial-number installation to the Admin Console, reinstall the InDesign server and remove the earlier installed copy.

### Recommendation

- Because Admin Console installation may be unsuitable for virtual environments, Adobe does not recommend using it there.

For instructions on installing earlier versions of InDesign Server with the Admin Console, create packages.

Note

If InDesign Server was previously activated with a serial number, ask your Adobe representative for an upgrade to the latest version.
