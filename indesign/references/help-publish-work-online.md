## Publish InDesign documents online

Publish Adobe InDesign documents online when they need to be shared, updated, and viewed in a browser.

Publish Online turns print-ready documents into web publications that open in common browsers on any device. It supports interactive elements including buttons, slideshows, animations, audio, and video, while keeping the layout faithful to the document. Before publishing, confirm that an internet connection is available and that the InDesign document is ready.

Open an InDesign document and choose File > Publish Online.

Open the General tab to add Title, Description, Pages, Export As, or Enable Password Protection.

Open the Advanced tab to add items such as Cover Thumbnail, Image Settings, Download PDF Settings, etc.

Open the Analytics tab to connect your Google Analytics account with the published document.

Choose Export HTML5 Package when you want to export your InDesign document as an HTML5 package.

Choose Publish to publish the document online. When republishing an existing document, choose Update Existing Document, then choose an existing document from the drop-down list.

Choose File > Publish Online Dashboard to see the published-document list. Google Analytics can also be configured for published documents.

Note

A verified Adobe ID is required before an InDesign document can be published. Unverified users cannot publish InDesign documents. For an embedded password-protected document with multiple pages, the password must be entered again each time a page is changed with the dropdown menu.

### Export HTML5 Package option

At the bottom of the Publish Online dialog, choose Export HTML5 Package when you need a local HTML5 package rather than an online publication. For related guidance, consult the material on exporting to HTML5.

### Limitations and special cases

- Password-protected documents with multiple pages: When a protected document is embedded, changing pages through the page dropdown menu prompts viewers for the password again each time.
- Embedded HTML content: Published documents can include embedded HTML content only from websites that InDesign supports. If the embedded site is unsupported, the published output shows the HTML content as blocked.
- Browser requirements: A browser with TLS 1.2 support is required to open published documents.
- Maximum export size: If Download PDF is enabled, PDF export crops anything beyond 200" × 200".

## Set up Google Analytics for published documents

Use Google Analytics with published Adobe InDesign documents.

Create a free Analytics account at analytics.google.com, then supply the Measurement ID during publication of the InDesign document. Connecting Google Analytics leaves the InDesign files unchanged. If cross-domain analytics are not being recorded, configure cross-domain measurement in Admin for the Measurement ID.

For embedded password-protected documents that contain multiple pages, each page change made with the drop-down menu requires entering the password again.

### Add Google Analytics tracking to your document

Open the InDesign document, then choose File > Publish Online.

In the Analytics tab, paste the Measurement ID generated in Google Analytics so it is attached to the published document. Adobe receives no access to, or data from, your Google Analytics account.

Choose Analytics and enter the Measurement ID so document-view data and other metrics appear in Google Analytics.

Choose Analytics and supply the Measurement ID again so Google Analytics can track views and related metrics.

Select Enable cookie banner on my document to show visitors a consent notice.

In Cookie Banner text, type the wording required for your cookie notice. The banner lets visitors accept or reject analytics collection for that document.

Select Publish, or select Close to collapse the dialog box while you continue editing other InDesign documents.

Open Google Analytics to review insights for the published documents.

### Analytics tab settings

Use the Analytics tab to connect published documents to Google Analytics and to add cookie-consent banners.

Note

- Analytics are recorded only after a visitor consents. Google Tag Manager shows data for users who accept the notice in the cookie banner. The consent banner is shown solely on the published document; once cleared, it remains hidden for one year.
- Because regional cookie notice rules differ, add the banner where your data-protection duties require it.

## Publish Online FAQ

Find answers to common questions about publishing online with Adobe InDesign.

Publish Online turns print layouts into online documents. An InDesign document can be published as a digital version that opens on any device in any modern web browser, with no plug-in installation required.

For a more interactive reading experience, publish an InDesign document that uses InDesign's interactive authoring features, such as buttons, slideshows, animations, audio, and video.

Once documents are published, share the online document URL so other people can open them in a simple, polished reading experience on any device or platform. One click can post the online document to Facebook or Twitter, or send it by email. You can also place the document on a website or blog with the embed code available from the embed option in the viewing layout.

To begin using Publish Online, install the latest version of Adobe InDesign. Create the document that should go online, then choose File > Publish Online.

Viewing does not require a login. Anyone who has the link can open the published document in a web browser, but viewing a Publish Online document requires an internet connection.

Publish Online documents open in modern browsers on desktop and mobile devices. The reading layout adjusts for the device to improve viewing. After you publish or re-publish the file from InDesign, text search is available inside published documents on any device. Touch devices support searching text, while desktops and laptops support both searching and copying text.

Publish Online documents can be shared in several ways: email the URL as a hyperlink, post it on Facebook or Twitter, or place it in a website or blog with the embed code. To edit and re-publish a published document, use these steps:

1. Revise the InDesign file that produced the published document.
2. Choose File > Publish Online.
3. In the Publish Online dialog box, choose Update Existing Document.
4. From the dropdown menu, choose the document to replace, then choose OK.

The revised document is republished at the same URL.

Use the Publish Online Dashboard to view, manage, and delete published documents. Choose File > Publish Online Dashboard to open the InDesign online dashboard. To remove a document, choose Documents, choose the more options icon, then choose Delete.

Adobe servers host Publish Online documents, and each published document receives a unique URL. Hosted content can be embedded on, or linked from, your site; however, Publish Online does not currently let you host that content on your own server.

Files hosted for Publish Online are generally small unless the published document contains large embedded videos. Publish Online does not impose a document-size limit, so documents can keep being published. For the best reading experience with Publish Online Documents, encode videos as MP4s and keep their file sizes small.

Adobe currently does not set a fixed limit on how many documents it will host for you, provided the service is used fairly. Keep creating and publishing.

Adobe may stop hosting your documents only when it detects spam-like use involving too many Publish Online documents.

With paid Creative Cloud memberships, including InDesign Single App plans, Adobe hosts Publish Online documents until you delete them.

After a membership expires, documents stay hosted on Adobe servers for at least 90 days. Adobe may decide to stop hosting them after that 90-day period.

All Publish Online features are available with a free Creative Cloud membership and with an InDesign free trial. After the trial ends, Adobe may stop hosting the documents after 90 days unless the trial is converted to a paid membership.
