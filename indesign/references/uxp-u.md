## UserDictionaries

Collection containing user dictionaries.

### Instance

> _Read Only_
>
> Number **length**
>
> Count of objects held by the collection.

### Methods

> Number **count**()
>
> Reports how many elements the UserDictionary contains.
> UserDictionary **item**( Mixed **index** )
>
> Retrieves the UserDictionary addressed by the given index or name.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| Mixed | index | Index or name selector. Can accept: Long Integer or String. |

> UserDictionary **itemByName**( String **name** )
>
> Retrieves the UserDictionary matching the supplied name.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| String | name | Name selector. |

> UserDictionary **itemByRange**( Mixed **from**, Mixed **to** )
>
> Retrieves the UserDictionaries contained in the requested range.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| Mixed | from | Starting bound for the range: a UserDictionary, index, or name. Can accept: UserDictionary, Long Integer or String. |
| Mixed | to | Ending bound for the range: a UserDictionary, index, or name. Can accept: UserDictionary, Long Integer or String. |

> UserDictionary **firstItem**()
>
> Retrieves the first UserDictionary in the collection.
> UserDictionary **lastItem**()
>
> Retrieves the last UserDictionary in the collection.
> UserDictionary **middleItem**()
>
> Retrieves the middle UserDictionary in the collection.
> UserDictionary **previousItem**( UserDictionary **obj** )
>
> Retrieves the UserDictionary at the index before the supplied UserDictionary.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| UserDictionary | obj | UserDictionary whose position follows the desired UserDictionary. |

> UserDictionary **nextItem**( UserDictionary **obj** )
>
> Retrieves the UserDictionary positioned after the supplied UserDictionary in the collection.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| UserDictionary | obj | UserDictionary whose position comes before the desired UserDictionary. |

> UserDictionary **anyItem**()
>
> Retrieves any UserDictionary in the collection.
> UserDictionary **everyItem**()
>
> Retrieves every UserDictionary in the collection.
> String **toSource**()
>
> Builds a string that returns the UserDictionary when executed.
> UserDictionary **[]**( Number **index** )
>
> Retrieves the UserDictionary at the supplied index.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| Number | index | Index value. |

## UserDictionary

### Instance

> _Read Only_
>
> String **name**
>
> Name assigned to the UserDictionary.
> _Read Only_
>
> Boolean **isValid**
>
> True when the object specifier resolves to valid objects.
> _Read Only_
>
> Application **parent**
>
> Parent object for the UserDictionary (a Application).
> _Read Only_
>
> Number **index**
>
> Position of the UserDictionary within its containing object.
> _Read Only_
>
> Events **events**
>
> Event collection.
> _Read Only_
>
> EventListeners **eventListeners**
>
> Event listener collection.
> String **addedWords**
>
> Words stored in the user dictionary's added list.
> String **removedWords**
>
> Words stored in the user dictionary's removed list.
> Object **properties**
>
> Allows several properties to be set at the same time.

### Methods

> **addWord**( String **addedWords**, Boolean **removedList** )
>
> Adds the supplied words to the chosen dictionary list.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| String | addedWords | Words to add. |
| Boolean | removedList | When true, places the words in the removed words list. When false or unspecified, places them in the added words list. (Optional) |

> **removeWord**( String **removedWords**, Boolean **removedList** )
>
> Removes the supplied words from the chosen dictionary list.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| String | removedWords | Words to remove. |
| Boolean | removedList | When true, removes the words from the removed words list. When false or unspecified, removes them from the added words list. (Optional) |

> String **toSource**()
>
> Builds a string that returns the UserDictionary when executed.
> UserDictionary **getElements**()
>
> Produces an array of object references after resolving the object specifier.
> String **toSpecifier**()
>
> Gets the specifier string for the object.
> EventListener **addEventListener**( String **eventType**, Mixed **handler**, Boolean **captures** )
>
> Registers a listener for the event.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| String | eventType | Event type. |
| Mixed | handler | Event handler. Can accept: File or JavaScript Function. |
| Boolean | captures | Obsolete parameter. (Optional) |

> Boolean **removeEventListener**( String **eventType**, Mixed **handler**, Boolean **captures** )
>
> Unregisters an event listener.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| String | eventType | Registered event type. |
| Mixed | handler | Registered event handler. Can accept: File or JavaScript Function. |
| Boolean | captures | Obsolete parameter. (Optional) |
