## Cloud document management options

Adobe InDesign includes choices for organizing, managing, and deleting cloud documents from inside the application.

To organize cloud documents, move them, or delete files you no longer need, use the management choices on the Adobe InDesign home screen. Open them by selecting Your files from the home screen, then right-click a cloud document or select its checkbox. To manage several cloud documents together, select the checkbox for each one.

### Document management options

This table covers every management action shown when you open Your files and choose the more options icon for an InDesign Cloud document in the application.

### Organization options

Use the view and sorting controls to manage cloud-document display and place documents into folders.

### Manage deleted files:

Open the Deleted section, then choose the more options icon to restore a cloud document or delete it permanently.

## GPU performance in InDesign

Learn how GPU acceleration in Adobe InDesign can improve rendering and interaction performance.

### Overview

The Graphics Processing Unit (GPU) handles rendering and display work. InDesign uses GPU acceleration to make interaction more responsive and performance smoother.

Rendering on high-resolution HiDPI displays can raise CPU usage. By moving rendering work to the GPU, InDesign enables smoother zooming, scrolling, and panning while maintaining high-quality display.

On supported systems, InDesign activates the GPU automatically and changes display performance to High Quality Display. If you encounter performance problems, use CPU rendering instead or adjust the preview mode.

### Technical requirements

### Windows

- VRAM: Minimum 1024 MB VRAM (2 GB recommended)
- Display: Monitor resolution greater than 2K
- OpenGL: version 4.4 or later

### macOS

- VRAM: Minimum 1024 MB VRAM (2 GB recommended)
- Metal support

On macOS, GPU acceleration uses the Metal API and improves responsiveness on Apple silicon hardware, beginning with M1.

The supported macOS device list covers:

- iMac models: 4K and 5K
- MacBook Pro with Retina
- Mac Pro with a HiDPI monitor connected
- Mac mini with a HiDPI monitor connected

### Use GPU performance

When a compatible GPU is present, InDesign automatically uses it for rendering. GPU acceleration helps with zooming, panning, and working on high-resolution assets.

GPU features make full-quality rendering smoother and improve responsiveness during demanding design work.

### Deactivate GPU performance

On supported systems, GPU performance is enabled by default. To switch to CPU-based rendering, select Edit > Preferences > GPU Performance and deselect the GPU Performance option.

### Change preview mode

Preview modes let you move between GPU and CPU rendering without editing preferences. Press Shift + E to switch between GPU Preview and CPU Preview. The View menu also provides GPU Preview and Preview on CPU.

### Animated Zoom

GPU acceleration supports features such as Animated Zoom and makes zooming interactions smoother. To use Animated Zoom, choose the Zoom tool, then hold down anywhere on the document so the view zooms toward the center. For zooming out, hold Option (macOS) or Alt (Windows). Shift also switches to marquee zoom mode.

## Support for Windows ARM-based machines

Review availability and performance improvements for native Windows on ARM (ARM64) builds of Adobe InDesign and Adobe InCopy.

Starting in version 21.9 (Beta), InDesign and InCopy support Windows on ARM (ARM64) natively. On Windows devices with Snapdragon X Series ARM architecture-based processors, these applications run directly and deliver better responsiveness and performance. On Windows, HEIC/HEIF import requires both the HEIF Image Extensions and the HEVC Video Extensions.

Note

Earlier InDesign (Beta) versions in the 21.x line continue to run in emulation mode on Windows ARM devices.

### Minimum system requirements

- Processor: Snapdragon X Elite X1E-78-100

  - Speed and cores: up to 3.4 GHz, 12 cores
  - With Advanced Vector Extensions 2 (AVX2) Support (20.0 or later)

- Graphics: adapter is Snapdragon X Elite Qualcomm Adreno
- Operating System: 21.0 and later beta builds are supported on Windows 11 version 24H2 (26100.7623). To verify your Windows version, select Window + R, or enter winver in the Run dialog box.

### Fix startup error (0xc0000142) on Windows ARM

Install the newest Windows 11 release before using these builds: for 21.0 and later beta builds on Windows 11, support starts at 24H2 (26100.7623) and 25H2 (26200.7623).

## Create and deploy InDesign server packages

Use Admin Console to make license packages for Adobe InDesign that support online or offline activation.

Build online and offline activation InDesign Server packages, then deploy them. After deployment, you can remove licenses when machines are retired or when the license must be redeployed. This capability is for Enterprise (Feature Restricted Licensing - FRL) for Adobe InDesign.

Access to Adobe Admin Console and the new FRL SKUs is required. If the FRL SKUs are not available to you, ask your account manager for help.

### Create online and offline activation for the InDesign Server package

Sign in to Admin Console. In the upper-right corner, find and apply the organization that includes InDesign Server.

Open the Packages tab, then choose Packages. The page lists the package history created by every admin in your organization.

Choose Create a Package.

On the next screen, set the activation method to Online or Offline, then choose Next. For connected environments, review Feature Restricted Licensing - Online; for offline environments, review Feature Restricted Licensing - Offline.

At the Entitlements step, choose the needed entitlement, then choose Next. The entitlement choices vary based on whether Online or Offline activation was selected in step 4.

At the System step, choose the needed settings, then choose Next.

- Choose a Platform: Select the macOS or Windows 64-bit operating system.
- Language: Choose the language used when the package is created.
- Use OS Locale: Builds a package that installs in the client machine's OS language. In this case, that OS language becomes the fallback default language for deployment.

At the Choose Apps step, choose whether the package should be License-only, Apps-only, or contain both an app and a license.

To confirm which versions your Creative Cloud plan supports, review the Creative Cloud Support policy. When the selections are complete, choose Next.

At the Options step, choose the required option, then choose Next. This step appears only for the online activation method.

At the Finalize step, type the package name in the Package Name box.

Choose Build Package. When the build succeeds, the Availability column shows the Download link.

The Admin Console keeps a package available for as long as three days. To see how much download time remains, select the package row and open its details.

### Install licenses for license-only packages

After creating a license-only package in the Admin Console, use this process for packages that use Online, Offline, or Isolated activation:

Get the package from the Admin Console.

Unpack the package contents. The license-only package provides licensing details in a .json file and also includes the Licensing Toolkit utility. Windows utility: adobe-licensing-toolkit.exe macOS utility: adobe-licensing-toolkit

Use administrator privileges when running the license-install commands. Windows command: adobe-licensing-toolkit.exe --precondition --install --filePath <absolute path of the .json file> Short form: adobe-licensing-toolkit.exe -p -i -f <absolute path of the .json file> macOS command: sudo adobe-licensing-toolkit --precondition --install --filePath <absolute path of the .json file> Short form: sudo adobe-licensing-toolkit -p -i -f <absolute path of the .json file>

### Deploy packages

Once the package is built and downloaded locally, select a distribution method to install the packaged apps:

- Open the package file directly by double-clicking it.
- Distribute with deployment tools including Microsoft System Center Configuration Manager (SCCM), Apple Remote Desktop, or JAMF Casper Suite.
- Use the command line for deployment on Windows computers.
- Use the Info.plist file for deployment on macOS computers.

For installation or uninstallation error fixes, use the troubleshooting guidance for Adobe app installation issues.
