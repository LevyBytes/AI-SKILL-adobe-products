# Scale User Interface

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

Use Adobe InDesign UI scaling preferences to size the interface for your monitor resolution.

Tailor the interface to your display needs so controls stay readable during extended work. On first launch, InDesign detects the screen resolution and applies a matching UI scale. If you attach another monitor, change display resolution, or want a different size, you can adjust UI scaling manually whenever needed.

On high-resolution screens, UI scaling helps because default settings can make tools and menus appear too small. The selected scale applies across panels, tools, menus, and cursor icons.

Open Edit > Preferences > User Interface Scaling (Windows) or InDesign > Preferences > User Interface Scaling (macOS).

Drag the UI Sizing slider left or right to reduce or enlarge the interface for the current screen resolution.

Check the preview beside the slider to see how the interface changes.

Review the preview again after adjustment to confirm the interface result.

Enable Scale Cursor Proportionately so cursor icons resize automatically with the UI scale.

Use the Anchor Points, Handle, and Bounding Box Display Size slider to set those elements separately.

Select OK.

Restart InDesign when asked so the new scaling settings are applied.

Note

Available scaling increments vary with screen resolution. Higher-resolution displays provide finer scale steps. If you skip the restart, the changes apply the next time InDesign launches.
