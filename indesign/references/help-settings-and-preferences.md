## Create and manage workspaces

Customize panel layouts in Adobe InDesign and move among saved arrangements to streamline your workflow.

Workspaces let you place windows, panels, and tools in InDesign to match your design habits and working style. A workspace saves the current panel positions and sizes under a name, making it easy to return to a preferred setup. InDesign provides several presets for specific tasks, and you can add as many custom workspaces as different projects or workflow stages require. Switching is available whenever needed, and changes to panels are saved automatically in the active workspace.

### Workspace overview

Default InDesign workspace

- The application frame places the workspace controls into a single window so they operate together. When you resize or move that frame or its contents, the layout adjusts responsively to avoid overlap. Panels stay visible when you switch focus or click outside the application. If several applications are open, arrange them side by side or distribute them across monitors. On macOS, use Window > Application Frame to enable or disable the traditional user interface.
- Across the top, the application bar holds controls such as the workspace switcher, menus (Windows only), unified account management icon, and other application controls. On macOS, this bar appears only when the Application frame is off. Use the Window menu to show or hide it.
- Use the Tools panel to create and edit images, artwork, page elements, and related items. Similar tools are collected together.
- Options for the currently selected object appear in the Control panel.
- The Document window shows the file currently being edited. Document windows support tabs and, in some situations, grouping and docking.
- Panels are used to inspect and change your work. You can group, stack, or dock panels.

InDesign workspaces give windows, panels, and tools a customizable layout so you can build a design environment around your preferences.

### Create a custom workspace

Set up the panels, windows, and tools in the arrangement you want to store.

Choose Window > Workspace > New Workspace.

Type a descriptive workspace name.

In Capture, choose Panel Locations to keep the current panel arrangement, or choose Menu Customization to include customized menu sets.

Choose OK. The custom workspace is then listed in the workspace switcher in the Application bar and is also available from Window > Workspace.

### Delete a custom workspace

Choose Window > Workspace > Delete Workspace.

From the Name dropdown menu, choose the workspace to remove.

Choose Delete to confirm. Deletion is available only for custom workspaces; built-in InDesign workspaces cannot be removed.

## Customize panels

Organize panels in Adobe InDesign so the workspace supports the way you work.

Set up the panel layout so frequently used tools are easy to reach and the workspace stays clear. In InDesign, panels can be stacked, floated, or collapsed, and the layout is saved automatically. You can also store layouts as named workspaces with Window > Workspace > New Workspace, making it easier to switch between project types. For the best working setup, keep the panels you rely on most in convenient spots without covering the document view.

### Stack floating panels

Drag a panel by its tab out of the dock so it becomes floating.

To stack it, drag the floating panel by its tab into the drop zone at the bottom of another floating panel.

Reorder stacked panels by dragging a panel tab upward or downward.

Move stacked floating panels as one unit by dragging the topmost title bar.

### Collapse panels to icons

Use the double-arrow icon at the top of the dock to collapse every panel in that column into icons. This saves screen space while leaving less-used panels within reach.

Select a panel icon to expand only that panel.

Select icons again to collapse open panels, or move between panels by selecting their tabs.

Select icons again to collapse open panels, or move between panels by selecting their tabs.

Change the dock width by dragging its edge. Narrow docks hide icon labels; wider docks show them.

### Work with panel groups

Add a panel to a group by dragging the panel tab into the highlighted drop zone inside that group.

Rearrange panels in a group by moving a panel's tab to another position in the group.

Remove a panel from a group by dragging it outside the group by its tab.

Move a whole group by dragging the title bar above the tabs.

Add panels, remove unused ones, and reorganize individual or grouped panels so essential tools stay quick to reach while documents are open. These controls let you shape a workspace around your design needs and workflow preferences.

### Show or hide panels

Use Tab to toggle every panel, including the Tools and Control panels.

Use Shift + Tab to toggle panels while leaving the Tools and Control panels visible.

### Add a panel

Choose Window.

Select the panel you want to add from the list.

Dock the panel in the desired location by dragging it by its tab. When panels are visible in your workspace, the Window menu displays checkmarks beside them.

### Move panels within a dock

Use the panel tab to move the panel into the slim blue drop zone positioned above or below another panel.

When the highlight turns blue at the target placement, let go of the pointer.

### Remove panels

On the panel tab, right-click (Windows) or Control-click (macOS).

In the context menu, choose Close. Another way to remove the panel is to clear its entry in the Window menu. After the final panel is removed from a dock, that dock disappears automatically.

### Dock panels

Panels gathered into one vertical stack along a workspace edge make up a dock. Docking keeps related controls in the same place, while undocking lets a panel be used on its own. As you drag panels, InDesign marks valid destinations with blue-highlighted drop zones. Workspace changes remain in the active workspace until you reset it or choose another workspace.

Choose the panel for relocation by selecting its tab.

Move the panel tab toward the dock you want until a blue drop zone is shown.

Place the panel at the top, at the bottom, or between existing panels in that dock.

Let go of the pointer when the blue highlight marks the intended spot.

### Undock panels

Press and hold the tab for the panel that should leave its dock.

Pull the panel away from the dock where it currently sits.

Move it into a blank area of the workspace and keep it out of any blue drop zones.

Release the pointer to turn it into a free-floating panel. When a dock has no panels left, it disappears. To build another dock, move either a panel or a panel group toward the workspace's right edge and stop when a drop zone is displayed. To move a panel group without splitting it, drag from the title bar instead of from a single tab.

## Set general preferences

Set Adobe InDesign defaults for panel placement, measurement units, and display behavior.

General preferences define basic application behavior, such as how page numbers are shown, how fonts are handled, and how scaling math is calculated. Changes made here affect documents created afterward. For preferences meant only for the document you are editing, open that document before you open the Preferences dialog box.

When no documents are open, choose Edit > Preferences > General (Windows) or InDesign > Preferences > General (macOS).

In the Page Numbering section, use View to choose the page-numbering method used in the Pages panel.

In Font Downloading and Embedding, enter the threshold that triggers font subsetting according to how many glyphs from a font are used. This setting changes font downloading choices in the Print and Export dialog boxes and may reduce file size.

Under When Scaling, choose Apply To Content when scaled text frames should also scale text point size proportionally.

Choose Adjust Scaling Percentage to show both the original point size and the new point size in parentheses during text scaling, which makes transformations easier to track.

Choose OK to store the preferences.

## Reset document settings and preferences

Configure Adobe InDesign preferences and object settings as defaults for later documents and objects.

Document defaults give new projects a consistent starting state, which saves setup time and helps keep work uniform. InDesign uses two default levels: document-level defaults apply to new documents when no files are open, and object-level defaults apply to new objects when an open document has nothing selected. The values stay in place until changed again, so they are useful for standardized workflows.

### Set document-level defaults

Close every open document with Ctrl + Alt + Shift + W (Windows) or Cmd + Opt + Shift + W (macOS).

Choose Edit > Preferences (Windows) or InDesign > Preferences (macOS).

Change any needed settings in menus, panels, or dialog boxes.

### Set object-level defaults for a document

Open the document that should receive the object defaults.

Choose Edit > Deselect All so no objects remain selected.

Choose Edit > Preferences (Windows) or InDesign > Preferences (macOS).

Adjust the necessary settings in menus, panels, or dialog boxes.

### Reset all preferences to factory defaults

Quit InDesign.

Start InDesign again while holding Shift + Ctrl + Alt (Windows) or Shift + Option + Command + Control (macOS).

When asked whether to delete preference files, select Yes.

Alert

A preference reset deletes customized settings, including workspace layouts, keyboard shortcuts, and default values. Back up preference files before you take this step if you may need those settings later.

### Reset preferences from the Preferences dialog

If InDesign can launch normally, use this procedure to schedule the preference reset for the next time the app closes.

Open InDesign.

Choose Edit > Preferences > General (Windows) or InDesign > Preferences > General (macOS).

Enable Reset Preferences On Quit.

In the Preferences dialog box, choose Reset Preferences on Quit to restore the default setting.

In the Preferences dialog box, choose Reset Preferences on Quit to restore the default setting.

Exit InDesign and launch it again.

## Customize menus

Use Adobe InDesign menu customization to hide commands or apply colors, reducing workspace clutter and calling attention to commands you use often.

Menu customization can remove rarely used commands from view and mark high-use commands with color, keeping the interface centered on the workflows that matter most. When you need both focused and complete menu views, make multiple menu sets for particular tasks, such as Text Editing or Print Production, and save each one in its own workspace.

### Create a custom menu set

Choose Edit > Menus.

Select Save As, type a descriptive name for the menu set, and choose OK.

In the Category dropdown menu, choose Application Menus to edit the main menu bar, or choose Context & Panel Menus for right-click and panel menus.

Expand menu categories with the arrows beside them so individual commands are visible. While selecting a menu name, hold Ctrl (Windows) or Command (macOS) to temporarily show commands hidden inside that menu.

For each command to customize, use the eye icon under Visibility to show it or hide it.

Under Color, select None and choose the highlight color from the menu.

Select Save to keep the changes, then select OK. The custom menu set becomes active and stays active until you choose a different menu set or change workspaces.

### Switch between menu sets

Choose Edit > Menus.

From the Set dropdown menu, choose the menu set you want. The default menu set cannot be edited or deleted.

Select OK to use the selected menu set.

### Modify or delete an existing menu set

Open Edit > Menus.

From the Set dropdown menu, pick the menu set that you plan to change or remove.

Choose one of these actions:

- Modify the menu set: Change command visibility or colors as required, choose Save, and then choose OK.
- Delete the menu set: Choose Delete. When unsaved edits exist in the menu set, InDesign asks whether to save those changes before it proceeds. Choose Yes to approve the deletion.

## Change screen modes

In Adobe InDesign, screen modes let you review layouts, present work, or edit while reducing interface clutter.

Several screen modes in InDesign alter only the on-screen view of the document; they do not change the file itself or the final output. Use them for different working contexts, such as editing with the full interface visible, inspecting bleed or slug areas, or showing a clean view without distractions. To turn on a screen mode, choose View > Screen Mode, and then select Normal, Preview, Bleed, Slug, or Presentation Shift + W.

## Search options to find and replace

Use the search options in Adobe InDesign to make finding and replacing content fit your workflow.

Efficient search tools can make content retrieval faster, reduce repetitive steps, and support more productive work.

To define where InDesign searches, choose any of these options:

- All Documents: looks through every open InDesign document.
- Document: limits the search to the current document. This option is selected by default.
- Story: checks all text in the selected frame, including text that continues into threaded text frames and overset text. The option is visible only when a text frame is selected or an insertion point is active.
- To End of Story: starts at the insertion point and continues to the end of the text frame. The option appears only when an insertion point is active.
- Selection: restricts the search to selected text. The option appears only after text is selected.

Additional icons let you include particular document sections in the search.

## Undo and redo edits

Keyboard shortcuts and menu commands in InDesign can reverse recent edits or apply them again.

During the current work session, InDesign can quickly undo mistakes or redo changes. These controls make it easier to try edits and fix errors without losing work.

Undo and Redo apply only within the open session. After a document is closed and opened again, changes from earlier sessions cannot be undone.

### Reverse or reapply your most recent change

To reverse your last action, choose Edit > Undo or press Ctrl + Z (Windows) or Cmd + Z (macOS).

To apply again an action you just undid, use Edit > Redo; the keyboard shortcuts are Ctrl + Shift + Z (Windows) and Cmd + Shift + Z (macOS).

The menu names include the action involved, such as Undo Delete or Redo Move.

Note

Some operations cannot be undone, including scrolling the document view or saving files.

### Revert to the last saved version

Revert permanently removes every unsaved change, and you cannot undo it afterward. To keep the current work, first create a separate version with File > Save As before you revert.

When the revert finishes, InDesign opens the document again in the condition it had at the most recent save. Edits created after that save point are removed permanently.

Choose File > Revert to remove every change made since the document was last saved.

In the confirmation dialog box, choose Revert.

## Manage document states using History Panel

Use the History Panel in Adobe InDesign to move through earlier design states, undo changes, or create new documents from past states.

The History panel shows a visual timeline of document edits, so you can move backward or forward among states from the current work session.

### Open and navigate the History panel

Choose Window > History.

Pick any state in the list to return the document immediately to that moment.

Open the panel menu icon and choose Step Forward to redo the next edit, or choose Step Backward to undo the prior edit.

### Create a new document from a selected state

Choose Window > History.

Pick the history state that should become the starting point.

At the bottom of the History panel, choose the Create new document from current state icon. InDesign creates a new unsaved document in another tab that reflects the selected state, but the history timeline is not brought over.

Choose File > Save.

### Delete specific states

Choose Window > History.

Pick the state that you want to remove from the History panel.

Choose the Delete icon at the bottom of the panel.

Choose OK.

Alert

State deletion is permanent and cannot be undone. Removed states leave the timeline right away.

To clear all history states while keeping the current document unchanged, choose Clear History from the panel menu. This frees memory without altering how the document currently looks.

### Things to keep in mind

- Changes that belong to the application, including panel and color settings, actions, and preferences, do not appear in the History panel because they are not edits to a specific document.
- The History panel stores as many as the previous 25,000 states. Once that limit is exceeded, older states are removed from the History panel automatically.
- Closing and reopening a document clears every state from the previous work session out of the panel.
- By default, if you select a state and then alter the design, every later state is removed.
- The Delete and Clear History actions cannot be reversed.
- For unsaved documents, the History panel still shows content and keeps the history after you first choose Save or Save As.

## Recover documents

Automatic recovery in Adobe InDesign can restore unsaved work after unexpected power failures, crashes, or system failures.

Adobe InDesign guards work with automatic recovery by writing document changes to a temporary file apart from the original document. This protection is used when InDesign closes unexpectedly because of power failures, system crashes, or application errors.

InDesign also has an auto-repair mechanism that detects corrupted documents and tries to repair damage caused by internal problems, outside system issues, or disk errors. If repair works, InDesign prompts you to save the recovered document before you continue working.

When InDesign detects document corruption, let the automatic repair finish.

Check any recovered documents that open on their own; their title shows [Recovered] after the filename.

Choose File > Save As to keep the recovered version with the automatically recovered changes included.

After InDesign recovers a document successfully, unsaved changes appear inside the opened file. To reject the recovered changes and return to the last version you saved deliberately, use the History Panel to revert them or close the recovered document without saving, then reopen the original file from disk.

### Change document recovery location

While you work, InDesign writes recovery data automatically to a temporary folder. That data can restore unsaved edits if the application or system crashes unexpectedly.

Recovery files are temporary, and InDesign deletes them automatically when documents are saved or closed normally. Change this preference only when recovery data must be kept in a particular place for backup, performance, or IT policy needs.

Choose Edit > Preferences > File Handling (Windows) or InDesign > Preferences > File Handling (macOS).

In the Document Recovery Data section, choose Browse (Windows) or Choose (macOS).

Go to the folder where InDesign should keep recovery data, and select that folder.

Choose Select (Windows) or Choose (macOS) to confirm the folder.

Choose OK. The updated location is used immediately. Recovery files already in the old location stay there until InDesign no longer needs them.

Tip

Use a local drive location that has enough free space and dependable performance. Network locations can make saves slower or cause recovery to fail when the connection is interrupted.

## Export and import user settings

Exporting and importing User Settings is available in Adobe InDesign.

InDesign can export and import User Settings, which helps users restore customized settings when needed and keeps the setup experience smoother. For the easiest setup, keep settings aligned with the latest version. Available actions include:

- Export User Settings: writes the settings into a file.
- Import and apply User Settings: brings settings in from a file and applies them.

### Export user settings

User Settings can be exported to a file.

Choose File > User Settings > Export User Settings.

Choose the destination, and enter a value for File name. By default, InDesign names the file IDSettings*<version>*<locale>_<platform>_<date (`YY_MM_DD`)>.

Choose Save.

### Import user settings

An exported User Settings file can quickly configure InDesign.

Choose File > User Settings > Import User Settings.

Choose the saved User Settings file.

Choose Restart Now to import the User Settings.

### Scenarios when user settings cannot be imported

Importing User Settings may fail when the exported settings were created under:

- another locale.
- another InDesign version, including latest public version, beta app, or pre-release app.
- another OS platform.

### Limitations

While User Settings are imported, these values are reset to default:

- Interface > Live Screen Drawing
- User Interface Scaling
- Type > Enable in-menu font previews > Number of Recent Fonts to Display
- Type > Enable Japanese Font Preview in 'Find More'
- Type > Sort Recent Fonts List Alphabetically
- Type > Preview Font on Hover
- Advanced Type > Type Contextual Controls > Show Adornment on Text Selection/ Text Frame for more Type controls
- Clipboard Handling > Show Auto Style Option
- Clipboard Handling > Show Paste Options

## Adjust text display quality

In Adobe InDesign, you can manage text smoothing, Greek text behavior, and display quality levels.

To manage on-screen text in InDesign, use options that smooth text edges, substitute gray bars for very small text, and switch display quality levels. These settings support readability and display performance when working on dense layouts or checking final output.

### Enable anti-aliasing for smooth edges

Open Edit > Preferences > Display Performance (Windows) or InDesign > Preferences > Display Performance (macOS).

In the Preferences panel, choose the view setting you need from Adjust View Settings.

Turn on Enable Anti-aliasing.

Select OK.

### Set Greek type threshold

When the display cannot render very small letters clearly, InDesign may show that text as a muted bar instead. This substitution is greeking type: any type at or under the configured size appears on-screen as placeholder shapes rather than actual letterforms.

Open Edit > Preferences > Display Performance (Windows) or InDesign > Preferences > Display Performance (macOS).

In Adjust View Settings, choose the view setting you want to change.

Enter the point value in Greek Type Below.

Select OK.
