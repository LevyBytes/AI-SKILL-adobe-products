## Starters and samples

Use the samples and starter templates as a launch point when building scripts and plugins for real production problems.

Treat 'samples' as working examples for particular features. A 'starter' focuses on helping you set up the framework.

### Git repo

Samples and starters for scripts/plugins are available at [here](https://github.com/AdobeDocs/uxp-indesign-samples).

### UDT

UDT also includes several templates that can be selected while creating a new plugin.

[Figure: Templates in UDT](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/main/src/pages/resources/starter-kits/create-plugin-template.png)

### In-app helpers

InDesign ships with ready-to-run sample UXP Scripts inside the application. They are located under Windows-> Utilities -> Scripts panel.

[Figure: Packaged sample scripts](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/main/src/pages/resources/starter-kits/scripts-panel.png)

### Recipes

The following [recipes](uxp-recipes-2.md) section includes examples for common use cases.

Script examples can be used in plugins, and plugin examples can be used in scripts. One useful model is to view UXP plugins as UXP scripts combined with rich UI controls and manifest configuration.

Additional samples for relevant use cases are welcome. Contribute to the repo, share your work with the community, create a pull request, and tag the maintainers for review.
