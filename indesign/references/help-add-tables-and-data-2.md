# Table And Cell Styles, Strokes And Fills

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

## Overview

Covers: Define and apply table and cell styles; Apply table cell styles; Import table and cell styles; Manage table and cell styles; Base one table or cell style on another; Override table style; Add strokes and fills to cells; Add alternating strokes and fills; Add diagonal lines to a cell; Table stroke and fill options; Change table border settings.

## Define and apply table and cell styles

Adobe InDesign table and cell styles help apply consistent table formatting.

For consistent formatting across tables, create, define, and apply table and cell styles in InDesign. Table styles govern the overall table structure; cell styles handle formatting for individual cells. Defining and updating styles preserves consistency and reduces repeated manual formatting work.

### Define a cell style

Open Window > Styles > Cell Styles.

From the panel menu icon, choose New Cell Style.

Type the new style name in the Style Name field.

For Based On, pick the style whose attributes should be inherited, or choose [None].

In the Shortcut field, combine modifier keys with a number from the numeric keypad.

Choose the required style in the Paragraph Style drop-down menu.

Confirm with OK.

### Define a table style

Open Window > Styles > Table Styles.

From the panel menu icon, choose New Table Style.

Type a name in the Style Name field.

Use the Based On drop-down menu to inherit another style, or choose [No Table Style].

In the Shortcut field, enter modifier keys together with a numeric keypad number.

For Header Rows, Footer Rows, Body Rows, Left Column, and Right Column, assign the appropriate Cell Styles.

Confirm with OK.

### Apply styles to tables and cells

With the Type tool, highlight the cells you want to format, or put the insertion point anywhere inside the table when applying a table style.

Open Window > Styles > Cell Styles or Table Styles.

Apply a style by selecting it. To change a style that already exists, double-click that style.

Adjust the needed attributes in the Table Style Options or Cell Style Options dialog box.

Confirm with OK.

## Apply table cell styles

Use cell styles in InDesign when table-cell formatting needs to remain consistent.

InDesign cell styles give document tables a repeatable way to format individual cells. A cell style can manage text formatting, borders, fills, and spacing inside a cell. Apply one directly to selected cells, or assign cell styles to defined table areas through table styles. Because the reusable formatting is stored in the style, consistency is maintained while unrelated cell properties can stay as they are.

### Apply a cell style to selected cells

With the Type tool, select the cells that need formatting.

Open Window > Styles > Cell Styles.

Choose the cell style that should be applied to the selected cells.

### Assign cell styles within a table style

Open Window > Styles > Table Styles.

Use Create New Style icon.

Open the table style by double-clicking it.

In the Cell Styles section, choose a cell style from Header Rows, Footer Rows, Body Rows, Left Column, or Right Column.

Confirm with OK.

## Import table and cell styles

Bring table and cell styles from another Adobe InDesign document when matching formatting across files.

InDesign can reuse table and cell styles from a different document so formatting stays aligned between documents. Imported styles can also bring dependent resources, such as paragraph styles and swatches, into the current project. When an imported style has the same name as an existing one, choose whether to replace that definition or rename the incoming style.

Open Window > Styles > Cell Styles or Table Styles.

Use the panel menu icon, then choose Load Cell Styles, Load Table Styles, or Load Table and Cell Styles.

Select the InDesign document, then import its styles by double-clicking the file.

Within the Load Styles dialog box, mark the styles that should come in.

When names conflict, choose Use Incoming Style Definition to replace the existing style, or choose Auto-Rename to preserve both versions.

Confirm with OK.

## Manage table and cell styles

In Adobe InDesign, table and cell styles can be edited, cleared, and redefined to keep formatting steady.

Use table and cell style management in InDesign when table formatting needs updates, removal, or redefinition. Table styles govern the table as a whole, while cell styles handle the appearance of individual cells. Updating, clearing, or redefining those styles keeps documents consistent and cuts down on repeated manual formatting.

### Edit an existing style

Open Window > Styles > Table Styles or Cell Styles.

In the panel, right-click the style name and choose Edit [style name].

Specify the formatting in the Table Style Options or Cell Style Options dialog box.

Confirm with OK.

### Clear table and cell formatting

Open Window > Styles > Table Styles or Cell Styles.

In the Table Styles or Cell Styles panel, choose the table or cell style.

Use Delete icon, or right-click and choose Delete Style.

### Redefine a table and cell style

Open Window > Styles > Table Styles or Cell Styles.

In the Table Styles or Cell Styles panel, choose the table or cell style.

Open the panel menu icon, then choose Redefine Style.

## Base one table or cell style on another

In Adobe InDesign, one table or cell style can be built from another style to reuse formatting.

Base an InDesign table or cell style on another style when you want parent-and-child style relationships. Child styles take formatting from the parent but can still carry their own targeted changes. When the parent changes, matching shared attributes in the child styles update as well, improving consistency and reducing manual adjustments.

Open Window > Styles > Table Styles or Cell Styles.

Use Create New Style icon.

Open the new style by double-clicking it.

Type a name in the Style Name field.

Choose the parent style from the Based On dropdown menu.

Apply formatting from the Cell Styles section.

Confirm with OK.

## Override table style

Use local formatting changes in Adobe InDesign table and cell styles without altering the original style.

InDesign table and cell style overrides let you change local formatting while leaving the original style definition intact. Overrides support specific formatting differences while the applied style remains in place.

### Apply formatting to create an override

Open Window > Styles > Cell Styles or Table Styles.

Choose the Table tab.

From the panel menu icon, choose Table Options > Table Setup or Cell Options > Text.

Change formatting in the Table Options or Cell Options panel.

Confirm with OK.

### Clear overrides while applying a table style

Open Window > Styles > Cell Styles or Table Styles.

Choose a table or cell that has overrides.

Use Clear overrides in selection icon, or hold Alt (Windows) or Option (macOS) while choosing the style.

To apply a table style and clear overrides plus cell styles at the same time, press Alt+Shift (Windows) or Option+Shift (macOS) while choosing the style in the panel.

### Break the link between formatting and styles

Open Window > Styles > Cell Styles or Table Styles.

Choose a table or cell.

From the panel menu icon, choose Break Link to Style.

## Add strokes and fills to cells

Use strokes and fills in Adobe InDesign table cells to control borders and background formatting.

InDesign applies strokes and fills to table cells through Cell Options, the Stroke panel, or the Swatches panel. These approaches format single cells or selected cell groups, improving readability and creating clearer visual separation.

### Add strokes and fills using Cell Options

With the Type tool, select the cells. For header or footer row formatting, choose cells at the start of the table.

Open Table > Cell Options > Strokes and Fills.

Choose lines in the proxy preview area for formatting. Lines that are selected appear blue, and lines that are not selected appear gray.

Double-click an outside edge to choose the outer border, or double-click an inside line to choose interior lines. Triple-click to choose or clear every line.

Set the Cell Stroke and Cell Fill properties.

Enable Overprint Stroke or Overprint Fill when required.

Confirm with OK.

### Add a stroke to cells using the Stroke panel

With the Type tool, select the cells.

Open Window > Stroke.

Choose lines in the proxy preview area.

In the Tools panel, choose the Formatting affects container tool.

Set the Weight and Type in the Stroke panel.

### Add a fill to cells using the Swatches panel

With the Type tool, select the cells.

Open Window > Color > Swatches.

In the Tools panel, choose the Formatting affects container tool, then choose a color from the Swatches panel.

### Add a fill to cells using the Gradient panel

With the Type tool, highlight the target cells.

Choose Window > Color > Gradient.

In the Tools panel, activate the Formatting affects container tool, and then pick a color in the Swatches (Window > Color > Swatches) panel.

Use Gradient Ramp on the selected cells, and change the gradient controls as needed.

## Add alternating strokes and fills

Adobe InDesign tables can use alternating strokes and fills on rows or columns to make the layout easier to scan.

InDesign lets you apply row or column patterns across table strokes and fills. These repeating treatments improve readability and add rhythm to tabular content. The patterning affects body cells, and row-based and column-based settings can be adjusted separately.

### Apply alternating strokes to table rows or columns

Put the insertion point inside a table, or select a cell.

Choose Table > Table Options > Alternating Row Strokes or Alternating Column Strokes.

From the Alternating Pattern drop-down menu, choose the pattern you want.

For First and Next rows, define weight, type, color, tint, and gap color.

Use Skip First for rows or columns at the start, and use Skip Last for rows or columns at the end.

Enable Preserve Local Formatting when individual cell stroke formatting should remain unchanged.

Select OK.

### Apply alternating fills to table rows or columns

Put the insertion point inside a table, or select a cell.

Choose Table > Table Options > Alternating Fills.

From the Alternating Pattern drop-down menu, choose the pattern you want.

For First and Next rows, define color and tint.

Use Skip First for rows or columns at the start, and use Skip Last for rows or columns at the end.

Enable Preserve Local Formatting when individual cell fill formatting should remain unchanged.

Select OK.

### Turn off alternating strokes or fills

Put the insertion point inside a table, or select a cell.

Choose Table > Table Options > Alternating Row Strokes, Alternating Column Strokes, or Alternating Fills.

From the Alternating Pattern drop-down menu, choose None.

Select OK.

## Add diagonal lines to a cell

Adobe InDesign can split table cells visually with diagonal lines so content is easier to organize.

InDesign supports diagonal rules inside table cells for showing division or structure. These lines can make data presentation clearer by separating information within a cell. You can choose the diagonal direction and adjust stroke settings to fit the surrounding formatting.

Using the Type tool, select the cells.

Choose Table > Cell Options > Diagonal Lines.

Pick the diagonal line direction you need.

Configure Line Stroke properties.

From the Draw drop-down menu, choose Diagonal in Front or Content in Front.

Select OK.

## Table stroke and fill options

Adobe InDesign provides stroke and fill controls that determine how tables and individual cells appear.

Open Table > Cell Options > Strokes and Fills when you need border or fill settings for table cells.

## Change table border settings

Adobe InDesign lets you change a table's outside border by editing its stroke settings.

InDesign table borders control the outer stroke surrounding a table. You can revise that frame by changing weight, style, color, tint, and drawing order. Adjusting the border can improve clarity and keep formatting consistent.

Using the Type tool, select a cell in the table.

Choose Table > Table Options > Table Setup.

In the Table Border section, set border weight, type, color, tint, and the other required options.

In the Stroke Drawing Order section, choose the drawing order from the Draw drop-down menu.

To keep stroke formatting already applied to individual cells, enable Preserve Local Formatting.

Select OK.
