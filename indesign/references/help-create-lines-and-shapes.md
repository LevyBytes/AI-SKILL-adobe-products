## Types of paths and shapes

See how Adobe InDesign uses simple paths, compound paths, and compound shapes, and how these objects differ.

All vector graphics are built from paths, so each shape you draw starts with a path. Knowing how path types behave makes it easier to build complex artwork and manage shape interactions.

Adobe InDesign works with three main path types: simple paths, compound paths, and compound shapes. The types progress from basic to more flexible structures, with each offering a different level of control.

### Simple paths

Simple paths are the base-level objects: one open or closed path, possibly self-intersecting. They become the starting pieces for building more complex shapes.

### Compound paths

Compound paths merge at least two simple paths into one object. The included paths use shared attributes such as fill and stroke and act as a single unit. Designers often use them for shapes that contain transparent areas.

### Compound shapes

Compound shapes bring several paths or objects together while leaving each component separately editable. In contrast to compound paths, individual parts may keep different attributes and can be changed on their own.

## Draw with the pencil tool

Use this topic to create freehand paths with the Pencil tool in Adobe InDesign.

In InDesign, the Pencil tool lets you sketch open or closed paths that retain a natural, hand-drawn appearance. As your cursor moves, InDesign inserts anchor points for the path automatically. That workflow is useful for organic shapes and fast page sketches.

### Draw an open path

Choose the Pencil tool.

Place the cursor where the path should begin, then drag out the path.

Let go to finish the path.

### Draw a closed path

Choose the Pencil tool and place the cursor at the beginning point.

Drag out the path.

To make the path close, keep Alt (Windows) or Option (macOS) held down while you drag.

Let up on the mouse button first, and then let go of Alt or Option.

### Edit an existing path

With the Selection tool, choose the path.

Choose the Pencil tool.

Move the Pencil tool close to the path until the x is no longer shown.

Drag across the section of the path you want to redraw.

### Connect two separate paths

With the Selection tool, choose both paths.

Choose the Pencil tool.

Start on one endpoint and drag the cursor toward the other path.

To combine the paths, keep Ctrl (Windows) or Cmd (macOS) held down as you drag.

Release the mouse button first, and then release Ctrl or Cmd.

### Adjust Pencil tool settings

Double-click the Pencil tool to display the Pencil Tool Preferences panel.

Adjust Fidelity to set how tightly the path tracks the cursor.

Adjust Smoothness to set the amount of smoothing applied to curves.

Turn on Keep Selected if the workflow calls for it.

Turn on Edit Selected Paths, and then adjust Within if needed.

Choose OK.

## Draw lines with the pen tool

Use this topic to build precise paths from anchor points and curves with the Pen tool in Adobe InDesign.

In InDesign, the Pen tool creates straight or curved paths by placing anchor points. It gives detailed control over custom path shapes. Use it for detailed shapes, tracing work, and paths that mix straight and curved segments.

### Draw straight line segments

Choose the Pen tool.

Place the cursor, then click to add the first anchor point.

Move the cursor and click again to add the next anchor point.

To limit the angle, hold Shift while dragging.

Press Esc when the path is complete.

### Draw curved segments

Choose the Pen tool.

Drag after clicking to set the first anchor point with direction handles.

Reposition the cursor, then click and drag to shape the curve.

Keep adding anchor points and dragging from them to continue the path.

Press Esc when the path is complete.

### Draw straight segments followed by curves

Choose the Pen tool.

Click twice to make a straight segment.

Click and drag to pull out direction handles.

Click and drag again to make a curved segment.

### Draw curved segments followed by straight lines

Choose the Pen tool.

Click and drag to make the first smooth point and form the curve.

Click the smooth point so it becomes a corner point, then make a straight segment.

### Draw two curves connected by a corner

Choose the Pen tool.

Click and drag to make the first smooth point, then add the curve endpoint with direction handles.

Hold Alt (Windows) or Option (macOS), then drag the direction handle to split it.

Let go of Alt or Option, then click and drag to make the next curve.

## Reposition anchor points as you draw

Use this topic to move an anchor point while you are creating a path with the Pen tool in Adobe InDesign.

While drawing in InDesign, the Pen tool can reposition anchor points without breaking the current path operation. This lets you place points more accurately during path creation. It is helpful for exact shapes and detailed path refinement.

Choose the Pen tool.

Click and keep holding to place an anchor point.

Keep holding, and also hold the Spacebar.

Drag to move the anchor point into position.

Release the Spacebar, then release the pointer to set the point.

## Manage automatic pen tool switching

Use this topic to override automatic Pen tool switching temporarily with keyboard shortcuts in Adobe InDesign.

In InDesign, you can control editing behavior by overriding automatic Pen tool switching while working on paths. Holding a tool shortcut key keeps the automatic switch from happening and supports precise edits. That prevents accidental path changes.

Activate the Pen tool.

Keep a tool shortcut key held down, such as A for Direct Selection.

Apply edits while the shortcut key remains held down.

Release the shortcut key to go back to the Pen tool.

## Draw basic lines and shapes

Use this topic to create lines, rectangles, ellipses, and polygons for Adobe InDesign layouts with the drawing tools.

InDesign drawing tools let you make custom graphics, frames, and design elements that keep clean scaling. You can place filled shapes or placeholder frames directly in the layout with these tools.

From the toolbar, choose one drawing tool: Line tool, Ellipse tool, Rectangle tool, or Polygon tool.

In the document window, drag to draw the line or shape.

To keep a line at 45Â° angles, or to keep a path's width and height proportional, hold Shift while dragging.

To draw outward from the center, hold Alt (Windows) or Option (macOS) while dragging.

To move the shape before releasing the mouse button, hold Spacebar while dragging.

While dragging, use the Up and Down arrow keys to change the number of sides of a polygon, and use the Left and Right arrow keys to adjust how many polygons are created.

Tip

After drawing, press V or Esc to change to the Selection tool so you can immediately reposition or resize the new shape.

## Draw multiple objects as a grid

Use this topic to create evenly spaced rows and columns of frames in Adobe InDesign by pressing arrow keys while dragging.

In InDesign, frame-creation tools can build structured grid layouts as you draw by changing rows, columns, and spacing, avoiding the need to duplicate and position each frame by hand.

Choose from these frame-creation tools: Polygon Frame tool, Rectangle Frame tool, Ellipse Frame tool, or Type tool.

After choosing one, drag until the frame starts forming.

With the mouse button still held down, press these keys:

- Right Arrow key: increases the column count.
- Left Arrow key: decreases the column count.
- Down Arrow key: increases the row count.
- Up Arrow key: decreases the row count.

To change gutter spacing between frames, hold down Ctrl (Windows) or Command (macOS) while pressing the arrow keys.

Release the mouse button.

## Create and customize placeholder frames

Use this topic to make placeholder frames in Adobe InDesign and adjust their size and polygon shape options.

Placeholder frames are layout containers used before final content is added, and an X indicates that a frame is empty. Build image or text containers ahead of time by using Frame tools and configuring their settings.

### Create a placeholder frame

Choose one of these frame tools: Rectangle Frame tool, Ellipse Frame tool, or Polygon Frame tool.

Drag to set the frame dimensions.

To force equal width and height, hold Shift while dragging.

To draw outward from the center, hold Alt (Windows) or Option (macOS) while dragging.

### Configure polygon frame settings

Double-click the Polygon Frame tool to display the Polygon Settings dialog box.

In Number of Sides, type the value that determines how many sides the polygon uses.

In Star Inset, type a percentage to make star shapes.

At 0%, the result is a regular polygon; higher values (40-50%) make longer, narrower points, while lower values (10-20%) make subtler points.

Choose OK.

## Edit and reshape paths

Use Adobe InDesign selection tools and path-editing commands to change anchor points, segments, and curves.

Every shape, line, and drawn object in InDesign gets its outline from a path. After drawing, edit and reshape paths to refine the design: soften overly sharp curves, reposition segments so they fit the layout better, or place anchor points for precise alignment.

### Move straight segments

With the Direct Selection tool, choose the segment that needs adjustment.

Drag that segment into its new position.

### Adjust the length or angle of straight segments

With the Direct Selection tool, choose an anchor point on the segment that needs adjustment.

Move the anchor point to the desired position. Shift-drag to limit the change to 45° increments.

### Adjust the position or shape of curved segments

With the Direct Selection tool, choose a curved segment, or choose an anchor point at either end of that curved segment. If direction lines exist, they appear.

To reposition the segment, drag it. Shift-drag limits the adjustment to 45° increments.

For shape changes around the selected anchor point, move either the anchor point or its direction point. Hold Shift while dragging to limit movement to 45° increments.

### Delete a segment

With the Direct Selection tool, choose the segment to remove.

Press Backspace (Windows) or Delete (macOS) to remove the selected segment.

Press Backspace or Delete again to remove the rest of the path.

### Delete the handle of an anchor point

With the Convert Direction Point tool, choose the handle's anchor point.

Drag the direction point onto the anchor point and release it there.

### Move or nudge anchor points or segments using the keyboard

Choose the anchor point or path segment.

Press an arrow key to move 1 pixel in that arrow's direction. Add the Shift key while pressing the arrow key to move 10 pixels at a time.

### Split a path

Split locations can be anchor points or path segments on a path, graphics frame, or empty text frame. Keep these behaviors in mind:

- To turn one closed path into two open paths, cut it in two separate places. A single cut leaves one path with a gap.
- Split paths keep the original stroke and fill settings, although stroke alignment may need adjustment.

### Split a path with the Scissors tool

Select the path so its current anchor points are visible.

Select the Scissors tool.

Select the location on the path where you want the split; new endpoints appear.

Use the Direct Selection tool to refine the new anchor point or path segment.

### Open a path from the Pathfinder panel

Choose the closed path.

Open Window > Object & Layout > Pathfinder.

In the Pathfinder dialog box, select the Open Path icon.

### Smooth out paths

Use the Smooth tool when an existing path, or a section of one, contains too many angles. Smoothing usually reduces the point count, which makes editing, display, and printing simpler.

Choose the path.

Select the Smooth tool.

Drag along the path segment that needs smoothing.

Keep smoothing until the stroke or path reaches the desired smoothness.

To adjust smoothing strength, double-click the Smooth tool and configure these options:

- Fidelity Sets how closely curves track the pointer. Lower values preserve sharper angles, while higher values ignore small movements to create smoother curves. The pixel value range is 0.5 to 20 pixels.
- Smoothness Sets how much smoothing the tool applies. Smoothness can range from 0% to 100%. Higher values make the path smoother.
- Keep Selected Sets whether the path remains selected after smoothing.

Select OK.

### Reshape closed paths or objects

With the Direct Selection   tool, drag around the anchor points to include. You can also shift-click individual anchor points.

Move the pointer over the anchor point or segment that should act as the focal point, then select it.

Drag the highlighted anchor points to adjust the path.

Note

Distance from the focal point controls the movement. The focal point itself moves directly; selected points travel along with it; points outside the selection do not move.

## Add or delete anchor points

Use the Pen tool options in Adobe InDesign to add or remove anchor points on paths.

Adding anchor points increases path control or lengthens an open path. Removing points you do not need simplifies paths, making them easier to edit, display, and print.

This workflow changes existing paths by altering how many anchor points they contain. For reshaping that involves moving anchor points or changing direction handles, switch to the Direct Selection tool.

On any selected path, anchor points can be added or deleted with the Pen tool, Add Anchor Point tool, or Delete Anchor Point tool. When the pointer is over a selected path or anchor point, InDesign changes the Pen tool to the matching mode automatically.

From the toolbar, select the Pen tool to draw the path.

Choose the Add Anchor Point tool, move the pointer to a path segment, and click to insert an anchor point.

Choose the Delete Anchor Point tool, move the pointer to an anchor point, and click to remove that anchor point.

Caution

When deleting anchor points, avoid the Delete or Backspace keys and the Edit > Cut or Edit > Clear commands. Those actions remove the point plus the connected line segments.

## Convert anchor points

Convert path anchor points in Adobe InDesign while keeping the broader shape intact.

Paths use two anchor-point types. Corner points make sharp direction changes, and smooth points produce continuous curves. The Convert Direction Point tool switches between these point types and changes how the path behaves.

### Use the Convert Direction Point tool

Using the Direct Selection tool, choose the path.

From the Pen tool context menu, choose the Convert Direction Point tool.

Put the tool on the target anchor point, then apply the required action:

- From a corner point, pull out direction lines to create a smooth point.
- Select a smooth point to turn it into a corner point without direction lines.
- From a corner point, drag direction lines, release, and then pull one direction line to create a corner point with independent handles.
- From a smooth point, drag one direction line to convert it into a corner point with independent handles.

### Convert using the Pathfinder option

Choose the path with the Direct Selection   tool.

Open Window > Object & Layout > Pathfinder.

In the Convert Point section, select one of the points.

Note

An anchor point selected with the Direct Selection   tool can also be converted by selecting Object > Convert Point.

## Extend, join, and convert paths

Use Adobe InDesign controls to extend, join, close, and convert paths for precise shape control.

To build continuous shapes, extend open paths or join them. These operations help control path direction and structure while preserving smooth or corner transitions.

### Extend an open path

Choose the Pen tool, then hover on an open path endpoint until the pointer changes.

When the pointer changes, click the endpoint to extend the path.

For a corner point, click where the segment should end.

For a smooth point, click and drag where the curved segment should end.

### Connect two open paths

Choose the Pen tool, then hover on the first open path's endpoint until the pointer changes.

When the pointer changes, click the endpoint to extend the path.

To connect another open path, choose the other path's endpoint when the merge symbol appears beside the pointer icon.

To connect a new path, draw the new segment, move the pointer to the existing path’s endpoint, and select once the merge symbol appears.

### Close or join paths

Choose an open path with the Selection tool.

Open Window > Object & Layout > Pathfinder.

To close one open path, select the path with the Selection tool, then choose the Close Path icon.

To close endpoints between two paths, choose both paths and select the Join Path icon. Select the Join Path icon again to join the second endpoint.

### Convert path shape

Any existing path can be transformed into a predefined shape, such as a triangle or polygon. After conversion, the original stroke settings remain, preserving visual consistency.

When converting to a polygon, the resulting shape uses the settings defined in the Polygon Settings dialog box.

### Convert a path from the Object menu

With the Selection tool or the Direct Selection tool, choose the path to convert.

Select Object > Convert Shape, then choose the desired shape from the submenu: Rectangle, Rounded Rectangle, Beveled Rectangle, Inverse Rounded Rectangle, Ellipse, Triangle, Polygon, Line, or Orthogonal Line.

### Convert a path through the Pathfinder panel

Choose the path with the Selection tool.

Open Window > Object & Layout > Pathfinder.

In the Convert Shape section of the Pathfinder panel, select the desired shape.

Note

If the new shape includes corner effects, the radius comes from the values set in the Corner Options dialog box (Object > Corner Options).

## Apply and save line stroke styles

Define reusable dash, dot, and stripe patterns for strokes in Adobe InDesign.

Create and save custom stroke styles in InDesign with the Stroke panel to define line patterns. Custom stroke styles keep dashed, dotted, or patterned lines consistent across objects. Saving these styles makes them reusable across documents and helps maintain design consistency.

### Apply strokes to paths and frames

Choose the path, frame, or shape with the Selection tool.

Open Window > Stroke.

In the Weight drop-down menu, choose a weight, or type a value and press Enter.

When additional properties are hidden, use the panel menu    icon and choose Show Options.

From the Type drop-down menu, choose a stroke type.

Set Cap, Join, and Align Stroke.

### Create custom stroke styles

Open Window > Stroke.

### Save and load custom stroke styles

## Add start and end shapes to lines

Use the Stroke panel in Adobe InDesign to place arrowheads or other decorative endpoint shapes on lines.

Start and end shapes control how the endpoints of a path are drawn. In the Stroke panel, these shapes are assigned to create arrows and other directional markers.

### Add start and end shapes

Create an open path, or draw a line with the Line tool.

Show the Stroke panel from the docked panel workspace. If it is not visible, open Window > Stroke.

Use the Selection tool to select the path or line.

In the Stroke panel, choose a shape from the Start menu to assign it to the first endpoint.

Choose a shape from the End option to assign it to the last endpoint.

Use the Stroke panel to preview and apply start and end shapes on strokes.

Preview strokes in the Stroke panel and apply the chosen start and end shapes.

### Switch a path’s start and end shapes

Select the path with either the Selection tool or the Direct Selection tool.

Open Object > Path > Reverse Path.

### Guidelines for start and end shapes

Keep these points in view while working with start and end shapes:

- The built-in start and end shapes cannot be edited, but plug-in software can add choices that appear in the Start and End menus in the Stroke panel.
- Start and end shapes scale relative to stroke weight. Adding one to either end leaves the path length unchanged.
- Each start or end shape turns automatically to align with the angle of that endpoint's direction line.
- Start and end shapes display only on endpoints of open paths; they do not appear on separate dashes within a dashed stroke.
- When a compound path has open subpaths, applying start and end shapes gives every open subpath the same start and end shapes.
- Closed paths can receive start and end shapes, but those shapes stay hidden until the path is opened.

## Apply corner effects to frames

In Adobe InDesign, rectangular frames and paths can receive rounded or ornamental corner effects.

Corner effects change path corners, ranging from basic rounded edges to more decorative treatments. Apply them to frames and paths when the object needs additional visual styling.

### Apply corner effects using Corner Options

Use the Selection tool to choose the frame or path that needs changes.

Open Object > Corner Options.

Click the Make all settings the same icon when every corner should share one effect, or turn it off to set corners individually.

From the corner effect dropdown menus, choose Fancy, Bevel, Inset, Inverse Rounded, or Rounded.

Enter a size value that determines how far the effect reaches from each corner point.

Turn on Preview to inspect the result, then click OK.

### Apply corner effects using Live Corners

Live Corners lets you change rectangular-frame corners by selecting the yellow box on the frame and dragging. Each corner can also use its own corner effect and radius.

Select a rectangular frame with the Selection tool.

Click the small yellow box near a frame corner. Four yellow diamonds appear on the selected frame to show that Live Corners mode is active.

If the yellow box is missing on the selected frame, open View > Extras > Show Live Corners.

Drag any diamond toward the frame center to change all four corner radii together.

Hold Shift while dragging a diamond to change just one corner.

Alt-click (Windows) or Option-click (macOS) a yellow diamond to move through the available effects.

Select anywhere outside the selected frame to finish corner editing.

To clear corner effects, open Object > Corner Options, then choose None from the corner effect dropdown menus.
