# previousItem

> GotoNextPageBehavior **previousItem**( GotoNextPageBehavior **obj** )
>

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| GotoNextPageBehavior | obj | GotoNextPageBehavior index that comes after the desired GotoNextPageBehavior. |
