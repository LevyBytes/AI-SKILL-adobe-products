# View Select Tools, Change The Toolbox Layout, Use Contextual Task Bar, Create Layouts With Hand Gestures

> Adobe InDesign reference. Original prose; identifiers preserved verbatim.

## Overview

Covers: View and select tools; Change the toolbox layout; Use the Contextual Task Bar; Create layouts with hand gestures.

## View and select tools

Use visible icons or expanded hidden tool groups to reach tools in Adobe InDesign.

The InDesign toolbox gives fast access to selection, drawing, type, transformation, and navigation tools. Knowing how to show and move through the toolbox can speed routine work.

By default, the toolbox is displayed as one vertical column. Related hidden tools are marked with small arrows on some tool icons. Keyboard shortcuts can temporarily change the active tool.

### View and select visible tools from the toolbox

Open Window > Tools.

The toolbox is shown in the workspace; drag its top edge to move it.

Choose the tool icon you want in the toolbox.

Point at a tool to display a tooltip with its name and keyboard shortcut.

Note

To disable tool tips, open Edit > Preferences > Interface (Windows) or InDesign > Preferences > Interface (macOS), then set Tool Tips to None.

### Access hidden tools

Hidden tools sit in groups with related tools. For example, the Rectangle tool is grouped with the Ellipse tool and the Polygon tool.

Place the pointer over a tool that shows a small arrow in the lower-right corner.

Long-press or right-click the main tool to reveal the hidden tools.

### Switch tools temporarily

After selecting one tool, hold down the keyboard shortcut for a different tool.

Complete the action while the keyboard shortcut remains held.

Release the keyboard shortcut to switch back to the previous tool.

### View tool hints

The Tool Hints panel explains, for the selected tool, how modifier keys such as Shift, Alt (Windows), or Option (macOS) change its behavior.

Open Window > Utilities > Tool Hints.

Choose any toolbox tool to display its description, modifier keys, and shortcuts.

## Change the toolbox layout

Set the Adobe InDesign toolbox to appear as a single column, double column, or horizontal row.

All InDesign selection, drawing, type, transformation, and navigation tools are available from the toolbox. It uses a single vertical column by default, but the layout can be changed to better fit your workspace, screen dimensions, or preferences. Tool locations inside the toolbox are fixed, so you cannot rearrange individual tools.

Open Edit > Preferences > Interface (Windows) or InDesign > Preferences > Interface (macOS).

Find Floating Tools Panel in the Preferences dialog box.

Choose a layout option you prefer: Single Column, Double Column, or Single Row.

Select OK.

Tip

The double-arrow at the upper-left of the toolbox can also switch the layout.

## Use the Contextual Task Bar

Use the floating Contextual Task Bar in Adobe InDesign to adjust text, frame, and panel options from the current workspace.

The Contextual Task Bar changes with the active selection and surfaces relevant formatting and workflow controls so you do not need separate panels or menus. Make sure it is visible; if it is hidden, choose Window > Contextual Task Bar to show it.

### Use scripts to control Contextual Task Bar visibility

At either the app level or user level, a custom script can now show or hide the Contextual Task Bar.

### Use the Contextual Task Bar from a blank workspace

Create a new document in InDesign.

From the Contextual Task Bar, choose any of these options:

- Add a frame , then drag in the workspace to draw a new frame.
- Start with Image , then choose Import File to bring in an existing image, or choose Text to Image to make an image from a simple text prompt.
- Type tool, then drag anywhere in the workspace to make a text frame and begin typing.
- Margins and Columns , then define the Margin and Column specifications for the document.
- Add a Page , to insert a new page using the same dimensions and properties as the current page.

Use the ellipsis icon for Show Properties Panel , Start with a Template , Hide Context Bar , or Unpin Context Bar .

### Use text formatting options

Choose the Type tool from the Contextual Task Bar.

Drag anywhere in the workspace to make a text frame and enter content.

In the Contextual Task Bar, choose Generate Text  , Font Name, Font Style, Font Size, Fill color, and Align options.

Apply saved styles by using the Paragraph and Character text styles icon.

Use the ellipsis icon for Show Properties Panel , Start with a Template , Hide Context Bar , or Unpin Context Bar .

### Use frame and image options

Choose Add a Frame from the Contextual Task Bar.

Drag in the workspace to draw an image frame at the size you want.

Choose Start with Image > Text to Image to create an image from a text prompt, or choose Import Image to place an existing file.

Use the ellipsis icon for Show Properties Panel , Start with a Template , Hide Context Bar , or Unpin Context Bar .

## Create layouts with hand gestures

On touch-enabled devices, use the Touch workspace and drawing gestures to build layout objects.

The Touch workspace is intended for Windows hardware that supports touch, such as tablets, touchscreen laptops, and touch-capable desktop systems. Files that include objects made in other workspaces still display correctly, though editing is limited to objects supported by the Touch workspace.

Detaching the keyboard from a touch-enabled device switches automatically to the Touch workspace; reattaching it restores the previous workspace. To switch manually, choose Window > Workspace > Touch.

In the Touch workspace, the four main tools are Drawing tool, Type tool, Frame tool, and Shape tool. Drawing tool is unique to this workspace; Type tool creates text frames, Frame tool creates graphics placeholders, and Shape tool creates rectangles, ellipses, and polygons. InDesign turns 16 recognized hand gestures made with the Drawing tool into layout elements.

Create a new document, or open an existing one.

Choose the Drawing tool from the toolbar if it is not already active.

Use the Help icon in the upper-right corner to open the complete gesture reference guide with all 16 available gestures.

Draw any supported gesture directly on the canvas to create its matching element.

Use the panels on the right side of the workspace to refine elements by changing colors, opacity, alignment, and other properties.
