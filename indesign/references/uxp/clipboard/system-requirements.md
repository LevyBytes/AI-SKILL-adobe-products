# System requirements

Confirm that your local setup is running these application versions before you continue.

- InDesign v18.5 or higher
- UXP version v7.1 or higher
- Manifest version v5 or higher

Plugins and Scripts

**In plugins**, request manifest permission before using `clipboard` access. IMPORTANT: Review [manifest permissions](../uxp-manifest/permissions-definition.md) before continuing.

**In scripts**, `clipboard` permission is predefined. The manifest details in the examples below can be ignored. The [manifest fundamentals section](../uxp-manifest.md) explains these values.
