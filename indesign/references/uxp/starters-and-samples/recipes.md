# Recipes

The following [recipes](../recipes.md) section includes examples for common use cases.

Script examples can be used in plugins, and plugin examples can be used in scripts. One useful model is to view UXP plugins as UXP scripts combined with rich UI controls and manifest configuration.

Additional samples for relevant use cases are welcome. Contribute to the repo, share your work with the community, create a pull request, and tag the maintainers for review.
