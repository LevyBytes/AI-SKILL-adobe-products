# CSS Variables

**Since** UXP v3.0

UXP allows CSS Variables, also called Custom Properties. Combined with the [prefers-color-scheme](media-queries/prefers-color-scheme/reference-index.md) media query, they make custom themes easy to build so they can respond to the host application's selected theme.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/--\*](https://developer.mozilla.org/en-US/docs/Web/CSS/--*)
