# font-style

**Since** UXP v2.0

Applies the element's font style. Accepted values are `normal` (default) and `italic`.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/font-style](https://developer.mozilla.org/en/docs/Web/CSS/font-style)

**Example**

```css
.someElement {
  font-style: italic;
}
```
