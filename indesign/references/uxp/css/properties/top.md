# top

**Since** UXP v2.0

For elements using relative or absolute positioning, assigns the offset from the top side.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/top](https://developer.mozilla.org/en/docs/Web/CSS/top)

**Example**:

```css
.someElement {
  top: 0;
  position: absolute;
}
```
