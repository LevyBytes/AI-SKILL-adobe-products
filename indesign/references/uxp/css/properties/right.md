# right

**Since** UXP v2.0

For elements using relative or absolute positioning, assigns the offset from the right side.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/right](https://developer.mozilla.org/en/docs/Web/CSS/right)

**Example**:

```css
.someElement {
  right: 0;
  position: absolute;
}
```
