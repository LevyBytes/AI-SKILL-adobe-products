# ::before

**Since** UXP v3.0

Adds a pseudo-element before whatever element matched the selector.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/::before](https://developer.mozilla.org/en-US/docs/Web/CSS/::before)

**Example:**

```css
.addBullet > *::before {
    content: "•";
}
```
