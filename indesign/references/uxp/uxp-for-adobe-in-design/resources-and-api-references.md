# Resources and API references

Build UXP scripts and plugins by studying the needed [fundamental concepts](../fundamentals.md) and using bite-size [recipes](../recipes.md) for common use cases.

Because UXP continues to evolve, watch the [latest APIs](../release-history/reference-index.md) in recent releases, and consult [UXP APIs](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/index.md) plus [InDesign APIs](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/dom/api/index.md) for the corresponding references.

The [sample repository](https://github.com/AdobeDocs/uxp-indesign-samples) provides ready-made plugins and scripts that make popular framework setup easier.
