## Access Express templates from InDesign

Browse Adobe Express templates from inside Adobe InDesign and use them without leaving the InDesign workflow.

InDesign includes access to Adobe Express templates, so you can inspect and preview prepared designs. After choosing one, open it in Express and customize it while staying within the app experience.

Choose Templates on the InDesign homescreen.

Choose a template so it appears in the Adobe Express Templates dialog box.

Choose Edit in Adobe Express.

After the template opens in Adobe Express, adjust its text, images, and design elements.

## Adobe Capture plugin

Use Adobe Capture inside Adobe InDesign to pull color themes, vector shapes, and font styles out of images, then turn them into design elements.

The Capture extension in InDesign can start from an inspiring image and produce creative assets, including color themes, shapes, and type. Store the generated assets in a Creative Cloud library, reuse them later in projects, or build additional assets from new images.

### Open Capture panel

Add an image to the InDesign document with File > Place.

With the Selection tool, choose the placed image.

Right-click the image, then choose Extract from Image > Color Themes, Shapes, or Type.

### Extract and save color themes

Create a color palette based on the image.

Adjust the palette with either of these controls:

- Reposition the round selectors over the image.
- Work with the settings under Color Mood.

Choose Save to CC Libraries to store the theme.

### Create shapes

Turn the chosen image into a black-and-white vector graphic.

In the Shapes tab, complete these adjustments:

- Detail: Move the slider to control how much detail appears in the vector image.
- Invert: Choose this option to swap the black and white regions.
- Smooth On Save: Choose this option when the vector image should be smoothed during save.
- Use the Eraser icon when you need to remove areas from the image.

Choose Save to CC Libraries to store the shapes.

### Extract and match fonts from images

For selected text inside an image, Adobe Fonts supplies the nearest font match. Choosing a font activates it automatically from Adobe Fonts so it is ready to use.

Use the crop handles to isolate a single letter or a text block.

Choose the font type, then use Sample Text to test the font with different wording.

Use the Edit feature and its sliders to change leading, tracking, font size, and style.

Choose Save to CC Libraries to add the new font type to your libraries as a character style or paragraph style.

## Create InDesign plug-ins with UXP

Build modern Adobe InDesign plug-ins with the Unified Extensibility Platform (UXP), using JavaScript ES5 plus ES6 capabilities supported by UXP.

Flyout menus, persistent storage, and Access Globally Unique Identifier (GUID) support can extend plug-in behavior and refine the user experience.

### Create InDesign plug-ins

Use UXP as the basis for creating plug-ins.

UXP supports modern JavaScript development, including ES5 and most ES6 features, for plug-in work.

### Flyout menu enhancements

Use a flyout menu to expose more InDesign operations while keeping the panel uncluttered:

- Run scripts from the flyout menu.
- Add sub-menus, then nest those menus through several levels.
- Use emojis in menu items.
- Set enabled properties so items are grayed out and unavailable.
- Programmatically change toggle, checked, and enabled properties.

### Persistent storage

Persistent storage lets plug-in data remain available between sessions or through version upgrades. User preferences and states stay accessible after the application has been closed.

### GUID support

For 3P plug-ins with GUID support, identify users so the experience can be personalized and smoother. GUID support is available through the UXP Developer Tool (UDT) and Creative Cloud Marketplace.

## Use Adobe Bridge with InDesign

Adobe Bridge can improve Adobe InDesign workflows by making asset management more efficient.

Bridge is included with Adobe Creative Cloud components and runs across platforms, giving you a way to find, organize, and browse assets for print, web, video, and audio projects. Launch Bridge from any Creative Cloud component except Adobe Acrobat(R), then use it with both Adobe and non-Adobe assets.

### Use Bridge to manage and access assets

Bridge supports these actions:

- Manage image, footage, and audio files: In Bridge, preview, search, sort, and process files without launching each individual application. You can edit file metadata as well, then place Bridge files into projects, compositions, or documents.
- View the links inside an InDesign document as thumbnails: While working in Bridge, inspect thumbnail previews of an InDesign document's links without opening the file in InDesign.
- Drag assets from Bridge into the InDesign document window: Move assets from Bridge into the InDesign document window, or move assets from the document window back into Bridge, to create and use snippets.
- Perform automated tasks: Run automation such as batch commands.
- Synchronize color settings: Keep color settings aligned across color-managed Creative Suite components.
- Start a real-time web conference: Begin a live web conference for desktop sharing and document review.

## Manage assets in Creative Cloud Libraries

Organize Creative Cloud content while working in Adobe InDesign.

Use these asset-management actions for colors, character styles, paragraph styles, graphics, and text saved in Creative Cloud Libraries. They apply to existing library assets, whether you made those assets yourself or received them through sharing. Asset management requires edit permission on the library. Libraries you created already grant you full rights. When a shared library shows dimmed options, ask the library owner about access.

### Rename, delete, or duplicate assets

Choose Window > CC Libraries, then choose the library that contains the assets for renaming, deletion, or duplication.

In the CC Libraries panel, right-click one or more assets.

For one asset, choose Rename, Delete, or Duplicate from the context menu.

When several assets are selected, choose Delete Selected Items or Duplicate Selected Items.

To rename, enter the new name and press Enter.

Note

Removing an asset deletes it from the library, but placed instances already in InDesign documents remain unchanged.

### Copy or move assets between libraries

Choose Window > CC Libraries, then choose the library that holds the assets you plan to copy or move.

In the CC Libraries panel, right-click one or more assets.

For one asset, choose Copy to or Move to from the context menu.

When several assets are selected, choose Copy selected items to or Move selected items to.

In the submenu, choose the destination library and choose Copy.

Moving an asset takes it out of the current library and adds it to the destination library. Copying makes a duplicate in the destination library while the original stays where it is. Asset properties are retained by both actions, including names and styling information.

### Search for assets by name

Choose Window > CC Libraries, then choose the library that contains the assets you need.

From the dropdown menu, choose the search scope: Current library, All libraries, or Adobe Stock.

Enter the asset name in the search box and press Enter.

Results show in the panel right away. To show every asset again, empty the search box or choose Current library from the dropdown and leave the search field blank.

## Creative Cloud add-on integrations

Adobe InDesign can connect with plug-ins and extensions that broaden creative workflows.

On the Adobe Exchange website, find add-ons, extensions, or plug-ins for InDesign and other Adobe products, then install the ones you need.

### Browse add-ons from InDesign

InDesign can serve as the entry point for discovering plug-ins. Choose Plug-Ins > Browse Plugins to open a web page that shows free and paid choices. Plug-ins installed or acquired through the Creative Cloud (CC) app then sync automatically with InDesign.

### View installed add-ons

Installed add-ons are later available from Window > Find Extensions on Exchange or from your downloads. Adobe Exchange also shows the add-ons you have downloaded, along with the products and versions they support.

### Sync add-ons with CC

With file syncing enabled, browsed add-ons sync to the CC account.

## Share libraries with Creative Cloud users

Use Adobe InDesign to share and manage Creative Cloud Libraries with other users.

Creative Cloud Libraries make collaboration easier because colors, character styles, paragraph styles, and graphics can be shared with other Creative Cloud users. After a library is shared, collaborators may view, edit, and use its assets in InDesign and in other Adobe applications, including Photoshop and Illustrator.

### Share a Creative Cloud library

Open Window > CC Libraries.

Choose the library, then open the panel menu icon.

Choose Invite people.

Choose Add people or groups, then enter the recipient's email address and optional message.

Set the editing permission to Can edit or Can view & use.

Choose Invite to edit.

### Cancel the sharing of a library

Open Window > CC Libraries.

Choose the library, then open the panel menu icon.

In the Invite to Library dialog box, choose the user whose sharing access should be canceled.

Choose Remove.

### Accept a collaboration invitation

Start the Adobe Creative Cloud desktop application, then sign in with Adobe ID credentials.

Open notifications using the bell icon.

Inspect the collaboration invitations.

Accept each invitation so the shared libraries become available.

### Leave a shared library

Start the Adobe Creative Cloud desktop application, then sign in with Adobe ID credentials.

Choose Files > Shared with you to display the shared library.

Choose the library, then left-click the three-dotted icon.

Choose Leave.

### Delete a shared library

Start the Adobe Creative Cloud desktop application, then sign in with Adobe ID credentials.

Choose Files > Your libraries to display the shared library.

Choose the library, then left-click the three-dotted icon.

Choose Delete.

Note

The shared library can be deleted only by its owner.

## Illustrator integration with InDesign

Place native Adobe Illustrator (.ai) files in Adobe InDesign while keeping layers, effects, and editability available.

Use the Place command to import native .ai files into InDesign, preserving vector quality, transparency, and layer structure. The placed artwork remains linked to its source file, so edits to the original artwork can be refreshed in the layout.

### Place a single Illustrator file

Choose File > Place.

Browse to the Illustrator file, then choose it.

Make sure Show Import Options is selected.

Choose Open to load the file into the place cursor.

Click in the document to place the graphic at native size, or drag to draw a frame with custom dimensions.

### Configure Illustrator import options

Choose File > Place.

Choose Show Import Options, select the Illustrator file, and then choose Open.

On the General tab, select the page or artboard to place when the file includes multiple artboards.

Use the Crop to drop-down menu to choose the imported bounding area: Bounding Box, Art, Crop, Trim, Bleed, or Media.

Choose Window > Layers. The Layers panel appears only when the Illustrator file has more than one layer. Any layers hidden in Illustrator can still be reached in InDesign through the Object Layer Options dialog box after placement.

Show or hide individual Illustrator layers by checking or unchecking their layer names.

Choose OK.

### Place multiple Illustrator files simultaneously

Choose File > Place.

Hold Ctrl (Windows) or Cmd (macOS).

Clear Show Import Options when separate settings are unnecessary for each file.

Choose Open to load all files into the place cursor.

Click in the document to place the graphics one after another.

### Update linked Illustrator files

Open the Links panel with Window > Links.

Find Illustrator files that show a modified link icon.

Choose the modified link, then choose the Update Link icon.

### Edit Illustrator artwork in place

With the Selection tool, choose a placed Illustrator graphic.

Right-click the graphic and choose Edit Original, or choose Edit > Edit Original.

Edit the artwork in Illustrator, then save the file.

Go back to InDesign and, if the modified icon appears, update the link in the Links panel.

## Manage project assets with Creative Cloud Libraries

Work with colors, graphics, and styles in InDesign documents, then share those assets with other Adobe apps.

In InDesign, the CC Libraries panel centralizes access to Creative Cloud Libraries and syncs assets across devices when the same Adobe ID is used. From this panel you can create, view, rename, and delete libraries; add, edit, organize, and manage assets; and sort or browse the contents of each library. These tools help keep design work consistent and organized across projects.

### Open a Creative Cloud library

Choose Window > CC Libraries.

Open the panel menu icon, then choose Create new library.

Enter the new library's name, then choose Create.

### Add assets to a library

Choose the asset to save, for example text, a graphic, or a color swatch.

Choose Window > CC Libraries.

Choose the Add elements icon, then choose the asset type so the selected asset is added to the library automatically. Assets can also be dragged straight from the document into the CC Libraries panel.

### Use library assets in a document

Open the document that will receive the asset.

Choose Window > CC Libraries.

Find the asset, then drag it onto the document.

### Invite people to edit or view your library

Choose Window > CC Libraries.

Choose the library that you want to share.

Open the panel menu icon, then choose Invite people.

Enter the email addresses for the people to invite. Edit access is assigned by default.

Open the Can edit drop-down menu, then choose Can view & use to block edits to the library content.

Choose Invite to edit or Invite to view & use.
