### Reset preferences to fix startup issues

When startup problems occur in Media Encoder, the Reset options dialog box provides troubleshooting choices that can help resolve launch failures. The dialog supports several actions:

- Reset preferences: Reset options dialog box preference reset returns settings to their defaults, which often clears launch-blocking issues.
- Clear media cache: Media Encoder stores media files and previews in cache for performance. Clearing cache through the Reset options dialog box can remove cached data that interferes with startup.
- Restore default presets: Removing custom encoding presets through the Reset options dialog box can help with conflicts or errors from damaged or incompatible preset configurations.
- Turn off plugins: Reset options dialog box can temporarily disable all plugins so Media Encoder starts without extra components. Use this to find and disable a plugin.

Choose one or more reset options to control how Media Encoder restarts.

Choose one or more reset options to control how Media Encoder restarts.

### Hardware acceleration for Canon Cinema RAW Light

Premiere, After Effects, and Media Encoder now provide hardware acceleration for Canon Cinema RAW Light on Apple silicon computers. With Cinema RAW Light files, this can improve editing and transcoding performance, provide smooth timeline playback, and deliver 10x faster export performance.

The Encoding panel reports the status for each item currently being encoded.

### Queue panel

Place encoding inputs in the Queue panel. Sources can include video or audio files, Adobe Premiere sequences, and Adobe After Effects compositions. Add them by dragging files into the queue, or use Add Source and choose the media to encode.

Jobs can also be sent straight into the queue from other Adobe applications, letting work continue while AME renders in the background. Export to AME is supported by these Adobe applications:

- Premiere
- After Effects
- Audition
- Character Animator

Queue panel

Queue panel

Once the queue is started, Adobe Media Encoder encodes the items it contains. AME can begin automatically after an item is added, or it can wait until you start the queue manually. A preference can also trigger encoding after a chosen delay following the addition of a new item to the encoding queue.

Add, delete, or reorder entries directly in the Queue panel. For details, see Add and manage items in the encoding queue.

Once video and audio sources are queued, additional presets can be applied from the Preset Browser; output details can also be changed in the Export Settings or Ingest Settings dialogs. Related guidance is in Encode using presets or custom settings.

### Working with the media browser

Working with the media browser

Working with the media browser

Use the media browser to inspect media before sending it to the queue. The panel's left side lists local drives, network drives, and a Favorites area for frequently used directories. The selected drive or directory appears on the right. Results can be filtered by file type, or found through the Search field. Folder structures from camera makers including Canon, Sony, and Panasonic are straightforward to browse, as are After Effects and Premiere project contents.

Double-click files in the Media Browser to queue them, or drag them straight onto the Queue panel. To attach particular encoding or ingest presets, drop the files on presets in the Preset Browser.

- For Thumbnails display, select the Icon View button.
- For list display, select the List View button.
- To preview a file quickly, move the cursor across its thumbnail. You can also select the thumbnail and scrub the movie with the playhead. The JKL keys control playback for the selected thumbnail as another option.
- Adjust file thumbnail size with the Zoom slide bar.
- To show one file type, choose an entry from the Files Of Type menu. Repeat this action to select multiple entries. By default, all supported file types are shown.
- To show media from one source, choose that source in the View As menu. When ingesting from a device, verify that the device is connected to the computer.
- To ingest only part of a file, select its thumbnail, then navigate through the clip with the JKL keyboard shortcuts or by dragging the playhead. Press I and O at the desired frames to set In and Out Point.

Note

For custom-duration ingest, Adobe Media Encoder requires the Transcode option. The Copy option always copies the full source file.

### Stitching clips together using Adobe Media Encoder

When adding media to the queue, multiple files can be joined into one output file. To stitch media files together, use this workflow:

1. Select File > Add Source.
2. In the dialog, choose the assets to stitch and enable the Stitch clips together check box.
3. Click Open to place the stitched clip in the queue.

Other workflows can also create combined media files.

1. Open the media browser panel.
2. Choose the assets that should be stitched together.
3. Drag the selected assets into the queue and use the choices shown at the bottom of the Queue. Place the files on Drop here to stitch clips together.
4. Desktop assets can also be dragged in to create a stitched clip. The queue receives a new stitched clip.

Another method is:

1. Open the Media Browser panel.
2. Choose the assets that should be stitched together.
3. Right-click the assets and select Stitch Clips Together. The queue receives a new stitched clip.

The stitched clip name comes from the first clip in the alphabetically sorted source series. Since the name opens in edit mode, enter a custom value when needed. Press the Enter key to confirm it. A stitched clip can still be renamed later, provided it is not currently encoding, by clicking the source name in the Queue.

Note

Stitched clips honor In and Out Points set in media browser. After sources have been added to a stitched clip, their duration cannot be changed.

### Adding, deleting, and rearranging sources in stitched clips

The source files inside a stitched clip appear immediately under the stitched clip name.

1. The hot-text toggle on the right side of the name hides or shows stitched clip sources. Before editing sources in a stitched clip, make sure the sources are visible in the queue.
2. To include additional assets in an existing stitched clip, drag assets from the media browser or desktop and drop them onto the source list. A blue line marks where the new sources will be inserted in the series.
3. To remove sources already in a stitched clip, highlight them in the list, then use the Delete button at the top of the queue or press the Delete key on the keyboard. To reorder sources in a stitched clip, choose one or more entries and drag them to another position. A blue line shows the placement point in the series.
4. When stitched-clip sources differ in properties, such as frame sizes or frame rates, the first clip in the series defines the properties for the whole stitched clip. Sources with different frame sizes are scaled to match the first clip's frame size. Pixel aspect ratio is preserved, but letter boxing and pillar boxing can appear.

## Media intelligence in Media Encoder

Search. Last updated: Mar 27, 2026

Analyze videos with AI-powered media intelligence in Media Encoder, preparing them for immediate search in Premiere after import.

Media Intelligence in Adobe Media Encoder analyzes video and audio before editing begins, creating sidecar files that Premiere can use as soon as the media is imported. Those sidecar files support visual and audio search through speech transcription and searchable dialogue, audio classification, and scene detection, which can make editing faster and more efficient.

Depending on the workflow, analysis can be launched for chosen files or automated for every media file as it appears:

- Manual analysis: Add jobs for specific clips when on-demand analysis is needed.
- Automatic analysis: Set Media Encoder to create and refresh sidecar files for every file in a folder, so both current and new media are analyzed without manual steps.
