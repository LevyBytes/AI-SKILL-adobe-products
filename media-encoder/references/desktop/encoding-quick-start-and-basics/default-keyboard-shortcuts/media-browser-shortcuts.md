# Media Browser shortcuts

| Result | Windows | Mac OS |
| --- | --- | --- |
| Set In Point for selected clip | I | I |
| Set Out point for selected clip | O | O |
| Clear In & Out points | C | C |
| Toggle playback of selected clip | Space | Space |
| Fast-backward playback | J | J |
| Pause playback | K | K |
| Fast-forward playback | L | L |
| Slow-backward playback | Shift+J | Shift+J |
| Slow-forward playback | Shift+L | Shift+L |
