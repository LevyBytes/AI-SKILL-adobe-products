# Media intelligence in Media Encoder

Search. Last updated: Mar 27, 2026

Analyze videos with AI-powered media intelligence in Media Encoder, preparing them for immediate search in Premiere after import.

Media Intelligence in Adobe Media Encoder analyzes video and audio before editing begins, creating sidecar files that Premiere can use as soon as the media is imported. Those sidecar files support visual and audio search through speech transcription and searchable dialogue, audio classification, and scene detection, which can make editing faster and more efficient.

Depending on the workflow, analysis can be launched for chosen files or automated for every media file as it appears:

- Manual analysis: Add jobs for specific clips when on-demand analysis is needed.
- Automatic analysis: Set Media Encoder to create and refresh sidecar files for every file in a folder, so both current and new media are analyzed without manual steps.
