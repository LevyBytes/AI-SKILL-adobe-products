# Adobe Media Encoder workspace

Adobe Media Encoder has five primary panels used during encoding. Panels can be grouped as tabs inside one frame or detached from the frame.

Adobe Media Encoder user interface

A. Encoding panel B. Queue panel C. Preset Browser D. Watch Folder E. Media Browser

Adobe Media Encoder user interface

After tailoring the workspace, choose Window > Workspace > New Workspace to save it as a custom workspace.

Note

Many Adobe Media Encoder commands include keyboard shortcuts so tasks can be completed faster with less mouse use. See the Default keyboard shortcuts in Adobe Media Encoder.
