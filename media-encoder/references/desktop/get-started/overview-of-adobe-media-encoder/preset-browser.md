# Preset Browser

The Preset Browser gives Adobe Media Encoder controls for speeding up preset-driven work.

Preset Browser

Preset Browser

Browser system presets are grouped by purpose (such as Broadcast, Web Video) and by target device or format (such as DVD, Blu-ray, Camera, Tablet). Editing those presets creates custom presets, also known as User Presets.

Within the Preset Browser, search and the collapsible folder tree make presets easier to locate. For Preset Browser details, see Using the Preset Browser.

For preset-based encoding guidance, see Create custom presets for Media Encoder.
