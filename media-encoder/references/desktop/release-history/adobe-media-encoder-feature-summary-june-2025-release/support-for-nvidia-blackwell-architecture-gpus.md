# Support for NVIDIA Blackwell Architecture GPUs

Premiere adds NVIDIA Blackwell GPU acceleration for 4:2:2 video, enabling fast playback. Compared with 4:2:0, 4:2:2 video carries twice the color detail with only a modest file-size increase, making it useful for precise color grading, cleaner chroma keying, and sharper text rendering. Editors with NVIDIA Blackwell GPUs can use accelerated 4:2:2 playback.
