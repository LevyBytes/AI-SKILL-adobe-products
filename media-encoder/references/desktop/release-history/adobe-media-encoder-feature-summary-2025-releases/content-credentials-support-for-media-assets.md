# New features in April 2025 (25.2) — Content Credentials support for media assets

In Adobe Media Encoder, valid Content Credentials for properly signed C2PA-compliant media assets, including audio, video, and images, remain intact during import, export, and editing. That preservation helps confirm authenticity and content origin, improving transparency and trust. For details, see Content Credentials in Adobe Media Encoder.

Assets created with Adobe Firefly features receive Content Credentials automatically from Adobe. A visual indicator shows that content credentials will be included on the exported file.
