# Property.keyLabel

Community declaration reference: AfterEffects/26.0.

Gives the labelIndex for the keyframe: 0 for None, or 1 to 16 for preset colors in Labels preferences.

```typescript
declare class Property<T extends UnknownPropertyType = UnknownPropertyType> extends PropertyBase {
    keyLabel(keyIndex: number): number
}
```
