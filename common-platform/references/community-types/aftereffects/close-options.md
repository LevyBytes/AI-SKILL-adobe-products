# CloseOptions

Community declaration reference: AfterEffects/26.0.

```typescript
declare enum CloseOptions {
    /* Close while leaving changes unsaved. */
    DO_NOT_SAVE_CHANGES = 1212,
    /* Ask whether changes should be saved before closing. */
    PROMPT_TO_SAVE_CHANGES = 1213,
    /* Save automatically during close. */
    SAVE_CHANGES = 1214,
}
```
