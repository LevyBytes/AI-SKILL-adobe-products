# AudioChannelLayout declaration

Community declaration reference: Audition/2018.

AudioChannelLayout models a channel layout. Named channel constants use AUDIOCHANNELLABEL* ..., and layouts can be built from an Array of those constants or from a CHANNELLAYOUT* ... constant for common layouts.

Declaration: `declare class AudioChannelLayout`.

Source: [Audition/2018/index.d.ts](https://raw.githubusercontent.com/docsforadobe/Types-for-Adobe/5a69e41e5c5b59f7254cc07ca1e57cf8b6884867/Audition/2018/index.d.ts).
