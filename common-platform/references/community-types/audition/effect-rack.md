# EffectRack

Community declaration reference: Audition/2018.

Represents an effect rack for a multitrack session clip or track, exposing both rack effects and rack slots.

```typescript
declare class EffectRack {
    /**
    - EffectRackSlotCollection providing access to the rack's individual slots.
      */
      readonly slots: EffectRackSlotCollection
}
```
