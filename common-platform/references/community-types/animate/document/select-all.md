# Document.selectAll

Community declaration reference: Animate/22.0.

Selects every item on the Stage. This matches pressing Control+A (Windows) or Command+A (Macintosh), or choosing Edit > Select All.

```typescript
declare class Document {
    selectAll(): void
}
```
