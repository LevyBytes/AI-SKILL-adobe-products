# ColorModel

Community declaration reference: Photoshop/2015.5.

Lists color models.

```typescript
declare enum ColorModel {
    /**
    - CMYK model.
      */
      CMYK = 3,
    /**

    - Grayscale model.
      */
      GRAYSCALE = 1,
    /**

    - HSB model.
      */
      HSB = 5,
    /**

    - Lab model.
      */
      LAB = 4,
    /**

    - Color model has not been assigned yet.
      */
      NONE = 50,
    /**

    - RGB model.
      */
      RGB = 2,
}
```
