# PicturePackageTextType

Community declaration reference: Photoshop/2015.5.

Identifies the role of text in a Picture Package.

```typescript
declare enum PicturePackageTextType {
    /**
    - Caption text.
      */
      CAPTION = 5,
    /**

    - Copyright text.
      */
      COPYRIGHT = 4,
    /**

    - Credit text.
      */
      CREDIT = 6,
    /**

    - Filename text.
      */
      FILENAME = 3,
    /**

    - No text.
      */
      NONE = 1,
    /**

    - Origin text.
      */
      ORIGIN = 7,
    /**

    - User-defined text.
      */
      USER = 2,
}
```
