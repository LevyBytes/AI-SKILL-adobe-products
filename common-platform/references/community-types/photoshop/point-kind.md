# PointKind

Community declaration reference: Photoshop/2015.5.

Identifies the path point kind.

```typescript
declare enum PointKind {
    /**
    - Requires the point to be a corner.
      */
      CORNERPOINT = 2,
    /**

    - Allows the point to be a curve.
      */
      SMOOTHPOINT = 1,
}
```
