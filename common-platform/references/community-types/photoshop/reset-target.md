# ResetTarget

Community declaration reference: Photoshop/2015.5.

Object type or object types reset to default settings.

```typescript
declare enum ResetTarget {
    /**
    - Resets tools.
      */
      ALLTOOLS = 2,
    /**

    - Resets warning dialogs.
      */
      ALLWARNINGS = 1,
    /**

    - Resets every target.
      */
      EVERYTHING = 3,
}
```
