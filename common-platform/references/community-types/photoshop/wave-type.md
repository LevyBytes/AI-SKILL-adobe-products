# WaveType

Community declaration reference: Photoshop/2015.5.

Identifies the wave form.

```typescript
declare enum WaveType {
    /**
    - Rolling wave.
      */
      SINE = 1,
    /**

    - Square wave.
      */
      SQUARE = 3,
    /**

    - Triangular wave.
      */
      TRIANGULAR = 2,
}
```
