# Geometry

Community declaration reference: Photoshop/2015.5.

Provides geometric shape choices, including the iris shape in the Lens Blur Filter.

```typescript
declare enum Geometry {
    /**
    - Heptagon shape.
      */
      HEPTAGON = 4,
    /**

    - Hexagon shape.
      */
      HEXAGON = 2,
    /**

    - Octagon shape.
      */
      OCTAGON = 5,
    /**

    - Pentagon shape.
      */
      PENTAGON = 1,
    /**

    - Square shape.
      */
      SQUARE = 3,
    /**

    - Triangle shape.
      */
      TRIANGLE = 0,
}
```
