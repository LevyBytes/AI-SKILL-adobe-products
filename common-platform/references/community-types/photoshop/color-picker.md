# ColorPicker

Community declaration reference: Photoshop/2015.5.

Color picker selection.

```typescript
declare enum ColorPicker {
    /**
    - Uses the Adobe Color Picker.
      */
      ADOBE = 1,
    /**

    - Uses the built-in Apple color picker.
      */
      APPLE = 2,
    /**

    - Uses an installed plug-in color picker.
      */
      PLUGIN = 4,
    /**

    - Uses the built-in Windows color picker.
      */
      WINDOWS = 3,
}
```
