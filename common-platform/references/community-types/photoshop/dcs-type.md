# DCSType

Community declaration reference: Photoshop/2015.5.

DCS format choice.

```typescript
declare enum DCSType {
    /**
    - Creates a color composite file along with DCS files.
      */
      COLORCOMPOSITE = 3,
    /**

    - Creates a grayscale composite file along with DCS files.
      */
      GRAYSCALECOMPOSITE = 2,
    /**

    - Creates no composite file.
      */
      NOCOMPOSITE = 1,
}
```
