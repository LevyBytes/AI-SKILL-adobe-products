# FormatOptions

Community declaration reference: Photoshop/2015.5.

Settings for saving a JPEG file.

```typescript
declare enum FormatOptions {
    /**
    - Baseline (Optimized), using optimized color and a modestly smaller file.
      */
      OPTIMIZEDBASELINE = 2,
    /**

    - Shows progressively more detailed scans while the image downloads.
      */
      PROGRESSIVE = 3,
    /**

    - Baseline (Standard), accepted by most web browsers.
      */
      STANDARDBASELINE = 1,
}
```
