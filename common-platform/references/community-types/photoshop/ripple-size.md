# RippleSize

Community declaration reference: Photoshop/2015.5.

Specifies undulation size.

```typescript
declare enum RippleSize {
    /**
    - Large size.
      */
      LARGE = 3,
    /**

    - Medium size.
      */
      MEDIUM = 2,
    /**

    - Small size.
      */
      SMALL = 1,
}
```
