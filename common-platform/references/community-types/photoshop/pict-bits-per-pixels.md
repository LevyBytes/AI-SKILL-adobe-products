# PICTBitsPerPixels

Community declaration reference: Photoshop/2015.5.

Lists pixel-depth choices for compressed PICT files.

```typescript
declare enum PICTBitsPerPixels {
    /**
    - 8-bit pixel depth.
      */
      EIGHT = 8,
    /**

    - 4-bit pixel depth.
      */
      FOUR = 4,
    /**

    - 16-bit pixel depth.
      */
      SIXTEEN = 16,
    /**

    - 32-bit pixel depth.
      */
      THIRTYTWO = 32,
    /**

    - 2-bit pixel depth.
      */
      TWO = 2,
}
```
