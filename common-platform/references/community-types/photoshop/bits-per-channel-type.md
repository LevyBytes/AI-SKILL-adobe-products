# BitsPerChannelType

Community declaration reference: Photoshop/2015.5.

Lists available channel bit depths.

```typescript
declare enum BitsPerChannelType {
    /**
    - 8-bit channel depth.
      */
      EIGHT = 8,
    /**

    - 1-bit channel depth.
      */
      ONE = 1,
    /**

    - 16-bit channel depth.
      */
      SIXTEEN = 16,
    /**

    - 32-bit channel depth.
      */
      THIRTYTWO = 32,
}
```
