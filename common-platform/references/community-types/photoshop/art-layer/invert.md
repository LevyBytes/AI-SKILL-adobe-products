# ArtLayer.invert

Community declaration reference: Photoshop/2015.5.

Reverses layer colors by mapping every channel pixel brightness to its opposite on the 256-step color-values scale.

```typescript
declare class ArtLayer extends Layer {
    invert(): void
}
```
