# Rectangle

Community declaration reference: Photoshop/2015.5.

Rectangle description object; it also behaves as a four-element collection.

```typescript
declare class Rectangle {
    /**
    - Bottom coordinate.
      */
      bottom: number
    /**

    - Height value.
      */
      height: number
    /**

    - Left coordinate.
      */
      left: number
    /**

    - Array length value.
      */
      readonly length: number
    /**

    - Right coordinate.
      */
      right: number
    /**

    - Top coordinate.
      */
      top: number
    /**

    - Width value.
      */
      width: number
    /**

    - Left coordinate.
      */
      x: number
    /**

    - Top coordinate.
      */
      y: number
}
```
