# FontPreviewType

Community declaration reference: Photoshop/2015.5.

Preview type size for font menus in the Type tool.

```typescript
declare enum FontPreviewType {
    /**
    - Preview appears extra large.
      */
      EXTRALARGE = 4,
    /**

    - Preview appears huge.
      */
      HUGE = 5,
    /**

    - Type appears large.
      */
      LARGE = 3,
    /**

    - Type appears medium.
      */
      MEDIUM = 2,
    /**

    - Preview is disabled.
      */
      NONE = 0,
    /**

    - Type appears small.
      */
      SMALL = 1,
}
```
