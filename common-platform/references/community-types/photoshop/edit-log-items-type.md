# EditLogItemsType

Community declaration reference: Photoshop/2015.5.

Selects history log edit detail.

```typescript
declare enum EditLogItemsType {
    /**
    - Saves a concise history log.
      */
      CONCISE = 2,
    /**

    - Saves a detailed history log.
      */
      DETAILED = 3,
    /**

    - Saves history only for the session.
      */
      SESSIONONLY = 1,
}
```
