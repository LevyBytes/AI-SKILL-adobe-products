# GallerySecurityTextColorType

Community declaration reference: Photoshop/2015.5.

Chooses the color for the antitheft text overlay on gallery images.

```typescript
declare enum GallerySecurityTextColorType {
    /**
    - Black overlay text.
      */
      BLACK = 1,
    /**

    - Custom text color.
      */
      CUSTOM = 3,
    /**

    - White overlay text.
      */
      WHITE = 2,
}
```
