# SourceSpaceType

Community declaration reference: Photoshop/2015.5.

Selects the source color space for printing.

```typescript
declare enum SourceSpaceType {
    /**
    - Document color space.
      */
      DOCUMENT = 1,
    /**

    - Proof color space.
      */
      PROOF = 2,
}
```
