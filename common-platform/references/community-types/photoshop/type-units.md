# TypeUnits

Community declaration reference: Photoshop/2015.5.

Unit used for type measurement.

```typescript
declare enum TypeUnits {
    /**
    - Millimeters.
      */
      MM = 4,
    /**

    - Pixels.
      */
      PIXELS = 1,
    /**

    - Points.
      */
      POINTS = 5,
}
```
