# SaveOptions

Community declaration reference: Photoshop/2015.5.

File-saving behavior options.

```typescript
declare enum SaveOptions {
    /**
    - Leave changes unsaved.
      */
      DONOTSAVECHANGES = 2,
    /**

    - Prompt the user about saving.
      */
      PROMPTTOSAVECHANGES = 3,
    /**

    - Write changes to storage.
      */
      SAVECHANGES = 1,
}
```
