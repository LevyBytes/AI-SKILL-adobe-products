# Extension

Community declaration reference: Photoshop/2015.5.

Formatting style for the filename extension.

```typescript
declare enum Extension {
    /**
    - Writes the extension in lowercase letters.
      */
      LOWERCASE = 2,
    /**

    - Omits the extension.
      */
      NONE = 1,
    /**

    - Writes the extension in uppercase letters.
      */
      UPPERCASE = 3,
}
```
