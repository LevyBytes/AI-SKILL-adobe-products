# DocPositionStyle

Community declaration reference: Photoshop/2015.5.

Printed document placement.

```typescript
declare enum DocPositionStyle {
    /**
    - Centers the image on the page for printing.
      */
      PRINTCENTERED = 1,
    /**

    - Fits the image to the page while printing.
      */
      SIZETOFIT = 2,
    /**

    - Prints with user-defined spacing.
      */
      USERDEFINED = 3,
}
```
