# ElementPlacement

Community declaration reference: Photoshop/2015.5.

Determines the position Photoshop uses when placing an element.

```typescript
declare enum ElementPlacement {
    /**
    - Position after an element.
      */
      PLACEAFTER = 1,
    /**

    - Position at the end.
      */
      PLACEATEND = 3,
    /**

    - Position before target.
      */
      PLACEBEFORE = 2,
}
```
