# GridLineStyle

Community declaration reference: Photoshop/2015.5.

Nonprinting image-grid line style.

```typescript
declare enum GridLineStyle {
    /**
    - Dashed.
      */
      DASHED = 2,
    /**

    - Dotted.
      */
      DOTTED = 3,
    /**

    - Solid.
      */
      SOLID = 1,
}
```
