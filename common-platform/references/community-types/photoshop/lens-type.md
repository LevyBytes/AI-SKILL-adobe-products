# LensType

Community declaration reference: Photoshop/2015.5.

Identifies the lens type.

```typescript
declare enum LensType {
    /**
    - Movie Prime lens.
      */
      MOVIEPRIME = 5,
    /**

    - 105mm Prime lens.
      */
      PRIME105 = 3,
    /**

    - 35mm Prime lens.
      */
      PRIME35 = 2,
    /**

    - 50-300mm Zoom lens.
      */
      ZOOMLENS = 1,
}
```
