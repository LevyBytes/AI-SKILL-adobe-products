# TargaBitsPerPixels

Community declaration reference: Photoshop/2015.5.

Lists bit-depth choices for Targa image saves.

```typescript
declare enum TargaBitsPerPixels {
    /**
    - 16-bit pixel depth.
      */
      SIXTEEN = 16,
    /**

    - 32-bit pixel depth.
      */
      THIRTYTWO = 32,
    /**

    - 24-bit pixel depth.
      */
      TWENTYFOUR = 24,
}
```
