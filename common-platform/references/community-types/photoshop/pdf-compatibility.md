# PDFCompatibility

Community declaration reference: Photoshop/2015.5.

PDF version selected for document compatibility.

```typescript
declare enum PDFCompatibility {
    /**
    - Compatible with PDF 1.3 (Acrobat 4 or higher).
      */
      PDF13 = 1,
    /**

    - Compatible with PDF 1.4 (Acrobat 5 or higher).
      */
      PDF14 = 2,
    /**

    - Compatible with PDF 1.5 (Acrobat 6 or higher).
      */
      PDF15 = 3,
    /**

    - Compatible with PDF 1.6 (Acrobat 7 or higher).
      */
      PDF16 = 4,
    /**

    - Compatible with PDF 1.7 (Acrobat 9 or higher).
      */
      PDF17 = 5,
}
```
