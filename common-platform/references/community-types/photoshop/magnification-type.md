# MagnificationType

Community declaration reference: Photoshop/2015.5.

Magnification choices used for PDF display.

```typescript
declare enum MagnificationType {
    /**
    - Shows the image at actual size.
      */
      ACTUALSIZE = 0,
    /**

    - Scales the image to fit the page.
      */
      FITPAGE = 1,
}
```
