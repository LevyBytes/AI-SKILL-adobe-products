# PDFSaveOptions.jpegQuality

Community declaration reference: Photoshop/2015.5.

Produced image quality. Applies only to JPEG-encoded PDF documents. Range: 0 to 12.

```typescript
declare class PDFSaveOptions {
    jpegQuality: number
}
```
