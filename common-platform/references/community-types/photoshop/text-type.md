# TextType

Community declaration reference: Photoshop/2015.5.

Identifies the text object category.

```typescript
declare enum TextType {
    /**
    - Text constrained to wrap inside a bounding box.
      */
      PARAGRAPHTEXT = 2,
    /**

    - Text placed without automatic wrapping.
      */
      POINTTEXT = 1,
}
```
