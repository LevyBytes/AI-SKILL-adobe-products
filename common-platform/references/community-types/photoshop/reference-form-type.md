# ReferenceFormType

Community declaration reference: Photoshop/2015.5.

Identifies the form of an action reference object.

```typescript
declare enum ReferenceFormType {
    /**
    - Class form.
      */
      CLASSTYPE = 7,
    /**

    - Enumerated form.
      */
      ENUMERATED = 5,
    /**

    - Identifier form.
      */
      IDENTIFIER = 3,
    /**

    - Index form.
      */
      INDEX = 2,
    /**

    - Name form.
      */
      NAME = 1,
    /**

    - Offset form.
      */
      OFFSET = 4,
    /**

    - Property form.
      */
      PROPERTY = 6,
}
```
