# BitmapHalfToneType

Community declaration reference: Photoshop/2015.5.

Defines the dot shape, or ink-deposit shape, used in the halftone screen.

```typescript
declare enum BitmapHalfToneType {
    /**
    - Cross shape.
      */
      CROSS = 6,
    /**

    - Diamond shape.
      */
      DIAMOND = 2,
    /**

    - Ellipse shape.
      */
      ELLIPSE = 3,
    /**

    - Line shape.
      */
      LINE = 4,
    /**

    - Round shape.
      */
      ROUND = 1,
    /**

    - Square shape.
      */
      SQUARE = 5,
}
```
