# DisplayOrderOptions

Community declaration reference: InDesign/2023.

Values that determine table-cell ordering in story and galley views.

```typescript
declare enum DisplayOrderOptions {
    /**
    - Orders by columns.
      */
      ORDER_BY_COLUMNS = 1652114254,
    /**

    - Orders by rows.

      ORDER_BY_ROWS = 1652118103,
}
```
