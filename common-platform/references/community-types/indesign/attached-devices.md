# AttachedDevices

Community declaration reference: InDesign/2023.

Attached device type choices.

```typescript
declare enum AttachedDevices {
    /**
    - Reports all devices, Android followed by iOS.
      */
      ALL = 1634495520,
    /**

    - Reports Android devices.
      */
      ANDROID = 1685086564,
    /**

    - Reports iOS devices.
      */
      IOS = 1684631411,
}
```
