# Sequences

Community declaration reference: InDesign/2023.

Choices for printing page sequences.

```typescript
declare enum Sequences {
    /**
    - Prints every page.
      */
      ALL = 1634495520,
    /**

    - Prints only pages with even numbers.
      */
      EVEN = 1702258030,
    /**

    - Prints only pages with odd numbers.
      */
      ODD = 1868850208,
}
```
