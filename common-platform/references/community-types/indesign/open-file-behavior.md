# OpenFileBehavior

Community declaration reference: InDesign/2023.

Represents an open file behavior object.

```typescript
declare class OpenFileBehavior extends Behavior {
    /**
    - File path, using colon delimiters on Mac OS.
      */
      filePath: string | File
}
```
