# ToolTipOptions

Community declaration reference: InDesign/2023.

Tool tip behavior choices.

```typescript
declare enum ToolTipOptions {
    /**
    - Shows tool tips sooner than the normal timing.
      */
      FAST = 1180791668,
    /**

    - Disables tool tips.
      */
      NONE = 1852796517,
    /**

    - Shows tool tips.

      NORMAL = 1852797549,
}
```
