# XMLTag.tagColor

Community declaration reference: InDesign/2023.

Color assigned to the tag: either [R, G, B] using three doubles from 0 to 255, or a UI color.

```typescript
declare class XMLTag {
    tagColor: [number, number, number] | UIColors
}
```
