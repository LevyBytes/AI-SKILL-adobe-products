# prompt

Community declaration reference: shared/ScriptUI, shared/JavaScript, shared/XMPScript, shared/PlugPlugExternalObject, shared/global.

Shows a dialog where the user can enter text.
Returns null if the user canceled the dialog; otherwise returns the entered text.
@param prompt Text to display.
@param default_ Default text used to prefill the edit field.
@param title Dialog title.

```typescript
declare function prompt(prompt: string, default_?: string, title?: string): string | null
```
