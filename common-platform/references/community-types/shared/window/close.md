# Window.close

Community declaration reference: shared/ScriptUI, shared/JavaScript, shared/XMPScript, shared/PlugPlugExternalObject, shared/global.

Shuts this window.
When an onClose() callback exists for the window, that function runs before the close completes.
@param return_ Number returned by the show() call that displayed this window as a modal dialog.

```typescript
declare class Window extends _Control {
    close(return_?: any): void
}
```
