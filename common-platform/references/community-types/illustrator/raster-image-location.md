# RasterImageLocation

Community declaration reference: Illustrator/2022.

Selects the storage location for raster images.

```typescript
declare enum RasterImageLocation {
    /**
    - Embeds raster images in the svg file.
      */
      EMBED = 0,
    /**

    - */
      LINK = 1,
    /**

    - */
      PRESERVE = 2,
}
```
