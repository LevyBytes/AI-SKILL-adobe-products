# TrappingType

Community declaration reference: Illustrator/2022.

Trapping category.

```typescript
declare enum TrappingType {
    /**
    - Opaque trapping type is ignored.
      */
      IGNOREOPAQUE = 3,
    /**

    - Trapping type is normal.
      */
      NORMALTRAPPING = 0,
    /**

    - Trapping type is opaque.
      */
      OPAQUE = 2,
    /**

    - Trapping type is transparent.
      */
      TRANSPARENT = 1,
}
```
