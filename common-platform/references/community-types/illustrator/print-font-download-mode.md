# PrintFontDownloadMode

Community declaration reference: Illustrator/2022.

Printer font download mode.

```typescript
declare enum PrintFontDownloadMode {
    /**
    - Downloads complete fonts.
      */
      DOWNLOADCOMPLETE = 2,
    /**

    - Downloads no fonts.
      */
      DOWNLOADNONE = 0,
    /**

    - Downloads a subset.
      */
      DOWNLOADSUBSET = 1,
}
```
