# PrintTiling

Community declaration reference: Illustrator/2022.

Page tiling category.

```typescript
declare enum PrintTiling {
    /**
    - Tiles full pages.
      */
      TILEFULLPAGES = 1,
    /**

    - Tiles imageable areas.
      */
      TILEIMAGEABLEAREAS = 2,
    /**

    - Tiles one full page.
      */
      TILESINGLEFULLPAGE = 0,
}
```
