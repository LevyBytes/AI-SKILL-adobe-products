# ImageColorSpace

Community declaration reference: Illustrator/2022.

Image color-space values.

```typescript
declare enum ImageColorSpace {
    /**
    - Color space is CMYK.
      */
      CMYK = 3,
    /**

    - Color space is DeviceN.
      */
      DeviceN = 6,
    /**

    - Color space is Gray.
      */
      GrayScale = 1,
    /**

    - Color space is Indexed.
      */
      Indexed = 7,
    /**

    - Color space is LAB.
      */
      LAB = 4,
    /**

    - Color space is RGB.
      */
      RGB = 2,
    /**

    - Color space is Separation.
      */
      Separation = 5,
}
```
