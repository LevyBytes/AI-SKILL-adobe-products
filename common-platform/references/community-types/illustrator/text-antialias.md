# TextAntialias

Community declaration reference: Illustrator/2022.

Text antialiasing category.

```typescript
declare enum TextAntialias {
    /**
    - Text placed along a path.
      */
      CRISP = 3,
    /**

    - Text created from a point.
      */
      NONE = 1,
    /**

    - Text constrained inside an area.
      */
      SHARP = 2,
    /**

    - Text placed along a path.
      */
      STRONG = 4,
}
```
