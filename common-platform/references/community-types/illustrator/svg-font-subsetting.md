# SVGFontSubsetting

Community declaration reference: Illustrator/2022.

Controls the included SVG font subset.

```typescript
declare enum SVGFontSubsetting {
    /**
    - */
      ALLGLYPHS = 7,
    /**

    - */
      COMMONENGLISH = 3,
    /**

    - */
      COMMONROMAN = 5,
    /**

    - */
      GLYPHSUSED = 2,
    /**

    - */
      GLYPHSUSEDPLUSENGLISH = 4,
    /**

    - */
      GLYPHSUSEDPLUSROMAN = 6,
    /**

    - System fonts are used.
      */
      None = 1,
}
```
