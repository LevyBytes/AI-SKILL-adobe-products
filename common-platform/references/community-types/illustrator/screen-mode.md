# ScreenMode

Community declaration reference: Illustrator/2022.

Screen mode values.

```typescript
declare enum ScreenMode {
    /**
    - Full screen view that retains the menu bar.
      */
      DESKTOP = 2,
    /**

    - Full screen view with no menu bar shown.
      */
      FULLSCREEN = 3,
    /**

    - Several windows are displayed.
      */
      MULTIWINDOW = 1,
}
```
