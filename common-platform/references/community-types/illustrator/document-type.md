# DocumentType

Community declaration reference: Illustrator/2022.

Document types that can be saved.

```typescript
declare enum DocumentType {
    /**
    - File format is EPS.
      */
      EPS = 2,
    /**

    - File format is FXG.
      */
      FXG = 4,
    /**

    - File format is Illustrator.
      */
      ILLUSTRATOR = 1,
    /**

    - File format is Acrobat PDF.
      */
      PDF = 3,
}
```
