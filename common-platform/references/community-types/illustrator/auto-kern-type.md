# AutoKernType

Community declaration reference: Illustrator/2022.

Automatic kerning category.

```typescript
declare enum AutoKernType {
    /**
    - Kerning is automatic.
      */
      AUTO = 1,
    /**

    - Metrics roman only.
      */
      METRICSROMANONLY = 3,
    /**

    - Automatic kerning is disabled.
      */
      NOAUTOKERN = 0,
    /**

    - Optical kerning.
      */
      OPTICAL = 2,
}
```
