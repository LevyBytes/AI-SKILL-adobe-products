# PointType

Community declaration reference: Illustrator/2022.

Path point kind, either smooth or corner.

```typescript
declare enum PointType {
    /**
    - Corner point type.
      */
      CORNER = 2,
    /**

    - Smooth path point type.
      */
      SMOOTH = 1,
}
```
