# InkType

Community declaration reference: Illustrator/2022.

Ink category.

```typescript
declare enum InkType {
    /**
    - Ink color is black.
      */
      BLACKINK = 3,
    /**

    - Ink color is custom.
      */
      CUSTOMINK = 4,
    /**

    - Ink color is cyan.
      */
      CYANINK = 0,
    /**

    - Ink color is magenta.
      */
      MAGENTAINK = 1,
    /**

    - Ink color is yellow.
      */
      YELLOWINK = 2,
}
```
