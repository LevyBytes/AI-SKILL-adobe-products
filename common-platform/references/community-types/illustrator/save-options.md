# SaveOptions

Community declaration reference: Illustrator/2022.

Choices that can be used when saving a file.

```typescript
declare enum SaveOptions {
    /**
    - Leaves changes unsaved.
      */
      DONOTSAVECHANGES = 2,
    /**

    - Prompts the user about saving.
      */
      PROMPTTOSAVECHANGES = 3,
    /**

    - Saves changes.
      */
      SAVECHANGES = 1,
}
```
