# KnockoutState

Community declaration reference: Illustrator/2022.

Knockout state for a page item.

```typescript
declare enum KnockoutState {
    /**
    - Knockout is off.
      */
      DISABLED = 0,
    /**

    - Knockout is off.
      */
      ENABLED = 1,
    /**

    - Knockout state comes from the group?
      */
      INHERITED = 2,
    /**

    - Knockout state is unknown or uninitialized.
      */
      Unknown = -1,
}
```
