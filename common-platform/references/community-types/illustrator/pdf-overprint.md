# PDFOverprint

Community declaration reference: Illustrator/2022.

Pdf overprint choices.

```typescript
declare enum PDFOverprint {
    /**
    - Overprint is discarded.
      */
      DISCARDPDFOVERPRINT = 2,
    /**

    - Overprint is preserved.
      */
      PRESERVEPDFOVERPRINT = 1,
}
```
