# Top 3 Rejection Reasons — _Insufficient installation instructions._

- Installation instructions included with a submission are sometimes too vague for a user to find the plugin and install it for each supported Adobe application. Each supported version of an Adobe application should have its own instructions in the listing's "Where to find it" section.

- If the review team cannot find the files named in the "Where to find it" section of the listing, the plugin will be rejected. Provide the path users should follow inside the Adobe product to find this plugin.
