# FAQs — How can I generate coupon code(s)?

_Answer:_ Ask the Review Team to create one or more coupon codes for you. Send these details to the Review Team:

1. Extension name (or listing name)

2. Coupon validity period: Choose either a limited date range for the discount or a coupon that does not expire.

3. Percent off: State the discount percentage to offer to your user(s).

4. Coupon code and code format: Select one of the supported coupon formats, either a single coupon code or multiple random codes.

   - When using a single coupon code, choose a unique code for FastSpring to store. Whenever a user enters that coupon code on the payment page, the cart value receives the discount. (For example, "MYCOUPON-FREE".)

   - Multiple Random Codes: If you need, for example, 100 coupon codes, the Review Team generates them. Provide a five-character prefix to place at the start of every coupon code.

After coupon creation is finished, the Review Team will contact you. You can then give the coupon code(s) to customers and direct them to enter the code during checkout.
