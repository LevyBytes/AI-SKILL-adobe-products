# Functionality

1. The plugin must install without error.

2. It should open successfully in the highest supported version of the point product.

3. It should open successfully in the lowest supported version of the point product.

4. Modal dialogs need a visible UI control for closing them (e.g., a cancel/close button).

5. A completely blank UI must never appear.

6. No screen should trap users without a navigation path out.

7. When an internet connection is required but unavailable, the plugin must tell the user.

8. Behavior must match the developer's description.

9. Every external link in the plugin must open a website when clicked.
