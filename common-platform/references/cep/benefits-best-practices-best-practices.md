# Benefits & Best Practices — Best Practices

1.  **Use same developer AdobeID for both UXP and CEP plugins:** Submit both CEP and UXP plugins from the same developer ID. A shared ID makes plugin performance easier to follow, keeps listing management together, and simplifies responses to user comments.

1.  **Proper Description:** In the description field, explain the plugin's capabilities, features, functionality, and expected outcomes. End users benefit from a video that shows the plugin in action, because new users can understand how to work with it more quickly.

1.  **Update Your Plugin(s) Regularly:** Keep plugin(s) current so they remain compatible with the latest version of each supported point product. Regular updates improve the end-user experience and can affect revenue and ratings.

1.  **Share Test Credentials:** Provide test credentials to the review team through the "Notes to Approver" section. Including them with the listing submission helps the review move faster.

1.  **Share a License:** Some plugins require a license key before use. When your plugin works this way and FastSpring processes your payments, provide 100 license keys to the review team in the "Notes to Approver" section so the keys can be stored on FastSpring. FastSpring distributes a license key to users after they successfully purchase your plugin.

    - Note: Before the current license supply is depleted, asupport@adobe.com will ask you for additional licenses and will restore them on FastSpring so users can receive a key after purchase.

    - You decide how many licenses to keep on FastSpring. Adobe generally encourages sharing at least 100 licenses, but you may provide fewer or more license keys.

1.  **Provide Proper Installation Instructions:** Put clear installation directions in the "Where to find" section, including which files users install and where those files should be placed. If the plugin supports multiple Adobe products and the steps differ by product, provide separate instructions for each point product. (For example, include both sets of directions when Photoshop and InDesign require different installation steps.)

1.  **Follow the Adobe Brand Guidelines:** Before using any Adobe brand asset, such as product icons, read and comply with the [Adobe Brand Guidelines](https://partners.adobe.com/content/dam/tep_assets/public/public_1/documents/Adobe-Creative-Cloud-Developer-Brand-Guide.pdf). Do not use an asset in a listing or in marketing materials unless Adobe has granted the required authorization. Listings that use Adobe assets without prior approval can be rejected.

1.  **Provide Support:** Make sure users have a reliable way to contact you about plugin problems. Poor reviews and ratings often result when users cannot communicate with the developer.

1.  **Additional Payment:** If using the plugin requires any additional payment, disclose all related information to users and include it in the plugin description.

1.  **Companion application:** If the plugin needs any companion application to function, state that requirement in the plugin description and tell users where to download the companion application.
