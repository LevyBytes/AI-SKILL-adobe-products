# Getting started with CEP extensions

Open when starting the Adobe CEP tutorial for a Photoshop extension that opens a file from a local folder.

CEP provides an HTML, CSS and JavaScript extension interface for supported Adobe Creative Cloud hosts. This overview belongs to the shared Adobe platform reference collection.

## Walkthrough

Follow the [official six-step guide](https://github.com/Adobe-CEP/Getting-Started-guides/blob/master/readme.md) for folder structure, manifest configuration, CSInterface, frontend code, ExtendScript and host launch. The example assumes HTML, CSS and JavaScript familiarity; preserve its Photoshop and CEP version requirements.

The [example extension animation](https://raw.githubusercontent.com/Adobe-CEP/Getting-Started-guides/master/.meta/readme-assets/extension.gif?raw=true) shows the tutorial outcome. Continue with the guide's [next steps](https://github.com/Adobe-CEP/Getting-Started-guides/blob/master/readme.md#next-steps) for debugging and further examples.
