# FAQs — How can I submit a patch?

_Answer:_ Submit a patch when changing functionality for a listing that already exists. Functional updates can include bug fixes, new features, or both.

_Patch submissions allow edits to these fields:_

1. Upload File (Note: For a non-ZXP upload, the patch file type must match the parent upload file type.)

2. Version Number (Note: Only ZIP based extensions use this field. CEP based extensions get version numbers from the manifest file automatically, and those values cannot be typed in manually.)

3. EULA (End User License Agreements)

4. Where to Find It

5. Installation Instructions for Enterprise Users or Creative Cloud Teams users

6. Release Notes

7. Note to the approver
