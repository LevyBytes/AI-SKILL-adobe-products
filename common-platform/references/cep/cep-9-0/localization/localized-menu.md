# Localized menu

Manifests can use locale strings for menu values. In the ShareOnBehance manifest, for example, `%UI_share_on_Behance` is used, and `messages.properties` defines `UI_share_on_Behance` as `UI_share_on_Behance=xxx`.

Manifest/XML excerpt for the documented CEP edition. Merge it at the shown manifest location; omitted settings are marked as comments.

```xml
<UI>
    <Type>ModalDialog</Type>
    <Menu>%UI_share_on_Behance</Menu>
    <!-- Other manifest settings omitted. -->
</UI>
```
