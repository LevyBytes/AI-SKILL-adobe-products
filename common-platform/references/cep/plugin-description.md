# Plugin Description

Use "Adobe Photoshop" in a plugin name only when the name follows the pattern "\${Plugin Name} for Photoshop". See the [Adobe Branding Guidelines](https://partners.adobe.com/content/dam/tep_assets/public/public_1/documents/Adobe-Creative-Cloud-Developer-Brand-Guide.pdf) for more detail. Examples: 
OK: "Rectanglator", or "Rectanglator for Adobe Photoshop"   
 Not OK: "PS Rectanglator", or "Rectanglator PS". A plugin named "Rectanglator PS" would be rejected because of the name. 
The plugin description must be relevant and understandable without extra context. 
Provide an English description, no matter which other languages are supported. 
Listing material, including the author name, email address, and website, must follow the [Adobe Branding Guidelines](https://partners.adobe.com/content/dam/tep_assets/public/public_1/documents/Adobe-Creative-Cloud-Developer-Brand-Guide-062218.pdf).
A plugin website must include an email address or contact form that lets users reach the plugin developer easily.  (The submitted website will be checked to verify that this information exists.) 
Do not include links in the listing to websites that are still being built (i.e., "under construction", "coming soon", etc.).
