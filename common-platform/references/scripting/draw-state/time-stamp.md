# timeStamp

eventObj.timeStamp

### Description

Initiation time for the event. A JavaScript Date object.

### Type

Object

### type

eventObj.type

### Description

Event name. Predefined events types are:

- "blur"
- "change"
- "changing"
- "enterKey"
- "focus"
- "move"
- "moving"
- "resize"
- "resizing"
- "show"

Other type names are specific to keyboard and mouse events.

### Type

String
