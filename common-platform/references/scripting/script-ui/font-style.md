# ScriptUI.FontStyle

ScriptUI.FontStyle

### Description

Groups the enum values accepted as the style argument to ScriptUI.newFont(). For instance:

```javascript
var font = ScriptUI.newFont( "Helvetica", ScriptUI.FontStyle.BOLD )
```

Values are:

- REGULAR
- BOLD
- ITALIC
- BOLDITALIC

### Type

String. Read only.
