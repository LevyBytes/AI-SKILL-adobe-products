# ScriptUIFont Object Attributes

These properties are available on the object:

| Property | Type | Description |
| --- | --- | --- |
| family | String | family stores the font family name. |
| name | String | name stores the full font name, including family and style when a style is specified. |
| size | Number | size gives the font point size. |
| style | Object | style selects the font style. Use one of these constants: - ScriptUI.FontStyle.REGULAR - ScriptUI.FontStyle.BOLD - ScriptUI.FontStyle.ITALIC - ScriptUI.FontStyle.BOLDITALIC |
| substitute | String | substitute names a fallback font to use when the requested family or style is unavailable. |
