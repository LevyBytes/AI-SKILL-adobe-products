# Showing properties in the Effect Controls panel

After Effects shortcuts for revealing properties in the Effect Controls panel, action paired with Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Expand the selected effects so every property shows | Ctrl + ` (accent grave) | Command + ` (accent grave) |
| Expand a property group together with all of its child groups so every property shows | Ctrl-click the triangle to the left of the property group name | Command-click the triangle to the left of the property group name |
