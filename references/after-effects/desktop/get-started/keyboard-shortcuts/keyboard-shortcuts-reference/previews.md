# Previews

After Effects preview shortcuts, listing the action alongside its Windows and macOS bindings.

| Action | Windows | macOS |
| --- | --- | --- |
| Begin playback or halt it | Spacebar, 0 on the numeric keypad, Shift + 0 on the numeric keypad | Spacebar, 0 on numeric keypad, Shift + 0 on numeric keypad |
| Hear just the audio starting at the playhead | . (decimal point) on numeric keypad\* | . (decimal point) on numeric keypad\* or Control + . (period) on the main keyboard |
| Hear just the audio that falls inside the work area | Alt + . (decimal point) on numeric keypad\* | Option + . (decimal point) on numeric keypad\* or Control + Command + . (period) on the main keyboard |
| Scrub the video by hand — the behavior follows whatever Live Update is set to | Drag or Alt-drag current-time indicator; which one you use is governed by your Live Update choice. | Drag or Option-drag current-time indicator; which one you use is governed by your Live Update choice. |
| Scrub the audio by hand | Ctrl-drag current-time indicator | Command-drag current-time indicator |
| Play back the frame count set in the Alternate Preview preference, which starts at 5 | Alt + 0 on numeric keypad\* | Option + 0 on numeric keypad\* or Control + Option + 0 (zero) on the main keyboard |
| Flip Mercury Transmit video preview on or off | / (on numeric keypad) | / (on numeric keypad), Control + / on the main keyboard |
| Grab a snapshot | Shift + F5, Shift + F6, Shift + F7, or Shift + F8 | Shift + F5, Shift + F6, Shift + F7, or Shift + F8 |
| Put a stored snapshot up in the viewer that is currently active | F5, F6, F7, or F8 | F5, F6, F7, or F8 |
| Clear a snapshot from memory | Ctrl + Shift + F5, Ctrl + Shift + F6, Ctrl + Shift + F7, or Ctrl + Shift + F8 | Command + Shift + F5, Command + Shift + F6, Command + Shift + F7, or Command + Shift + F8 |
| Restore preview settings so they mimic RAM Preview and Standard Preview behavior | Alt-click Reset in the Preview panel | Option-click Reset in the Preview panel |
| Fast Previews > Off | Ctrl + Alt + 1 | Command + Option + 1 |
| Fast Previews > Adaptive Resolution | Ctrl + Alt + 2 | Command + Option + 2 |
| Fast Previews > Draft | Ctrl + Alt + 3 | Command + Option + 3 |
| Fast Previews > Fast Draft | Ctrl + Alt + 4 | Command + Option + 4 |
| Fast Previews > Wireframe | Ctrl + Alt + 5 | Command + Option + 5 |

Heads-up: any shortcut carrying an asterisk (\*) is a reminder to confirm Num Lock is engaged before reaching for the numeric keypad.
