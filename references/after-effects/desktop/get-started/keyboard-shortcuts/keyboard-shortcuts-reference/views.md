# Views

After Effects view shortcuts, mapping each action to its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Toggle display color management for the view that is active | Shift + / (on numeric keypad) | Shift + / (on numeric keypad) |
| Render the red, green, blue, or alpha channel in grayscale | Alt + 1, Alt + 2, Alt + 3, Alt + 4 | Option + 1, Option + 2, Option + 3, Option + 4 |
| Render the red, green, or blue channel in color | Alt + Shift + 1, Alt + Shift + 2, Alt + Shift + 3 | Option + Shift + 1, Option + Shift + 2, Option + Shift + 3 |
| Switch straight RGB color display on or off | Alt + Shift + 4 | Option + Shift + 4 |
| Reveal the alpha boundary — the dividing line between clear and solid areas — inside the Layer panel | Alt + 5 | Option + 5 |
| Reveal the alpha overlay — a tint laid over clear areas — inside the Layer panel | Alt + 6 | Option + 6 |
| Re-center the composition within the panel | Double-click the Hand tool | Double-click the Hand tool |
| Magnify inside the Composition, Layer, or Footage panel | . (period) on the main keyboard | . (period) on the main keyboard |
| Shrink the view inside the Composition, Layer, or Footage panel | , (comma) | , (comma) |
| Snap the Composition, Layer, or Footage panel back to 100% | / (on main keyboard) | / (on main keyboard) |
| Fit the contents inside the Composition, Layer, or Footage panel | Shift + / (on main keyboard) | Shift + / (on main keyboard) |
| Fit the contents but cap the zoom at 100% in the Composition, Layer, or Footage panel | Alt + / (on main keyboard) | Option + / (on main keyboard) |
| Choose Full, Half, or Custom resolution in the Composition panel | Ctrl + J, Ctrl + Shift + J, Ctrl + Alt + J | Command + J, Command + Shift + J, Command + Option + J |
| Bring up the View Options dialog for the active Composition panel | Ctrl + Alt + U | Command + Option + U |
| Magnify along the time axis | = (equal sign) on the main keyboard | = (equal sign) on the main keyboard |
| Shrink along the time axis | - (hyphen) on the main keyboard | - (hyphen) on the main keyboard |
| Zoom the Timeline panel down to single-frame units — pressing it once more zooms back out across the whole composition duration | ; (semicolon) | ; (semicolon) |
| Zoom the Timeline panel out to span the full composition duration — pressing it once more returns to the range the Time Navigator defines | Shift + ; (semicolon) | Shift + ; (semicolon) |
| Stop viewer panels from rendering images during previews | Caps Lock | Caps Lock |
| Toggle the safe zones | ' (apostrophe) | ' (apostrophe) |
| Toggle the grid | Ctrl + ' (apostrophe) | Command + ' (apostrophe) |
| Toggle the proportional grid | Alt + ' (apostrophe) | Command + ' (apostrophe) |
| Toggle the rulers | Ctrl + R | Command + R |
| Toggle the guides | Ctrl + ; (semicolon) | Command + ; (semicolon) |
| Switch grid snapping on or off | Ctrl + Shift + ' (apostrophe) | Command + Shift + ' (apostrophe) |
| Switch guide snapping on or off | Ctrl + Shift + ; (semicolon) | Command + Shift + ; (semicolon) |
| Lock the guides or release them | Ctrl + Alt + Shift + ; (semicolon) | Command + Option + Shift + ; (semicolon) |
| Toggle the layer controls — that is, the layer handles, effect control points, motion paths, masks, and the wireframes for lights and cameras | Ctrl + Shift + H | Command + Shift + H |
| Show Refine Edge X-ray | Alt + X | Option + X |
