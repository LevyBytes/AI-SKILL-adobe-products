# Time navigation

After Effects time-navigation shortcuts. Each row pairs an action with its Windows binding and then its macOS binding.

| Action | Windows | macOS |
| --- | --- | --- |
| Jump straight to a chosen time value | Alt + Shift + J | Option + Shift + J |
| Snap to where the work area starts or where it stops | Shift + Home or Shift + End | Shift + Home or Shift + End |
| Step to the nearest visible marker on either side along the time ruler — a keyframe, a layer marker, or a work-area edge | J or K | J or K |
| Land on the start, finish, or base frame of a Roto Brush span — applies while you have the Roto Brush open in the Layer panel | J or K | J or K |
| Move to the start of the comp, the layer, or a footage item | Home or Ctrl + Alt + Left Arrow | Home or Command + Option + Left Arrow |
| Move to the end of the comp, the layer, or a footage item | End or Ctrl + Alt + Right Arrow | End or Command + Option + Right Arrow |
| Advance a single frame | Page Down or Ctrl + Right Arrow | Page Down or Command + Right Arrow |
| Advance ten frames at once | Shift + Page Down or Ctrl + Shift + Right Arrow | Shift + Page Down or Command + Shift + Right Arrow |
| Step back one frame | Page Up or Ctrl + Left Arrow | Page Up or Command + Left Arrow |
| Step back ten frames | Shift + Page Up or Ctrl + Shift + Left Arrow | Shift + Page Up or Command + Shift + Left Arrow |
| Jump to the layer's In point | I | I |
| Jump to the layer's Out point | O | O |
| Hop to the In point or Out point that comes before | Ctrl + Alt + Shift + Left Arrow | Command + Option + Shift + Left Arrow |
| Hop to the In point or Out point that comes after | Ctrl + Alt + Shift + Right Arrow | Command + Option + Shift + Right Arrow |
| Bring the Timeline panel into view at the current time | D | D |
