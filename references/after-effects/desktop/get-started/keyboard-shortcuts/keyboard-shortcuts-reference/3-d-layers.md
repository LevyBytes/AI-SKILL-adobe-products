# 3D layers

After Effects shortcuts for 3D layers. A caution for macOS users: bindings that lean on the F9-F12 function keys can collide with the ones the operating system claims, so consult macOS Help if you need to remap the Dashboard & Expose shortcuts. Each action appears with its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Flip to 3D view 1, which starts out as Front | F10 | F10 |
| Flip to 3D view 2, which starts out as Custom View 1 | F11 | F11 |
| Flip to 3D view 3, which starts out as Active Camera | F12 | b |
| Drop back to the previous view | Esc | Esc |
| Add a new light | Ctrl + Alt + Shift + L | Command + Option + Shift + L |
| Add a new camera | Ctrl + Alt + Shift + C | Command + Option + Shift + C |
| Aim the camera and its point of interest at the selected 3D layers | Ctrl + Alt + Shift + \ | Command + Option + Shift + \ |
| With a camera tool active, aim the camera and its point of interest at the selected 3D layers | F | F |
| With a camera tool active, aim the camera and its point of interest at every 3D layer | Ctrl + Shift + F | Command + Shift + F |
| Flip the Casts Shadows property for the selected 3D layers | Alt + Shift + C | Option + Shift + C |
| Switch to Orbit camera control | 1 | 1 |
| Switch to Pan camera control | 2 | 2 |
| Switch to Dolly camera control | 3 | 3 |
| Switch to Universal gizmo | V | V |
| Switch to Position gizmo | 4 | 4 |
| Switch to Scale gizmo | 5 | 5 |
| Switch to Rotation gizmo | 6 | 6 |
