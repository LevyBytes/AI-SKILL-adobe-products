# Spacebar

| Function | Default preview settings |
| --- | --- |
| Play video in preview | On |
| Play audio in preview | On |
| Show overlays and layer controls | Off |
| Cache before playback | Off |
| Range | Work area extended by current time |
| Play From | Current Time |
| Frame Rate | Auto |
| Skip | 0 |
| Resolution | Auto |
| Full Screen | Disabled |
| If caching, play cached frames (when the Spacebar is used to stop a preview) | Disabled |
| Move time to preview time (when the Spacebar is used to stop a preview) | Enabled |
