# Alt + Numpad-. (Decimal)

| Function | Default preview settings |
| --- | --- |
| Play video in preview | Off |
| Play audio in preview | On |
| Show overlays and layer controls | Off |
| Cache before playback | Off |
| Range | Work area extended by current time |
| Play From | Start of range |
| Frame Rate | Auto |
| Skip | 0 |
| Resolution | Auto |
| Full Screen | Disabled |
| If caching, play cached frames (When the Alt + Numpad-. (Decimal) is used to stop a preview) | Enabled |
| Move time to preview time (When the Alt + Numpad-. (Decimal) is used to stop a preview) | Disabled |
