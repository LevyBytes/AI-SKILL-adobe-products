VR Color Gradient settings

VR Color Gradient settings

| Parameter | Description |
| --- | --- |
| Frame Layout | Chooses between a Monoscopic and a Stereoscopic Over/Under frame layout. |
| Points Number | Sets how many color points get laid onto a footage. |
| Gradient Power | Tunes the gradient power across every color point at once. |
| Gradient Blend | Controls how much all the color points blend together overall. Larger numbers fuse the colors more, with the blend beginning at the edges and working its way inward - feathering around the edges, for instance. |
| Points | Sets the Color and Point of Interest per color point. Every Point of Interest is independently movable and can be key-framed. |
| Opacity | Controls how opaque the combined color gradients appear on your footage. The effect is fully opaque at 100% and fully transparent at 0%. |
| Blending Mode | Pick any of the available color blending modes for layering the effect over your original footage. Normal is the default. |
| Stereoscopic Side-by-Side | Beyond the Monoscopic and Stereoscopic Over/Under choices already there, Frame Layout now also accepts Stereoscopic Side-by-Side. |
| Horizontal and Vertical Field of View | Each field of view, horizontal and vertical, is adjustable on its own. They default to 360x180; for VR 180 material, drop both to 180. |
