# Shape and Ease

| Property | Options | Description |
| --- | --- | --- |
| Shape | Square | Hard edge between affected and unaffected characters |
| Shape | Ramp Up | Gradual increase into the range |
| Shape | Ramp Down | Gradual decrease out of the range |
| Shape | Triangle | Gradual in and out |
| Shape | Round | Smooth bell curve |
| Shape | Smooth | Very gradual transitions |
| Ease | High Ease | Very gradual transitions |
| Ease | Low Ease | Sharper transitions |

An example worth trying:

| Example | Font axis setting | Range selector | Additional settings | Result |
| --- | --- | --- | --- | --- |
| Smooth weight gradient | Font Axis Weight: 900 | - Start: 0%<br>- End: 0% | - Shape: Ramp Down<br>- Ease High: 50% | Text starts bold and gradually lightens to base weight |
