# Variable Font Axes overview

Through Variable Font Axes support, the design variations baked into OpenType Variable fonts become reachable and animatable right inside After Effects. A single variable font file packs many styles together, so you gain exact typographic control without juggling separate files for every weight, width, or style.

- Fine-grained control: Dial typography with continuous values rather than locked-in weights or styles.

- Smooth animations: Set keyframes on font variations to drive dynamic effects in your text.

- Per-character control: Hand individual characters their own axis values by way of text animators.

- File efficiency: Dozens of separate font files collapse into one variable font file.

After Variable Font Axes are in place, you can drive them by inserting them as properties within Text Animators, shape how strongly they apply via selectors, and steer them through ExtendScript.
