# Examples from popular variable fonts

| Name with Axis Tag | Description |
| --- | --- |
| INFM (Informality) | Casual vs. formal letterforms |
| BNCE (Bounce) | Playful vertical offset of characters |
| SPAC (Spacing) | Inter-letter spacing control |
| FILL (Fill) | Outline vs. filled letterforms |
| LINE (Line Weight) | Outline thickness |
| BACK (Background) | Background shape weight |
| RECT (Rectangularity) | Rounded vs. rectangular forms |
| ELSH (Element Shape) | Alternative shape variations |
| CASL (Casual) | Formal vs. casual styles |
| MONO (Monospace) | Proportional vs. monospaced |
| SOFT (Softness) | Sharp vs. rounded corners |
| WONK (Wonky) | Straight vs. playful/distorted |

Note

Custom axes differ entirely from one font to the next. To learn a font's custom axes, always consult that specific font's documentation.
