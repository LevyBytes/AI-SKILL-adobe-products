# Use the Properties panel to adjust the anchor points

Use new beta features

Now open for testing and feedback, Quick Set Anchor is something you can try right away in After Effects (beta).

Get started

Positioning and tweaking anchor points becomes fast through Quick Set Anchor in the Properties panel, whether your goal is refining an animation or lining up elements in a composition. Pick a 2D layer, then click the Anchor Point icon sitting beside the Anchor Point property in the Properties panel; a brief pop-over Quick Set Anchor dialog then appears, offering nine of the most-used points — every corner plus the midpoints along each edge of the layer.
