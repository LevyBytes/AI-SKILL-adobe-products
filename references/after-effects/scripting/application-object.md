# Application object

app

### Description

Serves as the gateway to After Effects objects and the program's own settings. That lone global object answers to one name, app, and is reachable at all times.

By way of its attributes, the Application object reaches particular objects inside After Effects. Its methods can spin up a project, open one that already exists, drive Watch Folder mode, free up memory, and shut After Effects down. As the program exits it closes whatever project is open, asking the user to keep or drop changes where that matters, and writes out a project file when needed.
