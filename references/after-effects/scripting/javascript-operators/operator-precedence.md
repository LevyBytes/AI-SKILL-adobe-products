# Operator Precedence

| Operators (highest precedence to lowest) | Associativity |
| --- | --- |
| [], (), . | left to right |
| new, delete, - (unary negation), !, typeof, void, ++, -- | right to left |
| \*, /, % | left to right |
| +, - (subtraction) | left to right |
| <<, >>, >>> | left to right |
| <, <=, >, >= | left to right |
| ==, != | left to right |
| & | left to right |
| ^ | left to right |
| \ | left to right |
| && | left to right |
| \|\| | left to right |
| ?: | right to left |
| ==, /=, %=, <<=, >>=, >>>=, &=, ^=, \=, +=, -=, \*= | right to left |
| , | left to right |
