# The ExtendScript Toolkit (ESTK)

The legacy After Effects scripting guide describes the ExtendScript Toolkit (ESTK) as its bundled script editor and debugger, launched through **File > Scripts > Open Script Editor**.

Should you prefer a different text editor for writing, editing, and saving scripts, pick one that won't tack on header information at save time and that writes in Unicode (UTF-8) encoding. Saving with UTF-8 encoding is a preference you can set in plenty of text editors. A few applications, Microsoft Word, for one, add header information to files by default, which can throw "line 0" errors and break your scripts.

For Visual Studio Code, Adobe provides the [ExtendScript Debugger](https://marketplace.visualstudio.com/items?itemName=Adobe.extendscript-debug). It supports script evaluation, breakpoints and attached debugging; check its supported host and platform requirements for your installation.

The [JavaScript Tools Guide](https://extendscript.docsforadobe.dev/) covers ExtendScript tools and runtime facilities. The [legacy ESTK description](https://ae-scripting.docsforadobe.dev/introduction/overview/#the-extendscript-toolkit-estk) provides the original editor context.
