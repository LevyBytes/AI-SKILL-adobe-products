# AE Properties

LightLayer adds no attributes of its own, yet its AE properties differ from those of other layer types. The properties and property groups it carries are:

- Marker

  - PointofInterest
  - Position
  - Scale
  - Orientation
  - XRotation
  - YRotation
  - Rotation
  - Opacity

  - Intensity
  - Color
  - ConeAngle
  - ConeFeather
  - CastsShadows
  - ShadowDarkness
  - ShadowDiffusion
