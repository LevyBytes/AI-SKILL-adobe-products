## The work behind the references

After Effects references for compositing, animation and extensibility. Creative workflows, scripting objects and native plug-in contracts have distinct entrypoints so the agent can choose the appropriate level of detail. Expressions, ExtendScript and the C++ SDK have distinct requirements, and each reference names its runtime and host version.
