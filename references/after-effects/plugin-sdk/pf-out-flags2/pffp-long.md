# PF_FPLong

`PF_FPLong`

Sliders stand for numeric values. `FLOAT_SLIDERs` hold phase, precision, and curve-tolerance values that audio filters use. Give a minimum and a maximum, and the user either drags the slider or types a figure to set it. `PF_Param_FLOAT_SLIDERs` also honor the slider flags covered in Audio Filters.
