# AEGP_GetRegionOfInterest

`AEGP_GetRegionOfInterest`

From the given AEGP_RenderOptionsH, reads back which sub-rectangle serves as the region of interest.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetRegionOfInterest(
  AEGP_RenderOptionsH  optionsH,
  A_LRect              *roiP);
```
