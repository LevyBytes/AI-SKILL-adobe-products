# AEGP_GetEffectCategory

`AEGP_GetEffectCategory`

The effect's menu category. categoryZ can be up to AEGP_MAX_EFFECT_CATEGORY_NAME_SIZE + 1 long.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetEffectCategory(
  AEGP_InstalledEffectKey  installed_key,
  A_char                   *categoryZ);
```
