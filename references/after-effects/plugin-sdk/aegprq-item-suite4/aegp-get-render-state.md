# AEGP_GetRenderState

`AEGP_GetRenderState`

Returns TRUE when the AEGP_RQItemRefH is enabled for rendering after the user clicks the Render button.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetRenderState(
  AEGP_RQItemRefH  rq_itemH,
  A_Boolean        *will_renderPB);
```
