# AEIO_GetMimeType

`AEIO_GetMimeType`

Describes the output mime type. XMP support uses this value.

Suite argument declaration (not a standalone call):

```cpp
AEIO_GetMimeType(
  AEIO_BasicData  *basic_dataP,
  AEIO_OutSpecH   outH,
  A_long          mime_type_sizeL,
  char            *mime_typeZ);
```

Direction: Output. Required: No.
