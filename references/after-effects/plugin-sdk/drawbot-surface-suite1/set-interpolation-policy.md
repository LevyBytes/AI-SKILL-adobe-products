# SetInterpolationPolicy

SetInterpolationPolicy

Suite argument declaration (not a standalone call):

```cpp
SetInterpolationPolicy(
  DRAWBOT_SurfaceRef           in_surface_ref,
  DRAWBOT_InterpolationPolicy  in_interp);
```

`DRAWBOT_InterpolationPolicy` is one of the following: - `kDRAWBOT_InterpolationPolicy_None` - `kDRAWBOT_InterpolationPolicy_Med` - `kDRAWBOT_InterpolationPolicy_High`
