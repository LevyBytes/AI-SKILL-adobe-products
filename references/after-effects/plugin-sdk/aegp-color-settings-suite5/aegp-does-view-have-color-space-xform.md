# AEGP_DoesViewHaveColorSpaceXform

`AEGP_DoesViewHaveColorSpaceXform`

Tells you whether a colorspace transform is in effect on the current item view.

Suite argument declaration (not a standalone call):

```cpp
AEGP_DoesViewHaveColorSpaceXform(
  AEGP_ItemViewP  viewP,
  A_Boolean       *has_xformPB);
```
