# AEGP_GetReceiptGuid

`AEGP_GetReceiptGuid`

New in CS6. Fetch a GUID for a rendered frame. Dispose of the memory handle that comes back.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetReceiptGuid(
  AEGP_FrameReceiptH  receiptH,
  AEGP_MemHandle      *guidMH);
```
