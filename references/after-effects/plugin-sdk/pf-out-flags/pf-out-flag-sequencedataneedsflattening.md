# PF_OutFlag_SEQUENCE_DATA_NEEDS_FLATTENING

`PF_OutFlag_SEQUENCE_DATA_NEEDS_FLATTENING`

This flag is taken as set by both After Effects and Premiere Pro. Flattening becomes necessary where sequence data carries referencing items (pointers, handles), which have to be flattened for storage and unflattened for use. See `PF_Cmd_SEQUENCE_RESETUP`.
