# PF_OutFlag_I_DO_DIALOG

`PF_OutFlag_I_DO_DIALOG`

The effect puts up a dialog in reply to `PF_Cmd_DO_DIALOG`. Set during `PF_Cmd_GLOBAL_SETUP`, checked during `PF_Cmd_SEQUENCE_SETUP`.

Note

An effect's reply to `PF_OutFlag_I_DO_DIALOG` cannot be undone. Should such changes prove necessary, arbitrary data paired with a custom UI is an option.
