# PF_ParamFlag_COLLAPSE_TWIRLY

`PF_ParamFlag_COLLAPSE_TWIRLY`

Set this flag during `PF_Cmd_USER_CHANGED_PARAM`. You can now both set and clear this bit while handling `PF_Cmd_UPDATE_PARAMS_UI` and `PF_Cmd_USER_CHANGED_PARAM` messages, letting you twirl your parameters and groups open or shut whenever you like.
