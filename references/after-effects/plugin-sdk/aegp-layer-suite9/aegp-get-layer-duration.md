# AEGP_GetLayerDuration

`AEGP_GetLayerDuration`

Fetches how long the layer runs, given in seconds, in either composition or layer time.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetLayerDuration(
  AEGP_LayerH     layerH,
  AEGP_LTimeMode  time_mode,
  A_Time          *durationPT);
```
