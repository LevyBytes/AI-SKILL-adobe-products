# AEGP_ConvertHSFRatioToFpLong

`AEGP_ConvertHSFRatioToFpLong`

Gives back an A_FpLong reading of the supplied A_Ratio. Handy for interpreting a horizontal scale factor.

Suite argument declaration (not a standalone call):

```cpp
AEGP_ConvertHSFRatioToFpLong(
  A_Ratio    ratioR,
  A_FpLong  *numberPF);
```
