# AEGP_ConvertFpLongToHSFRatio

`AEGP_ConvertFpLongToHSFRatio`

Gives back an A_Ratio reading of the supplied A_FpLong. Handy for interpreting a horizontal scale factor.

Suite argument declaration (not a standalone call):

```cpp
AEGP_ConvertFpLongToHSFRatio(
  A_FpLong  numberF,
  A_Ratio   *ratioPR);
```
