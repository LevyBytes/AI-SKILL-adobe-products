# Create a paragraph border

Paragraph borders let you place a border around one or more paragraphs. Corner designs can be customized to emphasize the paragraph with decorative effects.

Before applying paragraph border within a text frame, select the frame or put the pointer in its text.

Choose one route:

- Paragraph Styles panel (Window > Styles > Paragraph Styles): choose Style Options, then choose Paragraph Border.
- Paragraph panel (Window > Type and Tables > Paragraph): open Paragraph Borders and Shading.

The Border dialog contains these options:

| Border control | Behavior |
| --- | --- |
| Top | Enter the top border value for the selected paragraph. |
| Left | Enter the left border value for the selected paragraph. |
| Bottom | Enter the bottom border value for the selected paragraph. |
| Right | Enter the right border value for the selected paragraph. |
| Type | Choose the stroke type used for the paragraph border. |
| Color | Choose a stroke color for the paragraph border. |
| Tint | Enter the tint value for the paragraph border stroke. |
| Overprint | Select this option to apply overprint. |
| Gap Color | Set the color shown in the spaces between dashes, dots, or multiple lines in a patterned stroke. |
| Gap Tint | Enter a tint value when a gap color is specified. |
| Cap | Choose the cap style that controls both ends of an open path: Butt cap makes squared ends that stop at the endpoints. Round cap makes semicircular ends extending half the stroke width beyond the endpoints. Projecting cap makes squared ends extending half the stroke width beyond the endpoints, so the stroke weight extends evenly in every direction around the path. |
| Join | Set how the stroke appears at corner points: Miter join makes pointed corners extending past the endpoint. Round join makes rounded corners extending half the stroke width beyond the endpoints. Bevel join makes squared corners that stop at the endpoints. |
| Corner Size And Shape | Choose the corner size and shape. Each of the four corners can have its own size and shape. |
| Top (Offsets) | Enter the value that extends the border beyond the top margin. |
| Left (Offsets) | Enter the value that extends the border beyond the left margin. |
| Bottom (Offsets) | Enter the value that extends the border beyond the bottom margin. |
| Right (Offsets) | Enter the value that extends the border beyond the right margin. |
| Top Edge | Choose the top-edge position of the border for the selected paragraph. |
| Bottom Edge | Set the bottom-edge position of the border for the selected paragraph. |
| Width | Set the border width. Selecting Column spans the border across the text frame; selecting Text extends the border across the text. |
| Display Border If Paragraph Splits Across Frames/Columns | Enable this to show a border when paragraph text flows across columns or from one threaded frame into another. |
| Merge Consecutive Borders And Shading With Same Settings | Enable this to combine the paragraph border and shading of two consecutive paragraphs when they share the same paragraph border and shading properties. |

Check the Chain button to keep every offset value identical. When one offset value changes, the other values update as well.

To use different offset values, make sure the chain button is not selected.

Click OK.
