# Text markers and special characters

Open when choosing Find/Change metacharacters for text markers and special characters.

An empty cell means that the source lists no equivalent for that tab. “Find only” entries belong in Find What; “Change only” entries belong in Change To.

| Character or operation | Text tab | GREP tab | Availability |
| --- | --- | --- | --- |
| Tab Character | `^t` | `\t` | Both fields |
| End of Paragraph | `^p` | `\r` | Both fields |
| Forced Line Break | `^n` | `\n` | Both fields |
| Any Page Number | `^#` | `~#` | Both fields |
| Current Page Number | `^N` | `~N` | Both fields |
| Next Page Number | `^X` | `~X` | Both fields |
| Previous Page Number | `^V` | `~V` | Both fields |
| Any Variable | `^v` | `~v` | Find only |
| Section Marker | `^x` | `~x` | Both fields |
| Anchored Object Marker | `^a` | `~a` | Find only |
| Footnote Reference Marker | `^F` | `~F` | Find only |
| Index Marker | `^I` | `~I` | Find only |
| Bullet Character | `^8` | `~8` | Both fields |
| Japanese Bullet | `^5` | `~5` | Both fields |
| Caret Character | `^^` | `\^` | Both fields |
| Backslash Character | `\` | `\` | Both fields |
