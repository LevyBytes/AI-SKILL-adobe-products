# Working with managed files - Save changes (InDesign)

While you edit content checked out to you, you can save changes and refresh the file-system copy.

Use one of these methods:

For selected content only, select the content in the layout and choose Edit > InCopy > Save Content; this does not save changes to the InDesign document or any linked files.

To save every content file checked out to you, choose File > Save. This save operation does not, by itself, refresh assignment files or checked-out InCopy content files. The checked-out files in InCopy, however, will show the Out Of Date icon  in the Assignments panel.

To save the InDesign document with a new name while preserving links to existing InCopy files, choose File > Save As. Until updated, the assignments in that InDesign file appear as missing.

To save a copy of the active document, choose File > Save A Copy. The copy can be given a new name and location while retaining links to any existing InCopy files.
