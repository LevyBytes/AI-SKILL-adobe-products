# Workspace basics - Use keyboard shortcut sets

InCopy includes keyboard shortcuts for numerous menu commands, options, scripts, and controls. You can define custom keyboard shortcuts as well. In the Keyboard Shortcuts dialog box, you can:

Select the set to use.

Display commands that already have shortcuts.

Produce a full shortcut list.

Build your own shortcuts and shortcut sets.

Modify existing shortcuts.

Commands that support shortcuts but lack entries in the default shortcut set are also shown in the Keyboard Shortcuts dialog box.
