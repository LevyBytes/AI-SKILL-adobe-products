# Keys for resolving conflicts between Mac OS 10.3x and 10.4

These legacy shortcuts supplement menu commands and tool tips; they are not an exhaustive keyboard reference.

| Action | Mac OS shortcut |
| --- | --- |
| Open Preferences | Command+K |
| Open Paragraph Styles | Command+F11 |
| Open Character Styles | Command+Shift+F11 |
| Open Text Macros | Control+Command+Shift+F10 |
| Open Swatches | F5 |
| Show or hide the toolbox | Control+Command+F12 |
| Minimize the application window | Command+M |
| Hide the application | Command+H |
