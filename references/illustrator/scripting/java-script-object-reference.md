# JavaScript Object Reference

This section catalogs every object class exposed by the type library.

For each class entry, the reference provides:

- Class properties, with their value type, read-only state, and explanatory notes.

  - Constants and value types required by a method appear in bold face.
  - Required terms appear in plain face.
  - Brackets [ ] mark items that are optional.

- Notes that call out special considerations.
- Sample code that demonstrates syntax and common workflow use for the object class.

The examples are written as straightforward syntax demonstrations, not as recommendations for the most efficient or best JavaScript script structure.

For example, error handling is usually minimal or omitted.

Even so, you can combine and extend the examples to build scripts with more capability.
