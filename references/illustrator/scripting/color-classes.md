# Illustrator color classes

Color is the abstract base class for Illustrator color classes.

Choose the concrete class that represents the color value you need.

## Component colors

- Use [CMYKColor](cmyk-color.md) for cyan, magenta, yellow and black component values.
- Use [RGBColor](rgb-color.md) for an RGB color value.
- Use [GrayColor](gray-color.md) for a grayscale value.
- Use [LabColor](lab-color.md) for a CIE Lab color value.

## Document paint resources

- Use [SpotColor](spot-color.md) to apply a spot color at a chosen tint.
- Use [GradientColor](gradient-color.md) for a color based on a document gradient.
- Use [PatternColor](pattern-color.md) for a pattern-based color.

## Remove a fill or stroke

- Use [NoColor](no-color.md) to remove an item's fill or stroke color.
