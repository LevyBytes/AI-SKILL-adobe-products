# October 2025 (version 30.0)

Illustrator 30.0 includes these performance enhancements:

- Quicker save: Save complex artwork edits faster because Illustrator now saves only the changes you make, not the whole document every time.
- Better crash recovery: Restore your work quickly and reliably after an unexpected crash.
- Smoother editing: Edit on canvas in real time for lag-free move, scale, rotate, and duplicate operations.

Learn how to configure the quick save and recovery experience.
