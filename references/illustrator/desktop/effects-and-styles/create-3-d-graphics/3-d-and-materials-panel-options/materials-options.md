# Materials options

Give 3D objects surface styling, texture, or graphics by starting with built-in materials or adding your own artwork.

Use this area to apply base materials and Substance assets, change material settings, and place graphics onto 3D geometry.

A. Base Materials B. Adobe Substance Materials C. Substance 3D assets D. Properties E. Substance 3D community assets F. Add and Delete Materials and Graphics G. Graphics

This group covers base materials, Substance assets, surface settings, and artwork mapping for 3D objects.

| Option | Function |
| --- | --- |
| Base Materials | Applies the default material preset. |
| Adobe Substance Materials | Adds preset textures supplied by the Adobe Substance library. |
| Find more materials on Substance 3D assets | Opens the Adobe Substance 3D library so more materials can be chosen. |
| Find more materials on Substance 3D community assets | Brings in materials from the Adobe Substance community. |
| Add Materials and Graphics | Adds material choices or places artwork on the object as a graphic. |
| Delete | Removes the selected custom or applied material from the object. |
| Graphics | Places graphics or text onto the 3D effect. |
| Properties | Changes surface roughness and metallic intensity (0–1 range). |
