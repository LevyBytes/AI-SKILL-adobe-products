# Light Presets

| Option | Function |
| --- | --- |
| Presets | Applies preset lighting effects, including Standard, Diffuse, Top Left, or Right, to the artwork. |
| Lighting widget | Allows light sources to be dragged and positioned around the object. |
| Light source | Provides controls for adding multiple light sources to make lighting more realistic. |
| Move selected light to the back/front of object | Sends the selected light behind the object if it is in front, or brings it forward if it is behind. |
| List of lights | Shows every light currently applied to a 3D object. |
| Add Light | Creates a new customizable light source in the scene. |
| Delete Light | Deletes the light selected in the list. |
