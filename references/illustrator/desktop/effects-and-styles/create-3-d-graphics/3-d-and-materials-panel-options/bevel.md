# Bevel

Bevel controls add style and definition to 3D object edges. Change profile, size, and direction for smooth or decorative edge contours.

Refine 3D object edges with bevel controls.

A. Bevel Shape B. Width C. Height D. Repeat E. Space F. Bevel Inside G. Bevel both sides H. Reset

Use bevel controls to finish and define 3D object edges.

| Option | Function |
| --- | --- |
| Bevel Shape | Chooses the edge style, including rounded or angular forms. |
| Width | Sets how far the bevel projects away from the edge. |
| Height | Sets the apparent height or depth of the bevel. |
| Repeat | Duplicates the bevel shape pattern along the bevelled edge to create decorative results. |
| Space | Sets the gap between repeated bevel shapes when Repeat is active. |
| Bevel Inside | Places the bevel inward instead of outward from the edge surface. |
| Bevel both sides | Applies the bevel on both object faces, front and back. |
| Reset | Returns every bevel setting to its default value. |
