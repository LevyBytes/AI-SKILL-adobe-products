# Light Settings

Improve 3D-object illumination and perceived depth.

A. Color B. Intensity C. Rotation D. Height E. Softness F. Ambient Light

Use these settings to strengthen light and depth on 3D objects.

| Option | Function |
| --- | --- |
| Color | Sets the selected light's color. |
| Intensity | Sets brightness for the selected light (0% to 100%). |
| Rotation | Moves the light focus around the object (-180° to 180°). |
| Height | Raises or lowers the light (0° to 90°), changing whether the shadow appears longer or shorter. |
| Softness | Sets whether the light edge appears soft or sharp (0% to 100%). |
| Ambient Light | Controls the scene-wide background light level (0% to 200%). |
