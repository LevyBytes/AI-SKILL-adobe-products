# Create brushes

Make custom brushes for personalized strokes and textures in your artwork.

Your own artwork can become calligraphic, scatter, art, pattern, or bristle brushes. Before making a custom brush, prepare the artwork so it is compatible. Do not include unsupported content such as gradients, blends, brush strokes, mesh objects, bitmap images, graphs, placed files, or masks. For art brushes or pattern brushes, outline any text first.

Build the artwork that will become the brush. For scatter brushes and art brushes, select all of that artwork.

Open the Brushes panel from Window > Brushes.

Select the artwork, then use the New Brush icon in the Brushes panel.

Choose the brush type you want, then select OK.

In the brush options dialog box, add a name, configure the brush settings you want, and select OK. Brushes saved in the Brushes panel are tied to the active file only, so each Illustrator file carries its own Brushes panel contents.

Note

To limit visible seams in pattern brushes, disable Anti-aliased Artwork under Edit > Preferences > General (Windows) or Illustrator > Preferences > General (macOS).
