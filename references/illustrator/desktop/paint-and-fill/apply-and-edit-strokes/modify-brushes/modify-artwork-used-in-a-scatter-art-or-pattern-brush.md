# Modify artwork used in a scatter, art, or pattern brush

Drag the brush out of the Brushes panel and onto the artwork, then edit that artwork as needed.

Double-click the brush in the Brushes panel.

With the Direct Selection tool, select the artwork, then Alt-drag (Windows) or Option-drag (macOS) the revised brush onto the original brush in the Brushes panel.

Tip

To edit a brushed path without changing the associated brush, select the path and Options of Selected Object.
