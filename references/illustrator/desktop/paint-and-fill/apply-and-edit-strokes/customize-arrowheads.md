# Customize arrowheads

Use the Arrowheads.ai file to build custom arrowheads and make them available for your Illustrator artwork.

Find the Arrowheads.ai file used for custom arrowhead creation here:

- macOS: /Applications/Adobe Illustrator &lt;year&gt;/Support Files/Resources/&lt;locale&gt;.
- Windows: C:\Program Files\Adobe\Adobe Illustrator &lt;year&gt;\Support Files\Required\Resources&lt;locale&gt;.

Open Arrowheads.ai and use the on-screen directions in that file to make custom arrowheads.

Save the changed Arrowheads.ai file in this location:

- macOS: /Applications/Adobe Illustrator &lt;year&gt;/Plug-ins.
- Windows: C:\Program Files\Adobe\Adobe Illustrator &lt;year&gt;\Plug-ins.

Caution

Keep the original Arrowheads.ai untouched; store the customized copy separately in the Plug-ins folder.

Restart Illustrator so the custom arrowheads are loaded.
