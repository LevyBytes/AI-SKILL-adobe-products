# Create brush libraries

Create a brush library, save it, and reopen it in Adobe Illustrator.

Choose Window > Brushes.

In the Brushes panel:

- Add new bushes by selecting the plus icon.
- Remove brushes from the library with the delete icon.

Use the Brushes panel menu icon, then choose Save Brush Library to store the library locally.

Create a new library file with the current brushes using the Save Brush Library option from the Brushes panel menu.

To make the new library appear from the Brush Libraries menu, put the file in one of these folders:

- (Windows) Users\Admin\AppData\Roaming\Adobe\Adobe Illustrator &lt;version number&gt; Settings\en_US\x64\Brushes
- (macOS) Library/Application Support/Adobe/Adobe Illustrator &lt;version number&gt;/en_US/Brushes

Note

Substitute &lt;version number&gt; for the Illustrator version installed on your computer.

To load the saved brushes, choose Window > Brush Libraries, then select and open the file.

For brushes stored elsewhere, choose Window > Brush Libraries > Other Library, select the brush file, and open it in Illustrator.
