# Add arrowheads to paths

Add arrowheads from the Stroke panel, then adjust their sizing and alignment.

Select the path that should receive an arrowhead.

Open the Stroke panel by choosing Window > Stroke.

From the Stroke panel menu, choose Show Options.

Use the Arrowheads dropdown menus to choose the arrowhead style for the path start point and end point. When the direction needs to be reversed, select Swap start and end arrowheads.

Note

To clear arrowheads from an object, choose None in the Arrowheads dropdown list.

Add and customize arrowheads in the Stroke panel.

In the Scale section, change the scale factor for the start arrowhead and end arrowhead when resizing is needed. Both values begin at 100%. To keep both scales identical, select Link start and end of arrowhead scales.

In the Align section, set how the arrowhead sits on the path by choosing Extend arrow tip beyond end of path or Place arrow tip at the end of path.
