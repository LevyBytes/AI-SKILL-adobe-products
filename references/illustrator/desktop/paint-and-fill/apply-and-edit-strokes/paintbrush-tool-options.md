# Paintbrush tool options

Adjust stroke behavior and appearance through the Paintbrush tool options.

Double-click the Paintbrush tool to display the Paintbrush Tool Options dialog box.

The Paintbrush Tool Options dialog box includes these controls:

| Options | Functions |
| --- | --- |
| Fidelity | Determines the cursor or stylus movement distance required before Illustrator places another anchor point. The Fidelity slider runs from Accurate, which favors detailed paths, to Smooth, which produces cleaner curves. |
| Fill new brush strokes | Adds a fill to brush strokes. This is useful for closed paths because the enclosed area can be filled automatically while drawing. |
| Keep Selected | Keeps the newly drawn path selected after it is created. |
| Edit Selected Paths | Lets the Paintbrush tool reshape paths that are already selected. |
| Within | Defines how near the cursor or stylus must be to a selected path before the Paintbrush tool can edit it. The slider is available after Edit Selected Paths is selected. |
