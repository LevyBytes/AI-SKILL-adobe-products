# Set Live Paint gap options

Choose Object > Live Paint > Gap Options.

In the Gap Options dialog box, provide any of these settings:

- Paint stops at: defines the gap size that blocks paint from flowing through. Custom Gaps lets you enter a custom Paint stops at gap size.

- Gap Preview Color: chooses the color used to preview gaps in Live Paint groups. Pick a color from the dropdown menu, or use the swatch beside Gap Preview Color to define a custom color.
- Close gaps with paths: when enabled, Illustrator adds unpainted paths inside the Live Paint group to close gaps instead of only blocking paint flow through them. Because those added paths have no paint, the gaps can still look visible even after closure.
- Preview: shows the gaps currently detected in Live Paint groups as colored lines, using the preview color you chose.

Note

Turning on Gap Detection can make Illustrator slower with large, complex Live Paint groups. In that situation, choose Close gaps with paths to help restore speed.
