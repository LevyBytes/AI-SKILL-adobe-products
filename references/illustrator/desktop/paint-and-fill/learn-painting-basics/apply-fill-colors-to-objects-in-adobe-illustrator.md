# Apply fill colors to objects in Adobe Illustrator.

Choose the object with the Selection tool.

Open the Color Picker by double-clicking the Fill box on the toolbar.

Note

If you are new to Illustrator or have reset preferences, Orange (#f8991d) remains the default Fill color. It changes after you choose another color or open the Color Picker from either the toolbar or the Color panel.

Inside the Color Picker dialog box, use the Color Picker icon to set a Fill color.

In the Color Picker dialog box, choose the desired Color Swatches.

Select OK.
