# Adjust or resize paths in a Live Paint group

With the Direct Selection tool, select the path to adjust or select one or more paths to resize.

Do one of the following:

- To change the path shape, drag a path segment or an anchor point.
- To resize the paths, use the Selection tool and drag the bounding-box points.

You can also double-click the Live Paint group with the Selection tool to enter isolation mode, then resize paths with the Selection tool or reshape them with the Direct Selection tool.
