# Add new artboards

Choose New Artboard in the Properties panel.

Double-click the artboard to edit it.

Choose OK to apply changes, or press Esc to leave artboard editing mode.

Tip

- New artboards can also be created from the Artboard, Properties, and Control panels.
- The Artboard Options dialog box is available from the Artboards, Properties, or Control panel when you need artboard presets, artboard orientation, dimension changes, or position adjustments for the artboard.
