# Create pie shapes with the Ellipse tool in Illustrator.

Choose the Ellipse tool.

Drag to draw an ellipse. Hold Shift while dragging to make a circle.

Note

To display the live shape's on-screen control widgets, turn on Show Shape Widgets in the Control panel.

Create the pie shape by dragging the pie widget.

Choose View > Show Bounding Box if the Bounding box is hidden.

Tip

The Transform panel supports precise pie-shape edits. Choose Window > Transform to open the panel, then enter slice angles in the Pie Start Angle and Pie End Angle fields.
