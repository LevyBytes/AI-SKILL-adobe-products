# Add decorative brush strokes to a path to build out artwork detail.

Use the Selection tool to select the path.

When several paths need the same brush treatment, press Shift while selecting the additional paths.

Open the Brushes panel with Window > Brushes.

In the Brushes panel, choose the brush style you want placed onto it.

Apply brush stroke to the selected path using the Brushes panel.

Apply brush stroke to the selected path using the Brushes panel. Tip

Brush styles are also available from the Brush Libraries panel or the Control bar.

To switch brushes but retain the stroke settings from the original brush, hold Alt (Windows) or Option (macOS) while selecting the replacement brush.
