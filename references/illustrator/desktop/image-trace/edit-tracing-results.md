# Edit tracing results

Use expand, ungroup, simplify, and color-editing steps to work with trace results.

A trace must be expanded before it can be edited like another vector object. After expansion, the tracing options are no longer adjustable:

Select the tracing result on the canvas with the Selection tool.

Select Expand in the Image Trace panel. Expand turns the result into grouped editable paths.

Use Expand to convert the trace result into editable paths.

Choose Expand when you need the result changed into editable paths.

Edit the paths as needed:

- Double-click the trace group to enter isolation mode, which lets you edit while keeping the group intact.
- Select Ungroup in the Contextual Task Bar when you want to edit paths one by one.

Tip

Select Object > Path > Simplify to reduce extra anchor points.

Select the paths, then select Object > Live Paint > Make to turn them into a Live Paint group.
