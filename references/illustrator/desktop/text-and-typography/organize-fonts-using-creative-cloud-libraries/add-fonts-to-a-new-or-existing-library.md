# Add fonts to a new or existing Library

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

In Your Fonts or Discover More, hover over the font or font family to store in a Library, then choose Add font(s) to Library.

Choose one:

- For a new Library, choose Add to new Library.
- For an existing Library, hover over that Library, then select it.

Note

A single font can be added to more than one Library.
