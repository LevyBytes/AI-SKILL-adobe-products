# Use the registration point as a reference to transform symbol instances

While creating a symbol, you can choose one of nine registration points to determine how instances transform. When the instance is selected, that point is shown as a crosshair in both normal mode and isolation mode.

Open Window > Transform.

From the Transform panel menu, choose Use Registration Point for Symbol.

Note

With this setting, transformations use the symbol's registration point rather than the default Reference Point. The registration point is shown whenever the symbol instance is selected.

Use the Registration point as the transform reference for symbol instances.

Transform symbol instances from the Registration point.

Choose the symbol instance on the artboard and change it as needed.
