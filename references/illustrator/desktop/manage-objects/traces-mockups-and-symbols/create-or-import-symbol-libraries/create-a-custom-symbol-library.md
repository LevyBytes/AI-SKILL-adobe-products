# Create a custom symbol library

Open Window > Symbols to display the Symbols panel.

Choose one or more symbols, then choose Add to Symbols from the menu.

Build a custom symbol library with Add to Symbolsoption.

Use Add to Symbolsoption when creating the custom symbol library.

Choose the symbols you do not want, then choose Delete Symbol in the Symbols panel.

Tip

To remove every symbol unused by the current document, choose Select All Unused from the Symbols panel menu, choose Delete Symbol, then choose Yes in the confirmation dialog.

Choose Save Symbol Library from the Symbols panel menu, enter a name, and choose Save to store it in the default Symbols folder. After the library is created, its name appears automatically in the User Defined menu in the symbol libraries list.
