# Install Illustrator add-ons

In Mainland China and Russia, Mockup requires Adobe Illustrator add-ons installed through the Adobe Creative Cloud desktop app.

Close Illustrator, then open the Creative Cloud desktop app.

Go to the Apps tab.

In the Illustrator card, open More actions and select Get add-ons.

For Mockup feature components, Mapping components, and Masking components, select Add.

Open Illustrator.
