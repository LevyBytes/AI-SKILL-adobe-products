# Save mockups as templates

Save mockups as templates so the same design setup can be reused easily in later projects.

The Mockup panel can store a mockup as a template for future use. The added template appears under Your Mockups in the panel drop-down, and the saved version includes a placeholder showing where the vector art was positioned.

Open Window > Mockup.

Choose the mockup to store as a template, then use the save control in the Mockup panel.

Note

Your Mockups can contain up to 20 mockup templates, and those templates are available across Illustrator documents. For mockups made in Illustrator 28.5 or earlier, release the mockup first, then create it again before adding it.
