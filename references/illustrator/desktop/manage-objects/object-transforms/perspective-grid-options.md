# Perspective grid options

Learn about perspective grid options that set angles, units, and grid visibility for accurate depth and 3D perspective work in Adobe Illustrator.

Open the Define Perspective Grid dialog box through View > Perspective Grid > Define Grid.

Customize the perspective grid with presets, grid settings, and grid appearance controls:

| Options | Functions |
| --- | --- |
| Preset | Choose a preset from the drop-down menu, or create a custom one. |
| Type | Choose the grid type for the perspective you want to build. |
| Units | Set the measurement units used for grid size. |
| Scale | Define or adjust artboard measurements alongside real-world measurements. |
| Gridline every | Set the size of each grid cell. |
| Viewing Angle | Set left and right vanishing point positions relative to the observer. |
| Viewing Distance | Set the distance between the observer and the scene. |
| Horizon Height | Set the height of the horizon line above ground level. |
| Third Vanishing Point | For three-point perspective, enable this option and enter the preset's X and Y coordinates. |
| Grid Color & Opacity | Pick colors for the Left Grid, Right Grid, and Horizontal Grids. Adjust grid Opacity with the slider. |
