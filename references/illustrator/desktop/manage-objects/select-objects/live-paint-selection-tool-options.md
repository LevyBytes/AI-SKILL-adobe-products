# Live Paint Selection tool options

In the tool panel, double-click the tool to open Live Paint Selection Options.

Use the Live Paint Selection Options dialog box to adjust fills, strokes, highlight color, and width when targeting and editing specific areas.

Fills, strokes, highlight color, and width are adjusted in the Live Paint Selection Options dialog box for targeting and editing specific areas.

- Select Fills: selects faces in Live Paint groups.
- Select Strokes: selects edges in Live Paint groups.
- Color: controls the highlight color. Choose a color from the menu, or use the paint swatch to define a custom color.
- Width: sets the thickness of the selection highlight.
