# Save object selections

Save object selections that you have edited or changed so you can reuse them later.

You can select multiple objects and keep that selection available for later by using Save Selection, which helps move the objects together or adjust their appearance. Unlike grouping, Save Selection records the selected objects without moving them onto one layer.

With the Selection tool, choose one or more objects in the artwork.

Select Select > Save Selection.

Tip

Another route is the Layers panel > Save Selection > Save Selection command.

In the Save Selection dialog box, type a selection name and select OK.

Use the name field in the Save Selection dialog box to store the selection under that name.

Enter a name in the Save Selection dialog box name field to save the selection.

After a selection is saved, its name appears in the Select menu and in the Layers panel Save Selection menu. Choose that selection name from either menu, and the canvas shows the saved selection as selected.
