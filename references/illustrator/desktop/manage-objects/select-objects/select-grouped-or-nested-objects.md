# Select grouped or nested objects

The Layers panel can target objects that sit inside groups or nested structures.

Select Window > Layers.

In the Layers panel, scroll through and expand layers or groups until you find the object to select. Selection color boxes are displayed beside selected items in the panel.

Choose the Indicates Selected Art (click to select art) column located between the target button and the scroll bar.

To select or deselect several objects, Shift-click in the Indicates Selected Art (click to select art) column.

Click the Indicates Selected Art (click to select art) column beside a layer or group name to choose all artwork contained there.

After choosing an object in the Layers panel, use Select > Object > All on Same Layers to select every object on that layer.
