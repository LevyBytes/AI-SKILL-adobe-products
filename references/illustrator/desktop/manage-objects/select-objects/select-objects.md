## Select objects

Select objects in Adobe Illustrator when you need to move, edit, or transform them efficiently.

Illustrator provides several selection tools for selecting and transforming artwork. The Selection tool handles complete objects, the Direct Selection tool changes object parts, and the Group Selection tool targets objects inside groups, including a single item within a grouped design.
