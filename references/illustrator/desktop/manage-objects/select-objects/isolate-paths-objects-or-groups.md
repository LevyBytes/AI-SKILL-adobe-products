# Isolate paths, objects, or groups

Using the Selection tool, double-click the path, group, or object.

For a path inside a group, choose it with the Direct Selection tool, then use Isolate Selected Object in the Control panel.

To leave isolation mode, press Esc or choose Exit Isolation Mode in the Control panel.

After isolation mode closes, new or replacement art is placed at the same location as the original isolated artwork.
