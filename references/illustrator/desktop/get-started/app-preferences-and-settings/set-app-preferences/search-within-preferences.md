# Search within Preferences

Use the Search Preferences bar to quickly find any setting.

Open the Preferences dialog box with Cmd + K (macOS) or Ctrl + K (Windows).

The Preferences dialog box opens with Search Preferences already active, so you can start typing immediately. Return to it anytime with Cmd + F (macOS) or Ctrl + F (Windows).

Press Enter or choose See all results to show every match. Select an option to jump to its matching section.

Use the Search Preferences bar to filter settings by keyword and quickly find what you need.
