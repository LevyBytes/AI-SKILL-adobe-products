# Use Microsoft surface dial in Illustrator

Learn how Microsoft Surface Dial in Illustrator can support efficient design workflows.

Adobe Illustrator supports Microsoft Surface Dial on Windows 10 Anniversary edition and later, and directly on Surface Studio. Use Surface Dial to adjust settings and parameters in Illustrator documents.

While using Illustrator, long-press Surface Dial to open these options:

- Undo or Redo: Runs Undo and Redo operations.

- Arrange: Moves the selected object one object forward or backward in a stack.

- Zoom: Zoom in or out while working on artwork.

- Artboard navigation: Move from one document artboard to another.

- Tools: Select one of these Illustrator tools: Rotate, Scale, Paintbrush, Blob Brush, and Eraser.

  - Select the Rotate tool, place a pivot point on the selected object, then rotate Surface Dial to transform the selected artwork around that pivot point in five-degree intervals.
  - Select the Scale tool, then rotate Surface Dial to uniformly scale the selected artwork in 5 % intervals.
  - Select the Paintbrush tool or the Blob Brush tool, then rotate Surface Dial to change brush size.
  - Select the Eraser tool, then rotate Surface Dial to change the eraser diameter.
