# Discover panel overview

Learn how the Discover panel in Illustrator helps you reach contextual help, search for tools, and apply quick actions that improve your workflow.

The Discover panel offers context-aware help and learning resources so you can locate articles quickly and work efficiently with Illustrator tools.

The panel recommends ways to work faster and more efficiently with Illustrator tools. Those recommendations include tips and tutorials for speeding up multi-step workflows.

The Discover panel home screen has three useful sections that point you to key learning resources:

- Suggestions help you begin your learning journey. Suggestions become more personalized from your search history and chosen content.
- Browse helps you locate in-app tutorials and information about current Illustrator features.
- Resource Links provide useful Adobe resources for continued learning and plugin-based Illustrator feature expansion.
