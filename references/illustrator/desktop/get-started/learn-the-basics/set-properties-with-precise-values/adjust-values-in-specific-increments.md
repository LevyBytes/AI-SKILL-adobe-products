# Adjust values in specific increments

On the canvas, select the object to modify.

Click the value field in the panel or dialog box where the adjustment should happen.

Use the Up or Down arrow key to raise or lower the current value by 1 unit.

Hold Shift while using the arrow keys for larger changes, typically 10 units.

Hold Cmd (macOS) or Ctrl (Windows) while using the arrow keys for fractional changes. Some fields may not support this, especially fields with percentage values.

Press Enter to apply the value.
