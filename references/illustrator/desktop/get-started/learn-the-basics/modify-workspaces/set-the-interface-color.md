# Set the interface color

Select Edit > Settings > User Interface (Win) or Illustrator > Settings > User Interface (macOS).

For Brightness, choose Dark, Medium Dark, Medium Light, or Light.

Use the brightness icon to change the interface.

Select Canvas Color from these options:

- Match Brightness: Sets the canvas color to the selected brightness level. This is the default setting.
- White: Sets the canvas color to white.

For Share Button, choose Match Brightness or White to change the share button.
