# Common categories of controls

The Properties panel always includes controls for the selected object and for general document settings.

- Transformation and Appearance controls: Basic settings such as width, height, fill, stroke, and opacity
- Dynamic controls: Additional options based on the selected object, such as text or image tools.
- Quick actions: Shortcuts for common tasks tied to your selection

Note

To open more expandable controls, select the ellipses in an area's lower-right corner or select an underlined option.
