# Additional controls

Depending on the selected tools or objects, the Properties panel can show these additional contextual controls:

| Control | Behavior |
| --- | --- |
| Width Profile dropdown menu | Shown after you select the Width tool or a path with variable width. Choose a width to update the width profile. |
| Corners dropdown menu | Shown after you choose the Direct Selection tool in the toolbar and select an object corner. Choose a value to adjust the corner curve. |
| Blend Options button | Shown in Quick Actions after you select one blend object and choose the Blend tool. Use it to change blend settings, including spacing and orientation. |
| Merge Live Paint button | Shown in Quick Actions after you select two or more groups that contain multiple live paint objects. Use it to combine the selected live objects. |
| Variable Font icon | Shown in the Character section after you select a text object using a variable font. Use it to adjust the selected font's weight and optical size. |
| Delete icon | Shown in the Appearance section after one effect is applied to an object. Use it to remove that effect.<br><br>When multiple effects exist, select the icon to open the Appearance panel, then remove the effects there. |
