# Explore tool tips and tool techniques

Use optimized search results to find important information quickly. Find tools quickly and learn how to use them with Tool Tips and Techniques.

- Tool Tip: Gives a basic idea of how to use the tool.
- Tool Technique: Provides step-by-step instructions for using the tool.

Hover over any toolbar tool to see a short tool description.

Select Learn more on the tool tip to open detailed step-by-step instructions for using the tool.
