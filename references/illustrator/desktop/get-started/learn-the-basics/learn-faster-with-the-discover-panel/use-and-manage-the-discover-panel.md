# Use and manage the Discover panel

To open the discover panel, use the search icon in Illustrator's upper-right corner, select Help > Illustrator Help, or press F1.

Type a keyword in the Discover panel search bar to find tools, in-app tutorials, and articles that help build your skills. When you choose a tool or menu item from the results, a blue coach mark shows its location in the interface.

Return to the previous page with the arrow icon, or start over by selecting the home icon in the Discover panel.

To configure preferences for the Discover panel, use the settings icon in the panel's lower-right corner, then select Preferences to access these options:

- Location coach marks: Select to control whether interface tool locations are shown by the panel.
- Quick select: Select to decide whether pressing Enter selects the top result or shows all results.

To close the Discover panel, press Esc.
