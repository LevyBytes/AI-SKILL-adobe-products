# Apply Quick Actions

Quick actions are available inside the Discover panel so a workflow can be completed with one click. Select Browse> Quick actions to see the list of quick actions that can be applied to objects.

When an object is selected, quick action changes apply automatically. Select the icon to learn more about Quick actions.

In the Discover panel, select Browse > Quick Actions to view available quick actions.

Select the object in your document that should receive the quick action.

Choose a list item, such as Convert sketch into vector or Neon glow text.

Select Apply so the effect is applied instantly to the selected object.

Explore these Illustrator quick actions:

- Convert sketch into vector: Turns hand-drawn sketches into vector artwork.
- Recolor: Adds a random color theme to your artwork.
- Retro text: Applies a vintage look to text.
- Neon glow text: Applies a neon glow effect to text.
- Old school: Applies an old-school look to text
