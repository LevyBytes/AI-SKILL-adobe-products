# Configure Discover panel preferences

In the lower-right corner of the Discover panel, select the settings icon.

From the menu, select Preferences.

Enable or disable Location coach marks to control whether interface tool locations are shown by the panel.

Enable or disable Quick select to decide whether Enter chooses the top result or displays all results.

Click outside the preferences panel to close it and apply changes.

The Discover panel provides instant access to the information and tools you need, helping you work efficiently at the moment you need them.
