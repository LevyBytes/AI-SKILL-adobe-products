# Application Frame

The Application Frame places all workspace components inside one integrated window so the app can be handled as a single unit.

On macOS, the Application Frame can be turned on or off. When it is on, moving or resizing the app or any component makes all components respond to one another so they do not overlap. Panels remain visible when you switch apps or accidentally click outside the app. You can also place each app side by side on one monitor or across multiple monitors. If you prefer the traditional free-form macOS interface, turn off the Application Frame from the Window menu.
