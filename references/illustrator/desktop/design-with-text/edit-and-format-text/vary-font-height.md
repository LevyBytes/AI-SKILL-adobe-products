# Vary font height

Use font-height controls when text height needs to support the layout or visual emphasis.

Select a text frame using the Selection tool.

Open Window > Type > Character.

Choose More options > Show Font Height Options from the Character panel.

Choose the needed height metric from the Set font height reference dropdown in the Character panel:

- Em Box: bases font size on the font's complete em square.
- Cap Height: bases font size on the height of uppercase letters.
- x-Height: bases font size on the height of lowercase characters.
- ICF Box: bases font size on the ICF (Ideographic Character Face) Box, which is commonly used in CJK fonts.

The Character panel can vary font height, style, or size.
