# Change the font style

With the Selection tool, double-click the text on the canvas to activate the Type tool.

Inside the text box, highlight the text segment that should receive the style.

In the Character panel, use the Set the font Style dropdown menu to choose a style, or apply a shortcut:

- Bold: Shift + Command + B (macOS) or Shift + Ctrl + B (Windows).
- Italic: Shift + Command + I (macOS) or Shift + Ctrl + I (Windows).
- Underline: Shift + Command + U (macOS) or Shift + Ctrl + U (Windows).

Note

Bold and italic formatting cannot be used unless the chosen font family includes those styles and the styles are installed on your system.

When a requested regular style is unavailable in that font family, Illustrator switches to the nearest installed style, usually Myriad Pro Regular.
