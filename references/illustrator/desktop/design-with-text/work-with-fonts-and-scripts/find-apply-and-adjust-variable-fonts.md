# Find, apply, and adjust variable fonts

Find and apply variable fonts in Adobe Illustrator, then adjust their properties.

Select the text with the Selection tool.

Choose Window > Type > Character. In the Character panel, open the Set the font family dropdown to show the font menu.

Limit the list to variable fonts by choosing Filter fonts by classification, then Variable in the Font Technology section.

Apply one of the variable fonts to the text.

After closing the font menu, choose Variable Font in the Character panel.

Change properties such as Weight, Width, and Slant.
