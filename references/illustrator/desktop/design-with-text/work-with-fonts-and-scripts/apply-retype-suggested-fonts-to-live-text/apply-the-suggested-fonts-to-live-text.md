# Apply the suggested fonts to live text

Use the Selection tool to select the text on the canvas.

Open Retype with Window > Retype.

Run Match Font to scan for matching fonts, then choose Exit.

Note

Choose Add to favourites from the Font Matches list to mark fonts as favorites.

From the last scan list or the Show Favorite Fonts filter, choose a suggested font.

Apply the suggested font for your live text from the last scan or from favorite fonts.
