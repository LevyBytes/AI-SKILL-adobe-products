# Discover more fonts from Adobe Fonts

Use the font browser's Discover More tab to find and add fonts from Adobe Fonts:

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Open Discover More. Browse Explore Styles, Trending fonts, New releases, or Browse Adobe Fonts. Apply filters or quick filters if you need a shorter list.

For adding a font to the account, point to the font name, choose the Add icon, then wait for the control to change to Remove.
