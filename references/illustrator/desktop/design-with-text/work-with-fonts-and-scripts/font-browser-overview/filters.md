# Filters

Filters, including quick filters, reduce the visible font list by selected criteria. Your Fonts and Discover More use the same filter set. If you filter in one tab and move to the other, the chosen filters stay on and the list updates with matching fonts from that tab. Restarting Illustrator clears the filters automatically.

Multiple filters can be active together. In that state, they intersect rather than act separately, so only fonts common to both criteria appear.
