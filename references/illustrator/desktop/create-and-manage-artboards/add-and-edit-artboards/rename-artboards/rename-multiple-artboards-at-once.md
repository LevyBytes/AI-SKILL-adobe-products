# Rename multiple artboards at once

Choose the artboards that need new names.

Right-click or control-click (macOS) the selected artboard, then choose Rename....

Use clear, distinctive artboard names so tracking and collaboration stay straightforward.

Distinct, easy-to-read names make shared work and later tracking easier.

In the Artboard Options dialog box, choose a naming pattern and enter a name in the Name field. Illustrator applies that entry to every selected artboard with numbering appended: abc-1, abc-2, abc-3, and so on.

Choose OK to apply the changes.

Note

Illustrator now shows artboard names and numbers above the outside of artboards, which helps keep a multi-artboard workspace organized.
