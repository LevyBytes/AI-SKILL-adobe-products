# Scale artwork with artboard

Scale the artwork together with its artboard when a proportional design resize should keep alignment intact.

Use Window > Properties to display the Properties panel.

With the Selection tool, choose the artboard, then use Edit Artboards in the Properties panel.

Turn on Scale artwork with Artboard in the Properties panel so artwork and artboard scale at the same percentage.

Use Scale artwork with Artboard in the Properties panel whenever both the artwork and the artboard must scale proportionally.

Enable Scale artwork with Artboard, then drag the artboard bounding box to resize the artwork and artboard together in proportion.

Tip

The Control panel also includes the Scale Artwork with Artboard option.
