# Rearrange selected artboards

Activate the Artboard tool, then choose the artboards to rearrange.

Use Window > Artboards to display the Artboards panel.

In the Artboards panel, choose Rearrange.

Use the Rearrange dialog box to organize selected artboards into an efficient canvas layout.

The Rearrange dialog box can place selected artboards into a more efficient canvas layout.

Choose Layout and Layout order in the Rearrange dialog box.

Enter the number of Columns or Rows required by the selected layout.

Set the horizontal or vertical Spacing between artboards.

Choose OK, then click anywhere on the canvas to apply the new arrangement.

Note

Enable Move artwork with Artboard when the artwork should move together with the artboard.
