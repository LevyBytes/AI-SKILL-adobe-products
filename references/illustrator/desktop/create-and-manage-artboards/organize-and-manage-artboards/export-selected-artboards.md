# Export selected artboards

Export selected artboards quickly from either the canvas or the Artboards panel to keep the workflow direct.

Choose artboards on the canvas or in the Artboards panel when you only need those artboards exported. This avoids typing artboard numbers or lists during export.

Use the Artboard tool in the toolbar, or press Shift + O.

Choose one or more artboards on the canvas.

With those artboards selected, right-click or control-click (macOS), then choose Export.

In the Export for Screens dialog box, set format, location, and any other options, then select Export Artboard. Each selected artboard is exported as a separate file.

Export selected artboards directly from the artboard context menu.

Tip

Before exporting, check the Artboards panel to confirm which artboards are selected.
