# Edit a graphic

Use one of these methods in the Libraries panel:

- Double-click a graphic
- Open the context menu for a graphic, then choose Edit.

When the component opens in an Illustrator document window, edit it.

Save the document.

Illustrator updates the graphic in the Creative Cloud Library and refreshes the thumbnail automatically. For an asset made in Illustrator CC 2015 or later, the item is also a Linked Asset, and Adobe CreativeSync keeps it current everywhere it is used.
