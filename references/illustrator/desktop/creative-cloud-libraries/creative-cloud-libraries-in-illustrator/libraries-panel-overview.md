# Libraries panel overview

Illustrator shows Creative Cloud Libraries inside the Libraries panel. When you make libraries on multiple computers while signed in with the same Adobe ID, those libraries and their assets appear in the Libraries panel on each computer.

Open the Creative Cloud Library panel (Libraries panel) by choosing Window > Libraries. In the Libraries panel, you can:

- Create a Creative Cloud Library, inspect it, rename it, remove it, and use it.
- Add items to a Creative Cloud Library, remove items from it, revise them, and change their names.
- Sort Creative Cloud Library items and change how those items are viewed.
