# File formats for exporting artwork

| Format | Description |
| --- | --- |
| AutoCAD Drawing and AutoCAD Interchange File (DWG and DXF) | - AutoCAD Drawing is AutoCAD's standard save format for vector graphics created there.<br>- AutoCAD Interchange File supports drawing exchange by exporting AutoCAD drawings for other applications or importing drawings from them. Details: AutoCAD export options. |
| BMP | A standard Windows image format. Details: BMP export options. |
| Enhanced Metafile (EMF) | Windows applications commonly use EMF as an interchange format for vector graphics data. During EMF export, Illustrator may rasterize some vector data. |
| JPEG (Joint Photographic Experts Group) | JPEG is a standard format for web image display. It is commonly used for saving photographs. The format preserves image color data and lowers size by throwing away selected information. Details: JPEG export options. |
| Macintosh PICT | macOS graphics and page-layout applications use PICT to transfer images between applications. PICT compresses images especially well when they contain large areas of solid color. |
| Photoshop (PSD) | The standard Photoshop format. If Photoshop format cannot carry some artwork data, Illustrator maintains the visible result by merging document layers or rasterizing artwork. Details: Photoshop export options. |
| PNG (Portable Network Graphics) | Used for lossless compression and web display. In grayscale and RGB images, PNG can keep transparent areas. Details: PNG export options. |
| Targa (TGA) | Built for systems using the Truevision video board. Details: Targa export options. |
| Text Format (TXT) | Writes illustration text to a text file. Details: Export text. |
| SVG (Scalable Vector Graphics) | As an XML-based format, SVG offers many benefits to developers and users. Details: SVG export options. |
| TIFF (Tagged-Image File Format) | TIFF supports file exchange across applications and computer platforms. As a flexible bitmap image format, it is supported by most paint, image-editing, and page-layout applications. Many desktop scanners can create TIFF files. Details: TIFF export options. |
| Windows Metafile (WMF) | For 16-bit Windows applications, WMF serves as an intermediate exchange format. Almost all Windows drawing and layout programs support WMF format. Its vector graphics support is limited, so use EMF format instead of WMF format wherever possible. |
| WebP | WebP is a modern image format that provides strong lossless and lossy compression for images on the web. It keeps image quality high while reducing file sizes, helping pages load faster and improving user experiences across the internet. Details: WebP export options. |
| PDF | Portable Document Format (PDF) is universal: it preserves source-document fonts, images, and layout from many applications and platforms. Adobe PDF is the standard for secure, reliable distribution and exchange of electronic documents and forms worldwide. For more information, see Create Adobe PDF files. |

Note

- Multiple-artboard export is available only for these formats: SWF, JPEG, PSD, PNG, and TIFF.
- Save For Web & Devices can also create PNG or JPEG files from an image.
