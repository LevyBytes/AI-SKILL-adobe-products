# PNG export options

For PNG file export, these options are available:

| Option | Description |
| --- | --- |
| Resolution | Sets the resolution of the rasterized image. Higher values improve image quality while increasing file size. |
| Anti-aliasing | Smooths jagged artwork edges through supersampling. Turning this option off helps keep line-art edges hard after rasterization. |
| Interlaced | Shows low-resolution image versions as the file downloads in a browser. |
| Background Color | Sets the fill color used for transparent areas.<br><br>- Transparent preserves transparency.<br>- White fills transparency with white.<br>- Black fills transparency with black. |
