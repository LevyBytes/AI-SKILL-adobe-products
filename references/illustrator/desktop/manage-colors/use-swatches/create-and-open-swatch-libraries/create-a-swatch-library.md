# Create a Swatch Library

Choose Window > Swatches.

In the Swatches panel, create or edit the swatches that should be part of the Swatch library.

In the Swatches panel, choose More options, then choose any required option:

- Save Swatch Library as ASE: writes the colors to an ASE file that other Adobe applications, such as Photoshop, can use.
- Swatch Library as AI: creates an Illustrator file for the color set, and Illustrator opens that file directly.

Use New Swatch Group to create another swatch group.

Enter a file name, then choose Save.
