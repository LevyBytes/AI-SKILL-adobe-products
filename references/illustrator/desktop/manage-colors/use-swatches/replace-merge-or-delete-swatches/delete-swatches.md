# Delete swatches

Choose Windows > Swatches.

Select one or more swatches, then choose Delete Swatch.

Choose Delete Swatch to remove unused colors and keep the swatch panel cleaner.

In the Adobe Illustrator confirmation dialog box, choose Yes.

Note

If you delete a spot-color swatch, a global process-color swatch, a pattern, or a gradient that contains a spot or global process color, Illustrator converts every object using those colors to the matching non-global process color.
