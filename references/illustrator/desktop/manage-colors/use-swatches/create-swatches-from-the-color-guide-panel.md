# Create swatches from the Color Guide panel

Create and save swatches from the Color Guide panel in Adobe Illustrator when you want harmonious color sets available again.

Choose Window > Color Guide.

Pick a color from the Swatches panel or from artwork, making it the base color.

In the Color Guide panel, choose colors from the Harmony Rules dropdown menu.

Select the colors you want in the Color Guide panel.

At the bottom of the Color Guide panel, choose the Save swatch group to Swatch panel icon.

Move the chosen colors from the Color Guide panel into the Swatches panel.
