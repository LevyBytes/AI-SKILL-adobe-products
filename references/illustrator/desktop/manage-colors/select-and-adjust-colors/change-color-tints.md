# Change color tints

Change color tints in Illustrator when you need lighter or stronger versions of a color.

Select Window > Swatches.

In the Swatches panel, choose a Global Process Color or Spot Color, or choose an object that already uses one.

Select Window > Color.

In the Color panel, change the color’s intensity by dragging the T slider left or right, or by typing a value in the text box.

Note

When the T slider is missing, confirm that a Global Process Color or Spot Color is selected. If it still does not appear, open the More options dropdown list in the Color panel and select Show Options.

Tint values run from 0% to 100%; lower values produce a lighter Tint.

Use the Color panel to make Fill and Stroke active.

Use the Color panel to make Fill and Stroke active. Tip

To store the Tint as a swatch, drag the color into the Swatches panel or select New Swatch in the Swatches panel. Illustrator names the new swatch from the original color plus the Tint value. For example, if the base color is Sky Blue and the Tint is 50%, the swatch name becomes Sky Blue 50%.
