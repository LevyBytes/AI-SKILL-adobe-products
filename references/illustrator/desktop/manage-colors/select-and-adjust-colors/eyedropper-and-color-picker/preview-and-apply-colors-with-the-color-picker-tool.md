# Preview and apply colors with the Color Picker tool

In the Tools panel, Double-Click Fill or Stroke to open the Color Picker dialog box.

Choose a color using one of these methods:

- Drag the circular color marker inside the Select Color column.
- Move the color slider, or choose a color in the Color spectrum bar.
- Type HSB, RGB, or CMYK values in the text boxes.
- From Color Swatches, choose one item in the Color Swatches column.
- With the Color Picker tool selected, move the cursor over the area to sample. A Sampling Ring appears with a color preview. Its upper half indicates the color that will be sampled, and its lower half shows the most recent sampled color. Alternatively, hold Shift with the Eyedropper tool to display the Sampling Ring.

Choose OK to apply the selected color to the object.
