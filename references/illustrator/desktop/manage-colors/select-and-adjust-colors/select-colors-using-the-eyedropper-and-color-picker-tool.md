# Select colors using the Eyedropper and Color Picker tool

The Eyedropper and Color Picker tools in Illustrator support selecting, changing, and sampling colors.

Illustrator lets you apply colors with both the Eyedropper and Color Picker tools. Use the Eyedropper tool to pick a color already present in artwork or an image, such as one sampled from a logo or photo. Use the Color Picker tool for visual color choice by entering exact values or choosing from the spectrum, sliders, or swatches.

Review how the Eyedropper tool and Color Picker tool work in Adobe Illustrator, including the main differences between them.
