# Use recent colors across your document

When colors are applied, Illustrator records them as Recent Colors. They appear in the Swatches panel and the Color panel. Illustrator keeps up to 30 recent colors, and they remain available across documents until newer colors replace them.

Apply a color to any object with the Swatches panel or Color Picker. After that application, the color shows in the Recent Colors section.

Recently used colors are available from the Color panel for maintaining visual consistency across artwork.

The Color panel provides direct access to recently used colors so artwork can stay visually consistent.

To save a recent color for later use, drag it into the Swatches panel.

To hide Recent Colors, turn off Show Recent Colors in the More Options menu.
