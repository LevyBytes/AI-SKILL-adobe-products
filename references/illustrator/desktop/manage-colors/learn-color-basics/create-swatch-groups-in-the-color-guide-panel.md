# Create swatch groups in the Color Guide panel

Use the Color Guide panel to build, save, and organize a swatch group made from related color variations.

Choose Window > Color Guide to open the Color Guide panel.

In the Color Guide panel, choose a color variation, then choose the Set base color to the current color icon Set Base Color To The Current Color icon.

Choose a rule from the Harmony Rules dropdown menu.

To restrict the group to a swatch library, choose Limits the swatch group to colors in a swatch library, then choose a library from the list.

To store the color group or a single color in the Swatches panel, choose Save swatch group to Swatch panel icon.

For the new swatch group's name, use these steps:

- Select the group in the Swatches panel, open the Swatches panel menu, and choose Swatch Group Options.
- When the Swatch Group Options dialog box opens, type a name in the Name field and choose OK.

Enter the swatch group's name in the Swatch Group Options dialog.

Use the Swatch Group Options dialog to supply the swatch group name.

To apply a swatch-group color to artwork, select the artwork and choose any color in the Color Guide panel.
