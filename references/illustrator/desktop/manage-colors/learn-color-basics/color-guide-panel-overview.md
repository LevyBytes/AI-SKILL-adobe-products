# Color Guide panel overview

The Color Guide panel helps set up color variations, swatch groups, and harmony rules for Illustrator artwork.

Open Color Guide by choosing Window > Color Guide.

For faster artwork color decisions, use the Color Guide panel to adjust harmony rules and organize color groups.

A. Harmony Rules menu and active color group B. Set as base color C. Active Colors D. Color variations E. Limit the swatch group to colors in a swatch library F. Edit Colors or Edit or Apply Colors depending on selection G. Save swatch group to Swatch panel H. Color variations I. Color Guide panel menu

Artwork color choices can be refined in the Color Guide panel by working with harmony rules and color groups.
