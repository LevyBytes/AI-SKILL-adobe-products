# Modify colors in swatch groups

Change colors inside swatch groups when a design needs consistent color treatment.

Select the object, then choose Edit > Edit Colors > Recolor Artwork.

In the Recolor tab, choose Advanced Options.

In the Recolor Artwork dialog box, choose the Edit tab.

Choose a swatch group from the Swatch Groups list.

To choose colors in the Color Picker dialog box, use these steps:

- On the color wheel, double-click the color handle.
- On the color bar, right-click the color, then choose Color Picker.

In the Color Picker dialog box, choose a new color, then select OK.

Use the Color Picker dialog box when individual colors in the selected swatch group need editing.

Edit individual colors in the selected swatch group with the Color Picker dialog box.

To keep the edited colors as a new group, enter a new name in the name box, then select New Swatch Group icon.

To update the original color group with the edits, select Save changes to swatch group icon.
