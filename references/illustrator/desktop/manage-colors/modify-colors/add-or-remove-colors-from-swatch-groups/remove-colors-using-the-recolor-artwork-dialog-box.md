# Remove colors using the Recolor Artwork dialog box

Select the artwork with the Selection tool.

Open Edit > Edit Colors > Recolor Artwork. In the Recolor panel, choose Advanced Options to display the Recolor Artwork dialog box.

In the Recolor Artwork dialog box, open the Edit tab.

Right-click the color marker or color bar, then choose Remove color from the dropdown list.

Note

As another method, choose the Remove Color tool, then select the color to remove.

The base color marker cannot be removed.

In the Recolor Artwork dialog box, choose Reset to restore the artwork to its original colors.

Use Reset in the Recolor Artwork dialog box when the artwork should return to its original colors.

Choose OK.
