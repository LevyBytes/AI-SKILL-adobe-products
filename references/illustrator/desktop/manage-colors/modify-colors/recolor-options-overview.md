# Recolor options overview

Review the controls used to modify and refine an artwork color scheme.

Select the artwork, then choose Edit > Edit Colors > Recolor Artwork to display the Recolor dialog box.

The Recolor dialog lets you revise the artwork's color palette.

A. Undo Changes B. Redo Changes C. Change color order randomly D. Change saturation and brightness randomly E. Link Unlink harmony colors F. Adjust brightness or saturation G. New swatch group H. Show saturation and hue on color wheel I. Show brightness and hue on color wheel

Use the Recolor dialog when the artwork palette needs to be changed.
