# Edit swatch groups using the color wheel

Use the color wheel to adjust swatch groups and make color changes easier inside your artwork.

Select the object, then open Edit > Edit Colors > Recolor Artwork.

On the Recolor tab, choose Advanced Options.

In the Recolor Artwork dialog box, open the Edit tab.

To change the swatch group, use one of these actions:

- Choose Display smooth color wheel icon or Display segmented color wheel icon, then drag the color handle to change its color.
- Choose Display color bars to show the color group only as separate solid bars.

Enable Recolor Art to preview every color in your artwork.

Turn on Recolor Art so the artwork previews all colors.

To adjust the colors, use these actions:

- Change hue, saturation, and brightness by dragging the H, S, and B sliders.
- On the color wheel or the color handle, right-click and choose Add New Color.
- Right-click the color in the color wheel, then choose Remove Color.

Use Show saturation and hue on wheel when you need to switch the wheel display between hue and saturation views.

Right-click a color in the color wheel or bars, then choose Set as Base Color.

You can also choose a color in the Active Colors box, then choose Set current colors as the base colors.

To restrict colors to a swatch library, choose Limit the swatch group to colors in a swatch library.

To store the edited colors as a new group, enter a new name in the name box, then choose New Swatch Group icon.

To apply the edits to the original color group, choose Save changes to swatch group icon.

To check whether colors are in gamut or web safe, choose each color marker and use Out Of Gamut Warning or Out Of Web Color Warning as needed.
