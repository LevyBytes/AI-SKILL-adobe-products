# Use Adobe Stock templates in Illustrator

In Illustrator, select File > New.

In the New Document dialog box, choose a category tab such as Recent, Saved, Mobile, Web, Print, Branding, Social, Art & Illustration, Film & Video, or Free Templates.

In the Templates section, select a template.

Select See Preview to preview the template you plan to license.

Select Download to license the template. The Adobe Stock dialog box appears and handles processing and licensing for the free template.

After the template downloads, select Open to work on it.

Tip

If fonts are missing, the Missing Fonts dialog box appears. Select Add Fonts or Replace Fonts to open the template.

Use these steps to access downloaded templates:

- Select Window > Libraries.
- Select Stock Templates in the Libraries panel.
- Right-click the template, and then select Open new document to open and work with the template.

Note

Illustrator templates use the .ait extension but open as .ai files. Changes made to the .ai version do not affect the original .ait template.

Visit Adobe Stock Help for licensing details and related guidelines.
