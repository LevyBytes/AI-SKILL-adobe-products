# Create and save custom document presets

Learn how to create, customize, and save document presets for later use.

Customize settings in the Preset Details pane before opening a document from a preset.

Open the New Document window with File > New.

In the Preset Details pane, enter a document name.

Specify these options for the selected preset:

- Width and Height: Specify the artboard size. Select the unit from the dropdown menu.
- Orientation: Set the document page orientation: Landscape or Portrait.
- Artboard: Set the number of artboards in the document.
- Bleed: Set the bleed position along each artboard side. Use the link icon when different side values are needed.
- Color Mode: Set a document color mode: RGB Color or CMYK Color.
- Raster Effects: Set the raster effects resolution for the document.
  - Default option shows artwork created in the document in full-color vector view. Curves remain smooth when you zoom in or out.
  - Pixel option shows artwork with a rasterized appearance.
  - Overprint option shows an ink preview that approximates blending, transparency, and overprinting in color-separated output.

Select More Settings for additional preset changes.

Use the View menu to change Preview mode while working on the file.

Select the download icon, then choose Save Preset for future use.

Select Create to open a document using the preset settings.

To use saved presets, select the Saved category tab in the New Document window.
