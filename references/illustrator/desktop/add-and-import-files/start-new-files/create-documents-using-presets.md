# Create documents using presets

Learn how Adobe Illustrator presets help you start a new project quickly.

In the New Document dialog box, select one category tab:

Recent, Saved, Mobile, Web, Print, Branding, Social, Art & Illustration, Film & Video, or Free Templates.

Select a preset.

Use View more in the dialog's upper-right corner to show more presets.

Select Create to open a document based on the preset.

To change preset settings, modify options in the Preset Details pane.
