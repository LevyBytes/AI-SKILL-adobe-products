# Import Adobe PDF files

Import PDF files into Adobe Illustrator and use the PDF import options when opening multipage files.

In Illustrator, use File > Open.

From the Open dialog box, choose one or more PDF files, then select Open. For a PDF with multiple pages, Illustrator displays the PDF Import Options dialog box.

In the PDF Import Options dialog box, choose one of these options:

- To open the page currently shown in the preview, select Previewed Page.
- To open chosen pages, select Range and enter the page numbers.
- To open every page, select All.

Adjust the PDF Import Options dialog box settings to control how Illustrator brings in PDF pages.

A. Preview PDF pages B. Specify page number to view thumbnail C. Import a range of pages D. Import all pages E. Import as a linked file

Customize the settings in the PDF Import Options dialog box to import PDF pages.

To open PDF pages as links, select Import PDF pages as links for optimal performance.

Select OK to import the PDF file.

Caution

When the PDF is larger than Illustrator's canvas, Illustrator shows this error: Could not open the complete PDF file because it exceeds the available drawing area. Select OK to continue.
