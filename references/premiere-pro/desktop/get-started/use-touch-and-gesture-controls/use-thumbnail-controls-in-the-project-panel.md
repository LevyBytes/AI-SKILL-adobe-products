# Use thumbnail controls in the Project panel

Use Premiere touch or mouse thumbnail controls to quickly play, scrub, and mark clips.

With thumbnail controls in Icon View, Premiere lets you scrub, play, and mark clips directly, without opening menus. The workflow supports touch gestures and mouse operation, reduces repeated navigation, and helps rough cuts and assembly edits move faster while keeping the controls visual.

Launch Adobe Premiere and open the project.

Select the Project panel (Shift+1).

Select Icon View.

Choose a clip so the thumbnail controls are shown.

Use buttons or drag on the thumbnail to scrub, play, or mark clips directly. During touch use, thumbnail controls appear automatically.

In the Project panel's Settings menu, select Thumbnail controls for all pointing devices when working with a mouse.

Tap the playback and scrub controls on the thumbnail to use touch gestures with the clip.
