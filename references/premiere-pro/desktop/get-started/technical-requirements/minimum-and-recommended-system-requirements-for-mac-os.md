| Requirement type | Minimum specification | Recommended specification |
| --- | --- | --- |
| Processor | - Intel® 6th Generation or newer CPU<br>- Advanced Vector Extensions 2 (AVX2) Support required<br><br>Note: Mac Pro 2013 and earlier systems cannot install Premiere 24.x versions. | Apple silicon M1 or newer |
| Operating system | macOS Monterey (version 12)<br><br>Compatibility note: macOS 11.0 (Big Sur) support has ended. Mac users on Apple silicon and Intel-based Mac can continue with version 24.0. | macOS Monterey (version 12) or later |
| Memory | 8 GB RAM | Apple silicon: 16 GB unified memory |
| GPU | Apple Silicon: 8 GB unified memory<br><br>Intel: 2 GB GPU memory | Apple silicon: 16 GB unified memory |
| Storage | - 8 GB of available hard disk space, with additional free space needed during installation. | Display | 1920x1080 pixels | - 1920x1080 pixels or greater<br>- DisplayHDR 1000 for HDR workflows |
| Network storage connection | 1 Gigabit Ethernet (HD only) | 10 Gigabit Ethernet for 4K shared network workflow |
