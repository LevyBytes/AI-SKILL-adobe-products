# Tools panel in Premiere

Options in the Tools panel in Premiere and how those features help editing workflows.

Choosing a tool changes the pointer shape to match that tool. For example, choosing the Razor tool and placing the pointer over a clip in the Timeline panel changes the pointer to a razor icon.

The Selection icon can also update to show the task currently in progress.

Note

Sometimes a modifier key, such as Shift, changes how a tool behaves while you use it, and the icon changes to match. Choose tools in the Tools panel, or trigger them with a keyboard shortcut.

By default, Premiere uses the Selection tool. It handles tasks that do not require a specialized tool. If Premiere is not behaving as expected, confirm that the Selection tool is active.

The Tools panel can also be resized and set to a vertical or horizontal orientation.
