# Align and reset clips to grid in Freeform View in Project panel

Align clips to the grid or reset them to the grid in Freeform View for a more organized Project panel layout.

For grid alignment, select multiple clips, right-click, and choose Align to Grid.

For all clips, right-click an empty area in Freeform View and choose Align to Grid.

Tip

Before aligning clips to grid, consider saving the current arrangement as a new layout so the earlier layout can be restored.

Aligning clips to a grid in Freeform View helps keep layouts organized.

Freeform View layouts stay tidier when clips are aligned to a grid.

To reset clips to a grid, select all clips or multiple clips, right-click, and choose Reset to Grid. Pick a sorting criteria, and Premiere aligns the selected clips in the specified order.

From the Reset to Grid menu, choose the sorting criterion that should be used for the selected clips in Freeform View.

Use a sorting criterion in the Reset to Grid menu to reset selected Freeform View clips.
