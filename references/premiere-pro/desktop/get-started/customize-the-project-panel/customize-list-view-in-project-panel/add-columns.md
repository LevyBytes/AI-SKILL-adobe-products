# Add columns

Choose Metadata Display from the Project panel menu.

Select Add Property.

Enter a column name.

Choose a type:

- Integer: permits whole-number values only.
- Real: permits decimal values up to two digits.
- Text: accepts any text that you enter.
- Boolean: provides a Boolean-term option for the column.

Custom data columns can be created to organize project details.

Use custom data columns when project details need additional organization.

Select OK, then select OK again.
