# Customize List View in Project panel

Customize List View in the Project panel to organize, sort, and filter media with metadata.

List View shows all media files and can sort the list by different criteria so files are easier to find or group.

Choose Preview Area from the Project panel menu to hide or show the thumbnail viewer and clip information.

Hover over a clip with the mouse to display a tooltip containing clip information.

Hover over a column with the mouse to display a tooltip containing column information.
