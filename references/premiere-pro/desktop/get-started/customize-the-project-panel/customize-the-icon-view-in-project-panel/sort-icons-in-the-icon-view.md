# Sort icons in the Icon View

To sort icons in the Icon View, select the Sort Icons icon in the Project panel. The sort menu includes:

- User Order: arrange icons yourself by dragging them into the preferred order.
- List View Sort: reuse the sorting choice from List View; for example, a Media Duration sort in List View also applies after switching to the Icon View.
- Metadata Sort: order icons by common metadata fields such as Name, Label, or Media Type, with ascending or descending direction available.

Icon View clips can be sorted by manual placement, List View sorting, or metadata values such as name and media type.

Manual order, list-view criteria, and metadata fields such as name and media type are all supported for sorting clips in Icon View.
