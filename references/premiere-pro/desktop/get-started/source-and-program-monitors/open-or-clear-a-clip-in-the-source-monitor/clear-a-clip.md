# Clear a clip

In the Source Monitor, open the Source menu and select Close to clear one clip, or Close All to clear every clip.

Note

Another way to close all clips and the Source Monitor itself is to click the Close button in the Source Monitor tab.


In the Source menu of the Source Monitor, choose Close to clear one clip or Close All to clear every clip.

Note

Clicking the Close button in the Source Monitor tab can also close every clip along with the Source Monitor itself.
