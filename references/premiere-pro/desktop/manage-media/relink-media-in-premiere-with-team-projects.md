# Relink media in Premiere with Team Projects

When media goes missing, use the same relink workflow (Link Media) in Team Projects that you use in a Premiere project. This workflow changes only the local system and is not handled as a project edit, so no collaborator sharing is required.

Use File menu > Link Media to reconnect Team Projects media in Premiere.

Relink Team Projects media from Premiere by choosing Link Media from the File menu.

Behind the scenes, it behaves like the Media Management dialog because Team Projects creates the required media mapping without changing media paths on other collaborators' machines. Because relinking stays local, one collaborator cannot accidentally alter media mappings for everyone else.
