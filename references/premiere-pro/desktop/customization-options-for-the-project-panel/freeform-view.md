# Freeform View

Freeform View provides a visual workspace for arranging assets and building storyboards from media.

In the Project panel, Freeform View lets you place media clip thumbnails freely by dragging them into position.

Freeform View also supports thumbnail-based free placement for media clips there.

A. The project is editable B. List View C. Icon View D. Freeform View E. Zoom slider F. Automate to Sequence G. New Bin H. New Item I. Clear

Switch views by selecting the List View icon or the Icon View icon in the panel. You can also use View > List or View > Icon from the Project panel menu.
