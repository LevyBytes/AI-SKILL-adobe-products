# Icon View

Icon View lets you inspect a clip in the Project panel with hover scrub. Move the cursor across an icon to play through the clip backward or forward as the mouse is dragged.

Use Icon View in the Project panel when thumbnails are helpful for browsing, previewing, and organizing media clips visually.

Icon View also supports visual media review and organization through thumbnail-based clip browsing there.
