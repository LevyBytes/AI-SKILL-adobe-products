# Creating Team Projects in Premiere from a blank start

Watch this video for an overview of collaboration with Team Projects in Adobe Premiere.

A collaborative project can be created in three ways:

- Start directly from the After Effects or Premiere start screen.
- Inside the application, choose File > New > Team Project.
- To convert an existing Premiere project, choose Edit > Team Project > Convert Project to Team Project.

Provide a name (required) and a description (optional). Collaborators can be invited during project creation or afterward.

To invite collaborators now, select Edit. In the Edit Collaborators dialog, type the name or email address for each user you want to collaborate with.

Open the Edit Collaborators dialog to add people to the project.

The Edit Collaborators dialog is where new collaborators are invited.

When users have been invited before, a drop-down list suggests the most recently invited people. The dialog also shows matching search results while you type.

Groups in your Active Directory can also be invited to collaborate on the project. Changes made later to that invited group, such as adding or deleting team members, are not reflected automatically; send another invite when the invite list needs to be refreshed.

To remove a selection, select the X in the name tag. An email address can also be typed directly.

Suggestions come from collaborators invited previously or, for enterprises syncing Active Directory with the Adobe Admin console, from the organizational address book.

Note

Enterprise users should make sure their IT administrator has enabled the Team Projects service for the account. Explore ways to manage your organization setup.

After all collaborators have been added, select Invite.

The invitation appears for collaborators in the Creative Cloud Desktop app and in Premiere or After Effects.
