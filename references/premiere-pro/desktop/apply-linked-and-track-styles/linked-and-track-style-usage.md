# Apply created styles and use style usage indicators in Adobe Premiere.

After creating a style, link it to additional titles or caption tracks. Follow this sequence for text layers and captions.

Choose the text layer or caption you want to edit.

In the Properties panel, open the Linked style section and select the desired style from the dropdown list.

Apply text and caption styles, or switch between them.

Switch among text and caption styles, or apply one to the selection.

The text layer or caption track is now linked to the style.

Tip

Style usage indicators show how many graphics or caption tracks use a given style. Selecting the indicator jumps to the beginning of the caption track or graphic where the style is applied. Each dropdown item also shows metadata for identification:

- Captions metadata: sequence name: caption track: caption track name
- Graphics metadata: sequence name: video track: timecode: number of layers in graphic using style
