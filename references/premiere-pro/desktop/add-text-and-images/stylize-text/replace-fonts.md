# Replace fonts

Replace project fonts in Adobe Premiere with Graphics and Titles > Replace Fonts in Project.

Project fonts can be swapped in one pass, so every matching text layer updates together instead of being changed layer by layer. If a graphic contains several text layers and the design needs a different typeface, Replace Fonts in Projects applies the replacement across those layers at the same time.

Before you begin:

Open the project and make sure text has already been added. When the replacement is a new font, confirm that it is installed on the computer or activated through Adobe Fonts.

Choose Graphic and Titles > Replace Fonts in Project.

The Replace Fonts in Projects dialog shows the fonts currently used by the project.

Choose the font that needs to be replaced.

In the Replacement Font dropdown menu, choose the font that should take its place.

Use the Replacement Font dropdown menu to look up the font that will replace the current one.

Select OK.
