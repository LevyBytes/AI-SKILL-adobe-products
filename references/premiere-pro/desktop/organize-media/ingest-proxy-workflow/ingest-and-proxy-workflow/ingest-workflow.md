# Ingest workflow

In Premiere, ingesting means copying and transcoding media files from source storage, such as memory cards, external hard drives, or network drives, into the project's local storage or a designated media cache location.

The ingest workflow is mainly used to prepare optimized, consistent media files for editing. It preserves the original files while also creating working copies that can be better suited to the edit system.

During ingest, you can transcode media into a more editable format, such as a lower-resolution format or a codec the computer can process more easily. You can also consolidate media by copying it to the project's local storage so all required files are together. Premiere verifies the copy so corruption or data loss is not introduced while media is transferred.
