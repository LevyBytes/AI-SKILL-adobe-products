# Proxy workflow

Proxy workflows in Premiere create lightweight, lower-resolution versions of high-resolution video files. These lower-resolution versions, called proxy files, are edited in place of the original high-res files.

The proxy workflow is intended to make editing faster and smoother, particularly with high-resolution footage or media that places heavy demands on computer hardware.

When using proxies, you create proxy files first, edit with those proxies, and later switch to full resolution media when the full resolution files are needed.

You can also use proxies made outside Premiere, such as proxies generated by cameras or other applications. In that case, attach the proxies to the full resolution media files before starting the edit.
