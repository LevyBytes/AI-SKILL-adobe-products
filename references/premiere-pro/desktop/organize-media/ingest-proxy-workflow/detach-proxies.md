# Detach proxies

Detach proxies when you are ready to return to the original high-resolution media.

Detaching proxies in Adobe Premiere removes the relationship between proxy files and the high-resolution media clips in the project. This is useful when proxies are no longer needed or when you want to resume working from the original high-resolution media.

View the files in the Project panel and identify the files with attached proxies.

To add a proxy status column in the Project panel, open the context menu for a List view column header. Search for proxy-related fields and enable the fields you want displayed.

Add a proxy status column in the Project panel from a List view column header.

Use a List view column header to add proxy status information to the Project panel.

In the Project panel, open the clip's context menu and select Proxy > Detach Proxy.

Detach proxies from one selected clip or from multiple selected clips in one action.

Select one or more clips and detach their proxies together. Note

Premiere removes the proxy attachment, but it does not remove proxy files from disk so files or proxies referenced by another project are not accidentally deleted. You can choose whether to keep or delete those proxy files.
