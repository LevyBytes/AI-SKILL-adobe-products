# Search for similar visuals using media intelligence

Learn how AI-powered media intelligence in Adobe Premiere can help locate alternate takes or related visuals.

With media intelligence in Premiere on desktop, a selected frame can be used to find visually similar shots without manually scrubbing through footage. This makes alternate takes and related visuals faster to locate, improving editing speed and reducing search time.

Right-click the frame to match in the Program Monitor.

From the context menu, select Search Similar Frames.

After choosing Search for similar frame from the Program Monitor, review visually similar shots in the Search panel.

The Search panel can show visually similar shots after Search for similar frame is chosen from the Program Monitor.

The Search panel opens with clips whose visuals match the selected frame.
