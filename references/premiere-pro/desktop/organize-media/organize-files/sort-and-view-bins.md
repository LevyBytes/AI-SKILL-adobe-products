# Sort and view bins

Organize and locate media more efficiently from the Project panel in Adobe Premiere.

Bin sorting and view choices in Adobe Premiere help keep large projects with extensive media easier to manage. Display choices such as list view or icon view, metadata sorting, and label-based grouping can make assets faster to find and can speed up editing work.

Project panel bins can be sorted and viewed in these ways:

- To show bins as a vertically scrollable list, select List View.

- To show bins as horizontal folders, select Icon View.

- To use a layout that fits your workflow, select Freeform View.
