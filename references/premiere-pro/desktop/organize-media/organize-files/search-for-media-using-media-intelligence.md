# Search for media using media intelligence

Find shots with AI-powered media intelligence through visual descriptions, spoken words, or embedded metadata such as shoot date, location, and camera type.

Note

At this time, visual search accepts only English language searches.

Import footage into a new project, or open a project you already have.

Allow the background analysis to complete. The upper-right corner of the main window shows progress, and Window > Progress opens the Progress panel.

In the main Premiere app, use the upper-right magnifying glass icon to open the Search panel.

Search footage by imagery, spoken words, or content carrying embedded metadata.

A. Media Search B. Search window

Use imagery, spoken words, or embedded metadata to search for visuals in footage.

Enter keywords in the search field. Detailed scene descriptions tend to produce stronger visual search matches.

The Search panel presents Visuals, Audio, Text, and Metadata results at the same time. Use the dropdown menu when you want to show only one result type.

Visual search is not the same as conventional search in other apps or search engines. English searches that appear close in meaning can still return different matches.

Tip

- Multi-word searches will often work better than single words.
- Include descriptive details, such as lighting or camera angle.
- Try alternate phrasing, as though explaining the scene to someone who has never viewed it.
- The AI model evaluates a smaller version of the footage as a sequence of still images, so tiny details and fast motion may be less reliably detected.
