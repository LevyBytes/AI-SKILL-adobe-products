# Accepting or rejecting Team Projects collaboration invitations

After being invited to collaborate on Team Projects, an invitation notification appears in the Creative Cloud desktop application and in Premiere or After Effects. Use either of these approaches to accept or reject it.

In the Creative Cloud Desktop application, select Accept.

Invitation notifications appear in the Creative Cloud desktop app.

The Creative Cloud desktop app can show collaboration invitations.

Alternatively, choose File > Open Team Project > Invites, review pending invitations, and then accept or reject them.

Pending collaboration invitations appear on the Invites tab in Manage Team Projects.

Use the Invites tab in Manage Team Projects to accept or reject pending invitations.
