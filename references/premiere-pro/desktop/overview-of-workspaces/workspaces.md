# Workspaces

In Premiere, panels are arranged into layouts that can be stored as workspaces. Premiere includes 16 default workspaces, each shaped around post-production work such as color, audio, or graphics. Common general workspaces include:

- Essentials: suited to a single-monitor setup, with the primary editing controls kept close at hand.
- Vertical: built for vertical video workflows. Source Monitor and Program Monitor can be switched within the same panel.
- Learning: set up for using in-app tutorials and learning content while editing.
- Assembly: uses a large Project panel so rough cuts can be built quickly.
- Captions and Graphics: useful when the edit involves captions or graphics.
- Review: choose this workspace when Frame.io is part of your review process.
- Production: designed for team collaboration inside a Production.
