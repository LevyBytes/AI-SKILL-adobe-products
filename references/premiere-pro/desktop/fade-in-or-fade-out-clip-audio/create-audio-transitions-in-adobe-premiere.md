# Create audio transitions in Adobe Premiere.

Make the audio track taller in the Timeline panel.

With visual fade handles visible on audio clips, drag to create custom fades.

Create audio fades by dragging interactive fade handles on clip edges.

The same interactive fade handles on clip edges create audio fades. Tip

Hold the option key while dragging to constrain movement to one axis: up-down for slope or left-right for duration.

Hold the shift key to affect only one side of the crossfade effect. Hold the option key and drag left or right to change the curve or duration.
