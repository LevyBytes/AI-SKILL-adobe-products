# Redefine created styles in Adobe Premiere.

After a style is linked to the relevant caption track or text layers, all instances can be updated together.

Select one text layer or a caption block from the captions track that you want to edit.

Make the changes you want, then use the Redefine Style button beside the Linked style or Track style dropdown to replace the style with those changes.

Use the Redefine Style button to ripple style changes across all instances.

Send style changes to every instance with the Redefine Style button.

Every text layer or caption using that style changes to the new style at once.

For captions, the Redefine Style dialog asks whether changes should be saved to all captions in the track, which leaves the style itself unchanged, or whether the style should be overwritten with the changes.
