# Create a title for video projects in Adobe Premiere.

Before you begin:

Make sure the sequence is prepared and that you know the timeline location where the title should appear.

Select the Type tool from the toolbar.

Enter the title text directly in the Program Monitor.

With the title still visible, right-click it in the Program Monitor, then select Edit Properties from the context menu to open the Properties panel. From there, customize the title with fonts, colors, and styling options.

Use the Properties panel to customize title fonts, colors, outlines, and alignment.

For the title, adjust fonts, colors, outlines, and alignment through the Properties panel.

Change fonts, colors, and styles to shape the text's appearance and produce the effect you want.
