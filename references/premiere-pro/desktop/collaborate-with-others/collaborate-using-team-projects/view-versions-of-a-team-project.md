# View versions of a Team Project

Whenever a collaborator publishes a change, Team Project stores a new project version. You can view earlier published versions or return to one of them. Versions provide a durable history of published Team Project changes.

Several entry points let you view versions for a Team Project.

- Select the Team Project name in the Premiere header bar, then choose Auto Save History from the dropdown menu.

Use the Team Project name in the Premiere header bar, then choose Auto Save History so the Media Browser panel lists saved versions.

- Select Edit > Team Project > Browse Versions, then browse in the Media Browser to reach the project's current version.

Use Browse Versions from the Edit menu to inspect auto-saved Team Project versions in the Media Browser panel.

- Right-click Team Project in the Media Browser panel, then select Team Project Versions to open a dialog box listing all versions and related information, including earlier shared comments.

Use Team Project Versions to open a dialog box listing the auto-saved versions for the Team Project.

- Select the Team Project in the Media Browser panel, then move the vertical slider under the Versions tab to browse versions visually.

Use the entries under the Versions tab in the Media Browser panel to move through auto-saved versions.
