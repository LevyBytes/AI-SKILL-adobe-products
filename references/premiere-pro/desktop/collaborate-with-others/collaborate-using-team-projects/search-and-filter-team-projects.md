# Search and filter Team Projects

Searching and filtering Team Projects while many projects are available.

When the list of Team Projects grows, use search and filtering in the Manage Team Project dialog box to reduce scanning time and find the project you need faster.

Choose File > Open Team Project.

In the Manage Team Project dialog, type in the search box to look up a project. This helps when many Team Projects are listed and manually checking the whole list would be inefficient.

Use the Manage Team Projects dialog to search and filter Team Projects.
