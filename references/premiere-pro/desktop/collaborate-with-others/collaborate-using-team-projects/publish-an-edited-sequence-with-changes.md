# Publish an edited sequence with changes

Publishing an edited sequence in Premiere so teammates receive your changes.

During Team Projects collaboration in Premiere, publishing an edited sequence shares your work with the rest of the team. Publishing releases the sequence lock, after which collaborators can see the edits and update their projects with those changes.

You may include a comment for collaborators during publishing.

While a sequence is being edited, the Project panel shows that editing is underway and the Publish button becomes available.

When editing is finished, select Publish.

Select the Publish button to share the edited sequence and its changes with other team members.

Add comments when you want collaborators to understand what changed.

Add comments to tell other collaborators about your changes.

Select Publish to finish publishing.

Note

Saving the project does not send it to collaborators. To distribute edits, select the Publish button.

Key points to remember:

- While you edit a sequence, other collaborators are locked out of editing it; they can still view it.
- Saving your project does not publish changes.
- Use the Publish button when edits need to be shared.
- Publishing unlocks the sequence and lets other collaborators update to view your changes.
- The Project and Timeline panels use visual cues to show when another user has updated a sequence.
