# Transcription settings in Adobe Premiere

Speech to Text accuracy, language support, and speaker labeling can be improved by customizing transcription settings.

Premiere uses these settings to control speech-to-text processing and visual analysis for media.

Visual analysis and speech-to-text processing are controlled through these media settings.

Configure Visual Analysis and Transcription options in Media Analysis & Transcription preferences to tailor media processing.

| UI option | Function |
| --- | --- |
| Cache analysis results for re-use | Chooses the cache location for media analysis and transcription results:<br><br>- Next to the media as a sidecar file: stores media analysis and transcriptions in sidecar files beside the media. Importing the media into another project on any computer will not require analysis again.<br>- In the Media Cache: stores media analysis and transcriptions in the Media Cache folder. Importing the media into another project on the computer will not require analysis again.<br>- Do not cache: keeps media analysis and transcriptions only in the project file. Importing the media into another project on any computer will require analysis again. |
| Analyze all imported media to visually search your projects | Turns on automatic visual analysis for each clip imported into the project. |
| Automatically transcribe clips | Creates speech-to-text transcripts automatically for imported clips or for all clips in a sequence. |
| Transcription preferences | Chooses which media should be transcribed:<br><br>- Select Auto-transcribe all imported clips to transcribe all current and newly imported clips with the chosen language.<br>- Select Auto-transcribe only clips in sequence to transcribe every clip in the sequence with the chosen language. |
| Speaker Labeling | Chooses how speakers are labeled:<br><br>- Select Yes, separate speakers to label individual speakers separately.<br>- Select No, don't separate speakers to turn off speaker separation and treat all dialogue as one speaker. |
| Enable language auto-detection | Detects the spoken language in a clip automatically during transcription. When enabled, the default language is used for locale selection or as a fallback if detection fails. |
| Default language | Chooses the language used to transcribe clips. |
