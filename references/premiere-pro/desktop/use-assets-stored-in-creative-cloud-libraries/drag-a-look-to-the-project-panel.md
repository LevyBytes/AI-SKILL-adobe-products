# Drag a Look to the Project panel

- Dragging a Look from the Libraries panel onto a project item in the Project panel applies a Lumetri Color effect to the master clip.
- When the track item is visible in the Source Monitor, Premiere renders the effect.
- The master clip gets a Lumetri Color effect in the Effect Controls panel.

Note

- For a Look with the .cube filename extension, Premiere sets the Input LUT field in the Basic Correction section of the Lumetri Color panel to that Look.
- For a Look with the .look filename extension, Premiere sets the Look field in the Creative section of the Lumetri Color panel to that Look.
