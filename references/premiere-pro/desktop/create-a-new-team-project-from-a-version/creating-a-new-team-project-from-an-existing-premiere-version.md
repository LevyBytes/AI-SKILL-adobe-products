# Creating a new Team Project from an existing Premiere version.

Before you begin

Verify that the Team Projects and their existing versions are available to you.

Select Edit > Team Project > Browse Versions, then browse in the Media Browser to reach the project's current version.

Move the version vertical slider in the Media Browser to reach the current project version while reviewing the full version set.

In the Media Browser panel, right-click the Team Project under Creative Cloud, then select New Team Project from Version to make Team Projects from an earlier shared version.

Use New Team Project from Version when making a new Team Projects based on a previous version.

The New Team Project dialog box opens and applies these details:

- The current Team Project name is pre-populated and a copy suffix is appended.
- The collaborator list from the original Team Project is queued.

Select OK to create a Team Project.

Premiere creates a new Team Project from the chosen version, and the new project appears in your Team Projects list.

Creating a Team Project from a version lets you begin from a fresh copy while keeping the work completed up to that version. This supports alternate edits or a new project phase. The new Team Project is separate from the original, so changes to it do not alter the source project.
