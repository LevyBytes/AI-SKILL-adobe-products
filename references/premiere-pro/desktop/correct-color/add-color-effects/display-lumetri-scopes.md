# Display Lumetri Scopes

Monitor Adobe Premiere color and exposure with visual scopes so brightness, contrast, and tone can be balanced.

Lumetri Scopes provides resizable built-in video scopes: Vectorscopes, Histogram, Parade, and Waveform. Use these scopes to judge clips and guide color correction.

Open Lumetri Scopes from Window > Lumetri Scopes in the menu bar.

To show one scope, right-click inside the Lumetri Scopes panel and choose a scope from the drop-down. The selected scope appears in the panel.

For scope configuration, use the dropdown menu in the lower-right corner and choose the mode that matches the footage: 8-bit, 10-bit, float, or HDR. With HDR footage, the scale adjusts automatically to show 0-10000 Nits.

Enable the Clamp Signal checkbox to clip any signal above 100 IRE or below 0 IRE. This clamping changes only the scope display and does not change the timeline or exported media.

Tip

To see all scopes at once, right-click the Lumetri Scopes panel and choose Presets > All Scopes RGB or All Scopes YUV/YC.
