# Adjust the Project panel position to better fit the workspace.

When a Project panel is opened for a particular project and binned into a workspace for the first time, Premiere chooses its default location using these rules:

- If any project panels are already open in the workspace, Premiere places the new Project panel in the same workspace frame as those project panels.
- If no project panels are open, Premiere uses the workspace frame that contains the Media Browser.
- If no Media Browser panels are open, Premiere uses the workspace frame that contains the Effects panel.
- If the Effects Panel isn't open, Premiere uses the workspace frame that contains the Effect Controls panel.

The Project panel location can still be adjusted to match the workflow.

Move the Project panel by selecting it and dragging it to the desired location.

The Project panel can also be docked or left floating. Use the docking and undocking panel guidance to learn how to dock, group, or float panels.

Drag and drop the selected Project panel into the preferred position in the workflow.

Move the selected Project panel by dragging and dropping it where the workflow needs it. Tip

When a Project panel is docked by itself without any other tabs beside it, Premiere might not always retain its position. Include another panel, such as the Media Browser, with it to avoid this issue.
