# Object mask

| Objective | Tool(s) | Modifier | Action | Conditions |
| --- | --- | --- | --- | --- |
| Create Object Mask | Object Mask Tool | Command + Option + O | Click<br><br>hover and click | Clip must be selected |
| Change Object Mask Tool (Rectangle or Lasso) |  | Command + Option + L | Dropdown to change | Object Mask tool must be selected, or an object mask must be selected |
| Change Object Mask Mode (Add to/Subtract from mask) |  | Option/Alt | Click on "+" or "-" to toggle | Object Mask tool must be selected, or an object mask must be selected |
| Turn off Object Mask hover |  |  | Dropdown to select | Object Mask tool must be selected, or an object mask must be selected |
