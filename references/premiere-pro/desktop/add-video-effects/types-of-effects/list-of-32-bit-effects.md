# List of 32-bit effects

Use the 32-bit Color icon in the Effects panel to locate and apply 32-bit effects.

Premiere provides these 32-bit effects for smoother gradients and higher color detail.

- ASC CDL
- Auto Reframe
- Gaussian Blur
- Horizontal Flip
- Luma Key
- Lumetri Color
- ProcAmp
- SDR Conform
- Tracke Matte Key
- Video Limiter
