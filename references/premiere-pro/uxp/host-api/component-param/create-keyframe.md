# createKeyframe

25.0

_Keyframe_

Creates and returns a keyframe initialized from the ComponentParam's type plus the supplied value. Throws when the supplied value is incompatible with the component param type.

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| inValue | _number_ or _string_ or _boolean_ or [_PointF_](../point-f/reference-index.md) or [_Color_](../color/reference-index.md) | Input may be number, string, boolean, PointF, or Color depending on effect param type. |
