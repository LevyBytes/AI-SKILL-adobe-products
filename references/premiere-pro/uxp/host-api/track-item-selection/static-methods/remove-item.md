# removeItem

25.0

_boolean_

Removes one track item out of the selection.

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| trackItem | [_VideoClipTrackItem_](../../video-clip-track-item/reference-index.md) or [_AudioClipTrackItem_](../../audio-clip-track-item/reference-index.md) | trackItem targeted for removal from the selection |
