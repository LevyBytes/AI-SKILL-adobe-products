# `LaunchProcessPermission`

`LaunchProcessPermission` lists schemes and extensions that the plugin may launch. For browser launching, include schemes such as `"http"` and `"https"`.

```json
{
  "schemes": ["http", "https"],
  "extensions": ["pdf"]
}
```
