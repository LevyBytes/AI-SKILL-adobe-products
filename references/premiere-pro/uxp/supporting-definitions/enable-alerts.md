# `enableAlerts`

| Name | Type | Required | Default |
| --- | --- | --- | --- |
| `enableAlerts` | `boolean` | optional | `false` |

`enableAlerts` allows simple dialogs through [`alert()`](../dom/window/alert.md), [`prompt()`](../dom/window/prompt.md), and [`confirm()`](../dom/window/confirm.md).
