# Q: Can Spectrum UXP Widgets and SWC work with frameworks such as React?

A: Yes. The components do not depend on a particular framework and can be used with any framework that works with UXP. Some frameworks have their own patterns for web components, so review the framework documentation. See [Use with React](../using-with-react.md).

Work on a React wrapper for SWC is underway, and a sample plugin is expected to be added soon.
