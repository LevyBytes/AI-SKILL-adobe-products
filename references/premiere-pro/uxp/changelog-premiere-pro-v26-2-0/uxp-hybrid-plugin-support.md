# UXP Hybrid Plugin Support

Premiere Pro now has official support for [UXP Hybrid Plugins](../hybrid-plugins.md). Developers can pair a UXP plugin with native C++ libraries, so performance-sensitive work such as audio/video processing, ML inference, or native SDK integration can run as compiled code beside the JavaScript UI and logic.

- **UXP Hybrid Plugin SDK**: available from the [Adobe Developer Console](https://developer.adobe.com/console). The package includes C++ headers, helper utilities, and native-addon templates for `.uxpaddon` output.
- **New documentation**: start with [Overview](../hybrid-plugins/reference-index.md), then continue to [Building Hybrid Plugins](../building-hybrid-plugins/reference-index.md) and [FAQ](../hybrid-plugins-faq/reference-index.md).
