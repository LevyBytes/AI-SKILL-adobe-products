# Create a new plugin

The [Getting Started guide](../building-your-first-uxp-plugin/scaffold-your-plugin.md) covers scaffolding; to make a new plugin, choose **Create Plugin** and pick one of the templates supplied by UDT. More detail is available in [this section](../building-your-first-uxp-plugin/scaffold-your-plugin.md).
