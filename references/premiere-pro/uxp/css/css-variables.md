# CSS Variables

**Since** UXP v3.0

UXP can use CSS Variables, also called Custom Properties. Pair that with [prefers-color-scheme](media-queries/prefers-color-scheme/reference-index.md), and a plugin can build custom themes that follow the selected theme inside the app hosting the plugin.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/--\*](https://developer.mozilla.org/en-US/docs/Web/CSS/--*)
