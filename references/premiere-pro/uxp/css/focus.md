# :focus

**Since** UXP v3.0

Applies to the selected element while it has focus; in practice, keyboard focus is currently on that element.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:focus](https://developer.mozilla.org/en-US/docs/Web/CSS/:focus)

**Example:** 

```css
input:focus {
  border: 1px solid red;
}
```
