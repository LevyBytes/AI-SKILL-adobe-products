# :nth-last-child

**Since** UXP v3.0

Counts from the end and selects only the Nth child; expressions, `even`, and `odd` are accepted.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-last-child](https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-last-child)

**Example:**

```css
.row:nth-last-child(even) {
  background-color: #E8E8E8;
  /* color even rows (from the end) */
}
```
