# Releases

The SDK has its own versioning, separate from the host application. It carries a UXP version label because Hybrid plugins are meant to be app-independent. New SDK announcements appear in the [Changelog](../changelog-premiere-pro-v26-2-0/reference-index.md). Updating to a newer SDK means recompiling and republishing the plugin, while plugins built on older SDKs remain forward-compatible with newer host application versions.
