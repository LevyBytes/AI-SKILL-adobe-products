# Working with JavaScript Frameworks

Vanilla JavaScript, HTML, and CSS are enough for many plugins, but modern JavaScript frameworks can help when an application becomes more complex. Popular frameworks such as **React**, **Vue**, and **Svelte** are compatible with [UXP plugin bundler workflows](plugin-workflows/working-with-bundlers.md).

Frameworks can simplify complex state, reusable components, and maintainable code. They also add setup requirements, including Node.js, package managers, and build tools.

If React is already familiar, or if the plugin is expected to become complex, read the [React Spectrum integration guide](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro/55a2a2d3eb0c4a2453eb9d38e8d067f851fa6b6e/src/pages/uxp-api/reference-spectrum/spectrum-uxp-widgets/using-with-react.md). A common path is to use [SWC React wrappers](https://opensource.adobe.com/spectrum-web-components/using-swc-react/).
