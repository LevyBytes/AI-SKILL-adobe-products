# Hybrid Plugin SDK

When a [Hybrid Plugin](hybrid-plugins/reference-index.md) needs both JavaScript and native C++ code, obtain the **UXP Hybrid Plugin SDK** through the [Adobe Developer Console](https://developer.adobe.com/console). The SDK provides:

- C++ header files plus API definitions used to build native addons (`.uxpaddon` files)
- `template-dev`, a starter project that includes source code
- `template-plugin`, pre-compiled and ready to load directly into UDT

For build steps and configuration information, see the [Hybrid Plugins guide](hybrid-plugins.md).
