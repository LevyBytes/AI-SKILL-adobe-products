# GenerativeUpscaleOptions

Options accepted by [Document.generativeUpscale](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/document.md#generativeupscale)().
Model support varies; currently Firefly supports only scale.

| Name | Type | Min Version | Description |
| --- | --- | --- | --- |
| scale | _number_ | 27.2 | Upscale factor. Must be 2 or 4. |
