# bottom

**Since** UXP v2.0

Sets the bottom offset for an element positioned with relative or absolute layout.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/bottom](https://developer.mozilla.org/en/docs/Web/CSS/bottom)

**Example**:

```css
.someElement {
  bottom: 0;
  position: absolute;
}
```
