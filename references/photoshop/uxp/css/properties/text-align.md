# text-align

**Since** UXP v3.0

Within the parent container, text alignment can be set with `left`, `center`, or `right`.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/text-align](https://developer.mozilla.org/en/docs/Web/CSS/text-align).

**Example**

```css
.someElement {
  font-style: left;
}
```
