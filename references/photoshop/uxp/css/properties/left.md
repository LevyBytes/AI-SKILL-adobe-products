# left

**Since** UXP v2.0

For an element using relative or absolute positioning, this property assigns the left offset.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/left](https://developer.mozilla.org/en/docs/Web/CSS/left)

**Example**:

```css
.someElement {
  left: 0;
  position: absolute;
}
```
