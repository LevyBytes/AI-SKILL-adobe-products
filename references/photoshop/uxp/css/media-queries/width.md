# width

**Since** UXP v4.1

Use this media query to limit CSS rules by the plugin dialog or panel width that satisfies the criteria you set.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/@media/width](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/width)

**Example** 

```css
@media (max-width: 700px) {
  .someElement {
    background-color: red;
  }
}
```
