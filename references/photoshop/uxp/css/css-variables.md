# CSS Variables

**Since** UXP v3.0

UXP can use CSS Variables, also called Custom Properties. Together with the [prefers-color-scheme](media-queries/prefers-color-scheme/reference-index.md) media query, this support makes custom themes straightforward when they need to respond to the host application's selected theme.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/--\*](https://developer.mozilla.org/en-US/docs/Web/CSS/--*)
