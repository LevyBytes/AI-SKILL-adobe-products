# Installation Problems

During the Photoshop UXP beta period, developers had several possible methods for placing plugins where Photoshop could locate them. Today, the approved route for adding a development plugin to Photoshop is the [UXP Developer Tool](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/guides/devtool/index.md).
