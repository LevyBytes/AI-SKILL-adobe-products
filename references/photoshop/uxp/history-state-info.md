# HistoryStateInfo

Options for the history state created by [Document.suspendHistory](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/document.md#suspendhistory).

| Name | Type | Min Version | Description |
| --- | --- | --- | --- |
| documentID | _number_ | 23.0 | ID of the target document whose history is suspended with suspendHistory. |
| name | _string_ | 23.0 | History state name displayed in the History panel. |
