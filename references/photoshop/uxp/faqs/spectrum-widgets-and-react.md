# Q: Can Spectrum UXP Widgets and SWC work with frameworks such as React?

A: Yes. The components are framework agnostic, so any framework that runs with UXP can use them. Some frameworks still have their own Web Component idioms, so check that framework's docs. For React-specific guidance, see [Use with React](../using-with-react.md).

SWC React wrapper work is also underway. A sample plugin is planned soon.
