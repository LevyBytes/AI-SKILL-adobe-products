# TrimType

23.0

Pixel type trimmed around an image; pass to [Document.trim](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/document.md#trim).

| Name | Description |
| --- | --- |
| BOTTOMRIGHT | Uses the color of the pixel in the image's bottom right corner. |
| TOPLEFT | Uses the color of the pixel in the image's top left right corner. |
| TRANSPARENT | Uses pixels that are fully transparent. |
