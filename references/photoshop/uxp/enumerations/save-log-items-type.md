# SaveLogItemsType

24.0

Choices for recording history items.
Supply to [PreferencesHistory.saveLogItems](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/preferences/preferenceshistory.md#savelogitems)

| Name | Description |
| --- | --- |
| LOGFILE | Writes the history log to a text file. |
| LOGFILEANDMETADATA | Puts the history log into both a text file and file metadata. |
| METADATA | Puts the history log into file metadata. |
