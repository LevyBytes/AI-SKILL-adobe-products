# removeAllFromActiveGroup

24.1

_void_

Removes every [CountItem](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/countitem.md) object from the active group in this collection.

```javascript
app.activeDocument.countItems.removeAllFromActiveGroup();
```
