# New

- [GUID](../user-info/user-id.md) uniquely identifies a Creative Cloud User (Currently Supported only in `Photoshop`).
- Multipart `FormData` can now be used with [Request](../network-and-data/request/reference-index.md) and [Response](../network-and-data/response/reference-index.md) for `fetch`.
- [FormData](../network-and-data/form-data/reference-index.md) adds these APIs
  - delete()
  - get()
  - getAll()
  - has()
  - keys()
  - set()
  - values()
