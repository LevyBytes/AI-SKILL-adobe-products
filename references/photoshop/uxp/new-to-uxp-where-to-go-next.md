# New to UXP? Where to Go Next

Which starting point fits depends on your current background.

- Already built UXP plugins for other Adobe applications (e.g., XD), and only need Photoshop-specific differences? [start here](uxp-in-photoshop-vs-other-creative-cloud-applications/reference-index.md).
- Built Photoshop extensions with CEP (Common Extensibility Platform) but not UXP? [start here](uxp-for-cep-developers-goodbye-cep/reference-index.md).
- New to both UXP and CEP, but you have written Adobe ExtendScript scripts? [start here](uxp-for-extend-script-developers/reference-index.md).
- Know some HTML, CSS, and JavaScript, but have not scripted Photoshop with those technologies? [start here](uxp-for-web-developers.md).
- Completely new to the whole area? [Start here to begin your awesome journey](uxp-for-newbies.md).
