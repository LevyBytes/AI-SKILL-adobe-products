# apiVersion

Photoshop 2021's UXP implementation has a key isolation gap: plugins do not have a protected execution mechanism. Any plugin can change Photoshop whenever it runs, even while another plugin is also active. Photoshop 2022 addresses that gap with a modal JavaScript scope. At a given moment, only one plugin may occupy that modal JavaScript scope. See [executeAsModal](../executeasmodal.md) for details. Because modal scope limits the timing of Photoshop modifications, it cannot behave like the original model. Those timing limits are what prevent two plugins from changing Photoshop simultaneously. To give developers a migration path, Photoshop 2022 accepts both the original JavaScript mode and the newer modal JavaScript mode. A plugin declares its choice through the apiVersion field.
- `apiVersion` of **1** means the plugin targets the original Photoshop 2021 behavior.
- `apiVersion` of **2** means the plugin targets the newer modal JavaScript paradigm. After apiVersion = 2 was introduced, the original implementation became formally deprecated, and a later major Photoshop release will remove apiVersion 1 support. Several newer capabilities are therefore limited to apiVersion 2 plugins. Those apiVersion 2-only capabilities include the new DOM v2 and suspend/resume support for multiple history states at once.
