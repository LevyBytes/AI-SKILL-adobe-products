# enableMenuRecording

[Menu items](../code-samples/menu-items.md) (`type: "command"`) declared in the manifest's `entrypoints` appear in that plugin's submenu beneath the top-level Plugins menu. To let Actions record those menu items as steps, set `enableMenuRecording` to `true`. After that setting is enabled, a recorded Action shows the item as "Plugin Menu Command" together with the menu item's label.
