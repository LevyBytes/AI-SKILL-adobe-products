# Uxpscripting

> Adobe Photoshop reference. Original prose; identifiers preserved verbatim.

Photoshop 23.5 added support for running standalone JavaScript files through UXP. The [general documention of UXP Scripting](how-uxp-scripting-works/reference-index.md) explains that Photoshop treats .psjs as the JavaScript file extension for code executed by UXP.
