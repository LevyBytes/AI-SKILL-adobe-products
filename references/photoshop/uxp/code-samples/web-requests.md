# Web Requests

UXP exposes a global `fetch` method with the same behavior as the HTML DOM `fetch` method. More detail is available in [fetch](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/uxp-api/reference-js/global-members/data-transfers/fetch.md).

The [web-service-call-js-sample](https://github.com/AdobeDocs/uxp-photoshop-plugin-samples/tree/main/web-service-call-js-sample) shows a plugin communicating with a web server.
