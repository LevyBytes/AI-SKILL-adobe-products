# applyMotionBlur

23.5

_Promise_`<void>`

Executes Motion Blur.

Unsupported color modes: Indexed Color, Bitmap

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `angle` | _number_ | Angle, in degrees, at which to apply the blur effect [-360,360] |
| `distance` | _number_ | Blur amount [1,2000] |
