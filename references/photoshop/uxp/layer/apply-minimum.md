# applyMinimum

23.5

_Promise_`<void>`

Executes Minimum.

Unsupported color modes: Indexed Color, Bitmap

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `radius` | _number_ | Filter radius in pixels. Use an integer from [1,500] with `SQUARENESS`, or a float from [0.2,500] with `ROUNDNESS`. |
| `preserveShape` | [_PreserveShape_](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/modules/constants.md#preserveshape) | Corner-preservation choice (default: `PreserveShape.SQUARENESS`) |
