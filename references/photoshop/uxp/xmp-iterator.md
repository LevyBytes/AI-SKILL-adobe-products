# XMPIterator

**Since**: v7.2.0
[XMPMeta.iterator](xmp/xmp-meta/iterator.md) creates this object. It recursively visits properties and qualifiers in an [XMPMeta object](xmp/xmp-meta/reference-index.md), returning them as [XMPProperty object](xmp-property-xmp-property/reference-index.md).

No JavaScript properties are defined on the object.
