# Output options

| Output | What it does |
| --- | --- |
| Current layer | Writes the Neural Filter onto the active layer itself, replacing pixels there. |
| New layer | Builds a duplicate layer and applies the filter separately from the original. |
| New layer masked | Copies the layer and adds a mask that isolates the filter result for simpler masking and blending. |
| Smart filter | Turns the layer into a Smart Object, then attaches the filter non-destructively as a Smart Filter. |
| New document | Creates a separate Photoshop document that contains only the filtered result. |
