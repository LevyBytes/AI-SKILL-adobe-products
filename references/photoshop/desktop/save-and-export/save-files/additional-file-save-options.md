# Additional file-save options

These controls are shown only if File Handling is set to Ask When Saving for Image Previews (Windows) or Append File Extension (macOS).

| Option | Usage |
| --- | --- |
| Thumbnail (Windows) | Adds notes and a compact preview image so the file is easier to identify in folders or dialog boxes. |
| Image Previews options (macOS) | Adds notes and a compact preview image so the file is easier to identify in folders or dialog boxes. |
