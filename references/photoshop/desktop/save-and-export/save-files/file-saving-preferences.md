# File saving preferences

In the File Handling panel of Preferences (Edit > Preferences (Windows) or Photoshop > Preferences (macOS)), adjust extension handling, previews, save behavior, and recovery options to support the workflow and reduce data-loss risk.

| Option | Usage |
| --- | --- |
| Image Previews | Controls how image previews are saved:<br><br>- Never Save: writes files with no previews.<br>- Always Save: writes files with the selected previews.<br>- Ask When Saving: lets each file use its own preview choice.<br><br>On macOS, choose one or more preview types. |
| File Extension (Windows) | Adds three-character extensions that identify the file format:<br><br>- Use Upper Case: uses uppercase letters for file extensions.<br>- Use Lower Case: uses lowercase letters for file extensions. |
| Append File Extension (macOS) | Sets how extensions are added to filenames:<br><br>- Never: writes files with no file extensions.<br>- Always: adds file extensions to filenames.<br>- Ask When Saving: decides file extensions separately for each file.<br>- Use Lower Case: adds file extensions with lowercase letters. |
| Default File Location | Uses either Creative Cloud or the computer as the default save target. |
| Save As to Original Folder | When selected, starts in the image's source folder; when cleared, starts in the most recently used save folder. |
| Save in Background | Lets work continue in Photoshop while the file save runs. |
| Automatically Save Recovery Information Every: | Writes crash-recovery data at the chosen interval. |
| Enable legacy "Save As" | Returns Photoshop to the older Save As behavior from earlier releases. |
| Do not append "copy" to filename when saving a copy | Stops Photoshop from inserting the word copy in the filename for duplicate saves. |
