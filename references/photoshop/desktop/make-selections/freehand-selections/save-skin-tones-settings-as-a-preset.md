# Save Skin Tones settings as a preset

In Adobe Photoshop, save Skin Tones settings as a preset so you can reuse them later.

Choose Select > Color Range.

In the Color Range dialog, choose Skin Tones from the Select menu.

Choose Detect Faces to improve accuracy.

Set the Fuzziness slider, or type a value.

Set Display to Selection and choose a Selection Preview to view the selections.

Choose Save.

In the Save window, enter a file name for the preset, then choose Save.
