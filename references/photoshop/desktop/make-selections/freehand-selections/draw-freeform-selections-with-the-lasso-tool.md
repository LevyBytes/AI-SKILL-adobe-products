# Draw freeform selections with the Lasso tool

In Adobe Photoshop, the Lasso tool draws and refines freeform selection borders.

Activate the Lasso tool in the toolbar.

In the Options bar, enter a Feather value to soften selection edges.

Enable the Anti-alias checkbox to create smoother selection edges.

From the Options bar, choose Add to selection, Subtract from selection, or Intersect with selection.

Create a freehand selection border by dragging freely.

For straight-edged segment starts and ends, hold Alt (Windows) or Option (macOS) and choose points.

Release the mouse button to close the selection border.
