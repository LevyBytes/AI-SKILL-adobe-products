# Snap to image edges using Magnetic Lasso tool

In Adobe Photoshop, the Magnetic Lasso tool snaps selection borders to clearly defined edges in an image.

Magnetic Lasso in Photoshop helps create precise selections. While you trace an object's edge, the selection border snaps to defined areas, which makes the tool useful for complex outlines against high-contrast backgrounds. It is not available for 32-bit images.

Choose the Magnetic Lasso tool from the toolbar.

Choose one of the selection modes in the Options bar.

Enable the Current Tool Only checkbox.

Enable the Current Tool Only checkbox again where required.

Set these controls in the Options bar.

- Feather: softens a selection edge by fading it gradually into nearby pixels.
- Anti-alias: smooths the selection boundary by blending edge pixels with the background.
- Width: defines how far from the pointer the tool searches for edges.
- Contrast: changes how sensitive the tool is to edge differences in the image.
- Frequency: controls how often fastening points are placed automatically.

Choose Use tablet pressure to change pen width to reduce edge width as pen pressure increases when using a stylus.

Click in the image to place the first fastening point, then trace the edge by dragging.

If the border does not snap to the edge you want, choose to add fastening points manually.

Press Delete when you need to remove recently added segments or fastening points.

To close the selection border, choose the starting point when the circular icon appears. Away from the starting point, finish it with double-click or Ctrl + click (Windows) or Command + click (macOS).

Tip

Press Caps Lock to switch the lasso pointer so it shows the lasso width. Pointer changes are available when the tool is selected but idle. Use ] to increase the Magnetic Lasso edge width by 1 pixel, and use [ to decrease the width by 1 pixel.

For an image with well-defined edges, use higher Width and Contrast settings and trace the border roughly. For softer edges, use lower Width and Contrast settings and trace more precisely.
