# Measurement Log behaviour

- For every selected data point, the Measurement Log creates a separate column.
- Each time you measure, the log receives another data row.
- When several areas are selected, Photoshop first adds one summary row with cumulative data, then adds a row for each individual selection. The Label column lists each selection area as its own feature and gives it a unique number.
- The Document column shows which source document produced each measurement.

For a complete measurement dataset, repeat the workflow across additional selections or documents.
