# Add a stroke to a frame

Create borders around images or design elements in Adobe Photoshop by applying a stroke to a frame.

A stroke on a Photoshop frame adds a clear border around the image, which can increase visual emphasis and separation. The stroke's color, width, and alignment can be adjusted for different design results.

Before starting

Create a frame with the Frame Tool, then insert an image into that frame.

In the Layers panel, select the frame layer.

Choose fx in the lower-left corner of the Layers panel.

In the Properties panel, choose the Stroke options section. This opens the Layer Style dialog box.

Tip

If the Properties panel is hidden, choose Window > Properties to show it.

From the Fill Type dropdown menu, choose a stroke type: solid Color, Gradient, or Pattern.

Select the color swatch to choose a color from the Color Picker.

Set the stroke width by typing a value in the Size field or moving the slider.

For Position, choose Inside, Center, or Outside to control where the stroke sits relative to the frame edge.

When using Gradient or Pattern strokes, change the angle value to rotate the strokes.

Choose OK to apply the changes. The stroke appears around the frame.

Use strokes to call attention to framed content, make it visually separate, and improve design clarity.

Applying a stroke can emphasize framed content, distinguish it visually, and make the design clearer.
