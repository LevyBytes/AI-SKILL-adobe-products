# Add more artboards

Another way to insert artboards is to use the Plus icons displayed beside existing artboards.

Select the Artboard tool grouped with the Move tool. If it is not visible, hold the Move tool until the grouped tools appear.

Choose an existing artboard in the document. Icons appear along the sides of that selected artboard.

Select a icon to create a new artboard in that direction.

To copy an artboard and all of its contents, hold Option (macOS) or Alt (Windows) while selecting a icon.

Insert a new artboard to extend the document layout in Photoshop.
