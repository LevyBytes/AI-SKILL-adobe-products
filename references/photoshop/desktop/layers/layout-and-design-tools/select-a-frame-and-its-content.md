# Select a frame and its content

Select a frame and its contents together or separately in Adobe Photoshop.

Photoshop lets you target the frame and the content inside it either as one selection or as independent items. This gives precise control over the way the image is positioned within the frame.

On the canvas, select the inset image to select both the frame and the image.

Double-click the image when you want only the image selected.

On the canvas, select the frame border when you want only the frame selected.

Tip

You can also pick the frame or image by selecting its thumbnail in the Layers panel.

Direct canvas selection makes it easy to edit either framed content or the frame itself.

Select the image or frame on the canvas to edit the content inside the frame quickly.
