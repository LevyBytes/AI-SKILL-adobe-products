# Send a local PSD file to Firefly Boards

Select File > Open, then locate and open a local PSD file.

Select Share > Send to Firefly Boards. Photoshop uploads the file to Adobe Cloud as a cloud document (PSDC).

Pick an existing Boards file, or make a new Boards file.

Select Open in Boards to move the uploaded PSDC file into Firefly Boards.

Note

To share local PSD and PSDC files with Firefly Boards, select File > Export, then Send to Firefly Boards.
