# Change the font across multiple layers

Change fonts across multiple Adobe Photoshop layers to resolve template mismatches or keep all text elements visually consistent.

From the toolbar (Window > Tools), select the Horizontal Type tool or the Vertical Type tool.

Hold Ctrl (Windows) or Command (macOS), then select multiple type layers in the Layers panel.

In the Options bar (Window > Options), choose the down arrow beside Search and select fonts to show available fonts.

Choose the desired font.
