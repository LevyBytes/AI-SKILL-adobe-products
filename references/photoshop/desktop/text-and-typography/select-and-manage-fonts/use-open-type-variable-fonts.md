# Use OpenType variable fonts

Use OpenType variable fonts in Adobe Photoshop to build bold typographic effects for flexible, responsive designs without changing fonts.

OpenType variable fonts keep text editable while giving precise control over thickness and spacing. Style adjustments can happen without adding clutter to the Layers panel.

From the toolbar (Window > Tools), choose the Horizontal Type tool or the Vertical Type tool.

In the Options bar (Window > Options), choose an OpenType variable font. The font name typically contains Variable.

Highlight the text to modify. If nothing is selected, the settings apply to new text you create.

In the Character section of the Properties panel, choose the Variable font settings icon.

Use the sliders to adjust Weight and Optical size.

Set the Weight and Optical size of OpenType variable fonts using Properties panel.

OpenType variable font setting changes affect the text immediately.
