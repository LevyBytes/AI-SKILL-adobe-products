# Create a document with international text

In the Character panel, choose the language you want. That language choice matters only for hyphenation and spelling.

Choose a font that matches the selected language. For example, after choosing Thai language, use Adobe Thai or Noto Sans Thai as a Thai font.

Copy text written in the language you selected and paste it into the document. If a keyboard for that language is available, you can type the text directly instead.

Once the Unified Text Engine is in use, Photoshop manages text shaping and layout automatically for the selected language, with no need to switch among text engines.
