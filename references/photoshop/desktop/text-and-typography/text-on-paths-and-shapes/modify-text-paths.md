# Modify text paths

Adjust anchor points and curves in Photoshop to reshape text paths, refine alignment, and build custom typography effects.

After type is placed on a path, the path shape can be edited to fix spacing or alignment and to create distinctive typographic results.

Open a Photoshop document that contains text on paths.

Choose the Direct Selection tool.

Select the text layer in the Layers panel so the anchor points are visible.

Move an anchor point to alter the path; the type reflows onto the updated shape.

Drag an anchor point to change the path, with the text updating to match.

Move another anchor point as needed; the text follows the adjusted path automatically.
