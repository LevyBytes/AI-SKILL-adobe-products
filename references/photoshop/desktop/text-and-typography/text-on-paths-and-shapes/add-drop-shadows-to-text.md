# Add drop shadows to text

Use layer styles in Adobe Photoshop to give text a professional drop shadow that adds depth and dimension.

In Adobe Photoshop, a drop shadow is an easy way to separate text from the background. The effect suggests depth by making the type appear raised above the surface, which can improve readability and visual impact.

Select the text layer in the Layers panel that needs the drop shadow.

Select the Add a layer style icon > Drop Shadow.

Change Drop Shadow settings to shape the shadow effect.

Refine the Drop Shadow settings until the shadow effect matches the design.

Set Opacity, Distance, Spread, and any other needed controls in the Layer Style dialog.

The Layers panel lists Drop Shadow beneath the text layer; select the eye icon next to Drop Shadow to toggle visibility.

Select OK to apply the effect.
