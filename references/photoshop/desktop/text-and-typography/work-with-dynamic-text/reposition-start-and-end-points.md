# Reposition start and end points

For Circle, Arch, and Bow Dynamic Text in Adobe Photoshop on desktop, adjust where the path begins and ends.

Use File > Open to choose and open an image.

In the Layers panel, choose the text layer that contains the Dynamic Text.

From the toolbar, choose the Path Selection tool.

Move the pointer to the beginning of the text. When the cursor changes, drag along the path to reposition the start point.

Move the pointer to the end of the text. When the cursor changes, drag along the path to reposition the end point.

When the start or end point reaches the position you want, release the mouse. Photoshop resizes the text to fit the updated span.
