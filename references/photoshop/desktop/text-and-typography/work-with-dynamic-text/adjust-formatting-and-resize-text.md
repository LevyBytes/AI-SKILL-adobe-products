# Adjust formatting and resize text

Learn how to resize and reflow text with Dynamic Text so it fits a bounding box in Adobe Photoshop on desktop.

Use File > Open to choose and open an image.

Select the Type tool, then choose existing text or create new text.

Choose Dynamic Text from the Contextual Task Bar.

Tip

You can also choose Type > Convert to Dynamic Text or Dynamic Text from the Options bar.

Choose the text shape: Block, Circle, Arch, or Bow. For shape resizing and behavior details, refer to Dynamic Text in Photoshop.

Dynamic Text formatting in Photoshop, including block, circular, and arched text styles

In the Properties panel, under Dynamic Text, adjust text spacing for Block and adjust position and direction for Circle, Arch, and Bow.
