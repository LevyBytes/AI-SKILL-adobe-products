# Using the Glyphs panel

Choose the Horizontal Type tool or Vertical Type tool to make a new type layer, or select an existing type layer.

In the Options bar, Character panel, or Properties panel, set the font to Noto Color Emoji SVG. The Glyphs panel opens automatically.

Tip

If the Glyphs panel is not visible, choose Window > Glyphs.

Browse the Glyphs panel, choose the emoji you need, and insert the selected emoji glyph at the cursor in the text layer.

To add an emoji glyph as document text, double-click it in the Glyphs panel.

Double-click a glyph in the Glyphs panel when you want to place that emoji as document text.
