# Resize a text layer

Choose Move tool, then in Layers panel select the text layer to resize.

Drag an anchor point to scale both bounding box and text inside it.

Drag an anchor point to resize the text together with its bounding box.

During the drag, these modifiers apply:

- Shift: resize the text non-proportionally within the text layer.
- Alt: keep the center of the text layer fixed.
- Command (macOS) or Ctrl (Windows): try skewed angles.

Click Commit icon in Options bar.

Tip

Use Window > Options to display the Options bar.
