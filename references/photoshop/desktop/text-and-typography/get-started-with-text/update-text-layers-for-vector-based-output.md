# Update text layers for vector-based output

Update Chinese, Japanese, and Korean (CJK) text layers in Adobe Photoshop so display and print output stay accurate.

When a document opens, Photoshop can find rendering differences in Chinese, Japanese, or Korean (CJK) text, particularly when another version or different fonts created the content. In that case, Photoshop may ask you to update text layers for accurate display and vector-based output.

Use File > Open for a Photoshop document that contains CJK text.

If Photoshop prompts you, choose Update to refresh text layers for vector-based output. Most differences are small and show only at high zoom.

Photoshop prompts users to update text layers for accurate vector-based output when opening a document with CJK text.

Check the document for text differences, including shifted, reflowed, or missing text.

To correct the result, change the text frame, spacing, or alignment; to keep the original text appearance, press Esc and cancel.

Note

Without updating text layers, Photoshop relies on the saved bitmap version for display and printing. Updating layers keeps CJK text crisp and vector-based.
