# Edit text

Edit existing text in Adobe Photoshop when you need to correct typos, clarify wording, or update content within a text layer.

Choose Horizontal Type tool or Vertical Type tool from Tools panel.

Click inside the text to put the insertion point at the edit location. For a specific span, drag across the characters to be changed.

Drag with Horizontal or Vertical Type tool to edit point text or paragraph text.

Point text and paragraph text can be edited by dragging with Horizontal or Vertical Type tool.

Enter the required text changes.

Click Commit icon in the Options bar.

Tip

Use Window > Options when you need to show the Options bar.
