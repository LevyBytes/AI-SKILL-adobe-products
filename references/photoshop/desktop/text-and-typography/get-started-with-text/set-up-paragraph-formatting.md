# Set up paragraph formatting

In Adobe Photoshop, paragraph settings help keep spacing and alignment consistent across multi-column type layouts.

Choose the Horizontal Type tool or Vertical Type tool.

In the Layers panel, pick the type layer that contains the paragraph for alignment or justification.

Note

Alignment and justification apply only to paragraph text. For point text spacing control, first use Type > Convert to Paragraph Text.

Open the Paragraph panel with Window > Paragraph.

For text alignment, choose any of these controls:

- Left align text icon
- Center text icon
- Right align text icon

For text justification, choose any of these controls:

- Justify last left icon
- Justify last centered icon
- Justify last right icon
- Justify all icon

Select different alignment, justification, indentation, and spacing options from the Paragraph panel to customize your text.

In the Options bar (Window > Options), choose the Commit icon.
