# Add paragraph text

Use paragraph text for longer material, including paragraphs and descriptions. Photoshop builds a bounding box around the text so you can edit, resize, shape, and format full paragraphs in one layer.

Choose Horizontal Type tool or Vertical Type tool from the toolbar.

Drag anywhere in the document to create paragraph text.

Photoshop adds a text layer in Layers panel; Type icon marks it.

Drag in the document with Horizontal or Vertical Type tool when adding paragraph text.

To add paragraph text, drag in the document while Horizontal or Vertical Type tool is selected.
