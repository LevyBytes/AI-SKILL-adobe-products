# Add point text

Point text creates one editable text layer that runs in a straight line with no boundary or bounding box. Line breaks are allowed, making it useful for headlines, buttons, and simple annotations.

Choose Horizontal Type tool or Vertical Type tool from the toolbar.

Click anywhere in the document, then begin typing to create point text.

Photoshop adds a text layer in Layers panel; the Type icon identifies it.

Click the document with Horizontal or Vertical Type tool when adding point text.

To add point text, click the document while Horizontal or Vertical Type tool is active.
