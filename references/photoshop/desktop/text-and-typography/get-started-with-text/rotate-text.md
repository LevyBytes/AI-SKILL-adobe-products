# Rotate text

Rotate a text layer in Adobe Photoshop when the design needs angled type or a break from minimal symmetry.

Select the Move tool, then choose the text layer to rotate.

Move the pointer outside a bounding-box corner until a curved arrow like the rotate bottom icon appears.

Drag that curved arrow to turn the text.

Tip

For finer rotation control, open Window > Contextual Task Bar.

Hover around any corner and drag the curved arrow to rotate text.

Choose the Commit icon.
