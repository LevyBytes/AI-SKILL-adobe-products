# Move text

Use Adobe Photoshop text movement when a layout changes or when important image areas need emphasis.

With the Move tool active, choose a text layer in the Layers panel. Photoshop shows a bounding box around that selected type.

Drag from inside the bounding box to place the text where it belongs.

For precise frame movement, use the arrow keys. Add Shift while pressing the arrow keys to step through larger moves.

Drag a text frame with the Move tool to reposition it.
