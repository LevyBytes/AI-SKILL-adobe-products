# Add bulleted and numbered lists

Use bulleted and numbered lists in Adobe Photoshop when brochure content needs schedules, performances, or activities.

With Horizontal Type tool or Vertical Type tool, create a type layer or select an existing one.

Open Properties panel with Window > Properties.

From Bullets and Numbering section, choose Bulleted list icon or Numbered list icon.

Choose Bulleted or Numbered List icon in the Properties panel.

The Properties panel contains Bulleted or Numbered List icon.

Type the first list item, then press Enter (Windows) or Return (macOS) for additional items.

Tip

To stop Photoshop from turning typed text into lists automatically, choose Preferences > Type, clear Automatic detection of Bulleted and Numbered lists while typing, and select OK.
