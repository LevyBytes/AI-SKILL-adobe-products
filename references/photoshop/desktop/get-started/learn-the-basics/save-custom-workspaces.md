# Save custom workspaces

Save a custom Adobe Photoshop workspace when you want to keep a preferred layout and set of settings.

In Photoshop, a workspace means an arrangement of panels, tools, and windows. You can use built-in workspaces or make your own custom workspace to move more easily among application layouts. Custom workspaces can support different project types, including photo editing, graphic design, and digital painting.

Set up the panels and tools in the layout you want:

- Drag panels to change their order.
- Dock a panel by moving its tab onto another panel.
- Group panels by moving one tab into another.

Select Window > Workspace > New Workspace.

Save and name the custom Photoshop workspace, including panel layout, shortcuts, and menus.

Include panel layout, shortcuts, and menus when naming and saving your custom Photoshop workspace.

Type a workspace name in the New Workspace dialog box.

Under Capture, choose the elements to include:

- Panel Locations
- Keyboard Shortcuts
- Menus

After you select Save, Photoshop creates the workspace. The saved name appears in the Choose a workspace dropdown menu in the Application bar.
