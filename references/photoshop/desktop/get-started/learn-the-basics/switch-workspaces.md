# Switch workspaces

Switch workspaces in Adobe Photoshop when you need the interface to match a creative workflow.

Photoshop includes task-focused workspaces such as Painting and Photography. You can also build and save a custom workspace. Changing workspaces brings forward the relevant tools and panels for the project at hand.

From the Application bar, open Choose a workspace.

Choose Essentials, Photography, another preset layout, or a custom workspace from the list, depending on the workflow.

Note

Another path is Window > Workspace, followed by the workspace you want from the list.

Pick the workspace that fits the creative task to improve the workflow.
