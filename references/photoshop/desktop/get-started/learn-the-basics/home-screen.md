# Home screen

At startup, Photoshop displays the Home screen with these areas:

- Feature highlights that surface recent Photoshop improvements.
- Tutorials for learning concepts, workflows, tips, and tricks.
- A Recents section for recent cloud documents, including files shared with you.
- Keyword filters for locating particular cloud documents. Offline status greys out online-only cloud documents.

Photoshop tailors Home screen content to your Photoshop experience and Creative Cloud membership.

Based on your Photoshop experience and Creative Cloud membership, the Home screen presents personalized content. Tip

While a document is open, select Home in the Options bar to go back to the Home screen. Press Esc to leave the Home screen.

The Home screen includes these tabs and buttons:

- New file: starts a new document from the available templates.
- Open: loads an existing Photoshop document.
- Home: returns to the Home screen.
- Learn: opens tutorials for beginner and advanced Photoshop skills.
- Your files: shows all of your files within the categories below:
- Shared with you: shows Photoshop cloud documents that others shared with you.
- Lightroom photos: shows synced Lightroom photos and lets you bring them into a Photoshop document.
- Deleted: lists cloud-storage documents you removed, with choices to restore or permanently delete them.

Note

To change how many recent files appear, select Edit > Preferences > File Handling and set a value from 0 to 100 in the Recent File List Contains field.
