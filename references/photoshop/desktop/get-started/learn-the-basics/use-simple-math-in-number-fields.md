# Use simple math in number fields

Use simple math inside Adobe Photoshop numeric fields to calculate values while editing.

Basic calculations can be entered directly in fields that accept numbers, including width, height, font size, and canvas dimensions. Mathematical expressions make precise design or editing adjustments faster.

Select any numeric input field, such as Width or Height.

In the field, enter a mathematical expression. Examples include 30+45, 300/2, 12*4, and 3 cm * 50%.
