# Snap Layout support on Windows

On Windows, Snap Layouts can organize Photoshop windows across the screen. The feature supplies preset window arrangements based on display size and orientation. These layouts make it easier to manage several apps side by side or in a grid, which supports multitasking.

Arrange Photoshop windows and other apps with Snap Layouts by placing them into predefined screen layouts for easier multitasking.
