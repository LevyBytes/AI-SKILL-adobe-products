# Explore beyond the canvas with Generative Expand

Use Generative Expand in Adobe Photoshop to enlarge an image and create new content from text prompts.

Choose Crop tool from the Tools panel, then pull the crop handles outward so the canvas becomes larger.

From the Contextual Task Bar, select Generative Expand.

In the Contextual Task Bar, use the model picker to choose an Adobe Firefly model. Options are Firefly Fill & Expand, Firefly Image 3, and Firefly Image 1.

To have Photoshop extend the image, keep the prompt empty and select Generate.

Pick one variation from the Properties panel.
