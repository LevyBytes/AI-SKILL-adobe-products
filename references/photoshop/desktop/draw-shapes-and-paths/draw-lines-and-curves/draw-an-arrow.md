# Draw an arrow

Add arrowheads to a line in Adobe Photoshop when you need to draw an arrow.

To draw the line, choose Line tool from the shapes tool group in the Tools panel.

On the Contextual Task Bar (Window > Contextual Task Bar), use Arrowheads and choose Start or End.

For the arrowhead, enter Width and Length values in pixels.

Set Concavity between -50% and +50% to control the curve where the arrowhead joins the line.
