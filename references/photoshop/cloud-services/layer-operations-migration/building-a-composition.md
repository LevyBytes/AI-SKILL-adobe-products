# Building a composition

1. Begin with [Image Layers](../image-layer-operations-migration/reference-index.md) for the background
2. Add [Text Layers](../layer-operations/text/reference-index.md) for titles
3. Use [Adjustment Layers](../layer-operations/adjustments/reference-index.md) for color correction
4. Place logos/graphics through [Smart Objects](../layer-operations/smart-objects/reference-index.md)
5. Use [Groups](../layer-operations/advanced/layer-groups.md) for structure, then apply [Blend Modes](../layer-operations/advanced/blend-modes-and-opacity/supported-blend-modes.md)
