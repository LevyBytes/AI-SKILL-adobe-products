# Editing existing documents

1. Read [Layer Operations Overview](layer-operations-overview.md) for editing patterns
2. Use the relevant guide to change existing layers
3. Use [Advanced Operations](../layer-operations/advanced/reference-index.md) when reorganizing the layer stack
4. Before finalizing, test changes to visibility and opacity

### Related guides

Layer operations are often used together with these v2 endpoints:

- **[Export Layers Migration](../export-layers-migration-guide.md)** - export layers in single-layer or multi-layer form, with PSD support and quality defaults covered
- **[Format Conversion](../format-conversion-migration/reference-index.md)** - turn PSDs into other formats without making edits
- **[ICC Profile Migration](../icc-profile-migration-guide-overview.md)** - manage color for exported output
- **[Document Creation](../document-creation-migration/reference-index.md)** - start new blank documents
- **[Document Operations](../document-operations-migration/reference-index.md)** - handle resize, crop, trim, and other document-level operations
