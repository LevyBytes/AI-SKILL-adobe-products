# Migrating from v1?

Already using legacy Photoshop or Lightroom APIs (v1)? The v2 API provides a unified architecture, single-call combined operations, and more flexible storage, along with a defined migration path.

**Start here:**

- **[Migration to v2 overview](migration-to-v2-overview/reference-index.md)**: Details what changes, which changes break compatibility, and how to follow the migration path, including a table that pairs each v1 endpoint with its v2 counterpart and guide.
- **[Key improvements and architecture with v2](key-improvements-and-architecture-with-v2/reference-index.md)** - Explains the migration case: combined operations, flexible storage options, published action files, and other architecture advantages.

The migration overview lets you jump into detailed endpoint guides for format conversion, document creation, layer operations, actions, artboards, manifest, status, convenience APIs, and edit operations.
