# Output formats

**JPEG result:**

```json
{
  "destination": {
    "url": "<JPEG_URL>"
  },
  "mediaType": "image/jpeg",
  "quality": "maximum",
  "width": 2000
}
```

**PNG result:**

```json
{
  "destination": {
    "url": "<PNG_URL>"
  },
  "mediaType": "image/png",
  "compression": "medium",
  "width": 1920
}
```

**TIFF result:**

```json
{
  "destination": {
    "url": "<TIFF_URL>"
  },
  "mediaType": "image/tiff",
  "width": 3000
}
```

**PSD result:**

```json
{
  "destination": {
    "url": "<PSD_URL>"
  },
  "mediaType": "image/vnd.adobe.photoshop"
}
```

**PSDC (Cloud Document) result:**

```json
{
  "destination": {
    "url": "<PSDC_URL>"
  },
  "mediaType": "document/vnd.adobe.cpsd+dcxucf"
}
```

**JSON Manifest result:**

```json
{
  "destination": {
    "url": "<JSON_URL>"
  },
  "mediaType": "application/json"
}
```
