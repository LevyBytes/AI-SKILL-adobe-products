# Migrating from v1?

For teams still on the legacy Photoshop or Lightroom APIs (v1), Photoshop API v2 provides one architecture, single-call combined operations, and more flexible storage with a defined migration route.

**Start here:**

- **[Migration to v2 overview](../migration-to-v2-overview/reference-index.md)** - Covers the changes, breaking differences, and a step-by-step migration path, including a reference table that connects each v1 endpoint to its matching v2 endpoint and guide.
- **[Key improvements and architecture with v2](../key-improvements-and-architecture-with-v2/reference-index.md)** - Explains the migration value: combined operations, broader storage options, published action files, and additional architecture improvements.

From the migration overview, continue into focused endpoint guides for edit work, format conversion, document creation, layer tasks, actions, artboards, manifest, status, and convenience APIs.
