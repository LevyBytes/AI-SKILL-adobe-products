# Migration (v1 to v2)

When a project still depends on legacy v1 Photoshop or Lightroom APIs, these resources help plan and carry out the move to v2.

- **[Migrating to v2 overview](../migration-to-v2-overview.md)**: Covers breaking changes, the recommended migration sequence, and a table pairing legacy endpoints with the corresponding v2 guide.
- **[Key improvements and architecture with v2](../key-improvements-and-architecture-with-v2/reference-index.md)**: Migration rationale covering combined operations, storage options, published action files, and architecture.

The migration overview points into guides for documents, layers, actions, artboards, manifest, status, convenience APIs, edit operations, and more.
