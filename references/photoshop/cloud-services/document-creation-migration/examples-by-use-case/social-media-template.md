# Social media template

Use a square canvas for social media work:

```json
{
  "image": {
    "width": 1080,
    "height": 1080,
    "resolution": { "unit": "density_unit", "value": 72 },
    "fill": "white",
    "mode": "rgb",
    "depth": 8
  },
  "outputs": [
    {
      "destination": {
        "url": "<SIGNED_POST_URL>"
      },
      "mediaType": "image/vnd.adobe.photoshop"
    }
  ]
}
```
