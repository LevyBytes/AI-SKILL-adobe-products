# Defaults when exporting layers

- **Omitted JPEG quality:** defaults to `photoshop_max`. The accepted values are `very_poor`, `poor`, `low`, `medium`, `high`, `maximum`, and `photoshop_max`.
- **Omitted PNG compression:** defaults to `default` (level 6); `medium`, `maximum`, and other values are also accepted. See [Output Types Migration – PNG](../output-types-migration/output-types-migration-guide-png-output-migration/reference-index.md).
