# Firestore Setup

Next, create a `.env` file that contains every variable. Fill it with the values from the matching Firebase setup:

```sh
{
        echo 'API_KEY='
        echo 'AUTH_DOMAIN='
        echo 'PROJECT_ID='
        echo 'STORAGE_BUCKET='
        echo 'MESSAGING_SENDER_ID='
        echo 'APP_ID='
        echo 'COLLECTION_NAME='

} >> .env
```
