## When agents open this product area

Use when working with Adobe Photoshop desktop images, layers, selections, masks, color, typography, filters, automation and export; developing Photoshop UXP plugins with the object model, batchPlay, executeAsModal, imaging, storage, UI and XMP APIs; or integrating Photoshop cloud APIs and their versioned migration contracts.

## The work behind the references

Adobe Photoshop references for image work and programmable integrations. Desktop editing, UXP plug-ins and cloud APIs have distinct entrypoints that retain their different execution models and capabilities. Legacy scripting has its own conditions as well, and the [plug-in examples](plugin-samples/reference-index.md) carry their documented runtime and setup.
