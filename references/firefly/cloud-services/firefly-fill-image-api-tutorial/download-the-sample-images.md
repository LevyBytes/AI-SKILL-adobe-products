# Download the sample images

Download the four files shown here, consisting of two source images and two masks, and place them in your project folder as PNG files.

- [Figure: source-person-photo-1](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/guides/images/source-person-photo-1.png) source-person-photo-1.png
- [Figure: mask-person-photo-1](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/guides/images/mask-person-photo-1.png) mask-person-photo-1.png
- [Figure: source-person-photo-2](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/guides/images/source-person-photo-2.png) source-person-photo-2.png
- [Figure: mask-person-photo-2](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/guides/images/mask-person-photo-2.png) mask-person-photo-2.png

Within your own applications, automate mask generation for your own images with [Photoshop Create Mask API](https://developer.adobe.com/firefly-services/docs/photoshop/api/?aio_internal).
