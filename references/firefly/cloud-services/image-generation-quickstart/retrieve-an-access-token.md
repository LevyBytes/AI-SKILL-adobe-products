# Retrieve an Access Token

From a secure terminal, use `export` to place your **Client ID** and **Client Secret** in environment variables available to later commands:

Replace these example values with your own credentials or the returned upload identifier in your private shell session.

```bash
export FIREFLY_SERVICES_CLIENT_ID=yourClientIdAsdf123
export FIREFLY_SERVICES_CLIENT_SECRET=yourClientSecretAsdf123
```
