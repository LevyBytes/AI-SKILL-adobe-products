# Generate images using FLUX 1.1

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

On the Text to image page, type a text prompt in the Prompt field.

In General settings, choose the Model dropdown menu.

Under Partner models, choose FLUX1.1 [pro], FLUX1.1 [pro] Ultra, or FLUX1.1 [pro] Ultra (Raw).

Open the Aspect ratio dropdown menu and choose one of these options:

- Widescreen (16:9)
- Vertical (9:16)
- Square (1:1)
- Portrait (3:4)
- Landscape (4:3)

In Reference image, upload an image from your device or Adobe cloud storage.

Pair a reference image with a text prompt to steer the generated image.

Use both a reference image and a text prompt when you want to influence the generated image.

Note

Only FLUX 1.1 Ultra and FLUX 1.1 Ultra (Raw) support Reference image.

After you add a reference image, Firefly considers it together with the text prompt while guiding the generated image.

Select Generate.
