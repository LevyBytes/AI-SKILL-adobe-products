# Generate images using Imagen 3 and Imagen 4

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

On the Text to image page, type a text prompt in the Prompt field.

In General settings, choose the Model dropdown menu.

Under Partner models, choose the Imagen 3 or Imagen 4 model.

Open the Aspect ratio dropdown menu to choose the generated image dimensions.

- Widescreen (16:9)
- Vertical (9:16)
- Square (1:1)
- Portrait (3:4)
- Landscape (4:3)

When needed, upload an object image as a reference so specific objects or elements can be generated in the final image.

Note

Subject is available only for the Imagen 3 model.

Select Generate.
