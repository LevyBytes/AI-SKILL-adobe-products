# Generate images using FLUX Kontext Max or FLUX Kontext Pro

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

On the Text to image page, type a text prompt in the Prompt field.

In General settings, choose the Model dropdown menu.

Under Partner models, choose FLUX.1 Kontext [max] or FLUX.1 Kontext [pro].

Open the Aspect ratio dropdown menu and choose one of these options:

- Widescreen (16:9)
- Vertical (9:16)
- Square (1:1)
- Portrait (3:4)
- Landscape (4:3)

Use Image to upload an image for editing, such as adding an element.

Select Generate.
