# Create a logo by Ideogram 3.0

Reference images on the canvas can guide a logo's visual style. With logo text added, the Create a logo preset produces designs aligned to the reference image's palette, arrangement, and general aesthetic.

Upload or add one or more images to use as logo references.

At the bottom of the page, choose Presets, then choose Logo maker.

Select Style to activate the eyedropper tool, then choose the desired canvas image. Repeat for each extra Style field to add more references.

Choose canvas images for the Create a logo by Ideogram 3.0 preset.

Pick one of the available aspect ratios.

Enter the logo text in Name of the brand, then choose Generate.
