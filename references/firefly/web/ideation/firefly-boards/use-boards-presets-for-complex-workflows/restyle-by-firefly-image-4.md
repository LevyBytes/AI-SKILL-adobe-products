# Restyle by Firefly Image 4

Use the Restyle preset to create another version of an image with the requested style and composition.

Upload the image that you want to restyle.

From the bottom of the page, select Presets, then choose Restyle.

Select the Composition field to enable the eyedropper tool, and choose the reference image on the canvas.

To define a style for generation, select the Style field to enable the eyedropper tool, then choose the reference image on the canvas.
