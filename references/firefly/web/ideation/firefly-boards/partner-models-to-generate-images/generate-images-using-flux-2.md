# Generate images using FLUX.2

On the Firefly homepage, choose Ideate, then Create a board.

On the Boards page, choose Generate image at the bottom of the page.

From the dropdown menu, choose FLUX.2 [pro].

Available partner models can be selected to generate images and add them to the canvas.

Choose the Sample from canvas icon to use an existing canvas image as a reference, or choose the Upload image reference icon to upload an image from the device.

Use Aspect ratio to pick from the available image dimensions.

For more generation controls, choose the Generation settings icon beside Aspect ratio. This opens the right-side panel, which contains these settings:

- Sub-prompts: browse a range of sub-prompts, from lighting through styles. Selecting preview thumbnails adds those sub-prompts to the prompt bar.

- Seed: add a seed number to start the process and influence the randomness of what the AI creates. Using the same seed, prompt, and control settings can produce similar images.

Enter a description in the prompt bar.

Choose Generate.
