# Add images to the canvas

From the Firefly homepage, choose Ideate in the left panel.

When you already have media ready, choose Upload files; to begin without existing files, choose Create a board.

On the Boards page, choose New board.

Bring an image onto the canvas through the Import option.

To find Adobe Stock imagery, select the icon in the right toolbar, then browse results in the Search panel.

Use Adobe Stock search, or look for images similar to items already placed on the canvas.

For text-prompt image creation, choose Generate image at the bottom of the page and add the result to the canvas.

Enter a description in the prompt bar. You can also choose among available Firefly models, partner models, and Custom Models for image generation.

In addition to Firefly models, partner models can generate board images as well.

When a canvas image should serve as a reference, choose the Sample from canvas icon and use the available options.

Before generating, open Generation settings if you need to change reference images, sub-prompts, or other generation choices.

Set image generation details such as aspect ratio and content type, then choose Generate.

Generated variations show as thumbnails in the filmstrip so you can pick which ones to place on the canvas.

Drop a generated image onto the canvas by dragging it. To move several images together, hold Shift while dragging and dropping them on the canvas.

After an image is on the canvas and selected, Firefly Boards shows editing and adjustment controls.

Use those editing and adjustment controls to refine the image and position it where you want it.

Selecting two or more canvas images enables extra controls.

Create a remixed image variation by auto-composing a text prompt from the selected images.
