# Add text to the canvas

Choose Text in the left panel of the canvas.

Put the cursor at the canvas location where the text should appear.

When text formatting controls become active, use them to set font style, size, color, alignment, and other text properties.

Open the Properties panel with the Properties icon to change text attributes such as color, opacity, and blend mode, along with text box properties including rotation, position, and size.

Adjust the text on the canvas with either its context menu or the Properties panel.
