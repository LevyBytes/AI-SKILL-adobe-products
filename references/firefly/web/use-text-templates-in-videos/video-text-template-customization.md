# Add a pre-designed text template and customize it for your video.

Firefly video editor includes built-in editable text templates that make it easier to add a polished, professional look. Template types include titles, name tags, signs, labels, and time stamps. With the text editing tools, you can change fonts, colors, sizes, and other attributes so the design fits the video.

Before you begin:

Begin from a new project with media files already on the timeline.

In the left panel, select the Text icon.

To add a text layer to the timeline, choose Add text and type in the text box.

To use a pre-designed text template instead, browse the available categories, select a template that matches your needs, and apply it.

In the Text panel, browse text templates and drag the chosen template onto the video to add it.

A text layer is added to the timeline, where the template can be edited and customized for your video requirements.

Edit the added template's text and shapes directly in the video editor panel.

Use the Properties panel to refine text elements and any shapes included in the template.

Use the Properties panel to refine text settings and personalize the template's appearance.
