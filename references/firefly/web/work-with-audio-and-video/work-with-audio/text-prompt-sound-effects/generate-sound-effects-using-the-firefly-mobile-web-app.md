# Generate sound effects using the Firefly mobile web app

Open the Firefly website in any supported browser.

Choose the Audio module, then pick Voice to sound effects.

On Generate SFX, choose Generate sound effects.

Choose Generate sound effects to reveal the prompt bar.

To work from a video while creating sound effects, select the Upload icon. After the file is added, it appears on the timeline.

Add the video that needs generated sound by using the upload button.

Move through the timeline until the playhead sits at the exact insertion point for the sound effect.

From the available choices, select Short Sound.

- Short Sound: creates a sound effect from a concise text description.
- Add timing: combines a spoken performance for volume and energy with text prompts to produce sound effects.

Choose Short Sound when you want a sound effect made from a concise text description.

In the prompt bar, describe the sound effect to create, then tap the Generate icon.

Preview the generated variations, pick the one to use, and tap Add sound effects.

Review the generated variations, then place one of those sound effects on the timeline.

To make another sound effect on the same audio track, move the playhead and generate it from the Prompt bar. For layered audio, select the icon to add a new track, then generate a new sound effect there.

Multiple sound effects can be generated and added to the timeline.

After selecting a sound effect on the timeline, the available actions include mute, volume adjustment, download, rename, and delete.

Select a generated sound effect variation to show its edit options.

Preview the sound effect with the play button, then open the download option from the icon.

Save the composed audio or video clip with Download.
