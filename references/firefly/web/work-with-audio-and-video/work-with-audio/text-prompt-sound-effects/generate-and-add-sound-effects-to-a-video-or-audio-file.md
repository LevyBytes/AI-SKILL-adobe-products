# Generate and add sound effects to a video or audio file

From the Adobe Firefly homepage, select Text to sound effects.

On Generate sound effects, choose Upload media and add the video or audio file you want to use for the sound-effect composition.

Choose Browse file to upload a file in .mp4, .mp3, .mov, .wav, or .aac format.

Use Browse file for uploading supported files: .mp4, .mp3, .mov, .wav, or .aac.

Note

- Uploaded files can be no longer than 30 seconds.
- Supported formats currently include .mp4, .mp3, .mov, .wav, and .aac.

After uploading, preview the file from the preview panel by selecting play or pressing the spacebar.

Use play to preview the video or audio clip that was added to the timeline.

Preview the timeline's video or audio clip with the play control.

Move the playhead to the timeline point where the sound effect should be added.

Scrub through the timeline and locate the playhead position for the sound effects.

Navigate the timeline to set the playhead where the sound effect should be inserted.

In the Prompt field, enter a text description of the sound effect to generate.

Describe the sound effect you want generated.

Add text that defines the sound effect to create.

Select Generate , then choose one generated sound effect variation to insert at the playhead position on the timeline.

Review generated sound effect variations and pick one for the timeline.

Preview the generated sound effect options, then choose one to add to the timeline.

Tip

To replace a timeline sound effect, select the existing sound effect first, then choose a replacement from the generated variations.

Select the sound effect on the timeline to edit it with options such as mute or volume adjustment. It can also be downloaded, renamed, or deleted.

Use the available editing controls to modify generated sound effects directly in the timeline.

Generated sound effects can be edited inside the timeline with the provided controls.

To add another sound effect on the same track, set the playhead at the desired point and generate one. To layer sounds, use Add Audio Track to add a new track, then create a sound from the text prompt bar.

Choose the sound effect variation you want as another layer in the timeline. After it is added, use the grab cursor to reposition it if necessary.

Tip

To shorten the generated sound clip, drag the trim handles inward from either end.

Use the Play icon or spacebar to preview the composition, and use Download to download the composed clip.
