# Steer image variations with personal or curated style images in Adobe Firefly

Style reference uses an existing image as guidance for the look and feel of generated variations. On the Adobe Firefly website, Reference in the Styles section lets you upload your own image or select from curated style images across many categories. Available reference style categories include 3D, Landscapes, Lighting effects, Texture, and more.

Use a style reference to keep assets aligned with a chosen brand or visual style.

Across multiple assets, style references help maintain the same look and feel.
