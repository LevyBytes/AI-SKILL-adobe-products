# Add a blank clip to the timeline in Firefly video editor.

A blank clip is useful for several editing situations. It can add a pause between scenes without leaving an empty gap, act as a solid background for text and logos, and support other timeline needs.

When inserted, the blank clip appears at the playhead position on the bottommost video or image layer.

Before you begin:

Set up a new project, and place any existing media files on the timeline.

On the video editor page, move the playhead to the timeline location for inserting the blank clip.

Set the playhead at the timeline location for the blank clip.

Note

Check placement by using the bottom video or image layer in the timeline as the guide.

Navigate to Menu > Clip > Add blank clip.

Use Add blank clip from the Clip menu to insert a blank clip where the playhead sits.

The existing image or video on the layer is trimmed automatically, and the blank clip is placed between the trimmed portions.

Note

The added blank clip is 5 seconds long.

This clip behaves like other clips: it can be trimmed, deleted, or moved elsewhere in the timeline.

Modify the blank clip the same way as other timeline clips.
