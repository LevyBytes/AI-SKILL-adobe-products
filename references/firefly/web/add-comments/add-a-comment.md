# Add a comment

Before you begin

Add visual elements to the artboard and arrange them to match the mood board vision.

Choose the space or visual element where the comment should be attached.

Select the icon to open the Comments panel.

Add comments and reply to collaborator comments with the comment option.

Choose the Place a pin icon, then select the chosen space or visual element on the canvas.

Place a pin on the canvas to identify a specific design element, then add your comment.

Enter the text in Add a comment.

Use the @ icon to tag a team member in the comment, and use the Emoji icon to add emojis.

Choose Submit.

To edit or delete a comment, select it, use the icon, then choose Edit or Delete. You can also choose the Resolve icon when the comment should move to resolved status.
