# Generate images in different styles

With Text to image and Firefly Image models, a reference image can guide newly generated variations toward the same visual style and aesthetic. You can also control how tightly the results follow that reference.

On the Firefly homepage, choose Generate in the left panel, then choose Generate image.

Type a text prompt in the prompt bar.

In Styles, under Reference, browse to an image on your device, or choose Browse gallery to select from the reference image gallery.

Choose an image from your device, or look through the reference gallery for a suitable one.

Use a local image or a reference gallery image that matches the style direction you want.

When a reference image is added, the Strength slider becomes active.

The Strength slider sets how strongly the variations follow the reference image.

Adjust Strength to loosen or tighten the connection between the variations and the reference image.

For generated variations, move the Strength slider to set adherence to the reference image: right increases adherence, and left reduces it.

Under Effects, browse the categories and choose the effects you want.

Color tone, Lighting, and Camera angle can also refine the generation.

Tip

Applied effects appear in the Prompt field. Remove every effect with Clear, or delete individual effects separately.

Choose Generate.
