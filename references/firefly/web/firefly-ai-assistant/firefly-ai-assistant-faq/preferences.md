# Preferences

Learn how to create, manage, and view preferences while working with the agent.

Tell the agent a preference in plain language. For example, you can state how outputs should be formatted or which tools should receive priority.

Preferences are saved at the user level and apply automatically across all of your chats. Project-level preferences may be supported later.

Use natural language to ask the agent to update or delete a preference. Examples include "Set my preference to..." or "Delete my preference for...".

Ask the agent to show your current preferences. At this time, there is no centralized interface for viewing them.
