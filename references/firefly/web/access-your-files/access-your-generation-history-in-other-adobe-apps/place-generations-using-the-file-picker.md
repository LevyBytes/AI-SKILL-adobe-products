# Place generations using the file picker

Inside the relevant Adobe app, choose the option that matches that app:

- Photoshop desktop: File > Place Embedded > Open cloud documents
- Illustrator: File > Place > Open cloud documents
- InDesign: File > Place > Open Cloud Document
- Photoshop web: Hamburger menu > Import

Tip

In Photoshop web, another route is Add image > Upload an image > Generation history from the toolbar, which opens Firefly generation history.

Browse the folders listed there to find the Firefly generation.

Note

The Generation history tab shows only generations that work with the app you are currently using, which reduces time spent searching for usable assets.

Choose the generation to use, then confirm the selection so it is added to the document.
