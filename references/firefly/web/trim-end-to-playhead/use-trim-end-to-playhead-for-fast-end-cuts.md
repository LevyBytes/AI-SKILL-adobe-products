# Use Trim end to playhead for fast end cuts

In Firefly video editor, Trim end to playhead removes the section after the playhead so the selected clip ends on the frame you chose. Instead of selecting the extra part and deleting it manually, use this command for quicker, more exact edits.

Before you begin:

Start a new project and place media files on the timeline.

On the timeline, choose the video, image, audio, or text layer you plan to edit.

Scrub through the timeline clip to the exact frame where playback should end, then set the playhead there.

From the top-left menu, open Clip, then choose Trim end to playhead.

Trim end to playhead cuts away the section after the playhead through the end of the timeline.

Trim end to playhead removes the timeline portion that follows the current playhead point. Tip

You can also press the keyboard shortcut W to trim the selected clip immediately from the playhead position through the end of the timeline.

After the command runs, timeline content from the playhead through the ending point is gone.
