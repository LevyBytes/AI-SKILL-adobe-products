# Properties panel

Select an image on the canvas, then choose the Properties icon to open the Properties panel, where image attributes can be changed:

The Properties panel provides controls for the Transform and Appearance properties on the selected image.

Use Properties to change the selected image's Transform and Appearance settings.

- Transform: Enter a rotation value and flip the image vertically or horizontally.
- Appearance: Choose a blend mode that controls how the image combines with other canvas elements, and adjust the image opacity.
