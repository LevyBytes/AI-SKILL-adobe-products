# Style Kits overview

Learn how Style Kits help collaborators keep generated image variations aligned with an on-brand style.

Note

Creating and saving Style Kits in Adobe Firefly requires entitlement to select enterprise plans. Without that entitlement, you can only use Style Kits shared with you through collaboration invitation links. If Firefly is provided through a company-owned account, contact your Adobe administrator to request access.

In Adobe Firefly, Style Kit supports collaboration and helps every image variation generated by collaborators stay consistent with the approved brand style.

After generating an image you want to reuse, save it as a Style Kit and specify which settings are hidden or locked, including the prompt and content, structure, style, and other specifications. Share the Style Kit with teammates so they can reuse approved styles, create faster, and maintain consistency.

Style Kits can be used in these ways:

- Save one for yourself so you can remember how a strong asset was made and create more assets in that style.
- Share with teammates who are working on a campaign and need to create content with one consistent style.
- Enable other users, including marketers, to make their own content while staying inside design and brand guidelines.
- Give the organization a way to use an official brand style.
