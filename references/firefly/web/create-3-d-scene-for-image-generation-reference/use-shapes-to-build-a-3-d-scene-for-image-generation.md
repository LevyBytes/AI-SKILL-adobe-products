# Use shapes to build a 3D scene for image generation

Scene to image (beta) helps you find the right angle for composition or reference art. It uses shape-building technology from Project Neo (beta) to assemble 3D scenes, then combines the scene with a text prompt so the generated variations can use your scene composition, camera angle, and depth as reference.

Example output pairs a Project Neo (beta) 3D scene reference with an image produced in Firefly Text to image.

The example shows a Project Neo (beta) 3D scene used as reference beside the Firefly Text to image result.

On the Firefly homepage, choose Generate in the left panel, then choose Scene to image (beta) under the Image tab.

The Scene to Image page shows a split layout: the Neo 3D canvas appears on the left, and the generation window appears on the right. To focus on scene composition in a larger canvas-only view, use View 3D scene only at the lower right.

Switch the Neo 3D canvas between side-by-side and single-view modes when adding details to the 3D object and scene.

Use either the split layout or the canvas-only view while refining the 3D object and scene.

Start the scene with preset shapes from the left panel. Choose a shape and then click the canvas to place it, or drag a shape out from the panel to the canvas and resize it with the shape handles.

Choose shape presets and place them on the Neo 3D canvas to start building the 3D scene.

Start the 3D scene by adding preset shapes to the Neo 3D canvas.

Change the 3D model perspective with the view controls. Rotate, zoom in or out, and pan across the model to inspect it from different viewpoints and angles.

Pan, Zoom, and Orbit controls help navigate the 3D object, inspect details, and understand its space.

Use Pan, Zoom, and Orbit to move through the 3D view, examine details, and read the spatial layout.

Edit the shape with the 3D shape controls.

A. Edge beveling: smooths or softens the shape edges. B. Depth control: changes depth. C. Rotation control: turns the shape. D. Axis position control: shifts placement by axis. E. Manipulation of a model's position: moves the model. F. Scaling gizmo: resizes the 3D model on the X axis, Y axis, or Z axis. G. Rotation gizmo: rotates the model around the X axis, Y axis, or Z axis.

For further shape edits, choose Edit shape; for example, you can adjust scaling along a specific axis or soften a shape's edges.

With the shape selected, Properties lets you change these settings:

- Appearance: controls the material color applied to the 3D shape.
- Transform: changes Size (Width, Height, and Depth), Position (X, Y, and Z axis), and Rotation (X, Y, and Z axis).
- Combine: blends and combines shapes with available blending methods. For additional combining and blending techniques, use Project Neo (beta).

Change the selected 3D object's appearance and position to improve the look and place it where needed.

Adjust placement and appearance for the selected 3D object until it fits the scene visually.

After adding the 3D shapes, switch to View 3D scene only mode and choose the Environment icon to adjust lighting and shadows.

- Light Rotation: changes the light angle and direction, which moves shadows and alters how objects are illuminated in the 3D scene.
- Light Height: sets the light higher or lower, changing whether the scene is lit more from above or below.
- Shadow Distance: defines the maximum scene distance at which shadows appear.
- Floor height: sets the ground height in 3D space. Changing that height can alter the floor shadow angle.

Tune lighting and shadows so the scene has a more finished appearance.

Use the lighting and shadow controls to make the scene look more polished.

When the 3D scene is ready, choose the Adobe Firefly icon in the right panel to open the image generation controls. These controls are available:

- Content type: set Content type to Art for illustrative variations or Photo for realistic ones. You can also keep Auto, allowing Firefly to choose the content type that best fits your text prompt.
- Scene reference: use the 3D shape strength slider to determine how closely the generated image follows the 3D shapes in your scene. Use the Color strength slider to set how strongly the result keeps to the colors in your 3D scene. Higher values make the generated image colors match the scene colors more closely.
- Style reference: choose Upload image and browse for a reference image on your device. Adjust the Visual intensity slider to change the strength of the photo's visual attributes, and use the Strength slider to set adherence to the reference image while generating the image variations.
- Style effects: choose from style effects, including art movements and techniques, to guide the generated image variations.

Image generation controls let you tailor the variations toward the result you have in mind.

Adjust the generation controls to make the image variations better match your intended direction.

Choose the aspect ratio from these options:

- Landscape 4:3
- Portrait 3:4
- Square 1:1
- Widescreen 16:9

The chosen aspect ratio determines the dimensions used for generated image variations.

Set an aspect ratio to control the output dimensions for the generated variations.

Type a text prompt, then choose Generate to create image variations.

Firefly generates image variations from the 3D scene, and you can choose one to download.

To create another variation set from a different angle or perspective, use Pan and Orbit, then choose Generate.

The regenerated variation set reflects the updated 3D scene.

Newly regenerated variations align with the changed scene view.

Point to the generated image variations and choose Download to save the generated image.

Download saves the selected image from the set of generated variations.

Choose Download when you want to save one generated variation.

(Optional) Choose Parallel or Perspective Camera for different scene viewing and rendering styles. With Parallel, object size stays the same no matter how far the object is from the camera. With Perspective, distant objects appear smaller.

All image generations from the current browser session can be viewed in the History strip. To enable it, choose the icon next to Generate.
