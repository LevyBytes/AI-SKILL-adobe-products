# Unlimited generations (Non-promotional)

Every Firefly and Creative Credit plan includes unlimited generations for standard features as part of the plan. Access to these features remains available during an active promotion and after it ends.

Unlimited standard features are:

- Firefly Image 4
- Firefly Image 3
- Generative Fill
- Generative Erase
- Generative Expand
- Remove Background
- Upscale

Using these features does not require additional credits, and unlimited-generation access remains unchanged after a promotional period ends.
