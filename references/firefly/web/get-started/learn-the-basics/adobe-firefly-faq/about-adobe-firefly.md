# About Adobe Firefly

Adobe Firefly is a standalone web app at firefly.adobe.com. It uses generative AI to give people additional ways to brainstorm, make content, and communicate, while also improving creative workflows. Beyond the Firefly website, Adobe provides the wider Firefly family of creative generative AI models, plus Firefly-powered features in Adobe flagship apps and Adobe Stock.

Firefly extends the technology Adobe has built over 40 years, with the idea that people should be able to bring imagined concepts into the world accurately.

Adobe works to keep Firefly smooth to use, but an account may be restricted when activity does not comply with guidelines, policies, or terms. Firefly feature use requires that you:

- Use a stable Internet connection.
- Use an Adobe ID.
- Have an active entitlement to Adobe Genuine software that approves Firefly-powered feature use within Creative Cloud apps.
- Comply with Adobe's generative AI user guidelines.
- Be located where Adobe Firefly is available. Adobe Firefly is not available in Russia, Belarus, and China. Adobe services and products are also unavailable in Cuba, Iran, North Korea, Syria, Crimea, and the territories referred to as the Donetsk and Luhansk People's Republics.

If questions remain and you believe your usage complies with those guidelines, contact us.

Firefly's accessibility approach follows the Web Content Accessibility Guidelines, abbreviated WCAG, at 2.1 Level A and Level AA. Firefly supports accessibility features including keyboard navigation, screen reader use, color contrast, and forms.

- Keyboard: Firefly supports Tab for moving between user interface controls, Space or Enter for activating buttons and links, arrow keys for moving between options, and Space for selecting options.
- Operating system accessibility: Firefly supplies operating-system user interface information so assistive technologies can interact with it, including VoiceOver on macOS and NVDA on Windows.
- Color contrast: Firefly's interface targets WCAG 2.1 AA color contrast guidelines.
- Forms: Forms in Firefly do not have error states.

Images displayed in Firefly inspiration streams are pre-cached samples and are not unique per user. Viewing samples does not spend generative credits, but credits are used if you perform an action that generates more images, such as selecting Refresh.
