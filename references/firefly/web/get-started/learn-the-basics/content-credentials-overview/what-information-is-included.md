# What information is included?

Content Credentials that Adobe Firefly applies automatically to generated assets always contain these non-personal details:

- Output thumbnail: a Firefly website visual preview for assets made with Text to image.
- Issuer: Adobe Inc., which issues the Content Credential.
- Date: the issue date for the Content Credential.
- App or device used: the Adobe software application or hardware device that generated the asset.
- AI tool used: the specific Adobe generative AI tool involved.
- Actions: broad creation, editing, and processing activity used to make the asset. For assets generated with Adobe Firefly features, the entries are limited to Created or Other edits.

If you have not chosen to add more information through Content Credentials in Photoshop, Lightroom, or Content Authenticity, nothing else is added.
