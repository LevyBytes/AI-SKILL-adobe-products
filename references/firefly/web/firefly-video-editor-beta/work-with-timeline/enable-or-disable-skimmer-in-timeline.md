# Enable or disable skimmer in timeline

Enable the skimmer tool so hovering the mouse can instantly preview any timeline area.

In Firefly video editor, the skimmer tool can preview timeline areas quickly when the mouse hovers over them. Rather than moving the playhead, skimming shows the frame under the cursor through a hover-to-preview interaction. If exact control is preferred, skimming can be disabled and the playhead can be used for quick previews.
