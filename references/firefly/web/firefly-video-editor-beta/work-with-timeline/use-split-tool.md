# Use split tool

Cut clips with the Split tool at the exact point you choose in the Firefly video editor's timeline.

The Split tool can cut clips, remove sections that are not needed, improve pacing, rearrange scenes, apply effects to chosen segments, and synchronize audio with visuals. Individual sections can also be moved, duplicated, or deleted, which makes editing more efficient and preserves full creative control.

Video, image, and text layers on the timeline can be separated with the Split tool.

The Split tool separates video, image, and text layers on the timeline. Before you begin:

Create a new project, and if media files are available, add them to the timeline.

Find the timeline point where the split should occur. Use Zoom in to magnify the timeline for more precise editing.

Above the timeline, choose the Split tool. The cursor changes to a split one,

To start adding splits to a video, image, or text layer on the timeline, select the Split tool above the timeline.

Use the Split tool above the timeline to start creating splits in video, image, or text timeline layers.

Move the cursor along the timeline and use the skimmer to preview frames. When the exact split point is located, select it to create the split.

Move the cursor with the skimmer along the timeline to find the exact point where the split should be created.

Use the skimmer by moving the cursor along the timeline until you locate the precise point for the split. Tip

Press S on your keyboard to activate the Split tool quickly. Learn more about keyboard shortcuts in Firefly video editor.

This method can create multiple splits, and it works not only for video but also for audio and text layers in the timeline.

In the timeline, the split media files can be handled as separate elements for editing.
