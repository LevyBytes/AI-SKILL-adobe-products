# Use snap mode

Enable automatic snapping for clips, images, text elements, and the playhead as they are dragged to the nearest timeline marker.

When editing video, keeping clips, images, text elements, and the playhead snapped to the nearest timeline marker while dragging helps maintain alignment. It prevents tiny gaps between timeline layers and reduces accidental clip overlaps.

Snap mode provides this snapping behavior for video elements, helping them attach to the nearest timeline point for easier precise placement.

Upload the media files, then place them on the timeline.

To turn on Snap mode, select the Snap icon below the preview panel. You can also open the upper-left Menu and choose Timeline > Snap mode.
