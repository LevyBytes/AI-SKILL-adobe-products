# Add text to the timeline

Add text layers to a video timeline while working in Firefly video editor.

Adding text means creating and placing elements such as titles, captions, or labels. After you enter the text, it becomes a timeline layer. Like other assets, the layer can be moved, trimmed, or stretched, giving you control over when and where text appears in the video.

Before you begin:

Create a new project, and place any needed media files on the timeline.

From the Video editor page, open the Text panel with the Text icon.

In the Text panel, choose Add text so a text box appears in the preview panel.

To begin adding text to the video, open the Text panel with the Text icon.

Move the pointer over the text box border until the four-way arrow cursor appears. Drag with that cursor to reposition the text box, or use the resize handles to change its size.

Hover over the text box to reveal controls for moving and resizing it.

Use the Properties panel to update text properties, including font, size, color, and alignment.

The Properties panel puts text style, alignment, color, and related settings in one place.

The text layer can be edited, repositioned, trimmed, and adjusted like any other clip.

Choose the Text layer in the panel to move it on the timeline.

Tip

You can also use Menu > Clip > Add text to add a text layer in the timeline.
