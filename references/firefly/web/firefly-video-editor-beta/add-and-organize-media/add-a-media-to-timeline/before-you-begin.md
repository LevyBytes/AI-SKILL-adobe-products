# Before you begin

Choose the media assets you plan to use and create a project.

On the Video Editor page, choose Select files to upload media from your device, Adobe cloud storage, or Adobe Stock.

Upload files from a local device or from Adobe Stock.

After upload, the media is added to the timeline automatically.

As another path, use the Your media icon in the left sidebar to open the Your media panel, then choose Select files and bring in media from a local device, Adobe cloud storage, or Adobe Stock.

The Your media panel adds files to the project before you place them on the timeline.

After media is in the Your media panel, drag and drop it onto the timeline, or right-click for the context menu and choose:

- Add to end of main track: places image and video files at the end of an existing timeline, or creates a new timeline when none exists.
- Add to playhead: places audio files at the playhead as the main audio track when no audio is already present. If the timeline already contains an audio clip, the file goes onto a new track.
- Add to timeline: places audio files at the playhead in the timeline, while video or image files go at the end of the main track.

Rename changes a media file's name, and Delete removes it from the project.

To bring more media files into the timeline, use the Add icon in the Your media panel and choose one of these sources:

- Select Your device to upload files from your device.
- Choose Adobe cloud storage for files that were previously created or used.
- Choose Adobe Stock for free or licensed stock files.

After the files are added, drag and drop them onto the timeline.

The Add option in the Your media panel brings new media files into the project before they move to the timeline.

Tip

You can also generate new videos inside the editor with the Firefly Video model, using customizable controls such as resolution, aspect ratio, keyframe images, style presets, and camera angle.
