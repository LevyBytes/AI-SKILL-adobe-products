# Can't generate videos in Firefly video editor

Use these fixes when video generation is not working in Firefly video editor.

Problems generating video in Firefly video editor are usually tied to missing settings, account access limits, low credits, or short-term service interruptions.

You might see any of these conditions:

- The Generate button is disabled
- Choosing Generate has no effect
- Generated videos are missing
- Errors mention insufficient credits
- Reference files do not upload
