# Stitching clips together using Adobe Media Encoder

When adding media to the queue, multiple files can be joined into one output file. To stitch media files together, use this workflow:

1. Select File > Add Source.
2. In the dialog, choose the assets to stitch and enable the Stitch clips together check box.
3. Click Open to place the stitched clip in the queue.

Other workflows can also create combined media files.

1. Open the media browser panel.
2. Choose the assets that should be stitched together.
3. Drag the selected assets into the queue and use the choices shown at the bottom of the Queue. Place the files on Drop here to stitch clips together.
4. Desktop assets can also be dragged in to create a stitched clip. The queue receives a new stitched clip.

Another method is:

1. Open the Media Browser panel.
2. Choose the assets that should be stitched together.
3. Right-click the assets and select Stitch Clips Together. The queue receives a new stitched clip.

The stitched clip name comes from the first clip in the alphabetically sorted source series. Since the name opens in edit mode, enter a custom value when needed. Press the Enter key to confirm it. A stitched clip can still be renamed later, provided it is not currently encoding, by clicking the source name in the Queue.

Note

Stitched clips honor In and Out Points set in media browser. After sources have been added to a stitched clip, their duration cannot be changed.
