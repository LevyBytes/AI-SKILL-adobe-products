# Create sidecar files for all media automatically

Open Media Encoder.

Select Window -> Watch Folders.

Choose the Add Folder icon, then choose Add Analysis Folder.

Pick a folder and click the Select Folder button.

Media Encoder scans the directory and creates sidecar files for media files that do not already have them. It keeps watching for changes and newly added media in that folder, creating sidecar files while leaving the media files where they are.

Note

Leave Media Encoder open so folder monitoring continues.

Auto generate and update sidecar files for new and existing media.

You can also create an Ingest Preset with Media Intelligence Analysis.
