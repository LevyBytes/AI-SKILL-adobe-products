# Export Settings dialog

| Result | Windows | Mac OS |
| --- | --- | --- |
| Moves playhead one frame earlier/later | Left/Right arrows | Left/Right arrows |
| Move playhead to the start/end frame | Home/End | Home/End |
| Set source range In Point to playhead's current position | I | I |
| Set source range Out Point to playhead's current position | O | O |
| Move playhead to the In Point | Q | Q |
| Move playhead to the Out Point | W | W |
| Zooms in frame preview | Ctrl++(plus) | Cmd++(plus) |
| Zooms out frame preview | Ctrl+- (minus) | Cmd+-(minus) |
| Exports preset as an EPR file | Alt+Click "Save Preset" button | Opt+Click "Save Preset" button |

Bit rate field in Mbps:

| Result | Windows | Mac OS |
| --- | --- | --- |
| Increase or decrease current value by 1 | Shift+Up/Down Arrows | Shift+Up/Down Arrows |
| Increase or decrease current value by .1 | Up and Down Arrows | Up and Down Arrows |
| Increase or decrease current value by .01 | Ctrl+Up/Down Arrows | Cmd+Up/Down Arrows |
| Increase or decrease current value by .001 | Ctrl+Alt+Up/Down Arrows | Cmd+Opt+Up/Down Arrows |
