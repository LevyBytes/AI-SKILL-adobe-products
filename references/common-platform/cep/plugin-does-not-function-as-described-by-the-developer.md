# Top 3 Rejection Reasons - _Plugin does not function as described by the developer._

- During testing, the review team checks all plugin functionality. Before submitting, verify that the plugin works as advertised and that every feature functions properly.

- Silent failures: When a plugin user tries an unsupported function, the plugin must not fail silently. Show a dialog explaining that the action/functionality is unsupported so users understand the limitation and do not repeat the same action.

- The plugin must be compatible with every Adobe product, product version, and operating system listed in the "Product Compatibility Information" section of the listing.
