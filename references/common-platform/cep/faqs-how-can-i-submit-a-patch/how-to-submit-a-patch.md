# How to submit a patch

1. Sign in to the [Exchange Developer Portal.](https://partners.adobe.com/exchangeprogram/creativecloud)

2. Open the Dashboard.

3. Choose your extension or listing by name; this step applies only after the listing has been published.

4. Use the "More" dropdown button in the upper-right corner and select "Create New Patch".

5. Then open the Patch Details Tab.

6. ZIP-based extensions allow the version number to be edited. ZXP-based extensions read version numbers automatically from the manifest file and do not allow manual changes.

7. To prevent immediate publication after approval, clear "Publish this patch immediately upon approval". With that option off, the approved patch is placed in the "Not Published" section of Dashboard, and you must publish it yourself before it appears in the Creative Cloud Exchange Marketplace.

8. Scroll down and click submit.

9. After submission, the Exchange Portal displays a success message for the requested changes, and confirmation email is sent from noreply@salesforce.com and ccintegrationsreview@adobe.com.
