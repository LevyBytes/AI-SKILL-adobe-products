# How to submit a patch for a rejected submission:

1. When the previous patch submission was rejected, open the "Not Published" section and select the most recent rejected version.

2. Click the "Edit" button and choose the "Patch Details" tab.

3. Replace the file uploaded earlier with the new file.

4. Patch uploads must use the same file type as the parent file. For example, if the initial submission used a ZXP file, the patch submission must also upload a ZXP file.

If metadata or patch creation causes problems, contact the Review Team at ccintrev@adobe.com. Also review the [Exchange FAQs (Frequently Asked Questions).](https://partners.adobe.com/exchangeprogram/creativecloud/support/faq.html)
