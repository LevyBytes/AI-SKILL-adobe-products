# Dialog Size based on Screen Size

CEP dialog dimensions may be declared as percentages of the screen size. Example:

XML excerpt for the documented CEP edition; merge at the described location. Comments mark omitted settings.

```xml
<UI>
    <Type>Modeless</Type>                  
    <!-- Other manifest settings omitted. -->
    <Geometry>
        <ScreenPercentage>
            <Height>50%</Height>
            <Width>50%</Width>
        </ScreenPercentage>
        <!-- Other manifest settings omitted. -->
    </Geometry>
</UI>
```
