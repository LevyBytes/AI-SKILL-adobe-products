# User Interface

1. Plugin UI elements must not overlap or truncate.

2. Plugin content must comply with [Adobe Branding Guidelines](https://partners.adobe.com/content/dam/tep_assets/public/public_1/documents/Adobe-Creative-Cloud-Developer-Brand-Guide.pdf).

3. Nothing in the content should be clipped.

4. UI content must wrap or adjust as needed for the available UI width.

5. When content does not fit on screen, the plugin UI must scroll.
