# Set up the sample extension

Use the following steps to install and start the sample extension for this guide:

1. Copy the complete linked example into a `com.cep.export` directory under your CEP extensions folder. See the Cookbook’s [extension folders](https://github.com/Adobe-CEP/CEP-Resources/blob/master/CEP_8.x/Documentation/CEP%208.0%20HTML%20Extension%20Cookbook.md#extension-folders) for the platform-specific location.

1. Copy `CSInterface.js` from the [CEP resources repository](https://github.com/Adobe-CEP/CEP-Resources/) into `./com.cep.export/client/js/lib/CSInterface.js`
