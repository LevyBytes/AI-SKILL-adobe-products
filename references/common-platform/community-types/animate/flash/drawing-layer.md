# Flash.drawingLayer

Community declaration reference: Animate/22.0.

Extensible tools use this drawingLayer object for temporary drawing during drag gestures, such as a selection marquee.

```typescript
declare class Flash {
    drawingLayer: DrawingLayer
}
```
