# Flash.xmlui

Community declaration reference: Animate/22.0.

XMLUI object used to read and write XMLUI properties in a XMLUI dialog box and to accept or cancel the dialog box from code.

```typescript
declare class Flash {
    readonly xmlui: XMLUI
}
```
