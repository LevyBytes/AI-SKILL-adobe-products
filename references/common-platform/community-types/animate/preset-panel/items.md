# PresetPanel.items

Community declaration reference: Animate/22.0.

PresetItem array for entries in the Motion Presets panel (see presetItem object). Each array entry is either a folder or a preset.

```typescript
declare class PresetPanel {
    items: PresetItem[]
}
```
