# Frame.labelType

Community declaration reference: Animate/22.0.

String describing which kind of Frame name is in use. Acceptable values are "none", "name", "comment", and "anchor". Assigning "none" removes the frame.name property.

```typescript
declare class Frame {
    labelType: string
}
```
