# Frame.soundLoop

Community declaration reference: Animate/22.0.

Integer playback count for a sound attached directly to a frame (frame.soundLibraryItem). To use this value, set frame.soundLoopMode to "repeat".

```typescript
declare class Frame {
    soundLoop: number
}
```
