# Stroke.dotSpace

Community declaration reference: Animate/22.0.

Dot spacing for a dotted line, stored as an integer. This member is available only when stroke.style is dotted. See stroke.style.

```typescript
declare class Stroke {
    dotSpace: number
}
```
