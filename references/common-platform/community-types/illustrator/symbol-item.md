# SymbolItem

Community declaration reference: Illustrator/2022.

Instance object for a Symbol.

```typescript
declare class SymbolItem extends PageItem {
    /**
    - Symbol used to create this symbol item.
      */
      symbol: Symbol
    /**

    - Disconnect the link to the symbol.
      */
      breakLink(): void
}
```
