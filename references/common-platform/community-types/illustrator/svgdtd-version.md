# SVGDTDVersion

Community declaration reference: Illustrator/2022.

SVG DTD version.

```typescript
declare enum SVGDTDVersion {
    /**
    - DTD is SVG 1.0.
      */
      SVG1_0 = 1,
    /**

    - DTD is SVG 1.1.
      */
      SVG1_1 = 2,
    /**

    - DTD is SVG Basic 1.1.
      */
      SVGBASIC1_1 = 5,
    /**

    - DTD is SVG Tiny 1.1.
      */
      SVGTINY1_1 = 3,
    /**

    - DTD is SVG Tiny 1.1 Plus.
      */
      SVGTINY1_1PLUS = 4,
    /**

    - DTD is SVG Tiny 1.2.
      */
      SVGTINY1_2 = 6,
}
```
