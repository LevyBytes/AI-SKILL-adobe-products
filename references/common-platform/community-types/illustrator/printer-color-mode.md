# PrinterColorMode

Community declaration reference: Illustrator/2022.

Printer color mode.

```typescript
declare enum PrinterColorMode {
    /**
    - Printer is black and white.
      */
      BLACKANDWHITEPRINTER = 2,
    /**

    - Printer uses color.
      */
      COLORPRINTER = 0,
    /**

    - Printer uses grayscale.
      */
      GRAYSCALEPRINTER = 1,
}
```
