# InkPrintStatus

Community declaration reference: Illustrator/2022.

Ink print status.

```typescript
declare enum InkPrintStatus {
    /**
    - Converts to process color while printing.
      */
      CONVERTINK = 2,
    /**

    - Disables the ink while printing.
      */
      DISABLEINK = 0,
    /**

    - Enables the ink while printing.
      */
      ENABLEINK = 1,
}
```
