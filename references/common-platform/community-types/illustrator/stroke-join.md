# StrokeJoin

Community declaration reference: Illustrator/2022.

Stroke join style.

```typescript
declare enum StrokeJoin {
    /**
    - Joints use a bevel.
      */
      BEVELENDJOIN = 3,
    /**

    - Joints use a miter.
      */
      MITERENDJOIN = 1,
    /**

    - Joints are rounded.
      */
      ROUNDENDJOIN = 2,
}
```
