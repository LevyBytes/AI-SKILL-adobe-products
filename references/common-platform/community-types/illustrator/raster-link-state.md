# RasterLinkState

Community declaration reference: Illustrator/2022.

State of a raster link.

```typescript
declare enum RasterLinkState {
    /**
    - Image data comes from the linked file.
      */
      DATAFROMFILE = 2,
    /**

    - Image data has changed.
      */
      DATAMODIFIED = 3,
    /**

    - Image data is unset.
      */
      NODATA = 1,
}
```
