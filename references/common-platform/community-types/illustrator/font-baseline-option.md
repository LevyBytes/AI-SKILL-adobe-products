# FontBaselineOption

Community declaration reference: Illustrator/2022.

Font baseline option.

```typescript
declare enum FontBaselineOption {
    /**
    - Baseline is normal.
      */
      NORMALBASELINE = 0,
    /**

    - Baseline is fauxed subscript.
      */
      SUBSCRIPT = 2,
    /**

    - Baseline is fauxed superscript.
      */
      SUPERSCRIPT = 1,
}
```
