# StrokeCap

Community declaration reference: Illustrator/2022.

Stroke cap style.

```typescript
declare enum StrokeCap {
    /**
    - Cap style is butted.
      */
      BUTTENDCAP = 1,
    /**

    - Cap style is projecting.
      */
      PROJECTINGENDCAP = 3,
    /**

    - Cap style is rounded.
      */
      ROUNDENDCAP = 2,
}
```
