# ColorModel

Community declaration reference: Illustrator/2022.

Custom color color model.

```typescript
declare enum ColorModel {
    /**
    - Process color using mixed ink.
      */
      PROCESS = 1,
    /**

    - Registration color printed in all separations.
      */
      REGISTRATION = 0,
    /**

    - Spot color using separate ink.
      */
      SPOT = 2,
}
```
