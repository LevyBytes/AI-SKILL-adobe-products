# DocumentPreviewMode

Community declaration reference: Illustrator/2022.

Preview modes selectable for a new document.

```typescript
declare enum DocumentPreviewMode {
    /**
    - Uses Default Preview mode.
      */
      DefaultPreview = 1,
    /**

    - Uses Overprint Preview Mode.
      */
      OverprintPreview = 3,
    /**

    - Uses Pixel Preview mode.
      */
      PixelPreview = 2,
}
```
