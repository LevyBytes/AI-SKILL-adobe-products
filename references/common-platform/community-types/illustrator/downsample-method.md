# DownsampleMethod

Community declaration reference: Illustrator/2022.

Resampling method.

```typescript
declare enum DownsampleMethod {
    /**
    - Uses Average Downsampling.
      */
      AVERAGEDOWNSAMPLE = 1,
    /**

    - Uses Bicubic Downsampling.
      */
      BICUBICDOWNSAMPLE = 3,
    /**

    - Uses Downsampling.
      */
      NODOWNSAMPLE = 0,
    /**

    - Uses Subsampling.
      */
      SUBSAMPLE = 2,
}
```
