# DocumentColorSpace

Community declaration reference: Illustrator/2022.

Document color-space options.

```typescript
declare enum DocumentColorSpace {
    /**
    - Document color space set to CMYK.
      */
      CMYK = 2,
    /**

    - Document color space set to RGB.
      */
      RGB = 1,
}
```
