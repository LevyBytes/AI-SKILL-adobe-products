# Case

Community declaration reference: Photoshop/2015.5.

Capitalization option.

```typescript
declare enum Case {
    /**
    - Sets all letters to uppercase.
      */
      ALLCAPS = 2,
    /**

    - Allows both uppercase and lowercase letters.
      */
      NORMAL = 1,
    /**

    - Formats lowercase letters as small caps.
      */
      SMALLCAPS = 3,
}
```
