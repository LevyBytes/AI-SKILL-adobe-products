# GalleryFontType

Community declaration reference: Photoshop/2015.5.

Font options for text used in web photo galleries.

```typescript
declare enum GalleryFontType {
    /**
    - Arial typeface.
      */
      ARIAL = 1,
    /**

    - Courier New typeface.
      */
      COURIERNEW = 2,
    /**

    - Helvetica typeface.
      */
      HELVETICA = 3,
    /**

    - Times New Roman typeface.
      */
      TIMESNEWROMAN = 4,
}
```
