# DescValueType

Community declaration reference: Photoshop/2015.5.

Identifies an object's descriptor value type.

```typescript
declare enum DescValueType {
    /**
    - Alias value.
      */
      ALIASTYPE = 11,
    /**

    - Boolean value.
      */
      BOOLEANTYPE = 5,
    /**

    - Class value.
      */
      CLASSTYPE = 10,
    /**

    - Double value.
      */
      DOUBLETYPE = 2,
    /**

    - Enumeration value.
      */
      ENUMERATEDTYPE = 8,
    /**

    - Integer value.
      */
      INTEGERTYPE = 1,
    /**

    - */
      LARGEINTEGERTYPE = 13,
    /**

    - Action list value.
      */
      LISTTYPE = 6,
    /**

    - Object value.
      */
      OBJECTTYPE = 7,
    /**

    - Raw value.
      */
      RAWTYPE = 12,
    /**

    - Reference value.
      */
      REFERENCETYPE = 9,
    /**

    - String value.
      */
      STRINGTYPE = 4,
    /**

    - Unit value stored as a double.
      */
      UNITDOUBLE = 3,
}
```
