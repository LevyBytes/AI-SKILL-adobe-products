# Urgency

Community declaration reference: Photoshop/2015.5.

Editorial urgency value for the artwork.

```typescript
declare enum Urgency {
    /**
    - Level 4 (fourth highest)
      */
      FOUR = 4,
    /**

    - Top urgency level.
      */
      HIGH = 8,
    /**

    - Low urgency level.
      */
      LOW = 1,
    /**

    - Urgency disabled.
      */
      NONE = 0,
    /**

    - Standard priority value.
      */
      NORMAL = 5,
    /**

    - Second from the low end at level 7.
      */
      SEVEN = 7,
    /**

    - Third from the low end at level 6.
      */
      SIX = 6,
    /**

    - Third from the high end at level 3.
      */
      THREE = 3,
    /**

    - Second from the high end at level 2.
      */
      TWO = 2,
}
```
