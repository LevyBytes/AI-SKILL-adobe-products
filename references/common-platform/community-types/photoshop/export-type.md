# ExportType

Community declaration reference: Photoshop/2015.5.

Selects which export option set is used.

```typescript
declare enum ExportType {
    /**
    - Writes Photoshop paths as Adobe Illustrator files.
      */
      ILLUSTRATORPATHS = 1,
    /**

    - Applies the save for web export settings.
      */
      SAVEFORWEB = 2,
}
```
