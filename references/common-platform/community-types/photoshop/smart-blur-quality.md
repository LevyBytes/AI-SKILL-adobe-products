# SmartBlurQuality

Community declaration reference: Photoshop/2015.5.

Sets smart blur quality.

```typescript
declare enum SmartBlurQuality {
    /**
    - High-quality processing.
      */
      HIGH = 3,
    /**

    - Low-quality processing.
      */
      LOW = 1,
    /**

    - Medium-quality processing.
      */
      MEDIUM = 2,
}
```
