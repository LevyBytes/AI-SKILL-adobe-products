# GridSize

Community declaration reference: Photoshop/2015.5.

Grid-square size.

```typescript
declare enum GridSize {
    /**
    - Uses large grid squares.
      */
      LARGE = 4,
    /**

    - Uses medium grid squares.
      */
      MEDIUM = 3,
    /**

    - Displays no grid.
      */
      NONE = 1,
    /**

    - Uses small grid squares.
      */
      SMALL = 2,
}
```
