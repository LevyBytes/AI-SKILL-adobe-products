# AnchorPosition

Community declaration reference: Photoshop/2015.5.

Transformation anchor point for the object.

```typescript
declare enum AnchorPosition {
    /**
    - Bottom-edge center point of the object.
      */
      BOTTOMCENTER = 8,
    /**

    - Lower-left object corner.
      */
      BOTTOMLEFT = 7,
    /**

    - Lower-right object corner.
      */
      BOTTOMRIGHT = 9,
    /**

    - Object center point.
      */
      MIDDLECENTER = 5,
    /**

    - Center point along the object's left side.
      */
      MIDDLELEFT = 4,
    /**

    - Center point along the object's right side.
      */
      MIDDLERIGHT = 6,
    /**

    - Top-edge center point of the object.
      */
      TOPCENTER = 2,
    /**

    - Upper-left object corner.
      */
      TOPLEFT = 1,
    /**

    - Upper-right object corner.
      */
      TOPRIGHT = 3,
}
```
