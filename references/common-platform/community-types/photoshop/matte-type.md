# MatteType

Community declaration reference: Photoshop/2015.5.

Selects the matte color.

```typescript
declare enum MatteType {
    /**
    - Uses the current background color.
      */
      BACKGROUND = 3,
    /**

    - Black matte.
      */
      BLACK = 5,
    /**

    - Uses the current foreground color.
      */
      FOREGROUND = 2,
    /**

    - Gray matte.
      */
      NETSCAPE = 7,
    /**

    - No matte color.
      */
      NONE = 1,
    /**

    - 50% gray matte.
      */
      SEMIGRAY = 6,
    /**

    - White matte.
      */
      WHITE = 4,
}
```
