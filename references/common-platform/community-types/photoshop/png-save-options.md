# PNGSaveOptions

Community declaration reference: Photoshop/2015.5.

Save settings for a PNG-format document.

```typescript
declare class PNGSaveOptions {
    /**
    - Compression applied to the image.
      */
      compression: number
    /**

    - When true, rows are interlaced.
      */
      interlaced: boolean
}
```
