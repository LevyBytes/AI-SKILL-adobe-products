# ArtLayer.merge

Community declaration reference: Photoshop/2015.5.

Merges this layer into the one below it, removes this layer, and returns the ArtLayer receiving the merge.

```typescript
declare class ArtLayer extends Layer {
    merge(): ArtLayer
}
```
