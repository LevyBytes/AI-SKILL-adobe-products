# PhotoCDSize

Community declaration reference: Photoshop/2015.5.

Defines the image pixel dimensions.

```typescript
declare enum PhotoCDSize {
    /**
    - 1024x1536 image size.
      */
      EXTRALARGE = 5,
    /**

    - 512x768 image size.
      */
      LARGE = 4,
    /**

    - 2048x3072 image size.
      */
      MAXIMUM = 6,
    /**

    - 256x384 image size.
      */
      MEDIUM = 3,
    /**

    - 64x96 image size.
      */
      MINIMUM = 1,
    /**

    - 128x192 image size.
      */
      SMALL = 2,
}
```
