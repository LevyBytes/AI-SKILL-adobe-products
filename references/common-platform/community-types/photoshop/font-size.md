# FontSize

Community declaration reference: Photoshop/2015.5.

Font sizing used in panels and dialogs.

```typescript
declare enum FontSize {
    /**
    - Large size setting.
      */
      LARGE = 3,
    /**

    - Medium size setting.
      */
      MEDIUM = 2,
    /**

    - Small size setting.
      */
      SMALL = 1,
}
```
