# DocumentFill

Community declaration reference: Photoshop/2015.5.

Fill type for the document window.

```typescript
declare enum DocumentFill {
    /**
    - Background color currently shown in the toolbox.
      */
      BACKGROUNDCOLOR = 2,
    /**

    - Transparent fill.
      */
      TRANSPARENT = 3,
    /**

    - White fill.
      */
      WHITE = 1,
}
```
