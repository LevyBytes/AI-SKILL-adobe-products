# TextDocument.paragraphCharacterIndexesAt

Community declaration reference: AfterEffects/26.0.

Finds start/end character indexes for the paragraph at characterIndex.

```typescript
declare class TextDocument {
    paragraphCharacterIndexesAt(characterIndex: number): { start: number; end: number }
}
```
