# ViewOptions

Community declaration reference: AfterEffects/26.0.

```typescript
declare class ViewOptions {
    /* Channels menu state */
    channels: ChannelType
    /* True when checkerboards are enabled */
    checkerboards: boolean
    /* Current exposure value */
    exposure: number
    /* Fast Previews menu state */
    fastPreview: FastPreviewType
    /* True when viewer guides are locked. */
    guidesLocked: boolean
    /* True when dragged layers snap to guides in the viewer. */
    guidesSnap: boolean
    /* True when guides are visible in the viewer. */
    guidesVisibility: boolean
    /* True when rulers appear in the viewer. */
    rulers: boolean
    /* Viewer Zoom value */
    zoom: number
}
```
