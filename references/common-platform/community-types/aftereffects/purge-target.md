# PurgeTarget

Community declaration reference: AfterEffects/26.0.

```typescript
declare enum PurgeTarget {
    /* Clears every item After Effects has cached to physical memory. */
    ALL_CACHES = 1412,
    /* Clears all saved image data. */
    IMAGE_CACHES = 1415,
    /* Clears cached composition/layer snapshot data. */
    SNAPSHOT_CACHES = 1414,
    /* Clears data stored in the undo cache. */
    UNDO_CACHES = 1413,
    /* Clears every After Effects RAM cache */
    ALL_MEMORY_CACHES = 1416,
}
```
