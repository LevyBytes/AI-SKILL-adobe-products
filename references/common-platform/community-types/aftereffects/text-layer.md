# TextLayer

Community declaration reference: AfterEffects/26.0.

TextLayer represents a composition text layer; create it with LayerCollection.addText.

```typescript
declare class TextLayer extends AVLayer {
    readonly source: null
    readonly text: _TextProperties
    readonly sourceText: TextDocumentProperty
}
```
