# AVLayer.removeTrackMatte

Community declaration reference: AfterEffects/26.0.

Clears this layer's track matte while keeping the TrackMatteType value; setTrackMatteType() can also remove a matte.

```typescript
declare class AVLayer extends Layer {
    removeTrackMatte(): void
}
```
