# Project named and indexed items

Community declaration reference: AfterEffects/26.0.

```typescript
declare class Project {
    /* Gets a project item. */
    item(index: number): _ItemClasses
    /* Gets an item through its Item ID */
    itemByID(id: number): _ItemClasses
}
```
