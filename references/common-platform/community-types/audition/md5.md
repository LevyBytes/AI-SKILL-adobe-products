# MD5

Community declaration reference: Audition/2018.

Compute an MD5 hash from audio data in a wave document, making comparison with a baseline straightforward.

```typescript
declare class MD5 {
    /**
    - */
      static __(): any
    /**

    -
    - @param wavedocument Compute an MD5 hash from audio data in a wave document.
      */
      static hash(wavedocument: WaveDocument): string
}
```
