# WaveDocument.saveAs

Community declaration reference: Audition/2018.

@param path
@param export_ Saves the document at the specified path. When parameter 'export' is true, performs an export. Returns true on success.

```typescript
declare class WaveDocument {
    saveAs(path: string, export_: boolean): boolean
}
```
