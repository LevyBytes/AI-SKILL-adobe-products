# Application.invokeCommand

Community declaration reference: Audition/2018.

@param command Invokes an application command by identifier string; the commands correspond to entries in the Keyboard Shortcuts dialog. Returns true when successful.

```typescript
declare class Application {
    invokeCommand(command: string): boolean
}
```
