# Text.dropcapDetail

Community declaration reference: InDesign/2023.

Glyph-outline drop-cap detail bits: 1 = left side bearing; 2 = descenders; 0x100,0x200,0x400 = Japanese frame grid.

```typescript
declare class Text {
    dropcapDetail: number
}
```
