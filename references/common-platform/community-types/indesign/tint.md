# Tint

Community declaration reference: InDesign/2023.

Tint swatch object.

```typescript
declare class Tint extends Color {
    /**
    - Base Color used by the tint.
      */
      readonly baseColor: Color
    /**

    - Base-color percentage for the tint. (Range: 0 to 100)
      */
      tintValue: number
}
```
