# ObjectStyle.setPositionAttributeState

Community declaration reference: InDesign/2023.

Sets the requested position attribute state to enabled or disabled
- `whichAttributes`: Position attributes to enable or disable.
- `attributeState`: State to assign; true enables the attributes and false disables them

```typescript
declare class ObjectStyle {
    setPositionAttributeState(whichAttributes: PositionAttributes, attributeState: boolean): boolean
}
```
