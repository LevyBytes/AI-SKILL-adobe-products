# PreviewTypes

Community declaration reference: InDesign/2023.

File-format choices for preview images.

```typescript
declare enum PreviewTypes {
    /**
    - Omits saving any preview image.
      */
      NONE = 1852796517,
    /**

    - Stores the preview as TIFF.
      */
      TIFF_PREVIEW = 1164997734,
}
```
