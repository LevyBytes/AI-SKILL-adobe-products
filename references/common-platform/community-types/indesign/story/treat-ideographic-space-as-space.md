# Story.treatIdeographicSpaceAsSpace

Community declaration reference: InDesign/2023.

When true, ideographic spaces do not wrap to the next line like text characters.

```typescript
declare class Story {
    treatIdeographicSpaceAsSpace: boolean
}
```
