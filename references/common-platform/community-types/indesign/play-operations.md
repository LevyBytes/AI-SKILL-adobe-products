# PlayOperations

Community declaration reference: InDesign/2023.

Playback operation choices.

```typescript
declare enum PlayOperations {
    /**
    - Puts playback on pause.
      */
      PAUSE = 1885435251,
    /**

    - Begins playback.
      */
      PLAY = 1886151033,
    /**

    - Continues playback after a pause.
      */
      RESUME = 1919251317,
    /**

    - Ends playback.
      */
      STOP = 1937010544,
    /**

    - Ends all playback (SWF only).
      */
      STOP_ALL = 1937010785,
}
```
