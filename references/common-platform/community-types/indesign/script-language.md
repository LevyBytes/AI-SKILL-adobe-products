# ScriptLanguage

Community declaration reference: InDesign/2023.

Language values for script execution.

```typescript
declare enum ScriptLanguage {
    /**
    - JavaScript language.
      */
      JAVASCRIPT = 1246973031,
    /**

    - No language is specified.
      */
      UNKNOWN = 1433299822,
    /**

    - UxpScript language.
      */
      UXPSCRIPT = 1431522407,
    /**

    - VBScript language.
      */
      VISUAL_BASIC = 1447185511,
}
```
