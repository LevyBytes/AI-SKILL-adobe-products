# Available policy management options

Select a policy in All tools > Protect a PDF > Manage security policies. Use these actions:

| Action | Effect | Availability |
| --- | --- | --- |
| Copy | Create another policy using the selected policy's settings. | All policy types. |
| Edit | Local user policy: changes affect documents protected after the edit. Server user policy: change permissions and other options. | Unavailable for organizational policies. |
| Delete | Remove the policy from the list. | Usually unavailable for organizational policies. |
| Favorite | Toggle a star for easier retrieval; several policies can be starred. | All policy types. |

Changing an organizational policy on the server requires administrator access to Adobe Experience Manager - Forms Server (Document Security).

For the dialog and confirmation steps, follow [Manage security policies](manage-security-policies.md).
