# Copy, edit, or delete security policies

Use a security policy to reuse document protection settings. Check that you have permission to manage it; organizational policies restrict which actions are available.

- Open [Manage security policies](copy-edit-or-delete-security-policies/manage-security-policies.md) for the dialog, selection and action steps.
- Check [Available policy management options](copy-edit-or-delete-security-policies/available-policy-management-options.md) for local versus server effects and organizational restrictions.
