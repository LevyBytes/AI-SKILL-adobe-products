# HTML conversion settings

- Default Encoding: pick the file text's input encoding from a list grouped by operating system and alphabet.

  - Always: sticks with the encoding you picked no matter what.
  - When Page Doesn’t specify Encoding: applies your encoding only where the HTML file leaves it undeclared.

- Language Specific Font Settings: tune the script, the font style, and the font size.

  - Force These Settings for All Pages. Leave this off and the default colors land only on pages that don't already define a color scheme.

- Embed multimedia content when possible: decide whether multimedia such as SWF files is turned off, embedded, or linked.
- Reference multimedia content by URL: switch this on to point at multimedia content by link rather than embedding it.
- Retain page background: holds onto the background colors and tiled images from the source page.
- Convert Images: brings the images into the PDF.
- Underline Links: draws underlines beneath text links.
- Expand Scrollable Blocks: makes sure scrollable regions appear fully opened out in the PDF.
