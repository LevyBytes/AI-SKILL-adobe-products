# Convert web pages to PDFs

Turn individual web pages, or whole websites, into PDFs while keeping control over their structure and contents.

A web page that's open in your browser can be captured as a PDF in one step using the Adobe Acrobat browser extension. The desktop version of Acrobat goes further, letting you grab full websites, decide how many page levels to pull in, and append pages to PDFs you already have.

With Acrobat running, choose Create over on the global toolbar.

On the page that comes up, pick Web page out of the left rail.

Type in the web page URL, or browse your way to an HTML file.

To set how many levels deep the capture should reach, tick the Capture multiple levels checkbox, then pick one of these:

- Get level(s) then type in how many levels you'd like captured.
- Get entire site grabs every level the website has.

When you're pulling several levels, rein in the scope with one or both of these:

- Stay on same path: restricts the grab to pages that sit beneath the URL you gave.
- Stay on same server: keeps outside domains out of it.

If you like, open Advanced settings to adjust the Web page conversion settings.

Select Create.

Note

Further pages can be queued while another is still converting, and each one joins the line automatically. The Download Status dialog box shows you whatever is still waiting.
