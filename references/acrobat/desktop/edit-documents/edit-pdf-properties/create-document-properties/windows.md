# Windows

Open Menu > Document properties.

When the dialog appears, switch to the Custom tab.

For a new property, fill in the Name and Value fields, then choose Add.

Adding your own document properties is how particular metadata gets attached to a PDF.

Defining fresh document properties gives you a way to embed specific metadata in a PDF.

To revise one, pick the property you'd like to change, adjust its name and value to suit you, and then choose OK.

Removing a property is a matter of selecting it and choosing Delete.

Choose OK.
