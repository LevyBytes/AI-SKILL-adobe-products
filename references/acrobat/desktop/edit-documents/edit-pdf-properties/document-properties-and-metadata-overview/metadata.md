# Metadata

Think of metadata as a rich layer of information riding along with a document — it reveals where the file came from, what it holds, and how it behaves. Because it powers more capable searching, the kinds of detail it carries break down into these groups:

- Baseline fields, for example. when the file was first created and when it was last changed
- Richer schema sets, among them Dublin Core and IPTC
- Metadata tied to a particular application
