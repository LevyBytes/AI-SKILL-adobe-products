# Remove headers and footers from multiple PDFs

Pick Go to Home view and pick See all tools.

Pick See all tools at the top-right corner to browse the whole set of features Acrobat offers and kick off new tasks with ease.

Pick Edit a PDF from the All tools tab.

Pick Header and footer > Remove.

Once the dialog box appears, pick Add files, and then pick the files you mean to change.

Pick OK.

Within the Output Options dialog box, name your folder and filename preferences, and then pick OK.

Note

Acrobat clears the headers and footers off every PDF you picked and saves them to the spot you named.
