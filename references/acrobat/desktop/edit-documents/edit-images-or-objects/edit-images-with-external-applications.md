# Edit images with external applications

See how to take images or graphics placed in Adobe Acrobat and edit them in outside apps such as Adobe Photoshop.

With your document open, click Edit on the global bar.

Pick the image you intend to edit.

Inside the Edit pane, click Edit using beneath ADJUST OBJECTS.

The Edit panel's tools let you open a PDF image in an outside program — say, Microsoft Paint — and edit it there.

Through the Edit panel controls, a picture from your PDF can be handed off to an external app like Microsoft Paint for editing.

From the menu, pick an image-editing program.

After the picture loads in the chosen program, apply your edits and save the result inside that external app.

Head back to Acrobat.

Your edits flow back automatically, refreshing the image inside the PDF.
