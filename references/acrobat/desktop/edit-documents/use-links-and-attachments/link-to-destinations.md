# Link to destinations

See how Adobe Acrobat lets you build links that drop users straight onto a specific spot within a PDF.

Select Edit from the global bar.

From the left pane under ADD CONTENT, select Link > Add or edit a link.

Drag out a rectangle on the page to mark where the link goes.

In the Create Link dialog box, select Go to a page view under Link Action. A link like this sends the reader straight to a chosen page or section of the document.

Pointing a link at a destination is how you route someone to an exact page or section in the file.

Select Next. A Create Go to View dialog box opens.

Scroll to whatever location or page you want the reader sent to and select Set link.
