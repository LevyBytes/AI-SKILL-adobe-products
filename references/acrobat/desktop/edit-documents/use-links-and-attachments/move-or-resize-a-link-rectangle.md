# Move or resize a link rectangle

See how Adobe Acrobat lets you reposition and resize the link rectangles inside a PDF.

Select Edit from the global bar.

From the left pane under ADD CONTENT, select More > Link > Add or edit a link.

Select the link rectangle you want move or resize.

Shifting a link rectangle is a matter of selecting it and dragging the rectangle wherever you want it.

To make a link rectangle bigger or smaller, grab a corner handle and drag until it's the size you need.

Click anywhere beyond the link rectangle to lock in the changes.
