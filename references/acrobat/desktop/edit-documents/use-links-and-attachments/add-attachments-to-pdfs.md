# Add attachments to PDFs

Find out how Adobe Acrobat lets you bundle files into a PDF as attachments.

A PDF can carry attached files such as images, PDFs, Word documents, Excel spreadsheets, and multimedia like audio or video. Relocate the PDF and its attachments travel along with it. Those attached files may themselves carry links back to the main document or across to other attachments.

Select Edit from the global bar.

In the right pane under ADD CONTENT, select More > Attach file.

When the dialog box appears, pick the file you'd like to attach and select Open.

To give the attachment a description, find it in the Attachments pane, right-click, and choose Edit Description.

Type in the description and select OK.
