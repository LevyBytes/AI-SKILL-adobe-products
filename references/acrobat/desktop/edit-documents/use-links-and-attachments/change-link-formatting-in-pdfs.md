# Change link formatting in PDFs

See how Adobe Acrobat lets you restyle the links in a PDF so they stand out or simply look better.

Select Edit from the global bar.

From the left pane under ADD CONTENT, select Link > Add or edit a link.

Right-click the link, select Properties and then select the Appearance tab.

Turning on the locked option in the appearance tab stops anyone else from altering how the link is formatted.

That locked setting on the appearance tab is what keeps other users from reformatting the link.

Once the Link Properties dialog box appears, adjust whichever of these settings you need:

- Color: choose the color of the link's border.
- Link Type: pick either Visible Rectangle or Invisible Rectangle.
- Line Style: pick the Solid, Dashed, or Underline option.
- Highlight Style: decide how the link reacts visually on a click.
- Line Thickness: set how wide the link border runs.

Select OK.

Want every new link to follow the format you just set? Right-click a link and select Use Current Appearance as New Default.
