# Add backgrounds to PDFs

How to drop in, tailor, and lay backgrounds across your PDFs for a refined, professional finish.

Backgrounds let you brand a document or draw the eye to key material, giving your PDFs more visual punch and presence. Drop a background onto one PDF, or push it across several files using the straightforward tools in Acrobat on the desktop.

Note

The only file types that work as background images are PDF, JPEG, and BMP.

Launch the PDF, then pick Edit.

Pick Background > Add over in the left pane.

To land the background on particular pages, pick Page Range Options, then set the page range and subset to suit.

Set the background choices:

- Source: Pick a color or an image file for the background.
- Appearance: Tune opacity and scaling.
- Position: Fix where it sits vertically and horizontally.
