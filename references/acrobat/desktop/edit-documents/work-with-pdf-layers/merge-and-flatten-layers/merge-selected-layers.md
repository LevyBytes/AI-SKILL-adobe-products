# Merge selected layers

Click Layers in the right-side panel; the Layers panel appears.

Tip

If Layers isn’t visible, select Menu > View > Show/Hide > Side panels > Layers.

In the Layers panel, choose Options, then Merge Layers.

In the Layers to be merged dialog box, pick the layers you want joined and select Add.

Decide which layers to bring together and which one will serve as the target for the merge.

In the Target layer to merge into pane, select the layer that should receive the combined content.

Select OK to complete the merge.

Every property of the target layer now belongs to the merged result, and whatever the source layers held has folded into the target layer.
