# Add Bates numbering to existing file names in Acrobat Pro

Fold Bates numbers into your filenames in Acrobat Pro to keep legal documents organized and traceable.

While Bates stamping is being applied in Acrobat, the Bates numbers can also be folded into the existing file names. That lets the original filename sit before or after the span of Bates numbers.

Open the PDF, then click Edit.

Walk through More > Bates numbering > Add.

Once the Bates Numbering dialog box is up, click Output Options.

Use Output Options within the Bates Numbering dialog box to aim the target folder, settle on file-naming conventions, and choose the log file preferences for documents you've stamped.

In the Output Options dialog box, select Add to original file names.

Type %`BATES_NUMBER_KEY`% into the Insert Before or the Insert After field, picking whichever side places the Bates number where you want it relative to the original filename.

Within the Output Options dialog box, set prefix and suffix numbers through the Insert Before and Insert After fields.

Select OK.

Finish off the remaining Bates Numbering options however you like, then select OK.
