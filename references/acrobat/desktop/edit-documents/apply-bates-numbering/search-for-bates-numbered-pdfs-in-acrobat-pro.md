# Search for Bates-numbered PDFs in Acrobat Pro

Track down a single Bates-numbered document fast, or sweep an entire run of Bates-numbered PDFs.

On Windows go to Menu > Search > Advanced search; on macOS use File > Advanced Search instead.

Inside the Search window, drop the Bates number, or just part of it, into the What word or phrase would you like to search for? field.

Pin down one document by typing its full Bates number. To sweep a whole series, feed in a telling fragment such as the prefix or the suffix.

Where the dialog asks Where would you like to search, pick All PDF Documents in.

Run your search through the All PDF Documents in menu to surface the Bates-numbered PDFs.

Open the dropdown menu, choose Browse for Location, and then point it at the folder you mean.

Key in the word or phrase you're after, then switch on any optional filters you want, such as Whole words only, Case-sensitive, Bookmarks, or Comments.

Select Search.

Note

For Bates-numbered PDFs held inside a portfolio, open the portfolio and type the Bates number into the Search box on its toolbar.
