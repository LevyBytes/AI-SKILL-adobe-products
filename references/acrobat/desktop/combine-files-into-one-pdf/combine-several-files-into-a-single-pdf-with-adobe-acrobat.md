# Combine several files into a single PDF with Adobe Acrobat.

Through Adobe Acrobat you can pull together PDFs, Word, Excel, PowerPoint, audio, video, or web files. Before the final, in-order PDF is built, the pages can be previewed, reordered, shifted, or removed. Either fold in files that are already open or grab them from your device.

On Windows select Menu > Combine files; on macOS use File > Combine files.

Select Add Files and select the files you want to combine. Files can also be dragged and dropped straight into the Combine files window.

Note

If you trigger Combine files while documents are already open in Acrobat, those documents come along automatically. Going with Add open files keeps you moving.

Arrange the files and pages as desired:

- drag and drop thumbnails to put pages in a new order.
- hover over a file and click the expand icon to reveal its individual pages.
- select to take out pages you don't want.

Select Combine in the upper-right corner.

Acrobat fuses the files you picked into one PDF. From there the merged file can be renamed and saved wherever you choose.
