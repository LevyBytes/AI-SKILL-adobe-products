# Add multiple headers and footers

Several headers or footers can go in so details like page numbers, titles, and dates land in different sections of one document. That can sharpen clarity and consistency when a document gets complex.

Pick Header and footer > Add.

Once the dialog box appears, pick Add New.

Up comes the Add Header and Footer dialog box, its Preview pane laying out the headers and footers already in place.

Type whatever text you want into the header and footer fields.

The Preview section refreshes on its own as you type.

Tweak the formatting choices to suit.

Pick OK.
