# Add a header and footer

Launch the PDF, then pick Edit from the global bar.

Pick Header and footer > Add over in the left pane.

Once the dialog box appears, type whatever text you want into the header and footer fields.

Lean on the Font section to tune font type, size, and color.

Lean on the Margin (inches) section to fix the top, bottom, left, and right margins to suit.

Lean on the Add Header and Footer dialog box to drop in text and other details.

Lean on the Preview section to see how the header and footer turn out.

Note

Header and footer settings can be kept for later by picking Save Settings. To reuse the same header and footer settings on other PDFs, pick Apply to Multiple Files > Add files. After that, pick your files, fix output preferences in the Output Options dialog box, and pick OK.

Pick OK.
