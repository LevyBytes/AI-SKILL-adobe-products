# Technical requirements for Acrobat Pro 2024

| Component | Windows | macOS |
| --- | --- | --- |
| Processor | Intel or AMD, at least 1.5 GHz | Intel, Apple M1 or Apple M2 |
| Operating system | 64-bit Windows 11; Windows 10 v1809 or later; Windows Server 2016, 2019 or 2022 | macOS 12, 13 or 14 (Sonoma) |
| RAM | 4 GB | 4 GB |
| Available disk space | 4.5 GB | 4.5 GB |
| Display | 1024x768 | 1024x768 |
| Graphics acceleration | Optional | Not specified |

Acrobat and Reader ended support for 32-bit operating systems, including product and security updates, in January 2023.

See Adobe's [Acrobat Pro 2024 requirements](https://helpx.adobe.com/acrobat/system-requirements-acrobat-pro-2024.html) for language support and online-service terms.
