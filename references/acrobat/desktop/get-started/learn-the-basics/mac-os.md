# macOS

What you need to get Acrobat Studio, Acrobat Pro, and Acrobat Standard running on macOS:


| Component | Requirement |
| --- | --- |
| Processor | Intel processor; M1, M2, M3, and M4 Apple Silicon processor |
| Operating system | macOS v13, macOS v14 (Sonoma), macOS v15 (Sequoia), or macOS v26 (Tahoe) |
| RAM | 2GB of RAM |
| Hard disk space | 2.75GB of available hard-disk space |
| Monitor resolution | 1024x768 screen resolution |

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements.html).


Note

On macOS there is no Acrobat Standard 2020.

| Monitor resolution | 1024x768 screen resolution |

Source: [Adobe 2020 requirements](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements-acrobat-2020.html).
