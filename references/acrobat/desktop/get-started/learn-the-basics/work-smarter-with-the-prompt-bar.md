# Work smarter with the prompt bar

From a single spot, lean on plain-language prompts to track down tools, pull up answers, and kick off new work.

On the Acrobat Studio desktop homepage, the prompt bar folds the AI Assistant, search, and the creation features of Acrobat and Adobe Express together into one tidy area. Rather than hunting through menus, you simply state your intent. Type a short, everyday-language prompt and the tool points you toward the matching actions, answers, or tools, converting what you meant into results with fewer steps along the way.
