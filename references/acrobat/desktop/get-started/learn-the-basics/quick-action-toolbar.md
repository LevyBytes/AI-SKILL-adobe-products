# Quick action toolbar

Tools for commenting, annotating, and completing forms are gathered in the Quick action toolbar for fast reach. Because the panel floats as a widget, you can adjust it to suit the demands of a given workflow.

You can select or pan objects from the Quick Action toolbar, add comments, draw shapes, highlight text, fill out forms, and sign documents.
