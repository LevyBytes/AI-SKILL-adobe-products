# Unified starting point for your work

Built to act as a smart command surface, the prompt bar gathers your routine tasks in one place so your attention stays on the outcome you're after. Be it digging into a document, producing content, or hunting through your files, the prompt bar clears away friction and shortens the path to a result.

- Ask questions about your documents: Select Doc Q&A, add one or more files, and enter prompts like "Summarize the key takeaways" or "Compare insights across these documents." Learn how to explore your documents using AI Assistant and gain insights across PDF Spaces.
- Access Acrobat tools instantly: Use the Find tools and describe your task to discover the relevant Acrobat tools, such as "Help me combine multiple PDFs into one file" or "Edit text in a PDF."
- Create professional presentations in minutes: Selecting Generate presentation, add a document, and prompt with requests such as "Create a 5‑slide presentation from this report" or "Turn this report into a client‑ready pitch deck with key highlights." Learn how to generate professional presentations.
- Explore ready‑to‑use Adobe Express templates: Select Explore templates and prompt with requests like "Show templates for flyers or invoices" or "Find templates for reports or project summaries." Learn how to create marketing documents using Adobe Express.
- Search across PDFs, PDF Spaces, and Adobe Express files: Use Search files to find documents by keywords in the file name or content, such as "project budget" or "pricing details."

Together these features hand you quicker entry to the tools that are already part of your routine while surfacing new approaches to building and creating.

Use the prompt bar to begin tasks quickly - analyze documents, create visuals, build presentations, or browse templates.
