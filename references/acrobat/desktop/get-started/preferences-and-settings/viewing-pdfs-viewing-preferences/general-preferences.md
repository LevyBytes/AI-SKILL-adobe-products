# General preferences

Basic Tools

- Use Single Key Accelerators To Access Tools: Lets a single keystroke pick a tool. The option starts out off.
- Create Links From URLs: Sets whether links not made in Acrobat get spotted automatically in the PDF and turned into clickable links.
- Make Hand Tool Select Text & Images: Has the Hand tool act like the Select tool while it sits over text in an Adobe PDF.
- Make Hand Tool Read Articles: Alters how the Hand tool pointer looks above an article thread. The first click zooms the article to span the document pane horizontally, and each click after that follows the article's thread.
- Make Hand Tool Use Mouse-wheel Zooming: Flips the mouse wheel from scrolling over to zooming.
- Make Select Tool Select Images Before Text: Reorders how the Select tool makes selections.
- Show Quick actions on text selection: Brings up a quick action toolbar whenever text or an image is selected.
- Show Online Storage When Opening Files: Surfaces cloud storage inside the file open dialog box.
- Show Online Storage When Saving Files: Surfaces cloud storage as you save a file.
- Open PDFs from last session on Acrobat launch: Brings back the PDFs from your previous session when Acrobat starts.
- Open Documents As New Tabs In The Same Window (requires relaunch): Bundles several documents into tabs as they open. Tabs can also be snapped out or pulled free as their own windows — select a tab, drag away the thumbnail that shows up beside the toolbar, then let go.
- Prompt Before Closing Multiple Tabs: Checks with you before Acrobat closes.
- Show Starred Files In Recent Tab: Puts your starred files on display as cards in Home view.
- Use Fixed Resolution For Snapshot Tool Images: Fixes the resolution applied when copying an image grabbed with the Snapshot tool.
- Enable PDF thumbnail preview in Windows Explorer: Turn this on to have PDFs show as thumbnail previews within Windows Explorer.
- Touch Mode: Determines how — or whether — Acrobat slips into Touch mode on touch-capable devices. Under Touch mode, toolbar buttons, panels, and menus spread out a bit so fingers can select more easily. Viewing is tuned by the Touch reading mode, which handles the most common gestures.
- Scale for screen resolution (restart required): Either detects the screen resolution automatically and scales the PDF for viewing, or leaves the PDF as-is no matter the screen resolution.

Warnings

- Do Not Show Edit Warnings: Switches off the warning boxes that usually pop up when you remove things like links, pages, page thumbnails, and bookmarks.
- Reset All Warnings: Puts warning settings back to their defaults.

Messages From Adobe

- Show Me Messages When I Launch Acrobat: Permits Adobe's in-product marketing messages to surface in the Welcome Screen when you start the app with no document open. Clicking a message turns up information on features, updates, or online services, or opens something inside the app such as a task pane. Clear the option and those in-product marketing messages stay away.

Note

The transactional messages that keep the Adobe Online Service running cannot be switched off.

Application Startup

- Use Only Certified Plug-Ins: Makes sure only third-party plug-ins certified by Adobe get loaded. A Currently in Certified Mode notation reads Yes or No to reflect the present state.
- Check 2D Graphics Accelerator (Windows only): (Shows up only when your computer hardware can do 2D graphics acceleration.) Selected, it lets hardware acceleration kick in as the first document opens. Deselected, hardware acceleration begins only after that first document is open. Because it can drag out startup, the option is off by default.

Note

You can use this option only while Use 2D Graphics Acceleration sits selected in the Page Display preferences.

- Select As Default PDF Handler (Windows only): Decides which program — Reader or Acrobat — opens PDFs. It matters once you have installed the two of them side by side.
- Tell Me If Adobe Acrobat Is Not My Default PDF Application (Windows only): When Acrobat is not the default PDF handler, launching it brings up a dialog asking whether to make Adobe Acrobat the default PDF application.
