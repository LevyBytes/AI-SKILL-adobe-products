# Compare a revised PDF to an earlier version (Acrobat Pro)

When you need to see what changed between two editions of a PDF, reach for the Compare Files feature, which surfaces the differences side by side. How those differences get displayed is configurable through a range of options. Compare two versions of a PDF file covers the full procedure.
