# Replace pages between multiple PDFs

Launch both the PDF you plan to revise and the PDF holding the replacement pages.

For each PDF, pick All tools > Organize pages so the page thumbnails show.

Within the PDF that holds the replacement pages, pick whichever page(s) you want to use:

- Under Windows, hold Ctrl while picking the pages.
- Under macOS, hold Command while picking the pages.

Pull the chosen thumbnails over to the document area of the PDF you're targeting.

Let go of the mouse once the pointer sits squarely on the page number where the new pages belong.

Note

However many pages you chose will take the place of an equal count in the target PDF, beginning at the page number where you dropped them.

Save the PDF you just revised.
