# Convert PDFs to image formats

Use Adobe Acrobat to turn PDF documents into image types such as JPEG, PNG, TIFF, and JPEG 2000.

From the global bar, select Convert.

In the left pane, select Image format.

Out of the dropdown menu, pick the format you want:

- JPEG
- JPEG 2000
- PNG
- TIFF

The button you click should match your chosen format — that is, Convert to JPEG, or else Convert to JPEG 2000, or Convert to PNG, or Convert to TIFF.

When the dialog box appears, pick where you'd like the file saved.

Rename the file if you like, then select Save.

Tip

Reach for JPEG when the image is headed to the web, PNG when you need a transparent background, TIFF for high-quality archiving, and JPEG 2000 when you want stronger compression.
