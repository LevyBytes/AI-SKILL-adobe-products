# Export user data from a response file

Sending every entry from a PDF Portfolio response file off to a spreadsheet or an XML file works like this.

With that response file open in Acrobat, highlight the data you'd like to send out.

Head to the All tools menu, choose Export a PDF, pick a format, then choose Convert to (format selected).

When the Select Folder To Save File dialog box opens, supply a name and a location, settle on either CSV or XML as the format for your form data, and then select Save.
