# Fill text fields in PDF forms

Open E-Sign and then pick the Fill in form fields icon.

Click the field that should hold your text. Up comes a text field together with a text box menu.

Either type into the field or pull a signature or initials over from the E-sign panel.

Click the text box and revise it however you need.

Should you need to reposition it, hover at the text box's border until the cursor shifts, then drag it where it belongs.

Resize the text with the larger or smaller text size options on the text box menu.

The pop-up toolbar is where you resize the text or remove the text box.

Recolor the typed text by picking Choose a color for type text on the Quick action toolbar.

Switch the text spacing from normal to combed by opening the options menu on the text box menu and picking Character spacing.
