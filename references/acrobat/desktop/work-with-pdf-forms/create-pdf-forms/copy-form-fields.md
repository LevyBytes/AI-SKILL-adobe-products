# Copy form fields

See how Adobe Acrobat lets you duplicate form fields inside a PDF form.

Copy a form field and you no longer have to set properties such as size, font, and fill order over and over for every field. Because the duplicates carry over all the original properties, the form keeps a consistent look and feel throughout. Copying and pasting lets you spin up many fields sharing the same attributes in short order, which speeds the form creation workflow.
