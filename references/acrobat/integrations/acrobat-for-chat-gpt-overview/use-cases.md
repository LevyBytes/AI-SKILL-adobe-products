# Use cases

| Workflow | Actions |
| --- | --- |
| Job applications | Combine application documents; edit the company name. |
| Medical records | Select and redact sensitive content. |
| Proposals | Combine files, move pricing first, compress. |
| Regional sales | Combine and order US, EMEA, APAC. |
| Handwritten notes | Convert to PDF; request a summary. |
| Rental applications | Combine supporting documents; add a cover. |
| School projects | Combine essay, outline and bibliography; compress. |
| Expenses | Combine receipts; extract totals; mark reimbursements. |
| Recipes | Extract recipes; edit serving amounts. |
| Personal finance | Identify patterns; find expenses above $500 over 30 days. |
