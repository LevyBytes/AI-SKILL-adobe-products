# Supported tasks

Start requests with `@Adobe Acrobat`. Review the result in the editor.

| Task | Request pattern | Editor action |
| --- | --- | --- |
| Edit | Edit this PDF | Edit, review, save |
| Create PDF | Convert this file to PDF | Review layout, save |
| Export | Export as Word | Review Word output, save |
| Combine | Combine these PDFs | Order files, save |
| Delete pages | Delete pages 5-7 | Select pages, delete |
| Reorder | Reorder PDF pages | Arrange thumbnails, save |
| Rotate | Rotate PDF pages | Review orientation, save |
| Split | Split this PDF | Choose boundaries, save |
| Compress | Compress this PDF | Choose level, download |
| Redact | Redact sensitive content | Select content, apply redactions |
