# Collaborate on PDFs through Chat

Log in to your Microsoft Teams account and select Chat.

Beside the chat compose box, select Add > Attach file.

Pick the file you'd like to share and work on together, then select the Send icon.

Move your pointer over the shared file card and select More options > Collaborate on PDF.

Should you want to view the shared PDF in a browser or save it locally, select the 'More attachment options' icon on the file card, then pick the option you need.

When you want to comment on the open document, select Add comments from the Quick Actions menu and drop it wherever you like on the document.

Enter your comment and select Post.

Replying to an existing comment works the same way: select it, enter your text in the Add a reply field, and select Post when finished.

Mark up the document as needed with annotation tools such as Highlight, Underline, Insert text, or Add text comment.
