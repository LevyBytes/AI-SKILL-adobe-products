# Acrobat for Microsoft Teams overview

Understand what Acrobat for Microsoft Teams delivers, plus the permissions its integration depends on.

A full set of PDF capabilities arrives with Adobe Acrobat for Microsoft Teams, which keeps PDF work flowing without leaving Teams. Through this built-in PDF solution you can:

- Open and read PDFs on the web by way of Adobe's modern browser-based viewer.
- Lean on the AI Assistant feature to make sense of dense PDF documents fast, hand off repetitive work, and draft content that lands.
- Convert PDFs into formats you can edit — Word, Excel, PowerPoint, or RTF — while the source fonts, formatting, and layouts stay intact, whether you work from mobile or the web.
- Build PDFs that preserve fonts, formatting, and layouts, and lock them down with password protection when needed.
- Rework PDFs by changing text and images, shuffling page order, or splitting one document into several PDFs.
- Combine separate documents and PDFs into one file, and shrink the result when you want easier sharing or storage.
- Work together on PDF documents, annotating them with sticky notes, highlights, and freehand drawings so the message gets across.
- Complete and sign PDF forms.
- Keep things accessible through screen reader support, keyboard navigation, and High Contrast modes that assist anyone with limited vision.
- Tailor how the viewer looks by switching Acrobat's theme to light, dark, or whatever the Microsoft Teams preference is set to.
