# For Non-admins

For any configuration change, non-admins first need the Microsoft admin's consent.

Choose Sign in and request access, then sign in using your Microsoft 365 credentials.

Choose Create request link, followed by Copy link.

Pass the link you copied along to your Microsoft 365 or Teams admin.

That Microsoft 365 or Teams admin then has to open the link and choose Authorize access.

After it's authorized, head to the Admin configuration page to sign in and set your preferences.
