# How to put Acrobat for Microsoft Teams to work editing PDFs.

PDFs can be edited right inside Acrobat for Microsoft Teams without much fuss. That lets you work together and apply changes while staying on the platform.

Sign in to your Microsoft Teams account, then choose Adobe Acrobat in the left pane.

Out of the Recent or Documents list, choose whichever file you want to open.

From the main menu, select Edit.

Reach for the Edit tools in the left pane to carry out whichever of these you need:

- Add new text
- Change, replace, or delete text
- Move, or resize a text box
- Add or edit lists
- Add image to the PDF
- Organize pages
- Combine files

Edit PDFs spells out the specifics.

Clicking any boxed stretch of the text brings the text and image editing tools into view.
