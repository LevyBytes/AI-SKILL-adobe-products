# Prompts to edit PDFs via chat

Find out which prompts let you edit PDFs through the chat feature in Adobe Acrobat.

A prompt might carry out one action, link several tools one after another, or lean on the document's content and structure to work out what to act on. How you phrase the request shapes how AI Assistant reads it.

Use specific document references and actions so Acrobat can identify the requested change.

- For one action, start with [Simple prompts](prompts-to-edit-pdfs-via-chat/simple-prompts.md).
- For a sequence, use [Multi-tool prompts](prompts-to-edit-pdfs-via-chat/multi-tool-prompts.md).
- For selection by meaning or structure, use [Content-aware prompts](prompts-to-edit-pdfs-via-chat/content-aware-prompts.md).
- To make a request precise, follow [Prompt phrasing tips](prompts-to-edit-pdfs-via-chat/prompt-phrasing-tips.md).

Browse the [Acrobat AI prompt library](https://helpx.adobe.com/acrobat/desktop/use-acrobat-ai/get-started-with-smart-actions/prompts-to-edit-pdfs-via-chat.html) for replacement, rewriting, restructuring, redaction, formatting and highlighting requests.

Note

Only individual Acrobat Pro and Studio plan users can reach multi-tool and content-aware prompts; on Teams and Enterprise plans they aren't supported yet. Check the [supported tools and actions](edit-pdfs-via-chat-overview/supported-tools.md) for your plan.
