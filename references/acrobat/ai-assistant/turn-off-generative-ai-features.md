# Turn off generative AI features

Generative AI features are enabled by default. Individual users can turn them off, and administrators can revoke access for teams or organizations.

1. Close all open documents in Acrobat.
2. Open Preferences > Generative AI through Menu on Windows or View on macOS.
3. Clear Enable generative AI features.
4. Select OK to save the setting.

For organization-wide access and licensing, use [enterprise administration](administer-acrobat-studio-for-enterprise/reference-index.md).
