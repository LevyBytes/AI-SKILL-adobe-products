# AI Assistant chat history

Chat history contains prompts and generated responses for a document or a PDF Space containing multiple documents. AI Assistant can use earlier exchanges as context for later answers.

- To return to a conversation or understand content retained from removed documents, read [Access chat history](ai-assistant-chat-history/access-chat-history.md).
- To locate stored conversation data, read [Understand chat history storage](ai-assistant-chat-history/understand-chat-history-storage.md).
- To keep responses outside Acrobat, read [Export and sharing limits](ai-assistant-chat-history/review-export-and-sharing-limits.md).
- To remove prompts, responses and overviews, follow [Clear chat history](ai-assistant-chat-history/clear-chat-history.md).
- To manage enterprise controls, read [Review chat history controls](ai-assistant-chat-history/review-chat-history-controls.md).
- Before removing an external storage connection, read [Disconnect third-party cloud storage](ai-assistant-chat-history/disconnect-third-party-cloud-storage.md).
