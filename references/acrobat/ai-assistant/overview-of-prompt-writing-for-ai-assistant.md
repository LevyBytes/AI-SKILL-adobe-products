# Overview of prompt writing for AI Assistant

Get familiar with the ideas behind composing clear, effective prompts for the AI Assistant in Acrobat.

Prompts that are written well lead to summaries that hold up, surface the points that matter, and tighten document text with less back-and-forth. When a prompt is specific and unambiguous, the AI Assistant has an easier time grasping what you're after, which cuts down on rework and yields stronger output.

- Build the request with [Task, Context, Expectations and Format](overview-of-prompt-writing-for-ai-assistant/components-of-a-strong-prompt.md).
- Set scope, tone and constraints through [Prompt-quality guidelines](overview-of-prompt-writing-for-ai-assistant/guidelines-for-improving-prompt-quality.md).
- Compare basic and improved requests in [Effective prompt examples](overview-of-prompt-writing-for-ai-assistant/examples-of-effective-prompts.md).
- Develop an answer through [Follow-up prompts](overview-of-prompt-writing-for-ai-assistant/expand-responses-step-by-step.md).
- Check ambiguity and conflicting instructions in [Common mistakes](overview-of-prompt-writing-for-ai-assistant/common-mistakes-to-avoid.md).
