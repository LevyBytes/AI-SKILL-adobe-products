# Generative AI technical requirements

Check these requirements before using Acrobat's generative AI features:

- Confirm a supported Adobe ID, an internet connection and enabled AI in [Account and login requirements](generative-ai-technical-requirements/account-and-login-requirements.md).
- Check document languages in [Supported file languages](generative-ai-technical-requirements/supported-file-languages.md) and availability of each feature in [Supported languages for GenAI features](generative-ai-technical-requirements/supported-languages-for-gen-ai-features.md).
- Check document size, pages, protection and portfolios in [File requirements](generative-ai-technical-requirements/file-requirements.md).
- Check prompt length, text selections, images and webpages in [Usage limitations](generative-ai-technical-requirements/usage-limitations.md).
- Set the application language and new Acrobat experience through [App settings](generative-ai-technical-requirements/app-settings.md).
- Check app versions and web compatibility in [Supported devices and browsers](generative-ai-technical-requirements/supported-devices-and-browsers.md).
- For deployment, background and support, use [Additional resources](generative-ai-technical-requirements/additional-resources.md).
