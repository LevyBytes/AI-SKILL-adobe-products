# Prompt types

A range of prompts is open to you in AI Assistant, including ones that fire a single tool, ones that chain several tools, or ones that act on what the document contains and how it's laid out. Note that multi-tool and content-aware prompts reach only individual Acrobat Pro and Studio plan users; Teams and Enterprise plans don't carry that support yet.

Choose [Simple prompts](../prompts-to-edit-pdfs-via-chat/simple-prompts.md), [Multi-tool prompts](../prompts-to-edit-pdfs-via-chat/multi-tool-prompts.md) or [Content-aware prompts](../prompts-to-edit-pdfs-via-chat/content-aware-prompts.md) for examples.
