# Supported tools

Available chat actions, grouped by Acrobat plan:

## Reader, Standard, Pro and Studio

| Tool | Action |
| --- | --- |
| Find | Locate matching text. |
| Print | Print with existing settings. |
| Share | Send a link or email. |
| Add Signature | Insert a signature. |

## Standard, Pro and Studio

| Tool | Action |
| --- | --- |
| Create | Make PDFs from editable formats. |
| Convert | Turn PDFs into editable formats. |
| Delete | Remove pages, text, comments or images. |
| Export | Save PDF content in editable formats. |
| Extract | Separate pages, text, comments or images. |
| Find & Replace | Change one or all text matches. |
| Rotate pages | Rotate clockwise or counterclockwise by 90 degrees. |
| Compress | Reduce file size. |
| Password protect | Restrict viewing or editing with a password. |
| Scan & OCR | Make scanned text searchable. |

## Pro and Studio

| Tool | Action |
| --- | --- |
| Organize | Rearrange, rotate or delete pages. |
| Header | Add text at page tops. |
| Footer | Add page numbers or other bottom text. |
| Watermark | Overlay text or images. |
| Rephrase text | Rewrite or restructure by meaning. |
| Format text | Change typography, spacing or indentation. |
| Highlight text | Add, recolor or remove highlights. |
| Redact text | Remove sensitive content across matches. |

Multi-tool and content-aware prompts require individual Pro or Studio; Teams and Enterprise are excluded. Unsupported actions receive manual guidance. Check [current availability](https://helpx.adobe.com/acrobat/desktop/use-acrobat-ai/get-started-with-smart-actions/edit-pdfs-via-chat-overview.html).
