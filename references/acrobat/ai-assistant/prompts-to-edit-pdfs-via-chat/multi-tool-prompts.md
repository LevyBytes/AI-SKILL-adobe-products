# Multi-tool prompts

A multi-tool prompt strings two or more PDF tools together in sequence to finish the task. Before any of it runs, AI Assistant puts a plan in front of you to confirm.

For example, ask "Rotate page 2 clockwise by 90 degrees, then compress the PDF." Review the proposed sequence before accepting it. Multi-tool requests require an individual Pro or Studio plan; check [tool and plan availability](../edit-pdfs-via-chat-overview/supported-tools.md).
