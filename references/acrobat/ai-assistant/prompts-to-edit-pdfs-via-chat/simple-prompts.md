# Simple prompts

With a simple prompt, one tool runs to get the task done.

For example, ask "Rotate page 2 clockwise by 90 degrees." Name the target page and action explicitly. Follow [Edit PDFs via chat](../edit-pdfs-via-chat.md) to submit the request and review the result; check [tool availability](../edit-pdfs-via-chat-overview/supported-tools.md) for your plan.
