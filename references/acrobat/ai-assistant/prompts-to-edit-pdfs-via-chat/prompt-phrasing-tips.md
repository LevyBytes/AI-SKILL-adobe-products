# Prompt phrasing tips

State the editing action and identify the content it should affect.

- Use exact page numbers, quoted text or a specific section description.
- Replace vague requests such as "Improve this" with a concrete action, such as "Highlight the phrase 'delivery date' in yellow."
- If selection by content fails, retry with page numbers or exact text.
- Check [supported tools and plans](../edit-pdfs-via-chat-overview/supported-tools.md) when Acrobat gives manual steps instead of executing an action.
- Review the proposed action or preview before accepting changes.

Follow [Edit PDFs via chat](../edit-pdfs-via-chat.md) to run a request; use the [current prompt library](https://helpx.adobe.com/acrobat/desktop/use-acrobat-ai/get-started-with-smart-actions/prompts-to-edit-pdfs-via-chat.html) for additional editing examples.
