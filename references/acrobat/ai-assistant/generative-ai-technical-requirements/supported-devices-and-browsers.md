# Supported devices and browsers

Every GenAI feature works on these versions and later:

- iOS: 26.02.50
- Android: 26.2.0.43379
- Desktop: 25.001.21288
- Acrobat on the web: use the [web technical requirements](https://helpx.adobe.com/acrobat/web/get-set-up/learn-the-basics/technical-requirements.html).

Support for GenAI features on older versions ended on June 1, 2026.
