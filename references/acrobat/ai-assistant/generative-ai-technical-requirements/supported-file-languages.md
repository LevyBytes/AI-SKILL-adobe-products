# Supported file languages

- Acrobat apps on desktop and web: Generative AI supports files in English, French, German, Spanish, Italian, Brazilian Portuguese, Japanese, Korean, Danish, Norwegian, Finnish, Swedish, and Dutch.
- AI Assistant for webpages: English-language webpages only.

Feature availability is listed separately in [Supported languages for GenAI features](supported-languages-for-gen-ai-features.md).
