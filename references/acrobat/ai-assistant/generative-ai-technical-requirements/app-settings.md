# App settings

- Set the Adobe Acrobat, Acrobat Reader, or Adobe Scan application language to English, French, German, Spanish, Italian, Brazilian Portuguese, or Japanese.
- Enable the new Acrobat experience:
  - On Windows, select Menu > Enable new Acrobat.
  - On macOS, select View > Enable new Acrobat.

File-language support and individual feature availability are separate requirements. Check [Supported file languages](supported-file-languages.md) and [Supported languages for GenAI features](supported-languages-for-gen-ai-features.md).
