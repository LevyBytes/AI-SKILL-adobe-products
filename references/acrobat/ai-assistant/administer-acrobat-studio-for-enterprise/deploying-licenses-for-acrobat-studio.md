# Deploying licenses for Acrobat Studio

Licensing requirements

Because AI Assistant leans on cloud-based services tied to a user's identity, it calls for a Named User license of Acrobat. To hand both out to users, the Acrobat license and the AI Assistant license have to show up within the same Admin Console. Organizations buying through the VIP buying program need both licenses tied to one and the same VIP account.

Deploy Acrobat Studio by way of the Admin Console. Ahead of deployment, confirm that [Acrobat is up to date](https://www.adobe.com/devnet-docs/acrobatetk/tools/ReleaseNotesDC/index.html) and set to a [supported application language](../generative-ai-technical-requirements/app-settings.md). Consult the [basic configuration settings](https://www.adobe.com/devnet-docs/acrobatetk/tools/AdminGuide/basicconfig.html).

Bring users into the Admin Console through a [supported user-management method](https://helpx.adobe.com/business/enterprise/users/understand-user-management/user-management-overview.html), including bulk upload. After the necessary product profiles exist, you can hand Acrobat Studio straight to users. For specifics, review [Adobe app deployment options](https://helpx.adobe.com/business/enterprise/deploy-apps-updates/prepare-for-deployment/app-deployment-overview.html).

Once Acrobat Studio has been assigned, users must restart Acrobat before the features open up.
