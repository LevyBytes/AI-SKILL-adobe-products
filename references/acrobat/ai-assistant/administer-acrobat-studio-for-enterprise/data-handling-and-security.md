# Data handling and security

Within Acrobat AI Assistant and Acrobat Studio, safeguards govern how data is handled and protected. Capabilities using third-party LLMs also operate under Adobe's Responsible AI Ethics governance, based on accountability, responsibility and transparency.

- Submit requests for early data deletion through the [Adobe Privacy Policy](https://www.adobe.com/privacy/policy.html).
- Enterprises with in-app feedback enabled can rate AI responses using Like or Dislike.
- Creation workflows using Adobe Express save their files in Adobe cloud storage.

Traffic is encrypted over HTTPS with TLS 1.2 or later. Data stored by the Acrobat Generative AI Service uses AES-256 encryption.

The [AI Assistant security factsheet](https://www.adobe.com/dc-shared/assets/pdf/acrobat/business/gen-ai/adobe-acrobat-aiassistant-security-fact-sheet.pdf) describes handling, storage, processing, data flow and encryption. For the request and retention workflow, read [Content usage and handling](../content-usage-and-handling.md).
