# Access generative AI tools in Acrobat

Use the procedure for your application after checking [generative AI requirements](generative-ai-technical-requirements.md):

- On desktop, start from [the Acrobat homepage](access-generative-ai-tools-in-acrobat/from-the-acrobat-on-desktop-homepage.md).
- In a browser, start from [the Acrobat web homepage](access-generative-ai-tools-in-acrobat/from-the-acrobat-on-the-web-homepage.md).
- In Reader, use [the signed-in Home workflow](access-generative-ai-tools-in-acrobat/from-acrobat-reader.md).
