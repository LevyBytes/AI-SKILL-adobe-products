# Key generative AI features

Choose the capability that matches the document task:

- [PDF Spaces](pdf-spaces.md) brings multiple files, links and collaborators into a shared workspace.
- [Generate presentation](generate-presentation.md) turns documents or insights into a deck.
- [Generate podcast](generate-podcast.md) converts document insights into audio.
- [AI Assistant](ai-assistant.md) answers document questions with source references.
- [Generative summary](generative-summary.md) extracts an overview, section outlines and key points.
- [Image generation](image-generation.md) uses Adobe Express tools for PDF visuals.
