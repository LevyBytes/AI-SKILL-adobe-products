# Examples of effective prompts

Minor tweaks can sharpen a prompt and lift the quality of the output. The cases below contrast a weak prompt with a stronger one and explain the difference.

| Category | Basic prompt | Improved prompt | Why it works |
| --- | --- | --- | --- |
| Classification | Categorize this document. | Categorize this document as analysis, blog, report, or review under a specific category like marketing or finance. | Adds the category choices, reducing ambiguity. |
| Sentiment analysis | Is this review good? | Is this product or feature review positive or negative? | Defines the sentiment categories clearly. |
| Summarization | Summarize this report. | Summarize this analyst report in a few paragraphs. | Specifies the expected length and context. |
| Rewriting content | Rewrite these instructions. | Review these instructions and provide them in simple language for beginners. | Clarifies the audience and rewriting intent. |
| Information extraction | Find drivers for the company. | Find strategic drivers for the company. | Adds precision by specifying strategic drivers. |
| Comparison | Compare performance. | Compare the performance per quarter and showcase the growth percentage across the last two quarters. | Specifies the time frame and output expectations. |
