# Edit PDFs via chat

Multi-tool, content-aware and text-editing prompts require an individual Acrobat Pro or Studio plan. Teams and Enterprise plans do not support those prompt types. Check [supported tools](edit-pdfs-via-chat-overview/supported-tools.md) for plan availability.

1. Open the PDF in Acrobat and select AI Assistant from the top bar.
2. Enter a specific request in the chat field, such as Delete the last two pages or Compress this file. The [prompt library](https://helpx.adobe.com/acrobat/desktop/use-acrobat-ai/get-started-with-smart-actions/prompts-to-edit-pdfs-via-chat.html) offers further examples.
3. Select Submit.
4. For a multi-tool request, review the proposed plan and type Yes to confirm it.
5. Review text changes. Select Accept to apply a proposed change or Skip to continue to the next instance, as applicable to the request.

To reverse a supported edit, select Undo on the top bar. If Acrobat cannot perform the action, add page numbers, file names or other specifics to the request, or follow the manual steps it provides. Check [common issues](edit-pdfs-via-chat-not-working-in-acrobat/reference-index.md) if the problem continues.
