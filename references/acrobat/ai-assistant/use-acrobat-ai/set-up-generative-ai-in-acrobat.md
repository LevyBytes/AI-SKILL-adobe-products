# Set up generative AI in Acrobat

- Open AI tools from Reader, desktop or web. [Access generative AI tools in Acrobat](../access-generative-ai-tools-in-acrobat.md).
- Purchase or assign Teams licenses and review requests. [Request AI Assistant access as Teams admins](../request-ai-assistant-access-as-teams-admins.md).
- Request an organization license and check approval status. [Request AI Assistant access as Teams users](../request-ai-assistant-access-as-teams-users.md).
- Disable AI tools in application preferences. [Turn off generative AI features](../turn-off-generative-ai-features.md).
- Review enterprise identity, licensing, deployment and service controls. [Administer Acrobat Studio for enterprise](../administer-acrobat-studio-for-enterprise.md).
