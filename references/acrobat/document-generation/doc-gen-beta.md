# DocGen Beta

Pair the [PDF Services Beta SDK](doc-gen-beta/beta-sdk.md) with the [Beta API](https://documentcloud.adobe.com/document-services/beta.html#post-documentGeneration) to turn out mobile-optimized PDFs from Document Generation. Adobe's Liquid Mode inside the Acrobat Reader App tunes the resulting PDF so it reads well on mobile.

[Video](https://images-tv.adobe.com/mpcv3/5644/7be694f8-5299-41eb-a2da-2d47fbce1891_1629809837.1920x1080at3000_h264.mp4)

**Note**: This mobile-optimized PDF generation remains in Beta, so hold off on relying on it in production.
