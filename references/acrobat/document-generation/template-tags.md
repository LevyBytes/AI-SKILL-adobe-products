# Template Tags

**Every template tag available for authoring a document template is described in this section.** Across the [Document Generation Process](overview-what-is-document-generation/overview-document-generation-process.md), the Document Generation API swaps the document template's template tags for the supplied input data to produce the output document.

Each tag is [JSONata compliant](https://docs.jsonata.org/overview.html).

Keep every tag within a 1000-character limit.
