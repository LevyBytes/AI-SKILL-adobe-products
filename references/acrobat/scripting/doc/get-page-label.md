# getPageLabel

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 5.0 | No | No | All |

Returns, for the page you name, its page label information.

Parameters

| Parameter | Description |
| --- | --- |
| nPage | (optional) A 0-based page index; left unset it falls back to 0, meaning the document's opening page. |

Returns

Page label information for the specified page.

Example: See setPageLabels for an example.
