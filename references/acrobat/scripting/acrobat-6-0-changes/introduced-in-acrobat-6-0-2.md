# Introduced in Acrobat 6.0.2

Acrobat 6.0.2 introduced API members for the Multimedia plug-in. Under Acrobat 6.0.2, multimedia JavaScript had its own dedicated document, titled the "Acrobat Multimedia JavaScript Reference".

Use the official [API member changes](https://opensource.adobe.com/dc-acrobat-sdk-docs/library/jsapiref/JS_API_AcroJSChanges.html#introduced-in-acrobat-6-0-2) to look up the affected objects, properties and methods.
