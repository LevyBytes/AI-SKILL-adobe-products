# tallest

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 6.0 | No | No | All |

Hands back a duplicate of the Monitors object trimmed to only the display or displays with the greatest height, in pixels.

Parameters

| Parameter | Description |
| --- | --- |
| nMinHeight | (optional) When nMinHeight is supplied and no display reaches that height, what comes back is an empty Monitors array. |

Returns

A Monitors object
