# widest

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 6.0 | No | No | All |

Hands back a duplicate of the Monitors object trimmed to only the display or displays with the greatest width, in pixels.

Parameters

| Parameter | Description |
| --- | --- |
| nMinWidth | (optional) When nMinWidth is supplied and no display reaches that width, what comes back is an empty Monitors array. |

Returns

A Monitors object
