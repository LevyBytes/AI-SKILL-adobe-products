# beep

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 3.01 | No | No | All |

Makes the system sound a tone.

Note

Under Mac OS and UNIX the beep type carries no effect.

Parameters

| Parameter | Description |
| --- | --- |
| nType | (optional) Which sound to play. Each value maps to a sound as follows:<br><br>0: Error<br><br>1: Warning<br><br>2: Question<br><br>3: Status<br><br>4: Default (default value) |
