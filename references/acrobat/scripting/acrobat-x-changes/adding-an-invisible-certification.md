# Adding an invisible Certification

Acrobat X introduced `Doc.certifyInvisibleSign` to apply an invisible document certification. Reader does not provide this method.

Check [PAdES signature event restrictions](signature-support-for-emerging-p-ad-es-etsi-esi-standard.md) before use. Open [Doc.certifyInvisibleSign](../doc/certify-invisible-sign.md) for engine, signing information, output path, UI, reason and return value.
