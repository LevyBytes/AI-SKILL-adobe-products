# Adding an invisible timestamp

Acrobat X introduced `Doc.timestampSign` to apply an invisible document timestamp. The Acrobat X release note excludes Reader.

Check [PAdES signature event restrictions](signature-support-for-emerging-p-ad-es-etsi-esi-standard.md) before use. Open [Doc.timestampSign](../doc/timestamp-sign.md) for its signature engine, output path, UI and return contract.
