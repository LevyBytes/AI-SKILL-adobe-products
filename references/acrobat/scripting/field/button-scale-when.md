# buttonScaleWhen

| Version (Key) | Save-Prefs | Security | Product | Type | Access |
| --- | --- | --- | --- | --- | --- |
| 5.0 | D | No | F | Integer | R/W |

Sets the circumstances under which an icon scales to sit inside the button face. Every valid alternative is laid out by the convenience scaleWhen object:

| When is icon scaled | Keyword |
| --- | --- |
| Always | scaleWhen.always |
| Never | scaleWhen.never |
| If icon is too big | scaleWhen.tooBig |
| If icon is too small | scaleWhen.tooSmall |

Fields

button
