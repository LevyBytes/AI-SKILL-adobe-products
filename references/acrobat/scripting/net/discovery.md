# Discovery

| Version (Key) | Save-Prefs | Security | Product | Type | Access |
| --- | --- | --- | --- | --- | --- |
| 8.0 | No | No | All | Object | R |

The Discovery object exists for finding network services on the fly. Two methods hang off the Net.Discovery object. The linked reference carries the complete documentation.

| Net.Discovery method | Short Description |
| --- | --- |
| queryServices | Finds network services that have advertised themselves via DNS Service Discovery (DNS-SD). |
| resolveService | Lets a service name be tied to a network address and port so that a connection can happen. |
