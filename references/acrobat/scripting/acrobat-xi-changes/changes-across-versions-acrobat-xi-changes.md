# Changes Across Versions - Acrobat XI changes

When updating print scripts for Acrobat XI, check [Changes to PrintParams object](changes-to-print-params-object.md): `colorOverride` is no longer supported.

Use the [JavaScript API reference](https://opensource.adobe.com/dc-acrobat-sdk-docs/library/jsapiref/index.html) and Developing Acrobat Applications Using JavaScript for complete contracts.
