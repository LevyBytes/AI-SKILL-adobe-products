# Annotation methods

- Delete an annotation and invalidate its object. [destroy](destroy.md).
- Read annotation properties for inspection or duplication. [getProps](get-props.md).
- Inspect an annotation's states within a model. [getStateInModel](get-state-in-model.md).
- Apply property updates to an annotation. [setProps](set-props.md).
- Change an annotation's state using an existing model. [transitionToState](transition-to-state.md).
