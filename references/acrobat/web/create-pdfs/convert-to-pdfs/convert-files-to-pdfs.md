# Convert files to PDFs

See how to turn Microsoft Office documents — Word, Excel, or PowerPoint — plus other supported formats into PDFs.

Starting from the Acrobat on the web homepage, choose Convert > Convert to PDF.

Depending on which file type you're converting, pick the matching Convert tool out of the options shown. This walkthrough demonstrates turning a PPT into a PDF.

Within the list of conversion tools, the right tool to pick depends on the kind of file you mean to convert.

When the dialog box opens, choose a tab for where the file lives, then select the file you'd like to convert.

Choose Continue.

Your uploaded file becomes a PDF and lands in Adobe cloud storage.
