# Learn how to delete templates.

Keeping your template library tidy and trimmed is simple: delete the stale or unused templates straight from Acrobat on the web.

Note

Delete a library template and it's gone permanently, with no way to bring it back.

From the Acrobat on the web homepage, choose Documents.

Beneath Agreements, choose Templates.

Pick out the template you'd like to delete.

Over in the right pane under Actions, choose Delete.

A dialog box opens; in it, choose Delete.

A template can be removed by picking the Delete option out of the Actions menu.
