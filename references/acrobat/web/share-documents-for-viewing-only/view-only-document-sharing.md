# See how any document can be handed to others purely for viewing.

Hand off a document directly and a link arrives in each recipient's email. One click on it opens the document in a browser, no sign-in required.

From the Acrobat on the web homepage, pick Documents.

Within Your documents or Recent files, hover over the one you'd like to pass along, then pick Invite .

Alternatively, open the document, check it over, and reach for the share tool on the main menu.

Another route: open it, confirm the content looks right, and pick the share tool from the main menu.

Once the dialog box appears, key in the recipients' email addresses.

Begin keying the recipient's details into the Enter name or email field. Grabbing a link to the document to pass around is also an option.

In the Enter name or email field, start entering who it's for. You may instead fetch a shareable link to the document and distribute that.

Make sure the Allow comments option is switched off.

Pick Invite.

With the document shared, each recipient gets an email alert carrying a link to open and read it. That shared document then turns up under your Shared by you documents list.
