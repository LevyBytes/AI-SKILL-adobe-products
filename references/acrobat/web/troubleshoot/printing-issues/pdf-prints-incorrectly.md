# PDF prints incorrectly

Steps to take when the Acrobat browser extension prints a PDF incorrectly.

When a PDF's content is corrupt, printing can break down even though the file looks fine on screen.

Bring up the PDF in your browser.

Pick Print, download, and more > Open in desktop app.

To work through printing trouble, you can bring the PDF up in the Acrobat desktop application.

Print the PDF.

Tip

Another approach: open the PDF inside a Google Chrome or Microsoft Edge incognito window and print from there.
