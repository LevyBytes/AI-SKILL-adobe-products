# Source PDF quality is low

A PDF you're exporting may convert at low quality if it began life in Microsoft Word and was then turned into a PDF by way of Print to PDF or Scan to PDF.

To get a high-quality result, run the document through Convert to PDF first, then export it.

From the Acrobat on the web homepage, select Convert > Convert to PDF.

Pick Add a file from your device and browse to the file you want to upload.

When the PDF has finished, select Convert from the top menu.

Beneath Export a PDF to, pick the format you want, then select Convert to [selected format].
