# Edit images

Find out how Acrobat on the web lets you rotate, reposition, or remove images.

Right from your browser, images inside your PDFs are simple to edit, keeping your documents tidy and easy on the eyes.

From the Acrobat on the web homepage, choose Edit > Edit text & images.

Pick Select a file and browse your device to upload the PDF file.

Pick the image you want to edit and reach for the tools in the Edit panel to make changes:

- Spin the image clockwise by choosing Rotate right
- Spin the image anti-clockwise by choosing Rotate left
- Get rid of the image by choosing Delete image
- Swap the image by choosing Replace image, then using the dialog box that appears to pick an image.
- Put text on the image by choosing Add text, then dragging the cursor where you want it and typing. Once text is in place, the text tools in the left panel let you reposition or reformat it.
- Shift the image elsewhere by hovering over it until the drag handle icon shows, then dragging the image to its new spot.

The refreshed PDF shows the edited images, and every change syncs automatically into Adobe cloud storage.

As you reposition an image, the horizontal and vertical dotted lines help you line it up precisely.
