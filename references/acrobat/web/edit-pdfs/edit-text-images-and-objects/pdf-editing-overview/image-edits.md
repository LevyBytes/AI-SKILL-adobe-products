# Image edits

- Basic editing: Drop in, swap out, resize, and reposition images inside your PDF.

Tip

When heavier editing is needed, image editing tools such as Adobe Photoshop or Adobe Illustrator are the better route before you bring images into your PDF.

- Performance: Shrink an image before you insert it to keep the document running smoothly, since hefty image files can drag on performance.
- Accessibility tools: Attach alternative text to images and tag them properly so screen readers navigate them more easily.
