# Supported file formats for combining or converting

Discover which file types Acrobat on the web is able to convert or combine.

Acrobat on the web lets you fold together and convert a range of file formats into PDFs, keeping things compatible no matter the platform. That matters for anyone pulling reports, presentations, and assorted documentation from many sources into one unified PDF.

Because so many formats are supported, text documents, spreadsheets, presentations, images, and more slot easily into your PDFs, which lifts both productivity and collaboration.
