# Review PDF Spaces

Discover how to review shared PDF Spaces within Adobe Acrobat, contributing comments, annotations, and feedback that match the permission level you've been granted.

Collaboration runs smoothly when you review shared PDF Spaces, since it lets you weigh in on files, notes, and insights. What you're allowed to do during review hinges on the permission level assigned to you: Viewer, Reviewer, or Contributor. A Contributor enjoys full access, which covers managing files and notes, contributing fresh content, and deleting or editing whatever already exists inside the PDF Space.

Learn more about collaborating on PDF Spaces.

Bring up the invitation email and select Open PDF Space. Sign in afterward if you're asked to.

Note

A PDF Space set to public access can open with no sign‑in needed. When a PDF Space is restricted to an organization or shared privately, anyone receiving it has to sign in first.

Take a look at the PDF Space and interact with it. The things you can do:

- Walk through the Overview to grasp what the PDF Space is for and how it's laid out
- See and engage with every piece of shared content, including files, audio summaries, podcasts, and notes
- Read through comments and notes already present
- Put questions or summary requests to the AI Assistant
- Grab the PDF Space link and pass it along to others

Note

Run into content in a file that's offensive or inappropriate? Select More options > Report abuse and complete the form so it gets flagged for review.

Look over the project files. The things you can do:

- Open every shared file and read it.
- Move from one file to another within the project.
- See comments and notes already present.

Note

Run into content in a file that's offensive or inappropriate? Select More options > Report abuse and complete the form so it gets flagged for review.

(Reviewer or Contributor access only) Go over the content and attach comments or annotations.

Bring up a file or note, highlight the text with the Select text tool on the Quick action toolbar, and then settle on an action in the floating toolbar:

- Add a comment
- Highlight text
- Strikethrough text
- Underline text
- Copy text
- Save as note

Note

Anyone with project access sees every comment. A Comments icon marks any file or note that carries comments, and selecting it lets you read them and reply.

Picking out text within a file to spin into notes or feed to the AI Assistant turns plain reading and review into insights you can act on.

(Contributor access only) Handle the notes and look after the project files:

- Add notes: From the left pane, choose Notes, after which you select Create a note.
- Add files: Either drop them onto the Files panel, or reach for Select a file to bring in whatever belongs there.
- Rename files: Go to More options > Rename file.
- Remove files or notes: Use More options > Remove file.

Tip

Taking a file out of the PDF Space leaves the original untouched.
