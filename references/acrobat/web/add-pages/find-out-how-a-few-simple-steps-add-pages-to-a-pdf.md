# Find out how a few simple steps add pages to a PDF.

From the Acrobat on the web homepage, choose Edit > Insert pages.

Pick Select files and browse your device to upload whichever file should receive the new pages.

Choose where the new pages ought to land.

Choose the plus icon at the spot where the new pages should go.

When the Organize Pages: Insert dialog box appears, pick the file you'd like to pull the pages from, then choose Continue.

Choose Save.

Tip

With the pages added, you're free to reorganize, rotate, delete, add, and even design a new page.

The refreshed PDF carries the added pages and saves itself automatically into Adobe cloud storage.
