# Mark up with redlining tools

A walkthrough for marking up and reviewing documents with redlining tools that make edits and comments stand out clearly.

For tracking and calling out changes on a document, Acrobat on the web hands you these commenting and markup features:

- Highlight selected text: Draw the eye to text by swapping its background color.
- Strikethrough selected text: Flag text for cutting by running a line across it.
- Underline selected text: Lend emphasis or signal text edits.
- Insert text: Drop in new text.
- Replace selected text: Put forward substitutes for text already there.
- Add comments: Leave feedback inside a chat bubble.
- Draw freehand: Sketch to get your feedback across.

From the Acrobat on the web homepage, choose Documents.

Pick the right category over in the left pane, then choose whichever document you mean to review.

Pick out the text you want to mark up.

Marking up content in a PDF goes like this: pick the region you mean to review, then grab the right tool off the Context menu.

To apply your markup, grab a redlining tool from the Context menu that pops up:

- Highlight selected text
- Underline selected text
- Strikethrough selected text

For more options, grab a tool off the Quick Actions toolbar:

- Choose Add comment > Replace selected text. Key the suggested substitute text into the box that appears.
- Choose Draw freehand , then sketch with the pen cursor.
- Choose Add comment > Insert text. Key the proposed new text into the box that appears.

Choose Insert text and a text box shows up where suggested text can go.

For adding comments, choose Edit, delete, or reply to comments over in the right pane. Into the Comments pane that shows up, key your comment and choose Post. Drag the chat bubble to whatever spot on the document you want.

Recoloring a highlight or drawing starts with selecting it, then choosing Change color out of the Context menu. Grab whatever color you want off the palette.

Recoloring the markup by way of the color palette is something the Context menu lets you do.

Removing a markup means selecting it, then choosing Delete out of the Context menu.
