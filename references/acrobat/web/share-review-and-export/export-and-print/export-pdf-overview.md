# Export PDF overview

Get familiar with the file types you can target and a few handy tips for exporting PDFs in Adobe Acrobat on the web.

Converting a PDF into something editable — DOCX, XLS, or RTF — is straightforward with the Export a PDF tool in the browser version of Acrobat. Because it holds onto the document's original layout and formatting, you save time and move between file types cleanly, which keeps your work flowing.
