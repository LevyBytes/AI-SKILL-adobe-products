# See how one PDF file gets divided into several PDFs.

Bulky PDFs break down into tidier, smaller pieces with Acrobat on the web. By marking particular pages or ranges, you turn out individual PDF documents quickly.

From the Acrobat on the web homepage, pick Edit > Split a PDF.

Pick Select a file, then browse your device to bring in the PDF you intend to divide.

Tap the dotted horizontal divider lines to flag where the pages should break into separate PDFs.

Tip

Selecting the dotted lines recolors them blue. The page count of your PDF caps you at up to 22 divider lines for splitting it.

Between the page thumbnails you'll spot dotted lines; tap one to call for a split right at that spot.

Pick Continue.

When the Save your split files dialog box appears, tick the Save in a new folder checkbox so the resulting PDFs land in their own folder.

Pick Save.

The PDF divides into several PDFs that go to Adobe cloud storage. Reach them later from either the Recent or the Documents section.
