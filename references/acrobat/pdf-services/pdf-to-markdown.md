# PDF to Markdown

The PDF Services cloud API converts native or scanned PDFs into a primary `.md` document. It preserves document hierarchy, reading order and Markdown formatting for downstream document and LLM workflows.

- Check whether an input can be processed and estimate its transaction use. [Document requirements and limits](pdf-to-markdown/document-requirements.md).
- Authenticate, upload a PDF, submit a conversion and retrieve its result. [REST API workflow](pdf-to-markdown/rest-api.md).
- Interpret headings, tables, figures and structural element names. [Output structure](pdf-to-markdown/output-structure.md).
- Choose an ingestion, publishing or analysis workflow. [Use cases](pdf-to-markdown/use-cases.md).

For language-specific setup and examples, open the [.NET quickstart](https://developer.adobe.com/document-services/docs/overview/pdf-extract-api/quickstarts/pdf-to-markdown/dotnet/) or [Python quickstart](https://developer.adobe.com/document-services/docs/overview/pdf-extract-api/quickstarts/pdf-to-markdown/python/). Request figure extraction when images are needed in the Markdown output.
