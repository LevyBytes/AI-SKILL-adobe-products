# Compress PDFs with Compression Level

Shrink a PDF's footprint according to a compression level you choose, before kicking off workflow steps that draw on bandwidth or memory. The set of valid compression levels is documented under `CompressionLevel` in the API docs.

For guidance on calling these APIs, consult the [API usage guide](https://raw.githubusercontent.com/AdobeDocs/pdfservices-api-documentation/main/src/pages/overview/pdf-services-api/howtos/api-usage.md).
