# PDF Extract output

PDF Extract identifies document elements such as paragraphs, lists, headings, tables and images, then returns text, formatting and structural relationships as JSON. Table data can also be supplied as CSV or XLSX, and extracted image renditions use PNG.

Open the [extraction output reference](../extract-api.md) for the archive layout, element fields, schemas and rendition paths. Use the [official PDF Extract guide](https://developer.adobe.com/document-services/docs/overview/pdf-extract-api/howtos/) when checking output options and complete examples.

For document-processing security controls, see Adobe's [Document Services security overview](https://www.adobe.com/cc-shared/assets/pdf/trust-center/ungated/whitepapers/doc-cloud/adobe-document-services-security-overview.pdf).
