# February 4, 2025; Server Side Release

- The PDF Services API gained an [Export PDF Form Data API](../export-pdf-form-data/reference-index.md) operation that pulls data from a PDF form and hands it back as a JSON file.
- The PDF Services API gained an [Import PDF Form Data API](../import-pdf-form-data/reference-index.md) operation that fills PDF forms from JSON data and produces the finished PDF.
