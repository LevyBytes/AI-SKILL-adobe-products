# Document Requirements

Use an unprotected PDF, or one that permits content copying. Password-protected content is unsupported.

The conversion does not support hidden objects (JavaScript or OCG), XFA or fillable forms, complex annotations, CAD drawings or vector art.

## Processing and usage limits

| Constraint | Limit |
| --- | --- |
| Input file size | 100 MB. |
| Native PDF pages | 400. |
| Scanned PDF pages | 150. |
| Requests per minute | Enterprise: 100; free tier: 25. |
| Free-tier allowance | 500 Document Transactions per month. |
| Conversion accounting | One Document Transaction for each group of up to five pages. An eight-page PDF uses two. |

Table-heavy documents can have lower page limits. Enterprise agreements can alter supported file-size and request-rate limits; confirm the applicable agreement through Adobe.

Check the current [Licensing and Usage Limits](https://developer.adobe.com/document-services/docs/overview/limits) before sizing a workload. These are PDF Services conversion limits; they are distinct from Acrobat desktop or AI Assistant limits.
