Use `storage: "SHAREPOINT"` with a supported SharePoint signed URI for the required transfer. Obtaining access to the file or creating an upload session requires the application's Microsoft authorization and permissions. A preauthenticated transfer URL delegates access without giving Adobe the application's separate Microsoft bearer token.

The [Microsoft Graph download contract](https://learn.microsoft.com/en-us/graph/api/driveitem-get-content?view=graph-rest-1.0) returns a `302` from `/content` to a short-lived preauthenticated URL, also exposed as `@microsoft.graph.downloadUrl`. Adobe's external-storage interface does not follow redirects, so a Graph `/content` endpoint is not a direct file URL. Check the actual transfer URL against the [supported SharePoint host pattern](supported-url-prefixes.md#sharepoint); do not assume every Graph or OneDrive URL is accepted.

For output, consult the [upload-session contract](https://learn.microsoft.com/en-us/graph/api/driveitem-createuploadsession?view=graph-rest-1.0) for the upload URL, expiry and byte-range requirements. Those requirements differ from downloading. Verify that the chosen operation and provider transfer contract match before using the [external-storage request](../overview-external-storage-for-adobe-pdf-services-apis.md).
