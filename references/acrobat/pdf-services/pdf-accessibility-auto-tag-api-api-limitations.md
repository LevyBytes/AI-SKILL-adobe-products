# PDF Accessibility Auto-Tag API - API limitations

- **File size:** The maximum accepted file size is 100 MB.
- **Number of Pages:** Up to 200 pages are handled for non-scanned PDFs and up to 100 pages for scanned ones, though documents carrying many tables may hit a lower ceiling.
- **Rate limits:** Hold your request rate under 25 requests per minute.
- **Page Size:** Neither dimension may go beyond 17.5” or fall under 6”; standard page sizes within that window are accepted.
- **Hidden Objects:** Anything not visible on the page — JavaScript, OCG (optional content groups), and the like — falls outside support, and a file carrying such hidden material can fail during processing. When that happens, [removing hidden content](https://helpx.adobe.com/acrobat/using/removing-sensitive-content-pdfs.html) before resubmitting the file may yield a successful outcome.
- **Language:** English is what the API is currently tuned for. Documents written in French, German, Spanish, Danish, Dutch, Norwegian (Bokmal), Galician, Catalan, Finnish, Italian, Swedish, Portuguese, and Romanian tend to come back with good results most of the time. Content in Afrikaans, Bosnian, Croatian, Czech, Hungarian, Indonesian, Malay, Polish, Russian, Serbian, Turkish, Hindi, Marathi and comparable languages will frequently do well too. Non-English punctuation can be a sticking point for non-English files. OCR itself is set up for English.
- **OCR and Scan quality:** How clean the source file is drives the quality of text pulled from scanned documents, and the extraction is presently tuned for English. Skewed pages, shadowing, fonts that are obscured or overlapping, and resolution below 200 DPI each tend to degrade the resulting text.
- **Form fields:** XFA and other fillable form components are not handled.
- **Unprotected files:** Files that carry no protection, or whose security settings still permit content editing, are accepted; ones locked down so editing is disallowed will be skipped. Should you know the password of a protected PDF, you can adjust its permissions through the PDF Services API as demonstrated [here](remove-protection.md).
- **Annotations:** A PDF carrying annotations such as highlights and sticky notes still gets processed, yet annotations sitting over text can drag down output quality. Whatever text lives inside annotations is left out of the result.
- **PDF Producers:** Adding tags to a PDF so it is easier to make accessible is the purpose of the PDF Accessibility Auto-Tag API. Documents generated by tools that produce other kinds of content — illustrations, CAD drawings, or assorted vector art — may not come back with high-quality results.
- **PDF Collections:** A PDF assembled from a set of files, PDF Portfolios included, is not supported at this time.
