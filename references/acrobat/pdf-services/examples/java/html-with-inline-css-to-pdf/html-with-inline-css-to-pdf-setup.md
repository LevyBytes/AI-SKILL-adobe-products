# Html with inline css to pdf example setup

Open when running or adapting the linked html with inline css to pdf example.

The complete program is Adobe's [source sample](https://raw.githubusercontent.com/adobe/pdfservices-java-sdk-samples/25f97d7b48719e0ed26878e734d2840b39870624/src/main/java/com/adobe/pdfservices/operation/samples/htmltopdf/HTMLWithInlineCSSToPDF.java). The [call pattern](../CallPattern.java) shows the shared upload, submit, wait and download sequence; the [operations table](../operations.md) lists this example's job, parameter and result classes.

Supply your own PDF Services credentials through the environment variables or credentials object used by the example. The SDK, service access and input documents are external prerequisites; no credentials or sample binaries are bundled here.

## Input paths

- `src/main/resources/createPDFFromHTMLWithInlineCSSInput.html`

## Source implementation notes

- This sample illustrates how to create a PDF file from an HTML file with inline CSS. Refer to README.md for instructions on how to run the samples.
- Initialize the logger
- Initial setup, create credentials instance
- Creates a PDF Services instance
- Creates an asset(s) from source file(s) and upload
- Create parameters for the job
- Creates a new job instance
- Submit the job and gets the job result
- Get content from the resulting asset(s)
- Creates an output stream and copy stream asset's content to it
- Define the page layout, in this case an 8 x 11.5 inch page (effectively portrait orientation)
- Generates a string containing a directory structure and file name for the output file
