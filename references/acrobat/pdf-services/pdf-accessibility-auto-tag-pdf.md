# Pdf Accessibility Auto Tag Pdf

> Adobe Acrobat reference. Original prose; identifiers preserved verbatim.

What the PDF Accessibility Auto-Tag API returns breaks down into two parts:

- The PDF that has been tagged.
- When report generation was switched on, an XLSX-format report as well. That report surfaces details about whichever tags turned up in the source document, plus the tags applied to the auto-tagged version.
