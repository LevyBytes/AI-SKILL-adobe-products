## When agents open this product area

Use when creating, editing, reviewing, signing, securing, or troubleshooting PDFs in Adobe Acrobat desktop, web, or Reader; automating Acrobat with JavaScript; or integrating Adobe PDF Services, Document Generation, PDF Extract, PDF Embed, or electronic seals. Includes forms, accessibility, printing, and Acrobat AI workflows.

## The work behind the references

Adobe Acrobat references for document workflows, PDF automation and application integration. Desktop, web and mobile tasks have separate routes from JavaScript and document-service APIs, keeping the relevant product surface explicit. Examples apply to desktop, web, mobile or service behavior as each reference states, and the index also links Document Generation, PDF Embed, application integrations and AI workflows.
