# Keys for editing audio files

Scope: Waveform Editor only.

| Result | Windows shortcut | macOS shortcut |
| --- | --- | --- |
| Repeat the previous command (opening its dialog box and selecting OK) | Shift+R | Shift+R |
| Repeat the previous command (opening its dialog box but not selecting OK) | Ctrl+R | Command+R |
| Open the Convert Sample Type dialog box | Shift+T | Shift+T |
| Capture a noise reduction profile for the Noise Reduction effect | Shift+P | Shift+P |
| Activate the left channel of a stereo file for editing | Up arrow | Up arrow |
| Activate the right channel of a stereo file for editing | Down arrow | Down arrow |
| Make the spectral display more logarithmic or linear | Ctrl+Alt+up or down arrow | Option+Command+up or down arrow |
| Make the spectral display fully logarithmic or linear | Ctrl+Alt+Page Up or Down | Option+Command+Page Up or Down |
| Increase or decrease spectral resolution | Shift+Ctrl+up or down arrow | Shift+Command-up or down arrow |
