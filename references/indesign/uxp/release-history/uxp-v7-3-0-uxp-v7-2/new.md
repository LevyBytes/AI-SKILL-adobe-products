# New

- Multipart `FormData` is available for [Request](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/reference-js/global-members/data-transfers/request.md) and [Response](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/reference-js/global-members/data-transfers/response.md) when used with [fetch](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/reference-js/global-members/data-transfers/fetch.md).
- [FormData](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/reference-js/global-members/data-transfers/form-data.md) includes these APIs:
  - delete()
  - get()
  - getAll()
  - has()
  - keys()
  - set()
  - values()
- **(Photoshop Only)** GUID support for unique Creative Cloud User identification.
- **(Photoshop Only)** Support for Adobe Extensibility Metadata Platform (XMP).
- The [pointer-events: none](https://developer.mozilla.org/en-US/docs/Web/CSS/pointer-events) `CSS` property is available.
- `pseudoElement` is supported by the [getComputedStyle(element, pseudoElement)](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/reference/uxp-api/reference-js/global-members/html-dom/get-computed-style.md) API.
