# :focus

**Since** UXP v3.0

Selects the element that currently has focus. In this context, the active state corresponds to keyboard focus on that element.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:focus](https://developer.mozilla.org/en-US/docs/Web/CSS/:focus)

**Example:** 

```css
input:focus {
  border: 1px solid red;
}
```

Host limitations: [Quirks and Exceptions](focus/quirks-and-exceptions.md).
