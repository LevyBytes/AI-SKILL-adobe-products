# :nth-child

**Since** UXP v3.0

Applies to a child at the Nth position; the selector also accepts an expression, `even`, or `odd`.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-child](https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-child)

**Example:** 

```css
.row:nth-child(even) {
  background-color: #E8E8E8;
  /* color even rows */
}
```
