# :active

**Since** UXP v3.0

Selects the element while it is in the active state. In UXP, an element enters that state during an active user click.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:active](https://developer.mozilla.org/en-US/docs/Web/CSS/:active)

**Example:** 

```css
p:active {
  background-color: yellow;
}
```

Host limitations: [Quirks and Exceptions](active/quirks-and-exceptions.md).
