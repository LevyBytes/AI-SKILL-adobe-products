# CSS Units

**Since** UXP v3.0

UXP includes several CSS units for easier layout work. Supported units are `em`, `rem`, `vh`, `vw`, `vmin`, `vmax`, `cm`, `mm`, `in`, `pc`, `pt`, `px`.

**See**: [https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Values_and_Units](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_Values_and_Units)
