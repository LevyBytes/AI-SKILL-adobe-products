# width

**Since** UXP v4.1

Use this media feature to limit CSS rules so they apply only when the plugin dialog or panel width satisfies the conditions you define.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/@media/width](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/width)

**Example** 

```css
@media (max-width: 700px) {
  .someElement {
    background-color: red;
  }
}
```
