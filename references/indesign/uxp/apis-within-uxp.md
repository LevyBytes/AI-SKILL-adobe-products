# APIs within UXP

Once an initial [script](building-your-first-script.md) or [plugin](uxp-plugins.md) is working, more involved tasks require access to additional APIs. Start by identifying the API types available and where to find them.

The UXP platform has two main parts:

1. Core UXP APIs
2. Host-specific APIs

You will find examples of these APIs in the [recipes](recipes.md). For now, focus on the difference between the two categories.
