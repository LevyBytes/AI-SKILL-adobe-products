# IpcPermission

Turns on inter-plugin messaging.

**Example**

```json
{
  "enablePluginCommunication": true
}
```

### Properties

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `enablePluginCommunication` \* | `boolean` | required | Turns plugin-to-plugin communication on. |

The [inter-plugin communication example](https://raw.githubusercontent.com/AdobeDocs/uxp-indesign/cba672dce97bcb5805baaa7558d83abbabd825f6/src/pages/plugins/tutorials/inter-plugin-comm/index.md) provides additional detail.
