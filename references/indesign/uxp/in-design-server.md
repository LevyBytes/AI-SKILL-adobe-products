# InDesign Server

Adobe InDesign Server software provides the layout and composition engine behind automated publishing workflows. It is derived from desktop InDesign, but it does not include a built-in user interface.

Begin with [InDesign Server background](https://helpx.adobe.com/in/indesign/using/indesign-server.html), then use [get started with UXP scripts](building-your-first-script.md) for the local setup.
