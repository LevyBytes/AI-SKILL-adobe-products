# Bleed and slug modes for verification

Before output, check the bleed and slug with the specialized views under View > Screen Mode.

| Screen modes | Display |
| --- | --- |
| Normal | Shows the standard editing workspace. |
| Preview | Uses a gray background instead of the pasteboard and shows the final page trim. |
| Bleed | Uses a gray background instead of the pasteboard and makes the bleed area visible. |
| Slug | Uses a gray background instead of the pasteboard and makes the slug area visible. |
