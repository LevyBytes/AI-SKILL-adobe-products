# Create unequal column widths

InDesign can build custom column layouts with different widths by manually moving column guides on specific pages or spreads. Use this method for asymmetric layouts or specialized column arrangements.

Go to the page or spread where unequal columns are needed.

Choose View > Grids & Guides and clear Lock Column Guides.

With the Selection tool, drag a column guide to a new position. Column guides are paired and move together so the specified gutter width is maintained. A guide cannot be dragged past a neighboring column guide or beyond the page edge.
