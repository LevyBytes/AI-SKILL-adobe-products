# Copy a parent within a document

In the Pages panel (Window > Pages), find the parent spread you want to copy.

Drag the parent spread's page name onto the Create new page icon at the bottom-right of the panel.

Another way to duplicate a parent page is to right-click the parent page name and choose Duplicate Parent Spread &lt;spread name&gt; from the context menu. When a parent page is duplicated, InDesign gives the copy the next available letter as its page prefix. For example, duplicating A-Parent creates a copy named B-Parent.
