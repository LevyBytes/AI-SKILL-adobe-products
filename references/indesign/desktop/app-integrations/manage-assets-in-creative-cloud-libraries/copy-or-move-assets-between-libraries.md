# Copy or move assets between libraries

Choose Window > CC Libraries, then choose the library that holds the assets you plan to copy or move.

In the CC Libraries panel, right-click one or more assets.

For one asset, choose Copy to or Move to from the context menu.

When several assets are selected, choose Copy selected items to or Move selected items to.

In the submenu, choose the destination library and choose Copy.

Moving an asset takes it out of the current library and adds it to the destination library. Copying makes a duplicate in the destination library while the original stays where it is. Asset properties are retained by both actions, including names and styling information.
