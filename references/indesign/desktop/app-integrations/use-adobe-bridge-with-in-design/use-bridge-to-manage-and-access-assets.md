# Use Bridge to manage and access assets

Bridge supports these actions:

- Manage image, footage, and audio files: In Bridge, preview, search, sort, and process files without launching each individual application. You can edit file metadata as well, then place Bridge files into projects, compositions, or documents.
- View the links inside an InDesign document as thumbnails: While working in Bridge, inspect thumbnail previews of an InDesign document's links without opening the file in InDesign.
- Drag assets from Bridge into the InDesign document window: Move assets from Bridge into the InDesign document window, or move assets from the document window back into Bridge, to create and use snippets.
- Perform automated tasks: Run automation such as batch commands.
- Synchronize color settings: Keep color settings aligned across color-managed Creative Suite components.
- Start a real-time web conference: Begin a live web conference for desktop sharing and document review.
