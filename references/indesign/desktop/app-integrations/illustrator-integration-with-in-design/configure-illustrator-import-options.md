# Configure Illustrator import options

Choose File > Place.

Choose Show Import Options, select the Illustrator file, and then choose Open.

On the General tab, select the page or artboard to place when the file includes multiple artboards.

Use the Crop to drop-down menu to choose the imported bounding area: Bounding Box, Art, Crop, Trim, Bleed, or Media.

Choose Window > Layers. The Layers panel appears only when the Illustrator file has more than one layer. Any layers hidden in Illustrator can still be reached in InDesign through the Object Layer Options dialog box after placement.

Show or hide individual Illustrator layers by checking or unchecking their layer names.

Choose OK.
