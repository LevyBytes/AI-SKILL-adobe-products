# Edit text in the browser

Use Google Chrome to open the shared document link. If prompted, sign in with your Adobe ID.

Move the pointer over a text frame. The cursor changes to show that the frame can be edited.

Click inside the frame to start editing. Use the bold icon and italics icon to apply text formatting.

- A. Cloud sync status: sync indicator.
- B. Threaded text: thread-flow indicator.
- C. Collaborators present on the document: presence indicator.
- D. Pages panel: page navigation.
- E. Overset text: overflow indicator.
- F. Focus Mode: focused writing view.
- G. Italics text format: italic styling.
- H. Bold text format: bold styling.
- I. Locked frame as the collaborator is working on it: unavailable frame state.

Choose the Focus Mode icon to enter a clean writing view with fewer distractions. Threaded frames indicate how text continues through multiple containers. When content goes beyond the available space, an overset text icon is shown on the frame.

After editing, choose the Go Back icon. Changes sync automatically to the InDesign document.

To send product feedback, choose the Help icon, then choose Submit Feedback.

About real-time sync and sync status

- Real-time sync keeps the desktop app and web aligned.
- Frame locking stops two people from changing one text frame simultaneously.
- Locked frames show the collaborator's avatar, name, and color highlight.
- InDesign shows collaborator presence and alerts users who attempt edits on a locked frame.

Cloud sync status tells you whether web and desktop are matched:

- indicates the desktop app and web currently match.
- signals unsynced changes from the InDesign desktop app on the web side; reload the document.
