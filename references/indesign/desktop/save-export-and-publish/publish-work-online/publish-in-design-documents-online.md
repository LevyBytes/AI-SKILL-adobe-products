# Publish InDesign documents online

Publish Adobe InDesign documents online when they need to be shared, updated, and viewed in a browser.

Publish Online turns print-ready documents into web publications that open in common browsers on any device. It supports interactive elements including buttons, slideshows, animations, audio, and video, while keeping the layout faithful to the document. Before publishing, confirm that an internet connection is available and that the InDesign document is ready.

Open an InDesign document and choose File > Publish Online.

Open the General tab to add Title, Description, Pages, Export As, or Enable Password Protection.

Open the Advanced tab to add items such as Cover Thumbnail, Image Settings, Download PDF Settings, etc.

Open the Analytics tab to connect your Google Analytics account with the published document.

Choose Export HTML5 Package when you want to export your InDesign document as an HTML5 package.

Choose Publish to publish the document online. When republishing an existing document, choose Update Existing Document, then choose an existing document from the drop-down list.

Choose File > Publish Online Dashboard to see the published-document list. Google Analytics can also be configured for published documents.

Note

A verified Adobe ID is required before an InDesign document can be published. Unverified users cannot publish InDesign documents. For an embedded password-protected document with multiple pages, the password must be entered again each time a page is changed with the dropdown menu.
