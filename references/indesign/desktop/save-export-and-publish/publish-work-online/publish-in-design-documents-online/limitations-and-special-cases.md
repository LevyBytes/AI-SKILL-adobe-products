# Limitations and special cases

- Password-protected documents with multiple pages: When a protected document is embedded, changing pages through the page dropdown menu prompts viewers for the password again each time.
- Embedded HTML content: Published documents can include embedded HTML content only from websites that InDesign supports. If the embedded site is unsupported, the published output shows the HTML content as blocked.
- Browser requirements: A browser with TLS 1.2 support is required to open published documents.
- Maximum export size: If Download PDF is enabled, PDF export crops anything beyond 200" × 200".
