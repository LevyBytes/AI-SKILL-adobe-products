# Add and edit data fields

Insert field placeholders and format them so merged data appears the way you need in an Adobe InDesign document.

Once a data source is selected in the Data Merge panel, add field placeholders to the target document at the positions where variable content should appear. Text placeholders appear in double angle brackets, such as <&lt;name&gt;>, and image fields appear as image frames. Formatting applied to those placeholders controls the look of merged results. The Data Merge panel lists every field available from the source and uses icons to distinguish text fields from image fields.
