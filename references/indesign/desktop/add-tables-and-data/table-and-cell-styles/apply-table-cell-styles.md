# Apply table cell styles

Use cell styles in InDesign when table-cell formatting needs to remain consistent.

InDesign cell styles give document tables a repeatable way to format individual cells. A cell style can manage text formatting, borders, fills, and spacing inside a cell. Apply one directly to selected cells, or assign cell styles to defined table areas through table styles. Because the reusable formatting is stored in the style, consistency is maintained while unrelated cell properties can stay as they are.
