# Clear overrides while applying a table style

Open Window > Styles > Cell Styles or Table Styles.

Choose a table or cell that has overrides.

Use Clear overrides in selection icon, or hold Alt (Windows) or Option (macOS) while choosing the style.

To apply a table style and clear overrides plus cell styles at the same time, press Alt+Shift (Windows) or Option+Shift (macOS) while choosing the style in the panel.
