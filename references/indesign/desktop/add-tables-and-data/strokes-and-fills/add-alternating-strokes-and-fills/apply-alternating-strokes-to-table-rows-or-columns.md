# Apply alternating strokes to table rows or columns

Put the insertion point inside a table, or select a cell.

Choose Table > Table Options > Alternating Row Strokes or Alternating Column Strokes.

From the Alternating Pattern drop-down menu, choose the pattern you want.

For First and Next rows, define weight, type, color, tint, and gap color.

Use Skip First for rows or columns at the start, and use Skip Last for rows or columns at the end.

Enable Preserve Local Formatting when individual cell stroke formatting should remain unchanged.

Select OK.
