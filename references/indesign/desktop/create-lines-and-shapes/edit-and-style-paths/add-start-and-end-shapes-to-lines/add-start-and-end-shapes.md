# Add start and end shapes

Create an open path, or draw a line with the Line tool.

Show the Stroke panel from the docked panel workspace. If it is not visible, open Window > Stroke.

Use the Selection tool to select the path or line.

In the Stroke panel, choose a shape from the Start menu to assign it to the first endpoint.

Choose a shape from the End option to assign it to the last endpoint.

Use the Stroke panel to preview and apply start and end shapes on strokes.

Preview strokes in the Stroke panel and apply the chosen start and end shapes.
