# Apply corner effects using Corner Options

Use the Selection tool to choose the frame or path that needs changes.

Open Object > Corner Options.

Click the Make all settings the same icon when every corner should share one effect, or turn it off to set corners individually.

From the corner effect dropdown menus, choose Fancy, Bevel, Inset, Inverse Rounded, or Rounded.

Enter a size value that determines how far the effect reaches from each corner point.

Turn on Preview to inspect the result, then click OK.
