# Apply corner effects using Live Corners

Live Corners lets you change rectangular-frame corners by selecting the yellow box on the frame and dragging. Each corner can also use its own corner effect and radius.

Select a rectangular frame with the Selection tool.

Click the small yellow box near a frame corner. Four yellow diamonds appear on the selected frame to show that Live Corners mode is active.

If the yellow box is missing on the selected frame, open View > Extras > Show Live Corners.

Drag any diamond toward the frame center to change all four corner radii together.

Hold Shift while dragging a diamond to change just one corner.

Alt-click (Windows) or Option-click (macOS) a yellow diamond to move through the available effects.

Select anywhere outside the selected frame to finish corner editing.

To clear corner effects, open Object > Corner Options, then choose None from the corner effect dropdown menus.
