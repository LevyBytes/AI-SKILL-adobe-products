# Add or delete anchor points

Use the Pen tool options in Adobe InDesign to add or remove anchor points on paths.

Adding anchor points increases path control or lengthens an open path. Removing points you do not need simplifies paths, making them easier to edit, display, and print.

This workflow changes existing paths by altering how many anchor points they contain. For reshaping that involves moving anchor points or changing direction handles, switch to the Direct Selection tool.

On any selected path, anchor points can be added or deleted with the Pen tool, Add Anchor Point tool, or Delete Anchor Point tool. When the pointer is over a selected path or anchor point, InDesign changes the Pen tool to the matching mode automatically.

From the toolbar, select the Pen tool to draw the path.

Choose the Add Anchor Point tool, move the pointer to a path segment, and click to insert an anchor point.

Choose the Delete Anchor Point tool, move the pointer to an anchor point, and click to remove that anchor point.

Caution

When deleting anchor points, avoid the Delete or Backspace keys and the Edit > Cut or Edit > Clear commands. Those actions remove the point plus the connected line segments.
