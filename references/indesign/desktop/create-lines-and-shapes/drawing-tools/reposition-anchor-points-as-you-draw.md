# Reposition anchor points as you draw

Use this topic to move an anchor point while you are creating a path with the Pen tool in Adobe InDesign.

While drawing in InDesign, the Pen tool can reposition anchor points without breaking the current path operation. This lets you place points more accurately during path creation. It is helpful for exact shapes and detailed path refinement.

Choose the Pen tool.

Click and keep holding to place an anchor point.

Keep holding, and also hold the Spacebar.

Drag to move the anchor point into position.

Release the Spacebar, then release the pointer to set the point.
