# Manage automatic pen tool switching

Use this topic to override automatic Pen tool switching temporarily with keyboard shortcuts in Adobe InDesign.

In InDesign, you can control editing behavior by overriding automatic Pen tool switching while working on paths. Holding a tool shortcut key keeps the automatic switch from happening and supports precise edits. That prevents accidental path changes.

Activate the Pen tool.

Keep a tool shortcut key held down, such as A for Direct Selection.

Apply edits while the shortcut key remains held down.

Release the shortcut key to go back to the Pen tool.
