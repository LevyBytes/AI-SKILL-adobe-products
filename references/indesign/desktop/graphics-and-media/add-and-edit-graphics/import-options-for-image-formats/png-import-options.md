# PNG import options

PNG import includes the same color management controls used by PSD, TIFF, GIF, JPEG, or BMP files, plus a PNG Settings area.

| Option | Description |
| --- | --- |
| Use Transparency Information | Uses PNG transparency when the file provides it. |
| White Background | Applies a white background together with transparency. This option is available only while Use Transparency Information is enabled. |
| File-defined Background Color | Shows the stored background color when the file has one and Use Transparency Information is enabled. |
| Apply Gamma Correction | Changes midtones so they better align with display or print output. It is enabled by default when a gamma value is present. |
| Gamma Value | Sets the gamma value (0.01-3.0). The field appears only while Apply Gamma Correction is selected. For PNG placement without gamma correction, turn off Apply Gamma Correction before placing the file. |
