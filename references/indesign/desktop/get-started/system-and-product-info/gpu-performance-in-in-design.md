# GPU performance in InDesign

Learn how GPU acceleration in Adobe InDesign can improve rendering and interaction performance.

### Overview

The Graphics Processing Unit (GPU) handles rendering and display work. InDesign uses GPU acceleration to make interaction more responsive and performance smoother.

Rendering on high-resolution HiDPI displays can raise CPU usage. By moving rendering work to the GPU, InDesign enables smoother zooming, scrolling, and panning while maintaining high-quality display.

On supported systems, InDesign activates the GPU automatically and changes display performance to High Quality Display. If you encounter performance problems, use CPU rendering instead or adjust the preview mode.
