# macOS

- VRAM: Minimum 1024 MB VRAM (2 GB recommended)
- Metal support

On macOS, GPU acceleration uses the Metal API and improves responsiveness on Apple silicon hardware, beginning with M1.

The supported macOS device list covers:

- iMac models: 4K and 5K
- MacBook Pro with Retina
- Mac Pro with a HiDPI monitor connected
- Mac mini with a HiDPI monitor connected
