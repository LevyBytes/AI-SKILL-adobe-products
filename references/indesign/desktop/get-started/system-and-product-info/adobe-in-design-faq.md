# Adobe InDesign FAQ

Find answers to frequent questions about Adobe InDesign for professional page layout and publishing.

These questions often come up while teams assess InDesign for professional use, prepare new projects, or investigate advanced capabilities. The topics include software basics, workflow integration, and whether particular features are available.

InDesign is a professional page layout application used to build print and digital publications. It provides precise typography and layout control for designing, preflighting, and publishing magazines, brochures, books, posters, interactive PDFs, digital magazines, eBooks, and more.

Adobe InDesign supports print and digital publishing as a professional page layout application, letting you design, preflight, and publish many kinds of content for print, web, and tablet apps. Its feature set includes exact typography controls, integrated creative tools, an accessible design workspace, and close connections with Adobe Photoshop, Illustrator, Acrobat, and Adobe Animate.

Designers, prepress and production specialists, and print service providers use InDesign in magazines, design firms, advertising agencies, newspapers, book publishers, retail/catalog companies, corporate design departments, commercial printing operations, and other advanced publishing environments.

Because InDesign is included in Adobe Creative Cloud, the newest updates and future releases become available as soon as they are released. For more information, see Creative Cloud.

InCopy and InDesign Server sit alongside InDesign in an integrated publishing family. InCopy, which is included with a Creative Cloud plan, is a professional writing and editing application that works with InDesign to support collaborative editorial workflows for designers, writers, and editors. InDesign Server delivers high-end composition and layout on a server platform, adding automation for editorial workflows, collateral production, data-driven personalized publishing, and template-based web-to-print solutions.

Multi-page layout and typography are InDesign strengths, which makes it well suited to publications. Illustrator is used for vector artwork and logos, and Photoshop is used for raster images and photos. In many professional workflows, all three are used together: images are edited in Photoshop, graphics are created in Illustrator, and the final layout is assembled in InDesign.

InDesign works closely with Photoshop, Illustrator, Acrobat Pro, InCopy, and Flash Professional. Photoshop, Illustrator, Flash Professional, InCopy, and InDesign share interface patterns, commands, panels, and tools, making skills from one application easier to transfer to another and helping people move efficiently among them. Native Photoshop and Illustrator files can be imported, which simplifies laying out, improving, and updating graphics. Built-in PDF support helps produce reliable, consistent output for print, web, or devices; page layouts can be handed off with high fidelity, and animation, sound, and video files placed in documents can be retained. In addition, InDesign and InCopy combine to support strong editorial workflow management for small creative teams.

InDesign Server is a highly flexible, scalable, and robust layout and composition engine that can automate InDesign design, layout, and typographical capabilities. Built on the same code base as InDesign, it can support automated publishing solutions such as web-to-print, VDP, and editorial workflow solutions while providing the output quality expected from InDesign. Most InDesign Server-powered solutions rely on templates that designers create in the desktop version of InDesign.

Even though InDesign Server and the desktop version of InDesign share a code base, several important differences apply:

- InDesign Server functions as an engine for larger automated publishing systems.
- InDesign Server runs headlessly and has no built-in user interface. The user interface for an automated publishing solution powered by InDesign Server is designed by the customer or solution partner.
- Like InDesign, InDesign Server can be controlled with scripting or C++ plug-ins. It can also be controlled through a SOAP interface or Java APIs.
- Automated publishing solutions based on InDesign Server can expand as requirements grow, including support for multiple instances running on multiple processors.
- Rigorous testing helps InDesign Server provide long periods of continuous uptime.
- InDesign Server is designed and tested for server editions of Windows and macOS; included targets include Microsoft Windows Server 2008 R2.
- InDesign Server is sold separately and is not included in Creative Cloud.
