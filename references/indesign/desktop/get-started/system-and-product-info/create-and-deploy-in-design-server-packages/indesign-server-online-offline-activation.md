# Create online and offline activation for the InDesign Server package

Sign in to Admin Console. In the upper-right corner, find and apply the organization that includes InDesign Server.

Open the Packages tab, then choose Packages. The page lists the package history created by every admin in your organization.

Choose Create a Package.

On the next screen, set the activation method to Online or Offline, then choose Next. For connected environments, review Feature Restricted Licensing - Online; for offline environments, review Feature Restricted Licensing - Offline.

At the Entitlements step, choose the needed entitlement, then choose Next. The entitlement choices vary based on whether Online or Offline activation was selected in step 4.

At the System step, choose the needed settings, then choose Next.

- Choose a Platform: Select the macOS or Windows 64-bit operating system.
- Language: Choose the language used when the package is created.
- Use OS Locale: Builds a package that installs in the client machine's OS language. In this case, that OS language becomes the fallback default language for deployment.

At the Choose Apps step, choose whether the package should be License-only, Apps-only, or contain both an app and a license.

To confirm which versions your Creative Cloud plan supports, review the Creative Cloud Support policy. When the selections are complete, choose Next.

At the Options step, choose the required option, then choose Next. This step appears only for the online activation method.

At the Finalize step, type the package name in the Package Name box.

Choose Build Package. When the build succeeds, the Availability column shows the Download link.

The Admin Console keeps a package available for as long as three days. To see how much download time remains, select the package row and open its details.
