# Customize menus

Use Adobe InDesign menu customization to hide commands or apply colors, reducing workspace clutter and calling attention to commands you use often.

Menu customization can remove rarely used commands from view and mark high-use commands with color, keeping the interface centered on the workflows that matter most. When you need both focused and complete menu views, make multiple menu sets for particular tasks, such as Text Editing or Print Production, and save each one in its own workspace.
