# Reset document settings and preferences

Configure Adobe InDesign preferences and object settings as defaults for later documents and objects.

Document defaults give new projects a consistent starting state, which saves setup time and helps keep work uniform. InDesign uses two default levels: document-level defaults apply to new documents when no files are open, and object-level defaults apply to new objects when an open document has nothing selected. The values stay in place until changed again, so they are useful for standardized workflows.
