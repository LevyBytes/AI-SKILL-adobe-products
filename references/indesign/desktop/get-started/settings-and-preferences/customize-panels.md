# Customize panels

Organize panels in Adobe InDesign so the workspace supports the way you work.

Set up the panel layout so frequently used tools are easy to reach and the workspace stays clear. In InDesign, panels can be stacked, floated, or collapsed, and the layout is saved automatically. You can also store layouts as named workspaces with Window > Workspace > New Workspace, making it easier to switch between project types. For the best working setup, keep the panels you rely on most in convenient spots without covering the document view.
