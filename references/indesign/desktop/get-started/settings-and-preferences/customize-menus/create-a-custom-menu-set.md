# Create a custom menu set

Choose Edit > Menus.

Select Save As, type a descriptive name for the menu set, and choose OK.

In the Category dropdown menu, choose Application Menus to edit the main menu bar, or choose Context & Panel Menus for right-click and panel menus.

Expand menu categories with the arrows beside them so individual commands are visible. While selecting a menu name, hold Ctrl (Windows) or Command (macOS) to temporarily show commands hidden inside that menu.

For each command to customize, use the eye icon under Visibility to show it or hide it.

Under Color, select None and choose the highlight color from the menu.

Select Save to keep the changes, then select OK. The custom menu set becomes active and stays active until you choose a different menu set or change workspaces.
