# Search options to find and replace

Use the search options in Adobe InDesign to make finding and replacing content fit your workflow.

Efficient search tools can make content retrieval faster, reduce repetitive steps, and support more productive work.

To define where InDesign searches, choose any of these options:

- All Documents: looks through every open InDesign document.
- Document: limits the search to the current document. This option is selected by default.
- Story: checks all text in the selected frame, including text that continues into threaded text frames and overset text. The option is visible only when a text frame is selected or an insertion point is active.
- To End of Story: starts at the insertion point and continues to the end of the text frame. The option appears only when an insertion point is active.
- Selection: restricts the search to selected text. The option appears only after text is selected.

Additional icons let you include particular document sections in the search.
