# Trap Thresholds

These numbers define the conditions that cause trapping to occur. Ink color, paper stock, press behavior, and other variables all influence the correct thresholds.

| Option | Description |
| --- | --- |
| Step | Sets how large a color change must be before a trap is generated.<br><br>- Default value: 10%.<br>- Recommended range: 8% to 20%.<br>- Effect: smaller percentages make subtler color differences trigger additional traps.<br>- Purpose: determines whether trapping starts on minor color shifts or only on strong color changes. |
| Black Color | Sets the minimum black-ink percentage that must be present before the Black trap width setting is used.<br><br>- Default value: 100%<br>- Recommended minimum: 70%<br>- Application: defines which colors count as "solid process black" or "rich black"<br><br>This helps when low-grade paper stock creates extreme dot gain. |
| Black Density | Sets the neutral density level at or above which InDesign treats an ink as black.<br><br>- Default value: 1.6.<br>- Application: defines when spot colors use the Black trap width setting.<br>- Example: type the neutral density value for a dark spot ink to make black trapping rules apply. |
| Sliding Trap | Controls the point at which a trap moves onto the centerline of a color boundary instead of staying mostly on one side.<br><br>- Default value: 70%.<br>- Calculation: neutral density of the lighter color / neutral density of the darker color.<br>- Effect at 70%: the trap starts crossing the centerline after the lighter color passes 70% of the darker color's neutral density.<br>- Range: 0% (every trap uses the centerline) to 100% (sliding traps are off; one color spreads entirely into another).<br>- Special case: colors with equal neutral density always straddle the centerline unless the value is 100%. |
| Trap Color Reduction | Adjusts the use of neighboring color components to lighten the trap color and avoid a trap darker than either adjacent color.<br><br>- Default setting: 100% (no reduction).<br>- Allowed range: 0% to 100%.<br>- At 100%: full color components are used, which can make dark traps between pastel colors.<br>- Effect below 100%: the trap color starts becoming lighter.<br>- Effect at 0%: the trap is created with neutral density equal to the darker color.<br>- Use case: avoids unattractive dark traps between pastel colors. |
