# previousItem

> LanguageWithVendors **previousItem**( LanguageWithVendors **obj** )

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| LanguageWithVendors | obj | LanguageWithVendors that follows the desired LanguageWithVendors. |
