# flipItem

> **flipItem**( Flip **given**, Mixed **around** )
>
> Flips this SVG.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| Flip | given | Axis used to flip the SVG. |
| Mixed | around | Point used as the flip center. Can accept: Array of 2 Units or AnchorPoint enumerator. (Optional) |
