# flipItem

> **flipItem**( Flip **given**, Mixed **around** )
>
> Mirrors the Button.

### Parameters

| Type | Name | Description |
| --- | --- | --- |
| Flip | given | Axis used to flip the Button. |
| Mixed | around | Point used as the flip center. Accepts Array of 2 Units or AnchorPoint enumerator. (Optional) |
