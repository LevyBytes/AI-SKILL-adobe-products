# Simulation Effects (part 5)

> Adobe After Effects reference. Original prose; identifiers preserved verbatim.

## Producer 1 and Producer 2 controls

Where the waves originate is set by the Producer controls.

Type

Sets which kind of producer is used. Ring throws off a wave as though a stone dropped into a pond, waves rippling outward in circles (or ellipses, depending on the effect point's size settings). Line sends waves out from the producer position along a line rather than an ellipse — handy for waves that should look as if they came from much farther off. Those waves form perpendicular to the line's edges, and the line's length follows the Height/Length setting.

Position

Sets where the wave producer's center sits.

Height/Length

Sets the (vertical) height of a Ring producer and tunes the length of a Line producer.

Width

Sets the (horizontal) width of the producer area.

Angle

Sets the angle of the wave producer area for both the Line and Ring types. It orients the line and steers the waves' starting direction, those waves spreading from each side of the line, perpendicular to its length.

Amplitude

Governs how tall the produced wave stands. Higher values yield more dramatic waves but can bring on clipping, which the Brightness and Contrast controls let you fix.

Frequency

Governs how many waves get produced each second. At a value of 1, a wave surfaces once per second.

Phase

Sets where in the wave's phase it starts. At the default of 0°, for instance, the liquid's first disturbance is a convex wave (bulging up from the water's surface). Set Phase to 180° and that first disturbance is a concave wave instead.
