### How to use the Properties panel

Think of the After Effects Properties panel as a context-aware panel you can drag around and stack on top of others. Turning it on is a matter of choosing Window > Properties.

Pick any layer over in the Timeline or Composition panel and its associated controls appear in the Properties panel. Text and Shape layers surface extra properties beyond that.

Across every layer type, the Layer Transform section sits at the top of the Properties panel. Stretch the panel taller or scroll downward to see the controls.

Surfacing a property back in the Timeline takes a double-click on it within the Properties panel, or a right-click on the property followed by Reveal in Timeline.

### Use the Properties panel for Text layers

Through the Properties panel you can reach and animate text layers, revise text and paragraph properties, and layer on text animations.

Pick the Text layer over in the Timeline or Composition panel.

Within the Properties panel, turn to the Layer Transform for controls along the lines of Position, Scale, Rotation, Opacity, and the rest.

Beside the Anchor Point property sits an Anchor Point icon — select it to call up Quick Set Anchor and shift where the anchor point lands. Picking any spot in the Quick Set Anchor dialog resets the anchor point across every selected layer and shuts the dialog.

Turn to the Text and Paragraph sections for handling text and paragraph properties or styles.

Under the Text Animation section, Add Animator is also there to attach further animator properties onto the text layer you've selected.

Note

Should Auto-Open Panel be switched on for the Type tools sitting in the toolbar, choosing one opens the Properties panel whenever it's still closed.

### Use the Properties panel for Shape layers

Reaching a chosen Shape layer's properties is quick and painless through the Properties panel, sparing you from juggling layered hierarchies in the Timeline panel.

Pick the Shape layer over in the Timeline or Composition panel.

Within the Properties panel, turn to the Layer Transform for controls along the lines of Position, Scale, Rotation, Opacity, and the rest.

Turn to the Shape Properties and Shape Transform sections for handling shape properties or transform controls.

Note

- Should Auto-Open Panel be switched on for the Shape or Pen tools in the toolbar, choosing one opens the Properties panel whenever it's still closed.

### Use the Properties panel for layers with Essential Properties

Whenever a layer carrying Essential Properties is selected, those Essential Properties show up in the Properties panel. The exposed controls let you tweak properties while sidestepping the tangle of layered hierarchies in the Timeline panel.

Pick the layer carrying Essential Properties over in the Timeline or Composition panel.

Within the Properties panel, work through the exposed controls sitting under Essential Properties.

Tip

The Essential Properties shown in the Properties panel hand you font controls that the Timeline view of Essential Properties leaves out. Within the Essential Graphics panel, turn to Edit Properties for Source Text to switch on custom font picking, size tweaking, and styles.

### Use the Properties panel for layers with Camera and Light properties

Building animations with real visual punch leans heavily on Camera and Light layers. With Camera layers you add depth and perspective to a composition so it lines up with real-world camera settings — Focal Length, Angle of View, Zoom, and others. Light layers, meanwhile, let you assign light types that throw shadows, raise highlights, and bring depth into your scenes, pushing your compositions toward greater realism.

As you handle Camera and Light layers, the Properties panel doubles as a single control hub for swiftly tuning a layer's Transform properties and settings options, no trip to the timeline required.

### Get to know Variable Font Axes and the commonly registered axes that make flexible designs and smooth animations possible.

### Variable Font Axes overview

Through Variable Font Axes support, the design variations baked into OpenType Variable fonts become reachable and animatable right inside After Effects. A single variable font file packs many styles together, so you gain exact typographic control without juggling separate files for every weight, width, or style.

- Fine-grained control: Dial typography with continuous values rather than locked-in weights or styles.

- Smooth animations: Set keyframes on font variations to drive dynamic effects in your text.

- Per-character control: Hand individual characters their own axis values by way of text animators.

- File efficiency: Dozens of separate font files collapse into one variable font file.

After Variable Font Axes are in place, you can drive them by inserting them as properties within Text Animators, shape how strongly they apply via selectors, and steer them through ExtendScript.

Tip

Pick up the suggested approaches for designing with variable font axes, building text animations efficiently, and streamlining the animation workflow.

### About Variable Fonts

OpenType fonts that carry one or more axes of variation are what we call variable fonts. A given axis stands for one dimension of design variation that you adjust on a continuous scale, instead of being boxed into a handful of preset font styles.

### Difference between traditional and variable fonts

Aspect

Traditional fonts

Variable fonts

File structure

Each style is a separate font file (Regular, Bold, Light, Italic, etc.)

Single font file contains all variations

Style range

Limited to discrete steps. For example, weight: 100, 200, 300… 900.

Continuous range of values. For example, weight: 100.0 to 900.0.

Transitions

Switching between styles requires changing fonts.

Smooth transitions between any values.

Flexibility

Only one axis per font. For example, weight or italic.

Can combine multiple axes simultaneously. For example, weight + width + slant.
