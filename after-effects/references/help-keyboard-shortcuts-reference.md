### Look up and tailor keyboard shortcuts in Adobe After Effects to move through common tasks faster, cut down on repetitive actions, and work more efficiently.

## Visual Keyboard Shortcut Editor

The visual keyboard shortcut editor lets you lay out your shortcuts visually as you go. Through the keyboard user interface you can see which keys already carry shortcuts, which keys are open for assignment, and you can change the shortcuts that are assigned.

## Work with Visual Keyboard Shortcut Editor

To bring up the editor, choose Edit > Keyboard Shortcuts or

- Windows: Ctrl + Alt + '
- macOS: Option + Command + '

Three sections make up the editor:

- Keyboard layout: A picture of the hardware keyboard that shows you which keys carry a shortcut and which are open.
- Command list: Every command that can take a shortcut is listed here.
- Key modifier list: For the key you select on the keyboard layout, this lists all the modifier combinations and the shortcuts assigned to them.

Color coding

Gray: On the keyboard layout, keys shaded gray have no shortcuts assigned.

Purple: On the keyboard layout, keys shaded purple carry application-wide shortcuts.

Green: On the keyboard layout, keys shaded green carry panel-specific shortcuts.

### Application Shortcuts

By default the keyboard layout shows application-wide shortcuts, which work no matter which panel is active. The Command list shows the full set of available commands. Selecting a key in the keyboard layout for application-wide commands outlines it with a blue focus indicator, and the Command list then shows the Application command tied to it. The Key modifier list inspects the key and lists every command assigned across it and each possible modifier combination.

### Panel shortcuts

From the Command drop-down list you can flip over to the panel-specific view. The keyboard layout then shows only keys shaded green, and those shortcuts fire only when the matching panel is active. Viewing a set of Panel shortcuts surfaces just the commands belonging to that panel.

### Assigning shortcuts

Within the Command list shortcut column you can assign shortcuts to commands — select the command and type the shortcut into the text field. Searching the Command List filters it by your search terms. You can also assign a shortcut by clicking in the shortcut column and tapping keys on the keyboard to build it, modifiers included.

Another route is to drag a command from the Command list onto a key in the keyboard layout or onto the Key modifier list. You can also drag keys from the keyboard layout onto a command in the Command List to bind them. If a Panel shortcut shares its assignment with an Application shortcut, the application-wide one stops working while that panel is active.

Should After Effects run into an unsupported keyboard, it falls back to showing the U.S. English keyboard. The After Effects Default preset is what shows by default.

### Key tool tips

Keys with long command names get abbreviated. Hover over a key to see a tool tip giving the command's full name plus whether it's an Application or Panel shortcut.

## Conflicts and resolutions

### Conflicts

You'll see a shortcut-conflict warning whenever:

- Another Application shortcut is already using that Application shortcut.
- Another command within the same panel already holds that Panel shortcut.
- A Panel shortcut takes over an Application shortcut while that panel holds focus.

### Resolution

- Typing a shortcut that another command already uses brings up a warning message along the bottom of the editor.
- The Undo and Clear buttons over in the lower right corner become active.
- The conflicting command turns blue, and clicking it jumps straight to that command in the Command List.

## Saving custom keyboard shortcut sets

Tweak the shortcuts however you like, then store the set with the Save As button.
