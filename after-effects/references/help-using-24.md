## Effect Manager

Search Last updated on May 7, 2026

### Use the Effect Manager in Adobe After Effects to find, apply, and govern your effects so your workflows run more efficiently.

The effects shipped with After Effects add a wide range of visuals, tools, and workflow options that round out your video production. Occasionally, though, one of these effects can bring the program down.

Effect Manager steps in here: after a crash, the next launch of After Effects surfaces a notice naming the effect that likely triggered the previous session's failure. From that prompt you decide whether to leave the flagged effect switched on or turn it off for the upcoming launch.

Effect Manager notification with an option to disable the effect.

Effect Manager notification with an option to disable the effect.

### Enable the disabled effect

Whenever an effect gets switched off — whether through the post-crash prompt or via Manage Effects on the Effect menu — it drops out of both the Effect menu and the Effects and Presets panel. Re-enabling those effects is possible whenever you like.

Choose Effect > Manage Effects.

Within the Effect Manager dialog box, read across the Enabled and Last Crashed columns to pin down which effect is switched off.

Tick the Enable check box beside that effect, then select OK.

Relaunch After Effects so the update takes hold.

### View list of installed effects

The Effect menu now carries an Effect Manager entry as well, which surfaces every installed effect and lets you flag any of them to be switched on or off at the next launch.

Effect Manager lists all effects, including the ones that recently crashed.

Effect Manager lists all effects, including the ones that recently crashed.

Within the Effect Manager dialog, each effect is described by these details:

- Enabled status
- Effect name
- Category
- Version
- Last crashed
- File Path

Once an effect is switched off through Effect Manager, it stops appearing in the Effect menu and the Effects and Presets panel. Turning those effects back on is always done through Effect Manager. Note

Wherever a project relies on a switched-off effect, that effect shows up as Missing.

### Crash Repair Options

When no single effect stands out as the likely cause of the most recent crash, After Effects instead hands you Crash Repair Options to diagnose, pin down, and fix the trouble.

Crash Repair Options dialog when After Effects is relaunched after a crash.

Crash Repair Options dialog when After Effects is relaunched after a crash.

Manage Plugins

Browse the available effects and plugins, switch off any that might be at fault, and relaunch After Effects.

Reset Preferences

Restore preferences to their defaults and relaunch After Effects with those default settings.

Start in Safe Mode

Launch After Effects with every preference set to its default value. Choosing this reset at startup is an easy way to test whether a configured preference is behind an issue, all without actually clearing your preferences.

For more on chasing down preference problems in After Effects, see how the Restart and Repair feature works.
