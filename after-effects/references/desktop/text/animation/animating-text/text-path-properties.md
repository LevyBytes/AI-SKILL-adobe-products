# Text path properties

Through the Path Options properties you name a path and reshape how the separate characters sit on it—perpendicular to the path, pushed left or right, flipped, and the like. One straightforward route to animating text along a path is to animate the Path Options properties.

Reverse Path

Flips which way the path runs.

Perpendicular To Path

Turns every character so it stands at a right angle to the path.

Force Alignment

Drops the first character onto the path's start (or wherever the specified First Margin sits), drops the last character onto the path's end (or wherever the specified Last Margin sits), and spreads the characters in between evenly across that span.

First Margin

Gives the spot of the first character in pixels, taken from the path's start. When text is right-aligned and Force Alignment sits at Off, First Margin gets ignored.

Last Margin

Gives the spot of the last character in pixels, taken from the path's end. When text is left-aligned and Force Alignment sits at Off, Last Margin gets ignored.
