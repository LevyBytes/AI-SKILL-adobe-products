# Accessing Creative Cloud Libraries

Across projects

Anything you stash in the Libraries panel is there for you across whichever After Effects projects you happen to be working on.

Across computers

Your libraries sync up to Creative Cloud, so a library follows you to any computer where you've signed into Creative Cloud with your Adobe ID.

Across apps

Anything you stash in the Libraries panel turns up automatically across the desktop and mobile apps that support Creative Cloud Libraries.

You could, for example, get at Libraries from desktop apps like Adobe Premiere or Photoshop, and from mobile apps like Adobe Capture.

For more on reaching Creative Cloud Libraries, see Access your assets anywhere.
