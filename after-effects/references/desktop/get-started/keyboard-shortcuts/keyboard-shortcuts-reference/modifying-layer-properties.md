# Modifying layer properties

After Effects shortcuts for changing layer properties, part one. Each action is shown with its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Nudge a property value by its default step | Drag property value | Drag property value |
| Nudge a property value by ten times the default step | Shift-drag property value | Shift-drag property value |
| Nudge a property value by one-tenth of the default step | Ctrl-drag property value | Command-drag property value |
| Bring up the Auto-Orientation dialog for the selected layers | Ctrl + Alt + O | Command + Alt + O |
| Bring up the Opacity dialog for the selected layers | Ctrl + Shift + O | Command + Shift + O |
| Bring up the Rotation dialog for the selected layers | Ctrl + Shift + R | Command + Shift + R |
| Bring up the Position dialog for the selected layers | Ctrl + Shift + P | Command + Shift + P |
| Center the selected layers in view — this edits Position so their anchor points land at the middle of the current view | Ctrl + Home | Command + Home |
| Nudge the selected layers by 1 pixel at the present magnification (Position) | Arrow key | Arrow key |
| Nudge the selected layers by 10 pixels at the present magnification (Position) | Shift + Arrow key | Shift + Arrow key |
| Slide the selected layers one frame earlier or later | Alt + Page Up or Alt + Page Down | Option + Page Up or Option + Page Down |
| Slide the selected layers ten frames earlier or later | Alt + Shift + Page Up or Alt + Shift + Page Down | Option + Shift + Page Up or Option + Shift + Page Down |
| Raise or lower the selected layers' Rotation (Z Rotation) by 1° | + (plus) or - (minus) on the numeric keypad | + (plus) or - (minus) on the numeric keypad |
| Raise or lower the selected layers' Rotation (Z Rotation) by 10° | Shift + + (plus) or Shift + - (minus) on numeric keypad | Shift + + (plus) or Shift + - (minus) on numeric keypad |
| Raise or lower the selected layers' Opacity — Intensity on light layers — by 1% | Ctrl + Alt + + (plus) or Ctrl + Alt + - (minus) on numeric keypad | Control + Option + + (plus) or Control + Option + - (minus) on numeric keypad |
| Raise or lower the selected layers' Opacity — Intensity on light layers — by 10% | Ctrl + Alt + Shift + + (plus) or Ctrl + Alt + Shift + - (minus) on numeric keypad | Control + Option + Shift + + (plus) or Control + Option + Shift + - (minus) on numeric keypad |
| Push the selected layers' Scale up by 1% | Ctrl + + (plus) or Alt + + (plus) on the numeric keypad | Command + + (plus) or Option + + (plus) on the numeric keypad |
| Pull the selected layers' Scale down by 1% | Ctrl + - (minus) or Alt + - (minus) on numeric keypad | Command + - (minus) or Option + - (minus) on numeric keypad |
| Push the selected layers' Scale up by 10% | Ctrl + Shift + + (plus) or Alt + Shift + + (plus) on the numeric keypad | Command + Shift + + (plus) or Option + Shift + + (plus) on the numeric keypad |
| Pull the selected layers' Scale down by 10% | Ctrl + Shift + - (minus) or Alt + Shift + - (minus) on numeric keypad | Command + Shift + - (minus) or Option + Shift + - (minus) on numeric keypad |
| Constrain Rotation or Orientation changes to 15° steps | Shift-drag with the Rotation tool | Shift-drag with the Rotation tool |
| Constrain a Scale change to the footage frame's aspect ratio | Shift-drag layer handle with the Selection tool | Shift-drag layer handle with the Selection tool |
| Snap Rotation back to 0° | Double-click the Rotation tool | Double-click the Rotation tool |
| Snap Scale back to 100% | Double-click the Selection tool | Double-click the Selection tool |
| Size and place the selected layers to fill the comp | Ctrl + Alt + F | Command + Option + F |
| Size and place the selected layers to fill the comp's width, holding each layer's image aspect ratio | Ctrl + Alt + Shift + H | Command + Option + Shift + H |
| Size and place the selected layers to fill the comp's height, holding each layer's image aspect ratio | Ctrl + Alt + Shift + G | Command + Option + Shift + G |
