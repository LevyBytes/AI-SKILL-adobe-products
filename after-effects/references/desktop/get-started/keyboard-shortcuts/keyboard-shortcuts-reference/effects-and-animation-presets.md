# Effects and animation presets

After Effects shortcuts for effects and animation presets, action paired with Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Strip every effect off the selected layers | Ctrl + Shift + E | Command + Shift + E |
| Reapply the last effect you used to the selected layers | Ctrl + Alt + Shift + E | Command + Option + Shift + E |
| Reapply the last animation preset you used to the selected layers | Ctrl + Alt + Shift + F | Command + Option + Shift + F |
