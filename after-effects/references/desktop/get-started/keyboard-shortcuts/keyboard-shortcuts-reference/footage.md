# Footage

After Effects footage shortcuts, with each action shown beside its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Bring in a single file or one image sequence | Ctrl + I | Command + I |
| Bring in several files or image sequences | Ctrl + Alt + I | Command + Option + I |
| Open a movie inside an After Effects Footage panel | Double-click the footage item in the Project panel | Double-click the footage item in the Project panel |
| Drop the selected items onto the comp you most recently worked in | Ctrl + / (on main keyboard) | Command + / (on main keyboard) |
| Swap the source footage on the chosen layers for whatever footage item is highlighted in the Project panel | Ctrl + Alt + / (on main keyboard) | Command + Option + / (on the main keyboard) |
| Swap the source on one selected layer | Alt-drag footage item from the Project panel onto selected layer | Option-drag footage item from the Project panel onto a selected layer |
| Remove a footage item, skipping the confirmation prompt | Ctrl + Backspace | Command + Delete |
| Bring up the Interpret Footage dialog for the chosen footage item | Ctrl + Alt + G | Command + Option + G |
| Hold on to the current footage interpretation | Ctrl + Alt + C | Command + Option + C |
| Edit the chosen footage item in whatever app it is tied to (Edit Original) | Ctrl + E | Command + E |
| Swap out the chosen footage item | Ctrl + H | Command + H |
| Refresh the chosen footage items | Ctrl + Alt + L | Command + Option + L |
| Assign a proxy to the chosen footage item | Ctrl + Alt + P | Command + Option + P |
