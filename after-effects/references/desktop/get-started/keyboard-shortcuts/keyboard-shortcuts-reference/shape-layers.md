# Shape layers

| Result | Windows | macOS |
| --- | --- | --- |
| Group selected shapes | Ctrl + G | Command + G |
| Ungroup selected shapes | Ctrl + Shift + G | Command + Shift + G |
| Enter free-transform path editing mode | Select the Path property in the Timeline panel and press Ctrl + T | Select the Path property in the Timeline panel and press Command + T |
| Increase star inner roundness | Page Up when dragging to create a shape | Page Up when dragging to create a shape |
| Decrease star inner roundness | Page Down when dragging to create a shape | Page Down when dragging to create a shape |
| Increase number of points for star or polygon; increase roundness for rounded rectangle | Up Arrow when dragging to create a shape | Up Arrow when dragging to create a shape |
| Decrease number of points for star or polygon; decrease roundness for rounded rectangle | Down Arrow when dragging to create a shape | Down Arrow when dragging to create a shape |
| Reposition shape during creation | Hold the Spacebar when dragging to create a shape | Hold the Spacebar when dragging to create a shape |
| Set rounded rectangle roundness to 0 (sharp corners); decrease polygon and star outer roundness | Left Arrow when dragging to create a shape | Left Arrow when dragging to create a shape |
| Set rounded rectangle roundness to maximum; increase polygon and star outer roundness | Right Arrow when dragging to create a shape | Right Arrow when dragging to create a shape |
| Constrain rectangles to squares; constrain ellipses to circles; constrain polygons and stars to zero rotation | Shift when dragging to create a shape | Shift when dragging to create a shape |
| Change outer radius of star | Ctrl when dragging to create a shape | Command when dragging to create a shape |
