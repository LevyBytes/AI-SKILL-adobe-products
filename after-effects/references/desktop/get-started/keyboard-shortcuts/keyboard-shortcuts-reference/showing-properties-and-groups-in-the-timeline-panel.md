# Showing properties and groups in the Timeline panel

After Effects shortcuts for revealing properties and groups in the Timeline panel. Note that this set relies on double-letter combinations such as LL — tap the two letters in fast succession to fire them. Each action is shown with its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Search within the Timeline panel | Ctrl + F | Command + F |
| Expand the selected layers so every property shows | Ctrl + ` (accent grave) | Command + ` (accent grave) |
| Expand a property group together with all of its child groups so every property shows | Ctrl-click the triangle to the left of the property group name | Command-click the triangle to the left of the property group name |
| Reveal the Anchor Point property on its own — for lights and cameras this is Point Of Interest | A | A |
| Reveal the Audio Levels property on its own | L | L |
| Reveal the Mask Feather property on its own | F | F |
| Reveal the Mask Path property on its own | M | M |
| Reveal the Mask Opacity property on its own | TT | TT |
| Reveal the Opacity property on its own — for lights this is Intensity | T | T |
| Reveal the Position property on its own | P | P |
| Reveal the Rotation and Orientation properties on their own | R | R |
| Reveal the Scale property on its own | S | S |
| Reveal the Time Remap property on its own | RR | RR |
| Reveal only the spots where effects have gone missing | FF | FF |
| Reveal the Effects property group on its own | E | E |
| Reveal the mask property groups on their own | MM | MM |
| Reveal the Material Options property group on its own | AA | AA |
| Reveal expressions only | EE | EE |
| Reveal only properties you have changed | UU | UU |
| Reveal only paint strokes, Roto Brush strokes, and Puppet pins | PP | PP |
| Reveal the audio waveform only | LL | LL |
| Reveal only the properties and groups you have selected | SS | SS |
| Tuck a property or group out of sight | Alt + Shift-click property or group name | Option + Shift-click property or group name |
| Toggle a property or group in the displayed set | Shift + property or group shortcut | Shift + property or group shortcut |
| Drop a keyframe at the current time, or clear one | Alt + Shift + property shortcut | Option + property shortcut |
| Show properties with keyframes | U | U |
