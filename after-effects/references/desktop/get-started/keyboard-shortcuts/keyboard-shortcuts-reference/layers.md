# Layers

After Effects layer shortcuts, part one. Bear in mind that a handful of these operations skip over shy layers. Each action is shown with its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Make a new solid layer | Ctrl + Y | Command + Y |
| Make a new null layer | Ctrl + Alt + Shift + Y | Command + Option + Shift + Y |
| Make a new adjustment layer | Ctrl + Alt + Y | Command + Option + Y |
| Pick a layer (1-999) by typing its number — key the digits fast for two- and three-digit values | 0-9 on the numeric keypad\* | 0-9 on the numeric keypad\* |
| Flip a layer (1-999) into or out of the selection by its number — key the digits fast for two- and three-digit values | Shift + 0-9 on numeric keypad\* | Shift + 0-9 on numeric keypad\* |
| Grab the next layer down the stack | Ctrl + Down Arrow | Command + Down Arrow |
| Grab the next layer up the stack | Ctrl + Up Arrow | Command + Up Arrow |
| Widen the selection to the next layer down the stack | Ctrl + Shift + Down Arrow | Command + Shift + Down Arrow |
| Widen the selection to the next layer up the stack | Ctrl + Shift + Up Arrow | Command + Shift + Up Arrow |
| Drop the selection on every layer | Ctrl + Shift + A | Command + Shift + A |
| Bring the topmost selected layer up to the top of the Timeline panel | X | X |
| Toggle the Parent column | Shift + F4 | Shift + F4 |
| Toggle the Layer Switches and Modes columns | F4 | F4 |
| Clear every other solo switch | Alt-click solo switch | Option-click solo switch |
| Flip the Video (eyeball) switch for the selected layers | Ctrl + Alt + Shift + V | Command + Option + Shift + V |
| Bring up the settings dialog for a chosen solid, light, camera, null, or adjustment layer | Ctrl + Shift + Y | Command + Shift + Y |
| Drop pasted layers in at the current time | Ctrl + Alt + V | Command + Option + V |
| Split the selected layers — with nothing selected, every layer splits | Ctrl + Shift + D | Command + Shift + D |
| Roll the selected layers into a precomposition | Ctrl + Shift + C | Command + Shift + C |
| Bring up the Effect Controls panel for the selected layers | Ctrl + Shift + T | Command + Shift + T |
| Open a layer in the Layer panel — for a precomposition layer, its source comp opens in the Composition panel | Double-click a layer | Double-click a layer |
| Open a layer's source in the Footage panel — a precomposition layer opens instead in the Layer panel | Alt-double-click a layer | Option-double-click a layer |
| Run the selected layers backward in time | Ctrl + Alt + R | Command + Option + R |
| Switch on time remapping for the selected layers | Ctrl + Alt + T | Command + Option + T |
| Shift the selected layers so the In point, or the Out point, lands at the current time | [ (left bracket) or ] (right bracket) | [ (left bracket) or ] (right bracket) |
| Trim the selected layers' In point or Out point back to the current time | Alt + [ (left bracket) or Alt + ] (right bracket) | Option + [ (left bracket) or Option + ] (right bracket) |
| Add an expression to a property or strip it off | Alt-click stopwatch | Option-click stopwatch |
| Drop an effect — or several highlighted ones — onto the selected layers | Double-click effect selection in the Effects & Presets panel | Double-click effect selection in the Effects & Presets panel |
| Set the In point or Out point by stretching time | Ctrl + Shift + , (comma) or Ctrl + Alt + , (comma) | Command + Shift + , (comma) or Command + Option + , (comma) |
| Shift the selected layers so the In point sits at the start of the comp | Alt + Home | Option + Home |
| Shift the selected layers so the Out point sits at the end of the comp | Alt + End | Option + End |
| Lock the selected layers | Ctrl + L | Command + L |
| Release the lock on every layer | Ctrl + Shift + L | Command + Shift + L |
| Set the selected layers to Best, Draft, or Wireframe quality | Ctrl + U, Ctrl + Shift + U, or Ctrl + Alt + Shift + U | Command + U, Command + Shift + U, Command + Option + Shift + U |
| Step through blending modes forward or backward for the selected layers | Shift + - (hyphen) or Shift + = (equal sign) on the main keyboard | Shift + - (hyphen) or Shift + = (equal sign) on the main keyboard |
| Search within the Timeline panel | Ctrl + F | Command + F |
