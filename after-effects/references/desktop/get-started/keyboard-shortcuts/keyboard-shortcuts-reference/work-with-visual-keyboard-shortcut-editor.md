# Work with Visual Keyboard Shortcut Editor

To bring up the editor, choose Edit > Keyboard Shortcuts or

- Windows: Ctrl + Alt + '
- macOS: Option + Command + '

Three sections make up the editor:

Pick up speed, efficiency, and a smoother workflow by leaning on keyboard shortcuts in After Effects.

- Keyboard layout: A picture of the hardware keyboard that shows you which keys carry a shortcut and which are open.
- Command list: Every command that can take a shortcut is listed here.
- Key modifier list: For the key you select on the keyboard layout, this lists all the modifier combinations and the shortcuts assigned to them.

Color coding

Gray: On the keyboard layout, keys shaded gray have no shortcuts assigned.

Purple: On the keyboard layout, keys shaded purple carry application-wide shortcuts.

Green: On the keyboard layout, keys shaded green carry panel-specific shortcuts.
