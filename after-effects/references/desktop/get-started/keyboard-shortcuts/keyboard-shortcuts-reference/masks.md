# Masks

| Result | Windows | macOS |
| --- | --- | --- |
| New mask | Ctrl + Shift + N | Command + Shift + N |
| Select all points in a mask | Alt-click mask | Option-click mask |
| Select the next or previous mask | Alt + &#96; (accent grave) or Alt + Shift + &#96; (accent grave) | Option + &#96; (accent grave) or Option + Shift + &#96; (accent grave) |
| Enter free-transform mask editing mode | Double-click the mask with the Selection tool or select the mask in the Timeline panel and press Ctrl + T | Double-click the mask with the Selection tool or select the mask in the Timeline panel and press Command + T |
| Exit free-transform mask editing mode | Esc | Esc |
| Scale around the center point in Free Transform mode | Ctrl-drag | Command-drag |
| Move selected path points 1 pixel at the current magnification | Arrow key | Arrow key |
| Move selected path points 10 pixels at the current magnification | Shift + Arrow key | Shift + Arrow key |
| Toggle between smooth and corner points | Ctrl + Alt-click vertex | Command + Option-click vertex |
| Redraw Bezier handles | Ctrl + Alt-drag vertex | Command + Option-drag vertex |
| Invert selected mask | Ctrl + Shift + I | Command + Shift + I |
| Open the Mask Feather dialog box for selected mask | Ctrl + Shift + F | Command + Shift + F |
| Open the Mask Shape dialog box for selected mask | Ctrl + Shift + M | Command + Shift + M |
| Subtract mode | S | S |
| Darken mode | D | D |
| Difference mode | F | F |
| Add mode | A | S |
| Intersect mode | I | I |
| None | N | N |
