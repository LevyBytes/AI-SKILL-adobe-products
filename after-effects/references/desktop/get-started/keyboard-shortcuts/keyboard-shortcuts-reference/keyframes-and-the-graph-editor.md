# Keyframes and the Graph Editor

After Effects shortcuts for keyframes and the Graph Editor. A caution for Mac OS users: bindings that lean on the F9-F12 function keys can collide with the ones the operating system claims, so consult macOS Help if you need to remap the Dashboard & Expose shortcuts. Each action appears with its Windows and macOS keys.

| Action | Windows | macOS |
| --- | --- | --- |
| Flip between Graph Editor and layer-bar modes | Shift + F3 | Shift + F3 |
| Grab every keyframe on a property | Select property name | Select property name |
| Grab all the keyframes and properties on screen | Ctrl + Alt + A | Command + Option + A |
| Clear the selection from keyframes, properties, and property groups | Shift + F2 or Ctrl + Alt + Shift + A | Shift + F2 or Command + Option + Shift + A |
| Slide a keyframe one frame forward or back | Alt + Right Arrow or Alt + Left Arrow | Option + Right Arrow or Option + Left Arrow |
| Slide a keyframe ten frames forward or back | Alt + Shift + Right Arrow or Alt + Shift + Left Arrow | Option + Shift + Right Arrow or Option + Shift + Left Arrow |
| Choose interpolation for the selected keyframes (layer-bar mode) | Ctrl + Alt + K | Command + Option + K |
| Flip keyframe interpolation to hold or Auto Bezier | Ctrl + Alt + H | Command + Option + H |
| Flip keyframe interpolation to linear or Auto Bezier | Ctrl-click in layer bar mode | Command-click in layer bar mode |
| Flip keyframe interpolation to linear or hold | Ctrl + Alt-click in layer bar mode | Command + Option-click in layer bar mode |
| Apply Easy Ease to the selected keyframes | F9 | F9 |
| Apply Easy Ease In to the selected keyframes | Shift + F9 | Shift + F9 |
| Apply Easy Ease Out to the selected keyframes | Ctrl + Shift + F9 | Command + Shift + F9 |
| Dial in velocity for the selected keyframes | Ctrl + Shift + K | Command + Shift + K |
| Drop a keyframe at the current time, or clear one | Alt + Shift + property shortcut | Option + property shortcut |
| Paste the copied keyframes into the timeline in reverse | Ctrl + Shift + V | Command + Shift + V |
