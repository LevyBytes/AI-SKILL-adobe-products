# Using simple math in expressions

When a property holds an expression, its values show up in red or pink type.

One solid way in is to build a simple expression with the pick whip, then shape how it behaves with basic math operations, like the ones the table below lists:

| Symbol | Function |
| --- | --- |
| `+` | Add |
| - | Subtract |
| / | Divide |
| `*` | Multiply |
| \*-1 | Perform the opposite of the original, such as counterclockwise instead of clockwise. |

To illustrate, append \*2 to the end of an expression to double the result, or append /2 to halve it.

Once editing expressions feels comfortable, you can stack these basic operations together — and others besides. For instance, tack /360\*100 onto the end of an expression to remap its range from 0-360 to 0-100. That would come in handy if you wanted to turn the values of a 360-degree dial into a slider read out in percentages.
