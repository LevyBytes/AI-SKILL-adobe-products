# Importing and interpreting footage items - Common pixel aspect ratios

| Format | Pixel aspect ratio | When to use |
| --- | --- | --- |
| Square pixels | 1.0 | The footage runs a 640x480 or 648x486 frame size, is 1920x1080 HD (neither HDV nor DVCPRO HD), is 1280x720 HD or HDV, or came out of an application with no nonsquare-pixel support. Footage carried over from film or one-off custom projects can also fit this choice. |
| D1/DV NTSC | 0.91 | The footage runs a 720x486 or 720x480 frame size and you're after a 4:3 frame aspect ratio. Footage exported from a nonsquare-pixel application—a 3D animation package, say—can also suit this setting. |
| D1/DV NTSC Widescreen | 1.21 | The footage runs a 720x486 or 720x480 frame size and the goal is a 16:9 frame aspect ratio. |
| D1/DV PAL | 1.09 | The footage runs a 720x576 frame size and the goal is a 4:3 frame aspect ratio. |
| D1/DV PAL Widescreen | 1.46 | The footage runs a 720x576 frame size and the goal is a 16:9 frame aspect ratio. |
| Anamorphic 2:1 | 2.0 | The footage was captured through an anamorphic film lens, or it came off a 2:1 film frame by way of an anamorphic transfer. |
| HDV 1080/DVCPRO HD 720, HD Anamorphic 1080 | 1.33 | The footage runs a 1440x1080 or 960x720 frame size and the goal is a 16:9 frame aspect ratio. |
| DVCPRO HD 1080 | 1.5 | The footage runs a 1280x1080 frame size and the goal is a 16:9 frame aspect ratio. |
