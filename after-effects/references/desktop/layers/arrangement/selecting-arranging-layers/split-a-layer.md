# Split a layer

The Timeline panel lets you split a layer at any moment, spawning two layers that stand on their own. Splitting is a quick stand-in for duplicating then trimming a layer — handy when you want to shift the layer's stacking-order spot partway through the composition.

Note

To have freshly split layers land above the original in the Timeline panel, turn on Create Split Layers Above Original Layer (Edit > Preferences > Composition (Windows) or After Effects > Preferences> Composition (macOS)). Turn that option off and the new layers land below the original instead.

1. Pick one or more layers.
2. Drag the current-time indicator over to the moment where the split should fall.
   Pick Edit > Split Layer.

Split a layer and both layers that result carry every keyframe the original had, each sitting in its original spot. Any track mattes already applied hold their order atop the layer.

Once the split is done, the original layer now ends at the split point and the new layer picks up from there in time.

When no layer is selected as you choose Edit > Split Layer, every layer gets split at the current time.
