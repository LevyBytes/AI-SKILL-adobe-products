VR Chromatic Aberration settings

VR Chromatic Aberration settings

| Parameter | Description |
| --- | --- |
| Frame Layout | Switches the frame layout between Monoscopic and Stereoscopic Over/Under. |
| Point of Interest | Sets where the footage's point of interest sits, and its position can be keyframed for movement. |
| Aberration (Red) | Scales your footage's Red channel. |
| Aberration(Green) | Scales your footage's Green channel. |
| Aberration (Blue) | Scales your footage's Blue channel. |
| Falloff Distance | Sets how far the effect falls off from the point of interest; raise it for crisper aberrations. |
| Falloff Invert | Holds the chromatic aberrations back from appearing around the point of interest. |
| Stereoscopic Side-by-Side | Beyond the Monoscopic and Stereoscopic Over/Under choices already there, Frame Layout now also accepts Stereoscopic Side-by-Side. |
| Horizontal and Vertical Field of View | Each field of view, horizontal and vertical, is adjustable on its own. They default to 360x180; for VR 180 material, drop both to 180. |
