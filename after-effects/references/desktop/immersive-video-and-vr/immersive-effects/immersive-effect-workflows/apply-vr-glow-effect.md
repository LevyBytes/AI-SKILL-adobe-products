VR Glow settings

VR Glow settings

| Parameter | Description |
| --- | --- |
| Luma Threshold | Marks which parts of the image glow - the regions whose luma (brightness) exceeds the threshold, ranging from 0.0 (black) to 1.0 (white). |
| Glow Radius | Sets how wide the glowing halo spreads. |
| Glow Brightness | Scales up the intensity of the glow's brightness. |
| Glow Saturation | Scales up the intensity of the glow's saturation (color). |
| Use Tint Color | Mixes a tint color into the resulting glow color. |
| Tint Color | Picks the tint color. |
| Stereoscopic Side-by-Side | Beyond the Monoscopic and Stereoscopic Over/Under choices already there, Frame Layout now also accepts Stereoscopic Side-by-Side. |
| Horizontal and Vertical Field of View | Each field of view, horizontal and vertical, is adjustable on its own. They default to 360x180; for VR 180 material, drop both to 180. |
