# Apply VR Sphere to Plane effect

Turning 360° spherical VR footage into a flat 2D view is what the VR Sphere to Plane effect does, so you can pull particular views or angles out of equirectangular footage.

VR Sphere to Plane settings in the Effect Controls panel.

| Parameter | Description |
| --- | --- |
| Input Format | State which format your 360° footage is in. |
| Output Frame Width | Sets the output frame's horizontal resolution; a greater width yields a higher-resolution flat view. |
| Output Frame Ratio | Governs the output's aspect ratio. Choosing Unchanged keeps the ratio tied to the input or composition. |
| Rotate Projection | Spin the camera view around inside the 360° footage:<br><br>- Projection Tilt (Y-axis): Left-right rotation.<br>- Projection Tilt (X-axis): Up-down rotation.<br>- Projection Tilt (Z-axis): Rotate the image around the center axis. |
