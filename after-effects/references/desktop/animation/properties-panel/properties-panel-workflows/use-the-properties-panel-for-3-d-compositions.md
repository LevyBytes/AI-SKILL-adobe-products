# Use the Properties panel for 3D compositions

Because the Properties panel exposes 3D model options, tuning how a model reacts to lights and shadows — and picking embedded animations — stays quick and straightforward in After Effects.

Every supported 3D model type exposes Compositing Options including Casts Shadows, Accepts Shadows, Accept Lights, and Shadow Color. Reach the embedded animations belonging to 3D models through Animation Options.
