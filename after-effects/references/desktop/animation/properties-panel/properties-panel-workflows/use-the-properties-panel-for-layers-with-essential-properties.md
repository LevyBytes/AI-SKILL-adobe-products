# Use the Properties panel for layers with Essential Properties

Whenever a layer carrying Essential Properties is selected, those Essential Properties show up in the Properties panel. The exposed controls let you tweak properties while sidestepping the tangle of layered hierarchies in the Timeline panel.

Pick the layer carrying Essential Properties over in the Timeline or Composition panel.

Within the Properties panel, work through the exposed controls sitting under Essential Properties.

Tip

The Essential Properties shown in the Properties panel hand you font controls that the Timeline view of Essential Properties leaves out. Within the Essential Graphics panel, turn to Edit Properties for Source Text to switch on custom font picking, size tweaking, and styles.
