# Alt + Numpad-0

| Function | Default preview settings |
| --- | --- |
| Play video in preview | On |
| Play audio in preview | On |
| Show overlays and layer controls | Off |
| Cache before playback | Off |
| Range | Play around current time. |
| Play From | Start of Range |
| Frame Rate | Auto |
| Skip | 0 |
| Resolution | Auto |
| Full Screen | Disabled |
| If caching, play cached frames (When the Alt + Numpad-0 is used to stop a preview) | Enabled |
| Move time to preview time (When the Alt + Numpad-0 is used to stop a preview) | Disabled |
