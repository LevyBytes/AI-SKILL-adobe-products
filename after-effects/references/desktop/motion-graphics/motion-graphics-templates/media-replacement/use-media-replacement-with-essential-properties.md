# Use Media Replacement with Essential Properties

Pull the layer you intend to swap into the Essential Graphics panel.

Place your composition within a second composition.

Twirl down to reach the media's Essential Properties in the timeline.

From the Project panel, drag a different asset — an image, video, or comp — and drop it on top. A blue outline appears on the thumbnails as the media gets replaced.

To edit that single instance of the media, double-click it in the timeline, which opens a precomp.
