What Creative Cloud Libraries does is put your assets within reach wherever you are. Inside Photoshop, Illustrator, and mobile apps such as Adobe Shape you can craft color looks, text styles, colors, images, and the rest, then pull them up effortlessly from other desktop and mobile apps for a creative workflow that never breaks stride.

For more, see Creative Cloud Libraries.

## Using Creative Cloud Libraries

Within After Effects, you reach Creative Cloud Libraries through the Libraries panel as well as the Start screen. That Libraries panel shows up in the Default workspace, the Standard workspace, and the All Panel workspace, docked along the right edge of the workspace.

Open the Libraries panel by choosing any of these:

- Window > Workspace > Libraries
- File > Import OR
- Window > Libraries

Your creative assets serve plenty of purposes inside After Effects:

- Drag graphics assets out of the Libraries panel and onto the Project panel to import them into your project.
- Vector assets built in mobile apps like Capture and stored in your library can come into After Effects and convert into shape layers for crisp vector animations.
- Text layer graphics you added to your library from Photoshop can come into After Effects and convert into editable text layers complete with live layer styles.

Note

Library assets that aren't graphics can't be applied directly, though you can still view and manage them in the Libraries panel. The Eyedropper tool in After Effects also lets you sample colors from your library, much like the Adobe Color Themes panel does.

## Location of Library assets

When you import Library assets into After Effects, they get copied into your user folder at these spots:

- macOS: Users/<user_name>/Documents/Adobe/After Effects CC 2015/User Libraries/
- Windows: C:\Users<user_name>\Documents\Adobe\After Effects CC 2015\User Libraries\

## Accessing Creative Cloud Libraries

Across projects

Anything you stash in the Libraries panel is there for you across whichever After Effects projects you happen to be working on.

Across computers

Your libraries sync up to Creative Cloud, so a library follows you to any computer where you've signed into Creative Cloud with your Adobe ID.

Across apps

Anything you stash in the Libraries panel turns up automatically across the desktop and mobile apps that support Creative Cloud Libraries.

You could, for example, get at Libraries from desktop apps like Adobe Premiere or Photoshop, and from mobile apps like Adobe Capture.

For more on reaching Creative Cloud Libraries, see Access your assets anywhere.

## Add a Creative Cloud library

Spin up as many libraries as you like to keep your assets organized. Whatever libraries you create show up in the Libraries panel within After Effects.

Choose the drop-down in the Libraries panel, then choose Create New Library.

Give the library a name and choose Create.

## Add assets to a Creative Cloud Library

Several routes exist for placing assets into a Creative Cloud Library; pick whichever of the following suits you:

Option 1:

Drop your assets onto the Library panel.

Whatever you drag lands in the library you currently have selected. Because these libraries stay synced to your Creative Cloud account, they remain reachable from any machine you sign in on.

Option 2:

From within After Effects, choose File > Save As or File > Save and write the files into the Creative Cloud Files directory.

That directory, kept in sync with your Creative Cloud account, can hold every one of your assets. By default the directory is set up for you by the Creative Cloud desktop app.

Option 3:

Opening the Creative Cloud Files directory from the Creative Cloud desktop app varies by which release you run, so do one of these:

a) Start the Creative Cloud desktop app.

b) Open the Your work tab, then in the left rail select the Your work links icon and choose Open sync folder.

a) Start the Creative Cloud desktop app.

b) Choose Files.

c) Choose Open Folder.

Further detail lives under adding assets to Creative Cloud Libraries.

A second route is to push assets straight to the Creative Cloud Assets page. To do that:

Visit https://assets.adobe.com/files.

Click the Upload Files icon to send your files across.

After the upload finishes, those files sync to your Creative Cloud account and become reachable from anywhere you log in.

## Graphic Assets

Just as you would pull in any file from a local drive, graphics assets are fair game for import into an After Effects project. Use one of these two approaches to bring graphics assets in:

- Right-click a graphic asset and choose Import.

OR

- Pick a graphic asset in the Libraries panel and drag it onto the Project panel.

Library vector graphics that originated in Illustrator or Shape will import into After Effects. Drop them into a composition and you can then turn them into shape layers, which gives you crisp vector animation.

Text-layer graphics from Photoshop that you have stored in your library import into After Effects too, where they become editable text layers complete with live layer styles.

How PSD and AI assets come across from a library depends on the Drag Import Multiple Items As setting found under Preferences > Import.

## Looks

Built and saved to the Creative Cloud library through Adobe Premiere (CC 2015 and later versions), Looks are color presets. Each one bundles together the color and lighting captured either from a live shot taken on your mobile device camera or from a still photo already on the device.

Saved as .look files, these presets can afterward be dropped onto a layer in After Effects. Reaching for a Look is a quick way to lift a project by shifting the image's color or laying in color grading — work normally handled in something like SpeedGrade or Premiere's color panel.

When pulled from the Libraries panel, a Look is interpreted through the Apply Color LUT effect, exactly as LUT files coming from elsewhere would be.

A Look can be applied from the Libraries panel by any of these routes:

- With a composition layer selected, give a look in the Libraries panel a right-click and pick Apply Look.
- From the Libraries panel, drag a look directly onto a layer within whichever panel you are in — Composition, Layer, Effect Controls, or Timeline.
- From the Libraries panel, drag a look onto the title row of an Apply Color LUT effect already present on a layer over in the Timeline or Effect Controls panels. After Effects then attaches the Apply Color LUT effect to that layer and applies the look. Should the layer already carry an Apply Color LUT effect, pulling a look from the Libraries panel reuses that existing instance instead of adding another. This lets you audition one look after another on a single layer.

Millions of high-quality, royalty-free photos, illustrations, and videos — HD and 4K included — are sold through the Adobe Stock service.

A hunt through Adobe Stock assets can be kicked off without leaving After Effects:

Choose Window > Library to bring up the Libraries panel in After Effects.

Click the Search Adobe Stock button along the bottom edge of the Libraries panel.

On the page that comes up, comb the Stock library for whatever asset you need.

For video assets, the returned results carry licensing status, duration, and format details. Results can be filtered and assets previewed. Pick Results From Adobe Stock to narrow the returns to photos, illustrations, vectors, or videos. When buying or previewing a 4K video by way of the Libraries panel, you can opt for either the 4K or the HD version.

Spot an asset you want and you can buy its license on the spot and add it to your library, where it shows up in the Libraries panel inside After Effects. Alternatively, drop an unlicensed, watermarked preview of the asset into your library. To license a Stock asset out of the Project panel, highlight a watermarked preview there and either choose File > License or click the shopping cart button; for any footage item still unlicensed, that button sits just to its left.

## Add assets from Essential Graphics panel

Motion Graphics templates can be passed around by way of Creative Cloud libraries. Confirm first that the newest Creative Cloud desktop app release is sitting on your computer.

Available app updates can be reviewed inside the Creative Cloud desktop app, where every Motion Graphics template surfaces as an update.

To run the check yourself, walk through these steps:

Launch the Creative Cloud desktop app by clicking its desktop icon — find it in the taskbar on Windows, or up in the Apple menu bar on macOS.

From your profile menu, choose Sign out.

Sign back in to your Adobe account.

Should you be running anything older than the latest Creative Cloud desktop app, an update prompt appears. Choose Update.

## Share libraries with Creative Cloud users

Handing your libraries to other Creative Cloud users lets them view, edit, or draw on what a shared library holds. Anyone using your library assets gets a heads-up each time a read-only asset in it is changed.

Note

A library that another Creative Cloud subscriber has shared with you can be passed along by you to still more Creative Cloud users.

Share a library: Two methods are open to you for sharing libraries with others:

Option 1:

On the Libraries panel, open the pop-up menu from the panel tab and choose Collaborate.

Option 2:

For sharing by way of the Creative Cloud website, head to the Your Work section of the Creative Cloud website.

Within the side navigation, choose Libraries. Libraries you own sit beneath the Owned by You tab.

Pick the library you intend to share and choose Share. Walk through the onscreen prompts to bring collaborators onto your library.

Join a shared library:

These steps cover joining a shared library:

Open the Adobe Creative Cloud desktop app and sign in using your Adobe ID credentials.

Each time a library is shared with you, a notification arrives. Click the bell icon to see your notifications.

For every library collaboration invitation, choose Accept.
