# AEIO_InitInSpecInteractive

`AEIO_InitInSpecInteractive`

Suite argument declaration (not a standalone call):

```cpp
AEIO_InitInSpecInteractive(
  AEIO_BasicData  *basic_dataP,
  AEIO_InSpecH    inH);
```
