# PF_AppGetLanguage

`PF_AppGetLanguage`

New in CC. Retrieves the active displayed language of AE UI so plug-in can match. Here are the possible language codes as of CC:

- Chinese - zh_CN

- English - en_US

- French - fr_FR

- German - de_DE

- Italian - it_IT

- Japanese - ja_JP

- Korean - ko_KR

- Spanish - es_ES

Suite argument declaration (not a standalone call):

```cpp
PF_AppGetLanguage(
  A_char  lang_tagZ);
```
