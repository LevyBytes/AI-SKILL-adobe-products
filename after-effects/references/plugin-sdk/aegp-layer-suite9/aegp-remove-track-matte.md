# AEGP_RemoveTrackMatte

`AEGP_RemoveTrackMatte`

New in 23.0. Removes the track matte layer of layerH.

Suite argument declaration (not a standalone call):

```cpp
AEGP_RemoveTrackMatte(
  AEGP_LayerH                layerH);
```
