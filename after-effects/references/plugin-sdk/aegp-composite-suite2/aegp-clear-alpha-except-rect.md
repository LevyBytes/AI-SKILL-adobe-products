# AEGP_ClearAlphaExceptRect

`AEGP_ClearAlphaExceptRect`

Sets alpha to fully transparent across the PF_EffectWorld except inside the specified rectangle.

Suite argument declaration (not a standalone call):

```cpp
AEGP_ClearAlphaExceptRect(
  A_Rect          *clipped_dst_rectPR,
  PF_EffectWorld  *dstP);
```
