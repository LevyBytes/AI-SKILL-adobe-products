# AEGP_InsertCuePointParam

`AEGP_InsertCuePointParam`

Adds a cue point parameter.

Follow this with AEGP_SetIndCuePointParam to populate its data.

Suite argument declaration (not a standalone call):

```cpp
AEGP_InsertCuePointParam(
  AEGP_MarkerValP  markerP,
  A_long           param_idxL);
```
