# SmartFX`PF_Cmd_SMART_PRE_RENDER`

The effect is asked by After Effects to produce output. In return the effect states which input it requires to make that output, doing so through callback functions and by editing the structures in the extra parameter. Any layer input the effect has not checked out during `PF_Cmd_SMART_PRE_RENDER` is off-limits — its pixels cannot be reached. For that reason every layer input the effect could conceivably want has to be checked out ahead of time with checkout_layer. Even if rendering later reveals a layer wasn't needed, any layer input the effect might require has to be checked out at this point. And because SmartFX gets no parameter array during `PF_Cmd_SMART_PRE_RENDER` or `PF_Cmd_SMART_RENDER`, you must pull any non-layer parameters you need with `PF_CHECKOUT_PARAM` (from Interaction Callbacks)
