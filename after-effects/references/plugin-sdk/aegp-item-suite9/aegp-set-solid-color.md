# AEGP_SetSolidColor

`AEGP_SetSolidColor`

Removed in AEGP_ItemSuite4. See AEGP_SetSolidFootageColor from AEGP_FootageSuite5.

Sets the color of an existing solid (error if itemH is not a solid).

Suite argument declaration (not a standalone call):

```cpp
AEGP_SetSolidColor(
  AEGP_ItemH     itemH,
  AEGP_ColorVal  color);
```
