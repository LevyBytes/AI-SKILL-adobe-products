# AEGP_CreateNewMask

`AEGP_CreateNewMask`

Adds a fresh mask, having no nodes, to the referenced AEGP_LayerH. You get back the new mask's index.

Suite argument declaration (not a standalone call):

```cpp
AEGP_CreateNewMask(
  AEGP_LayerH    layerH,
  AEGP_MaskRefH  *mask_refPH,
  A_long         *mask_indexPL0);
```
