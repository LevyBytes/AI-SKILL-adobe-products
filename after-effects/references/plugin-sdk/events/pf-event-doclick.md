# PF_Event_DO_CLICK

`PF_Event_DO_CLICK`

Within the effect's UI, the user clicked. A `PF_DoClickEventInfo` sits in `PF_EventUnion`. Field the mouse click and reply, passing drag info along (consult the sample code), inside a context.

Note

Starting with 7.0, don't sit blocked waiting for mouse-up; lean on `PF_Event_DRAG` instead.
