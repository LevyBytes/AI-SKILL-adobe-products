# AEGP_GetInSpecSoundEncoding

`AEGP_GetInSpecSoundEncoding`

Obtains the encoding method, signed PCM, unsigned PCM, or floating point, from AEIO_InSpecH.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetInSpecSoundEncoding(
  AEIO_InSpecH      inH,
  AEIO_SndEncoding  *encodingP);
```
