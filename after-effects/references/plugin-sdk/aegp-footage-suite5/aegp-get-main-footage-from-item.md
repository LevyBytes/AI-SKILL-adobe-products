# AEGP_GetMainFootageFromItem

`AEGP_GetMainFootageFromItem`

Returns an error if item isn't a footage item. Used to convert an item handle to a footage handle.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetMainFootageFromItem(
  AEGP_ItemH     itemH,
  AEGP_FootageH  *footagePH);
```
