# AEGP_ReorderCompSelection

`AEGP_ReorderCompSelection`

Move the selection to a certain layer index. Use along with AEGP_SetSelection().

```cpp
AEGP_ReorderCompSelection(
  AEGP_CompH  compH,
  A_long      index);
```
