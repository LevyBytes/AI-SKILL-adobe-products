# AEGP_SetCompSuggestedMotionBlurSamples

`AEGP_SetCompSuggestedMotionBlurSamples`

Specifies the number of motion blur samples After Effects will perform in the given composition. Undoable.

Suite argument declaration (not a standalone call):

```cpp
AEGP_SetCompSuggestedMotionBlurSamples(
  AEGP_CompH  compH,
  A_long      samplesL);
```
