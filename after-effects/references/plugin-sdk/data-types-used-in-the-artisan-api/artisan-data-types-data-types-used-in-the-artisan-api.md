# Artisan Data Types — Data Types Used In The Artisan API

| Type | Describes |
| --- | --- |
| `AEGP_RenderLayerContextH` | State at render-request time, sent by After Effects to an Artisan. |
| `PR_RenderContextH` | Settings collection that defines what will render and how it will render. |
| `AEGP_SoundDataH` | Audio settings for a particular layer. |
| `AEGP_RenderReceiptH` `AEGP_FrameReceiptH` | Artisans use these while rendering. |
| `AEGP_WorldH` | One frame of pixel data. |
| `AEGP_RenderOptionsH` | Settings tied to a render queue item. |
