# AEGP_GetMatteMode

`AEGP_GetMatteMode`

Reads back the AEGP_MatteMode for the given AEGP_LayerRenderOptionsH.

Suite argument declaration (not a standalone call):

```cpp
AEGP_GetMatteMode(
  AEGP_LayerRenderOptionsH  optionsH,
  AEGP_MatteMode            *modeP);
```
