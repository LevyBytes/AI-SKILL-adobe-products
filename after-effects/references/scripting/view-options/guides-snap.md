# ViewOptions.guidesSnap

app.activeViewer.views[0].options.guidesSnap

Note

This functionality was added in After Effects 16.1 (CC 2019)

### Description

True here means layers snap onto guides as you drag them within the view.

### Type

Boolean; read/write.

### Example

```javascript
app.activeViewer.views[0].options.guidesSnap;
```
