# app.pauseWatchFolder()

app.pauseWatchFolder(pause)

### Description

Halts or restarts the scan of the chosen watch folder for items awaiting render.

### Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| pause | Boolean | true to pause, false to resume. |

### Returns

Nothing.
