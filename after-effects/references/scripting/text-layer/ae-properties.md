# AE Properties

TextLayer adds no attributes of its own, but on top of what it inherits from AVLayer it provides these AE properties and property groups:

- Text
- SourceText
- PathOptions
- Path
- ReversePath
- PerpendicularToPath
- ForceAlignment
- FirstMargin
- LastMargin
- MoreOptions
- AnchorPointGrouping
- GroupingAlignment
- Fill&Stroke
- InterCharacterBlending
- Animators
