### Top features in beta

Duplicate layers using Alt/Option-drag

To clone a layer on the spot in both 2D and 3D compositions, Alt/Option-drag it into the Composition panel.

Change anchor point in a more efficient way

Reposition the anchor point on 2D layers with ease using Quick Set Anchor, which you reach via a keyboard shortcut or from the Properties panel.

Create and use Depth of Field in the Advanced 3D renderer

Build a Depth of Field effect in Advanced 3D that pulls focus onto 3D models, parametric meshes, Substance 3D materials, 3D text, shape layers, and more.

Curl Noise effect for swirling animated 2D patterns

Generate flowing, organic 2D noise reminiscent of smoke, water, or ink — a natural fit for smooth, drifting motion across backgrounds, textures, and abstract animations.

Quickly Find Variable Fonts by Axis

Narrow the font list down to variable fonts alone, so the right one is quicker to track down.

Effect Controls panel modernization

Built on a modern framework, the refreshed Effect Controls panel lets you view and manage effects through icon-based controls.

Copy a frame to the clipboard

Grab the frame currently rendered in the Composition, Footage, or Layer panel as a still image and send it to your system clipboard with one click.

Copy and paste Illustrator and SVG content

Drop SVG content from Illustrator or other apps straight into After Effects as native, editable shape layers via Edit > Paste.

Updated Mask Tracker

The revamped mask tracker tracks masks more quickly and precisely — as much as 5x faster — with within-reach controls that let tracking begin right from the Timeline panel.

Color labels for effects

Tag individual effect instances with color labels in the Effect Controls panel to keep your effects organized, easy to spot, and easier to work with.

### January 2026 release (version 26.0)

Substance 3D Materials (SBSAR) Drop Substance Materials (.sbsar files) onto 3D models and parametric meshes to range across many visual styles and land stylized looks. Learn to apply Substance 3D Materials to 3D models ›

Create parametric meshes With the new mesh tool you can build parametric shapes — spheres, cubes, and cones — right inside the app, then customize or animate their size, shape, and appearance. Learn to create parametric meshes ›

Enable lights to cast shadows In a 3D composition running the Advanced 3D renderer, drop in several shadow-casting Spot, Parallel, and Environment lights across your 3D scene. Learn to enable lights to cast shadows ›

Support for Variable Font Axes With a single font file carrying multiple styles, you can animate OpenType Variable fonts in After Effects and dial in weight, width, and style precisely. Learn more about Variable Font Axes ›

Improved Illustrator layer conversion Converting Illustrator layers to native shape layers now keeps gradient fills, strokes, and transparency intact, and those layers also handle animatable Scale and Rotation for gradients. Learn how to convert Illustrator layers to shape layers ›

Import SVG files as vectors Pull SVG files straight into your composition and turn them into editable shape layers that are set for customization and animation. Learn how to import SVG files as native, editable shape layers ›

Unmult effect for Keying transparency Strip solid black or white backgrounds out of footage while holding onto the foreground's colors and detail for compositing or other visual effects. Learn how to use the Unmult effect ›

Lossless Compressed Playback Preview longer stretches of your timeline using far less disk space, all without giving up any visual quality. Learn how Lossless Compressed Playback can help you ›

Crop composition to selected layer(s) bounds Fit your composition to the selected layers' bounds — shrink it down around smaller content or stretch it out to take in elements that run past the current frame. Learn how to crop composition to selected layer bounds ›

New built-in audio effects Three new audio effects — Distortion, Compressor, and Gate — let you shape and manage sound in your compositions, putting precise audio control right inside After Effects. Explore audio effects available in After Effects ›

Refreshed After Effects Preferences Preferences are now grouped and organized better, so you reach them faster and keep your workflow efficient. Explore the refreshed After Effects preferences ›

New expression and scripting enhancements Jump straight to the keyframe or marker before or after a given time, and read the current text value together with the full list of dropdown menu items. Learn about dropdown menu attributes ›

Windows ARM native support Running natively now on Windows ARM systems, After Effects delivers better performance and efficiency for ARM-based devices. Learn about support for ARM-based Windows devices ›

Improved UI language support Run After Effects in a language other than your OS display language, type Unicode characters into UI elements, blend several language scripts within one text field, and more. Learn about UI language support in After Effects ›
