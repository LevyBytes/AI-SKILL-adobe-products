# Animating Puppet Tools (part 2)

> Adobe After Effects reference. Original prose; identifiers preserved verbatim.

## Other enhancements to Advanced Puppet Tool

- Any pin already placed can be flipped between the Position and Starch types.
- Sitting second among the Puppet tools in the Toolbar panel, the Puppet Starch tool carries its own distinct icon.
- Pin size responds to the Path Point and Handle Size options found under Preferences > Appearance. Pins also grow larger whenever the mouse hovers over them.
- While building the mesh outline, the Puppet effect skips over masks set to None as well as any mask already serving an effect as its mask reference (Effect properties > Compositing Options > Mask Reference).
