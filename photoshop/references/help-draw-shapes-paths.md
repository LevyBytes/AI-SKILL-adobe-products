## Draw shapes

Build and adjust shapes in Adobe Photoshop with the shapes tool group.

On the canvas, draw a shape by selecting any tool from the shapes tool group in the Tools panel and dragging.

Press Shift while you draw when the shape should keep proportional dimensions.

Use the Contextual Task Bar (Window > Contextual Task Bar) to change these shape properties:

- Fill: chooses the color used inside the shape.
- Stroke: chooses the stroke color, width, and type.
- Duplicate layer: makes an exact copy of the selected layer so you can reuse or edit that copy while leaving the original unchanged.

Note

Shape properties are also available through Shape Properties in the Properties panel or the Options bar.

Create and customize a shape using the Rectangle tool from the shapes tool group in the Tools panel.

## Modify fill and stroke for shapes

Adjust Fill and Stroke on shape layers in Adobe Photoshop with solid colors, gradients, or patterns.

Choose any tool from the shapes tool group in the Tools panel.

Drag on the canvas to create the shape.

From the Contextual Task Bar (Window > Contextual Task Bar), select Fill or Stroke to change fill or stroke color:

- Solid Color: uses the current foreground color as an even fill or stroke on the shape layer.
- Gradient: uses a selected gradient preset as the shape layer's gradient.
- Pattern: uses a chosen pattern preset from the available pattern choices.

Change stroke thickness and Stroke Options from the Contextual Task Bar.

Note

The Options bar and Properties panel also expose Fill and Stroke controls.

Add solid colors, gradients, or patterns to your shapes using the Fill or Stroke options in the Contextual Task Bar.

## Draw custom shapes

In Adobe Photoshop, draw custom shapes from built-in choices or make your own from paths and text.

Custom shapes let reusable vector graphics appear in your designs. You can use the built-in library, bring in more shapes, or create and save shapes of your own.

### Draw and edit a custom shape

Choose the Custom Shape tool from the shapes tool group in the toolbar.

Open the Shape dropdown in the Options bar.

Pick one custom shape from the displayed choices.

Tip

Use Import Shapes from the gear icon beside the options when you want to add shapes stored in local files.

Drag across the canvas to draw the shape.

### Save a shape or path as a custom shape

Make a path with the Pen tool or shape tools, or convert text into a path.

Open Window > Paths, then choose a path in the Paths panel.

Choose Edit > Define Custom Shape, then type a name for the custom shape in the Shape Name dialog.

Find the added shape in the custom shape picker on the Options bar.

## Create star shapes

Use the Star tool in Adobe Photoshop to draw a star shape and refine it with on-canvas controls.

From the shapes tool group in the Tools panel, choose the Star tool.

Drag on the canvas to create a star.

Adjust the shape with the settings in the Contextual Task Bar.

- Fill and Stroke: chooses the colors you want.
- Stroke width: changes how thick the stroke is.
- Set number of sides (or points on a star): chooses how many tips the star has.
- Corner radius: changes the sharpness of the corners.
- Inner Radius: sets how deep the gaps between spikes are.
- Outer Radius: sets the length of the star's spikes.

Note

The Options panel also provides controls for points, corner radius, and inner/outer radii.

Draw and customize a star shape using the Star tool and adjust anchor points, corner radius, and stroke settings using on-canvas controls.

## Draw a circle, square, or rectangle

Use the Ellipse and Rectangle tools in Adobe Photoshop when drawing circles, squares, and rectangles.

### Draw a circle

For a circle, choose the Ellipse tool from the Tools panel.

Tip

Choose the Create a new layer icon in the Layers panel before drawing if you want a nondestructive workflow on a new layer.

### Draw a square or rectangle

For a square or rectangle, choose the Rectangle tool from the Tools panel.

Tip

Choose the Create a new layer icon in the Layers panel before drawing if you want a nondestructive workflow on a new layer.

## Draw lines and line segments

In Adobe Photoshop, line segments can be drawn either as editable shapes or as fixed pixels.

With the Line tool, create lines as shapes when they should remain editable and scalable, or create them as pixels when they should be fixed and not scalable.

Choose Line tool from the shapes tool group in the toolbar.

Leave Shape mode selected in the Options bar so the lines stay scalable and easy to edit.

Draw a line by dragging anywhere on the canvas.

Use the Contextual Task Bar (Window > Contextual Task Bar) to set line color and stroke thickness.

Fill and Stroke controls are also available from the tool options bar or the Properties panel.

## Shape, path, and pixel mode options

Review the drawing-mode settings available for the Line tool and shape tools in Adobe Photoshop.

When you work with the Line tool or other shape tools in Photoshop, the drawing mode can be Shape, Path, or Pixels. That choice controls how Photoshop creates the line or shape and which edits remain possible later.

### Shape mode options

- Fill color: chooses the color, from the color picker or swatches, that fills the middle of shapes or arrowheads.
- Stroke color: chooses the color for a line and for shape outlines.
- Stroke width: sets stroke thickness in pixels.
- Stroke type: chooses solid, dashed, or dotted lines, with these related settings:
- Align: chooses Inside, Center, or Outside alignment.
- Caps: chooses Butt, Round, or Square line cap shapes for line endings.
- Corners: chooses the corner appearance for shapes with corners; this does not apply to the Line tool.
- Weight: sets the path width in pixels as a visual reference only.

### Live Shapes controls

- Turn on on-canvas transform controls by choosing the gear icon and then Live Shapes Controls.
- Change shape properties directly on the canvas.
- Open the Properties panel for additional options.

### Path mode options

- Operation: chooses how new paths combine with existing paths: Add, Subtract, Intersect, or Exclude.
- Path arrangement: sets stacking order while multiple paths are in use.
- Path alignment: aligns and distributes path components.
- Weight: sets the path width in pixels as a visual reference only.

Once a path exists, available follow-up actions include:

- Use Select > Load Selection to convert it to a selection.
- Use Edit > Fill to fill it with color.
- Use Edit > Stroke to stroke it with color.
- Store it as a named path in the Paths panel for later use.

### Pixel mode options

- Mode: chooses the blend mode that controls how pixels interact with underlying content
- Opacity: sets transparency from 1-100%
- Weight: sets line width or shape-edge width in pixels
- Anti-alias: turns on smoother edges; this is applied automatically

### Additional settings

Across drawing modes, some of these additional controls may be available:

- Path Operations icon: shows or hides path operation buttons.
- Path Arrangement icon: shows or hides path arrangement buttons.
- Path Alignment icon: shows or hides path alignment buttons.
- Set additional shape and path options icon: opens more Path options, Live Shapes Controls, Arrowheads, and related settings.
- Set number of sides (or points of a star) icon: sets side count while using the Polygon tool, or point count while using the Star tool.
- Set radius of rounded corners icon: sets rounded-corner curve width; this does not apply to the Line tool.

## Draw an arrow

Add arrowheads to a line in Adobe Photoshop when you need to draw an arrow.

To draw the line, choose Line tool from the shapes tool group in the Tools panel.

On the Contextual Task Bar (Window > Contextual Task Bar), use Arrowheads and choose Start or End.

For the arrowhead, enter Width and Length values in pixels.

Set Concavity between -50% and +50% to control the curve where the arrowhead joins the line.

## Trace images with the Content-Aware Tracing tool

Use edge detection in Adobe Photoshop to build vector paths or selections from image objects more quickly.

Adobe Photoshop includes Content-Aware Tracing tool as a Technology Preview. Turn it on with Preferences > Technology Previews, then restart Photoshop.

From the toolbar's Pen tool group, choose Content-Aware Tracing tool.

Place the pointer near the object's edge so Photoshop can find and highlight that boundary automatically.

In Options bar, move Detail slider right for more edge detection, or move it left when simpler edge finding is preferred.

Choose one tracing option in the options bar:

- Create paths from detected edges: makes a new path.
- Extend currently selected path with detected edges: appends the detected edge to an existing path.
- Trim traced paths: discards unneeded anchor points from the generated path.

Click once to create a vector path that tracks the detected edge.

## Draw curves and straight segments

Build and revise smooth curves or straight line segments in Adobe Photoshop by placing path points on the canvas.

Choose Curvature Pen tool from the Pen tools group in the toolbar.

Click a canvas location to set the first anchor point.

Click again to place the second anchor point and finish the first path segment.

- Select once to create a curved segment.
- Double-click to create a line segment.
- Keep selecting to add more points and extend the path.

Click the first point when you want to close the path.

Tip

Double-click an anchor point to switch it between a curved point and a corner (straight) point.

Use Curvature Pen tool from the Pen tools group to draw curves and segments.

Curves and segments can also be drawn with Curvature Pen tool in the Pen tools group.

## Draw paths with the Pen tool

Use Pen tool in Adobe Photoshop when you need to draw straight segments and curves.

Among Photoshop drawing tools, Pen tool provides precise vector-path creation with full control over both curves and straight segments.

### Draw straight line segments

With Pen tool active, click the point where the first line segment should begin; Photoshop creates a corner point there.

Click the location where the segment should finish. Keep clicking to add more straight segments.

Hold Shift while clicking to restrict a line to 45-degree angles.

Click the starting point to close the path. To leave it open, press Ctrl + Enter (Windows) or Command + Return (macOS).

### Draw curved segments

With Pen tool, click where the curve should begin, then drag to pull out direction handles that define the curve.

Place the cursor at the intended curve endpoint. Drag to continue with another curve, or click once when the segment should finish as a corner point.

Tip

To reshape during drawing, drag a direction handle while holding Alt (Windows) or Option (macOS).

To make an S-curve, drag the second point opposite the direction of the first point's direction handle.

Close the path with a curve by dragging the starting point.

### Combine straight and curved segments

Use Pen tool to create straight segments wherever the path needs them.

Apply whichever action fits:

- Transition from a straight segment to a curve: click where the straight segment should end, then drag to form a smooth point and its direction handles.
- Transition from a curve to a straight segment: while clicking, hold Alt (Windows) or Option (macOS) to change a smooth point into a corner point.

## Overview of Pen tool settings

Review Adobe Photoshop Pen tool settings when precise paths, curves, and shapes are needed for design work.

Photoshop's Pen tool gives detailed control while building paths, shapes, and selections. Knowing its settings can speed path work and improve design results.

When any Pen tool is selected, Options bar (Window > Options) shows these key controls:

### Drawing modes

### Auto Add/Delete

With this option enabled, you can:

- Add anchor points by clicking a path segment.
- Remove anchor points by clicking them.
- Keep a path's shape from changing when an anchor point is selected.

### Rubber Band

With Rubber Band enabled, Photoshop previews path segments as the pointer moves before you click the next anchor point. The preview makes the path easier to visualize. Use Set additional pen and path options icon to choose Rubber Band.

### Anchor point types

### Direction handles

Direction handles determine how the curve is shaped:

- Longer handles produce flatter curves
- Shorter handles produce sharper curves
- Asymmetrical handles produce uneven curves
- Handles aimed in opposite directions produce S-curves
