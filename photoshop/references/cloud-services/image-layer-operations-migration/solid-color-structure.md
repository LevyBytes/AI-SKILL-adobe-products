# Solid color structure

**V1:** `rgb` remains nested inside the color object

```json
{
  "fill": {
    "solidColor": {
      "rgb": {
        "red": 255,
        "green": 0,
        "blue": 0
      }
    }
  }
}
```

**V2:** the same nested layout is still used

```json
{
  "fill": {
    "solidColor": {
      "rgb": {
        "red": 255,
        "green": 0,
        "blue": 0
      }
    }
  }
}
```
