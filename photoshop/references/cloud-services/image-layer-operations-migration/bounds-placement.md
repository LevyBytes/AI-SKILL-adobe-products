# Bounds placement

Explicit positioning is supported in both V1 and V2:

**V1:**

```json
{
  "type": "layer",
  "name": "Positioned Image",
  "bounds": {
    "left": 100,
    "top": 100,
    "width": 500,
    "height": 300
  }
}
```

**V2:** (identical bounds shape)

```json
{
  "type": "layer",
  "name": "Positioned Image",
  "bounds": {
    "left": 100,
    "top": 100,
    "width": 500,
    "height": 300
  }
}
```
