# Modify padding values

In the 5th action, edit `canvasSize` and replace the `_value` entries:

**100-pixel padding example:**

```json
{
  "_obj": "canvasSize",
  "height": {
    "_unit": "pixelsUnit",
    "_value": 100
  },
  "horizontal": {
    "_enum": "horizontalLocation",
    "_value": "center"
  },
  "relative": true,
  "vertical": {
    "_enum": "verticalLocation",
    "_value": "center"
  },
  "width": {
    "_unit": "pixelsUnit",
    "_value": 100
  }
}
```
