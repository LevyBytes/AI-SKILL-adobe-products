# Standard profile example

```json
{
  "iccProfile": {
    "type": "standard",
    "name": "sRGB IEC61966-2.1",
    "imageMode": "rgb"
  }
}
```

Profile names are exact-match values, including spaces and punctuation. For standard profiles, `imageMode` accepts only `rgb` or `grayscale`; CMYK is unsupported.
