# Standard profile names

**RGB Profiles:**

- Adobe RGB (1998)
- Apple RGB
- ColorMatch RGB
- sRGB IEC61966-2.1

**Grayscale Profiles (Dot Gain):**

- Dot Gain 10%
- Dot Gain 15%
- Dot Gain 20%
- Dot Gain 25%
- Dot Gain 30%

**Grayscale Profiles (Gray Gamma):**

- Gray Gamma 1.8
- Gray Gamma 2.2
