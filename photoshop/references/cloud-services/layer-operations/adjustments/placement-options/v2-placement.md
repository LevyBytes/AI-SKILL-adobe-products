# V2 Placement

```json
{
  "operation": {
    "type": "add",
    "placement": {
      "type": "top"
    }
  }
}
```

For relative placement, combine `"above"`, `"below"`, or `"into"` with `referenceLayer`: `{"name": "..."}` or `{"id": 123}`.

For detailed placement migration patterns, see [Image Layer Operations](../../../layer-operations-migration/image-layer-operations.md).
