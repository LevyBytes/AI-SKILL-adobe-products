# Migrating Convenience APIs

V1 included several convenience APIs backed by predefined action files on the server. In v2, those action files are available publicly so you can use them as-is, customize them, or study their structure.

**Key Benefits:**

- Inspect the exact ActionJSON definitions used by Adobe
- Customize every parameter and workflow path
- Study Adobe's implementation details
- Build variants and extensions of your own
- Aligns with the unified `/v2/execute-actions` endpoint
