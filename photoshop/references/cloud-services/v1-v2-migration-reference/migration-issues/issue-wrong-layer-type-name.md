# Issue: Wrong layer type name

**Problem:** Using V1 layer type names

Alternative layer `type` values for V1:

- `textLayer`
- `adjustmentLayer`
- `smartObject`

**Solution:** Use V2 underscore format

Alternative layer `type` values for V2:

- `text_layer`
- `adjustment_layer`
- `smart_object_layer`
- `solid_color_layer`
