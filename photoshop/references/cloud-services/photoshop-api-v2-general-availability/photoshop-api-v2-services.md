# Photoshop API v2 services

The v2 API exposes many useful Photoshop operations. Examples include:

- **[Remove background](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/guides/remove-background/index.md)** - Uses AI to find and isolate the primary subject, removes the background, and keeps the subject available for cutouts and composites.
- **[Smart Objects](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/guides/smart-objects-and-the-api/index.md)** - Creates and replaces embedded and linked Smart Objects in a PSD, fitting replacement imagery to the original layer bounds while preserving aspect ratio.
- **[Product Crop](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/guides/product-crop/index.md)** - Detects the subject and smart-crops the image so the subject becomes the focal point.
- **[ActionJSON](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/guides/actionjson-endpoint/index.md)** - Runs Photoshop Actions from an ATN file programmatically and lets the action payload be adjusted for flexible, dynamic edits.

For the full service set, open the [Photoshop API v2 guides](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/guides/photoshop-v2/index.md), or review endpoints in the [Photoshop API v2 reference](https://raw.githubusercontent.com/AdobeDocs/ffs-photoshop-API/6a5b7e759e09b595562aa4cb20a2e9b36437bb60/src/pages/api/photoshop-v2/index.md).
