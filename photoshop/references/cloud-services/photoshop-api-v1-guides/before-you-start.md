# Before you start

Before any example can run, obtain a Bearer token and API key. The [Getting Started](../authentication.md) section explains where to retrieve them.

To make the examples easier to run, export the token and API key first:

Replace these example values with your own credentials or the returned upload identifier in your private shell session.

```shell
export token="<your_token>"
```

Replace these example values with your own credentials or the returned upload identifier in your private shell session.

```shell
export apiKey="<your_api_key>"
```
