## Home screen overview

Learn where the Adobe Photoshop Home screen places files, tools, and creative resources so you can reach them quickly.

### Home screen

At startup, Photoshop displays the Home screen with these areas:

- Feature highlights that surface recent Photoshop improvements.
- Tutorials for learning concepts, workflows, tips, and tricks.
- A Recents section for recent cloud documents, including files shared with you.
- Keyword filters for locating particular cloud documents. Offline status greys out online-only cloud documents.

Photoshop tailors Home screen content to your Photoshop experience and Creative Cloud membership.

Based on your Photoshop experience and Creative Cloud membership, the Home screen presents personalized content. Tip

While a document is open, select Home in the Options bar to go back to the Home screen. Press Esc to leave the Home screen.

The Home screen includes these tabs and buttons:

- New file: starts a new document from the available templates.
- Open: loads an existing Photoshop document.
- Home: returns to the Home screen.
- Learn: opens tutorials for beginner and advanced Photoshop skills.
- Your files: shows all of your files within the categories below:
- Shared with you: shows Photoshop cloud documents that others shared with you.
- Lightroom photos: shows synced Lightroom photos and lets you bring them into a Photoshop document.
- Deleted: lists cloud-storage documents you removed, with choices to restore or permanently delete them.

Note

To change how many recent files appear, select Edit > Preferences > File Handling and set a value from 0 to 100 in the Recent File List Contains field.

## High-density monitor support and per-monitor scaling

Learn how Photoshop changes settings for high-density monitors so images stay sharp at every screen resolution.

### High-density monitors

Compared with standard monitors, high-density displays pack in more pixels per inch. Text appears sharper and images look clearer on them. Applications need display-aware design to render well on these monitors.

### Per-monitor scaling

On Windows 10 Creators Update and later, Photoshop provides UI scaling from 100% through 400% using 25% steps. This range keeps the Photoshop interface crisp and correctly sized across different monitor setups.

Multiple monitors can use different scaling values. For example, one monitor can run at 175% while another uses 400%, giving a smooth experience across a 4K laptop, a 1080p desktop, or an 8K monitor.

To change scaling on Windows, open Start > Settings > System > Display and pick the scaling factor for each display. Then use Scale And Layout to choose each display's scaling factor.

### Photoshop UI scaling

In Windows 10 and later, Photoshop applies UI scaling only to certain dialogs, including File Info and Camera Raw. To change Photoshop UI scaling, choose Edit > Preferences > Interface > UI Scaling and select Auto, 100%, or 200% for the display. Auto matches the primary monitor's 100% or 200% scaling.
