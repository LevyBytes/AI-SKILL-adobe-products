## Get started with artboards

Review how artboards work in Adobe Photoshop, including their structure, advantages, and appearance controls for multi-screen design.

### Overview

Artboards function as specialized layer groups whose boundaries crop the elements inside them. For web and UX design, artboards make it possible to build layouts for several devices and screen dimensions at the same time.

When an artboard is created, Photoshop lets you select a preset size or enter a custom size. They also help when the project targets just one screen size. For instance, a website design can place separate pages on artboards so those pages can be compared side by side and in context.

### Structure and organization

- Artboards crop the elements contained inside them.
- Artboards can contain layers and layer groups, but they cannot contain other artboards. Within a document, they behave like separate canvases.
- In the Layers panel, contents inside an artboard are shown next to other layers and layer groups.
- Layers that sit outside any artboard appear separately in the Layers panel and are not clipped.

### Benefits of artboards

- Side-by-side designs: keep several versions in a single file to compare screens more consistently.
- Organized layers: Photoshop groups and clips layers inside artboards automatically.
- Flexible structure: artboards can store layers and groups, but they do not hold other artboards.

## Artboard properties and behaviors

Use artboard properties and behaviors in Adobe Photoshop to organize layouts and make the workflow more efficient.

Photoshop artboard properties let you tune and administer several canvases inside one document. By changing those properties and applying key behaviors, the workspace can be shaped around the needs of the design. These features support faster work and help maintain consistency across web, mobile, and print projects.

### Artboard properties

When an artboard is selected, these options are available in the Properties panel.

### Artboard behaviors

Artboard behaviors cover how artboards and their contents are organized, moved, and managed in Photoshop. Through these behaviors, you can move elements, resize artboards, lock items, filter layers, and otherwise fit artboards into the design workflow.

### Artboard use cases

- Design for multiple devices: test responsive results by creating artboards from preset sizes such as iPhone, iPad, or web templates.
- Organize a campaign: keep banners, posters, and social graphics in one file by using multiple artboards with distinct names.
- Improve readability: during editing, switch background colors so white or light-colored designs are easier to see.

## Create artboard documents

Create fresh artboards in Adobe Photoshop or convert existing documents into artboard-based documents.

Artboards allow several canvases to live inside one Photoshop document. Use them to place screen sizes, page layouts, or design variations beside one another.

### Create new artboards

Choose File > New. Photoshop opens the New Document dialog box.

Select the Artboards checkbox.

Choose an artboard-capable preset, such as Mobile.

Enter a document name, for example iPhone-subscribe.

Choose Create. Photoshop creates a document and shows the first artboard in the Layers panel.

Add a new artboard when one Photoshop document needs responsive layouts or several design variations.

Add a new artboard when one Photoshop document needs responsive layouts or several design variations.

### Create artboards from existing documents

Choose File > Open, then select the Photoshop file to turn into an artboard.

In the Layers panel, choose the layers that should become part of the new artboard.

Right-click the selected layers and choose Artboard from Layers. Photoshop converts those selected layers into artboards, and each artboard appears as its own group in the Layers panel.

Tip

To make an artboard from a layer group, right-click that group in the Layers panel and choose Artboard from Group.

## Add artboards to the current document

Add artboards to an Adobe Photoshop document so multiple layouts can be designed in the same file.

Artboards support several screens or layouts inside one Photoshop document. New artboards can expand the project without requiring separate files.

### Draw new artboards

Select the Artboard tool, which is grouped with the Move tool. If it is hidden, select and hold the Move tool to reveal it.

Drag on the canvas to draw a new artboard at the size you want.

Tip

For preset dimensions, use the Size dropdown menu in the Options bar.

Rename the artboard by double-clicking its name in the Layers panel.

Choose the artboard in the Layers panel and design inside it as though it were an independent canvas. Smart objects, layers, and layer groups can be added to the artboard.

Choose an existing artboard in the document. Icons appear along the sides of that selected artboard.

Select a icon to create a new artboard in that direction.

## Draw frames

Use the Frame tool in Adobe Photoshop to make drawn containers that mask images placed into them.

Within Photoshop, the Frame tool creates shapes that both mask inserted images and scale those images to fit. Available frame choices include rectangles, ellipses, triangles, custom shapes, and generative AI options. Frames support layouts that need several images clipped into defined forms, including photo collages and mockups.

### Draw empty frames

Choose Frame tool.

From the Options bar, choose the frame shape you need: rectangular, elliptical, triangle, polygonal, or custom.

In the Options bar, configure any other frame attributes, including stroke color, width, and alignment.

Drag across the canvas until the frame reaches the size you want.

Tip

Bring in existing images, or use Generate Image to make images inside shapes, then refine their look from the Contextual Task Bar.

### Draw frames in existing images

Choose Frame tool.

From the Options bar, choose the frame shape you need: rectangular, elliptical, triangle, polygonal, or custom.

Draw the frame on top of the image region you want to mask.

In Photoshop, frames let you mask and scale images while building adaptable design layouts.

For flexible Photoshop layouts, use frames to clip images and resize them as needed.

## Convert shapes or text to frames

Turn shape or text layers into frames when you need to mask images in Adobe Photoshop.

The Frame Tool is useful for building image placeholders with nonstandard outlines. Drawing frames is one approach, but converting existing shapes or text to frames gives more design flexibility, particularly in complex artwork.

Choose a shape tool in the toolbar, then draw a rectangle, ellipse, or another shape.

Tip

A text layer can also be created and converted into a frame.

Using the Layers panel, right-click (Windows) or Control-click (macOS) the relevant shape or text layer.

From the context menu, choose Convert to Frame.

In the New Frame dialog box, enter a frame name and set the width and height.

Choose OK to turn the shape or text into a frame.

After that, either generate an AI image or import one that already exists.

## Place an image into a frame

Add or replace imagery in a frame made with the Frame tool in Adobe Photoshop.

Photoshop frames create shapes that mask whatever image is placed inside. With the Frame tool, inserted content becomes a Smart Object, so it can be edited while preserving clarity. Images scale automatically to the frame edges. Add images to frames when you need layouts with shaped picture areas.

Draw a frame with the Frame tool.

Choose File > Place Embedded or Place Linked to put an image into the frame. Photoshop adds the image as a Smart Object.

- Use Place Embedded when the image should remain stored inside your Photoshop file.
- Use Place Linked when the image should stay linked to a file on your computer and keep the Photoshop file smaller.

To add an asset from the Library panel, drag that asset onto the frame.

Place an image within a frame to clip its shape and assemble dynamic collage layouts.

Insert an image in a frame to shape it and create active collage layouts. Note

In the Layers panel, frames appear as their own layer type. A frame layer displays two thumbnails, one for the frame and one for the content, so you can edit each part more easily.

## Add a stroke to a frame

Create borders around images or design elements in Adobe Photoshop by applying a stroke to a frame.

A stroke on a Photoshop frame adds a clear border around the image, which can increase visual emphasis and separation. The stroke's color, width, and alignment can be adjusted for different design results.

Before starting

Create a frame with the Frame Tool, then insert an image into that frame.

In the Layers panel, select the frame layer.

Choose fx in the lower-left corner of the Layers panel.

In the Properties panel, choose the Stroke options section. This opens the Layer Style dialog box.

Tip

If the Properties panel is hidden, choose Window > Properties to show it.

From the Fill Type dropdown menu, choose a stroke type: solid Color, Gradient, or Pattern.

Select the color swatch to choose a color from the Color Picker.

Set the stroke width by typing a value in the Size field or moving the slider.

For Position, choose Inside, Center, or Outside to control where the stroke sits relative to the frame edge.

When using Gradient or Pattern strokes, change the angle value to rotate the strokes.

Choose OK to apply the changes. The stroke appears around the frame.

Use strokes to call attention to framed content, make it visually separate, and improve design clarity.

Applying a stroke can emphasize framed content, distinguish it visually, and make the design clearer.
