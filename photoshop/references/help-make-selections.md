## Selection tools overview

Review the selection tools available in Adobe Photoshop.

## Use the Object Selection tool

Select specific objects or areas in an image with the Object Selection tool.

With the Object Selection tool, draw a rectangle or lasso around an area, or allow Photoshop to detect and select the object or region automatically.

Choose the Object Selection tool from the toolbar.

Hover over the image so Photoshop highlights the object or region you want to select.

Choose Set additional options in the Option bar and disable Object finder when you want to define a region manually with either Rectangle or Lasso tool.

Use Set additional options in the Option bar to turn off Object finder for manually defining an area with either Rectangle or Lasso tool.

Choose a selection mode from the Options bar for further changes:

- New selection: create a selection when no selection is active.
- Add to selection: include more areas by hovering over them or drawing around them.
- Subtract from selection: remove areas you do not want by hovering over them or drawing around them.
- Intersect with selection: keep only areas where multiple selections overlap.

Refine the selection with more Options bar controls:

- Sample All Layers: include all visible layers in the selection.
- Hard Edge: use sharp edges on the selection boundary.

## Improve Select Subject and Remove Background results

Use Adobe Photoshop's improved Device and Cloud processing to build detailed selections and edit images faster.

For Select Subject and Remove Background, improved Device processing can produce more detailed selections.

Use improved Device processing with Select Subject and Remove Background when you need finer selection results.

### Improve results with on-device processing

Open an image with File > Open.

From the main menu, open Settings > Image Processing (macOS) or Edit > Preferences > Image Processing (Windows).

In the Preferences dialog box, choose Device from the Select Subject and Remove Background dropdown.

Note

Photoshop refines selections with Device processing by default.

For better results, set the processing mode to Device in Preferences > Image Processing.

In Preferences > Image Processing, use Device as the processing mode to improve the output.

Use the Select and Mask workspace to refine the selection and apply edits.

### Improve results with cloud processing

Open an image through File > Open.

From the main menu, choose Settings > Image Processing (macOS) or Edit > Preferences > Image Processing (Windows).

In the Preferences dialog box, set the Select Subject and Remove Background dropdown to Cloud.

Use the Select and Mask workspace to refine the selection and apply edits.

## Make precise selections using Select People

In Photoshop, use the Select People tool when you need accurate selections of people or their features.

Choose the Object Selection tool from the toolbar.

From the Options bar, choose Select people.

Choose a thumbnail for one person in the image.

Choose Entire person for the full body, or choose tags such as Facial skin, Beard, Hair, Eyebrows, and more for specific parts.

Note

When you hover on the canvas, you can also choose details directly there.

## Remove objects with Delete and Fill Selection

Use Delete and Fill Selection to remove unwanted objects from an image.

With whichever selection tool best fits the image, select the object to remove.

Control+click (macOS) or right-click (Windows) the selected object, then choose Delete and Fill Selection.

Photoshop removes that selection automatically and fills the empty area with content matched to the surrounding image.

## Improve hair selections with the Refine Hair tool

For cleaner and more accurate hair selections, use the hair refinement controls in the Select and Mask workspace.

Choose the Object Selection tool, then choose Select Subject.

Choose Select and Mask > Refine Hair.

In the Properties panel, adjust these settings:

- Transparency: changes how visibly the selection appears over the image.
- Preset: applies a commonly used set of refinement settings.
- Refine Mode: lets you choose Color Aware or Object Aware for improved edge detection.
- Edge Detection: provides controls that help Photoshop detect fine hair edges more effectively.
- Global Refinement: gives precise control over Smooth, Feather, Contrast, and Shift Edge values.
- Output Settings: controls where and how the final selection is applied or exported.

Choose OK to apply the refined selection.

## Mask all objects in a layer

Mask All Objects can automatically create individual masks for every detected object in a layer.

In the Layers panel, choose a layer.

Open the selected layer's context menu with Right-click (Windows) or Control-click (macOS).

Choose Mask All Objects.

## Detect subject using Select Subject

In Adobe Photoshop, Select Subject can detect the most prominent subject in an image and select it.

Choose the main subject in the image.

Choose Select Subject from the Options bar.

Use Add to selection or Subtract from selection to refine the selected area.

Choose Select and Mask to fine-tune the selection with the Properties panel options.

Tip

- Select Subject can select all main subjects in an image automatically.
- When an image has multiple subjects, use the Object Selection tool to choose one specific object.

## Paint a selection with Quick Selection tool

In Photoshop, the Quick Selection tool lets you create fast, precise selections by painting over the area you want.

Choose the Quick Selection tool from the toolbar.

In the Options bar, choose a selection mode: New selection, Add to selection, or Subtract from selection.

From the pop-up menu, choose these Brush settings.

- Size: changes the brush tip diameter.
- Hardness: controls how sharp the brush edges are.
- Spacing: sets the distance between brush marks within a stroke.
- Angle: rotates the brush tip to a specific angle.
- Roundness: adjusts the brush tip shape by changing its roundness.
- Size: makes brush behavior respond to pen pressure or the stylus wheel.

To adjust brush sensitivity, choose Size from the drop-down menu.

Use these settings to fine-tune the selection.

- Sample All Layers : builds the selection from all layers rather than only the currently selected layer.
- Enhance Edge: improves edges automatically by making them smoother and more refined.

Paint across the desired area to expand the selection along detected edges.

Choose Select and Mask for additional selection refinement.

## Select areas by color with the Magic Wand tool

In Photoshop, the Magic Wand tool selects similarly colored areas without requiring you to trace edges.

Activate the Magic Wand tool in the toolbar.

For selection behavior, use one of these Options bar modes:

- Add to selection
- Subtract from selection
- Intersect with selection

In the options bar, adjust these settings:

- Sample Size: controls how much image data is sampled when determining selection sensitivity.
- Tolerance: sets the selected color-value range from 0 (narrow) to 255 (broad).
- Anti-alias: turns on smoother edge creation.
- Contiguous: limits the selection to adjacent areas with similar color.
- Sample All Layers : bases the selection on every visible layer.

Choose the color area in the image to create a selection using the defined settings.

Choose Select and Mask to refine the selection further or preview it as a mask.

## Create quick selections with the Selection Brush Tool

In Adobe Photoshop, use the Selection Brush tool when you want to paint selections precisely.

Choose the Selection Brush tool from the toolbar.

Brush over the canvas area to create a selection overlay.

The selection overlay appears as a red color overlay.

In the Options bar, choose the settings icon, then pick a color from the Color dropdown to change the overlay color.

In the Options bar, set Opacity, Size, and Hardness for the brush.

Switch between Add brush and Subtract brush modes to refine the selection.

## Select a Color Range in Photoshop

Use the Color Range command in Photoshop to select and refine a particular color or tonal range.

Color Range in Photoshop builds selections from specific colors or tones in an image. Compared with manual selection tools, it gives more precision and flexibility because you can sample colors, detect skin tones, or identify out-of-gamut colors that cannot print in CMYK. Options such as Localized Color Clusters, Fuzziness, and Invert help target only the areas that need adjustment while the rest of the image remains unchanged.

Choose Select > Color Range.

In the Color Range dialog, choose one of these Select options:

- Skin Tones: chooses colors similar to common skin tones. Enable Detect Faces for greater accuracy.
- Sampled Colors: uses the Eyedropper tool to choose sample colors from the image. Choose Localized Color Clusters for a more precise selection.
- Color or tonal range: chooses a predefined color or tone.
- Out of Gamut: chooses colors outside the printable CMYK range and adjusts them to the nearest reproducible color.

Note

If you want to replace an existing selection, deselect any active selection first.

### Preview the selection

Choose Select > Color Range.

In the Color Range dialog, choose any of these display options:

- Selection: displays selected pixels in white, unselected pixels in black, and partially selected pixels in gray.
- Image: displays the full image as a reference.

Press Ctrl (Windows) or Command (macOS) to switch between Selection and Image previews.

### Sample and adjust colors

Place the Eyedropper tool over the image and choose to sample a color.

To add colors, choose Eyedropper or hold Shift while sampling.

To remove colors, choose Eyedropper or hold Alt (Windows) or Option (macOS).

Move the Fuzziness slider to broaden or narrow the color range.

When Localized Color Clusters is in use, move the Range slider to restrict the sampled-color area.

### Refine the selection

Choose Select > Color Range.

In the Selection Preview drop-down menu, choose one of these options:

- None: shows the original image.
- Grayscale: white = selected, black = unselected, gray = partial.
- Black Matte: shows selected pixels while unselected areas appear black.
- White Matte: shows selected pixels while unselected areas appear white.
- Quick Mask: displays unselected areas with a rubylith overlay.

To restore the original selection, hold Alt (Windows) / Option (macOS) and choose Reset.

### Save and load settings

Choose Select > Color Range.

In the Color Range dialog, choose Save to store the settings.

Choose Load to reuse stored settings.

Store Skin Tones selections as a preset for later use.

Tip

Enable Invert in the Color Range dialog when you want to preserve the selected colors and adjust everything else in the image.

## Draw freeform selections with the Lasso tool

In Adobe Photoshop, the Lasso tool draws and refines freeform selection borders.

Activate the Lasso tool in the toolbar.

In the Options bar, enter a Feather value to soften selection edges.

Enable the Anti-alias checkbox to create smoother selection edges.

From the Options bar, choose Add to selection, Subtract from selection, or Intersect with selection.

Create a freehand selection border by dragging freely.

For straight-edged segment starts and ends, hold Alt (Windows) or Option (macOS) and choose points.

Release the mouse button to close the selection border.

## Draw straight-edged segments of a selection border

In Adobe Photoshop, the Polygonal Lasso tool creates precise selections made from straight-edged segments.

Choose the Polygonal Lasso tool from the toolbar.

Choose a selection mode from the Options bar.

Enter a Feather value and enable the Anti-alias checkbox to smooth selection edges.

On the canvas, choose the starting point for the selection.

- To draw a straight segment, choose again at the point where the segment should end.
- For a segment constrained to a 45° angle, hold Shift and choose the next point.
- For a freehand segment, drag while holding Alt (Windows) or Option (macOS).
- Remove the most recent segment with the Delete key.

To close the selection,

- When the circular icon appears over Polygonal Lasso icon, choose the starting point.
- Away from the starting point, close the selection with double-click or Ctrl+click (Windows) or Command+click (macOS).

## Snap to image edges using Magnetic Lasso tool

In Adobe Photoshop, the Magnetic Lasso tool snaps selection borders to clearly defined edges in an image.

Magnetic Lasso in Photoshop helps create precise selections. While you trace an object's edge, the selection border snaps to defined areas, which makes the tool useful for complex outlines against high-contrast backgrounds. It is not available for 32-bit images.

Choose the Magnetic Lasso tool from the toolbar.

Choose one of the selection modes in the Options bar.

Enable the Current Tool Only checkbox.

Enable the Current Tool Only checkbox again where required.

Set these controls in the Options bar.

- Feather: softens a selection edge by fading it gradually into nearby pixels.
- Anti-alias: smooths the selection boundary by blending edge pixels with the background.
- Width: defines how far from the pointer the tool searches for edges.
- Contrast: changes how sensitive the tool is to edge differences in the image.
- Frequency: controls how often fastening points are placed automatically.

Choose Use tablet pressure to change pen width to reduce edge width as pen pressure increases when using a stylus.

Click in the image to place the first fastening point, then trace the edge by dragging.

If the border does not snap to the edge you want, choose to add fastening points manually.

Press Delete when you need to remove recently added segments or fastening points.

To close the selection border, choose the starting point when the circular icon appears. Away from the starting point, finish it with double-click or Ctrl + click (Windows) or Command + click (macOS).

Tip

Press Caps Lock to switch the lasso pointer so it shows the lasso width. Pointer changes are available when the tool is selected but idle. Use ] to increase the Magnetic Lasso edge width by 1 pixel, and use [ to decrease the width by 1 pixel.

For an image with well-defined edges, use higher Width and Contrast settings and trace the border roughly. For softer edges, use lower Width and Contrast settings and trace more precisely.

## Save Skin Tones settings as a preset

In Adobe Photoshop, save Skin Tones settings as a preset so you can reuse them later.

Choose Select > Color Range.

In the Color Range dialog, choose Skin Tones from the Select menu.

Choose Detect Faces to improve accuracy.

Set the Fuzziness slider, or type a value.

Set Display to Selection and choose a Selection Preview to view the selections.

Choose Save.

In the Save window, enter a file name for the preset, then choose Save.

### Load a Skin Tones preset

Choose Select > Color Range.

In the Color Range dialog, choose Load.

In the Load window, choose the preset file you want.

Choose Load.
