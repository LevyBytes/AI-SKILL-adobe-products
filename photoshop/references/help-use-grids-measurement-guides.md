## Overview of guides, grids, and smart guides

Learn how guides, grids, and smart guides support exact positioning and alignment of elements in Adobe Photoshop projects for polished layouts and designs.

### What are guides, grids, and smart guides?

Professional Photoshop layouts depend on exact positioning and alignment. Photoshop supplies three alignment aids: guides, grids, and smart guides, which make well-aligned layouts possible without relying on guesswork.

These visual aids sit above the image as non-printing lines or points and give you reference positions for precise element placement. Each aid has its own role, and together they support refined, professional designs.

### Guides

Guides are movable, customizable lines for placing particular elements accurately. Unlike grids, which follow a fixed structure, guides can go exactly where your layout needs them.

### Key characteristics of guides:

- Display as colored non-printing lines above the image
- Support horizontal or vertical placement at exact coordinates
- Can be moved, locked, or removed when needed
- Allow different colors so you can organize the layout
- Elements snap to guides when dragged within 8 screen pixels

Guides help when elements on separate layers need to line up or when a custom layout does not fit a regular grid. For a website mockup, for example, guides can mark the edges of different content sections.

### Grids

The grid gives the whole canvas a steady, evenly spaced line pattern. Use it for symmetrical layouts or when spacing between elements must stay consistent.

### Key characteristics of grids:

- Show a uniform non-printing pattern of lines or dots across the entire canvas
- Keep spacing between lines consistent
- Support symmetrical layouts and proportional structure
- Use the same grid pattern for every image
- When snap is enabled, elements attach to grid lines

Grids are useful for interface design, layouts with repeated elements, and projects where consistent proportions need to hold across the design.

### Smart guides

Smart guides are dynamic alignment helpers that show up automatically at useful moments. They align objects against one another without requiring you to place guides manually.

### Key characteristics of smart guides:

- Show automatically while you create or move shapes, selections, or layers
- Help align objects to one another's edges or centers
- Show distances between elements when modifier keys are used
- Give immediate feedback about alignment relationships
- Can be turned on or off when needed

Smart guides help most when several elements need to line up quickly or when objects must sit at defined distances from each other.

## Show or hide guides, grids, and smart guides

Control which Adobe Photoshop alignment tools are visible so the workspace stays uncluttered while you place elements precisely.

Guides, Grids, and Smart Guides support precise positioning in Photoshop documents. Because these non-printing visual aids help with object alignment, symmetrical layouts, and consistent spacing, they can speed up layout work.

Guides are movable non-printing lines above the image and can be removed when they are no longer needed. Grids supply a regular line pattern for symmetrical layouts. Smart Guides appear automatically as you create shapes, selections, or move objects, giving alignment feedback in the moment. These tools show only inside the workspace and do not appear in final output.

### Show or hide visual alignment tools

Use View > Show > Grid to change whether the grid is visible.

Use View > Show > Guides to change guide visibility.

Use View > Show > Smart Guides to change Smart Guides visibility.

Use View > Extras when you want all non-printing elements shown or hidden together, including guides, grid, selection edges, target paths, and slices.

### Toggle visibility with keyboard shortcuts

Press Ctrl + ' (Windows) or Command + ' (macOS) when you need the grid shown or hidden.

Press Ctrl + ; (Windows) or Command + ; (macOS) to switch guide visibility.

Press Ctrl + Shift + ; (Windows) or Command + Shift + ; (macOS) to switch Smart Guides visibility.

Tip

For the highest positioning accuracy, use 100% magnification or check exact values in the Info panel.

## Create guides

Use nonprinting guide lines and grids in Adobe Photoshop to align objects, build symmetrical layouts, and place elements accurately.

Photoshop guides support accurate placement while you design. They are nonprinting lines above the image, which makes aligning objects and balancing a layout easier.

A grid shows a fixed pattern across the full canvas, but guides can be set wherever the design requires them. Guides may be horizontal or vertical, and a project can contain as many as needed.

### Create guides from the horizontal or vertical ruler

Select View > Rulers.

From either the horizontal or vertical ruler, drag into the image to create a guide in that orientation.

Hold Shift while dragging to snap the guide to the ruler ticks.

### Create guides from the View menu

Select View > Guides > New Guide.

In the New guide dialog, choose the Orientation and Color, then enter a Position value.

Select OK.

## Move guides

Use the Move tool when guides need exact repositioning for aligning items in an Adobe Photoshop document.

In Photoshop documents, guides give a precision aid for placing elements. After a guide has been added, shift it whenever the layout needs adjustment.

Guides are non-printing overlay lines above the image. Moving them lets you build exact layouts and alignments while leaving the image pixels unchanged. At any stage of editing, you can place a guide somewhere else.

### Move a guide

Choose the Move tool.

Place the pointer over the guide to be moved; the cursor changes to a double-headed arrow (icon will be added here).

Drag the guide until it reaches the new location.

While dragging, hold Alt (Windows) or Option (macOS) to switch a guide between horizontal and vertical orientation.

Hold Shift during the drag when the guide should snap to ruler ticks.

### Move multiple guides

Choose the Move tool.

Press Shift + Alt (Windows) or Shift + Option (macOS), then click the guides you want included in the selection.

Drag once to reposition all selected guides as a group.

Let go of the mouse button after the guides reach the intended position.

### Edit guide position numerically

Use the Move tool to select a guide.

Choose View > Guides > Edit Selected Guides.

Change the Position value, then select OK.

## Edit guides

Change a guide's position, orientation, and color in Adobe Photoshop so layouts stay precise and the workflow remains efficient.

When guide settings need adjustment, edit the existing guides instead of deleting and rebuilding them. This helps on complex layouts that depend on exact alignment, and it also supports collaboration where colored visual cues need to stay specific.

### Edit guides when creating them

Choose View > New Guide to display the New Guide dialog.

Set Orientation to Horizontal or Vertical, then enter the Position value.

Choose a preset color, or select Custom and pick a color in the Color picker (guides color), then select OK.

Select OK.

### Edit existing guides

Choose the Move tool.

To include more than one guide, hold Alt + Shift (Windows) or Option + Shift (macOS).

Right-click any selected guide, then choose Edit Selected Guides.

Set Orientation to Horizontal or Vertical.

Choose a preset color, or select Custom and pick a color in the Color picker (guides color), then select OK.

Select OK.

## Set guide and grid preferences

Adjust guide colors, styles, and grid measurements in Adobe Photoshop to make precise positioning and alignment easier.

In Photoshop, guides are non-printing lines over the image, while the grid supplies a regular line or dot pattern for symmetrical layouts. Setting these preferences for the document lets different guide types stand apart visually and can streamline the work.

Choose Edit > Preferences > Guides, Grid, & Slices (Windows) or Photoshop > Settings > Guides, Grid, & Slices (macOS).

## Work efficiently with Smart Guides

Turn on Smart Guides in Adobe Photoshop so objects can align automatically and distances between design elements can be measured while you work.

In Photoshop, Smart Guides assist with precise alignment for shapes, layers, and selections. These temporary visual aids appear on their own as elements are created or moved, helping you place items in relation to surrounding content.

Smart Guides are useful for building symmetrical layouts, aligning several objects, or keeping spacing consistent between elements. Regular guides are placed manually; Smart Guides appear dynamically during editing and show alignment opportunities plus real-time measurements.

### Enable Smart Guides

Choose View > Show > Smart Guides to switch Smart Guides on or off. When the feature is active, the Smart Guides menu item shows a checkmark.

Tip

The same toggle is available with Ctrl+U (Windows) or Command+U (macOS).

### Align objects using Smart Guides

Choose the Move tool.

Choose View > Snap for precise alignment.

Drag a layer, shape, or selection in the document. Pink Smart Guides appear when the element lines up with edges, centers, or boundaries of other objects. Smart Guides also display the pixel distance between objects as you move them.

Release the mouse to place the element in exact alignment.

## Manage measurement scales

Review how Photoshop handles measurement scales, including setting a scale, creating presets for scales used often, and removing presets.

### Set measurement scale

Open an image.

Choose Image > Analysis > Set Measurement Scale > Custom. Photoshop automatically selects the Ruler tool.

Enter a value in the Pixel Length text box.

Set Logical Length and Logical Units so they correspond to Pixel Length. Example: for a scale of 50 pixels per micron with Pixel Length set to 50, use 1 in Logical Length and enter microns for the unit.

In the Measurement Scale dialog box, select OK to apply the scale to the image.

Choose File > Save to store the measurement scale setting with the document.

### Create a measurement scale preset

Open an image.

Choose Image > Analysis > Set Measurement Scale > Custom.

Set up the measurement scale values.

Select Save Preset, then enter a name for the preset.

Select OK. The new preset appears in the Image > Analysis > Set Measurement Scale submenu.

### Delete a measurement scale preset

Choose Image > Analysis > Set Measurement Scale > Custom.

In the preset list, choose the preset to remove.

Select Delete Preset, then select OK.

## Manage scale markers

Learn how to create a scale marker, add or replace markers, and delete markers in Photoshop when measurement scales need a visible representation.

### Create a scale marker

Use Image > Analysis > Place Scale Marker.

In the Measurement Scale Marker dialog box, configure these controls:

- Length: type a value that defines marker length. The active measurement scale determines the corresponding pixel length.
- Font: choose the font used for the display text.
- Font Size: choose the size used for the display text.
- Display Text: turn this on when the logical length and units should appear.
- Text Position: place the caption above or below the marker.
- Color: choose black or white for the marker and caption.

Select OK. Photoshop adds the marker in the lower-left corner of the image as a layer group with a text layer, when display text is enabled, and a graphic layer.

Use the Move tool when the marker needs a new position, or use the Text tool to change the caption, font, size, or color.

### Add or replace scale markers

Use Image > Analysis > Place Scale Marker.

In the dialog box, choose whether existing markers should be Remove or Keep.

Provide the replacement settings for the marker.

Select OK to add the new marker.

Note

Photoshop puts additional markers at the same coordinates, so they can cover one another. To inspect a marker underneath, hide the scale marker layer group in the Layers panel.

### Delete a scale marker

In the Layers panel, choose the Measurement Scale Marker layer group.

Right-click the group, then choose Delete Group or Delete Layer.

When the confirmation dialog box appears, choose Group and Contents.

## Use the measurement log for performing measurements

Photoshop measurements can capture selections, distances, angles, and object counts, then save those results in the Measurement Log.

Measurements can come from Photoshop selection tools, the Ruler tool, or the Count tool. Choose the measurement tool that fits the kind of information you need to record in the Measurement Log.

- Create a selection area when recording height, width, perimeter, area, and pixel gray values. One selection or several selections can be measured at the same time.
- Use the Ruler tool for linear distance and angle measurements.
- Use the Count tool to count image items, then store the count.

A measurement writes one or more data points. Your data point choices decide which fields the log captures.

- Selection data points: area, perimeter, height, width.
- Ruler tool data points: length, angle.
- Data point presets: saved sets you can reuse to make later measurement workflows quicker.

### Measure and record data

Open an existing document.

Use Image > Analysis > Set Measurement Scale, then choose a measurement scale preset, or choose Custom to define one.

- If no measurement scale exists, Photoshop uses 1 pixel = 1 pixel as the default scale.

Use Image > Analysis > Select Data Points, then do one of these:

- Choose Custom when you want to select data points manually.
- Choose an existing data point preset.
- In the Select Data Points dialog box, measurement tool groups organize the data points. Common data points include file name, measurement scale, and date/time.

Note

For measurements made with a particular tool, the log shows only that tool's applicable data points plus any selected Common data points.

Choose an image feature and the matching tool:

- Create one or more selections on the image.
- Use Image > Analysis > Ruler tool, or choose the Ruler tool from the toolbar, then measure length or angle.
- Use Image > Analysis > Count tool, or choose the Count tool from the toolbar, then count items.

Use Window > Measurement Log to display the Measurement Log panel.

Use Image > Analysis > Record Measurements, or choose Record Measurements in the Measurement Log panel, to capture all measurement data.

Note

When the selected data points do not fit the current measurement tool, Photoshop asks whether to update them.

### Measurement Log behaviour

- For every selected data point, the Measurement Log creates a separate column.
- Each time you measure, the log receives another data row.
- When several areas are selected, Photoshop first adds one summary row with cumulative data, then adds a row for each individual selection. The Label column lists each selection area as its own feature and gives it a unique number.
- The Document column shows which source document produced each measurement.

For a complete measurement dataset, repeat the workflow across additional selections or documents.

Use Image > Analysis > Select Data Points > Custom.

Turn data points on or off as required. Photoshop changes the preset name to Custom.

## Manage measurement logs

The Photoshop Measurement Log panel lets you display, select, organize, and delete measurement data.

### Display the Measurement Log

Use Image > Analysis > Record Measurements.

Tip

Window > Measurement Log is another way to show the measurement log.

Measurement data is captured in the Measurement Log panel.

That same Measurement Log panel stores the recorded measurement data.

### Select rows in the log

Choose a row in the Measurement log table.

For multiple contiguous rows, choose the first row, then Shift-click the last row, or drag through the rows.

For non-contiguous rows, choose the first row, then Ctrl-click (Windows) or Command-click (macOS) each additional row.

To include every row, choose Select all measurements.

To clear the row selection, choose Deselect all measurements.

### Select columns in the log

In the Measurement log table, choose a column header to select that column.

For multiple contiguous columns, choose the first header, then Shift-click the last header, or drag across the headers.

For non-contiguous columns, choose the first header, then Ctrl+click (Windows) or Command+click (macOS) any additional headers.

### Reorder, resize, or sort columns in the log

To change column order, drag the selected columns to the desired position. Placement is shown by a double black line.

To change a column width, choose the column header and drag the separator.

To sort a column's data, use either method:

- Select the column header to switch the sort order.
- Right-click the header, then choose Sort Ascending or Sort Descending.

Note

Rows cannot be manually reordered.

### Export Measurement Log data

Select one or more data rows in the Measurement Log.

Use one of these commands:

- Choose Export from the Measurement Log options menu.
- Choose Export selected measurement.
- Right-click inside a row and choose Export from the menu.

Enter a filename and location.

Select Save.

Note

Photoshop exports the measurements as a comma-delimited, UTF-8 text file.

## About the measurement scale and scale markers

In Adobe Photoshop, measurement scales and scale markers help you measure objects, define scales, calculate dimensions accurately, and log those dimensions.

### Measurement in Photoshop

In Photoshop, the Measurement feature calculates and records dimensions for chosen image areas. Areas can be measured with the Ruler tool or with any selection tool, including irregular shapes made using the Lasso, Quick Selection, or Magic Wand tools.

This feature lets you:

- Calculate height, width, area, and perimeter.
- Follow measurements across one image or across several images.
- Store measurement data in the Measurement Log panel.
- Adjust Measurement Log columns, sort the data, and export results as a tab-delimited Unicode text file.

### Measurement scale

A measurement scale connects an image's pixel count to a real-world unit, such as inches, millimeters, or microns. After you define a scale, Photoshop reports calculated values using those units.

Key points about measurement scales:

- A scale supports accurate real-world calculations for dimensions and areas.
- Multiple scale presets can be saved, but a document can use only one active scale at a time.

### Scale markers

Use scale markers to show the active measurement scale on the image itself. When the file is printed or shared, the marker gives viewers an immediate scale reference.

- Add a scale marker either with a caption or without one.
- Captions show the measurement unit, for example millimeters or inches.
- A single marker can stand for the current measurement scale.
