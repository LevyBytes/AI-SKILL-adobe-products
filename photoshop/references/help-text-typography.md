## Add text

Add point text and paragraph text in Adobe Photoshop for layouts such as professional flyers, posters, or magazines.

### Add point text

Point text creates one editable text layer that runs in a straight line with no boundary or bounding box. Line breaks are allowed, making it useful for headlines, buttons, and simple annotations.

Choose Horizontal Type tool or Vertical Type tool from the toolbar.

Click anywhere in the document, then begin typing to create point text.

Photoshop adds a text layer in Layers panel; the Type icon identifies it.

Click the document with Horizontal or Vertical Type tool when adding point text.

To add point text, click the document while Horizontal or Vertical Type tool is active.

### Add paragraph text

Use paragraph text for longer material, including paragraphs and descriptions. Photoshop builds a bounding box around the text so you can edit, resize, shape, and format full paragraphs in one layer.

Choose Horizontal Type tool or Vertical Type tool from the toolbar.

Drag anywhere in the document to create paragraph text.

Photoshop adds a text layer in Layers panel; Type icon marks it.

Drag in the document with Horizontal or Vertical Type tool when adding paragraph text.

To add paragraph text, drag in the document while Horizontal or Vertical Type tool is selected.

Drag with Horizontal or Vertical Type tool to edit point text or paragraph text.

Point text and paragraph text can be edited by dragging with Horizontal or Vertical Type tool.

Enter the required text changes.

## Add bulleted and numbered lists

Use bulleted and numbered lists in Adobe Photoshop when brochure content needs schedules, performances, or activities.

With Horizontal Type tool or Vertical Type tool, create a type layer or select an existing one.

## Update text layers for vector-based output

Update Chinese, Japanese, and Korean (CJK) text layers in Adobe Photoshop so display and print output stay accurate.

When a document opens, Photoshop can find rendering differences in Chinese, Japanese, or Korean (CJK) text, particularly when another version or different fonts created the content. In that case, Photoshop may ask you to update text layers for accurate display and vector-based output.

Use File > Open for a Photoshop document that contains CJK text.

If Photoshop prompts you, choose Update to refresh text layers for vector-based output. Most differences are small and show only at high zoom.

Photoshop prompts users to update text layers for accurate vector-based output when opening a document with CJK text.

Photoshop prompts users to update text layers for accurate vector-based output when opening a document with CJK text.

Check the document for text differences, including shifted, reflowed, or missing text.

To correct the result, change the text frame, spacing, or alignment; to keep the original text appearance, press Esc and cancel.

Note

Without updating text layers, Photoshop relies on the saved bitmap version for display and printing. Updating layers keeps CJK text crisp and vector-based.

## Replace missing fonts

Replace missing fonts in Adobe Photoshop to avoid problems during printing or export.

When a file opens with unavailable fonts, Photoshop can automatically activate them from Adobe Fonts if internet access is available. While activation runs, the text layer in the Layers panel shows a blue sync icon. After the font becomes available, that icon switches back to the standard text layer icon. The activated font is then available in Adobe apps.

### Replace missing Adobe fonts while activation is in progress

If you edit a text layer whose missing font is still activating, Photoshop shows a prompt that lets you replace that font with a default font and keep editing. The dialog offers these choices:

Choose a text layer in the Layers panel where font activation is still running.

Choose one of these options:

- Replace: swaps the missing font for the default font. For Roman text, Myriad Pro Regular is the default font.
- Cancel: leaves text-editing mode and lets activation of your missing Adobe Fonts continue.

### Replace missing non-Adobe fonts

A missing non-Adobe font can be replaced with the default font or with another font already present in the document.

Choose Type > Manage Missing Fonts.

In the Manage Missing Fonts panel, use the drop-down options to:

- Replace with the default font. For Roman text, Myriad Pro Regular is the default font.
- Replace with a font already used in the document.
- Don't replace.

To switch every missing font in the document to the default, choose Replace All Missing Fonts With the Default Font.

Confirm with OK.

## Overview of OpenType fonts

OpenType fonts bring Adobe Photoshop projects stronger typography controls and easier cross-platform handling.

Across Windows and macOS, OpenType fonts use one font file. That makes it easier to move Photoshop files between systems without font substitution or text alignment problems.

Cross-platform support is only part of what these fonts provide. They also include advanced typographic features such as swashes, ligatures, fractions, small caps, and old-style numbers. While working with OpenType fonts in Photoshop, you can enable those stylistic options.

Some fonts include expanded character sets and wider language coverage. For instance, Adobe OpenType fonts that support Central European (CE) languages use Pro in their names, while standard versions use Std. OpenType fonts can be used together with PostScript Type 1 and TrueType fonts.

## Apply OpenType features

Apply OpenType features in Adobe Photoshop to reach alternate characters and glyphs for decorative-font customization without distorting the type.

OpenType features let you use built-in alternates rather than manually transforming characters. Fractions, ordinals, and case-sensitive forms are also available for cleaner typography.

Choose the Horizontal Type tool or the Vertical Type tool from the toolbar.

Open Window > Character, then select an OpenType font in the Character panel. OpenType fonts often include Pro in the font name.

Highlight the text to modify. If no text is selected, the setting affects new text you create.

In the Character panel, choose the more options icon, then choose OpenType.

From the OpenType submenu, choose an available feature. Options include Standard Ligatures, Contextual Alternates, Discretionary Ligatures, Swash, Old Style, and related entries.

Apply OpenType features to your text using the Character panel.

Apply OpenType features to your text using the Character panel.
