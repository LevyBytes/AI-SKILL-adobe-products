# Use Content Credentials, Preview Content Credentials, Export Your Work With Content Credentials

> Adobe Photoshop reference. Original prose; identifiers preserved verbatim.

## Overview

Covers: Use Content Credentials; Preview Content Credentials; Export your work with Content Credentials.

## Use Content Credentials

In Adobe Photoshop, Content Credentials can carry attribution details and the image's edit history with exported files.

When you export from Photoshop, Content Credentials attach authorship information and editing history to the image. That added context helps audiences understand the work's background and supports credit as the image moves online.

Select Window > Content Credentials (Beta).

Select Enable Content Credentials.

Tip

To make Content Credentials active by default on new documents, open Photoshop > Settings > History & Content Credentials. Turn on Enable for saved documents with Content Credentials.

Select Enable for new and saved documents with Content Credentials so edits are recorded from the beginning through the end.

## Preview Content Credentials

Before exporting an Adobe Photoshop image with Content Credentials, preview the attribution details, edit history, and linked accounts that will be included.

By recording attribution details, editing history, and connected accounts, Content Credentials show how an image was made. Use the preview before export to inspect the exact information that will travel with the exported file.

Select Window > Content Credentials (Beta) > Enable Content Credentials.

Inspect the listed information categories. Choose the checkboxes beside each category for the information you want included.

Select Connect accounts to add social media or crypto wallet links, or to manage existing ones.

Select Preview to view how the credentials will be shown to viewers.

## Export your work with Content Credentials

When exporting from Adobe Photoshop, you can attach Content Credentials to add attribution details and edit history to your images.

For exported images, Content Credentials add attribution information and edit history, giving viewers more transparency and helping the creator retain credit.

Select File > Export > Export As.

Select JPG or PNG format, because Content Credentials are currently supported only for those formats.

In the Content Credentials (Beta) area of the export dialog, choose one of these options:

- Publish to Content Credentials cloud: stores the credentials in Adobe's public cloud storage, which keeps the file smaller and makes the credentials easier to recover if they are removed from the content.
- Attach to file: places the Content Credentials inside the exported file itself. File size increases, privacy is greater, and online publishing can still strip the attached credentials.
- None: omits Content Credentials for this export.

Set the remaining export options and select Export.
