# Reference language selector

Use an explicitly requested reference language first; otherwise use the language of the request. English is the default and fallback.

Only English references are bundled. If another reference language is requested, state that the matching English reference is being used because no translation is bundled for that language and topic.

Choose the relevant topic in the [reference index](INDEX.md). Preserve API identifiers, commands, versions and example syntax. Reference language and response language are independent; follow the requested response language.
