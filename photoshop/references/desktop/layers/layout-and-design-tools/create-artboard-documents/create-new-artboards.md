# Create new artboards

Choose File > New. Photoshop opens the New Document dialog box.

Select the Artboards checkbox.

Choose an artboard-capable preset, such as Mobile.

Enter a document name, for example iPhone-subscribe.

Choose Create. Photoshop creates a document and shows the first artboard in the Layers panel.

Add a new artboard when one Photoshop document needs responsive layouts or several design variations.
