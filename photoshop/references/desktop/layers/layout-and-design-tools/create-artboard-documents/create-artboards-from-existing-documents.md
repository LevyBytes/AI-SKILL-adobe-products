# Create artboards from existing documents

Choose File > Open, then select the Photoshop file to turn into an artboard.

In the Layers panel, choose the layers that should become part of the new artboard.

Right-click the selected layers and choose Artboard from Layers. Photoshop converts those selected layers into artboards, and each artboard appears as its own group in the Layers panel.

Tip

To make an artboard from a layer group, right-click that group in the Layers panel and choose Artboard from Group.
