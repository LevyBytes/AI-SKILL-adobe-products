# Draw empty frames

Choose Frame tool.

From the Options bar, choose the frame shape you need: rectangular, elliptical, triangle, polygonal, or custom.

In the Options bar, configure any other frame attributes, including stroke color, width, and alignment.

Drag across the canvas until the frame reaches the size you want.

Tip

Bring in existing images, or use Generate Image to make images inside shapes, then refine their look from the Contextual Task Bar.
