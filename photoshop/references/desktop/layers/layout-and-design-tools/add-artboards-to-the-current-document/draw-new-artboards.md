# Draw new artboards

Select the Artboard tool, which is grouped with the Move tool. If it is hidden, select and hold the Move tool to reveal it.

Drag on the canvas to draw a new artboard at the size you want.

Tip

For preset dimensions, use the Size dropdown menu in the Options bar.

Rename the artboard by double-clicking its name in the Layers panel.

Choose the artboard in the Layers panel and design inside it as though it were an independent canvas. Smart objects, layers, and layer groups can be added to the artboard.
