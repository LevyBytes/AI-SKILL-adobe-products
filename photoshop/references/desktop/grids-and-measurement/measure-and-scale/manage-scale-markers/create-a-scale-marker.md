# Create a scale marker

Use Image > Analysis > Place Scale Marker.

In the Measurement Scale Marker dialog box, configure these controls:

- Length: type a value that defines marker length. The active measurement scale determines the corresponding pixel length.
- Font: choose the font used for the display text.
- Font Size: choose the size used for the display text.
- Display Text: turn this on when the logical length and units should appear.
- Text Position: place the caption above or below the marker.
- Color: choose black or white for the marker and caption.

Select OK. Photoshop adds the marker in the lower-left corner of the image as a layer group with a text layer, when display text is enabled, and a graphic layer.

Use the Move tool when the marker needs a new position, or use the Text tool to change the caption, font, size, or color.
