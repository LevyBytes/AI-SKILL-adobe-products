# Select rows in the log

Choose a row in the Measurement log table.

For multiple contiguous rows, choose the first row, then Shift-click the last row, or drag through the rows.

For non-contiguous rows, choose the first row, then Ctrl-click (Windows) or Command-click (macOS) each additional row.

To include every row, choose Select all measurements.

To clear the row selection, choose Deselect all measurements.
