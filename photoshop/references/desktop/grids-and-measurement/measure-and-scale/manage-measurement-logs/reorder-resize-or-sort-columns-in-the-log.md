# Reorder, resize, or sort columns in the log

To change column order, drag the selected columns to the desired position. Placement is shown by a double black line.

To change a column width, choose the column header and drag the separator.

To sort a column's data, use either method:

- Select the column header to switch the sort order.
- Right-click the header, then choose Sort Ascending or Sort Descending.

Note

Rows cannot be manually reordered.
