# Create guides

Use nonprinting guide lines and grids in Adobe Photoshop to align objects, build symmetrical layouts, and place elements accurately.

Photoshop guides support accurate placement while you design. They are nonprinting lines above the image, which makes aligning objects and balancing a layout easier.

A grid shows a fixed pattern across the full canvas, but guides can be set wherever the design requires them. Guides may be horizontal or vertical, and a project can contain as many as needed.
