# Set guide and grid preferences

Adjust guide colors, styles, and grid measurements in Adobe Photoshop to make precise positioning and alignment easier.

In Photoshop, guides are non-printing lines over the image, while the grid supplies a regular line or dot pattern for symmetrical layouts. Setting these preferences for the document lets different guide types stand apart visually and can streamline the work.

Choose Edit > Preferences > Guides, Grid, & Slices (Windows) or Photoshop > Settings > Guides, Grid, & Slices (macOS).

Choose a preset color, or select Custom and pick a color in the Color picker (guides color), then select OK.

Select a line style for guides or grid.

For Gridline every, enter the spacing value and choose the measurement unit used between major grid lines.

For Subdivisions, enter how many smaller divisions appear between the major grid lines.

Select OK.
