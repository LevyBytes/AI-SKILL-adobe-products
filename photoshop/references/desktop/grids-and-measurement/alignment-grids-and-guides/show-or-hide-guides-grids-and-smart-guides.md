# Show or hide guides, grids, and smart guides

Control which Adobe Photoshop alignment tools are visible so the workspace stays uncluttered while you place elements precisely.

Guides, Grids, and Smart Guides support precise positioning in Photoshop documents. Because these non-printing visual aids help with object alignment, symmetrical layouts, and consistent spacing, they can speed up layout work.

Guides are movable non-printing lines above the image and can be removed when they are no longer needed. Grids supply a regular line pattern for symmetrical layouts. Smart Guides appear automatically as you create shapes, selections, or move objects, giving alignment feedback in the moment. These tools show only inside the workspace and do not appear in final output.
