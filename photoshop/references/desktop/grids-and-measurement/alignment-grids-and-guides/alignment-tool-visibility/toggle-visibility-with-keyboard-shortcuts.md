# Toggle visibility with keyboard shortcuts

Press Ctrl + ' (Windows) or Command + ' (macOS) when you need the grid shown or hidden.

Press Ctrl + ; (Windows) or Command + ; (macOS) to switch guide visibility.

Press Ctrl + Shift + ; (Windows) or Command + Shift + ; (macOS) to switch Smart Guides visibility.

Tip

For the highest positioning accuracy, use 100% magnification or check exact values in the Info panel.
