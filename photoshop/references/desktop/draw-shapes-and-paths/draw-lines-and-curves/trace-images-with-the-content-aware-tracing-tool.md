# Trace images with the Content-Aware Tracing tool

Use edge detection in Adobe Photoshop to build vector paths or selections from image objects more quickly.

Adobe Photoshop includes Content-Aware Tracing tool as a Technology Preview. Turn it on with Preferences > Technology Previews, then restart Photoshop.

From the toolbar's Pen tool group, choose Content-Aware Tracing tool.

Place the pointer near the object's edge so Photoshop can find and highlight that boundary automatically.

In Options bar, move Detail slider right for more edge detection, or move it left when simpler edge finding is preferred.

Choose one tracing option in the options bar:

- Create paths from detected edges: makes a new path.
- Extend currently selected path with detected edges: appends the detected edge to an existing path.
- Trim traced paths: discards unneeded anchor points from the generated path.

Click once to create a vector path that tracks the detected edge.
