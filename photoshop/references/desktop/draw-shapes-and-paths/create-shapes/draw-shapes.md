# Draw shapes

Build and adjust shapes in Adobe Photoshop with the shapes tool group.

On the canvas, draw a shape by selecting any tool from the shapes tool group in the Tools panel and dragging.

Press Shift while you draw when the shape should keep proportional dimensions.

Use the Contextual Task Bar (Window > Contextual Task Bar) to change these shape properties:

- Fill: chooses the color used inside the shape.
- Stroke: chooses the stroke color, width, and type.
- Duplicate layer: makes an exact copy of the selected layer so you can reuse or edit that copy while leaving the original unchanged.

Note

Shape properties are also available through Shape Properties in the Properties panel or the Options bar.

Create and customize a shape using the Rectangle tool from the shapes tool group in the Tools panel.
