# Use the Object Selection tool

Select specific objects or areas in an image with the Object Selection tool.

With the Object Selection tool, draw a rectangle or lasso around an area, or allow Photoshop to detect and select the object or region automatically.

Choose the Object Selection tool from the toolbar.

Hover over the image so Photoshop highlights the object or region you want to select.

Choose Set additional options in the Option bar and disable Object finder when you want to define a region manually with either Rectangle or Lasso tool.

Use Set additional options in the Option bar to turn off Object finder for manually defining an area with either Rectangle or Lasso tool.

Choose a selection mode from the Options bar for further changes:

- New selection: create a selection when no selection is active.
- Add to selection: include more areas by hovering over them or drawing around them.
- Subtract from selection: remove areas you do not want by hovering over them or drawing around them.
- Intersect with selection: keep only areas where multiple selections overlap.

Refine the selection with more Options bar controls:

- Sample All Layers: include all visible layers in the selection.
- Hard Edge: use sharp edges on the selection boundary.
