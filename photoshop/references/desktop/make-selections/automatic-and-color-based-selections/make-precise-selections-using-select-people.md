# Make precise selections using Select People

In Photoshop, use the Select People tool when you need accurate selections of people or their features.

Choose the Object Selection tool from the toolbar.

From the Options bar, choose Select people.

Choose a thumbnail for one person in the image.

Choose Entire person for the full body, or choose tags such as Facial skin, Beard, Hair, Eyebrows, and more for specific parts.

Note

When you hover on the canvas, you can also choose details directly there.
