# Improve results with on-device processing

Open an image with File > Open.

From the main menu, open Settings > Image Processing (macOS) or Edit > Preferences > Image Processing (Windows).

In the Preferences dialog box, choose Device from the Select Subject and Remove Background dropdown.

Note

Photoshop refines selections with Device processing by default.

For better results, set the processing mode to Device in Preferences > Image Processing.

In Preferences > Image Processing, use Device as the processing mode to improve the output.

Use the Select and Mask workspace to refine the selection and apply edits.
