# Improve hair selections with the Refine Hair tool

For cleaner and more accurate hair selections, use the hair refinement controls in the Select and Mask workspace.

Choose the Object Selection tool, then choose Select Subject.

Choose Select and Mask > Refine Hair.

In the Properties panel, adjust these settings:

- Transparency: changes how visibly the selection appears over the image.
- Preset: applies a commonly used set of refinement settings.
- Refine Mode: lets you choose Color Aware or Object Aware for improved edge detection.
- Edge Detection: provides controls that help Photoshop detect fine hair edges more effectively.
- Global Refinement: gives precise control over Smooth, Feather, Contrast, and Shift Edge values.
- Output Settings: controls where and how the final selection is applied or exported.

Choose OK to apply the refined selection.
