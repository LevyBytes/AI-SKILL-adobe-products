# Select areas by color with the Magic Wand tool

In Photoshop, the Magic Wand tool selects similarly colored areas without requiring you to trace edges.

Activate the Magic Wand tool in the toolbar.

For selection behavior, use one of these Options bar modes:

- Add to selection
- Subtract from selection
- Intersect with selection

In the options bar, adjust these settings:

- Sample Size: controls how much image data is sampled when determining selection sensitivity.
- Tolerance: sets the selected color-value range from 0 (narrow) to 255 (broad).
- Anti-alias: turns on smoother edge creation.
- Contiguous: limits the selection to adjacent areas with similar color.
- Sample All Layers : bases the selection on every visible layer.

Choose the color area in the image to create a selection using the defined settings.

Choose Select and Mask to refine the selection further or preview it as a mask.
