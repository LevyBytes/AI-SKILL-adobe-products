# Create quick selections with the Selection Brush Tool

In Adobe Photoshop, use the Selection Brush tool when you want to paint selections precisely.

Choose the Selection Brush tool from the toolbar.

Brush over the canvas area to create a selection overlay.

The selection overlay appears as a red color overlay.

In the Options bar, choose the settings icon, then pick a color from the Color dropdown to change the overlay color.

In the Options bar, set Opacity, Size, and Hardness for the brush.

Switch between Add brush and Subtract brush modes to refine the selection.
