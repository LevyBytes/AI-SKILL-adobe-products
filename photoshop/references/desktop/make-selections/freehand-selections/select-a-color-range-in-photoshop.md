# Select a Color Range in Photoshop

Use the Color Range command in Photoshop to select and refine a particular color or tonal range.

Color Range in Photoshop builds selections from specific colors or tones in an image. Compared with manual selection tools, it gives more precision and flexibility because you can sample colors, detect skin tones, or identify out-of-gamut colors that cannot print in CMYK. Options such as Localized Color Clusters, Fuzziness, and Invert help target only the areas that need adjustment while the rest of the image remains unchanged.

Choose Select > Color Range.

In the Color Range dialog, choose one of these Select options:

- Skin Tones: chooses colors similar to common skin tones. Enable Detect Faces for greater accuracy.
- Sampled Colors: uses the Eyedropper tool to choose sample colors from the image. Choose Localized Color Clusters for a more precise selection.
- Color or tonal range: chooses a predefined color or tone.
- Out of Gamut: chooses colors outside the printable CMYK range and adjusts them to the nearest reproducible color.

Note

If you want to replace an existing selection, deselect any active selection first.
