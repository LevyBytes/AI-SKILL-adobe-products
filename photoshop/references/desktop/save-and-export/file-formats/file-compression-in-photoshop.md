# File compression in Photoshop

Compare Adobe Photoshop compression types, then choose the format that fits image quality, file size, and final use.

| Compression type | Description | Use case |
| --- | --- | --- |
| RLE (Run Length Encoding) | Applies lossless compression that efficiently represents repeated data sequences. | Works for simple graphics in standard Windows file formats. |
| LZW (Lempel-Ziv-Welch) | Applies lossless compression so all image data remains while the file becomes smaller. | Works for images with large solid-color areas in TIFF, PDF, GIF, and PostScript. |
| JPEG (Joint Photographic Experts Group) | Uses lossy compression, reducing size by discarding image detail. Quality can be adjusted from the menu, with the slider, or by entering a value from 0 to 12. | Works for continuous-tone images, including photographs in JPEG, TIFF, PDF, and PostScript. Printing requires Level 2 or later PostScript printers, and plate separation may not be supported. |
| CCITT (Consultative Committee for International Telegraphy and Telephony). | Applies lossless compression intended for black-and-white images. | Works for scanned documents or line art in PDF and PostScript. |
| ZIP | Applies LZW-like lossless compression to lower file size without reducing quality. | Works for images with flat-color regions in PDF and TIFF. |
