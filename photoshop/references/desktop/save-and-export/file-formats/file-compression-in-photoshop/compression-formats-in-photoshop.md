# Compression formats in Photoshop

| Format | Reason to use |
| --- | --- |
| Image content | For photos, choose JPEG. For graphics built from solid colors, use LZW or ZIP. |
| Quality requirements | When exact image data must be preserved, choose RLE, LZW, ZIP, or CCITT. |
| File size constraints | For the smallest files, choose JPEG and accept some quality loss. |
| Output medium | Base the format choice on display or print needs. |
