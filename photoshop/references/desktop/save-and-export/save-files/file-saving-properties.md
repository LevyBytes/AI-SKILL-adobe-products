# File saving properties

Save As and Save a Copy expose file-saving controls, with the available choices changing according to the format you pick.

| Option | Usage |
| --- | --- |
| As a Copy | Creates a duplicate in another format or destination while leaving the original untouched. |
| Notes | Includes notes with the saved image. |
| Alpha Channels | Keeps alpha channel data in the file. Turn the option off when alpha channels should be removed. |
| Spot Colors | Keeps spot channel data in the file. Turn the option off when spot colors should be removed. |
| Layers | Keeps every image layer. If the selected format does not allow that, flatten or merge the visible layers instead. |
| Use Proof Setup, ICC Profile (Windows), or Embed Color Profile (macOS) | Generates a document with color management. |
| Save to cloud documents | Stores the file in Creative Cloud so it is available across devices and can be shared. |
