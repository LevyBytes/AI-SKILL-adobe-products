# Use on-canvas glyph alternatives

Choose alternate character glyphs on the canvas, without opening the Glyphs panel, to speed up typography work.

Typography work in Adobe Photoshop often calls for ligatures, swashes, stylistic variants, or other alternate forms. With on-canvas glyph alternatives, those choices appear next to the selected character for quicker access. The feature is available for OpenType fonts that include alternative glyphs.

Open the Type preferences: Edit > Preferences > Type (Windows) or Photoshop > Preferences > Type (macOS).

Enable the option labeled Enable Type layer glyph alternates.

With the Horizontal Type tool or Vertical Type tool, select a character that has alternative glyphs. The alternatives grid appears near that selected character.

Choose an alternative glyph in the grid to replace the selected character. To open the complete Glyphs panel, select the right arrow icon.

From the on-canvas alternative grid, select any alternate glyph to replace the selected character.
