# Add glyphs

Add special characters, symbols, and alternate glyph forms to text in Adobe Photoshop.

Use the Glyphs panel when punctuation, currency signs, mathematical symbols, language-specific characters, or alternate character forms are not convenient to enter from the keyboard.

Any active text layer can use the Glyphs panel. Latin, Greek, and Cyrillic scripts are supported, while Hebrew, Arabic, and complex scripts such as Indic scripts have limited support.

Create a new text layer, or choose an existing text layer with the Horizontal Type tool or the Vertical Type tool.

Place the text cursor at the insertion point for the glyph.

Open Window > Glyphs to display the Glyphs panel, then review the available glyphs.

Tip

To narrow the visible choices, filter by Set font family, Set font style, or Set font category.

To insert a glyph, double-click it. Photoshop adds the character at the cursor in the current text layer. Use a double-click in the Glyphs panel whenever that glyph should be added to the document.

Use a double-click on a Glyphs panel item to add that character to your document.
