# Copy and paste text from another Photoshop file

Open the source file.

Activate Horizontal Type tool or Vertical Type tool, then choose the text layer in Layers panel.

Choose Edit > Copy (Command + C (macOS) or Ctrl + C (Windows)).

Switch to the destination file where the copied text layer should be placed.

Choose Edit > Paste (Command + V (macOS) or Ctrl + V (Windows)).
