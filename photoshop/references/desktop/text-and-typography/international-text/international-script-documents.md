# Create documents using international languages, scripts, and text

Create Adobe Photoshop documents that use international languages and scripts through the Unified Text Engine.

Working with languages and scripts from many regions is handled by the Unified Text Engine. It removes the need to change text engines as your design moves between languages.

Legacy text engines are replaced by the Unified Text Engine, which supplies advanced typographic features for international languages and scripts. Arabic, Hebrew, Indic scripts, Japanese, Chinese, Korean, and other non-Latin scripts are included. This unified workflow lets multilingual designs be created without changing text engines for each language.
