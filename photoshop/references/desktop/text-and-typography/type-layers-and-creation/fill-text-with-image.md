# Fill text with image

Fill text shapes with images in Adobe Photoshop by using Convert to Frame for stronger visual effects.

From Window > Tools, use the Horizontal Type tool or Vertical Type tool to create text in the document.

Add the image that will fill the text.

In the Layers panel, place the image layer beneath the type layer. Make sure the image is large enough to cover the text.

In the Layers panel, right-click the text layer and choose Convert to Frame. After conversion, Photoshop places the image within the converted type.

Select Covert to Frame to fill text with image.

Use the Move tool to drag and reposition the image within the text frame.
