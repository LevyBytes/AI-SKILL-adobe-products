# Dynamic Text types

- Block: scales and reflows text so it fits inside a rectangular bounding box.
- Circle: places text on a circular path and scales it between defined start and end points.
- Arch: places text on an upward-curving path and scales it between defined points.
- Bow: places text on a downward-curving path and scales it between defined points.

Block resizes and reflows text within the bounding box. Circle, Arch, and Bow put text on a curved path and scale it across the shape's defined start and end points.

### Properties

- Set spacing between words: changes the gaps between words.

  - Set spacing between lines: changes the gaps between lines.

  - Adjust text position: sets where text sits relative to the path (above, center, below).
  - Adjust text direction: switches the text reading direction.
