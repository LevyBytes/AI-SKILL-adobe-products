# Search for and apply font styles

In Adobe Photoshop, searching for specific font styles helps keep work moving when a project uses large font libraries.

From the toolbar (Window > Tools), choose the Horizontal Type tool or Vertical Type tool.

In the Layers panel, choose the text layer that should receive the new font.

In the Options bar (Window > Options), choose Search and select fonts, then type the font name you need.

Limit the font list with Your fonts or More fonts, or use Show Adobe Fonts icon, Show Variable Fonts icon, Show favorite fonts icon, or Show similar fonts icon.

Tip

When a font includes variants such as Regular, Italic, Bold, and Bold Italic, Photoshop groups them under one menu item. Expand the group, then choose the variant you want.

Choose a font style from the list.
