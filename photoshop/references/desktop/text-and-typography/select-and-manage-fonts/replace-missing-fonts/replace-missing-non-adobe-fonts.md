# Replace missing non-Adobe fonts

A missing non-Adobe font can be replaced with the default font or with another font already present in the document.

Choose Type > Manage Missing Fonts.

In the Manage Missing Fonts panel, use the drop-down options to:

- Replace with the default font. For Roman text, Myriad Pro Regular is the default font.
- Replace with a font already used in the document.
- Don't replace.

To switch every missing font in the document to the default, choose Replace All Missing Fonts With the Default Font.

Confirm with OK.
