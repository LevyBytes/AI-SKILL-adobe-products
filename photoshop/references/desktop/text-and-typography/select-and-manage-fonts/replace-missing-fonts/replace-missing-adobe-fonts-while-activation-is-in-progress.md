# Replace missing Adobe fonts while activation is in progress

If you edit a text layer whose missing font is still activating, Photoshop shows a prompt that lets you replace that font with a default font and keep editing. The dialog offers these choices:

Choose a text layer in the Layers panel where font activation is still running.

Choose one of these options:

- Replace: swaps the missing font for the default font. For Roman text, Myriad Pro Regular is the default font.
- Cancel: leaves text-editing mode and lets activation of your missing Adobe Fonts continue.
