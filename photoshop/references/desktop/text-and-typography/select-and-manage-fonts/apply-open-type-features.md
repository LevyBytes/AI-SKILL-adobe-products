# Apply OpenType features

Apply OpenType features in Adobe Photoshop to reach alternate characters and glyphs for decorative-font customization without distorting the type.

OpenType features let you use built-in alternates rather than manually transforming characters. Fractions, ordinals, and case-sensitive forms are also available for cleaner typography.

Choose the Horizontal Type tool or the Vertical Type tool from the toolbar.

Open Window > Character, then select an OpenType font in the Character panel. OpenType fonts often include Pro in the font name.

Highlight the text to modify. If no text is selected, the setting affects new text you create.

In the Character panel, choose the more options icon, then choose OpenType.

From the OpenType submenu, choose an available feature. Options include Standard Ligatures, Contextual Alternates, Discretionary Ligatures, Swash, Old Style, and related entries.

Apply OpenType features to your text using the Character panel.

Photoshop applies the selected OpenType feature to the text right away.
