# Match fonts

Match fonts in Adobe Photoshop to turn text seen in an image into licensed, editable template typography.

With the Rectangular Marquee tool, select the text area in the photo.

Choose Type > Match Font. Adobe Photoshop then lists fonts that resemble the text inside the selection.

In the Match Font dialog, choose a Type Option.

Tip

Clear Show fonts available to add from Adobe Fonts when you want to hide Adobe Fonts choices and see only local fonts.

Pick the font that most closely matches the selected image text.

Select a font from the list of similar fonts in the Match Fonts dialog box.

Confirm with OK.
