# Overview of OpenType fonts

OpenType fonts bring Adobe Photoshop projects stronger typography controls and easier cross-platform handling.

Across Windows and macOS, OpenType fonts use one font file. That makes it easier to move Photoshop files between systems without font substitution or text alignment problems.

Cross-platform support is only part of what these fonts provide. They also include advanced typographic features such as swashes, ligatures, fractions, small caps, and old-style numbers. While working with OpenType fonts in Photoshop, you can enable those stylistic options.

Some fonts include expanded character sets and wider language coverage. For instance, Adobe OpenType fonts that support Central European (CE) languages use Pro in their names, while standard versions use Std. OpenType fonts can be used together with PostScript Type 1 and TrueType fonts.
