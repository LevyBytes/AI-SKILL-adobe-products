# Font types and their icons

Font previews are available in the Character panel, Contextual Task Bar, and Properties panel. Identify font categories with these icons:

- Adobe fonts icon (previously Typekit icon)
- OpenType icon
- Type 1 icon
- TrueType icon
- Multiple Master icon
- OpenType SVG icon
- OpenType variable fonts icon

Tip

Use Type > Font Preview Size to disable font previews or set the point size used for font names.
