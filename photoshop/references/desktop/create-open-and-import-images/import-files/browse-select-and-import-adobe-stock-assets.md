# Browse, select, and import Adobe Stock assets

Add free Adobe Stock images in Adobe Photoshop to move Photoshop workflows along faster.

From inside Photoshop, browse Adobe Stock images, import them, and select the assets you need.

Photoshop lets you browse, import, and choose Adobe Stock images without leaving the app.

Create a blank document with File > New, or open an image with File > Open.

From the Contextual Task Bar, select Add free stock Images.

Tip

Turn on Always Create Smart Objects When Placing (Preferences > General) so Stock images come in as Smart Objects. Keeping them as Smart Objects preserves editability and avoids quality loss during resizing.

The Contextual Task Bar provides a quick entry point for adding free stock images.

You can use that same Contextual Task Bar entry point for fast free-stock-image placement.

Open Browse Free Adobe Stock Images, review the categories, and choose an image. For details about free collection assets, browse these Adobe Stock frequently asked questions.

Note

Depending on the subscription, the number of free images available for download within 24 hours may vary.
