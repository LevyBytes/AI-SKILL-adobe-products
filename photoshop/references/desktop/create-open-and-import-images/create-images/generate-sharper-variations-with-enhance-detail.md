# Generate sharper variations with Enhance Detail

Enhance Detail improves sharpness in variations made with Generative Fill.

Use it when a variation needs stronger detail, clearer edges, and a better blend with the current image.

Create an object with Generative Fill (Edit > Generative Fill).

Select Window > Properties, then choose the variation you prefer.

Select the Enhance Detail icon. Photoshop creates a duplicate variation, leaving both the original variation and the Enhance Detail variation available.

Note

Enhancement is available only for variations larger than 1024 pixels.

Apply Enhance Detail when you want to sharpen variations from Generative Fill.

Generative Fill variations can be sharpened with Enhance Detail.

Select the variation that best matches the result you want.
