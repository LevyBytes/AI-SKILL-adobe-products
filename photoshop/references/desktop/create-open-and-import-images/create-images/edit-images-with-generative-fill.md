# Edit images with Generative Fill

In Adobe Photoshop, Generative Fill lets text prompts change an image without destructively altering it.

Choose the area that Generative Fill should transform.

Define the edit area with a selection tool, such as the Selection Brush.

Select Generative Fill.

Use the model picker in the Contextual Task Bar to choose either an Adobe Firefly model or a partner AI model.

- Adobe models: Firefly Image 5, Firefly Fill & Expand, Firefly Image 1
- Partner models: Gemini 3.1 (with Nano Banana 2), Gemini 3 (with Nano Banana Pro), Gemini 2.5 (Nano Banana), FLUX.2 pro, and FLUX.1 Kontext [pro]

Enter a text prompt for the content you want generated. You can also leave the prompt empty so Photoshop fills the selection from nearby pixels.

Select Generate, then pick a variation from the Properties panel.
