# Generate with Adobe Firefly models

Start with an active selection, then choose Generative Fill.

From the Contextual Task Bar, select Reference image.

Use Choose image to upload the image Photoshop should treat as the reference.

Choose Adobe models > Firefly Fill & Expand.

Set how the reference is used:

- Object: takes one subject as the reference.
- Whole image: takes the complete scene as the reference.

- Swap the selected area: changes out the current object inside the selected area.
- Place into the selected area: adds an object and preserves the background behind it.

Choose Generate.
