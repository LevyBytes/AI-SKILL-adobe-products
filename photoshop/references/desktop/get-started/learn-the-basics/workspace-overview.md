# Workspace overview

See how the Adobe Photoshop workspace uses layout, tools, and panels to support organized, efficient work.

Workspaces in Adobe Creative Cloud applications combine panels, tools, and windows that can be arranged around the way you work. They supply the core editing environment for creating and modifying documents.

The Adobe Photoshop workspace includes these parts:

Use the Application bar, Document window, Options bar, and Tools panel when customizing the Photoshop workspace.

To customize the Photoshop workspace, work with the Application bar, Document window, Options bar, and Tools panel.

A. Application bar B. Panels C. Tools panel D. Document window E: Options bar F: Notifications

- Application bar: holds the workspace switcher, menus, and other controls.
- Panels: offer controls for reviewing and changing your work, and they can be grouped or stacked.
- Tools panel: contains related tools for creating and editing images, artwork, and page elements.
- Document window: displays the current file and can be grouped or tabbed.
- Options bar: shows controls for whichever tool is currently selected.
- Notifications icon: displays in-app notices about tutorials, feature changes, or account-related actions.
