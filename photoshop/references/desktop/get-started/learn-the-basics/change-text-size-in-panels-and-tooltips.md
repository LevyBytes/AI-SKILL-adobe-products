# Change text size in panels and tooltips

Change text size in Adobe Photoshop when panels and tooltips need better readability.

Increasing or reducing the UI font size can make high-resolution displays easier on the eyes. The setting can also make navigation through the Photoshop interface more comfortable and efficient.

Select Edit > Preferences > Interface.

In the Preferences dialog box, choose a UI font size to change text in Photoshop panels and tooltips.

Pick the UI font size that should appear in Photoshop panels and tooltips.

In the Presentation section, choose a size from the UI Font Size dropdown menu:

- Tiny
- Small
- Medium
- Large

Select OK.

Turn on Scale UI To Font to resize the whole Photoshop interface according to the selected UI font size.

Note

System display settings can affect UI font size changes. Restart Photoshop so the changes take effect.
