# Delete workspaces

Delete Adobe Photoshop workspaces when you want a more focused and organized workspace list.

Remove outdated or unused workspaces to keep the list manageable. Deleted custom workspaces are not recoverable, so you would need to create and save them again.

From the Application bar, open Choose a workspace.

Select Delete Workspace.

In the dialog, choose a workspace from the dropdown menu, and then select Delete. Photoshop removes it from the workspace list.

Keep the workspace list tidy by deleting custom workspaces that are no longer needed.

Delete custom workspaces you no longer use so the workspace list stays clean.

Preset layouts cover common workflows such as photo editing, painting, or graphic design. Photoshop displays a warning before deleting a preset workspace.

Note

For preset restoration, use Edit > Preferences > Workspace > Restore Default Workspaces.
