# Boost workflows with the Contextual Task Bar

Use the Contextual Task Bar in Adobe Photoshop on desktop to reach tools and actions that fit the current selection.

The Contextual Task Bar sits on the canvas and gives quick access to common actions for the current work, such as selecting an object, editing a layer, or changing part of an image.

It updates dynamically so the most relevant actions appear directly on the canvas, which helps finish common workflows faster without moving through several panels.

The Contextual Task Bar can help:

- Reduce switching between panels and menus
- Present relevant actions at the moment they are useful
- Accelerate common workflows
- Keep attention on the canvas
