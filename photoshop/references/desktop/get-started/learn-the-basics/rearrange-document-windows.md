# Rearrange document windows

Use these steps to arrange document windows in Adobe Photoshop so the workspace supports faster editing.

With several files open in Photoshop, window management can make the workflow easier to follow. Documents can stay tabbed, float outside the tab group, or be arranged into layouts that match the task.

Open multiple documents in Photoshop before changing their arrangement.

Reorder tabs by dragging a window tab to another position in the group.

Detach a document window by pulling the window's tab out of the group.

Place a document back with the others by dragging the window into the group.

Create stacked or tiled document groups by dragging a window onto another document.

Place documents side by side when you need to view and edit them at the same time in Photoshop.

Use a tiled layout in Photoshop for simultaneous viewing and editing across documents.

While dragging a selection, move over another document's tab to switch to that document in the tabbed group.

Tip

To float one document window, choose Window > Arrange > Float in Window. To float every document window together, choose Window > Arrange > Float All In Windows.
