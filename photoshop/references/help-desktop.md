## Select an AI model for generative control

In Adobe Photoshop, choose an AI model when you want finer control over generative results.

Choose File > Open, then select and open an image.

Use Selection Brush or another selection tool to select the area where content should be added, removed, or changed.

Choose Generative Fill.

In the Contextual Task Bar, open the model selector to see the available AI models.

Review the models grouped under Adobe models and Partner models:

- Adobe models: Firefly Image 5, Firefly Fill & Expand, Firefly Image 1
- Partner models: Gemini 3.1 (with Nano Banana 2), Gemini 3 (with Nano Banana Pro), Gemini 2.5 (with Nano Banana), FLUX.2 pro, FLUX.1 Kontext [pro]

## Get new variations of generated content

Create another version of generated content with Generate Similar in Adobe Photoshop.

In Adobe Photoshop, Generate Similar produces fresh alternatives from an image that already exists. The feature is available in the Generative Fill, Generative Expand, Generate Background, and Generate Image workflows.

First, make content with one of the generative workflows, such as Generative Fill.

In the Variations tab of the Properties panel, open the ellipsis menu for the variation you want and select Generate Similar.

Photoshop refreshes the canvas with a related variation.

## Use Firefly Boards with Photoshop

Send Photoshop cloud documents or local PSD files to Firefly Boards when you want to develop ideas, build alternate versions, and keep editing the work.

### Send a local PSD file to Firefly Boards

Select File > Open, then locate and open a local PSD file.

Select Share > Send to Firefly Boards. Photoshop uploads the file to Adobe Cloud as a cloud document (PSDC).

Pick an existing Boards file, or make a new Boards file.

Select Open in Boards to move the uploaded PSDC file into Firefly Boards.

Note

To share local PSD and PSDC files with Firefly Boards, select File > Export, then Send to Firefly Boards.

### Send a cloud document to Firefly Boards

Select File > Open, then browse to and open a PSDC file.

Note

For cloud documents, Firefly Boards is available in three Photoshop locations: home screen, Share panel, and Export menu.

Use Share > Send to Firefly Boards.

Pick an existing Boards file, or create a new Boards file.

Select Open in Boards to send PSDC files to Firefly Boards.

### Open a Board variation in Photoshop

In Firefly Boards, choose an image and right-click it.

Select Open in Photoshop. Photoshop opens the image as a new document.

## Edit images with Generative Fill

In Adobe Photoshop, Generative Fill lets text prompts change an image without destructively altering it.

Choose the area that Generative Fill should transform.

Define the edit area with a selection tool, such as the Selection Brush.

Select Generative Fill.

Use the model picker in the Contextual Task Bar to choose either an Adobe Firefly model or a partner AI model.

- Adobe models: Firefly Image 5, Firefly Fill & Expand, Firefly Image 1
- Partner models: Gemini 3.1 (with Nano Banana 2), Gemini 3 (with Nano Banana Pro), Gemini 2.5 (Nano Banana), FLUX.2 pro, and FLUX.1 Kontext [pro]

Enter a text prompt for the content you want generated. You can also leave the prompt empty so Photoshop fills the selection from nearby pixels.

Select Generate, then pick a variation from the Properties panel.

## Generate sharper variations with Enhance Detail

Enhance Detail improves sharpness in variations made with Generative Fill.

Use it when a variation needs stronger detail, clearer edges, and a better blend with the current image.

Create an object with Generative Fill (Edit > Generative Fill).

Select Window > Properties, then choose the variation you prefer.

Select the Enhance Detail icon. Photoshop creates a duplicate variation, leaving both the original variation and the Enhance Detail variation available.

Note

Enhancement is available only for variations larger than 1024 pixels.

Apply Enhance Detail when you want to sharpen variations from Generative Fill.

Generative Fill variations can be sharpened with Enhance Detail.

Select the variation that best matches the result you want.

## Use reference images for consistent results

Reference Image in Adobe Photoshop on desktop guides generation so the composition stays consistent.

### Generate with Adobe Firefly models

Start with an active selection, then choose Generative Fill.

From the Contextual Task Bar, select Reference image.

Use Choose image to upload the image Photoshop should treat as the reference.

Choose Adobe models > Firefly Fill & Expand.

Set how the reference is used:

- Object: takes one subject as the reference.
- Whole image: takes the complete scene as the reference.

- Swap the selected area: changes out the current object inside the selected area.
- Place into the selected area: adds an object and preserves the background behind it.

Choose Generate.

### Generate with Partner AI models

Start with an active selection, then choose Generative Fill.

Select Partner models, then type a detailed prompt.

After entering the prompt, select the Reference image icon to open the panel. For Flux, upload up to 3 images; for Gemini, upload up to 8.

Choose Generate.

## Generate images guided by a reference image

In Adobe Photoshop, Reference image lets a chosen image steer the look or layout of generated results.

Start with a new document, then use Generate Image on the Contextual Task Bar.

In the Reference image section of the Generate Image dialog, choose one of the following options:

- Style: follows the visual treatment.
- Composition: follows the arrangement.

Select Choose Image to upload an image from your device. You can also pick a sample image from the Gallery.

Use the Describe the image you want to generate box to type a text prompt.

Select Generate.
