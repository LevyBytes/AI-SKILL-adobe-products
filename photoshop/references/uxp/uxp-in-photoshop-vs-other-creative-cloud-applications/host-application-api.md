# Host Application API

Photoshop and XD are obviously different applications, so their DOMs and APIs differ substantially. Photoshop also covers many distinct use cases, each with its own objects and properties, making it much more complex than XD.

Currently, the [Photoshop API](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/index.md) is less mature than the API available in XD, though that changes quickly with each Photoshop release. Until UXP directly exposes every needed Photoshop object, [batchPlay](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/media/batchplay.md) lets you reach objects, properties, and actions that do not yet have direct UXP coverage.
