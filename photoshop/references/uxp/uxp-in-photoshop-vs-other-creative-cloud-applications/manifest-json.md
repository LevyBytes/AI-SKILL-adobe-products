# Manifest JSON

Before XD version 34, XD plugins used manifest.json 3.x. Photoshop UXP uses manifest versions 4.x and later, so those older XD manifests differ in several ways. XD versions 35 and later use the same manifest versions.

When porting an XD plugin to Photoshop, review the current [manifest.json](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/guides/uxp-guide/uxp-misc/manifest-v4/index.md) structure.
