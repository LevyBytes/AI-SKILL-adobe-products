# applyOffset

23.5

_Promise_`<void>`

Executes Offset.

Unsupported color modes: Indexed Color, Bitmap

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| `horizontal` | _number_ | Horizontal offset [-2 \* doc.width, 2 \* doc.width] |
| `vertical` | _number_ | Vertical offset [-2 \* doc.height, 2 \* doc.height] |
| `undefinedAreas` | [_OffsetUndefinedAreas_](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/modules/constants.md#offsetundefinedareas) | Method that fills blank offset areas (default: `OffsetUndefinedAreas.WRAPAROUND`). |
