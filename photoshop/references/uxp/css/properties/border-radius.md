# border-radius

**Since** UXP v2.0

Provides the shorthand form for border radius settings.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/border-radius](https://developer.mozilla.org/en/docs/Web/CSS/border-radius)

**Example**

```css
.someElement {
  border-radius: 4px;
}
.card {
  border-radius: 4px 0;
}
```
