# ColorPicker

24.0

Color picker dialog provider.
Use with [PreferencesGeneral.colorPicker](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/preferences/preferencesgeneral.md#colorpicker)

| Name | Description |
| --- | --- |
| ADOBE | Adobe Photoshop Color Picker provider. |
| OSNATIVE | Apple or Windows built-in color picker. |
| PLUGIN | Plugin-supplied color picker. For PLUGIN, the argument object passed to [PreferencesGeneral.colorPicker](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/preferences/preferencesgeneral.md#colorpicker) needs the `pluginID` property; set it to the plugin's internal string ID. |
