# GridSize

24.0

Grid square size.
Use with [PreferencesTransparencyAndGamut.gridSize](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/preferences/preferencestransparencyandgamut.md#gridsize)

| Name | Description |
| --- | --- |
| LARGE | Large grid squares are shown. |
| MEDIUM | Medium grid squares are shown. |
| NONE | No grid appears. |
| SMALL | Small grid squares are shown. |
