# ColorProfileType

22.5

For [Document.colorProfileType](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/document.md#colorprofiletype), indicates how a document's color profile is managed.

| Name | Description |
| --- | --- |
| CUSTOM | Used by every custom profile |
| NONE | Used when the document is unmanaged for color |
| WORKING | Used when the document relies on the current working profile |
