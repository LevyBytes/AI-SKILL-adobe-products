# SavePreview

Application behavior for image previews.
Supply to [PreferencesFileHandling.imagePreviews](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/preferences/preferencesfilehandling.md#imagepreviews)

| Name | Description |
| --- | --- |
| ALWAYSSAVE | Always includes the item in file output. |
| ASKWHENSAVING | Asks whether file output should include the item. |
| NEVERSAVE | Never includes the item in file output. |
