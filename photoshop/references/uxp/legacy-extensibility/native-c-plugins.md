# Native C++ Plugins

[Plugins using native C++](https://www.adobe.com/devnet/photoshop/sdk.html) remain an important part of Photoshop extensibility and are still supported.

Adobe added a communication bridge suite for exchanging information between Photoshop-hosted C++ plugins and UXP plugins. Details are in [Communication with C++ Plugin SDK](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/media/cpp-pluginsdk.md).
