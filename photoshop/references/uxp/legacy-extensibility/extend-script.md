# ExtendScript

The UXP [Photoshop DOM API](../photoshop-api-overview.md) is intended as the next stage after the [ExtendScript](https://www.adobe.com/devnet/photoshop/scripting.html) DOM. Photoshop currently has no plan to discontinue ExtendScript support.

Because the ExtendScript Toolkit IDE depends on 32-bit architecture and is no longer maintained, ExtendScripts can instead be built with the [Visual Studio plugin for ExtendScript](https://marketplace.visualstudio.com/items?itemName=Adobe.extendscript-debug).

For moving plugins from ExtendScript to UXP, consult [UXP for ExtendScript Developers](../uxp-for-extend-script-developers/reference-index.md).
