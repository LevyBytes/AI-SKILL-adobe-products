# Guide fixes

- [Guide.coordinate](../../host-api/guide.md) fixes the coordinate getter for document resolutions other than 72 PPI
- [Guide.coordinate](../../host-api/guide.md) fixes the coordinate setter for document resolutions other than 72 PPI
- [Guides.add](../../host-api/guides/add.md) fixes coordinates when creating a guide at document resolutions other than 72 PPI
- [Guides.add](../../host-api/guides/add.md) now returns an existing guide instead of an invalid nonexistent instance after guide creation.
