# Photoshop API Changelog - Documentation update (May 2025)

- Output details for [`core.getDisplayConfiguration()`](../photoshop-core/get-display-configuration.md) were documented, including the new `maximumExtendedDynamicRangeColorComponent` property.
- [Event Codes](../event-codes/reference-index.md): a new page now lists event names used with [`core.addNotificationListener()`](../photoshop-core/add-notification-listener.md) and [`action.addNotificationListener()`](../functions/add-notification-listener.md). It also adds the Core event `displayConfigurationChanged`.
- RGB image data is required by [`imaging.encodeImageData()`](../imaging-api/encode-image-data.md), according to the new note.
- Descriptions and code samples were added, clarified, and cleaned up.
