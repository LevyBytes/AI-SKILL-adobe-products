# Different DOM access

The Photoshop DOM is reached through UXP-specific access patterns. For details, see [Photoshop UXP API reference](../photoshop-api-overview.md). Today the full DOM surface is not available yet, although each Photoshop release adds more access.

Until important Photoshop capabilities are exposed directly through UXP, [batchPlay](../batch-play/reference-index.md) can serve as a workaround.
