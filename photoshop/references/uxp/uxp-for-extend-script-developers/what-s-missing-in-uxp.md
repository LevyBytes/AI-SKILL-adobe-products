# What's Missing in UXP

UXP includes an HTML interpreter that resembles Chromium but is more constrained than a complete browser. As a result, some common web CSS and HTML patterns are unavailable. For the UXP HTML environment's supported and unsupported behavior, use [this document](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/guides/uxp-guide/unsupported/index.md).
