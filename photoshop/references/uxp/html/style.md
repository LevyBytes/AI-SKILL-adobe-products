# style

**Since** UXP v2.0

Provides inline CSS.

**See**: [https://developer.mozilla.org/en/docs/Web/HTML/Element/style](https://developer.mozilla.org/en/docs/Web/HTML/Element/style)

**Example**

```html
<style>
  .highlight {
    color: red;
  }
</style>
```

### Attributes

UXP ignores these unsupported attributes:

- `type`
- `media`
- `nonce`
- `title`
