# Must Reads

- [UXP API reference](../uxp-api-reference.md): Covers which browser-like capabilities UXP includes, and where the platform behaves differently.
- [Modal Execution in Photoshop](../executeasmodal.md): Describes the newer model for plugins that need performance and resilience. Treat it as required reading when your plugin changes a user's document.
- [Photoshop manifest](../photoshop-specific-manifest-properties/reference-index.md): Supplements `manifest.json`. In Adobe Photoshop 2022, pay attention to possible breaking changes related to Modal Execution.

Questions can go to the Adobe [Creative Cloud Developer Forums](https://forums.creativeclouddeveloper.com/), which are useful for finding answers.
