# TextFonts

TextFonts lists fonts installed on the computer. Each font appears as a [TextFont](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/textfont.md) object. Access the collection via the [Photoshop.fonts](https://raw.githubusercontent.com/AdobeDocs/uxp-photoshop/d3cf17a4cf92132513faf8f8ad6f143f518ac9d6/src/pages/ps-reference/classes/photoshop.md#fonts) property.
