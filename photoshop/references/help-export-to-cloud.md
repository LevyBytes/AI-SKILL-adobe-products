# Export To Cloud

> Adobe Photoshop reference. Original prose; identifiers preserved verbatim.

Save and export Photoshop assets to Adobe cloud so they are easy to access, share, and reuse across Adobe Photoshop on desktop, web, and mobile.

Put Photoshop assets in the cloud to support access and collaboration.

Export Photoshop assets to Adobe cloud when you need cloud access and collaboration.

## Save

Choose File > Open to browse for a file and open it.

After editing, choose File > Save As to save the changes.

In the Save As dialog, set the format to Photoshop, then choose Save to cloud documents.

In the Save to Adobe cloud dialog, start a new project or pick an existing project.

Select Save.

The file appears in the app homescreen as a recently saved or opened file. It also becomes part of your Adobe cloud assets and is available in Photoshop on the web and mobile.

## Export

Choose File > Open to browse for a file and open it.

Choose File > Export, then choose Export As.

In the Export As dialog, choose PNG, JPG, or GIF and adjust export settings if needed.

Select Export, then choose Save to cloud documents.

In the Export to Adobe cloud dialog, start a new project or pick an existing project.

Select Export.

The file appears in the Projects tab and is available in Photoshop on the web and mobile.
