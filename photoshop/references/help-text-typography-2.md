## Add text along paths or inside shapes

Create dynamic typography in Adobe Photoshop by placing text along curved paths or inside shapes for creative effects.

Text can follow paths or sit inside shapes to produce dynamic, creative typography effects. It can run along curves, circles, custom paths, or fill the inside of closed shapes.

Path text follows the edge of an open or closed work path made with the Pen tool or a shape tool. After text is added to a path, it follows the order in which the anchor points were created. For closed shapes, text may sit on the edge or inside the shape's boundaries.

### Add text along closed or open paths

Build a path or shape in the document.

Choose the Horizontal Type tool or Vertical Type tool.

Move the pointer onto the path until the type cursor with a wavy line appears.

Click the path where the text should begin, then type.

Use the Horizontal or Vertical Type tool when placing text on either a closed path or an open path.

In the Options bar (Window > Options), choose the Commit icon.

### Add text inside shapes

Build a path or shape in the document.

Choose the Horizontal Type tool or Vertical Type tool.

Move the pointer inside a shape until the type cursor appears enclosed in a circle.

Click inside the shape and type so the text fills that shape.

Use the Horizontal or Vertical Type tool when adding text inside a shape.

In the Options bar (Window > Options), choose the Commit icon.

## Flip or move text along a path

Use Adobe Photoshop to place type on the other side of a path or slide it along path curves for more exact typographic control.

Once text has been placed on a path, you can send it to the other side or shift it to another point on that same path. The behavior applies to open paths, such as lines and curves, and to closed paths, such as circles and shapes. While you reposition it, the text stays attached to the path.

From the Tools panel, choose either the Path Selection tool or the Direct Selection tool.

In the Layers panel, select the text layer.

Pause over the text path until the type cursor with a right arrow appears.

To place text on the other side, select the text and drag across the path.

Click any point on the path to set a new starting location for the text. Drag along the path to reposition the type.

Tip

For fine endpoint placement, pause over the end of the text path until the type cursor with a left arrow appears. Drag that handle to set where the text should finish.

Use the Direct or Path Selection tool to drag the type, either across the path or along it.

Dragging with the Direct or Path Selection tool lets path text switch sides or move to a new path position.

## Warp and unwarp text

In Adobe Photoshop, apply warp effects that bend and distort type into creative shapes while the text remains fully editable.

Warped text can produce strong typographic treatments by curving and distorting type into forms such as arcs, waves, or flags. Compared with other distortion approaches, the type stays editable. You can revise the wording, font, or color and keep the warp effect in place.

### Warp text

Choose the Horizontal Type tool or the Vertical Type tool.

Select the text for warping, then choose Type > Warp Text.

In the Warp Text dialog, open the Style drop-down menu and choose a warp style. Available styles include Arc, Arc Lower, Arc Upper, Arch, Bulge, and more.

Choose the Horizontal or Vertical orientation for the warp effect.

Use the Bend slider to set how strong the warp effect becomes. Higher values produce stronger curves.

Apply perspective with the Horizontal Distortion and Vertical Distortion sliders.

Use the Warp Text dialog to choose a Warp Style, then set Bend and Distort values.

Through the Warp Text dialog, set Warp Style and tune Bend plus Distort controls.

Select OK to apply the warp effect to your text.

### Unwarp text

Choose the Horizontal Type tool or the Vertical Type tool.

In the Layers panel, target the warped type layer, then choose Type > Warp Text.

From the Style drop-down menu in the Warp Text dialog, choose None.

Select OK to remove the warp effect from your text.

## Convert text to shapes or work paths

In Adobe Photoshop, turn type into editable vector shapes or work paths to build custom typography designs and special effects.

When text is converted to shapes, the type layer becomes a vector shape layer permanently. Use this route when you need direct control over individual letter forms.

Creating work paths from text produces a separate path in the Paths panel while the original text layer stays intact. Choose this route when text outlines are needed for selections or effects.

### Convert text to shapes

With the Horizontal Type tool or Vertical Type tool, select the text that should become a shape.

Choose Type > Convert to Shape. The type layer icon changes to a shape layer icon, confirming the conversion.

Use the Direct Selection tool to target and edit individual anchor points and paths in the converted text.

Move individual anchor points to edit the text as a vector shape.

Adjust individual anchor points when reshaping the vector text.

Once type becomes a shape, the letters support vector edits: anchor point changes, fill and stroke adjustments, and path operations.

### Convert text to work paths

Using the Horizontal Type tool or Vertical Type tool, select the text that will become a work path.

Choose Type > Create Work Path. The Paths panel receives a new path while the original type layer stays intact.

For path editing, choose the Path Selection tool or Direct Selection tool.

With the Direct Selection tool, drag any anchor point to revise the letter paths.

Use the Direct Selection tool on any anchor point to alter the letter paths.

After text becomes a work path, it can be turned into selections, stroked with color, or filled with patterns. The original text layer stays editable, with a separate path version maintained.

## Create text selection borders

Create text-shaped selections in Adobe Photoshop that behave like standard selections.

Text selection borders create selection outlines shaped like text characters. You can move them, copy them, fill them with color, or apply a stroke outline. Unlike regular type layers, which remain editable, type selection borders place outlines on the image layer. Use them for text effects that interact directly with image pixels instead of sitting above the image on a separate layer.

Target the layer where the type selection border should be created. For best results, use a normal image layer instead of a type layer. If the selection will be filled or stroked, consider placing it on a new blank layer.

From the toolbar, choose either the Horizontal Type Mask tool or the Vertical Type Mask tool.

Click the image at the intended text location; a red mask overlay appears while you type.

Enter the text, using the Options bar (Window > Options) for font, size, and any other type attributes you need.

Select the Commit icon from the Options bar. The active layer now shows a selection border matching the text shape.

Use the Horizontal or Vertical Type Mask tool when creating text selection borders.

Text selection borders can be added with the Horizontal or Vertical Type Mask tool.

## Work with OpenType SVG fonts

OpenType SVG fonts let text carry multiple colors and gradients without extra styling or effects.

OpenType SVG (Scalable Vector Graphics) fonts pair standard font technology with embedded SVG artwork. Because of that, colorful graphic text can remain editable without outline conversion or elaborate effects. A character may include multiple colors, gradients, and transparency while staying as live text.

Photoshop includes these OpenType SVG fonts:

- Trajan Color Concept
- EmojiOne

Font menus mark OpenType SVG fonts with the OpenType SVG icon beside the font name.

### How OpenType SVG fonts differ from standard fonts

Traditional fonts display as single-color solid forms. OpenType SVG fonts differ because they:

- Include prepared color schemes and gradients.
- Keep the same look no matter what background color is behind them.
- Do not expose their embedded colors through standard text color controls.
- Remain fully editable as text rather than outlines.Scale without quality or detail loss.

### Working with emoji fonts

OpenType SVG technology shows up most often in emoji fonts. The EmojiOne font included with Photoshop gives access to hundreds of colorful emoji characters.

Emoji fonts provide special capabilities:

- Composite glyphs: Some emoji come from multiple glyphs combined together, such as country flags.
- Skin tone variations: For certain emoji showing people or body parts, different skin tones can be applied.
- Visual consistency: Emoji keep a consistent look across platforms and applications.

### When to use OpenType SVG fonts in your workflow

OpenType SVG fonts work well for:

- Decorative headings and titles
- Social media graphics that require emoji
- Projects that need colorful text without complex layer effects
- Designs where text must stay editable

Use these fonts when text needs strong visual presence while still being searchable, editable, and accessible.

## Overview of Unified Text Engine

See how the Unified Text Engine supports advanced typography for international languages and scripts in Adobe Photoshop.

### What is the Unified Text Engine?

Photoshop 23.0 (October 2021) introduced the Unified Text Engine, a modern system for text processing that takes over from the older script-specific text engines. It supports advanced typography for international languages and scripts such as Arabic, Hebrew, Indic scripts, Japanese, Chinese, and Korean.

Because text handling is unified, multilingual work no longer requires switching engines for different languages. That makes designs containing several scripts easier to build and manage.

### Key enhancements and benefits

### Improved text shaping

For Arabic, Hebrew, Chinese, Japanese, Korean, and all non-Latin scripts, the Unified Text Engine relies on the open-source HarfBuzz text shaping engine to improve rendering. Across many writing systems, this helps characters form correctly and supports ligatures plus contextual alternates.

### Better bidirectional text support

The Unified Text Engine includes FriBidi technology, which improves handling for right-to-left and bidirectional text. This especially helps Arabic and Hebrew scripts, including text blocks where those scripts are combined with left-to-right languages.

### Working with the text layer Properties panel

Use the text layer Properties panel as the main place to reach typographic controls provided by the Unified Text Engine. Its sections group related settings so the controls needed for a particular text layer are easier to locate and apply.

As you work with different scripts, Photoshop surfaces the relevant typographic options in this panel automatically, reducing menu searching and avoiding separate text-engine switching.

## Supported international scripts

Review which languages are supported by the Unified Text Engine in Adobe Photoshop.

Photoshop handles scripts from many regions with shaping and common basic attributes, but without advanced typographic features for every script. Advanced typographic features are supported only for Latin, Arabic, and Japanese. Other scripts receive shaping and common type attributes only.

Feature parity is not guaranteed across Adobe applications because different apps can use different text engines. Text behavior may also vary with the application's main purpose, such as image editing, page layout, or illustration. As a result, formatting, style, and editability can be preserved differently across apps depending on the treatments applied.

The Unified Text Engine composer supports these languages and scripts:

- Gujarati
- Hindi
- Kannada
- Malayalam
- Marathi
- Oriya
- Punjabi
- Tamil
- Telugu

Middle Eastern

- Arabic
- Hebrew

South East Asian

- Thai
- Sinhalese
- Burmese
- Khmer
- Lao

CJK

- Chinese
- Japanese

Not every Adobe product currently supports South East Asian (SEA) languages or scripts. If SEA text is moved from an Adobe app that supports SEA scripts into an application without that support, some or all copied text and formatting edits may be lost. In that situation, keep these points in mind:

- Before moving Photoshop content into other applications, image files may have to be flattened.
- Before Illustrator text is used in other applications, it may have to be converted to outlines.
- Moving text from one application to another can make converted text no longer editable.

## Dynamic Text Overview

Learn how Dynamic Text changes size and reflows inside boundaries and shapes in Adobe Photoshop on desktop.

Dynamic Text keeps content inside defined boundaries or shapes by adjusting text size automatically. Available forms are Block, Circle, Arch, and Bow.

### Dynamic Text types

- Block: scales and reflows text so it fits inside a rectangular bounding box.
- Circle: places text on a circular path and scales it between defined start and end points.
- Arch: places text on an upward-curving path and scales it between defined points.
- Bow: places text on a downward-curving path and scales it between defined points.

Block resizes and reflows text within the bounding box. Circle, Arch, and Bow put text on a curved path and scale it across the shape's defined start and end points.

### Properties

- Set spacing between words: changes the gaps between words.

  - Set spacing between lines: changes the gaps between lines.

  - Adjust text position: sets where text sits relative to the path (above, center, below).
  - Adjust text direction: switches the text reading direction.
