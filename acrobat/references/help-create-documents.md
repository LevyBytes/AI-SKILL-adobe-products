## Convert web pages to PDFs

### Turn individual web pages, or whole websites, into PDFs while keeping control over their structure and contents.

A web page that's open in your browser can be captured as a PDF in one step using the Adobe Acrobat browser extension. The desktop version of Acrobat goes further, letting you grab full websites, decide how many page levels to pull in, and append pages to PDFs you already have.

With Acrobat running, choose Create over on the global toolbar.

On the page that comes up, pick Web page out of the left rail.

Type in the web page URL, or browse your way to an HTML file.

To set how many levels deep the capture should reach, tick the Capture multiple levels checkbox, then pick one of these:

- Get level(s) then type in how many levels you'd like captured.
- Get entire site grabs every level the website has.

When you're pulling several levels, rein in the scope with one or both of these:

- Stay on same path: restricts the grab to pages that sit beneath the URL you gave.
- Stay on same server: keeps outside domains out of it.

If you like, open Advanced settings to adjust the Web page conversion settings.

Select Create.

Note

Further pages can be queued while another is still converting, and each one joins the line automatically. The Download Status dialog box shows you whatever is still waiting.

## Web page conversion settings

### Tailor the way web pages become PDFs — layout, encoding, color handling, and multimedia all included.

From inside Acrobat, reach these controls by going to All tools > Create a PDF > Web page and then choosing Advanced settings, which exposes the conversion and layout options.

A faster route is to open the Adobe Acrobat extension in your browser and pick Conversion settings, which surfaces the most-used options.

### General settings

- Conversion Settings: governs the treatment of HTML or text files, font and layout choices among them.
- Create bookmarks: builds PDF bookmarks drawn from the titles or URLs of the web pages.
- Create PDF tags: carries the HTML structure into the PDF so it's easier to navigate and more accessible.
- Place headers and footers on new page: puts the page title or URL up in the header, with the URL plus the download date and time down in the footer.

### HTML conversion settings

- Default Encoding: pick the file text's input encoding from a list grouped by operating system and alphabet.

  - Always: sticks with the encoding you picked no matter what.
  - When Page Doesn’t specify Encoding: applies your encoding only where the HTML file leaves it undeclared.

- Language Specific Font Settings: tune the script, the font style, and the font size.

  - Force These Settings for All Pages. Leave this off and the default colors land only on pages that don't already define a color scheme.

- Embed multimedia content when possible: decide whether multimedia such as SWF files is turned off, embedded, or linked.
- Reference multimedia content by URL: switch this on to point at multimedia content by link rather than embedding it.
- Retain page background: holds onto the background colors and tiled images from the source page.
- Convert Images: brings the images into the PDF.
- Underline Links: draws underlines beneath text links.
- Expand Scrollable Blocks: makes sure scrollable regions appear fully opened out in the PDF.

### Text settings

- Input Encoding: determines how plain text files get read.
- Language Specific Font Settings: dial in the script, font, and size used for body text.
- Default Colors: assign the colors for text, background, and links.
- Wrap Lines At Margin: text wraps on its own once it hits the page margin.

### Page layout settings

- Page size and orientation: pick the page size, the margins, and whether the layout runs Portrait or Landscape.
- Scale Wide Contents to fit page: shrinks oversized content so it spans the page width.
- Switch to landscape if scaled smaller than (%): flips automatically to Landscape once scaling drops the content below a chosen percentage of its original size.

## Create PDFs by printing to file

### See how printing your documents to the Adobe PDF printer turns them into PDFs from any program that can print.

Plenty of applications can produce a PDF simply by issuing the Print command aimed at the Adobe PDF printer. Going this route converts your file into a PDF and never asks you to launch Acrobat.

PDFs made by the Adobe PDF printer come out untagged. Reflowing content onto a handheld device calls for a tagged structure, which also gives more dependable results when a screen reader is involved.

### Windows

Inside the program that made the file, go to File > Print.

Open the Printer menu and pick Adobe PDF.

For your printer choice, the Printer menu is where you'd set Adobe PDF.

For your printer choice, the Printer menu is where you'd set Adobe PDF.

To set or tailor a default, choose Printer Properties (or, in some cases, Preferences).

Note

A handful of applications make you pick Setup inside the Print dialog box first to reveal the printer list, after which you choose Properties or Preferences.

Select Print.

When the dialog box appears, give your PDF file a name and a place to live.

Note

On Windows, lean on PDFMaker for Microsoft Office documents when you want bookmarks and hyperlinks, since the Adobe PDF printer leaves those out.

### macOS

From within the app that authored the file, choose File > Print.

Down at the dialog box's foot, open the PDF menu and choose Save as Adobe PDF.

For the Adobe PDF Settings option, either pick a default or build your own with Distiller; whatever custom settings you've already made show up in the list too.

Under the After PDF Creation option, decide whether the PDF should open on its own.

Select Continue.

Give your PDF a name and a spot, then select Save.

Unless you change it, the PDF keeps the same filename and gets a .PDF extension.

Note

Which steps PDF creation takes can differ from one macOS version to the next. The Print command behaves another way in macOS Snow Leopard v10.6 and older, so check your system documentation for specifics.

## Create a PDF from clipboard content

### See how Acrobat builds a PDF straight from the text and images sitting on your clipboard.

Whip up PDFs from whatever is on the clipboard — handy for converting text, images, or other data out of various apps with no need to save a file first.

Get the content you want onto your clipboard by one of these routes:

- Run whatever app's copy command you like.
- Windows users grab the screen with the PrtScn key.
- macOS users open Applications > Utilities > Screenshot, capture a shot, and finish with Edit > Copy.

In Acrobat, head over to Menu (Windows) or File (macOS) > Create > PDF from clipboard.

Save the new PDF.

## Create a PDF from scratch

### How to build a blank PDF from nothing — no source file, picture, or scan required.

Starting a blank PDF comes in handy whenever a short one- or two-page document has to be built up from nothing. The same blank-page starting point also works for designing a brand-new PDF form, which you can populate with text fields, buttons, and other interactive controls.

When a document runs long or carries heavy formatting, reach for a dedicated layout application — Adobe InDesign or Microsoft Word, for instance — and then export the result to PDF.

### Windows

Choose Menu > Create > Blank page.

For fixed text and pictures, open the Edit menu at the top and then do either of the following:

- Pick Text when you want to enter non-editable wording for labels, directions, and the like.
- Pick Image to drop in logos, artwork, or any other graphic.

Form fields come from the Prepare a form entry in the left pane: pick it, select a field type, drag the field onto the page, then double-click it to adjust its settings. Step-by-step coverage lives under create PDF forms from scratch.

Finish by choosing Menu > Save as, picking where the file should go, typing a name, and clicking Save.

### macOS

Choose File > Create > Blank page.

For fixed text and pictures, open the Edit menu at the top and then do either of the following:

- Pick Text when you want to enter non-editable wording for labels, directions, and the like.
- Pick Image to drop in logos, artwork, or any other graphic.

Form fields come from the Prepare a form entry in the left pane: pick it, select a field type, drag the field onto the page, then double-click it to adjust its settings.

Step-by-step coverage lives under create PDF forms from scratch.

Finish by choosing File > Save as, picking where the file should go, typing a name, and clicking Save.
