# Net.SOAP methods

| Name | Short Description |
| --- | --- |
| connect | Turns a WSDL document's URL into a JavaScript object whose callable methods map to the web service. |
| request | Fires off a remote procedure call (RPC), or pushes an XML message to a SOAP HTTP endpoint. It either blocks until the endpoint answers (synchronous processing) or invokes a method on the notification object (asynchronous processing). |
| response | Fires off a remote procedure call (RPC), or pushes an XML message to a SOAP HTTP endpoint, without waiting on any reply. |
