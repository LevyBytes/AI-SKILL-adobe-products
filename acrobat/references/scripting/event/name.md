# name

| Version (Key) | Save-Prefs | Security | Product | Type | Access |
| --- | --- | --- | --- | --- | --- |
| 4.05 | No | No | All | String | R/W |

Gives the running event's name as a text string. Pairing the type with the name pins down the event uniquely. Valid names are:

Reference data, output or notation; not an executable JavaScript program.

```text
Keystroke        Mouse Exit
Validate         WillPrint
Focus            DidPrint
Blur             WillSave
Format           DidSave
Calculate        Init
Mouse Up         Exec
Mouse Down       Open
Mouse Enter      Close
```
