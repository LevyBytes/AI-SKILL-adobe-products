# largest

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 6.0 | No | No | All |

Hands back a duplicate of the Monitors object trimmed to whichever display or displays span the most area, counted in pixels.

Parameters

| Parameter | Description |
| --- | --- |
| nMinArea | (optional) Supply the optional number nMinArea and largest() yields an empty Monitors array whenever that top area comes in under the given value. |

Returns

A Monitors object
