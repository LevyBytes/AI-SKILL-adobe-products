# getPageRotation

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 5.0 | No | No | All |

Returns, for the page you name, its rotation. See also setPageRotations.

Parameters

| Parameter | Description |
| --- | --- |
| nPage | (optional) A 0-based page index; left unset it falls back to 0, meaning the document's opening page. |

Returns

The rotation value of 0, 90, 180, or 270.
