# getAnnotRichMedia

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 9.0 | No | No | All |

Fetches, by name, an AnnotRichMedia object belonging to a specified page.

Parameters

| Parameter | Description |
| --- | --- |
| nPage | A 0-based number naming the page on which the AnnotRichMedia object sits. |
| cName | What the AnnotRichMedia object is called. |

Returns

An AnnotRichMedia object, or undefined if there is no such object.

See also getAnnotsRichMedia.
