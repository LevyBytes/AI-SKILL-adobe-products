# getAnnot3D

| Version (Key) | Save-Prefs | Security | Product |
| --- | --- | --- | --- |
| 7.0 | No | No | All |

Pulls back, by name, an Annot3D object from a given page.

Parameters

| Parameter | Description |
| --- | --- |
| nPage | A 0-based number giving the page where the Annot3D object lives. |
| cName | What the Annot3D object is called. |

Returns

The Annot3D object, or undefined if there is no such object.
