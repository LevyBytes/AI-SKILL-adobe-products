## Use personalized AI Assistant in PDF Spaces on mobile

Reach for a prebuilt or personalized AI Assistant inside PDF Spaces to pose questions, clear up content, and pull out insights.

PDF Spaces in Acrobat on mobile let you bring together several files and links, surface AI-powered insights, and keep your research in one smart workspace. Drop in PDFs, MS Word files, photos, or text, and AI Assistant draws only on the content you added to field questions and spotlight the key insights, sparing you from reading every word.

### Get tailored insights

From the homepage, pick PDF Spaces and then open your PDF Space.

From the bottom menu, pick Chat.

In the chat bar, open the AI Assistant dropdown menu and settle on one of these:

- AI Assistant: All-around help across a wide range of tasks
- Analyst: The pick for digging into data or condensing research
- Entertainer: A fit for imaginative storytelling and lively content
- Instructor: The one for walking through concepts or teaching
- Create your own: Build an AI Assistant tailored to whatever you need

Settle on a prebuilt assistant and you get custom insights shaped around your goals.

- Build a study guide that comes with an answer key plus a recommended schedule for studying.
- Write up an email that captures the top 5 takeaways and lays out the next steps to take.
- Lay out a table that sets the sales results from the past six quarters side by side.

### Turn insights into charts and graphs

Take the information sitting in your documents and turn it into clear visual charts and graphs with AI Assistant in PDF Spaces. Rather than poring over tables or lengthy reports, you can rapidly picture trends, comparisons, and patterns. What you can do:

- Build charts and graphs out of the data cited across a single document or several
- Stack values, categories, or trends side by side in visual form
- Boil down complex information into clear visuals that are easy to grasp, reference, or share

Try these prompts

Speak plainly in the AI Assistant chat, such as:

- “Put together a bar chart that sets the quarterly revenue cited in these documents against each other.”
- “Build a pie chart that breaks out the issue categories found across the reports I uploaded.”
- “Picture the year‑over‑year trends drawn from this data.”
- “Draw a line chart that calls out how things shift over time.”

Tip

When the result misses the mark, follow up in chat to refine the chart. You might, for instance, ask the assistant to switch the chart type or zero in on a particular data range.

## Collect and manage PDF form data

Search Last updated on Feb 26, 2026 | Also applies to Adobe Acrobat 2017, Adobe Acrobat 2020

Share a form and Acrobat builds a PDF Portfolio on its own to gather the responses people send back. Unless you change it, the file lands in the same folder as the source form, named 'filename_responses'. What follows walks through how to:

- Collect user data
- Add user data to an existing response file
- Export user data from a response file
- Import form data
- Export file data
- Merge exported data files to a spreadsheet
- Use forms tracker

### Collect user data

1. Once someone sends a form back, open that returned form.
   The Add Completed Form To Responses File dialog box appears; pick one of these options:

Add to an existing responses file: Goes with the response file that was set up the first time you sent the form out through the Distribute form wizard. Click 'Browse' if you need to point Acrobat at the response file.

Create a new responses file: Builds a fresh response file at the name and location of your choosing.

Select OK.

The response file opens. Inside it, every returned form you add turns up as a component file of a PDF Portfolio.

### Add user data to an existing response file

With the response file open in Acrobat, look to the left pane and select Add.

When the Add Returned Forms dialog box comes up, select Add file.

Track down the returned forms, select them, and choose Open.

Need forms sitting in other folders? Run that last step again for each, then choose Ok when you're finished.

After that, every PDF form you brought in shows up as a component file of the PDF Portfolio.

### Export user data from a response file

Sending every entry from a PDF Portfolio response file off to a spreadsheet or an XML file works like this.

With that response file open in Acrobat, highlight the data you'd like to send out.

Head to the All tools menu, choose Export a PDF, pick a format, then choose Convert to (format selected).

When the Select Folder To Save File dialog box opens, supply a name and a location, settle on either CSV or XML as the format for your form data, and then select Save.

### Manage form data files

The answers captured on a PDF form can move out to other file formats and back in again, and those formats hold all the data in far less room than a full PDF would.

### Import form data

There are times when people hand back a filled-out form as a data-only file instead of a finished PDF. Such files skip the PDF format and arrive in something else, like FDF or XML. To view what a given recipient entered alongside the PDF itself, open the original file and pull in the contents of the data file.

Inside Acrobat, bring up whichever PDF form should receive the data.

Up in the global bar at the top left, select All tools, followed by Prepare a form.

From the Prepare a form panel, Select Options > Import data.

Pulling data from an outside file into a PDF form overwrites whatever already sits in the matching form fields. That said, where the incoming data file leaves one or more fields blank, the import won't wipe out the original entries.

When the Select File Containing Form Data dialog box appears, choose the format that matches your data file. Then track that file down, select it, and select Open.

Certain formats only work with particular kinds of PDF forms, which comes down to the program that built the form — Acrobat or Designer ES2, for instance. When the source is a text file (.txt), its data has to sit in tab-delimited rows that line up into columns.

### Export form data

Want a completed PDF form's contents stored as a data file in a different format? Here's the sequence:

Inside Acrobat, pull up the form you've already filled out.

Off the All tools menu, choose Prepare a form; in the left panel that appears, select Options > Export data.

When the Save As dialog box opens, pick which type you'd like the form data saved as — your choices are FDF, XFDF, XML, or TXT. After that, set a location and filename, and select Save.

Which file formats show up depends on the kind of PDF form, and that traces back to how the form was built.

### Merge form data files into a spreadsheet

Gathering data out of forms that haven't landed in a data set yet runs as follows:

In the upper-left global bar, choose All tools and then Prepare a form.

From the Prepare a form panel, select Options > Merge data files into spreadsheet.

In the Export Data From Multiple Forms dialog box, select Add Files.

Once the Select file Containing Form Data dialog box appears, set a file format under the File Of Type option — either Acrobat Form Data Files or All Files. Then locate the form files you'd like folded into the spreadsheet, select them, and select Open.

Got form data files elsewhere? Run that last step again for each location.

Select Export, settle on a folder and filename for the spreadsheet, and select Save.

When the Export Progress dialog box appears, select View file now to bring up the spreadsheet, or select Close dialog to head back to Acrobat.

Note

When the returned forms already live in a response file, the quicker route to a spreadsheet is the Export Data button in the left navigation panel of the PDF Portfolio response file.

### Use forms tracker

Tracker is the tool for staying on top of forms you've sent out or gotten back. Through it you can follow responses, change where the response file lives, bring in more recipients, email everyone at once, and read the form responses.

Starting at the Acrobat Home view, pick All tools under Suggested tools, then over in the Edit section Select Edit a PDF.

(Windows) Select the hamburger menu in the upper left. Then select Form Options > Track

(macOS) From the upper left, Select View > Tracker.

From the Tracker dialog box, expand Forms in the left navigation panel.

Pick a form, then do one of these:

To see every response, select View responses.

To point the response file somewhere else, under Responses File Location, select Edit file location.

To pull up the original form, select Open original form.

To bring in additional recipients, select Add recipients.
