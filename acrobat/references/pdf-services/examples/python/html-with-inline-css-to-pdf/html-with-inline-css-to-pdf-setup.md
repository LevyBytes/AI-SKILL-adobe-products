# Html with inline css to pdf example setup

Open when running or adapting the linked html with inline css to pdf example.

The complete program is Adobe's [source sample](https://raw.githubusercontent.com/adobe/pdfservices-python-sdk-samples/e2f2161723e8a077f5c272835f8305211c4ba500/src/htmltopdf/html_with_inline_css_to_pdf.py). The [call pattern](../call-pattern.py) shows the shared upload, submit, wait and download sequence; the [operations table](../operations.md) lists this example's job, parameter and result classes.

Supply your own PDF Services credentials through the environment variables or credentials object used by the example. The SDK, service access and input documents are external prerequisites; no credentials or sample binaries are bundled here.

- `src/resources/createPDFFromHTMLWithInlineCSSInput.html`
