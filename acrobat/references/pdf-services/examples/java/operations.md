# PDF Services operations: Java

Open when choosing the job, parameter and result classes for a PDF Services operation in Java. Use them in the shared [call pattern](CallPattern.java); each example's setup page links Adobe's complete sample.

Jobs live in `com.adobe.pdfservices.operation.pdfjobs.jobs` and results in `com.adobe.pdfservices.operation.pdfjobs.result`; other classes show their package under `com.adobe.pdfservices.operation`.
