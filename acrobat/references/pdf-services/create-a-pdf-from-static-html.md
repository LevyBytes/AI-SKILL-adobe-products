# Create a PDF from static HTML

A local static HTML file is what this snippet renders into a PDF. Because pages on the web usually reference external assets, package the input as a zip whose archive root holds an index.html, bundling alongside it any supporting files the page needs — images, css, and the like.

For the mechanics of calling these APIs, walk through the [API usage guide](https://raw.githubusercontent.com/AdobeDocs/pdfservices-api-documentation/main/src/pages/overview/pdf-services-api/howtos/api-usage.md).
