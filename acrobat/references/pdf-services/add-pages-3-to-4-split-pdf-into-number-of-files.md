# Add pages 3 to 4 — Split PDF into number of files

Beyond fixing a per-file page count or supplying explicit ranges, a PDF can also be divided by how many files you want back. Under this mode the service produces the requested file total and tries to distribute pages evenly across them.

The [API usage guide](https://raw.githubusercontent.com/AdobeDocs/pdfservices-api-documentation/main/src/pages/overview/pdf-services-api/howtos/api-usage.md) walks through how these APIs are called.
