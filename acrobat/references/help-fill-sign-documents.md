## E-sign agreements

### Learn how to e-sign agreements using Adobe Acrobat.

Get an email asking you to sign a document, and Acrobat makes adding your signature simple. Your signature lives safely in Adobe cloud storage, which keeps it on hand across every device and app you use. Each time you open a document to sign, Acrobat pulls up your saved signature on its own, so the next round goes faster.

Tip

On mobile, Acrobat lets you photograph your signature and apply it when signing across desktop, web, and mobile, thanks to the signature sync feature.

Head to Home, and beneath Agreements pick Waiting for you.

Double-click whichever agreement you mean to sign.

Click the signature field in the agreement and fill in the information.

Signing for the first time? Build your signature by going with one of these:

- Type: Type your name in the field. You can choose from a selection of signature styles.
- Draw: Draw your signature in the field.
- Image: Browse and select an image of your signature.
- Mobile: Select this option to create your signature on a mobile device. Enter your mobile number and select Send. A link is sent to your mobile. Selecting the link opens the web browser on your mobile device, where you can draw or select an image of your signature.

Typing, drawing, or bringing in a signature image are all on the table. Whatever signatures and initials you add get saved for next time.

Select Apply.

Fill every required field and signature, then select Click to Sign.

## Add digital signatures

With digital signatures in Adobe Acrobat, you sign documents under a verified identity, which keeps them authentic and intact. Secure IDs make it simple to drop digital signatures onto contracts, forms, or official paperwork.

Select All tools > Use a certificate.

Select Digitally sign.

When the dialog box shows you the signing instructions, choose OK to carry on.

Drag the dotted cursor to outline a rectangle wherever the signature should appear.

In the Sign with a Digital ID dialog box, pick the Digital ID you'd like to use for digitally signing and choose Continue.

Note

Without a digital ID on hand, build one first by choosing Configure New Digital ID before you continue.

In the Sign as <username> dialog box, check over your signature details, then key in your digital ID password.

Sign a PDF digitally with your certificate, and lock the document after signing so nobody can edit it further.

Sign a PDF digitally with your certificate, and lock the document after signing so nobody can edit it further.

Choose Sign, pick a spot when prompted, and choose Save. Following the signing, the signature panel shows a confirmation message noting that every signature is valid.

## Sign in preview mode for integrity

### Find out how to sign while Preview document mode is on so you can confirm a document's integrity in Adobe Acrobat.

For workflows where a signature demands that the document stay trustworthy, turn on View documents in Preview Mode before you sign. The mode scans for anything that could shift how the document looks and holds it back, letting you read and sign a frozen, secure rendering.

Signing under preview mode reveals whether the document carries:

- Dynamic content or dependencies that reach outside the file.
- Items like form fields, multimedia, or JavaScript that could change how it appears.

Once you've gone over the report, you can reach out to whoever authored the document about anything it flagged.

### Windows

Open Menu > Preferences > Signatures.

## Add time stamps

### See how attaching a trusted timestamp to a PDF in Acrobat backs up its authenticity and lets it be verified.

Certificate-based signatures, as well as PDFs that carry no identity-based signature, can have the date and time stamped onto them. A timestamp issued by a trusted authority confirms when signing happened and guards against the signature being invalidated. It also vouches for authenticity and meets the PAdES standard (ETSI 102 778).

The timestamp may come from an outside authority or from the certificate authority tied to your digital ID. When a timestamp server is configured, Acrobat draws on its time; with none in place, the machine's local clock fills in. Skip adding a timestamp at signing and you can still attach one afterward through long-term validation.

### Configure a timestamp server and set it as default

Before you begin

Make sure a trusted security settings file is on hand. Lacking one, request the server name and URL from your administrator.

Open Menu > Preferences.

Within Categories, choose Signatures.

Alongside Document Timestamping, choose More.

In the Server Settings dialog box, choose Time Stamp Servers in the left pane and then do one of the following:

- For pulling in a timestamp server settings file, choose Import. At the prompt, choose the file and then choose Open.
- For adding a timestamp server URL, choose New, and in the dialog box that appears, fill in the name plus the server URL. Note whether the server expects a username and password, then choose OK.

Configure a timestamp server by typing its name and URL into the Server Settings window. Doing so keeps the timestamps on your digital signatures secure and verifiable.

Configure a timestamp server by typing its name and URL into the Server Settings window. Doing so keeps the timestamps on your digital signatures secure and verifiable.

Highlight the timestamp you just added and then choose Set Default along the top menu.

When the dialog box appears, choose OK to confirm, then close it.

### Apply timestamps to documents

In the left pane, choose Timestamp.

Should you be prompted, save the document wherever you'd like and rename it if you need to.

As soon as the timestamp lands, a confirmation turns up in the Signature Panel up top.

Open the Signature Panel to see the timestamp details.

Through the Signature Panel you can confirm the document carries a digital signature and a timestamp. Signature details such as validity and expiration are there to review.

## Add verification information

### Find out how to attach verification information to a digital signature in Adobe Acrobat.

Attaching verification information keeps the digital signatures in your PDF valid and compliant over the long haul. You can layer this information on while signing or once the document has already been signed.

### Add verification information at signing

Open the PDF you intend to sign and supply with verification information.

Choose Menu (Windows) or File (macOS) > Preferences.

Within the Preferences dialog box, head to Signatures > Creation & Appearances: More.

Tick the Include signature's revocation status checkbox and then choose OK.

To pull in verification as you sign, tick Include signature's revocation status.

To pull in verification as you sign, tick Include signature's revocation status.

Sign the PDF.

Provided every link in the certificate chain is present, Acrobat writes the information into the PDF on its own. Where a timestamp server is configured, the timestamp goes in as well.

### Add verification information after signing

Sign while offline and validation particulars such as timestamps and revocation data might not be reachable, though they can be attached later once the PDF is validated online. Subsequent checks will then draw on that information.

Open the signed PDF document in Acrobat.

Track down the signature you want to supply with verification information.

Right-click the signature and choose Add Verification Information.

Note

You'll only find the Add Verification Information option when the signature earns trust through a certificate chain (rather than being self-signed or trusted by hand), when the verification time isn't fixed to "Always use current time," when the signature checks out as valid, and when it isn't a PKCS#1 object.

Should a prompt appear, let Acrobat reach the internet to fetch the verification information.

Confirm the verification information now attached to the signature, which might cover:

- Whether the signing certificate has been revoked
- A timestamp drawn from a trusted timestamp server, when one is configured

Save the PDF so the attached verification information sticks.

## Set up roaming ID accounts

### See how to get a roaming ID account going in Adobe Acrobat.

A roaming ID is a digital ID kept on a server that its subscriber can reach. Reaching one calls for an Internet connection plus an account from an organization that hands out roaming digital IDs.

### Windows

Open Menu > Preferences.

Under Categories, choose Signatures.

From the Identities & Trusted Certificates option, choose More.

Choose Digital IDs, choose Roaming ID Accounts, then choose the add account icon.

To start a fresh roaming ID account, choose Add ID and key in the details of your roaming ID server.

To start a fresh roaming ID account, choose Add ID and key in the details of your roaming ID server.

Type the roaming ID server URL plus a description into the dialog box, then choose Next.

Enter your username and password, or work through the steps to set up an account.

Choose Next, then choose Finish.

Note

Whenever a task calls for your roaming ID, Acrobat signs you into the roaming ID server automatically as long as your authentication still holds. Should that authentication have lapsed, you'll be asked to sign in once more before the roaming ID can be used.

Under Categories, choose Signatures.

## Manage certificates on directory servers

### See how to handle certificates kept on directory servers for Adobe Acrobat on Windows.

Within an organization, directory servers often serve as central stores of identities. They make a natural home for user certificates too, especially at enterprises relying on certificate encryption. Through a directory server you can track down certificates held on network servers, Lightweight Directory Access Protocol (LDAP) servers among them.

Track down a certificate and you can drop it into your list of trusted identities so the lookup never has to happen twice. Building up a store of trusted certificates lets you, or anyone in your workgroup, make encryption across the workgroup easier. Consult the Digital Signature Guide for more on directory servers.

### Import directory server settings

Note

Before settings get imported from a directory settings file, confirm you trust whoever provided the file ahead of opening it.

Open Menu > Preferences.

Under Categories, choose Signatures, then choose More from the Document Timestamping option.

Choose Directory Servers in the left pane, then choose Import.

Choose the Directory settings file and choose Open.

Click the Signature Properties button to inspect the present signature status whenever the file carries a signature.

From the dialog box that appears, choose Import Search Directory Settings.

Bring in directory server settings by way of the Acrobat FDF Directory Settings file.

Bring in directory server settings by way of the Acrobat FDF Directory Settings file.

At the confirmation prompt, choose OK. The directory server then shows up in the Server Settings dialog box.

### Export directory server settings

Directory settings can be exported as an import/export methodology file so you can set the directory server up on a different computer.

Open Menu > Preferences.

Under Categories, choose Signatures, then choose More from the Document Timestamping option.

Choose Directory Servers in the left pane, then pick one or more servers off the list.

Choose Export, settle on a destination, then choose Next.

So the file can be shown to have come from you, choose Sign, add your signature, then choose Next.

Depending on the destination you picked, go with one of these:

- To keep the file, give it a name and location, choose Save, and choose Next.
- To send the file along as an attachment, enter an email address in the To box and choose Next.

Note

Look over Export security settings for more on exporting security files.

Choose Finish.
