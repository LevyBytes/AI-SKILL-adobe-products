# Install the browser app

Note

Anyone subscribed to Acrobat Pro, Acrobat Standard, Acrobat PDF Pack, or PDF Export Pack is eligible to install Acrobat on the web, provided the Acrobat desktop app isn't already on their machine.

From the homepage of Acrobat on the web, open the Discover tab.

Find the Access Acrobat online more quickly card, then choose Install app.

The navigation buttons sitting beneath the Discover tab let you scroll to the ‘Access Acrobat online more quickly’ card.

Choose Install once the prompt appears.
