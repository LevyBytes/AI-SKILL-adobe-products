# Number pages

See how page numbers go onto your PDFs, with a range of font styles, sizes, and beyond.

From the Acrobat on the web homepage, pick Edit > Number pages.

Pick Select a file, then browse your device to bring in the file you'd like numbered.

Within the Number pages section, set both the Position on page and the Page range.

Press More when you want to fine-tune how the page numbers look and which font they use.

Under Format Number, dial in the font style, the size, and the formatting for the page number.

The Format Number section is where the page number's font style, size, and formatting get adjusted.

Pick Save.

Tip

Reverse any edits by picking from the top bar.

Page numbers attach to the PDF, which then saves itself to Adobe cloud storage automatically.
