# Combine files

See how a few clicks let you merge several files into one PDF with Acrobat on the web.

From the Acrobat on the web homepage, pick Edit > Combine files.

Pick Select files, then browse your device to bring in the files you'd like to merge.

Tick the files meant for merging, then press Continue.

A file location can be picked from the top menu, after which you mark the files to merge.

From the top menu you may set the source location, then flag the files you want combined.

Reordering is done by grabbing a file and dragging it where you want it.

Want to drop a file from the set? Hover over it and pick Delete .

For a look at and a reshuffle of a file's interior pages, hover over it and pick Expand .

With many files queued up, the List icon at the upper-right flips the layout into a list view.

Handling several files at once, you can toggle a list view through the List icon over on the upper-right.

Wrap things up by pressing Combine.

Note

Files that are secure, password-protected, 3D, or living inside a PDF Portfolio cannot be merged.

Your chosen files merge into one PDF that saves itself to Adobe cloud storage without further action.
