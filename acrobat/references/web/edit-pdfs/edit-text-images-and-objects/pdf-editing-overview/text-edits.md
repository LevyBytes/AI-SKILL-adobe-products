# Text edits

- Basic editing: Adding, swapping, or removing text is effortless. Typos get fixed, fonts swapped, typeface changed, and text resized with ease.
- Formatting: Tune text alignment, spacing, and formatting. The tool handles advanced text editing, though intricate layouts may still call for a few manual tweaks.
- Changing fonts: Lean on embedded fonts so your document reads the same from one device to the next, since whether a font is available shapes how text shows up.
