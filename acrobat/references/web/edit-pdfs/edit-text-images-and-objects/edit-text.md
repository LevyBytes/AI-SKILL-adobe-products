# Edit text

Find out how to drop in or swap text, fix typos, switch fonts and typeface, set alignment, and resize text.

Acrobat on the web lets you handle fast, essential edits straight in the browser, with no need to download and re-upload PDFs, which trims time and keeps your workflow smooth.

- Basic editing: Adding, swapping, or removing text is effortless. Typos get fixed, fonts swapped, typeface changed, and text resized with ease.
- Formatting: Tune text alignment, spacing, and formatting. The tool handles advanced text editing, though intricate layouts may still call for a few manual tweaks.
- Changing fonts: Lean on embedded fonts so your document reads the same across devices, since whether a font is available shapes how text shows up.

From the Acrobat on the web homepage, choose Edit > Edit text & images.

Pick Select a file and browse your device to upload whichever file you want to edit.

Selecting the text you want to edit brings up the Edit menu in the left panel.

Reach for the Format Text and Add Content tools to edit the text however you need, including:

- Setting the text in bold.
- Putting the text in italics.
- Removing the text.
- Adding fresh text.
- Switching the font style, size, color, and alignment of the text.
- Laying the text out as a bulleted or numbered list.
- Tweaking the text's line spacing, paragraph spacing, character spacing, and horizontal scaling.

Your edits to the PDF text take effect, with every change syncing automatically into Adobe cloud storage.

Tip

Lean on the AI Assistant to reword content so sections of your PDF grow shorter or longer.

Pick the text you want to edit and reach for the Context menu tools to adjust it quickly as needed.
