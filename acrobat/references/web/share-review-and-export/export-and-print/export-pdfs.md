# Export PDFs

Walk through turning PDF files into other formats with Acrobat on the web.

Through the Export a PDF tool in the browser edition of Acrobat, your PDF files can be exported into any of these formats:

- Microsoft Word (.doc, .docx, .rtf)
- Microsoft Excel (.xlsx)
- Microsoft PowerPoint (.ppt)
- Images (.jpg, .png, .tiff)

Note

Turning a PDF into a PPT file calls for an Acrobat PDF Pack subscription. To upgrade your account or handle your subscription, select the Profile icon and then select My Plan.

From the Acrobat on the web homepage, choose Convert > Export a PDF.

Open the Select files dropdown menu, choose the location, and then pick the file you'd like to export.

When the Export a PDF dialog box appears, set the file format you're converting to by way of the radio button and its paired dropdown menu.

For a document format, pick whichever language you need from the Document language dropdown menu.

For a Word conversion, select Microsoft Word, choose a filename extension next, and then select Convert to DOCX.

For an image format, choose the quality you'd like from the Image quality dropdown menu.

Aiming for an image instead? Pick the Image format option, then a filename extension, then whichever image quality suits you.

Select Convert to &lt;file format&gt;.

After the file becomes the format you picked, it shows up on the screen. Image output may arrive bundled in a zip file. Select Download file to open it on your system.
