# Manage shared documents

Viewing and keeping tabs on everything you've shared is straightforward.

Whatever you've shared lands in the Shared by you list of documents. The moment a recipient opens a file you sent, a notice reaches you inside Adobe Acrobat as well as by email.

From the Acrobat on the web homepage, choose Documents > Shared by you.

Look over your shared files, which carry these details:

- Name: The file name you sent out for review.
- Sharing: Who you handed the file to, by name.
- Status: How many people have opened the file.
- Last Activity: When the file was last touched.

Want to manage shared documents? Pick a document to bring up its details panel.

Tracking and handling the shared document is what the details panel equips you to do.

To extend the document to more people, open up the recipient list and choose Add people.

Open the people dropdown menu, then choose Add people to extend the document to others.

Want to pass the shared document's link to others? Choose Get link , and the moment the link reaches your clipboard, hand it off.

Pulling someone's access to the shared document is done by choosing Unshare .

Wiping the shared file out of Adobe cloud storage for good is done by choosing Delete ..
