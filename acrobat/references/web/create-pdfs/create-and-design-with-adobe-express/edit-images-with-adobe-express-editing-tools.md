# Edit images with Adobe Express editing tools

Learn how to enhance images using the Adobe Express image editing tools.

From the Adobe Acrobat homepage, pick Create > Edit an image.

Within the dialog box that appears, settle on the image you want to edit.

Turn to the Adobe Express image editor tools and you can do the following:

- Put filters and visual effects on the image
- Trim away the parts you don't want by cropping
- Take out the background, or particular objects
- Drop in shapes, icons, or text
- Tune opacity, brightness, contrast, along with color
- Mirror the image, horizontally or vertically

With Acrobat's built-in Adobe Express editing tools, you can polish images in no time.

Pick Download in the top-right corner to store your edited image.

Open the image in Acrobat and turn it into a PDF so you can readily edit it, reuse it in documents, or share it with others.
