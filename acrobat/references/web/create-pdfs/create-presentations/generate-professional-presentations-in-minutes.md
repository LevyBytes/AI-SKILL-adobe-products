# Generate professional presentations in minutes

See how, in just a few minutes, you can spin your ideas or documents into refined, AI-generated presentations with designs and layouts you control.

Building professional-grade presentations in a matter of minutes is what the Generate presentation tool in Adobe Acrobat is for. A single idea is enough to kick off a presentation, or you can lean on files you already have. Drawing on templates, automatic layouts, and AI-recommended visuals, the tool helps you put together clear, well-organized slides fast.

Decide where you'd like to start:

- From scratch: Go to the presentation builder page and type a detailed prompt or choose from the curated presentations.
- From existing files: Go to the presentation builder page and select Add files to upload files, add links, or paste text. Select a suggested prompt or write your own.
- From a PDF Space: Open your PDF Space and select Present from the left pane. Select a suggested prompt or write your own.

The presentation generation prompt is what you pick to convert your PDF Spaces files into a presentation.

Select Customize and then set the number of slides, audience, details, and file image usage as required.

Choose a template and select Next.

Look over the outline, tweak what's on each slide, and drag slides into a different order if you need to.

Note

At any point you can keep adjusting the prompt, tone, detail, audience, and file image usage by selecting Edit Prompt

Select Generate to create your presentation (powered by Adobe Express).

Reach for the Adobe Express-powered tools in the left panel when you want to:

- Edit text, layout, and structure
- Add media
- Adjust themes
- Recreate slides
- Apply other enhancements as needed

Turn to the Edit page tools when you need animations, translations, resizing, or image replacement.

Fine-tune your slides — one at a time or in bulk — using the Resize, Animate, Replace, Translate, and Bulk create controls.

Both Adobe Acrobat and Adobe Express hold on to the presentation files.

Wrap things up and pass the presentation along:

- Select Download from the top menu and export as PDF, PNG, JPG, or PPTX.
- Share via link or email.
- Present directly from Adobe Acrobat or Adobe Express.
