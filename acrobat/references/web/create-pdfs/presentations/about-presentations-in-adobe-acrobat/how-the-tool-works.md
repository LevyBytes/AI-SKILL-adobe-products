# How the tool works

Your ideas or documents get turned into refined, ready-to-edit slides in short order by the Generate presentation tool in Adobe Acrobat. Hand it a prompt or upload some files, and out comes a structured presentation carrying smart layouts and visuals. Building slides by hand isn't necessary. Spell out what you're after, then customize and refine. Learn how to create an AI-powered presentation.
