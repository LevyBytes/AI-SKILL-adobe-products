# Ways to begin

There are a few starting points for building a presentation:

- Text prompts only: Begin from a blank slate by defining the audience, the length, and the structure. The prompt can run as long as 1,000 words.
- File uploads: Bring in your material across several formats — PDF, Word, PowerPoint, Excel, and web links — then spell out the presentation you have in mind. As many as 10 documents are allowed, totaling 150 pages.
- PDF Spaces: Kick off a presentation straight from your PDF Space. Every file gets analyzed, the tool draws out the key insights, and editable slide content is produced.
