# Visual sources in generated presentations

The visuals that show up in a generated presentation may come from these sources:

- Adobe Stock images: Based on each slide's content and theme, the feature proposes Adobe Stock images. Right-click an image and pick Source info to review where it came from and its license.
- Images from your source files: The files you upload can supply images. Turn them off by heading to Customize > Settings and clearing the Include file images checkbox; with it cleared, only Adobe Stock or AI-generated images remain.
- Third-party AI models: For image generation the feature relies on Google's Gemini 2.5 Flash Image (Nano Banana). These visuals show up once the presentation has been built.
