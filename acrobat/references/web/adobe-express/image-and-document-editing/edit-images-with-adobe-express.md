# Edit images with Adobe Express

A walkthrough for improving photos with the Adobe Express tools built into Acrobat on Android.

Note

For now, this capability ships only inside Acrobat on Android; iOS does not support it.

Open Acrobat on Android and tap Create in the bottom menu.

Pick Edit image.

Choose whichever image you'd like to work on.

The Adobe Express image editor gives you these enhancements to apply:

- Crop to remove unwanted areas
- Remove the background or specific objects
- Resize, rescale, or flip the image
- Adjust opacity, brightness, contrast, and color
- Apply filters and visual effects

Photo touch-ups happen right inside Acrobat by way of the Adobe Express-powered toolset.

Tap Save.

Reopen the stored image from Recents, then reach for the bottom menu to keep going:

- Create PDF: turn the image into a brand-new PDF
- Edit as PDF: reach into an existing PDF and change its text or images
- Export: hand your PDF off to formats such as Word or Excel
- Recognize text: run OCR so scanned material becomes searchable and editable
- Edit image: polish or rework the image with the advanced editing tools
