## Convert PDFs to image formats

### Use Adobe Acrobat to turn PDF documents into image types such as JPEG, PNG, TIFF, and JPEG 2000.

From the global bar, select Convert.

In the left pane, select Image format.

Out of the dropdown menu, pick the format you want:

- JPEG
- JPEG 2000
- PNG
- TIFF

The button you click should match your chosen format — that is, Convert to JPEG, or else Convert to JPEG 2000, or Convert to PNG, or Convert to TIFF.

When the dialog box appears, pick where you'd like the file saved.

Rename the file if you like, then select Save.

Tip

Reach for JPEG when the image is headed to the web, PNG when you need a transparent background, TIFF for high-quality archiving, and JPEG 2000 when you want stronger compression.

## Convert PDFs to Word formats

### Turn PDF files into a Microsoft Word document the easy way with Adobe Acrobat.

DOC and DOCX are the two Microsoft Word document formats. The older DOC belongs to Word releases through 2003, whereas the newer XML-based DOCX has been the standard since Word 2007. As a rule, DOCX files run smaller and sit better with today's office software.

From the global bar, select Convert.

In the left pane select Microsoft Word, then from the drop-down menu select DOCX or DOC.

Select Convert to DOCX or Convert to DOC.

When the dialog box appears, pick where to save the file.

Give the file a name, then select Save.

## Convert PDFs to PostScript files

### Use Adobe Acrobat to push a PDF out to a PostScript-format file for printing and prepress work.

The PostScript (PS) and Encapsulated PostScript (EPS) formats both serve printing and graphics. PS suits high-quality, multi-page document printing, particularly on PostScript printers. EPS is a slice of PostScript, normally reserved for single-page files. Its purpose is to drop images, illustrations, or logos into other documents, above all in design and publishing work.

### Covert PDF to PS or EPS format

From the global bar, select Convert.

In the left pane select Other format. The dropdown menu then offers EPS or PS — pick whichever you need.

Depending on that pick, the button reads either Convert to EPS or Convert to PS; select it.

When the dialog box appears, pick where to save the file.

Give the file a name, then select Save.

### Adjust PDF to PS and EPS conversion settings

From the global bar, choose Convert.

In the left pane, pick Other format, then choose PS or EPS in the dropdown menu.

To change the export preferences, choose Settings.

Tune these settings to suit your output:

- Printer Description File: Pick a PPD, or go with Device Independent when you need composite PostScript.
- ASCII or Binary: Sets the output encoding. Although Binary yields smaller files, some workflows can't handle it.
- PostScript: Pick the level of the PostScript language.
- Font Inclusion: Decide which fonts get embedded in the PostScript file.
- Include Comments: Keeps any comments in the file that's produced.
- Convert TrueType to Type 1: Turns TrueType fonts into Type 1 within the output.
- Include Preview: Generates a preview, though this option is unavailable when the output is PS.
- Page Range: Sets which pages get exported.

Choose OK.

### Using Adobe Acrobat, here's how to turn a PDF into a webpage.

### Convert PDF to HTML format

From the global bar, choose Convert.

In the left pane, pick Other format, then choose HTML in the dropdown menu.

Turn your PDF documents into HTML so they slot cleanly into the web.

Turn your PDF documents into HTML so they slot cleanly into the web.

Choose Convert to HTML.

When the dialog box appears, pick where you want the file saved.

Enter a file name, then choose Save.

### Adjust conversion settings

From the global bar, choose Convert.

In the left pane, pick Other formats, then choose HTML in the dropdown menu.

To change the export preferences, choose Settings.

When the dialog box appears, tune these settings to suit your needs:

- File and Navigation Pane Settings: Decide whether one HTML file or several linked files get created, and layer in navigation that follows the document's structure.
- Content Settings: Control whether images are kept and whether headers and footers get stripped from the HTML that results.
- Text Recognition Settings: Pull text out of images and pick the language so recognition stays accurate.
- Restore Defaults: Reverts to the default settings for HTML conversion.

Choose OK.

### Convert PDF to XML

From the global bar, choose Convert.

In the left pane, pick Other format, then choose XML 1.0 in the dropdown menu.

Choose Settings to adjust the options below:

- Encoding: UTF-8 covers the majority of cases.
- Generate bookmarks: Builds XML tags that mirror the document's structure.
- Generate tags for untagged files: Inserts a basic set of structure tags.
- Export all images: Pulls every image from the PDF into the XML file.
- Use sub-folder: Names a folder where the exported images get stored.
- Use prefix: Prepends a prefix onto the image file names.
- Output format: Sets the format used for the images.
- Downsample to: Tunes the resolution of the images.

Choose Convert to XML.

When the dialog box appears, pick where you want the file saved.

Rename the file if you like, then choose Save.
