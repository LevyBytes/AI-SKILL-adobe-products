How a PDF first appears comes down to the document properties its creator configured. A file might, for instance, be set to open at a specific page or zoom level.

## View PDFs in Read mode

While you read, every toolbar and task pane can be tucked away so the document fills as much of your screen as possible.

A semi-transparent floating toolbar near the lower edge of the window keeps the essential reading controls — things like page navigation and zoom — within reach.

Reach Read mode through the hamburger menu (Windows) > View, or View (macOS), and then pick Read Mode. The floating toolbar's Read Mode button does the same thing.

Bring the work area back to how it was by choosing hamburger menu (Windows) > View or View (macOS) and selecting Read Mode a second time. The collapse button on the floating toolbar works too.

## View PDFs in Full Screen mode

Full Screen mode shows nothing but the document — the menu bar, toolbars, task panes, and window controls all disappear. Either the PDF's creator configures it to launch this way or you switch the view on yourself. Presentations frequently rely on Full Screen mode, occasionally pairing it with automatic page advancement and transitions.

Because the pointer stays live in Full Screen mode, you can still click links and open notes. Moving through a PDF this way can be done two ways: keyboard shortcuts handle navigation and magnification commands, and a Full Screen preference can put navigation buttons on screen that you click to flip pages or leave Full Screen mode.

Review PDFs can also be opened in Full Screen mode so attention stays on the content and the comments sent your way. The shortcut Ctrl + L flips you into Full Screen mode.

1. Within the Preferences dialog box, under Categories, pick Full Screen.
   Turn on Show Navigation Bar, then click OK.

From the hamburger menu (Windows) > View, or the View menu (macOS), pick Full Screen Mode.

Previous Page , Next Page , and Close Full Screen View buttons make up the Full Screen navigation bar. They sit in the lower-left corner of the work area.

## Display size in Acrobat

To make reading more comfortable on whatever device you have, the PDF's display size is adjustable. Open the hamburger menu (Windows) > View. From there pick Display Size Mode and select Small, Standard, or Large to suit your needs.

## Display themes in Acrobat

go to View > Display Theme,

Setting a display theme lets you alter the overall look and feel of Acrobat. Pick a theme by opening the hamburger menu (Windows) > View or the View menu (macOS) and selecting Display Theme. Then choose from the themes listed here:

- System Theme - Choosing System Theme tells Acrobat to follow the OS theme for its interface. Change the OS theme while Acrobat is open and Acrobat's theme follows along.
- Light Gray - Acrobat ships with Light Gray as its default. Every UI element along with the document background shows up in light gray.
- Dark Gray - Switching to Dark Gray eases eye strain, makes screen use more comfortable in dim surroundings, and saves battery — better visual ergonomics all around. Coverage of this dark theme now reaches the top menu, the on-page context menu, the scroll bar, and the comments pane.

## Preferences for viewing PDFs

A default page layout, along with plenty of other customizations, gets defined through the Preferences dialog box. When it comes to viewing PDFs, look over the preference options under Documents, Full Screen, General, Page Display, and 3D & Multimedia.

Rather than belonging to any single PDF, the preferences govern how the application acts every time you run it. Open the preferences dialog by choosing the hamburger menu (Windows) > Preferences or Acrobat / Adobe Acrobat Reader > Preferences (macOS).

Note

Whenever third-party plug-ins are installed, configure their preferences through Third-Party Preferences.

## Documents preferences

Open Settings

- Restore Last View Settings When Reopening Documents: Controls whether a document jumps back to the last page you viewed during a work session when reopened.
- Open Cross-document Links In Same Window: Shuts the current document and brings up the linked one in that same window, which keeps the count of open windows down. When the linked document already sits open in a separate window, clicking a link to it leaves the current document open. Leave this off and every click on a link to a different document spawns a fresh window.
- Allow Layer State To Be Set By User Information: Permits the author of a layered PDF to key which layers stay visible off of who the user is.
- Allow Documents To Hide The Menu Bar, Toolbars, And Window Controls: Lets the PDF decide whether the menu bar, toolbar, and window controls vanish when it opens.
- Always use filename as document title: Lets the filename stand in as the document title. (Off by default.)
- Documents In Recently Used List: Caps how many documents the File menu lists.

Save Settings

- Automatically Save Document Changes To Temporary File Every \_ Minutes: Governs the interval at which Acrobat saves changes to a document you have open.
- Save As Optimizes For Fast Web View: Reorganizes a PDF so web servers can deliver it a page at a time.
- Always reduce size for files more than 10MB: Shrinks the PDF on its own once the file climbs past 10MB.

PDF/A View Mode

- View Documents In PDF/A ModeSpecifies when to use this viewing mode: Never, or Only For PDF/A Documents.

Hidden Information

Combs the PDF for things that might go unnoticed — metadata, file attachments, comments, and concealed text and layers among them. A dialog box lists what turns up, and you can strip out whichever kinds you want.

- Remove Hidden Information When Closing Document (Off by default.)
- Remove Hidden Information When Sending Document By Email (Off by default.)

Redaction

- Adjust Filename When Saving Applied Redaction Marks: Lets you attach a prefix or suffix when saving a file that has had redaction marks applied.
- Choose Localization For Search & Remove Text Patterns: Picks which installed language edition of Acrobat supplies the patterns. Say both English and German are installed — either language's patterns are then available to you. Both the Search and Redaction dialog boxes carry the Patterns option.

## Full Screen preferences

Full-Screen Setup

- Current Document Only: Sets whether only a single PDF is shown.
- Fill Screen With One Page At A Time: Pushes the page view so one page covers as much of the screen as it can.
- Alert When Document Requests Full Screen: Pops up a message ahead of entering Full-Screen mode. Turning this on cancels any earlier choice of Do Not Show This Message Again in that prompt.
- Which Monitor To Use: Picks which monitor carries the full-screen display, for anyone running more than one.

Full-Screen Navigation

- Escape Key Exits: Allows the Esc key to take you out of Full-Screen mode. Leave it off and Ctrl+L becomes the way out instead.
- Show Navigation Bar: Keeps a slim navigation toolbar on screen no matter what the document specifies.
- Left Click To Go Forward One Page; Right Click To Go Back One Page: Lets mouse clicks move you through an Adobe PDF. Return, Shift-Return (for going back), or the arrow keys can also carry you across a document.
- Loop After Last Page: Keeps you cycling through a PDF without end, looping from the last page back to the first. Kiosk displays are the usual reason to set this.
- Advance Every \_ Seconds: Sets whether pages turn on their own after a chosen number of seconds. The mouse or keyboard still lets you move through a document even with automatic paging switched on.

Full-Screen Appearance

- Background Color: Sets the color of the window's backdrop while in Full-Screen mode. Pull a color from the palette to tailor that background.
- Mouse Cursor: Sets whether the pointer stays visible or stays hidden during Full-Screen mode.

Full-Screen Transitions

- Disable All Page Transitions: Strips transition effects from presentations you view in Full-Screen mode.
- Default Transition: Sets which transition plays as you move between pages in Full-Screen mode when the document itself specifies none.
- Direction: Sets how the chosen default transition travels across the screen — Down, Left, Horizontal, and the like. Which options exist depends on the transition, and when none of the directional options apply to it, this setting is grayed out.
- Navigation Controls Direction: Echoes how the viewer moves through the presentation — sliding top to bottom as they go to the next page, bottom to top as they return to the previous one. Only transitions that carry directional options offer this.

## General preferences

Basic Tools

- Use Single Key Accelerators To Access Tools: Lets a single keystroke pick a tool. The option starts out off.
- Create Links From URLs: Sets whether links not made in Acrobat get spotted automatically in the PDF and turned into clickable links.
- Make Hand Tool Select Text & Images: Has the Hand tool act like the Select tool while it sits over text in an Adobe PDF.
- Make Hand Tool Read Articles: Alters how the Hand tool pointer looks above an article thread. The first click zooms the article to span the document pane horizontally, and each click after that follows the article's thread.
- Make Hand Tool Use Mouse-wheel Zooming: Flips the mouse wheel from scrolling over to zooming.
- Make Select Tool Select Images Before Text: Reorders how the Select tool makes selections.
- Show Quick actions on text selection: Brings up a quick action toolbar whenever text or an image is selected.
- Show Online Storage When Opening Files: Surfaces cloud storage inside the file open dialog box.
- Show Online Storage When Saving Files: Surfaces cloud storage as you save a file.
- Open PDFs from last session on Acrobat launch: Brings back the PDFs from your previous session when Acrobat starts.
- Open Documents As New Tabs In The Same Window (requires relaunch): Bundles several documents into tabs as they open. Tabs can also be snapped out or pulled free as their own windows — select a tab, drag away the thumbnail that shows up beside the toolbar, then let go.
- Prompt Before Closing Multiple Tabs: Checks with you before Acrobat closes.
- Show Starred Files In Recent Tab: Puts your starred files on display as cards in Home view.
- Use Fixed Resolution For Snapshot Tool Images: Fixes the resolution applied when copying an image grabbed with the Snapshot tool.
- Enable PDF thumbnail preview in Windows Explorer: Turn this on to have PDFs show as thumbnail previews within Windows Explorer.
- Touch Mode: Determines how — or whether — Acrobat slips into Touch mode on touch-capable devices. Under Touch mode, toolbar buttons, panels, and menus spread out a bit so fingers can select more easily. Viewing is tuned by the Touch reading mode, which handles the most common gestures.
- Scale for screen resolution (restart required): Either detects the screen resolution automatically and scales the PDF for viewing, or leaves the PDF as-is no matter the screen resolution.

Warnings

- Do Not Show Edit Warnings: Switches off the warning boxes that usually pop up when you remove things like links, pages, page thumbnails, and bookmarks.
- Reset All Warnings: Puts warning settings back to their defaults.

Messages From Adobe

- Show Me Messages When I Launch Acrobat: Permits Adobe's in-product marketing messages to surface in the Welcome Screen when you start the app with no document open. Clicking a message turns up information on features, updates, or online services, or opens something inside the app such as a task pane. Clear the option and those in-product marketing messages stay away.

Note

The transactional messages that keep the Adobe Online Service running cannot be switched off.

Application Startup

- Use Only Certified Plug-Ins: Makes sure only third-party plug-ins certified by Adobe get loaded. A Currently in Certified Mode notation reads Yes or No to reflect the present state.
- Check 2D Graphics Accelerator (Windows only): (Shows up only when your computer hardware can do 2D graphics acceleration.) Selected, it lets hardware acceleration kick in as the first document opens. Deselected, hardware acceleration begins only after that first document is open. Because it can drag out startup, the option is off by default.

Note

You can use this option only while Use 2D Graphics Acceleration sits selected in the Page Display preferences.

- Select As Default PDF Handler (Windows only): Decides which program — Reader or Acrobat — opens PDFs. It matters once you have installed the two of them side by side.
- Tell Me If Adobe Acrobat Is Not My Default PDF Application (Windows only): When Acrobat is not the default PDF handler, launching it brings up a dialog asking whether to make Adobe Acrobat the default PDF application.

## Page Display preferences

Default Layout And Zoom

- Page Layout: Fixes which page layout scrolling uses the first time you open a document. Automatic is the default. Whatever sits under File > Properties > Initial View for Page Layout takes precedence over this.
- Zoom: Fixes the magnification a PDF opens at initially. Automatic is the default. The Magnification value under File > Properties > Initial View overrides this.

Note

A pair of conditions can sway page layout and zoom. 1) Someone has already given a particular PDF a different initial view through File > Properties. 2) You have Restore Last View Settings When Reopening Documents turned on in the Edit > Preferences > Document category.

Resolution

- Use System Setting: Falls back on the system's monitor-resolution settings.
- Custom Resolution: Lets you fix the monitor resolution yourself.

Rendering

- Smooth Text: Chooses which kind of text-smoothing gets applied.
- Smooth Line Art: Smooths lines so their sharp angles disappear.
- Smooth Images: Smooths images to soften abrupt shifts within them.
- Use Local Fonts: Decides whether the app draws on or skips the local fonts installed on your system. Deselect it and substitute fonts fill in for any font the PDF does not embed. When no substitute exists for a font, its text turns into bullets and an error message shows up.
- Enhance Thin Lines: Turned on, it sharpens thin lines on screen to make them stand out.
- Use Page Cache: Loads the upcoming page into a buffer before you reach the current one, trimming the wait as you page through a document.
- Use 2D Graphics Acceleration (Windows only): (Shows up only when your computer hardware can do 2D graphics acceleration.) Quickens zooming, scrolling, and page redraws, and speeds how 2D PDF content renders and responds. It is on by default.

Note

Should this option be missing from the Page Display preferences, your GPU card driver may need updating to switch on the hardware feature. Reach out to your card vendor or computer manufacturer for a newer driver.

Page Content And Information

- Show Large Images: Puts large images on screen. If image-heavy pages bog your system down, clear this option.
- Use Smooth Zooming (Windows only): Deselected, it kills the animation effects, which lifts performance.
- Show Art, Trim, & Bleed Boxes: Reveals whatever art, trim, or bleed boxes a document defines.
- Show Transparency Grid: Puts the grid on view behind transparent objects.
- Use Logical Page Numbers: Switches on the Number Pages command so a page's spot in the PDF lines up with the number printed on it. The Page Navigation toolbar and the Go To Page and Print dialog boxes then show a page number with its position in parentheses — for example, i (1 of 1) when the first page's printed number is i. Leave it off and pages carry Arabic numbers counting from 1. Switching it on guards against surprises after a tap on your browser's Back or Go Back control.
- Always Show Document Page Size: Puts the page measurements alongside the horizontal scroll bar.
- Use Overprint Preview: Sets whether Overprint Preview mode runs only for PDF/X files, never, always, or by automatic decision. On Automatic, the mode switches on whenever a document carries overprints. Overprint Preview mode lets you preview on screen how ink aliasing will look in print — a printer or service provider might, for instance, alias an ink when a document holds two close spot colors but needs only one.
- Default Transparency Blending Color Space: Picks the default color space for transparency blending, either Working RGB or Working CMYK.

Reference XObjects View Mode

- Show Reference XObject Targets: Sets which kinds of documents allow reference XObjects to be viewed.
- Location Of Referenced Files (Optional): Points to a location for the referenced documents.

## Touch mode for tablet and mobile devices

Working with Acrobat and Acrobat Reader on touch devices gets simpler under Touch mode. Toolbar buttons, panels, and menus spread out a bit so fingers can select more easily. Viewing is tuned by the Touch reading mode, which handles the most common gestures. On a touch-enabled device, Acrobat and Acrobat Reader move into Touch mode on their own. The default preference for Touch mode can be changed.

## Change Touch Mode preference

Get to your preferences through the hamburger menu > Preferences (Windows) or Acrobat / Adobe Acrobat Reader > Preferences (macOS).

From Categories, pick General.

Within Basic Tools, set the default you want from the Touch Mode menu.

## Change the PDF/A viewing mode

For archiving and preserving electronic documents over the long haul, PDF/A is the ISO standard. Anything you scan to PDF comes out PDF/A-compliant. Whether documents display in this viewing mode is up to you.

Open a PDF/A-compliant document in PDF/A viewing mode and it lands in Read mode so it stays unmodified. The document message bar shows a message about it. Editing and annotating are off-limits there. Switch PDF/A mode off and editing the document becomes possible.

Within the Preferences dialog box, under Categories, pick Documents.

Toggling this preference moves you into or out of PDF/A viewing mode.

## Display PDFs in Line Weights view

Lines render at the weights set in the PDF when Line Weights view is on. With it off, every line gets a fixed one-pixel stroke regardless of zoom. Printing the document, though, reproduces the stroke at its real width.

Choose (Windows) > View or View (macOS), then pick > Show/Hide > Rulers & Grids > Line Weights. Switch the Line Weights view off by choosing > View (Windows), View (macOS) > Show/Hide > Rulers & Grids > Line Weights once more.

Note

Line Weights view will not turn off while you view PDFs inside a web browser.
