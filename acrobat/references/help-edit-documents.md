Select Edit from the global bar.

Within the Edit pane, choose Text.

Click the spot in the document where the text should go.

Enter your text into the text box that pops up.

Lean on the AI Assistant when you want to rewrite text, soften the tone, or sharpen clarity in your PDF.

Pick the text formatting controls to adjust how the text looks and keep the document consistent.

Resize a text box by dragging its corners or the side handles.

Reposition a text box by hovering on its border until the cursor changes, then dragging it somewhere new.

Click anywhere outside the text box to commit your changes.

With Adobe Acrobat, here's how to revise the text already in a PDF, bring in new content, and take text out.

## Format text

### Work with the font, size, color, and other text formatting controls inside Adobe Acrobat.

Open the PDF and select Edit from the global bar.

Highlight whatever text you intend to format. The box around it turns blue and shows selection handles.

Text formatting controls let you reshape the text so it stays in keeping with the document.

Text formatting controls let you reshape the text so it stays in keeping with the document.

Reach for these FORMAT TEXT controls to style your text:

- Font: Pick another typeface from the dropdown.
- Font size: Grab a preset size or key in your own.
- Font color: Launch the color picker and choose a fresh text color.
- Bold, Italic, Underline: Switch any of these on or off as you like.
- Superscript/Subscript: Use these for scientific notation.
- Text alignment: Set the text left, center, right, or justified.
- Line spacing: Tighten or loosen the gap between lines.
- Paragraph spacing after: Decide how much room follows each paragraph.
- Character spacing: Dial in the gap between individual letters.
- Horizontal scaling: Stretch or squeeze the character width.
- Bulleted and numbered lists: Turn your text into a formatted list.

Note

Need to reverse or repeat a text edit? Open Menu (Windows) or Edit (macOS) > Undo, Redo & more > Undo, Redo and More, then choose whichever tool fits.

Click outside the text box to put your changes into effect.

## Adjust text boxes

### Reposition, scale, and rotate text boxes in Adobe Acrobat so your PDF pages read better and look cleaner.

Select Edit in the global bar.

Within the Edit pane, choose Text.

Click the text box you'd like to adjust.

A bounding box with selection handles wraps around the text.

To shift the text box, hover on its border until the Move pointer shows, then drag it where you want. Holding Shift keeps the movement on a straight line.

To resize it, hover over a circular handle until the Resize icon shows. Dragging a corner scales it proportionally, while a side handle changes only the width or height. Let go to lock in the new size.

Note

As you resize the text box, the text reflows inside it, though the font size stays the same.

To turn the text box, hover on the rotation handle until the Rotate icon shows, then grab it and drag to spin the box. Let go to fix the new angle.

## Set default fonts

### Define default and fallback fonts in Adobe Acrobat to keep text looking the same as you add or edit content in PDFs.

Acrobat lets you nominate particular fonts for both adding and editing text. Locking in the fonts you favor keeps the look uniform from one document to the next.

If the original font isn't on your system while you edit text in a PDF, Acrobat may fall back to another one. Defining your own fallback font gives you a say in how text appears whenever the original is unavailable.

### Windows

Select Menu > Preferences.

Under Preferences, choose Content Editing.

To choose which font new text starts in:

- Pick your choice from the Default font for Add Text dropdown menu.
- Set the size using the Font Size dropdown menu.

Note

Want the original behavior back? In the Default font for Add Text dropdown menu, pick Let Acrobat choose.

For editing, set a fallback by picking from the Fallback font for Editing dropdown menu.

Select OK.

### macOS

Select Acrobat > Preferences.

Under Preferences, choose Content Editing.

To choose which font new text starts in:

- Pick your choice from the Default font for Add Text dropdown menu.
- Set the size using the Font Size dropdown menu.

Note

Want the original behavior back? In the Default font for Add Text dropdown menu, pick Let Acrobat choose.

For editing, set a fallback by picking from the Fallback font for Editing dropdown menu.

Select OK.

- Start a fresh list by placing the cursor where it should begin and choosing Bullet list or Numbered list as appropriate.
- Turn a paragraph into a list item by selecting the text and choosing Bullet list or Numbered list as appropriate.
- Turn a list item back into a paragraph by selecting all the items and clicking the highlighted list type to clear the formatting.

## Check spellings and manage accepted words

Walk through how Adobe Acrobat's spell-checking lets you locate and fix mistakes in a PDF.

### Windows

### Run spell check

Choose Menu > Undo, Redo & more > Check spelling > Check Spelling in Comments and Fields.

When the dialog box opens, click Start so the scan begins.

As Acrobat flags problems, each one shows up beneath Word not found for you to review.

To pass over a suggested fix, click Ignore.

When you do want a replacement, pick an entry from the Suggestions list, and then:

- Click Change to fix that single occurrence.
- Click Change All to fix every occurrence of the word at once.

Click Done.

### Add or manage custom dictionary words

Should you want Acrobat to treat a particular spelling as valid going forward, store it in a custom dictionary. Entries there can likewise be edited or removed whenever you like.

Choose Menu > Undo, Redo & more > Check spelling > Edit Dictionary.

From the dialog box that opens, pick the dictionary you intend to modify.

Enter the word into the Entry field.

Click Add, Delete, or Change depending on what you need.

Click Done.

## Add images

### Walk through placing images into PDFs with Adobe Acrobat.

With the PDF open, click Edit on the global bar.

Within the Edit pane, click Image and pick one of these:

- Choose image: pulls in a picture stored on your machine.
- Generate image: builds an AI-created picture through Adobe Express.

Dropping images into a PDF gives you a way to strengthen its visual context.

Pictures placed in a PDF help reinforce the visual context around your content.

Should you go with the Choose image route:

- Pick the picture you want, click Open, and then click the spot on the PDF where it should sit.
- Drag the bounding box handles to size the picture however you need.
- Click and drag the picture to move it wherever you prefer.

Should you go with the Generate image route:

- When the dialog box opens, type out a description of the picture you have in mind.
- Selected the desired options for size, content type and style.
- Click Generate. From your description, Acrobat produces several image choices.
- Pick the one you like best from the choices and click Apply.
- Resize and reposition the picture however you need.

With the image selected, turn to the Edit pane to tweak scale, rotation, opacity, and the rest.

## Modify images

See how Adobe Acrobat lets you edit, swap out, and fine-tune the images inside a PDF.

With your PDF open, click Edit on the global bar.

Pick the image you intend to change.

Reach for any of these tools in the left pane to alter the chosen image:

- Flip vertical mirrors the image top-to-bottom across the horizontal axis.
- Flip horizontal mirrors the image left-to-right across the vertical axis.
- Rotate left turns the image 90° counterclockwise.
- Rotate right turns the image 90° clockwise.
- Crop image lets you drag the selection handles inward to trim the picture.
- Replace image swaps in a different picture from your device or one made with AI.
- Align objects lines up several objects along their edges.
- Arrange objects shifts objects forward or back through the stacking order.

Pick whichever image or object you want to change and reach for the tools beneath Adjust Objects.

Choose the object or image to modify, then work with the controls grouped under Adjust Objects.

Apply whatever changes you want with the tool you picked.

Click anywhere outside the image to commit the changes.

Tip

Click Edit image to launch the Adobe Express editor and reach the advanced editing tools inside Acrobat.
