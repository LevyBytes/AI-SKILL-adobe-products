Here is what the Adobe Express features in Acrobat get you:

- Improved visuals: Lean on design tools so your PDFs come across as more professional and engaging.

### Managing PDFs with Adobe Express integration

Choosing the Stylize this PDF option in Acrobat duplicates the open PDF and turns the copy into a brand-new Adobe Express file, which opens on a fresh browser tab. Meanwhile your source PDF stays open and within reach in Acrobat. Edits done in Express do not flow back into Acrobat on their own. Getting the revised file back means downloading it out of Adobe Express and uploading it into Acrobat. With the Edit or Generate image option, whatever you change in the PDF surfaces straight away in Acrobat.

### Turn off Adobe Express integration

By switching off the Adobe Express services on the product profile, admins can disable the integration for a whole group of users. Learn more about managing services in product profiles.

### Limitation on Fonts, Assets, and Branding Tools

Generating and editing images through the Adobe Express integration comes without restriction for Acrobat Pro and Standard users. That said, picking the Stylize option sends you over to Adobe Express, and there a handful of fonts, brand kits, and assets might call for an upgrade or sign-off from an enterprise admin. With Acrobat Studio, you get the whole of Adobe Express Premium, so the limits on fonts, brand kits, and premium assets fall away.

### Feature usage and reporting

For now, admins get no reports or analytics out of Acrobat about how people are putting Adobe Express features to use.

## Document properties and metadata overview

### Get to know the document properties and metadata that sharpen how your PDF files in Adobe Acrobat are organized, searched, and controlled.

Document properties carry key facts about a PDF file, such as metadata, security settings, and more. Getting a handle on these properties and managing them is what lets you organize and steer your PDF documents well.

### Document properties

Document properties are a group of attributes that characterize and sort a PDF file. They act as a fast reference for the important details of a PDF, sparing you from opening the file and reading through it. Among these properties are:

- Basic information (title, author, subject, keywords)
- Security settings
- Font information
- Initial view settings
- Custom properties

### Metadata

Think of metadata as a rich layer of information riding along with a document — it reveals where the file came from, what it holds, and how it behaves. Because it powers more capable searching, the kinds of detail it carries break down into these groups:

- Baseline fields, for example. when the file was first created and when it was last changed
- Richer schema sets, among them Dublin Core and IPTC
- Metadata tied to a particular application

### Importance of document properties and metadata

- Organization: keeps files tidy and quick to pull back up when needed
- Searchability: makes pinpointing a particular document far faster
- Workflow management: keeps tabs on revisions, sign-offs, and similar process details
- Rights management: bakes in copyright notices and permitted-use details
- Compliance: satisfies the rules a given industry imposes

### Types of document properties in Acrobat

- Description: carries the file's core identifying details
- Security: shows what encryption is applied and which permissions are set
- Fonts: enumerates every typeface the document draws on
- Initial View: dictates the way the file presents itself the moment it opens
- Custom: lets you define your own properties to cover particular requirements

### Metadata standards

To keep things consistent and workable across a mix of platforms and tools, Acrobat recognizes several established metadata formats. Among them you'll find:

- XMP (Extensible Metadata Platform)
- Dublin Core
- IPTC (International Press Telecommunications Council)

### Limitations and considerations

- Certain metadata arrives locked for editing, particularly when a different program generated it.
- Changing metadata leaves the actual page content untouched.
- For files holding sensitive material, stripping the metadata before you hand them off can be the safer move.
