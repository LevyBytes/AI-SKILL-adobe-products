# Introduction - Document Generation API for automating document workflows

A cloud-based web service, the [Document Generation API](../overview-what-is-document-generation/reference-index.md) lets you turn out high fidelity PDF and Word documents driven by dynamic data inputs. With it, you can blend your data(e.g. JSON file) into Word templates, producing dynamic documents — contracts and agreements, invoices, proposals, reports, forms, branded marketing documents and more.

Bring Document Generation API into any application by way of the [PDFServices SDK](../../pdf-services/sdk/reference-index.md) for Node.js, .Net, Python and Java.
