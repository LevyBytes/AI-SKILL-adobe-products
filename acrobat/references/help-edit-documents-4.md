## Add Bates numbering in Acrobat Pro

### Stamp Bates numbers onto legal paperwork so it stays easy to track, organize, and cite.

With Bates numbering, every page in a batch of legal paperwork receives its own distinct ID, which makes the set simpler to index and pull back up later. Prefixes or suffixes built from letters or numbers can be tacked on when you want extra clarity. Anything that isn't already a PDF gets turned into one ahead of the numbering pass. Files that are protected or encrypted, along with certain form types, fall outside what's handled.

With the PDF open, click Edit.

From the left pane, work through More > Bates numbering > Add.

Inside the Bates Numbering dialog box, hit Add files, then take your pick from these:

- Add Files: pick individual PDF files to bring in
- Add Folders: pull in whole folders of PDF files
- Add Open Files: draw from PDFs already open in Acrobat

Select Output Options to specify:

- where the output files should be written
- how the files get named
- any further settings you require

Select OK.

To rearrange which order the files run through Bates numbering:

- highlight a file, then use Move Up or Move Down
- click a column heading to sort, and click once more to flip the direction

Select OK.

Within the Add Header and Footer dialog box, click to set your cursor inside the box you want.

Select Insert Bates Number.

Configure the Bates numbering options:

- Number of Digits: choose how many digits apply (3-15). At the default of 6 digits the stamps come out as 000001, 000002, and so on
- Start Number: type the value the count begins from
- Prefix: enter any text that should sit ahead of the number
- Suffix: enter any text that should sit after the number

Tip

When a document runs long, bump up the digit count. Steer clear of the # character anywhere in the prefix or suffix.

Over in Bates Numbering Options, fill out the Number of Digits, Start Number, Prefix, and Suffix fields.

Over in Bates Numbering Options, fill out the Number of Digits, Start Number, Prefix, and Suffix fields.

Select OK.

## Rearrange or resize combined files

### Shuffle page order and tune file size while merging several documents into one PDF in Adobe Acrobat.

Once several files are merged into a PDF, there's often a need to shuffle the page order or trim the total size. Acrobat hands you tools to reorder pages without fuss and to compress the combined PDF.

### Rearrange combined files

From the top menu select All tools > Organize pages.

Within the window of page thumbnails, do any of the following to reshuffle the pages:

- To reorder pages: grab a page thumbnail and drag it somewhere new. A blue line marks the spot the page will drop into
- To move entire files: find the first page belonging to the file you're moving, then click and drag it to its new home. The rest of that file's pages travel with it.
- To delete pages: hover over the page and choose Delete, or hit Delete on your keyboard.
- To shift files higher or lower within the list: highlight the file or files, then click the Move up or Move down button.

### Resize the combined file

Choose Options, then pick whichever of these settings fits the converted file:

- Smaller File Size: shrinks oversized images down to screen resolution and squeezes them with low-quality JPEG. Handy for viewing onscreen, sending by email, and the Internet.
- Default File Size: turns out PDFs geared toward dependable on-screen reading and printing of business documents. Each listed PDF holds on to its starting file size and quality.
- Larger File Size: turns out PDFs geared toward output on desktop printers. It draws on the High-Quality Print conversion preset, and the listed PDFs hang on to their original file size and quality.

Note

Picking Larger File Size can push the finished PDF to a bigger size. Where source files are already PDFs, choosing Smaller File Size runs the Reduce File Size feature across them. That Reduce File Size step is skipped whenever Default File Size or Larger File Size is the choice.

Adjust the file size to whatever you need from inside the Options dialog box.

Within the Options dialog box, dial in the Adobe PDF Conversion Settings to taste, then select OK.

When that's set, select Combine from the upper-right.

## Embed PDFs in OLE container documents

### Place a PDF inside Word, PowerPoint, or any other OLE-friendly document so it stays right there for reference and access alongside your content.

Any host file that understands Object Linking and Embedding (OLE) — a Word document or an InDesign layout, for instance — can hold a PDF placed directly inside it. The host file in that arrangement is referred to as an OLE container document. Should the underlying PDF change later, OLE keeps the copy living inside the container current, so the container application redraws the embedded file to match whatever you altered.

### Embed a PDF from the OLE container application

Begin in the OLE container application — Microsoft Word is a typical choice.

Pick whichever command fits: Insert Object or Insert Hyperlink. In Word, for example, open the Insert tab and select Object.

When the Object dialog box opens, pick Adobe Acrobat Document and select OK.

Browse to the PDF you intend to embed, then select Open.

## PDF layers overview

See how PDF layers bring order to the dense content that design and technical programs produce.

Think of PDF layers as optional content groups that hold artwork, text, and annotations on distinct tiers within a single PDF. Because the content sits on separate levels, you can view, navigate, and print each portion on its own. Each layer can carry a starting visibility state, and Acrobat ships with controls for handling them — renaming, merging, flattening, and reworking their properties all included.

### Common uses for PDF layers

Files produced in programs like InDesign, AutoCAD, and Visio frequently carry PDF layers. When those programs export to layered PDF, visual, technical, or versioned material stays grouped so it can be shown a piece at a time.

### Work with PDF layers

For layered PDFs, Acrobat offers a number of broad capabilities, among them:

- Show or hide layers to control what appears in the document
- Change layer properties, including visibility, print settings, and export settings
- Reorder layers to change how content is visually stacked
- Import layers from other files or add new layers to existing documents
- Merge or flatten layers to make the combined content permanent
- Edit content associated with individual or shared layers
- Combine multiple-layered PDFs into one file while preserving layer groups

Any edit you make to layered content touches only the one layer that content sits on, while a visible selection reaches across every layer currently shown. Several layers can stay in play at once without disturbing how the layer structure is built.

Find out how Adobe Acrobat lets you reveal layers in a PDF and steer which ones stay visible.

By toggling content on and off, PDF layers make their way through dense documents far easier. The Layers panel is where you reveal or conceal layers, step through nested layer groups, and decide how each one renders on screen, in print, or during export.

### View PDF layers

With a PDF open in Acrobat, click Layers along the right-side panel; the Layers panel opens.

Tip

Where nested groups exist, open them up to reach the layers tucked inside a group.

Note

When a layer shows a lock, it serves an informational role and stays visible — you can't hide it.

### Control layer visibility

Bring up the Layers panel within your PDF.

Select Options in the Layers panel.

Pick whichever visibility control you need:

- List Layers For All Pages — Display every layer in the document.
- List Layers For Visible Pages — Display only layers on the pages currently in view.
- Reset To Initial Visibility — Restore the default visibility state.
- Apply Print Overrides — Preview the document using print-based visibility settings.
- Apply Export Overrides — Preview the document using export-based settings.
- Apply Layer Overrides — Display all layers regardless of individual settings.

For a temporary override, tick or untick the eye icon sitting next to whichever layer you choose.

When a visibility change needs to stick, adjust that layer’s Default state inside Layer Properties.

## Merge and flatten layers

See how merging and flattening layers can streamline the way a PDF is built.

Pull layer properties together, or fold visible content into one piece, to thin out a layered PDF. Merging draws the layers you pick into a single layer; flattening bakes every visible layer into one permanent page layer. Either route gets files ready for distribution or printing and trims away complexity.

Before you begin

Merging and flattening layers can't be undone. Stash a backup copy of your PDF before you combine anything.

### Merge selected layers

Click Layers in the right-side panel; the Layers panel appears.

Tip

In the Target layer to merge into pane, select the layer that should receive the combined content.

Select OK to complete the merge.

### Flatten all layers

Select Layers from the right-side panel to open the Layers panel.

In the Layers panel, choose Options, then Flatten Layers.

Flattening strips the entire layer structure out of your PDF. Whatever was visible at the moment you flattened stays behind; any hidden layer content is gone for good.
