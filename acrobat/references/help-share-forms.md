## Share PDF forms

### Hand off PDF forms through Adobe Acrobat, whether for feedback, for approval, or as view-only.

Acrobat's Share tool makes teamwork smoother by letting you hand out PDFs at whatever level of access fits. Bring people in to comment, to approve, or just to read the document. Tailor who gets in by tuning the link settings, and pass the file along over email, through outside apps, or with a link you generate.

Select Share from the global bar.

In the Share dialog box, choose one of the following options:

- Share for feedback - Recipients can add comments and annotations to the form.
- Share for approval - Recipients can approve or reject the form, typically used in review workflows.
- Share as View Only - Recipients can only view the form without making changes.

Note

Whichever option you pick, the Share tool drafts a tailored message for the people receiving it.

To change who can access the form, select Link Setting and then select one of the following options:

- Anyone on the internet with the link - Hands the file to whoever holds the link, anywhere online.
- Anyone in <your-organization> with the link - Keeps the file inside your organization, open only to its employees. Enterprise accounts have this picked for them by default.
- Invited people only – Opens the file to invited users and no one else.

Select Apply or Next as applicable.

In the Share dialog, choose one of the following sharing options:

- Invite people: Enter recipient email addresses, add a message or deadline if required, and select Invite.
- Share via third-party apps: Choose apps like Outlook, Gmail, Teams, or WhatsApp, and Acrobat will create a link and open the selected app.
- Create a shareable link: Select Create a link to share and then paste the link anywhere you want to share the form, such as in an email or messaging app.
- Send via email: Select Send a link or attach this file to an email and follow the onscreen instructions.

## Track shared PDF forms

### Follow distributed PDF forms in Acrobat: watch responses roll in and prod recipients with reminders.

On the desktop, Acrobat's Tracker tool keeps tabs on the PDF forms you've sent out, feeding you live updates as recipients reply. See who has already answered, nudge the ones who haven't, and pull in extra recipients when you need to, so tracking your forms stays painless and efficient.

From the Acrobat homepage, select See all tools > Prepare a form.

On the Prepare a form page, select Start from blank page > Create form.

From the left tools panel, select Options > Track status of forms sent.

In the Tracker dialog box, select Forms > Distributed to expand the list of distributed forms.

Select the form you want to track and choose one of the following actions:

- To view a spreadsheet with all form submission data, select View Responses.
- To change where response data is saved, select Edit file location.
- To view the original form, select Open Original Form.
- To send the form to additional people, select Add Recipients.
- To send a reminder or update to all form recipients, select Email All Recipients.
- To view or edit the original PDF form, select Open Original Form.

## Send PDF forms for e-signature

### Learn how to send PDF forms to recipients for e-signature.

Routing forms out for e-signature is a fast way to collect signatures that hold up legally on your PDF documents. Whatever device recipients are on, they can sign, and no Adobe account is required of them.

Open the PDF form and then select E-Sign > Request e-signatures.

In the dialog box that opens, enter the email addresses and names and modify the message if desired.

Note

Before you send, you can lay out a signing order, pick authentication methods, attach more files, schedule reminders, and put security options in place. Select More Options to set all of that up.

Select Specify where to sign.

To add recipients as CC, select Add Cc and then add the recipients’ details.

To add recipients as CC, select Add Cc and then add the recipients’ details.

In the RECIPIENTS section, select a recipient’s name, select a field type, and drag the field to the desired location in the document.

Once you add the required fields for all the recipients, select Send.

Note

Acrobat Sign sends you a confirmation email. An email goes out to the first person asking for their signature; once they sign, the document moves on to the next person, and so it goes down the line. A copy of the fully signed document lands with everyone, kept safe in Adobe cloud storage.

## Share certified copies of PDF forms

### Use Adobe Acrobat to produce and pass along tamper-proof certified copies of the PDF forms you've finished.

Finish filling out a PDF form in Acrobat and you can pass along a certified copy that's locked against changes. That way the completed form goes out safely while its integrity stays intact.

Open the completed PDF form and select E-Sign from the global bar.

Select Save a certified copy from the left pane.

Note

Should you be asked to sign in to your Adobe account, select Next, type in your account credentials, and select Continue. Doing so keeps your signed agreements protected.

A certified copy of the form is generated, and a certificate banner shows up.

View document certification details and file activity in Acrobat to verify authenticity and track actions on signed contracts.

View document certification details and file activity in Acrobat to verify authenticity and track actions on signed contracts.

From the File information pane that opens, choose one of the following options:

- Get a shareable link - Creates a link you can share for others to view the certified copy
- Send a copy - Allows you to email the certified copy to recipients
- Save a local copy - Saves the certified copy to your computer

Walk through the prompts to finish whichever sharing route you chose.

## Print PDF forms

### Print interactive as well as flat PDF forms from Acrobat on desktop, carrying along whatever was typed into the form fields.

Select Print this file from the upper-right corner.

In the Print dialog box, choose your desired printer.

Open the Comments & Forms dropdown menu and pick one of these:

- Document: Outputs the form together with whatever data was filled in, while leaving out comments and stamps.
- Document and Markups: Outputs the form, the filled-in data, and the comments too.
- Document and Stamps: Outputs the form, the filled-in data, and any stamps, though not the comments.
- Form Fields only: Outputs just the data that was entered, with no form underneath. Handy for keeping a record of only what was typed into interactive forms.

Selecting Summarize Comments will also fold a rundown of the comments into the printed output.

Tweak whatever other print settings you need.
