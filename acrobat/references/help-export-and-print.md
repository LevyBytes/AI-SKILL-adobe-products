## Compress PDFs online

### Shrink a PDF's file size on the web with Acrobat's Compress tool.

Right in the browser, Acrobat lets you trim how much space a PDF takes up without sacrificing its quality, so the document becomes simpler to send around and to keep on hand. What the compress tool does under the hood is strip out embedded fonts, squeeze the images down, and clear away anything the file doesn't need.

From the Acrobat on the web homepage, choose Convert > Compress a PDF.

When the dialog appears, pick where your file lives from the menu at the top, point to the PDF you'd like to shrink, and then choose Continue.

Need more than one file? Choose Add files and pick whichever others you want to bring in.

Want several documents compressed in one pass? Use the Add files option to bring in more.

Pick whatever compression level suits you, then choose Compress.

What comes out is named filename_compressed, and it lands in Adobe cloud storage on its own.

Note

As soon as compression finishes, a notification pops up offering to download the result. Choose Donwload to pull the file down.

## Export PDF overview

### Get familiar with the file types you can target and a few handy tips for exporting PDFs in Adobe Acrobat on the web.

Converting a PDF into something editable — DOCX, XLS, or RTF — is straightforward with the Export a PDF tool in the browser version of Acrobat. Because it holds onto the document's original layout and formatting, you save time and move between file types cleanly, which keeps your work flowing.

### PDF conversion limit

Export a PDF supports conversion of PDF files up to 100MB.

### File storage and reprocessing

After a file has been turned into a new format, its original copy is not kept. For more, see Adobe's general terms of use along with the additional terms covering Acrobat.com.

### Supported PDF types

Most PDFs, scanned documents included, will convert through the Export a PDF tool. That said, these particular kinds of PDF won't go through:

- A PDF locked behind a password before it will open
- A PDF whose permissions block printing, copying, or any change to its content
- PDF Portfolios
- Files generated from Adobe Illustrator

### OCR support

To handle assorted inputs — scanned pages, PDF files, or images — the Export a PDF tool runs OCR and turns them into data you can edit and search.

### Conversion quality

During an export to another format, Acrobat carries the source PDF's quality through to the result.

### Handling of comments

Any comments end up as text boxes inside the document you've converted.

### Document updates

An open file can't be overwritten by the Export a PDF tool, so close the original copy first and then convert.

## Export PDFs

### Walk through turning PDF files into other formats with Acrobat on the web.

Through the Export a PDF tool in the browser edition of Acrobat, your PDF files can be exported into any of these formats:

- Microsoft Word (.doc, .docx, .rtf)
- Microsoft Excel (.xlsx)
- Microsoft PowerPoint (.ppt)
- Images (.jpg, .png, .tiff)

Note

Turning a PDF into a PPT file calls for an Acrobat PDF Pack subscription. To upgrade your account or handle your subscription, select the Profile icon and then select My Plan.

For a document format, pick whichever language you need from the Document language dropdown menu.

## Supported languages for OCR

A rundown of which languages Adobe Acrobat Export PDF can handle when running OCR.

### OCR language selection

Documents written in a non-Latin script — Japanese, Chinese, or Korean, for instance — require you to pick the matching language ahead of running OCR. Skip that step and the OCR engine has no reliable way to interpret or convert the characters. The setting lives under Recognize text in the Scan & OCR pane: choose In this file, then pick the language that applies.
