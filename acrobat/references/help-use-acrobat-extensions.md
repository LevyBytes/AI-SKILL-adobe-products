## Edit and organize PDFs in ChatGPT

See how to put Adobe Acrobat for ChatGPT to work finishing PDF workflows.

Right within the chat interface, Adobe Acrobat for ChatGPT handles efficient PDF editing and organization. By letting you build and edit PDFs, lift data out of scans, and merge or compress files for easy sharing, the integration keeps workflows moving.

Before you begin

Confirm that Adobe Acrobat is hooked up to ChatGPT. Connecting goes like this: head to Adobe Acrobat for ChatGPT, select Connect, sign in with your Acrobat credentials, select Continue, and that's it.

Should that link fail, open ChatGPT, select Apps and search for Adobe Acrobat.

In the main chat box, select > More > Adobe Acrobat.

Kick off your chat request with “Adobe Acrobat” and then the task you're after, for example:

- Adobe Acrobat edit this PDF.
- Adobe Acrobat create a single job-application PDF by merging my resume, cover letter, and references.
- Adobe Acrobat extract key financial metrics from this scanned quarterly report.
- Adobe Acrobat compress my file to share over email.

Drop in the PDFs you need through the Asset upload interface and select Continue.

Lean on the widget to carry out your next step:

- Merge files: Rearrange them in the widget.
- Edit content: Select Edit to open the document in edit mode and make changes.
- Extract data: Review the OCR-generated summary or table and confirm accuracy.
- Combine & compress: Check the merged, compact PDF before saving or sharing.

## Access Acrobat admin settings

### Steps for opening the Acrobat admin settings from within Microsoft Teams.

### For Adobe admins

Open the Admin configuration portal.

Use your Adobe admin credentials to sign in.

### For Microsoft 365 or Microsoft Teams admins

Open Acrobat for Microsoft Teams.

In the upper-right corner, choose your profile icon, then pick Admin settings.

Select Sign in as Microsoft admin.

Caution

Should the Microsoft Teams admin not hold the rights needed to grant access to Adobe Admin, a "Need admin approval" message shows up. Two ways out: forward the authorization link to your Microsoft 365 or Teams Global admin so they can approve it, or have that Global admin change the account settings to allow authorization. The User and admin consent in Microsoft Entra ID page covers this further.

### For Non-admins

For any configuration change, non-admins first need the Microsoft admin's consent.

Choose Sign in and request access, then sign in using your Microsoft 365 credentials.

Choose Create request link, followed by Copy link.

Pass the link you copied along to your Microsoft 365 or Teams admin.

That Microsoft 365 or Teams admin then has to open the link and choose Authorize access.

After it's authorized, head to the Admin configuration page to sign in and set your preferences.

### Steps to follow if the request link expires

Once the link lapses, a Request link expired message reaches the Microsoft 365 or Teams admin.

Rebuilding the request link means going to the Adobe Acrobat integration settings page and choosing Create request link.

With the fresh link in hand, pass it to the Microsoft 365 or Teams admin.

The Acrobat admin configuration portal is now open to you, and customizing Acrobat for Microsoft integrations becomes possible.

Note

Whatever you change in the Admin portal rolls out on its own to Acrobat throughout Microsoft Teams, Outlook, OneDrive, SharePoint, and the Microsoft 365 app, reaching every user.

## Acrobat for Microsoft Teams overview

### Understand what Acrobat for Microsoft Teams delivers, plus the permissions its integration depends on.

A full set of PDF capabilities arrives with Adobe Acrobat for Microsoft Teams, which keeps PDF work flowing without leaving Teams. Through this built-in PDF solution you can:

- Open and read PDFs on the web by way of Adobe's modern browser-based viewer.
- Lean on the AI Assistant feature to make sense of dense PDF documents fast, hand off repetitive work, and draft content that lands.
- Convert PDFs into formats you can edit — Word, Excel, PowerPoint, or RTF — while the source fonts, formatting, and layouts stay intact, whether you work from mobile or the web.
- Build PDFs that preserve fonts, formatting, and layouts, and lock them down with password protection when needed.
- Rework PDFs by changing text and images, shuffling page order, or splitting one document into several PDFs.
- Combine separate documents and PDFs into one file, and shrink the result when you want easier sharing or storage.
- Work together on PDF documents, annotating them with sticky notes, highlights, and freehand drawings so the message gets across.
- Complete and sign PDF forms.
- Keep things accessible through screen reader support, keyboard navigation, and High Contrast modes that assist anyone with limited vision.
- Tailor how the viewer looks by switching Acrobat's theme to light, dark, or whatever the Microsoft Teams preference is set to.

### Required permissions for the Acrobat app

Delegated access is how the Acrobat app reaches your personal data or resources. These are the permissions it asks for:

- User.Read: lets the user sign in and pulls their profile together with basic details about the company.
- Files.Read.All: covers viewing and previewing whichever files the user picks.
- Files.ReadWrite.All: handles saving and writing files a user comments on, plus tasks such as organizing, compressing, and exporting.
- Team.ReadBasic.All: reads back the names of teams along with their descriptions.
- User.ReadBasic.All: opens up the basic profile properties belonging to other users so @mentioning works.

Note

Whenever a PDF is shared inside Microsoft Teams, it lives in your OneDrive or SharePoint accounts. The viewing, commenting, and searching all run right on your own machine, and any edits you make get written back to OneDrive or SharePoint. The one exception is creation, organizing, combining, or exporting: for those, the file travels briefly to Adobe cloud servers to be processed, stays encrypted the entire time, and is removed within 24 hours.

### Supported browsers

Acrobat for Microsoft Teams runs on every current browser — Chrome, Firefox, Safari, and Microsoft Edge among them.

## AI-powered meeting summaries and insights

### See how meeting summaries and insights get produced with the Acrobat AI Assistant and Generative Summary tools.

Ask a question about what a PDF contains and the Acrobat AI Assistant tool returns thorough answers in short order. It ties its replies back to the text and data tables sitting inside the document, and it proposes follow-up questions worth asking.

Document outlines come from the Generative Summary tool, which lays out headings alongside summaries that call out the main points. To turn around summaries faster, the feature works through PDF content in pieces while surfacing the key takeaways.

For specifics on how to use it, along with the guidelines and limitations, see Adobe Acrobat's Generative AI guide.

Note

Getting more out of a meeting with AI Assistant starts before the meeting itself: line up the participants and turn on recording/transcription. Once it wraps, a notification lands along with suggested questions that give you a starting point. From there, the AI Assistant prompt lets you:

- Get useful insights: Ask the AI assistant to draft meeting notes, lay out the concerns that came up, clarify what the meeting set out to achieve, and pin down the next steps.

## Resolve issues in Acrobat for Microsoft Teams

### Work through how to fix problems in Acrobat for Microsoft Teams.

### Error while pinning a file as a tab

Issue: Pinning a large file as a tab can throw the error "We couldn't save your tab settings. Please try again".

Solution: The cause is Acrobat holding on while the file finishes uploading. Keep choosing Save whenever it's available until the upload to the channel completes.

### Sharing files errors

Issue: Errors can crop up during any of these sharing flows:

- Choosing Share a copy to pass a file along.
- Picking out a file within the channel you're in.
- Moving between folders inside the file explorer.
- Loading the files for the channel.

Solution: A broken Microsoft® Graph API is behind these errors. Clear it by reloading the page, or by dismissing the dialog box and running the operation again.

### IMS login screen not visible

Issue: The IMS login screen won't appear when you're in the Adobe Acrobat app.

Solution: Switch off the browser's pop-up blocker so the IMS login screen can show.

### Admin approval required

Issue: The error "Need admin approval" shows up while you use the Adobe Acrobat app.

Solution: Ask your organization or tenant admin to assign you the rights you need.

### Comments not visible in a shared file

Issue: Comments you added to a shared file stay hidden once the file size goes past 50MB.

Solution: Keep the file under 50MB for shared commenting to work. Past that size, comments neither persist in the document nor appear in the downloaded copy.

## Customize Acrobat for Microsoft integrations

### See how Acrobat settings let you tailor Acrobat for Microsoft Teams, SharePoint, OneDrive, and Microsoft 365.

Provided your organization holds an active Adobe subscription, the Admin configuration portal is where you tailor how Acrobat behaves across Microsoft integrations.

These are the settings it lets you adjust:

- Disable paid tools
- Allow unified sign-in for all users
- Allow unified sign-in with company or school account
- Hide social login options
- Prevent users from creating an account from the sign-in screen
- Suppress welcome bot notification (Microsoft Teams only)
- Add a custom link to the company’s internal licensing portal
- Enable transient processing
- Customize GenAI touchpoints for anonymous and free users
- Choose if the Bot notifies users when a transcript is ready (Microsoft Teams only)

Note

Whatever you change in the Admin portal rolls out on its own to Acrobat everywhere — Microsoft Teams, Outlook, OneDrive, SharePoint, and the Microsoft 365 app — for every user.

### Disable paid tools

Switching on the Disable paid tools setting greys out the paid tools in the Acrobat viewer for Microsoft Teams, SharePoint, or OneDrive whenever a user is free or not signed in. The paid tools drop off the Acrobat Home page too.

Leave the setting off and every user sees the paid tools no matter their sign-in status or account type. People who aren't signed in get a prompt to log in, while those on free accounts are told to request paid tool access from the organization admin.

### Allow unified sign-in for all users

Turning on the Require users to sign in with the same email address used to sign into Microsoft option means the Microsoft sign-in email fills in automatically and can't be edited on the sign-in screen once a non-signed-in user selects Sign in. That keeps users from getting into Acrobat for Microsoft integrations with personal credentials.

### Require users to sign in with their company or school account

Turning this setting on forces anyone whose email is tied to both a personal and a work/school account onto the work/school account at sign-in; the personal-account choice is removed, so it is no longer an option.

### Hide social login options

Switching on the Hide social login options setting strips the Google, Facebook, Apple, and Microsoft buttons out of the sign-in flow, so none of those social options show up while signing in.

### Suppress welcome bot notification (Microsoft Teams only)

As things stand, installing the Acrobat app triggers the Acrobat bot to push a chat message to each end user automatically. Switching on the Suppress welcome not notification setting stops that message from going out.

- In the All tools pane in the Acrobat PDF viewer
- In the Acrobat Home tab

### Enable transient processing

Switch on the Enable transient processing when PDF services are turned off (Microsoft Teams only) setting and paid Acrobat users keep access to PDF tools inside Microsoft Teams even when PDF services have been disabled in the Adobe Admin Console. That access runs through transient processing on Adobe Document Cloud servers, and the files involved are removed after 24 hours.

Where PDF services are on, transient processing is already running for Acrobat in Microsoft Teams. Where PDF services are off:

- For existing users: the default leaves transient processing switched off.
- For new users (effective 20-01-2025): the default has transient processing switched on.

### Customize GenAI touchpoints

GenAI touchpoints can be switched on or off for users who haven't signed in as well as for anyone lacking GenAI entitlements. Turn them off and, for those users, the Generative Summary and AI Assistant touchpoints show as greyed out in the Acrobat viewer with the feature out of reach.

### Choose if the Bot notifies users when a transcript is ready (Microsoft Teams only)

It's up to you whether the bot pings your users once a transcript is ready. Leave the Disable meeting transcript notification toggle switched off and, when a scheduled recorded meeting wraps up, the meeting organizer gets a message from the Acrobat app. Picking any of the offered questions lets users spin up a meeting summary with little effort. For this to work, users need notifications turned on for the Acrobat for Microsoft Teams app. When GenAI touchpoints are off yet this feature stays on, only users who have GenAI access will receive the notification.
