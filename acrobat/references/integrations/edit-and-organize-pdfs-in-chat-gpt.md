# Edit and organize PDFs in ChatGPT

See how to put Adobe Acrobat for ChatGPT to work finishing PDF workflows.

Right within the chat interface, Adobe Acrobat for ChatGPT handles efficient PDF editing and organization. By letting you build and edit PDFs, lift data out of scans, and merge or compress files for easy sharing, the integration keeps workflows moving.

Before you begin

Confirm that Adobe Acrobat is hooked up to ChatGPT. Connecting goes like this: head to Adobe Acrobat for ChatGPT, select Connect, sign in with your Acrobat credentials, select Continue, and that's it.

Should that link fail, open ChatGPT, select Apps and search for Adobe Acrobat.

In the main chat box, select > More > Adobe Acrobat.

Kick off your chat request with “Adobe Acrobat” and then the task you're after, for example:

- Adobe Acrobat edit this PDF.
- Adobe Acrobat create a single job-application PDF by merging my resume, cover letter, and references.
- Adobe Acrobat extract key financial metrics from this scanned quarterly report.
- Adobe Acrobat compress my file to share over email.

Drop in the PDFs you need through the Asset upload interface and select Continue.

Lean on the widget to carry out your next step:

- Merge files: Rearrange them in the widget.
- Edit content: Select Edit to open the document in edit mode and make changes.
- Extract data: Review the OCR-generated summary or table and confirm accuracy.
- Combine & compress: Check the merged, compact PDF before saving or sharing.

Take a look at the results and either confirm the action or select Save.

Note

Whatever you create or edit through Adobe Acrobat in ChatGPT doesn't land in your Adobe account on its own. To keep your work, select Open in Acrobat and, from inside Adobe Acrobat, save the file to Adobe cloud storage.
