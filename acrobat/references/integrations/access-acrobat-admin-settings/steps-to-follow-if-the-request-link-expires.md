# Steps to follow if the request link expires

Once the link lapses, a Request link expired message reaches the Microsoft 365 or Teams admin.

Rebuilding the request link means going to the Adobe Acrobat integration settings page and choosing Create request link.

With the fresh link in hand, pass it to the Microsoft 365 or Teams admin.

The Acrobat admin configuration portal is now open to you, and customizing Acrobat for Microsoft integrations becomes possible.

Note

Whatever you change in the Admin portal rolls out on its own to Acrobat throughout Microsoft Teams, Outlook, OneDrive, SharePoint, and the Microsoft 365 app, reaching every user.
