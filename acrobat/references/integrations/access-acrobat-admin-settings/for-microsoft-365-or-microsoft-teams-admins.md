# For Microsoft 365 or Microsoft Teams admins

Open Acrobat for Microsoft Teams.

In the upper-right corner, choose your profile icon, then pick Admin settings.

Select Sign in as Microsoft admin.

Caution

Should the Microsoft Teams admin not hold the rights needed to grant access to Adobe Admin, a "Need admin approval" message shows up. Two ways out: forward the authorization link to your Microsoft 365 or Teams Global admin so they can approve it, or have that Global admin change the account settings to allow authorization. The User and admin consent in Microsoft Entra ID page covers this further.
