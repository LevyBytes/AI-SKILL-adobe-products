# Enable transient processing

Switch on the Enable transient processing when PDF services are turned off (Microsoft Teams only) setting and paid Acrobat users keep access to PDF tools inside Microsoft Teams even when PDF services have been disabled in the Adobe Admin Console. That access runs through transient processing on Adobe Document Cloud servers, and the files involved are removed after 24 hours.

Where PDF services are on, transient processing is already running for Acrobat in Microsoft Teams. Where PDF services are off:

- For existing users: the default leaves transient processing switched off.
- For new users (effective 20-01-2025): the default has transient processing switched on.
