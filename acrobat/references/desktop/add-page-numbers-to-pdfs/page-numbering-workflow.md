# Number your PDF pages through Adobe Acrobat's header and footer tools.

Tailoring both the style and the position of page numbers helps readers move through a document and makes its layout easier to follow.

With the PDF open, head to Edit on the global bar.

From the left pane, pick Header and footer > Add.

Once the dialog box opens, select Page Number and Date Format.

Note

Should the file already carry a header or footer, a prompt appears asking whether to swap in the new one or layer an additional one on top. Pick whichever choice suits what you're after.

The Page Number and Date Format dialog is where you control the look of page numbers and dates within headers and footers, covering the format style and the value they begin at.

Back in the dialog box, choose the page number format you want, fix the starting page number, and confirm with OK.

Click into whichever header or footer field matches the spot where the number should land.

Select Insert Page Number.

To add the current date, select Insert Date.

The Font section lets you change the typeface, point size, and color used for the numbering.

Check the result through the Preview section.

Select OK.
