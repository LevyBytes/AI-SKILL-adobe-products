# Merge form data files into a spreadsheet

Gathering data out of forms that haven't landed in a data set yet runs as follows:

In the upper-left global bar, choose All tools and then Prepare a form.

From the Prepare a form panel, select Options > Merge data files into spreadsheet.

In the Export Data From Multiple Forms dialog box, select Add Files.

Once the Select file Containing Form Data dialog box appears, set a file format under the File Of Type option — either Acrobat Form Data Files or All Files. Then locate the form files you'd like folded into the spreadsheet, select them, and select Open.

Got form data files elsewhere? Run that last step again for each location.

Select Export, settle on a folder and filename for the spreadsheet, and select Save.

When the Export Progress dialog box appears, select View file now to bring up the spreadsheet, or select Close dialog to head back to Acrobat.

Note

When the returned forms already live in a response file, the quicker route to a spreadsheet is the Export Data button in the left navigation panel of the PDF Portfolio response file.
