# Use forms tracker

Tracker is the tool for staying on top of forms you've sent out or gotten back. Through it you can follow responses, change where the response file lives, bring in more recipients, email everyone at once, and read the form responses.

Starting at the Acrobat Home view, pick All tools under Suggested tools, then over in the Edit section Select Edit a PDF.

(Windows) Select the hamburger menu in the upper left. Then select Form Options > Track

(macOS) From the upper left, Select View > Tracker.

From the Tracker dialog box, expand Forms in the left navigation panel.

Pick a form, then do one of these:

To see every response, select View responses.

To point the response file somewhere else, under Responses File Location, select Edit file location.

To pull up the original form, select Open original form.

To bring in additional recipients, select Add recipients.
