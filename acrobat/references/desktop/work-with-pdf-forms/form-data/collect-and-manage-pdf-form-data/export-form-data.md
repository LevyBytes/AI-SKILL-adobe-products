# Export form data

Want a completed PDF form's contents stored as a data file in a different format? Here's the sequence:

Inside Acrobat, pull up the form you've already filled out.

Off the All tools menu, choose Prepare a form; in the left panel that appears, select Options > Export data.

When the Save As dialog box opens, pick which type you'd like the form data saved as — your choices are FDF, XFDF, XML, or TXT. After that, set a location and filename, and select Save.

Which file formats show up depends on the kind of PDF form, and that traces back to how the form was built.
