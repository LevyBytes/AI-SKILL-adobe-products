# PDF forms overview

Get to know the main capabilities and the kinds of PDF forms that Adobe Acrobat lets you build and handle.

With a PDF form, you type your information straight into the fields set aside for it. Where an ordinary PDF mostly exists to be read, a PDF form gathers data by way of interactive parts—text fields, checkboxes, radio buttons, and dropdown menus among them. You can get to such forms across the web or through email.
