# Duplicate a form field across multiple pages

Open All tools > Prepare a form.

Right-click the field and pick Duplicate Across Pages.

When the dialog appears, pick whichever of these applies:

- Choose All and then OK to place the field on all pages.
- Choose From, type the first and last page numbers, then OK to place the field across only that page span.

Leaving the field name at its default makes each copy fill in automatically with whatever data goes into the source field.

Give the field a new name instead when each copy should hold its own separate information.
