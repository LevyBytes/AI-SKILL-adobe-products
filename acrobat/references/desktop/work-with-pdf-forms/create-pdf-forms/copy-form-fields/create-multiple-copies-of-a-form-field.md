# Create multiple copies of a form field

Open All tools > Prepare a form.

Find the field you'd like to duplicate, right-click it, and pick Create Multiple Copies.

When the dialog opens, turn on Preview so both the source field and its duplicates are shown on the form as you work.

Set how many duplicates you want with the Copy selected fields down and Copy selected fields across options.

Nudge the duplicates into place with the Up, Down, Left, and Right buttons.

Confirm with OK to generate the copies.

Leaving the field name at its default makes each copy fill in automatically with whatever data goes into the source field.

Give the field a new name instead when each copy should hold its own separate information.
