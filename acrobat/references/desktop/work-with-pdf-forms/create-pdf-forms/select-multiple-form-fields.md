# Select multiple form fields

Grab several form fields at once in Adobe Acrobat when you need to duplicate them, line them up, or even out their spacing.

Start by opening a fillable form.

Open All tools > Prepare a form.

Pick whichever of these suits what you're after:

- Hold Ctrl (Windows) or Command (macOS) and click each field to pick them one by one.
- Click the first field, then Shift-click the last one to grab everything in that span.
- Right-click any field and choose Select All from the context menu to grab them all at once.
- Drag the Select tool around a region to capture the fields sitting inside it.

Drop fields from your selection by Ctrl-clicking (Windows) or Command-clicking (macOS) the ones you no longer want.
