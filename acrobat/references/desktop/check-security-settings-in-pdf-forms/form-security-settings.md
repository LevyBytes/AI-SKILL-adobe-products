# Learn how to verify security settings for PDF forms in Adobe Acrobat.

Go to Menu > Document Properties (Windows) or File > Document properties (macOS).

In the Document Properties dialog box, open the Security tab.

Look over what's currently set under Document Restrictions Summary.

Adding or changing a form's security settings is how you decide who's allowed to edit, complete, or sign it.

Confirm with OK.

Note

Changing the form's security settings requires the permission password from whoever created the document. From the Security Method dropdown menu pick Password settings, type the permission password, and tune the security options as needed.
