# Adjust PDF to PS and EPS conversion settings

From the global bar, choose Convert.

In the left pane, pick Other format, then choose PS or EPS in the dropdown menu.

To change the export preferences, choose Settings.

Tune these settings to suit your output:

- Printer Description File: Pick a PPD, or go with Device Independent when you need composite PostScript.
- ASCII or Binary: Sets the output encoding. Although Binary yields smaller files, some workflows can't handle it.
- PostScript: Pick the level of the PostScript language.
- Font Inclusion: Decide which fonts get embedded in the PostScript file.
- Include Comments: Keeps any comments in the file that's produced.
- Convert TrueType to Type 1: Turns TrueType fonts into Type 1 within the output.
- Include Preview: Generates a preview, though this option is unavailable when the output is PS.
- Page Range: Sets which pages get exported.

Choose OK.
