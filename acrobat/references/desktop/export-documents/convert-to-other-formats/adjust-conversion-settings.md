# Adjust conversion settings

From the global bar, select Convert.

In the left pane select Microsoft Excel, then pick XML or XLSX from the dropdown menu.

To change the export preferences, select Settings.

Tune these settings however you need:

- Excel Workbook Settings: Choose whether a worksheet is built per table, per page, or for the whole document.
- Numeric Settings: Define which characters serve as the decimal and thousands separators for numeric data.
- Text Recognition Settings: Have text images recognized when required, and set the language.
- Restore Defaults: Reinstate the default conversion settings.

Select OK.


From the global bar, choose Convert.

In the left pane, pick Other formats, then choose HTML in the dropdown menu.

To change the export preferences, choose Settings.

When the dialog box appears, tune these settings to suit your needs:

- File and Navigation Pane Settings: Decide whether one HTML file or several linked files get created, and layer in navigation that follows the document's structure.
- Content Settings: Control whether images are kept and whether headers and footers get stripped from the HTML that results.
- Text Recognition Settings: Pull text out of images and pick the language so recognition stays accurate.
- Restore Defaults: Reverts to the default settings for HTML conversion.

Choose OK.
