# macOS

Open Acrobat > Preferences.

Under Categories, choose Signatures.

From the Identities & Trusted Certificates option, choose More.

Choose Digital IDs, choose Roaming ID Accounts, then choose the add account icon.

To start a fresh roaming ID account, choose Add ID and key in the details of your roaming ID server.

Type the roaming ID server URL plus a description into the dialog box, then choose Next.

Enter your username and password, or work through the steps to set up an account.

Choose Next, then choose Finish.
