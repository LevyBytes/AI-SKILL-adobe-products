# Windows

With your file open in Word, Excel, or PowerPoint

Up at the top, head to the Acrobat tab.

Select Create PDF.


Inside the program that made the file, go to File > Print.

Open the Printer menu and pick Adobe PDF.

For your printer choice, the Printer menu is where you'd set Adobe PDF.

To set or tailor a default, choose Printer Properties (or, in some cases, Preferences).

Note

A handful of applications make you pick Setup inside the Print dialog box first to reveal the printer list, after which you choose Properties or Preferences.

Select Print.

When the dialog box appears, give your PDF file a name and a place to live.

Note

On Windows, lean on PDFMaker for Microsoft Office documents when you want bookmarks and hyperlinks, since the Adobe PDF printer leaves those out.


Choose Menu > Create > Blank page.

For fixed text and pictures, open the Edit menu at the top and then do either of the following:

- Pick Text when you want to enter non-editable wording for labels, directions, and the like.
- Pick Image to drop in logos, artwork, or any other graphic.

Form fields come from the Prepare a form entry in the left pane: pick it, select a field type, drag the field onto the page, then double-click it to adjust its settings. Step-by-step coverage lives under create PDF forms from scratch.

Finish by choosing Menu > Save as, picking where the file should go, typing a name, and clicking Save.
