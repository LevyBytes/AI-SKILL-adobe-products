# Web page conversion settings

Tailor the way web pages become PDFs — layout, encoding, color handling, and multimedia all included.

From inside Acrobat, reach these controls by going to All tools > Create a PDF > Web page and then choosing Advanced settings, which exposes the conversion and layout options.

A faster route is to open the Adobe Acrobat extension in your browser and pick Conversion settings, which surfaces the most-used options.
