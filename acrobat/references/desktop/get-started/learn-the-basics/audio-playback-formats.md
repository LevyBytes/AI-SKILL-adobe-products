# Audio playback formats

For audio that plays back directly inside both Acrobat and Acrobat Reader, the formats below are the ones to use.


| Format | Direct placement without transcoding | Legacy placement |
| --- | --- | --- |
| mp3 Audio (.MP3) | Yes | Yes |
| Audio Waveform (.WAV) | No | Yes |
| Audio Interchange (.AIF, .AIFF) | No | Yes |
| MPEG Audio (.MPA, .M4A) | No | Yes |
| Windows Media Audio (.WMA) | No | Yes |

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/file-formats.html).
