# Supported languages

These are the languages in which Acrobat on desktop ships:


- English
- Danish
- Turkish
- French
- Finnish
- Hungarian
- German
- Norwegian
- Ukrainian
- Japanese
- Simplified Chinese
- Slovak*
- Italian
- Traditional Chinese
- Slovenian*
- Spanish
- Korean
- North African French #
- Dutch
- Czech
- Middle Eastern Hebrew §
- Brazilian Portuguese
- Polish
- Middle Eastern Arabic
- Swedish
- Russian

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements.html).
- Available on Windows only.

The North African French (Français) version is a French application user interface with Arabic/Hebrew right-to-left language support enabled by default.

§ With Arabic and Hebrew, the interface text stays in English while right-to-left support for Arabic and Hebrew is switched on out of the box.

Which languages you get can differ depending on the Acrobat features and services involved. Learn more about Acrobat language tiers.
