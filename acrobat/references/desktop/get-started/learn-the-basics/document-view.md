# Document view

Each fresh document you open in Acrobat lands on its own tab across the top bar. Selecting a document brings up the Quick Action toolbar together with the right panel.

Open a document in Acrobat to access the All Tools menu, Quick Action toolbar, and the right panel.

A. Home page B. Quick action toolbar C. Print D. Share E. Generative summary tool F. Comments tool G. Bookmark tool H. Page thumbnails tool I. Articles tool J. Rotate page K. Page display settings L. Zoom in/out
