# Video playback formats

The video file types listed here can be inserted into documents using Acrobat Pro. Within Acrobat Reader, these formats are limited to playback only.


| Format | Transcoding | URL streaming | Direct placement without transcoding | Legacy placement |
| --- | --- | --- | --- | --- |
| Shockwave Flash (.SWF) | N/A | No | No | No |
| QuickTime Movie (.MOV) | Yes | Yes | Yes, if H.264 encoded | Yes |
| MPEG (.MP4, .M4V) | Yes | Yes | Yes, if H.264 encoded | Yes (except .m4v) |
| 3GPP Movie (.3GP, .3G2) | Yes | Yes | Yes, if H.264 encoded | No |

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/file-formats.html).
