# Windows

What you need to get Acrobat Studio, Acrobat Pro, and Acrobat Standard running on Windows:


| Component | Requirement |
| --- | --- |
| Processor | Intel or AMD processor (1.5GHz or faster) |
| Operating system | Windows 11 (64-bit) Windows 10 (64-bit) v1809 or later Windows Server 2022 Windows Server 2019 (64-bit) Windows Server 2016 (64-bit) |
| RAM | 2GB of RAM |
| Hard disk space | 4.5GB of available hard-disk space |
| Monitor resolution | 1024x768 screen resolution |
| Graphics card | Video hardware acceleration (optional) |

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements.html).


What you need in place to put Acrobat Pro 2020 and Acrobat Standard 2020 on Windows:


| Component | Requirement |
| --- | --- |
| Processor | Intel or AMD processor, 1.5GHz or faster processor |
| Operating system | Windows Server 2012 (64-bit), 2012 R2 (64-bit), 2016 (64-bit), or 2019 (64-bit) Windows 8, 8.1 (32-bit and 64-bit) Windows 10 version 1903 or later (32-bit and 64-bit) Windows 11 (64-bit) |
| RAM | 2GB of RAM |
| Hard disk space | 4.5GB of available hard-disk space |
| Monitor resolution | 1024x768 screen resolution |
| Browser | Internet Explorer 11, Firefox (ESR), or Chrome |
| Graphics card | Video hardware acceleration (optional) |

Source: [Adobe 2020 requirements](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements-acrobat-2020.html).


What you need in place to put Acrobat Pro 2024 on Windows.


| Component | Requirements |
| --- | --- |
| Processor | Intel or AMD processor, 1.5GHz or faster processor |
| Operating system | Windows 11 (64-bit), Windows 10 (64-bit) version 1809 or later, Windows Server 2016 (64-bit), or Windows Server 2019 (64-bit) or Windows Server 2022 (64-bit) |
| RAM | 4GB of RAM |
| Hard disk space | 4.5GB of available hard-disk space |
| Monitor resolution | 1024x768 screen resolution |
| Graphics card | Video hardware acceleration (optional) |

Source: [Adobe 2024 requirements](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/tech-requirements-acrobat-pro-2024.html).
