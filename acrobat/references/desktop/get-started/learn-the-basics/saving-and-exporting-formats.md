# Saving and exporting formats

PDFs can be saved out to a range of formats from within Acrobat. Below are the formats available when you save and export your files.


| Extension | Filename | Version |
| --- | --- | --- |
| .PDF | Adobe PDF, Adobe PDF Optimized, PDF/A, PDF/E, PDF/X | PDF 1.3 - 1.7 |
| .PS | PostScript |  |
| .EPS | Encapsulated PostScript | PS level 2-3 |
| .HTML, .HTM | HTML |  |
| .JPG, .JPEG, .JPE | JPEG |  |
| .JPF, .JPX, .JP2, .J2K, .J2C, .JPC | JPEG2000 |  |
| .PNG | PNG |  |
| .PPTX | PowerPoint Presentation | 2010 and above |
| .RTF | Rich Text Format |  |
| .TXT | Text (Accessible), Text (Plain) |  |
| .TIF, .TIFF | TIFF |  |
| .XLSX | Excel workbook |  |
| .DOC, DOCX | Word document | 2010 and above |
| .XML | XML, XML Spreadsheet | 1.0, 2003 |

Source: [Adobe documentation](https://helpx.adobe.com/uk/acrobat/desktop/get-started/learn-the-basics/file-formats.html).
