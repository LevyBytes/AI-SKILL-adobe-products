# Technical requirements for Acrobat Pro 2020 and Acrobat Standard 2020

Get familiar with what Windows and macOS need in order to run Acrobat Pro 2020 and Acrobat Standard 2020.

Note

From January 2023 onward, 32-bit operating systems fell outside the support of Adobe Acrobat and Acrobat Reader, product updates and security updates included. The End of Support on 32-bit operating systems article covers this in more detail.
