# Read a document in Full Screen mode

Should the Full Screen navigation bar stay hidden, keyboard shortcuts let you move through a PDF.

Note

With two monitors connected, a page's Full Screen mode occasionally lands on just one of them. Click whichever screen is showing the Full Screen page to page through the document.

From the hamburger menu (Windows) > View, or the View menu (macOS), pick Full Screen Mode.

Advance to the following page by pressing Enter, Page Down, Down Arrow, or the Right arrow key.

Back up to the prior page by pressing Shift+Enter, Page Up, Up Arrow, or the Left arrow key.

3. Leave Full Screen mode with Ctrl+L or Esc. (This requires Escape Key Exits to be turned on in the Full Screen preferences.)

Note

A Full Screen tool can be added to the Common Tools toolbar: right-click the toolbar area and pick Show Page Display Tools > Full Screen Mode. Clicking the Full Screen tool then drops you into Full Screen mode.
