# Documents preferences

Open Settings

- Restore Last View Settings When Reopening Documents: Controls whether a document jumps back to the last page you viewed during a work session when reopened.
- Open Cross-document Links In Same Window: Shuts the current document and brings up the linked one in that same window, which keeps the count of open windows down. When the linked document already sits open in a separate window, clicking a link to it leaves the current document open. Leave this off and every click on a link to a different document spawns a fresh window.
- Allow Layer State To Be Set By User Information: Permits the author of a layered PDF to key which layers stay visible off of who the user is.
- Allow Documents To Hide The Menu Bar, Toolbars, And Window Controls: Lets the PDF decide whether the menu bar, toolbar, and window controls vanish when it opens.
- Always use filename as document title: Lets the filename stand in as the document title. (Off by default.)
- Documents In Recently Used List: Caps how many documents the File menu lists.

Save Settings

- Automatically Save Document Changes To Temporary File Every \_ Minutes: Governs the interval at which Acrobat saves changes to a document you have open.
- Save As Optimizes For Fast Web View: Reorganizes a PDF so web servers can deliver it a page at a time.
- Always reduce size for files more than 10MB: Shrinks the PDF on its own once the file climbs past 10MB.

PDF/A View Mode

- View Documents In PDF/A ModeSpecifies when to use this viewing mode: Never, or Only For PDF/A Documents.

Hidden Information

Combs the PDF for things that might go unnoticed — metadata, file attachments, comments, and concealed text and layers among them. A dialog box lists what turns up, and you can strip out whichever kinds you want.

- Remove Hidden Information When Closing Document (Off by default.)
- Remove Hidden Information When Sending Document By Email (Off by default.)

Redaction

- Adjust Filename When Saving Applied Redaction Marks: Lets you attach a prefix or suffix when saving a file that has had redaction marks applied.
- Choose Localization For Search & Remove Text Patterns: Picks which installed language edition of Acrobat supplies the patterns. Say both English and German are installed — either language's patterns are then available to you. Both the Search and Redaction dialog boxes carry the Patterns option.
