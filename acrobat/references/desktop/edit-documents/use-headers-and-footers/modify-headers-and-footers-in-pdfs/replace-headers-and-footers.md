# Replace headers and footers

With your PDF open, click Edit up on the global bar.

In the left pane, go to Header and footer > Add.

Select Replace Existing.

When the dialog box appears, supply the header and footer settings you want instead.

Select OK.

Every page across the document then picks up the fresh header and footer settings.
