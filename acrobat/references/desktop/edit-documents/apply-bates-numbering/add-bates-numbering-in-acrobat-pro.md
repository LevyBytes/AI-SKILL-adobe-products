# Add Bates numbering in Acrobat Pro

Stamp Bates numbers onto legal paperwork so it stays easy to track, organize, and cite.

With Bates numbering, every page in a batch of legal paperwork receives its own distinct ID, which makes the set simpler to index and pull back up later. Prefixes or suffixes built from letters or numbers can be tacked on when you want extra clarity. Anything that isn't already a PDF gets turned into one ahead of the numbering pass. Files that are protected or encrypted, along with certain form types, fall outside what's handled.

With the PDF open, click Edit.

From the left pane, work through More > Bates numbering > Add.

Inside the Bates Numbering dialog box, hit Add files, then take your pick from these:

- Add Files: pick individual PDF files to bring in
- Add Folders: pull in whole folders of PDF files
- Add Open Files: draw from PDFs already open in Acrobat

Select Output Options to specify:

- where the output files should be written
- how the files get named
- any further settings you require

Select OK.

To rearrange which order the files run through Bates numbering:

- highlight a file, then use Move Up or Move Down
- click a column heading to sort, and click once more to flip the direction

Select OK.

Within the Add Header and Footer dialog box, click to set your cursor inside the box you want.

Select Insert Bates Number.

Configure the Bates numbering options:

- Number of Digits: choose how many digits apply (3-15). At the default of 6 digits the stamps come out as 000001, 000002, and so on
- Start Number: type the value the count begins from
- Prefix: enter any text that should sit ahead of the number
- Suffix: enter any text that should sit after the number

Tip

When a document runs long, bump up the digit count. Steer clear of the # character anywhere in the prefix or suffix.

Over in Bates Numbering Options, fill out the Number of Digits, Start Number, Prefix, and Suffix fields.

Select OK.
