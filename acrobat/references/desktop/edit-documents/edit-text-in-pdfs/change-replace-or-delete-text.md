# Change, replace, or delete text

With Adobe Acrobat, here's how to revise the text already in a PDF, bring in new content, and take text out.

Select Edit from the global bar.

Within the Edit pane, under Add Content choose Text.

Swap out existing text by clicking it and typing the replacement.

Selecting a text box turns it blue and puts a rotation handle at the top of that box.

Lean on the AI Assistant to reword content when a section needs to be shorter or longer in your PDF.

For brand-new text, click wherever you want it and begin typing once the blinking cursor shows up.

Note

Reach for the FORMAT TEXT controls to set font, size, color, alignment, and other text properties.

Remove text by selecting it and pressing Delete (macOS) or Backspace (Windows).

Click outside the text box to put your changes into effect.

Note

Editing text in a particular font requires that font to be present on your machine. When the font is missing from your system but lives inside the PDF, all you can alter is the text's color or size.
