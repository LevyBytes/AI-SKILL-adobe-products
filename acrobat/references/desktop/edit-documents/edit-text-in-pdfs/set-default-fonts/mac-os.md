# macOS

Select Acrobat > Preferences.

Under Preferences, choose Content Editing.

To choose which font new text starts in:

- Pick your choice from the Default font for Add Text dropdown menu.
- Set the size using the Font Size dropdown menu.

Note

Want the original behavior back? In the Default font for Add Text dropdown menu, pick Let Acrobat choose.

For editing, set a fallback by picking from the Fallback font for Editing dropdown menu.

Select OK.
