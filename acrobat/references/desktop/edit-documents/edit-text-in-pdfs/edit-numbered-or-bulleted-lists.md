# Edit numbered or bulleted lists

Add entries to a numbered or bulleted list, start new lists, turn paragraphs into list items, and swap list types — all in Adobe Acrobat.

Select Edit in the global bar.

Click the list you intend to edit.

Work with these FORMAT TEXT options to reshape the list:

- Tack a row onto an existing list by pressing Enter at the end of a list item.
- Delete a row by selecting it and pressing Backspace.
- Start a fresh list by placing the cursor where it should begin and choosing Bullet list or Numbered list as appropriate.
- Turn a paragraph into a list item by selecting the text and choosing Bullet list or Numbered list as appropriate.
- Turn a list item back into a paragraph by selecting all the items and clicking the highlighted list type to clear the formatting.
- Switch between list styles by selecting the items and choosing Bullet list or Numbered list.
