# Format text

Work with the font, size, color, and other text formatting controls inside Adobe Acrobat.

Open the PDF and select Edit from the global bar.

Highlight whatever text you intend to format. The box around it turns blue and shows selection handles.

Text formatting controls let you reshape the text so it stays in keeping with the document.

Reach for these FORMAT TEXT controls to style your text:

- Font: Pick another typeface from the dropdown.
- Font size: Grab a preset size or key in your own.
- Font color: Launch the color picker and choose a fresh text color.
- Bold, Italic, Underline: Switch any of these on or off as you like.
- Superscript/Subscript: Use these for scientific notation.
- Text alignment: Set the text left, center, right, or justified.
- Line spacing: Tighten or loosen the gap between lines.
- Paragraph spacing after: Decide how much room follows each paragraph.
- Character spacing: Dial in the gap between individual letters.
- Horizontal scaling: Stretch or squeeze the character width.
- Bulleted and numbered lists: Turn your text into a formatted list.

Note

Need to reverse or repeat a text edit? Open Menu (Windows) or Edit (macOS) > Undo, Redo & more > Undo, Redo and More, then choose whichever tool fits.

Click outside the text box to put your changes into effect.
