# Split PDFs

How to break a PDF apart into smaller standalone files by page, by bookmark, or by size.

A single PDF or several can be broken into a set of smaller PDFs. As you do, the dividing point can hinge on a page-count ceiling, a file-size ceiling, or the top-level bookmarks.

Launch the PDF, then pick All tools > Organize pages.

Over in the left pane, pick Split.

Open the Split by dropdown and pick how the document should be divided:

- Number of pages: Carves the PDF into smaller documents that each carry a fixed page count.
- File Size: Produces several PDFs at a file size you name.
- Top level bookmarks: Breaks the PDF wherever its top-level bookmarks fall.

Break your PDF into several documents by naming the page count, the file size, or the top-level bookmarks.

When several PDFs need dividing, pick Split multiple files, pick Add files, and pick whichever PDFs you want to split.

Pick Output options to name:

- The destination folder for the divided files.
- The naming convention for the fresh PDFs.

Pick Split.
