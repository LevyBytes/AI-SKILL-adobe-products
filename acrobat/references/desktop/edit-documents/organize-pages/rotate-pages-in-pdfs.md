# Rotate pages in PDFs

How to spin pages within a PDF so their orientation is corrected or the layout suits your needs.

Launch the PDF, then pick All tools > Organize pages.

Pick one of these methods to set which pages get rotated:

- Open the dropdown beneath PAGES SELECTED and pick whichever option fits.
- Pick a ready-made choice: Even pages, Odd pages, or All pages.
- Type the page numbers yourself.

Set which way the pages turn:

- Rotate page left turns the page 90° counterclockwise.
- Rotate page right turns the page 90° clockwise.

Getting a PDF ready to send out or export? Reach for the Organize Pages tool when you need to pick, reorder, and divide particular pages.

Dismiss the tools pane, then save the PDF.

Note

For a view change that doesn't stick, head to View > Rotate view and pick Rotate view right or Rotate view left. Reopening the PDF later brings back its original page orientation.
