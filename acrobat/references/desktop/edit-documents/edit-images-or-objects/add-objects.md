# Add objects

See how to drop assorted objects — buttons, videos, sound clips, and 3D models — into PDFs with Adobe Acrobat.

With the PDF open, click Edit on the global bar.

From the Edit pane, pick whichever of these objects you need:

- Button: places an interactive button
- Video: embeds a video file
- Sound: drops in an audio clip
- 3D media: embeds a 3D model in U3D or PRC format

Placing objects in your PDF documents makes them more interactive for the people who open them.

Interactive objects added to a PDF give readers more to engage with.

Drag the cursor across the page to mark out the region for your object.

Depending on which object you picked, the cursor turns into either a box or a crosshair.

Clicking the page brings up a dialog box where you set a button's properties.

Double-clicking the page brings up a dialog box for loading the files behind Video, Sound and 3D media objects.

Click OK.
