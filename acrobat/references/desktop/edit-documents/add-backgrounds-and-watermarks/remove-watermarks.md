# Remove watermarks

How to strip watermarks off PDFs in a hurry with Acrobat on the desktop.

Pick Go to Home view and then pick See all tools > Edit a PDF.

Over in the Edit pane, pick Watermark > Remove.

Once the dialog box appears, pick Add files > Add Files.

Lean on the watermark removal tool to bring in several PDFs, look them over for any errors, and clear watermarks in bulk from the documents you picked.

Pick the files you want watermarks gone from, then pick Open.

Pick OK.

Within the Output Options dialog box, name your folder and filename preferences and pick OK.
