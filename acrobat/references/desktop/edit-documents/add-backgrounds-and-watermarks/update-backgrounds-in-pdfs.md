# Update backgrounds in PDFs

How to refresh a background already in your PDF without laying it down again.

Has the original image file changed? You can refresh an existing background inside your PDF document with no need to strip it out and re-add it. Refreshing a background only works when the background went in via Acrobat 7 or later.

Launch the PDF that carries the background, then pick Edit.

Pick Background > Update over in the left pane.

Within the Update Background dialog box, make whatever changes you want to the background choices.

Refresh an existing background by reworking the source, appearance, or position right inside the Update Background dialog box.

Pick OK.
