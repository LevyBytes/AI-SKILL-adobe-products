# Update watermarks

How to refresh watermarks already in your PDFs in a hurry with Acrobat on the desktop.

Watermarks make a document's status, ownership, or confidentiality clear. Existing watermarks sometimes need refreshing as document classification or branding shifts. During a refresh, only the watermark you added first gets changed; the rest fall away as the update runs.

Launch the PDF holding the watermark, then pick Edit from the top menu.

Note

Should the PDF be secured or carry form fields, watermark refreshes might fail. Look over the document permissions before you go on.

Pick Watermark > Update over in the Edit tools pane.

Within the Update Watermark dialog box, tweak the watermark settings as you need:

- Swap the text, font, size, or color
- Shift the rotation angle
- Change the opacity
- Pick fresh page range options

Within the Update Watermark dialog box, the choices let you refresh a watermark's appearance, position, and scaling.

Pick OK.

Save the PDF you just refreshed.
