# Resize the combined file

Choose Options, then pick whichever of these settings fits the converted file:

- Smaller File Size: shrinks oversized images down to screen resolution and squeezes them with low-quality JPEG. Handy for viewing onscreen, sending by email, and the Internet.
- Default File Size: turns out PDFs geared toward dependable on-screen reading and printing of business documents. Each listed PDF holds on to its starting file size and quality.
- Larger File Size: turns out PDFs geared toward output on desktop printers. It draws on the High-Quality Print conversion preset, and the listed PDFs hang on to their original file size and quality.

Note

Picking Larger File Size can push the finished PDF to a bigger size. Where source files are already PDFs, choosing Smaller File Size runs the Reduce File Size feature across them. That Reduce File Size step is skipped whenever Default File Size or Larger File Size is the choice.

Adjust the file size to whatever you need from inside the Options dialog box.

Within the Options dialog box, dial in the Adobe PDF Conversion Settings to taste, then select OK.

When that's set, select Combine from the upper-right.
