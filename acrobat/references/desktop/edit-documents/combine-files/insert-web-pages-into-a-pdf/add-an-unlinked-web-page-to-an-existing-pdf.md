# Add an unlinked web page to an existing PDF

In Acrobat, open the PDF you're targeting.

Follow Edit > Organize pages > Insert > From web page.

When the dialog box appears, type the webpage URL and then select Add.

After the web pages join your PDF, reshuffle the pages if you need to, and save the file.

Where the PDF is read-only, Acrobat spins up a new PDF instead.
