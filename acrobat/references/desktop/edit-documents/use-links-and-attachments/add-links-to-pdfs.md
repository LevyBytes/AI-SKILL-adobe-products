# Add links to PDFs

See how adding links to a PDF can steer readers around the document or out to outside resources.

Select Edit from the global bar.

From the left pane, under ADD CONTENT select More.

Select Link > Add or edit a link. The pointer turns into a cross hair.

Drag out a rectangle across the page to mark where the link sits.

When the Create Link dialog box appears, pick the link-appearance settings you want, among them Link Type, Highlight Style, Line thickness, Line Style, and Color.

Select the desired option under Link Action:

- Go to a page view: jump to a particular page and view inside the current PDF.
- Open a file: connect to another file stored on your computer.
- Open a web page: point to an outside website.
- Custom link: build your own action, whether that means opening an article to read, firing a JavaScript, or kicking off a command.

Attaching a link lets you define actions that turn the document into something readers can interact with.

The point of a link is to attach actions that make the PDF interactive for whoever opens it.

Select Next, then let the on-screen prompts walk you through defining what the link does.

Select OK.
