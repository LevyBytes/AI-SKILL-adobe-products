# Edit layer properties

Learn how to edit the properties of layers in a PDF.

When you review or present a PDF, layers are what keep content organized and visibility under control. Through layer properties you can rename a layer, fix its opening visibility, tailor how it prints, or cluster related layers together.

Before you begin

Make sure the PDF contains layers.

Reach the Layer Properties dialog box to adjust visibility, print settings, and default states across PDF layers. None of those edits take hold unless you have selected Allow layer state to be set by user information in document preferences.

With your PDF open in Acrobat, click Layers in the right-side panel to bring up the Layers panel.

Tip

If Layers isn’t visible, select Menu > View > Show/Hide > Side panels > Layers.

Select the layer you want to edit in the Layers panel.

Open the Options menu beside the layer name, then choose Layer Properties.

Set the Intent option. Pick View when the layer should switch on and off, or Reference to keep it on screen the whole time you edit.

Use the Default State to fix what shows the moment the document opens, and use the Visibility setting to govern the layer’s onscreen appearance.

Use the Print option to decide how the document prints, and the Export option to set whether the layer carries through when the PDF exports to supported layered formats.

Select OK to apply your changes.

Your property edits now show on the layer, and they travel with the document once saved.

For a watermark that shows up on paper yet stays off the screen, set Default State to On, Visibility to Never Visible, Print to Always Prints, and Export to Always Exports.
