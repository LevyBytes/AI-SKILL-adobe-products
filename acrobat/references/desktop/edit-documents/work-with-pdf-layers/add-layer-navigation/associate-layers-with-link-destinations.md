# Associate layers with link destinations

Select Menu , then select View > Show/Hide > Side panels > Destinations.

Open the Options menu in the Destinations panel, choose New Destination, and give the destination a name.

Grab the Link tool and drag out a rectangle wherever the link belongs.

When the Create Link dialog box opens, pick Go to a page view, then select Next.

In the dialog box that follows, select Set Link, and the link is made.

Within the Link Properties dialog box, open the Appearance tab and dial in how the link looks.

Move to the Actions tab, pick Set Layer Visibility out of the action list, then select Add.

Select OK to apply the link behavior.

Tip

Shut the dialog boxes, grab the Hand tool, and click the link area to make sure the link works.

Note

Toggling a layer with the eye icon leaves no trace in the Navigation toolbar. For navigation controls, lean on bookmarks or link destinations instead.
