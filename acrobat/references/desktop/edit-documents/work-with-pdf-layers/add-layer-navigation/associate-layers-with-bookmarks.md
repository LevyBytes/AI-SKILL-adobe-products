# Associate layers with bookmarks

In the right panel, choose Bookmarks, then click the new bookmark icon.

Click the bookmark label in the Bookmarks panel and type in a name that describes it.

With the freshly made bookmark selected, open the Options menu and pick Properties.

Once the Bookmark Properties dialog box is open, switch to the Actions tab.

Open the Select Action menu, pick Set layer visibility, and select Add.

Select OK to save the bookmark action.
