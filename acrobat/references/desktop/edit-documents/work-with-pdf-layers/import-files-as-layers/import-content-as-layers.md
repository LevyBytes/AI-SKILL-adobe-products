# Import content as layers

Open a PDF in Acrobat.

Select Layers from the right-side panel to open the Layers panel.

Tip

If Layers isn’t visible, select Menu > View > Show/Hide > Side panels > Layers.

In the Layers panel, choose Options and then Import as layer.

In the Import as Layer dialog box, select Browse and find the file you want to bring in.

When the source spans several pages, type which one you need in the Page number field.

When the target document spans several pages, set the Target page number over in the Preview section.

Pick how the import should behave:

- Create new layer: Enter a name to create a separate layer.
- Add to existing layer: Choose a destination layer from the list.
- Copy layers from source: Maintain original layer structure in the source files.

Fine-tune placement and scaling of what you brought in by adjusting the Position and Appearance settings.

Finish up by selecting OK.
