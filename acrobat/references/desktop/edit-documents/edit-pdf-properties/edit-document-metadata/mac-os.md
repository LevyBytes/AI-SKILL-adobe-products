# macOS

Open View> Document properties > Description.

Choose Additional Metadata, then pick Advanced over in the left pane.

Pulling in metadata you saved earlier means choosing Append, picking an XMP or FFO file, and then choosing Open.

Bringing in fresh data that overwrites what's there means choosing Replace, picking the file, and then choosing Open.

Getting rid of an XML schema is done by selecting it and choosing Delete.

Choose OK.


Open View> Document properties > Description.

Choose Additional Metadata, then pick Advanced over in the left pane.

Want the metadata kept as a reusable template? Choose Save.

In the dialog that comes up, give the file a name and point it at the location where it should live.

Choose Save.
