# Inviting collaborators

Pulling others into your PDF Space means firing off an invitation via Invite people, where an optional note can supply some context too. When speed matters, spin up a link or push it straight out through apps such as Outlook, Gmail, Teams, or WhatsApp. On restricted PDF Spaces, anyone lacking access can request access, and approving or denying that request is up to you.
