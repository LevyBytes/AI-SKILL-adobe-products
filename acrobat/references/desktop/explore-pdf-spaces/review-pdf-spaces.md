# Review PDF Spaces

Find out how to review shared PDF Spaces in Adobe Acrobat by adding comments, annotations, and feedback that fit your permission level.

Going over shared PDF Spaces drives real collaboration by letting you weigh in on files, notes, and insights. What you're able to do during review hinges on the permission level you hold: Viewer, Reviewer, or Contributor. Full access belongs to Contributors, who can handle files and notes, bring in new content, and delete or edit whatever already sits in the PDF Space.

Opening a shared PDF Space starts you off in an Overview experience that presents the space, spotlights the key content, and orients you on what to review and where to begin before any individual file opens.

Learn more about collaborating on PDF Spaces.

In the invitation email, click Open PDF Space, and sign in should you be asked.

Note

A PDF Space with public access can open without any sign‑in. With organization‑restricted or privately shared PDF Spaces, though, recipients have to sign in before they get in.

Sign in if prompted.

Once you're in the PDF Space, here is what you're able to do:

- Explore the Overview to understand the purpose and structure of the PDF Space
- View and interact with all shared content, such as files, audio summaries, podcasts, and notes
- View existing comments and notes
- Chat with the AI Assistant for questions or summaries
- Copy the PDF Space link and share it with others

Note

Run into offensive or inappropriate content in a file? Choose More options > Report abuse and complete the form to flag it for review.

(Reviewer or Contributor access only) Go through the material, layer in comments or annotations, and pull down files where required.

Bring up a file or note, grab the text with the Select text tool over on the Quick action toolbar, and pick an action off the floating toolbar:

- Add a comment
- Highlight text
- Strikethrough text
- Underline text
- Copy text
- Save as note

Note

Everyone holding project access can see all comments. A Comments icon marks files or notes that have comments, and selecting it lets you view and reply.

Drop comments onto shared files and run the AI Assistant right beside your content to review, clarify, and grow ideas all in one spot.

(Contributor access only) Handle the notes and take charge of the project files. Here's what's open to you:

- Add notes: Select Notes from the left pane and then select Create a note.
- Add files: Drag them into the Files panel or click Select a file and upload the files you want to include.
- Rename files: Select More options > Rename file.
- Remove files or notes: Select More options > Remove file.

Tip

Pulling a file out of the PDF Space leaves the original untouched.
