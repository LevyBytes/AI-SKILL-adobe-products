# Document specifications

Keep these per-space details in mind, each of which governs an individual PDF Space:

- Number of files: Each PDF Space can support up to 100 files.
- Maximum file size: Each file can be up to 100MB.
- Maximum pages: Each file can contain up to 600 pages.
- Unsupported content: Password-protected files, videos, images with complex vector graphics, and handwritten notes are not supported.
- Citation limitation: Citations are unavailable in the Insights dashboard when the app locale differs from the asset language.
