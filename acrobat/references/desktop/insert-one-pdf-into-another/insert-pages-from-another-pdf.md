# Drop pages from one PDF straight into another PDF using Adobe Acrobat.

Open whichever PDF will act as the foundation for the merged file, then go to All tools > Organize pages.

From the left pane, choose Insert > From file.

The Insert option inside the Organize Pages tool adds a page to your PDF—sourced from a file, the clipboard, a scanner, a web page, or a blank page.

Pick the PDF you mean to bring in, then hit Open.

In the Insert Pages dialog box, spell out where the document should land:

- Before or after the first page
- Before or after the last page
- Before or after a designated page number

Open the Location dropdown menu and pick the option you want.

Select OK.

Leave the source PDF untouched by going with Save As and giving the merged file a fresh name.

Note

An existing file can likewise be folded into an open PDF. Drag its file icon straight onto the Pages panel over in the navigation pane.
