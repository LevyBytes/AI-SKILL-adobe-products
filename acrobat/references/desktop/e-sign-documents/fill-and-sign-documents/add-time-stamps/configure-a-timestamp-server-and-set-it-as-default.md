# Configure a timestamp server and set it as default

Before you begin

Make sure a trusted security settings file is on hand. Lacking one, request the server name and URL from your administrator.

Open Menu > Preferences.

Within Categories, choose Signatures.

Alongside Document Timestamping, choose More.

In the Server Settings dialog box, choose Time Stamp Servers in the left pane and then do one of the following:

- For pulling in a timestamp server settings file, choose Import. At the prompt, choose the file and then choose Open.
- For adding a timestamp server URL, choose New, and in the dialog box that appears, fill in the name plus the server URL. Note whether the server expects a username and password, then choose OK.

Configure a timestamp server by typing its name and URL into the Server Settings window. Doing so keeps the timestamps on your digital signatures secure and verifiable.

Highlight the timestamp you just added and then choose Set Default along the top menu.

When the dialog box appears, choose OK to confirm, then close it.
