# Turn off generative AI features

See how to switch off the generative AI features in Adobe Acrobat.

Out of the box, the generative AI features come switched on, yet how they're used stays in your hands. Any individual user can switch features off when they prefer, and admins are able to pull access for teams or whole organizations.

Shut every open document in Acrobat, then head to:

- Windows: Menu > Preferences > Generative AI
- macOS: View > Preferences > Generative AI

Clear the Enable generative AI features checkbox.

Switch on generative AI features to put AI Assistant and smart suggestions to work throughout Acrobat.
