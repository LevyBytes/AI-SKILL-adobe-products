# Prompts to edit PDFs via chat

Find out which prompts let you edit PDFs through the chat feature in Adobe Acrobat.

A prompt might carry out one action, link several tools one after another, or lean on the document's content and structure to work out what to act on. How you phrase the request shapes how AI Assistant reads it.

The clearer and more specific your prompt, the more accurate the result, and the easier it is for Acrobat to land on the right action. Below, you'll see how various phrasings line up with particular tools and actions, so picking the right approach for whatever you're doing gets that much simpler.

Note

Only individual Acrobat Pro and Studio plan users can reach multi-tool and content-aware prompts; on Teams and Enterprise plans they aren't supported yet. Look over the supported tools and actions to see what your plan offers.
