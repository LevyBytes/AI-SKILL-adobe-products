# Setting identity types and authentication

To handle licensing and services, Adobe runs an identity management system that authenticates and authorizes users. Signing in happens through an email-based ID. These are the identity types it supports:

- Federated ID: Run by the organization. Tied to the enterprise directory through SAML2 Identity Provider (IdP) single Sign-On.
- Enterprise ID: Run by the organization and hosted by Adobe, where Adobe carries out the authentication.
- Business ID: Run by the organization. Sole authority to create and manage the user accounts stays with the organization.
- Adobe ID: Run by the end user, where Adobe carries out the authentication.

When accounts are run by the organization, getting to the AI Assistant calls for a federated ID or an enterprise ID. Read on about managing Adobe profiles.
