# Edit PDFs via chat not working in Acrobat

Find out how to work through problems that crop up when you edit PDFs by chat in Acrobat AI Assistant.

When a chat-driven edit to a PDF doesn't behave as expected, the cause might trace back to your subscription plan, the platform in play, the type of file, your language settings, or the way the prompt was worded.

Quick checks:

- Confirm you're on Acrobat for desktop (open to all users) or Acrobat on the web (individual users only), with your app language set to English.
- Load your prompt with specifics — page numbers, file names, precise content references, or a description of what's on the page — so Acrobat can pin down the right action. For instance: "Delete pages with financial information."
