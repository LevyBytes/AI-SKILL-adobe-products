## Protect PDFs

### See how a password lock gets added to a PDF.

Setting passwords through the Acrobat on the web tool is a quick way to lock down your PDF files. Doing so keeps your documents private and walls them off from anyone without permission.

Note

Once the password is in place, anyone wanting to open the PDF has to supply it.

From the Acrobat on the web homepage, pick Edit > Protect a PDF.

When the dialog box appears, choose the file location from the top menu, mark the file you mean to protect, then pick Continue.

After the Protect PDF dialog box opens, key the password into the Set password field and key it again into the Confirm password field.

With every keystroke, the password strength meter weighs your entry and reports how strong it is.

Keystroke by keystroke, the password strength meter gauges your password and signals its strength.

Pick Set password.

Tip

Files you've just secured are reachable from the Recent section on the Home page.

A protected duplicate of your PDF, tagged <filename>\_protected, gets stored on Adobe cloud storage. When that password-protected PDF opens, it asks for the password before granting access.

## Share PDFs for review

### See how PDFs get sent to others so they can review them and leave comments.

Only PDF files qualify for review-and-comment sharing; a non-PDF has to be turned into a PDF first. Send a PDF out for review and your recipients get an email bearing a link to it. Reviewing and commenting requires them to sign in. On top of that, custom access permissions are yours to set when you share PDFs.

Open the document you intend to share, then from the top menu pick Share.

For custom access, pick the Link settings option down at the bottom and settle on one of these access options:

- Anyone on the internet with the link spins up a public link. Such links reach wide audiences with no sign-in needed, though they're a poor fit for anything sensitive.
- People in <organization> with the link (For enterprise users only) opens access to everyone inside the organization.
- Invited people only (For subscription users only) restricts access to just the collaborators you invite. For a privately shared document, recipients have to ask for access; the owner sees each request and may grant or refuse it from desktop or web, keeping full say over who gets in.

Note

Among enterprise users, the Anyone in <organization> with the link option comes preselected. User access here is something enterprise admins handle through the Adobe Admin Console, and Acrobat's own access controls leave those settings alone.

Pick the 'Invite people only' option and you then pick Next to key in the email addresses of the participants you need.

Choosing 'Invite people only' means pressing Next afterward so you can enter the required participants' email addresses.

Changed the default access option? Pick Apply. Otherwise pick Cancel to head back to the Share dialog.

Within the Enter name or email field, type the recipients' email addresses.

Want a review deadline? Pick Add deadline and settle on a date.

Key in the recipients' email addresses and, if you like, attach a message. Ticking the checkbox also lets that message post as a comment.

Enter who the document is for and optionally write them a note; the checkbox, when ticked, turns that note into a comment as well.

See that the People can comment on this file toggle is flipped ON.

Pick Invite.

Tip

That shared document lands in your Shared by you documents list, the place to watch where your shared documents stand.

With the document shared, recipients get an email alert holding a link to open it. To review the document and add comments, they have to sign in.

## Manage shared documents

Whatever you've shared lands in the Shared by you list of documents. The moment a recipient opens a file you sent, a notice reaches you inside Adobe Acrobat as well as by email.

From the Acrobat on the web homepage, choose Documents > Shared by you.

Look over your shared files, which carry these details:

- Name: The file name you sent out for review.
- Sharing: Who you handed the file to, by name.
- Status: How many people have opened the file.
- Last Activity: When the file was last touched.

## Mark up with redlining tools

- Highlight selected text: Draw the eye to text by swapping its background color.
- Strikethrough selected text: Flag text for cutting by running a line across it.
- Underline selected text: Lend emphasis or signal text edits.
- Insert text: Drop in new text.
- Replace selected text: Put forward substitutes for text already there.
- Add comments: Leave feedback inside a chat bubble.
- Draw freehand: Sketch to get your feedback across.

## Turn documents into audio with Read aloud

### A walkthrough for getting PDFs read out loud, boosting accessibility and freeing up your hands.

Built into Adobe Acrobat on the web is a Read aloud tool that voices the text inside documents. People with visual impairments, or anyone who would rather listen to what's in a document, find this handy.

Head to Acrobat on the web and open whichever document you want voiced.

Off the top bar, choose Read aloud

Reading kicks off at the beginning of the document, running the default voice and a 1X playback speed.
