# May, 2021

| Change | Description |
| --- | --- |
| New | Fresh undo and redo tools added to the top bar. |
| Changed | Refreshed the Adobe Acrobat branding across all embed modes. For the full window, sized container and in-line embed modes the new Adobe Acrobat logo shows up in the bottom page-controls toolbar, and for lightbox embed mode it shows in the top bar. A click on the logo opens the [Adobe Acrobat online](https://documentcloud.adobe.com/link/home) application in a fresh browser tab. The [Embed modes](../embed-modes/reference-index.md) section has more. |
| New | Added the ability to pass a `strokeWidth` input parameter into the `startAnnotationMode()` annotation API so the line thickness of a drawing annotation can be set programmatically. |
