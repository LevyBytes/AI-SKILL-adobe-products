# August, 2021

| Change | Description |
| --- | --- |
| New | Past September 2021, PDF Embed API drops support for Internet Explorer 11 and Microsoft Edge Legacy. Through the end of that month, rendering a PDF on those browsers shows a warning urging users onto a supported one. From October 1, 2021 onward, PDF rendering ceases to function there. The [Supported browsers](../getting-started-supported-browsers.md) section lists which browsers are supported. |
