# July, 2021

| Change | Description |
| --- | --- |
| Changed | Until now the PDF grabbed focus on rendering no matter the embed mode. That default has shifted: the PDF will now claim focus only when it renders in full window or lightbox embed modes. Site builders can override this default through the `focusOnRendering` preview configuration. The [Focus on PDF rendering](../embed-modes/focus-on-pdf-rendering.md) section covers the details. |
