## About Firefly video editor (beta)

### Explore Firefly video editor (beta) and its main online video editing features.

Firefly video editor (beta) runs in the browser and lets you edit video online. You can trim, cut, add text, add audio, generate videos, and bring in videos from your Firefly generation history within the same editor. This supports many creative project types, including social media content and educational tutorials.

## Create a project

### Start a new project so you can begin editing video.

From the Firefly homepage, choose Edit video.

On the Video editor prompt, choose one of these ways to begin:

- New project: opens a blank project in the editor so you can add and edit videos.

- Upload media: lets you select files and create a timeline in a new project.

  - Generate with Firefly: creates videos with the Firefly Video model and adds them to the timeline.
  - Browse generation history: opens your video generation history so previously created videos can be selected and added to the timeline.

- Start with popular social platforms: uses aspect ratio presets for social media platforms such as TikTok, Instagram, and Facebook.

Choose from the available starting options when creating a new video editing project.

Use one of the provided options to begin a new project for video editing.

Use the rename option at the top left of the page to replace the default project name.

## Create a timeline in a project

### Create a project timeline so media files can be added, organized, and edited.

In Firefly video editor (beta), the timeline is the main workspace for arranging and editing a video. It is a horizontal area that places video, audio, and images in playback order over time. The playhead, shown as a vertical line that travels across the timeline, lets you move through the project and inspect what occurs at each moment. Use this area to arrange clips, trim or cut sections, and produce the finished edit.

## Change frame rate

### Select a frame rate that suits the style of your video.

In video editing, frame rate (fps) is the count of images shown each second. Firefly video editor (beta) lets you set the timeline frame rate for the kind of project you are making, including YouTube, social media, or film work. This setting affects the speed and smoothness of the exported video.

## Panels in Firefly video editor

Learn how panels in Firefly video editor support organizing, editing, and fine-tuning a project.

While working in Firefly video editor, several panels are available for media files, text elements, and media properties. These panels support project organization, editing, and detailed refinement.

Firefly video editor includes these panels:

- Viewer
- Timeline panel
- Your media panel
- Generation history panel
- Text panel
- Properties panel
- Generate media panel
- Text-based editing panel
- Transitions panel
- Looks panel

### Viewer

The Viewer sits in the center of the editor and shows timeline content while you edit. It gives you a live preview of the video so you can judge how clips, edits, and effects combine. The Viewer also supports direct interaction with visuals for precise changes, including edits to text overlays. With this panel, you can:

- Zoom in or out to inspect details or see the full frame
- Pan around the frame with the hand tool at the top-left corner of the timeline
- Refine particular clip areas for more precise visual edits

The view box on the bottom right of the viewer can also be used to pan through the generated video or adjust its crop.

Use the view box on the viewer's bottom right to move through the generated video or change the crop.

### Timeline panel

The Timeline panel is the central workspace in Firefly video editor for arranging and editing media. It shows each added clip, including video, images, audio, and text, along a time-based sequence so you can see how the project plays from beginning to end. Effects, transitions, and clip adjustments also appear in this panel. With it, you can:

- Cut or trim clips to change timing
- Reorder media to alter playback sequence
- Open clip properties for viewing and edits

Check the Timeline panel to see effects, transitions, and clip adjustments.

Effects, transitions, and clip adjustments are visible from the Timeline panel.

### Your media panel

Enable the Your media panel by selecting the Your media icon in the editor's left sidebar. This panel shows the media files you have added and the timeline in your video editor. With it, you can:

- Upload additional media files
- Remove media files
- Start an additional timeline for the project

Use the Your media panel to review media files added to the timeline.

The Your media panel lists the media currently available to the timeline.

### Generation history panel

Open the Generation history panel from the editor's left sidebar by selecting the Generation history icon. From there, you can:

- Review generated media, including items you have marked as favorites.
- Start creating new videos inside the editor, or go to the image and sound effect generation pages.
- Drag generated media from the panel into your timeline.

The Generation history panel shows content you generated earlier.

The Generation history panel shows content you generated earlier.

### Text panel

Select the Text icon in the editor's left sidebar to show the Text panel. Use this panel when you need to change text settings for timeline items.

The Text panel adds a text layer to the timeline.

The Text panel adds a text layer to the timeline.

### Properties panel

Timeline layers can contain video, images, or text. After you choose a layer, the matching Properties panel opens for that layer type. Its controls cover size, position, and related edit settings so the selected layer can be adjusted for the current edit.

For a selected layer, use the properties panel to set position, scale, opacity, and other values.

For a selected layer, use the properties panel to set position, scale, opacity, and other values.

### Generate media panel

Use the Generate media panel with Firefly and partner models to create video and audio. Custom outputs can be shaped with controls such as resolution, aspect ratio, keyframe images, style presets, duration, and voice timing.

The Generate media panel creates video and audio clips with adjustable controls.

The Generate media panel creates video and audio clips with adjustable controls.

### Text-based editing panel

The Text-based editing panel is for working with the transcript of the video clip currently selected in the timeline. Through that transcript, you can move around the timeline and edit text while building and refining the video.

To open it, first choose a speech-containing video clip. Then use the right panel's Text-based editing icon. Firefly video editor transcribes the audio automatically, and the transcript appears in this panel so the video can be edited through text.

Use the Text-Based Editing panel to revise video content from the generated transcript.

Use the Text-Based Editing panel to revise video content from the generated transcript.

### Transitions panel

Transitions combine scenes or add pauses so videos feel smoother and more finished. Firefly video editor (beta) includes simple transitions that can be applied straight to clips on the timeline.

Add transitions to selected clips from the transitions panel.

Add transitions to selected clips from the transitions panel.

### Looks panel

The Looks panel helps apply professional color grading for generated videos, supporting visual consistency and stronger impact. It includes color adjustment tools for applying cinematic styles or refining individual color properties quickly.

Use the Looks panel to apply preset Looks, or improve video color with adjustment sliders.

Use the Looks panel to apply preset Looks, or improve video color with adjustment sliders.
