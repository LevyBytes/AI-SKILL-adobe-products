# Grant Applications Access to Your Custom Model Guide

This guide explains how to grant applications access to your custom models so API endpoints can use them.

### Overview

After you have [trained a custom model](custom-models.md), share it with your technical account. The [List Custom Models](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/api/index.md) API can then see it. The [Text to Image](https://raw.githubusercontent.com/AdobeDocs/ffs-firefly-api/main/src/pages/api/index.md) API can use it too.

Note

Models shared at the organization level are shared with individual projects as well.
