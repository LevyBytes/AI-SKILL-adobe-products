## Set aspect ratio of images

### Choose an aspect ratio for generated images

Aspect ratio changes can alter the overall impression and framing of generated images. While text descriptions are used to create variations, Adobe Firefly provides four aspect-ratio choices.

From the Adobe Firefly homepage, open the Image module and choose Text to image.

Type a text prompt, then set any image generation options you need.

In General settings, choose Aspect ratio from Landscape (4:3), Portrait (3:4), Square (1:1), Widescreen (16:9), or Vertical (9:16).

Note

For Firefly Image 4 and Firefly Image 4 Ultra, Vertical (9:16) is an available option.

Choose Generate.

## Set content type

### Create image variations that look more illustrative or realistic

When Text to image builds variations from a prompt, Firefly chooses a content type automatically. To explore a more photographic or artistic direction yourself, select Photo or Art.

On the Firefly homepage, choose Generate in the left panel, then choose Generate image.

Add a text prompt and configure any image generation settings you need.

In Content type, choose Photo or Art.

Tip

Enable Auto mode so Firefly selects the content type on your behalf and predicts the proper photo settings.

Choose Generate to create the image variations.

## Match image composition to reference image

### Generate image variations that follow a reference image composition

Composition describes an image's structure, including the placement of subjects and visual elements within the frame. When Adobe Firefly matches a reference image structure, it evaluates outline and depth as two key aspects.

On the Firefly homepage, choose Generate in the left panel, then choose Generate image.

Provide the prompt text, then change any image generation settings you need.

In General settings, select the Model you want to use.

Open Composition to see the available choices.

In Reference, choose Upload image, then browse to an image on your device.

In Composition, either upload an image or choose one from the gallery as the structure reference.

In Composition, either upload an image or choose one from the gallery as the structure reference. Note

Use the Strength slider to set how strongly the result follows the reference image.

Choose Generate to produce variations aligned to the reference image composition.

## Reference images for styling

### Steer image variations with personal or curated style images in Adobe Firefly

Style reference uses an existing image as guidance for the look and feel of generated variations. On the Adobe Firefly website, Reference in the Styles section lets you upload your own image or select from curated style images across many categories. Available reference style categories include 3D, Landscapes, Lighting effects, Texture, and more.

Use a style reference to keep assets aligned with a chosen brand or visual style.

Across multiple assets, style references help maintain the same look and feel.

### Graphic design and branding

Apply Style references when shaping logos, advertisements, and branding materials. With your image set as a Style reference, Firefly can produce images that carry the same style and visual identity more accurately.

### Content creation

For articles, blogs, and social media posts, reference images can guide generated images and illustrations. Style reference images let you direct the style, theme, or mood of variations so they fit the message and audience you have in mind.

### Fashion and apparel

For clothing and fashion-item design, supply Style reference images to guide AI-generated patterns, styles, and color combinations. Reference images can also signal fashion trends or design inspirations that shape the resulting variations.

### Art and creative industries

Use your own uploaded images to define the style or theme you want; Firefly then applies that direction when creating art, illustrations, or digital artwork.

### Product design

Use Style reference images to express design preferences, color schemes, and overall product aesthetics while generating product concepts and prototypes.

## Set styles for image generation

### Generate images in different styles

With Text to image and Firefly Image models, a reference image can guide newly generated variations toward the same visual style and aesthetic. You can also control how tightly the results follow that reference.

On the Firefly homepage, choose Generate in the left panel, then choose Generate image.

Type a text prompt in the prompt bar.

In Styles, under Reference, browse to an image on your device, or choose Browse gallery to select from the reference image gallery.

Choose an image from your device, or look through the reference gallery for a suitable one.

Use a local image or a reference gallery image that matches the style direction you want.

When a reference image is added, the Strength slider becomes active.

The Strength slider sets how strongly the variations follow the reference image.

Adjust Strength to loosen or tighten the connection between the variations and the reference image.

For generated variations, move the Strength slider to set adherence to the reference image: right increases adherence, and left reduces it.

Under Effects, browse the categories and choose the effects you want.

Color tone, Lighting, and Camera angle can also refine the generation.

Tip

Applied effects appear in the Prompt field. Remove every effect with Clear, or delete individual effects separately.

Choose Generate.

## Create 3D scene for image generation reference

### Use shapes to build a 3D scene for image generation

Scene to image (beta) helps you find the right angle for composition or reference art. It uses shape-building technology from Project Neo (beta) to assemble 3D scenes, then combines the scene with a text prompt so the generated variations can use your scene composition, camera angle, and depth as reference.

Example output pairs a Project Neo (beta) 3D scene reference with an image produced in Firefly Text to image.

The example shows a Project Neo (beta) 3D scene used as reference beside the Firefly Text to image result.

On the Firefly homepage, choose Generate in the left panel, then choose Scene to image (beta) under the Image tab.

The Scene to Image page shows a split layout: the Neo 3D canvas appears on the left, and the generation window appears on the right. To focus on scene composition in a larger canvas-only view, use View 3D scene only at the lower right.

Switch the Neo 3D canvas between side-by-side and single-view modes when adding details to the 3D object and scene.

Use either the split layout or the canvas-only view while refining the 3D object and scene.

Start the scene with preset shapes from the left panel. Choose a shape and then click the canvas to place it, or drag a shape out from the panel to the canvas and resize it with the shape handles.

Choose shape presets and place them on the Neo 3D canvas to start building the 3D scene.

Start the 3D scene by adding preset shapes to the Neo 3D canvas.

Change the 3D model perspective with the view controls. Rotate, zoom in or out, and pan across the model to inspect it from different viewpoints and angles.

Pan, Zoom, and Orbit controls help navigate the 3D object, inspect details, and understand its space.

Use Pan, Zoom, and Orbit to move through the 3D view, examine details, and read the spatial layout.

Edit the shape with the 3D shape controls.

A. Edge beveling: smooths or softens the shape edges. B. Depth control: changes depth. C. Rotation control: turns the shape. D. Axis position control: shifts placement by axis. E. Manipulation of a model's position: moves the model. F. Scaling gizmo: resizes the 3D model on the X axis, Y axis, or Z axis. G. Rotation gizmo: rotates the model around the X axis, Y axis, or Z axis.

For further shape edits, choose Edit shape; for example, you can adjust scaling along a specific axis or soften a shape's edges.

With the shape selected, Properties lets you change these settings:

- Appearance: controls the material color applied to the 3D shape.
- Transform: changes Size (Width, Height, and Depth), Position (X, Y, and Z axis), and Rotation (X, Y, and Z axis).
- Combine: blends and combines shapes with available blending methods. For additional combining and blending techniques, use Project Neo (beta).

Change the selected 3D object's appearance and position to improve the look and place it where needed.

Adjust placement and appearance for the selected 3D object until it fits the scene visually.

After adding the 3D shapes, switch to View 3D scene only mode and choose the Environment icon to adjust lighting and shadows.

- Light Rotation: changes the light angle and direction, which moves shadows and alters how objects are illuminated in the 3D scene.
- Light Height: sets the light higher or lower, changing whether the scene is lit more from above or below.
- Shadow Distance: defines the maximum scene distance at which shadows appear.
- Floor height: sets the ground height in 3D space. Changing that height can alter the floor shadow angle.

Tune lighting and shadows so the scene has a more finished appearance.

Use the lighting and shadow controls to make the scene look more polished.

When the 3D scene is ready, choose the Adobe Firefly icon in the right panel to open the image generation controls. These controls are available:

- Content type: set Content type to Art for illustrative variations or Photo for realistic ones. You can also keep Auto, allowing Firefly to choose the content type that best fits your text prompt.
- Scene reference: use the 3D shape strength slider to determine how closely the generated image follows the 3D shapes in your scene. Use the Color strength slider to set how strongly the result keeps to the colors in your 3D scene. Higher values make the generated image colors match the scene colors more closely.
- Style reference: choose Upload image and browse for a reference image on your device. Adjust the Visual intensity slider to change the strength of the photo's visual attributes, and use the Strength slider to set adherence to the reference image while generating the image variations.
- Style effects: choose from style effects, including art movements and techniques, to guide the generated image variations.

Image generation controls let you tailor the variations toward the result you have in mind.

Adjust the generation controls to make the image variations better match your intended direction.
