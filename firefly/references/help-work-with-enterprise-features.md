## Style Kits overview

### Learn how Style Kits help collaborators keep generated image variations aligned with an on-brand style.

Note

Creating and saving Style Kits in Adobe Firefly requires entitlement to select enterprise plans. Without that entitlement, you can only use Style Kits shared with you through collaboration invitation links. If Firefly is provided through a company-owned account, contact your Adobe administrator to request access.

In Adobe Firefly, Style Kit supports collaboration and helps every image variation generated by collaborators stay consistent with the approved brand style.

After generating an image you want to reuse, save it as a Style Kit and specify which settings are hidden or locked, including the prompt and content, structure, style, and other specifications. Share the Style Kit with teammates so they can reuse approved styles, create faster, and maintain consistency.

Style Kits can be used in these ways:

- Save one for yourself so you can remember how a strong asset was made and create more assets in that style.
- Share with teammates who are working on a campaign and need to create content with one consistent style.
- Enable other users, including marketers, to make their own content while staying inside design and brand guidelines.
- Give the organization a way to use an official brand style.

## Create Style Kits

### Create Style Kits that teammates can share and use to speed up content creation.

Prerequisite:

Generate image variations by combining a text prompt with variation settings, including object additions, style, and compostion references.

After the image variations are generated, choose Save as style kit.

Type the kit name in the Save style kit dialog box.

In Settings, review which controls invited users may use for image variation generation. Unchecked entries are disabled or hidden.

Choose Save.

To share the kit, enter a recipient name or email address in the Share style kit dialog box.

If needed, add a message, then choose Invite to view.

You can also set access permission, copy the link, and share it directly.

Note

Saved Style Kits are available from the Files tab on the Firefly website. These Style Kits behave like other cloud-saved files and use your allocated Creative Cloud storage.

## Use shared Style Kits

### Learn how shared Style Kits generate image variations that retain a consistent, on-brand style.

Before you begin:

Confirm that a Style Kit has been shared with you. Look for the invitation in your email or in notifications from the Creative Cloud desktop app.

When you and invited collaborators have the required enterprise plan, Firefly saves shared Style Kits under the Files tab on the Firefly website. Without that plan, open the kit through the link in the invitation.

Open the shared Style Kit using the invitation link.

If your account has the required enterprise plan, you can also go to the Firefly website and use the Files tab in the menu bar to browse for and open the shared kit.

Browse Style Kits in the Files tab of the Firefly website.

Use the Files tab on the Firefly website to browse Style Kits.

In the Text to image editor, adjust the image with the settings that are available.

Note

- The Text to image editor shows only the controls that were checked when the Style Kit was created and saved. Controls that were not checked are hidden or turned off.
- Use the Reset icon in the Style Kit section to undo setting changes and return them to their original values.

Select Generate.

## Leave shared Style Kits

### Learn how to leave Style Kits that were shared with you when you no longer want to collaborate.

In the Files tab, hover over the Style Kit that you want to leave and stop collaborating on.

Select Leave, then confirm that you want to leave the Style Kit.

Note

After you leave a Style Kit, it is removed from the Style Kit tab and you no longer have access. Leaving a shared Style Kit does not delete it for the original creator.

## Delete Style Kits

### Delete Style Kits that have been shared with you.

Hover over the target Style Kit in the Files tab.

Note

Only the creator can delete a Style Kit.

Select Delete and confirm the deletion.

After deletion is confirmed, the Style Kit is permanently removed for you and for others you shared it with.

## Object Composites overview

### Combine product photos and objects into generated scenes with matching tones, colors, lighting, shadows, and textures.

Note

Object Composites in Adobe Firefly requires entitlement to select enterprise plans. If Firefly is provided through a company-owned account, contact your Adobe administrator to request access.

With Object Composites in Adobe Firefly, you can upload an image such as a product photo, then use a text prompt to generate a composited scene around that product.

Example workflow: upload a product photo, then use a text prompt to create a scene where the product is integrated smoothly.

Object Composites can be used to:

- Build compelling product shots with varied setups, backgrounds, and visual design treatments.
- Create professional, studio-quality headshots without heavy editing.
- Produce engaging social media creative with custom images and product photos.
- Show customers possible scenarios by presenting a product in different settings and environments.

## Create composite scenes with uploaded images

### Upload an image, such as a product photo, and build a composited product scene from a text prompt.

Note

Object Composites in Adobe Firefly requires entitlement to select enterprise plans. If Firefly is provided through a company-owned account, contact your Adobe administrator to request access.

Go to the Firefly website and select Text to image.

Choose Upload object and browse your device for a PNG or JPG file.

Use Upload object to add an object image that will be placed into the generated image variations.

Choose Upload object when you need to upload an object image for placement in generated image variations.

Use Remove background if you want to remove the background behind the object.

After the image uploads, use the Set position panel to set where the object should appear in the generated images.

Use Set position to choose the object's location in generated images.

Set position defines the object's placement for the generated images.

Choose Confirm.

Write a detailed prompt, then choose Generate.

Refine the image variations further with other Text to image settings, including content type, style references, and effects.

In the Reference section, upload an image to create variations that keep the uploaded object's style reference.

Upload an image in the Reference section so generated variations use the uploaded object while retaining the referenced style.

To resize or reposition an object and make new image variations, select the object so the frame around it is detected. As you resize or reposition it, the highlighted object indicates the expected placement of the image relative to its original position.

After positioning and resizing the object as desired, select Generate.
