## Generate images from text prompts

### Create compelling visual assets from short written descriptions.

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

In General settings, open the Model dropdown menu and choose from Adobe and partner models.

Alongside the Adobe models listed below, partner models are also available for creating image variations.

- Firefly Image 3
- Firefly Image 4
- Firefly Image 4 Ultra
- Firefly Image 5 (preview)

Note

Available image generation settings change according to the selected model.

Set Aspect ratio to control the dimensions used for the generated image variations.

For Content type, choose Art, Photo, or let Firefly automatically decide the content type from the prompt.

Adjust Visual intensity to control how strongly the image's visual attributes appear.

In Composition, upload an image to define the structure or composition, then have the generated variation follow that reference. Move the Strength slider to set outline intensity and depth adherence in the variations.

Use Styles when the generated image should follow the visual style and aesthetic of a reference image. Adjust Strength to control how closely the output follows that reference.

When a particular style is needed, choose from the available effects and optionally set Color and tone, Lighting, and Camera angle.

In the Prompt field, type a detailed description of the image you want to create.

Tip

- For effective text prompts, use simple direct language and include at least three words.
  - Prompt suggestions: Firefly can suggest prompts while you type the text description.
  - Prompt enhancement: Firefly can upgrade the prompt automatically (Available for Firefly Image 4 and Firefly Image 4 Ultra models).

Choose Generate to create a set of image variations.

The selected Model determines how many images are generated.

To see the generated variations in grid view, select the icon for that view. The History strip shows every image generation, with indicators for upscaled images.

Select the list-view icon to show the generated variations in a list, download all variations together, or use these actions:

- Use settings: uses the generated images' settings to make another set of images, without carrying over the text prompt.
- Generate more: uses both the settings and the text prompt to produce another set of image variations.

Use settings can create another batch of image variations, or you can rerun generation to make new variations from the same prompt and settings.

Use settings also lets you start another set of image variations or repeat the process with the same prompt and settings.

To see every generated image, select the History icon or the View all option above the prompt bar; Firefly opens the Generation history tab on the Files page.

Move the pointer over a generated variation to reveal editing, sharing, and download options.

Edit provides multiple editing choices, including the option to generate a video with Image to video.

Edit also exposes a collection of editing actions, among them video generation through Image to video.

## Generate images quickly using Fast mode

### Use a fast lower-resolution pass first, then upscale later for full-resolution downloads.

Fast mode in Text to image supports quick ideation, generation, and comparison of image variations at 512x512 resolution. You can download those images as-is or use Upscale to convert them to 2K resolution for improved quality. Fast mode works best for simple topics, backgrounds, most illustrations, and close portraits.

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

In the Model section, open the dropdown menu and choose Firefly Image 3.

Turn on Fast mode to produce lower-resolution images quickly and upscale them afterward.

Fast mode supports quick rounds of iteration and image adjustment before committing to high-resolution output.

Fast mode lets you compare and refine generated images rapidly before producing higher-resolution versions.

Set Aspect ratio to choose the proportions for the generated image variations.

Choose an aspect ratio that fits the intended use for the image variations.

Pick an aspect ratio so the generated variations match the format you need.

For Content type, choose Art or Photo, or let Firefly automatically select the content type from the prompt.

Turn on the Auto toggle button when Firefly should automatically choose the content type from the prompt.

Use the Auto toggle button to have Firefly determine the content type from the prompt by itself.

Under Reference, use these options to steer generated image variations with an existing reference image:

- Composition: upload an image to define the structure or composition and help the generated image variation follow it. Adjust the Strength slider to set outline intensity and depth adherence in the generated variations.

Add an image as the composition reference, then adjust strength to control adherence in the generated variations.

Use a composition reference image and tune strength to define how closely generated variations follow it.

- Style: steer new image variations toward the reference image's look and aesthetic. Move the Visual intensity slider to change the strength of the photo's visual attributes, and use Strength to control adherence to the reference image.

Guide new image variations so they align with the reference image's visual style and aesthetic.

Use the reference image to steer generated variations toward its visual style and aesthetic.

Choose the effects to apply, then set Color and tone, Lighting, and Camera angle.

Select effects and combine them with text prompts plus other settings to produce image variations.

Choose from available effects and pair them with text prompts and settings to create image variations.

In the Prompt field, type a detailed description of the image you want to generate.

Tip

- For effective text prompts, use simple direct language and include at least three words.
- Turn on Prompt suggestions beside the Generate button so Firefly can suggest prompts while you type in the prompt bar.
- When the image should include specific text, place that text in quotation marks. For example, "Firefly" or "Hello".

Choose Generate to create a set of image variations at 512x512 resolution.

Use Upscale all to convert all generated image variations to 2000x2000.

Choose Upscale all when every generated image variation should change to 2000x2000.

Use Upscale all to move the full set of generated image variations to 2000x2000.

Upscale all upscales all four generated images and consumes one credit.

Hover over the images to download them or open editing and sharing options.

## Writing effective text prompts

### Learn to write text prompts on the Adobe Firefly website that produce the image variations you want.

Prompts tell AI what task to perform or what output to make. They strongly shape AI behavior and affect the quality and relevance of the response. Use descriptive prompts to create extraordinary, vibrant images; when the result misses the mark, revise the prompt until it moves closer to your goal.

Adobe Firefly lets one idea branch into many possible results.

### Be specific

Use at least three words in prompts, avoid terms such as generate or create, and write in simple direct language that includes a subject, descriptors, and keywords.

- A fluffy cat perched on a windowsill while looking toward a city skyline.
- Three inverted waterfalls flowing through a fantastical alien landscape.
- A time traveler's crowded workshop packed with futuristic gadgets and historical artifacts.

### Be descriptive

Text descriptions can produce almost anything, and adding detail increases the chance that the images will reflect your intended vision.

- A woman with long flowing hair and blue eyes wearing a white dress in a flower field, realistic picture.
- A realistic tropical island paradise with pristine turquoise water, lush greenery, and vibrant exotic fruit.
- A steampunk submarine traveling underwater past bioluminescent sea creatures.

### Be original

Move past basic descriptions by adding your own point of view through mood, style, and lighting details.

- A serene beach at sunset with gentle waves and palm trees.
- A distant galaxy filled with colorful nebulae and twinkling stars.
- Stylish burgundy high heels with a futuristic design, translucent materials, and intricate metallic details.

### Be empathetic

Images generated from text become more engaging, memorable, and relevant when they match the audience's interests. That alignment helps ideas come across more clearly and makes the content stronger. For a heartwarming image, use words like love, gentle, and playful; for an inspiring image, use powerful, strong, and uplifting.

- A lonely man standing at the edge of a desolate cliff and looking over a vast barren landscape, lo-fi.
- A tender moment where a child has a heartfelt conversation with an elderly grandparent, love, wisdom.
- A joyful carnival with colorful balloons, lively performers, and rainbow-hued decorations, orange, purple.

### Use professional tools

Firefly can move with your exploration instead of locking you to the first idea. Revise text prompts and adjust settings until the image matches what you want, then refine it manually in the image editor or in apps such as Adobe Photoshop and Adobe Illustrator.

## Save your generated images as favorites

### Learn how to mark generated images as favorites so they are easier to find later.

Note

Starting August 27, 2025, favorites saved in the browser remain available only temporarily and will then be permanently deleted. This cannot be undone. To keep favorites, download them to your device or open them so they are saved to your generation history.

### Save to Favorites from the generated image variations

Generated variations can be marked as favorites immediately, so the images remain easy to find later without combing through the complete generation set.

From the Adobe Firefly homepage, open Text to image.

Provide a prompt, set the image generation options you need, then choose Generate.

Move the pointer over the image that should become a favorite.

Choose the Save to Favorites icon.

The Save to Favorites option stores a generated image in your favorites.

Save to Favorites can be used to keep generated images available from Favorites later.

### Save to Favorites from generation history

Even when an image or video was not favorited while it was being created, generation history still lets you locate it and add it to Favorites afterward.

From the Adobe Firefly homepage, choose Files.

Open the Generation history tab, then narrow the list to images or videos with the dropdown menu.

After finding the image or video you want to keep, choose the icon or open the More menu and choose Favorite.

The selected image or video can be favorited from its context menu.

Use that item's context menu when you want to add it to Favorites.

When the confirmation message says the image or video has been saved to favorites, open the Favorites tab to see it.

Favorites lists every image and video you have marked as a favorite.

Favorites lists every image and video you have marked as a favorite. Note

To take an item out of Favorites, locate that image or video, then choose the Remove favorite icon, or open the More menu and choose Remove favorite.

## Enhance prompts to generate images

### Improve prompts for image generation

For image creation with Firefly Image 4 and Firefly Image 4 Ultra, Prompt enhancement can be enabled so Firefly improves prompts automatically. In the background, the feature adds detail and descriptive language to the prompt, helping the generated results become richer and more varied.

Note

For Firefly Image 4 and Firefly Image 4 Ultra models, Prompt enhancement works only with English-language prompts.

On the Firefly homepage, open the Image module, then choose Text to image.

On the Text to image page, find General Settings and set the model to Firefly Image 4 or Firefly Image 4 Ultra.

Use the left panel sections Content type, Visual intensity, Composition, and Style to tune the generation settings.

After the settings are ready, type the description for the image into the prompt bar.

A text prompt supplies the description Firefly uses to generate the image.

Enter prompt text when you want the image generation to follow your description.

Next to Generate, choose the Prompt feature icon and confirm that Prompt enhancement is turned on by default.

Prompt enhancement can automatically refine the text prompt before image generation.

Enable Prompt enhancement when you want Firefly to improve the prompt automatically.

Choose Generate to create the image variations.

After generation finishes, the prompt bar shows Show enhanced, which opens the enhanced prompt for review.

Show enhanced displays the expanded, more descriptive prompt text.

Choose Show enhanced to inspect the prompt after Firefly has added detail.

The enhanced prompt can be edited to produce another set of images; Show original returns you to the pre-enhancement wording.

Show original brings back the prompt text as it existed before Prompt enhancement changed it.

Choose Show original when you need to compare against the pre-enhancement prompt.
