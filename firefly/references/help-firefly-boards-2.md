## Partner models to generate images

### Generate image variations in Firefly Boards with Adobe models and partner models.

While working in Boards, you can create image variations and put them directly on the canvas. The available choices can include Adobe models and partner models.

When a partner model is selected for image generation, Firefly Boards asks you to confirm that the model was not developed by Adobe and shows other relevant details. Review that information, then choose OK to continue.

## Edit images

### Review every editing choice that becomes available after you place an image on the canvas in a mood board.

After an image has been added to the canvas and selected, Firefly presents several editing choices for improving, changing, and tailoring that image.

### Properties panel

Select an image on the canvas, then choose the Properties icon to open the Properties panel, where image attributes can be changed:

The Properties panel provides controls for the Transform and Appearance properties on the selected image.

Use Properties to change the selected image's Transform and Appearance settings.

- Transform: Enter a rotation value and flip the image vertically or horizontally.
- Appearance: Choose a blend mode that controls how the image combines with other canvas elements, and adjust the image opacity.

### Image context menu

### Vary

Start from an image on the canvas and create a fresh set of variations that keep a related style or composition while introducing small differences.

With Vary, you can examine several creative readings of an image that is already on the canvas.

Vary gives you alternate interpretations of a placed canvas image without losing the source image's general direction.

### Edit

For a canvas image, Edit exposes tools that range from Generative expand to advanced edits powered by partner AI models.

- Generative fill: Use simple brush strokes and text prompts to add elements or remove existing content from images without destructive changes.

On the canvas, use Generative fill to add details to the image or subtract details from it.

Generative fill lets you revise the canvas image in place by painting in or removing details.

- Generative expand: Extend an image canvas, then add missing details or new material in the expanded region. In the Prompt bar, describe how the background should continue, or leave the prompt empty to have the extension follow the existing image.

With Generative expand, extend and fill the image either from a text prompt or automatically from the image composition.

Use Generative expand to grow the image area and complete it from your prompt or the current composition.

- Edit text in image (beta): This feature finds text in the selected image and lets you edit or replace that text while keeping the image background and style.

Use Edit text in image to turn text that appears inside an image into editable text.

Edit text in image converts detected image text into text that can be changed.

In Boards, you can import your own videos, use stock footage, or generate new videos with generative AI models from Firefly and non-Adobe providers.

On the Firefly homepage, choose Boards.

On the Boards page, choose Create new board.

To add a video file from your device, choose the Import option in the left panel and place it on the canvas.

For Adobe Stock videos, choose the icon in the right toolbar, then use the Search panel to find, browse, and add videos to the canvas.

From the list of Firefly and partner models, pick the video model to use for generation.

You can choose either Adobe or a partner model to create a video and add it to the board.

## Generate image variations

### Use an image already on the canvas to produce new images that keep a related style or composition with slight variations.

In Firefly Boards, the Vary feature supports fast exploration of alternate creative directions for a canvas image. Rather than beginning with an empty prompt, you can create new images that retain the image's main idea while varying the style, composition, or elements. This makes it easier to iterate quickly and test different visual styles and concepts.

### Before you begin

Upload or generate an image, then add it to the canvas.

Select the image on the canvas.

Choose the Vary icon to generate variations with the Firefly Image model.

Select a canvas image and use Vary to create several related image variations.

Use Vary on an image in the canvas to generate multiple similar variations.

Choose from these three options:

- More like this: Generate images that remain close to the original image's composition, mood, and idea.

Use More like this to create images that strongly resemble the original.

More like this generates images that closely follow the source image.

- Keep style: Maintain the original image's artistic treatment, such as watercolor, photorealism, or another recognizable technique.

Use Keep style to retain the original image's artistic look.

Keep style preserves the visual style used by the original image.

- Keep subject: Keep the original image's primary subject intact, whether the subject is a person, animal, or object.

Use Keep subject to retain the original image's main subject.

Keep subject keeps the main subject from the source image in place.

After variations have been generated, you can edit and rearrange them in the same way as other images on the canvas.

Select any generated image to access these editing and adjustment choices:

Use the editing options to continue refining the image or to make other adjustments.

The edit controls let you further refine the image and apply additional adjustments.

## Collect, arrange, and align elements in canvas

### Collect, arrange, and align visual elements on the canvas with layouts, layers, and spacing controls.

After using Firefly Boards to explore and gather visual elements, begin arranging those elements so they fit the theme and direction of the board. Different layouts, layered elements, spacing, and alignment controls help create a cohesive, polished composition.

### Collect visual elements in the canvas

In Firefly Boards, Collect items brings selected visual elements, including images, colors, and videos, together on the canvas. The feature places those items into a grid layout inside an artboard and automatically applies an appropriate arrangement.

Before you begin

Create an artboard, then add visual elements such as images, videos, and shapes.

On the canvas, select multiple elements, such as images, videos, or shapes.

From the context menu, choose Collect items to collect the selected elements into a grid layout within an artboard.

### Arrange images, videos, and shapes

Selecting multiple visual elements on the canvas lets you organize and arrange them in a structured layout.

On the canvas, select multiple elements, such as images, videos, or shapes.

Open the context menu, point to the Arrange icon, and use the dropdown choices to set the selection as rows, columns, or a mosaic layout.

After the elements are arranged in the chosen layout with consistent spacing, adjust the spacing with the magenta-colored spacer bar.

Move the cursor over the space between elements to make the spacing larger or smaller.

Hover between elements to increase or reduce the spacing.

### Align images, videos, and shapes

With several canvas elements selected, you can align them left, right, or center, or distribute them evenly across the layout.

On the canvas, select multiple elements, such as images, videos, or shapes.

In the context menu, point to the Align icon, then choose one of these alignment options:

- Align left
- Align center
- Align right
- Align top
- Align middle
- Align bottom
- Distribute horizontally
- Distribute vertically

### Layer images, videos, shapes, and texts

On the canvas, select multiple elements, such as images or videos.

From the context menu, choose the icon, then select one of these options:

- Bring to front
- Bring forward
- Send backward
- Send to back

### Group images, videos, shapes, and texts

On the canvas, select multiple elements, such as images or shapes.

From the context menu, choose the icon, then choose Group.

Note

If text is included in the canvas elements you select for arrangement, Collect items and Arrange are not available.
