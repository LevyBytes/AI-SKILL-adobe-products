## About Firefly Boards

### Use Firefly Boards for early idea exploration, moodboards, storyboards, and pitch materials.

Note

Anyone with an Adobe account can open Firefly Boards. Users who have premium feature access can create unlimited boards, while other plans are capped at 3 boards.

Generative AI features, including image generation, background removal, generative fill or expand, and video generation, require generative credits. Premium features, such as using partner models to generate images and videos, require a Creative Cloud subscription with premium feature access.

### What can I do with Firefly Boards?

Firefly Boards lets you bring in images and sketches, look through stock imagery, or create new images. After gathering those visuals, you can choose what to do next.

Note

Firefly Boards uses Content Credentials to acknowledge where images came from, honor generative AI usage and training preferences, and make content-creation history more transparent in support of artists' work.

## Remix images

### Remix material from several images directly on the canvas to produce original visuals.

In Firefly Boards, Remix lets you explore visual directions by combining elements from multiple canvas images. The Firefly Image Model creates a new set of image variations, and auto-generated text prompts can be used to refine them. This workflow can make board imagery more cohesive and distinctive while reducing the effort of building every element manually.

### Before you begin

First, add images to the canvas.

Choose more than one image so extra editing and arrangement controls become available.

Choose the Remix icon.

Pick the board images that you want to remix into new generated variations.

The canvas receives the remixed image variations together with an indicator for the image model used to create them.

The canvas receives the remixed image variations together with an indicator for the image model used to create them.

To revise generated variations, select them one at a time and use Load so their related text prompt fills the prompt bar automatically. After editing the prompt, use Generate to produce another set of variations.

To adjust a remixed image prompt, use Load to place the remixed text description in the prompt field.

## Add comments

### Add comments to a mood board for collaboration or independent notes.

Comments are useful whether a mood board is shared with collaborators or used privately. They can explain your vision to others or act as personal reference notes that keep the project organized. For shared mood boards, comments make it easier to collect feedback, begin discussions, gather reviews, and handle edit suggestions.

### Filter comments

Select the icon to open the Comments panel.

Use Filter options to list only the comments you want to review and handle.

Use Filter options to list only the comments you want to review and handle.

The comments can be filtered by choices under these parameters:

- Reviewers: contributors' names for people who left comments.
- Time: the day when the comment was added.
- Status: comments that have been marked resolved.
- Unread comments: new comments that have not been read yet.
