## Text-based editing

### Text-based editing overview for transcript-driven video edits

Text-based editing is useful for dialogue-heavy footage, including interviews, documentaries, and podcast content. Rather than searching through timelines or waveform displays, edit by acting on the transcript itself. Cutting, rearranging, and refining happen through text selections, which speeds up the process.

### Key features of Text-based editing

- Auto-transcribe your footage: Generate a transcript automatically and align spoken dialogue to timecodes, so transcript text can be searched, navigated, and selected as clip ranges.

- Edit Using Text: Build rough cuts by choosing transcript text and moving it into the desired order. Matching video sections are trimmed automatically and added to the timeline as the text changes.

- Fine-tune with precision: After the rough cut lands in the timeline, continue refining it by trimming clips or changing their order against the spoken words.

- Clean up dialogue easily: Find filler words such as "uh" and "umm" quickly and remove them in bulk. You can also filter by speaker and delete that speaker's dialogue.

## Known limitations in Firefly video editor

### Understand possible limitations while using Firefly video editor.

### Firefly video editor access

### Browser compatibility for Firefly video editor

Firefly video editor currently works only in the Chrome desktop browser. Edge, Firefox, Safari, and other browsers may not provide access to every feature yet.

### Device compatibility for Firefly video editor

Firefly video editor currently supports macOS and Windows systems in these categories:

- Mac computers that use Apple silicon (ARM-based) processors
- Mac computers with Intel processors
- Windows computers with Intel processors

### Working with Firefly video editor

### File size and duration limitation

Files added to the video editor need to stay below 20 GB and at or under 4 hours. Anything beyond either the size cap or duration cap is not supported right now.

Imported video and image files must be 3840 x 3840 pixels or smaller in resolution.

### Thumbnails not generated for certain videos

Timeline thumbnail generation is not available when media dimensions are greater than 3840 pixels.

### Working with GIF and WEBP files

When animated GIF or WEBP files are added to the timeline, their animation is not preserved. The timeline displays only the first frame, although Your media still shows the file as animated.

### Videos generated with the Transparent background option

Videos brought in from the Generation history panel after being generated with Transparent background may not display as expected. The reason is that generated videos with transparent backgrounds are not fully supported in Firefly video editor yet.

## Can't generate videos in Firefly video editor

Use these fixes when video generation is not working in Firefly video editor.

Problems generating video in Firefly video editor are usually tied to missing settings, account access limits, low credits, or short-term service interruptions.

You might see any of these conditions:

- The Generate button is disabled
- Choosing Generate has no effect
- Generated videos are missing
- Errors mention insufficient credits
- Reference files do not upload

### Required inputs are missing or your account does not have access to Firefly video features

If Generate is shown as disabled:

- Add a text prompt when the selected model requires one.
- Visit the Firefly homepage and look for account-related errors.
- For organization accounts, ask your admin to verify that Firefly access is enabled.
- Confirm that your account is not blocked from third-party model access.

### Temporary service disruption or page state issue prevents generation from starting

When choosing Generate has no visible effect, i.e., it never changes into a progress indicator that remains on screen briefly, use this sequence:

Reload the Firefly video editor page.

Use the Generate video page to try generation again.

Open the Generation history panel and refresh it to look for completed outputs.

Check the Adobe Status page for Firefly service alerts.

### Generated videos are hidden due to filters or delayed synchronization

When expected media is missing from the Generation history panel, use this sequence:

Go to the Generation history panel.

Change the filter to All or Video.

Confirm that Favorites is not selected.

Sort by Newest first, then scroll to the top.

If a placeholder thumbnail that says "Still working..." or "Generating..." remains in the Generation history panel after several seconds, refresh the page.

Check the Generation history page to verify that the video exists.

Go back to the editor and refresh so results sync.

### Your account does not have enough generative credits

If an onscreen error says "Insufficient credits...", use these steps:

Select your profile avatar.

Open the Generative AI section to see available credits.

Review the current generation settings so you understand credit usage.

Select Get Credits to buy more credits or upgrade the plan.

### Reference image or video does not meet supported requirements

Use the upload error as the guide: adjust the file until it satisfies the listed requirements, then upload it again.

- For images: confirm that the file format and dimensions are supported.
- For videos: check the format, resolution, duration, and frame rate.

### Partner model-specific or other uncertain issues

- Generate again with another model.
- Look at the Adobe Status page for any active service issues.
- If it still fails, use the remaining troubleshooting resources.
