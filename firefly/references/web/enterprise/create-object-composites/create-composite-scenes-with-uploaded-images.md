# Create composite scenes with uploaded images

Upload an image, such as a product photo, and build a composited product scene from a text prompt.

Note

Object Composites in Adobe Firefly requires entitlement to select enterprise plans. If Firefly is provided through a company-owned account, contact your Adobe administrator to request access.

Go to the Firefly website and select Text to image.

Choose Upload object and browse your device for a PNG or JPG file.

Use Upload object to add an object image that will be placed into the generated image variations.

Choose Upload object when you need to upload an object image for placement in generated image variations.

Use Remove background if you want to remove the background behind the object.

After the image uploads, use the Set position panel to set where the object should appear in the generated images.

Use Set position to choose the object's location in generated images.

Set position defines the object's placement for the generated images.

Choose Confirm.

Write a detailed prompt, then choose Generate.

Refine the image variations further with other Text to image settings, including content type, style references, and effects.

In the Reference section, upload an image to create variations that keep the uploaded object's style reference.

Upload an image in the Reference section so generated variations use the uploaded object while retaining the referenced style.

To resize or reposition an object and make new image variations, select the object so the frame around it is detected. As you resize or reposition it, the highlighted object indicates the expected placement of the image relative to its original position.

After positioning and resizing the object as desired, select Generate.

The highlighted object indicates where the image is expected to sit compared with its original position.

The highlighted object shows the expected image placement relative to the original position.
