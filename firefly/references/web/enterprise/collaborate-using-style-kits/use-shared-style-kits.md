# Use shared Style Kits

Learn how shared Style Kits generate image variations that retain a consistent, on-brand style.

Before you begin:

Confirm that a Style Kit has been shared with you. Look for the invitation in your email or in notifications from the Creative Cloud desktop app.

When you and invited collaborators have the required enterprise plan, Firefly saves shared Style Kits under the Files tab on the Firefly website. Without that plan, open the kit through the link in the invitation.

Open the shared Style Kit using the invitation link.

If your account has the required enterprise plan, you can also go to the Firefly website and use the Files tab in the menu bar to browse for and open the shared kit.

Browse Style Kits in the Files tab of the Firefly website.

Use the Files tab on the Firefly website to browse Style Kits.

In the Text to image editor, adjust the image with the settings that are available.

Note

- The Text to image editor shows only the controls that were checked when the Style Kit was created and saved. Controls that were not checked are hidden or turned off.
- Use the Reset icon in the Style Kit section to undo setting changes and return them to their original values.

Select Generate.
