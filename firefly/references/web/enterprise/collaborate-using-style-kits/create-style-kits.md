# Create Style Kits

Create Style Kits that teammates can share and use to speed up content creation.

Prerequisite:

Generate image variations by combining a text prompt with variation settings, including object additions, style, and compostion references.

After the image variations are generated, choose Save as style kit.

Type the kit name in the Save style kit dialog box.

In Settings, review which controls invited users may use for image variation generation. Unchecked entries are disabled or hidden.

Choose Save.

To share the kit, enter a recipient name or email address in the Share style kit dialog box.

If needed, add a message, then choose Invite to view.

You can also set access permission, copy the link, and share it directly.

Note

Saved Style Kits are available from the Files tab on the Firefly website. These Style Kits behave like other cloud-saved files and use your allocated Creative Cloud storage.
