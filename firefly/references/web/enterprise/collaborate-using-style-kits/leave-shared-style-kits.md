# Leave shared Style Kits

Learn how to leave Style Kits that were shared with you when you no longer want to collaborate.

In the Files tab, hover over the Style Kit that you want to leave and stop collaborating on.

Select Leave, then confirm that you want to leave the Style Kit.

Note

After you leave a Style Kit, it is removed from the Style Kit tab and you no longer have access. Leaving a shared Style Kit does not delete it for the original creator.
