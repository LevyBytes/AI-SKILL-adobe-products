# View and edit properties for a text layer placed on the timeline.

After text is added to the timeline, its properties can be customized for the intended look and feel. Available settings include font style, size, color, alignment, position, and opacity. You can also add effects such as shadows or outlines to help the text stand out. These controls help match titles, captions, or credits to the video's overall theme.

Before you begin:

Start with a new project where text has already been added to the timeline.

On the video editor page, select the timeline text layer to begin changing its properties.

The Properties panel turns on and shows these adjustable properties:

Use the Properties panel to change text settings such as position, size, opacity, and more.

- Flip horizontal: mirrors the image left to right.
- Flip vertical: flips the image upside down from top to bottom.
- Rotate clockwise: rotates the image 90° clockwise with each click.
- Align: snaps the image to the center or frame edges for accurate positioning.

- Font family: selects and sets the typeface.
- Font style: sets the text appearance by choosing a type such as bold, italic, or regular.

- Alignment: sets how text aligns inside its text box.
- Text layouts: defines the way text is arranged in its container.
- Text spacing: sets spacing between letters and lines.
- B (Bold): applies bold styling to the text.
- I (Italic): applies italic styling to the text.
- U (Underline): applies an underline to the text.
- Font size: changes text size with the slider.

Use the Properties panel to set text spacing between letters and lines.

- Position: sets where the text is located.
- Rotate: changes the angle of the text box.
- Opacity: sets text visibility or transparency.

- Fill: sets the text color.
- Outline: adds a border and lets you change its thickness.
- Background: adds a background color behind the text box.
- Shadow: applies shadow effects for depth and emphasis. You can set the shadow color and adjust properties such as blur, angle, and offset.

Use Shadow properties to set color, blur, angle, and distance.

The preview reflects property changes as you make them.
