# Adjust the timeline aspect ratio during a video edit.

As you add a media file for a new video editing project, Firefly asks for the project name and the Timeline aspect ratio method. Pick a predefined aspect ratio yourself, or choose Automatic so the imported footage determines the fit.

Choose the aspect ratio while adding media for a new video editing project.

The media import flow includes the timeline aspect ratio setting.

The timeline aspect ratio can also be changed during editing, even after media files are already on the timeline.

Open the menu icon in the upper-left corner of the page, then select Timeline > Properties.

Open Timeline properties when you need to adjust the aspect ratio.

Timeline properties is where the aspect ratio can be changed. Tip

You can also open the Timeline properties panel with the Properties icon when the project has no timelines yet.

The Timeline properties panel becomes active.

From the Aspect ratio dropdown menu, choose a preset.

Select one of the aspect ratio presets to update the timeline shape.

Aspect ratio presets let the timeline match the intended output frame.
