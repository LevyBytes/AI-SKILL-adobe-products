# Common Enhance Speech questions, with answers.

Enhance speech works across many desktop and mobile browsers. The latest versions of these browsers are supported:

- Google Chrome
- Apple Safari
- Microsoft Edge
- Mozilla Firefox

Note

Audio upload and download speed varies based on internet connection speed and device memory. If problems occur, update the browser to the latest version or clear the browser cache.

Audio formats and video formats are both supported.

Note

Premium users can use bulk upload and video upload. Learn more about different plans for the Enhance Speech feature.

The following details cover the maximum supported file sizes and durations for audio and video uploads.

Enhance speech does not change the file format during download. The download returns the same format you imported; for example, importing an .mp3 file returns an .mp3 file.

The free plan supports processing files up to 30 minutes long, with a maximum 500 MB file size and a daily limit of 1 hour. The Premium plan supports up to 4 hours of content each day, with individual files up to 1 GB. Learn more here.

Enhance speech is language agnostic and does not generate content in other languages or translate between languages. Output quality often depends on how audible the speaker is and how much background noise is present. Clearer, more polished input, including speaker pronunciation and enunciation, produces better output. The tool enhances audio by filtering noise and artifacts, adjusting pitch and volume levels, and normalizing the audio.

Start by checking the supported formats to confirm that the uploaded file type is accepted. If format is not the problem, open the avatar and/or initials menu in the top-right corner and check Enhance speech usage for the current plan's daily limits.
