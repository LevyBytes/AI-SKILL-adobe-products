# Create a timeline in a project

Create a project timeline so media files can be added, organized, and edited.

In Firefly video editor (beta), the timeline is the main workspace for arranging and editing a video. It is a horizontal area that places video, audio, and images in playback order over time. The playhead, shown as a vertical line that travels across the timeline, lets you move through the project and inspect what occurs at each moment. Use this area to arrange clips, trim or cut sections, and produce the finished edit.

A project timeline with a video already added.

Before you begin, start from a project timeline that contains video.

Create a project and have the media files ready to upload.

Select New project on the Get started prompt, then use these options to place media on the timeline:

- Add your media option for uploading local files
- Generate a video with the Firefly Video model
- Move items out of the Generation history panel.

Start a new project when you are ready to edit in Firefly video editor (beta).

The new project opens for editing in Firefly video editor (beta).

You can also select Upload media on the Get started prompt to add media to the project. A timeline is created automatically.

Import media into the Video editor so it builds a timeline and you can start editing.

Uploaded media opens as a timeline in the Video editor for immediate editing.

To create another timeline while one is already open, use the menu in the page's upper-left corner and choose New timeline.

Use New timeline to add another timeline for organizing the video project.

Additional timelines help keep separate edits or sections organized.
