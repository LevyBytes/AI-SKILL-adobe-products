# Fix pronunciation in the speech text

Fix pronunciation by changing how selected words sound in generated speech.

In Firefly Generate Speech (beta), some words may not be pronounced the way you expect. Proper names, technical terms, and words with several pronunciations can require adjustment. Fix Pronunciation lets you change those word sounds so the speech matches your preference.

Before you begin:

Add speech text or upload a text file, then set the voice, accent, and other options.

In the text editor, find and highlight the words that require pronunciation adjustment.

From the context menu, select Fix Pronunciation.

Use Fix Pronunciation to control how selected words sound in generated speech.

In the text box, type the word phonetically, matching how it should sound. For example, type "uhn-fer-GET-uh-buhl" to pronounce "unforgettable" correctly.

For accurate output, make sure the phonetic text is correct.

Select the icon to play and preview the adjusted pronunciation.

If the word sounds right, select Fix to update only the selected instance.

To use the adjusted pronunciation for every occurrence of the word in the audio, select Fix all.

Tip

After fixing pronunciation, generate a new version and play the whole audio back to confirm the updated pronunciation is used in the rest of the generated speech.
