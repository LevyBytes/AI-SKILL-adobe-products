# Add pauses to the speech text

Insert pauses in speech text for more natural, expressive generated speech.

Generate Speech (beta) lets you insert pauses after adding text or uploading a file, then adjust pause length so the output follows the intended rhythm, pacing, and natural flow.

Before you begin:

Add speech text or upload a text file, then set the voice, accent, and other options.

In the text editor, position the cursor where the speech pause should be inserted.

At the bottom Generate bar, select Add pause.

Select Add pause to create pauses that make generated speech sound natural.

A horizontal line appears with the pause length shown in seconds. The default pause length is one second.

Select the horizontal line to change the length of the added pause.

Select the pause indicator to open options for modifying the pause length.

Choose the desired pause time to set a pause length from 0.25 to 3 seconds.

Add all needed pauses, then select Generate.

Preview the generated speech, then use Download to save it locally.

Before downloading, review the generated speech by playing it or scrubbing through it.
