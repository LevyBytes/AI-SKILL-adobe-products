# Generate speech using partner models

Use partner models to generate audio clips with different voices, tones, and accents.

Generate Speech (beta) can use partner models to quickly create natural-sounding voice-overs. Speech generation controls such as speed and stability let you set different voices and tonalities.

On the Firefly homepage, select Generate in the left panel, then choose Generate speech (beta).

In the Partner model differences dialog box, review the model-specific feature differences and select Continue.

Grant permission to use Adobe partner model for speech generation.

On Generate speech, paste the text to turn into speech, or select Import text from a file and upload a DOCX or TXT file.

After adding the text, open the Speech settings panel on the left and use Model to select ElevenLabs Multilingual v2.

Note

Audio clips can also be created with the Firefly Speech model.

Open the Voice dropdown menu and choose a voice.

Pick the voice that best fits your project's requirements and creative goals.

Shape the selected voice with the available general settings.

- Speed: drag the Speed bar right to make generated audio faster, or left to make it slower.
- Stability: drag the Stability bar right to increase generated audio stability, or left to decrease it.
- Similarity: drag the Similarity bar right to make the audio more similar to the selected voice, or left to reduce similarity.
- Style Exaggeration: drag the Style Exaggeration bar right to increase adherence to the selected audio style, or left to reduce it.
- Speaker boost: turn on Speaker boost to increase similarity in the synthesized voice and speech.

Tip

- At the bottom of the left panel, select the icon to play a sample of the voice with the selected speed, pitch, and accent.
- Select the icon to add the voice to favorites.

Additional edits can be made in the main text editor window:

- Play: previews selected text in the uploaded content before generation.
- Find & Replace: selects words and replaces them.

Use Play to quickly hear how the text sounds with the selected voice settings.

Use Play to quickly hear how the text sounds with the selected voice settings. To add more script text and view writing tips, use the Generate bar and choose from these selections:

- Add Text: imports a TXT or DOCX file to add more text to the uploaded content.
- Show Tips: opens writing tips for producing the best possible results.

Select Generate.

When the generation sounds right, use Download to save the audio file locally.
