# Generate sound effects

From Adobe Firefly, open the Audio module and select Text to sound effects.

Use the Prompt field to describe the sound effect you want generated.

Tip

Review effective prompt-writing techniques for sound effects generation.

Write a detailed description of the sound effect you want.

Provide enough detail to define the sound effect to generate.

Note

At this time, text prompts support only English.

Select Generate .

Generated variations are shown above the timeline. Play each option, then choose the variation you want to add to the timeline.

Preview generated sound effect variations with play controls before placing one on the timeline.

Listen to the generated sound effect options first, then add the preferred one to the timeline.

The chosen sound effect is inserted on the timeline at the current playhead position.

To reposition the sound effect on the timeline, hover over it and drag with the grab cursor to the desired location.

Selecting a sound effect on the timeline shows controls to mute it, change volume, download, rename, or delete it.

Use timeline editing tools to adjust generated sound effects in place.

Generated sound effects can be edited directly on the timeline with the available tools.

Tip

Trim a generated sound effects clip by dragging either end's trim handle inward. After trimming, reposition the clip on the timeline as needed.

To add another sound effect on the same audio track, put the playhead where the new sound should go and prompt again. To layer sounds, select Add Audio Track to create another track, then generate from the Prompt bar.

Use Add Audio Track when you need another generated sound effect on the timeline.

Add Audio Track lets you place an additional generated sound effect into the timeline.

After the new sound effect is placed, press the spacebar or the main play button above the timeline to preview the composition. Use Download to download the composed sound clip.
