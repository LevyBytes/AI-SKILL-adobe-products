# Start a new project so you can begin editing video.

From the Firefly homepage, choose Edit video.

On the Video editor prompt, choose one of these ways to begin:

- New project: opens a blank project in the editor so you can add and edit videos.

- Upload media: lets you select files and create a timeline in a new project.

  - Generate with Firefly: creates videos with the Firefly Video model and adds them to the timeline.
  - Browse generation history: opens your video generation history so previously created videos can be selected and added to the timeline.

- Start with popular social platforms: uses aspect ratio presets for social media platforms such as TikTok, Instagram, and Facebook.

Choose from the available starting options when creating a new video editing project.

Use one of the provided options to begin a new project for video editing.

Use the rename option at the top left of the page to replace the default project name.
