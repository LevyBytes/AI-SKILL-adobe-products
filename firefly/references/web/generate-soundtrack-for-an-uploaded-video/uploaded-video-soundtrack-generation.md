# Generate original soundtracks for uploaded videos in Adobe Firefly.

With Generating soundtrack (beta), uploading a video gives you a tailored prompt based on content attributes such as vibe, style, purpose, energy, and tempo. The prompt can then be customized and refined to better fit your needs.

On the Firefly homepage, select Generate from the left panel, then open the Audio tab and choose Generate soundtrack.

On Generate soundtrack, the left panel includes a sample prompt. Colored text in that prompt shows the structure used to separate different soundtrack generation dimensions.

Different label colors identify Vibe, Style, and Purpose selections in the soundtrack generation prompt.

To create a soundtrack for your video, add the video with Upload Video.

After the video is analyzed, Firefly provides a starting prompt based on the video's attributes; you can edit and customize it before generating the soundtrack.

Revise the suggested prompt so it fits the specific need.

When Firefly is used on a mobile device to upload a video, the file must be MOV or MP4 format, under 100 MB, and no longer than 5 minutes.

To edit the prompt, refine it by removing or adding the preloaded tags for each attribute.

Prompt editing uses tags from these available attributes:

- Vibe: shown as purple text in the prompt. Use it to set the overall mood or emotional tone for soundtrack generation.

Choose Vibe inputs to set the mood of the generated soundtrack.

- Style: shown as blue text in the prompt. Use it to set the genre or instrumentation for soundtrack generation.

Choose Style inputs to set the basic genre of the generated soundtrack.

- Purpose: shown as green text in the prompt. Use it to set the intended use case or context for soundtrack generation.

Choose Purpose inputs to describe the intended use of the generated soundtrack.

Custom tags for any attribute can be added with descriptive adjectives.

Use extra descriptive tags to make generations more accurate.

Set the soundtrack energy by choosing one of these options:

- Low: gentle and calm
- Medium: even and steady
- High: lively and fast

Choose Energy options that align with the style and mood selected earlier.

Set tempo to define the soundtrack's speed or pace for generation. These options are available:

- Slow: calm at a low pace
- Medium: moderate, steady, and balanced
- Fast: brisk and energetic

Choose Tempo to set the generated soundtrack's pace and rhythm.

By default, the generated soundtrack duration matches the uploaded video's duration. To make it longer or shorter, use the Duration section.

Select Generate to start soundtrack generation.

Use the credits indicator beside Generate to see how many generative credits will be consumed.

When generation finishes, four variations are provided, and each one can be previewed alongside the video.

Choose the variation you prefer and download it.

Highlight the variation to download, then select Download.

The downloaded file keeps the uploaded video's format, MOV or MP4.

Tip

If the soundtrack does not match expectations, conflicting input terms may be the reason. For example, using a calm Vibe with a heavy metal Style can produce unpredictable results and may favor one input over the other.

Adjust Vibe so it better matches the desired mood, then refine Style so it complements that mood, and avoid combining terms with opposite emotional tones or musical genres.
