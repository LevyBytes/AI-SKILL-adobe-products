# Where are Content Credentials stored?

Assets generated with Adobe Firefly features carry Content Credentials on their files, and a copy may also be stored in Adobe's public Content Credentials cloud.

Keeping a copy in Adobe's Content Credentials cloud improves durability and recovery through the Inspect tool on Adobe Content Authenticity. When a selected asset has associated Content Credentials, Inspect can display them.

Note

Inspect is for recovering Content Credentials, not for gallery browsing or search.
