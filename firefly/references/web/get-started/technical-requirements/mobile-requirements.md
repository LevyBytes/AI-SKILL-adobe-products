# Mobile requirements

| Requirement type | Minimum requirement |
| --- | --- |
| iOS | Version 17.4 |
| Android | 9.0 Pie |

- Use Firefly at firefly.adobe.com in mobile browsers such as Chrome, Edge, Firefox, and Safari.
- Firefly does not support Lockdown mode in Safari.
- Firefly is also available as a downloadable app for iOS or Android devices. Review the technical requirements for Firefly on mobile.
