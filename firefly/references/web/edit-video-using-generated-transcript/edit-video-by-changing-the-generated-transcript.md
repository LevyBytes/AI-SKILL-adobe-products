# Edit video by changing the generated transcript

Text-based editing in Firefly video editor is designed for speech-heavy videos, including interviews, documentaries, and podcasts. Instead of hunting through timelines or audio tracks, use the transcript as the editing surface.

Start a new project, then place a dialogue video file on the timeline.

Select the Text-based editing icon in the right panel.

Use the Text-based editing icon to transcribe the selected dialogue video.

Select Text-based editing to generate a transcript for the chosen video with dialogue.

The Text-based editing panel shows the transcript generated automatically for the video.

Speaker labels are added according to the number of people speaking in the transcript.

Use the icon to enable these functions:

- Auto-scroll
- Show pauses

When your pointer is over the generated transcript, these options appear:

- Correct transcript: Manually fix generated transcript text that does not match the dialogue.
- Add text to timeline: Place the selected text on the timeline as a new text layer.
- Assign speaker: Set a speaker for the selected text, or create another speaker when needed.
- Delete: Remove the selected text. The matching video frames are removed from the timeline too, and a split is created.

Highlight transcript text to display the available editing options.

Select transcript text to access and use its edit controls.

Use search in the Text-based editing panel to locate video frames containing a chosen dialogue word.

Search the generated transcript for a word to list every place it occurs.

Search finds all appearances of the chosen word in the generated transcript.

When transcript-based editing is complete, download the final video.
