# Export finished video edits from Firefly video editor

Once the edit is complete and the result is ready, export the project. Export rendering combines the footage into one video file with resolution and quality chosen for the target platform.

Review the edited video first, then make any remaining changes, such as adjusting the timeline's frame rate or changing the aspect ratio.

Choose Download in the upper-right corner of the page, or open the main menu and select Export.

The Download settings panel displays frame rate and estimated file size. Set these options:

- Resolution: choose 720p, 1080p, or 4K.
- Quality: choose High (larger file size), Medium, or Low (faster download).

Set video resolution and quality, then download the result as MP4.

Choose the resolution and quality before downloading the video in MP4 format.

Select Download video to save the video as an MP4 file.
