# Generate image variations that follow a reference image composition

Composition describes an image's structure, including the placement of subjects and visual elements within the frame. When Adobe Firefly matches a reference image structure, it evaluates outline and depth as two key aspects.

On the Firefly homepage, choose Generate in the left panel, then choose Generate image.

Provide the prompt text, then change any image generation settings you need.

In General settings, select the Model you want to use.

Open Composition to see the available choices.

In Reference, choose Upload image, then browse to an image on your device.

In Composition, either upload an image or choose one from the gallery as the structure reference.

In Composition, either upload an image or choose one from the gallery as the structure reference. Note

Use the Strength slider to set how strongly the result follows the reference image.

Choose Generate to produce variations aligned to the reference image composition.
