# Select a frame rate that suits the style of your video.

In video editing, frame rate (fps) is the count of images shown each second. Firefly video editor (beta) lets you set the timeline frame rate for the kind of project you are making, including YouTube, social media, or film work. This setting affects the speed and smoothness of the exported video.

Before you begin:

Begin with a project that already has media files on the timeline.

Use the page's upper-left menu icon, then select Timeline > Properties.

Open Timeline properties when you need to change the frame rate.

Timeline properties is where the frame rate setting is available.

Timeline properties becomes active.

From Frame rate, choose the option you need.

Pick the frame rate that fits the timeline and the project's style.

The selected frame rate should fit the project style. Tip

Higher frame rates make movement appear smoother and more lifelike, while lower rates give motion a softer, more cinematic feel.
