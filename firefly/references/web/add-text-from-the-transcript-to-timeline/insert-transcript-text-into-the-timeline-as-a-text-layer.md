# Insert transcript text into the timeline as a text layer

Adding selected words or a transcript segment to the timeline as a text layer avoids creating a text layer and typing the content manually.

Firefly video editor lets you search transcript keywords or phrases to locate moments quickly. You can also scrub through the transcript yourself, select the needed section, and apply Add text to timeline to place it straight into the timeline as a text layer.

Before you begin:

Place a video file with dialogue on the timeline in a new project.

In the right panel, select the Text-based editing icon.

Search within the transcript, or scrub manually until you find the section to place on the timeline as a text layer.

Select the text, then choose Add text to the timeline from the context menu.

Add text to the timeline places the selection on the timeline as a text layer.

Use Add text to the timeline to create a text layer from the selected transcript words.

The text layer starts on the timeline at the exact video moment where those selected words are spoken.

The Properties panel for text opens as well, so you can change how the text looks in the video.

Use the Properties panel for text to adjust the text appearance in the video.

The Properties panel for text provides the controls for customizing the video's text layer.
