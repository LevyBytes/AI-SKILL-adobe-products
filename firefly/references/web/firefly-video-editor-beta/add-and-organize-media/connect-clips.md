# Connect clips

Connect clips to the timeline while editing video in Firefly video editor.

In Firefly video editor, the Connect option links secondary layers, including footage, images, titles, or audio, to a primary clip, usually the clip at the bottom of the layer stack. The connection keeps linked media aligned with that primary clip. In effect, secondary media stays attached to the primary clip, so timeline adjustments or movement of the primary clip move the connected items too. This keeps edits synchronized and prevents elements from shifting unexpectedly.

Connected layers can still be moved individually along the timeline. If the primary clip moves, all layers connected to it move automatically as a group.

Before you begin:

Begin with a new project that already has media files or text elements on the timeline.

Decide which clip should be primary for the connected layers, then move that clip to the bottom of the layer stack in the timeline.

Open the main menu at the upper-left of the page, then choose Connect under the Clip option.

The Connect option links the primary clip with other layers, including footage, images, titles, or audio.

Repeat these steps for each layer that should connect to the primary clip.

After connection, those layers stay synchronized with the primary clip, helping the timeline remain organized and the edit stay consistent.

Tip

To disconnect a layer from the primary clip, select the layer to remove from the connection. Then go to main menu > Clip > Disconnect.
