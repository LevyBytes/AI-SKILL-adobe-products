# About Firefly video editor (beta)

Explore Firefly video editor (beta) and its main online video editing features.

Firefly video editor (beta) runs in the browser and lets you edit video online. You can trim, cut, add text, add audio, generate videos, and bring in videos from your Firefly generation history within the same editor. This supports many creative project types, including social media content and educational tutorials.

Note

To switch between dark and light modes, open Account menu > Settings > Color theme. The selected theme applies across the Firefly surface.
