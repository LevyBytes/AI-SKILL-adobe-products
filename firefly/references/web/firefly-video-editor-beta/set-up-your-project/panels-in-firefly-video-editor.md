# Panels in Firefly video editor

Learn how panels in Firefly video editor support organizing, editing, and fine-tuning a project.

While working in Firefly video editor, several panels are available for media files, text elements, and media properties. These panels support project organization, editing, and detailed refinement.

Firefly video editor includes these panels:

- Viewer
- Timeline panel
- Your media panel
- Generation history panel
- Text panel
- Properties panel
- Generate media panel
- Text-based editing panel
- Transitions panel
- Looks panel
