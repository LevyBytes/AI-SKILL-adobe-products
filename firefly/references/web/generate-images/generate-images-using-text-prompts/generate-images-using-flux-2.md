# Generate images using FLUX.2

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

On the Text to image page, type a text prompt in the Prompt field.

In General settings, choose the Model dropdown menu.

Under Partner models, choose FLUX.2 [pro].

Open the Aspect ratio dropdown menu and choose one of these options:

- Classic (3:4)
- Ultra wide (21:9)
- Widescreen (16:9)
- Close (1:1)
- Landscape (4:3)
- Wide (5:4)
- Square (1:1)
- Standard (4:5)
- Portrait (3:4)
- Tall (2:3)
- Vertical (9:16)

In Reference image, upload up to four images from your device or Adobe cloud storage.

Pair a reference image with a text prompt to steer the generated image.

Use a reference image together with a text prompt when you want to influence the generated image.

This gives you more creative control because multiple styles, objects, and contexts can be blended instead of relying on a single source. The multi-image conditioning improves output quality and flexibility while keeping computation efficient.

Select Generate.
