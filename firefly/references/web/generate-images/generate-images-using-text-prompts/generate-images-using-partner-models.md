# Generate images using partner models

Learn how partner models work when you create image variations with Generate image.

During image variation generation with Generate image, you can choose several partner video models as well as Firefly models. After you choose a model, Firefly shows the settings and controls that apply to it.

The Generate image feature currently offers these partner models for image generation.

When you choose a partner model for images, Firefly asks you to confirm that the model was not developed by Adobe and shows other relevant details. Review the information, then select OK to continue.

Review the Start using the partner models prompt, then decide whether to begin creating images with partner models.

Look over the Start using the partner models prompt and choose whether you want to start generating images through partner models.
