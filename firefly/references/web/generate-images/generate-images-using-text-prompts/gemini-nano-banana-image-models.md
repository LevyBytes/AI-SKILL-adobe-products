# Generate images using Gemini 2.5 (Nano Banana), Gemini 3 (Nano Banana Pro), and Gemini 3.1 (Nano Banana 2)

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

In General settings, choose the Model dropdown menu.

Under Partner models, choose the Gemini 2.5 (w/ Nano Banana), Gemini 3 (w/ Nano Banana Pro), or Gemini 3.1 (w/ Nano Banana 2) model.

Choose the aspect ratio from these options:

- Ultra Wide (21:9)
- Widescreen (16:9)
- Classic (5:4)
- Landscape (4:3)
- Wide (3:2)
- Square (1:1)
- Standard (4:5)
- Portrait (3:4)
- Tall (2:3)
- Vertical (9:16)

For Gemini 3 (w/ Nano Banana Pro) and Gemini 3.1 (w/ Nano Banana 2), open the Resolution drop-down menu to set the generated video resolution to 1K or 2K.

To edit an image, such as adding elements, upload one or more files in Reference images.

Type a text prompt in the Prompt field.

Select Generate.
