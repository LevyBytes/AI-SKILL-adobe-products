# Save to Favorites from the generated image variations

Generated variations can be marked as favorites immediately, so the images remain easy to find later without combing through the complete generation set.

From the Adobe Firefly homepage, open Text to image.

Provide a prompt, set the image generation options you need, then choose Generate.

Move the pointer over the image that should become a favorite.

Choose the Save to Favorites icon.

The Save to Favorites option stores a generated image in your favorites.

Save to Favorites can be used to keep generated images available from Favorites later.
