# Generate images using Runway Gen-4 Image

From the Firefly homepage, choose Generate in the left panel, then choose Generate image.

On the Text to image page, type a text prompt in the Prompt field.

In General settings, choose the Model dropdown menu.

Under Partner models, choose the Runway Gen-4 Image model.

Open the Aspect ratio dropdown menu to choose the generated image dimensions.

- Widescreen (16:9)
- Vertical (9:16)
- Square (1:1)
- Portrait (3:4)
- Landscape (4:3)

Select Generate.
