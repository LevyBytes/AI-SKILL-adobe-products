# Add and edit texts

Add text to an artboard and edit it so the mood board communicates more clearly.

Mood-board text supplies context and explanations for visual elements, drawing attention to important points. Quotes, taglines, and descriptive words can structure the board so it is easier to read and understand. While you work with mood-board text, Firefly Boards provides an accessible context menu and Properties panel.

Prepare first

Create a canvas and add visual elements.

Choose Text in the left toolbar to turn on the text cursor.

Click the canvas location where the text field should be created, then start typing.

Change the text with the available text editing options as needed.

Use the text editing controls together with the Properties panel to try different styles and decide what fits the mood board.

Open the Properties panel with the Properties icon to change text attributes such as color, opacity, and blend mode, plus text box details including rotation, position, and size.
