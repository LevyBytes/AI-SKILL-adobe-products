# Arrange and refine the board

After collecting the visual elements, create an artboard so you can begin arranging, editing, and composing the board.

In the left toolbar, choose the Artboard icon.

Create the artboard by dragging on the canvas.

Use Artboard to make one artboard or several artboards, then organize the design elements inside them.

The Properties panel can change artboard attributes such as color, opacity, and blend mode, plus rotation, position, size, and related characteristics.

Drag assets into the artboard and arrange them to fit the theme and composition.

If the board's visual elements were already arranged during import or placement, select them all, choose the option, then choose Artboard from selection.

Put several visual elements into one artboard by selecting them together on the canvas.
