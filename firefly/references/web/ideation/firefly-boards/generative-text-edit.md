# Generative Text Edit

Edit or delete text in images added to a canvas while keeping the rest of the image intact.

You can change or remove text inside any image on a Boards canvas without altering the surrounding composition. Edit text in image helps revise messaging, fix typos, or adapt a design for another use.

This feature works with images on the Boards canvas that you upload from your device or create with Firefly or partner models.

Note

- Before starting, create a board and add or generate visuals, such as images, on the canvas.
- Before editing text, confirm that the image has clear horizontal Latin-character text. Stylized fonts, rotated text, and overlapping text elements have editing limits.

Identify and select the image whose text you want to edit or delete.

Select Edit, then choose Edit text in image.

Choose an image that contains text, then use Edit text in image to change or remove the text.

The selected text-bearing image is ready for modification through Edit text in image.

Open the model dropdown menu, then choose a supported Adobe model or partner model:

- Adobe Firefly Image 5
- FLUX.1 Kontext [pro]

Pick either listed model before editing the text.

Select either supported model before editing the detected text.

Firefly finds text that shares a baseline and marks it as one editable line.

Detected text appears highlighted as a single editable line, ready for modification or removal.

The highlighted text line can be edited or deleted from the image.

Make your edits in the text box.

- To edit, change the text directly.
- To delete, remove any portion of the detected text.

Use the image text box to change or remove the selected text.

The in-image text box is where the selected text is changed or removed.

To apply your changes, press Return (macOS) / Enter (Windows) while editing, or select Generate.

Either action starts image generation with the edited or deleted text.

Watch the animated progress overlay on the canvas to see that generation is underway.

Limits for text format and style

Edit text in image cannot handle every text format or style:

- The tool does not support emojis or non-Latin character sets
- Skewed, rotated, or heavily stylized (3D) text may be missed
- Text much larger or smaller than the original may not process correctly
