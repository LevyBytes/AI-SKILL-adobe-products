# Loose sketch by Firefly Image 3

Use the Loose sketch preset to turn an image into sketch-style art that favors expressive looseness over precise detail.

Upload the image that should be changed into a loose sketch style onto the canvas.

From the bottom of the page, select Presets, then choose Loose sketch.

Select the Image field, then choose the image on the canvas.
