# Colorize by FLUX Kontext Max

Use the Colorize preset to add context-aware color to a black-and-white image.

Upload the black-and-white image that you want to colorize onto the canvas.

From the bottom of the page, select Presets, then choose Colorize.

Select the Image field, then choose the image on the canvas.

Canvas image selected for the Colorize using FLUX Kontext Max preset.

The chosen canvas image prepared for the Colorize using FLUX Kontext Max preset.

Pick an aspect ratio from the options shown.

Use Generate to start.
