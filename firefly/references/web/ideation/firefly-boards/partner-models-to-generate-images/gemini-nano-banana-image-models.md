# Generate images using Gemini 2.5 (Nano Banana), Gemini 3 (Nano Banana Pro), and Gemini 3.1 (Nano Banana 2)

From the Firefly homepage, choose Ideate, then choose Create a board.

On the Boards page, go to the bottom of the page and choose Generate image.

From the model dropdown menu, select Gemini 2.5 (w/ Nano Banana), Gemini 3 (w/ Nano Banana Pro), or Gemini 3.1 (w/ Nano Banana 2).

To use an image already on the canvas as a reference, choose the Sample from canvas icon. To bring in a reference from your computer or device, choose the Upload image reference icon.

The uploaded reference can guide a newly generated image, and you can also revise that image by describing added elements in a text prompt.

With the Aspect ratio option, choose one of the available image dimensions.

Tip

With Gemini 3 (w/ Nana Banana Pro) or Gemini 3.1 (w/ Nano Banana 2), turn on Use Google Search to give image generation access to current information. When this setting is active, the model can use up-to-date Google search results, which helps with prompts that depend on recent conditions. For instance, a prompt such as "clothing appropriate for NYC today" lets the model check the current weather and suggest suitable imagery, such as warm winter attire.

For more controls, choose the Generation settings icon beside the Aspect ratio options. The right-side panel opens with these extra settings:

- Sub-prompts: Browse available sub-prompts, including lighting and style choices. Selecting a sub-prompt preview thumbnail adds that item to the prompt bar.

- Seed: Enter a seed number to initialize generation and influence how random the AI output is. Reusing the same seed, prompt, and control settings can produce similar video clips.

Enter a text description in the prompt bar.

Choose Generate.
