# Generate images using Ideogram 3.0

From the Firefly homepage, choose Ideate, then choose Create a board.

On the Boards page, go to the bottom of the page and choose Generate image.

In the model dropdown menu, select Ideogram 3.0.

To reference an image that is already on the canvas, choose the Sample from canvas icon. To add a reference from your device, choose the Upload image reference icon.

Use Aspect ratio to pick one of the dimensions available for the image.

For more controls, choose the Generation settings icon beside the Aspect ratio options. The right-side panel opens with these extra settings:

- Sub-prompts: Browse available sub-prompts, including lighting and style choices. Selecting a sub-prompt preview thumbnail adds that item to the prompt bar.

- Seed: Enter a seed number to initialize generation and influence how random the AI output is. Reusing the same seed, prompt, and control settings can produce similar video clips.

Enter a text description in the prompt bar.

Choose Generate.
