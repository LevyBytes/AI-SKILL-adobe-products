# Add artboards to the canvas

Create an artboard on the project canvas so you can begin building a mood board.

For a mood board, set up the artboard first. It defines size and layout, shows the available working space, and helps you see how the visual elements relate to one another. The artboard keeps chosen visuals organized while supporting the intended theme and flow.

On the Firefly homepage, choose Boards.

On the Firefly Boards page, choose Create new board.

Choose the Artboard icon from the left toolbar.

Use Artboard to make one artboard or several artboards, then organize the design elements inside them.

Draw the artboard on the canvas with a click-drag action.

The Properties panel controls artboard attributes including color, opacity, and blend mode. Other properties, including rotation, position, and size, can be changed there too.

Use the Properties panel when you need to adjust artboard transparency, color, Blend mode, and additional properties.

Add images, shapes, and text by dragging them inside the artboard, then arranging them around the theme and composition.

Drag selected visual elements onto the artboard and place them where you want them.

Note

When your mood board visuals are already arranged and should sit inside an artboard, select all of them, right-click the selection, and choose Artboard from selection.
