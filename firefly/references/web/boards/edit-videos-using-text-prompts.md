# Edit videos using text prompts

Use partner video models and text prompts in Firefly Boards to revise generated or uploaded videos.

After you place a video on the canvas or create one with Generate video in Firefly Boards, text prompts can guide edits and refinements. Use prompts for style adjustments, detail tuning, and broader creative revisions.

Before you begin:

Put a video on the canvas. You can generate it with Firefly or partner video models, or upload your own file.

Select the video on the canvas that you want to edit.

From the context menu, select Edit, then choose Edit with Runway Aleph.

Choose a partner video model to make prompt-based edits to the video.

Select a partner video model when you want to edit the video with text prompts.

Enter a prompt that describes what you want to edit in the image. The change can remove elements, add new ones, replace the background, enhance particular details, or make another adjustment.

Write a text prompt for the video edit, for example to adjust colors, change lighting, or replace objects.

Describe the desired video edit in text, such as color adjustment, lighting changes, or object replacement.

Select Generate to begin creating content with the prompt edits applied.

When the generated video matches what you need, drag it onto the canvas or use Place on canvas.

If the generated video is satisfactory, choose Place on canvas to add it to the canvas.

When you are satisfied with the generated video, add it to the canvas with Place on canvas.

For additional changes, move the generated video into the AI video editor.
