# View and edit properties for images placed on the timeline.

In Firefly video editor, selecting an image on the timeline reveals editable controls in the Properties panel. These tools cover the image's dimensions, placement, transparency, and angle. They provide precise control over how the image appears in the composition.

Before you begin:

Start with a new project that includes an image on the timeline.

On the video editor page, select the timeline image whose properties you want to change.

The Properties panel turns on and shows these adjustable properties:

- Flip horizontal: mirrors the image left to right.
- Flip vertical: flips the image upside down from top to bottom.
- Rotate clockwise: rotates the image 90° clockwise with each click.
- Align: snaps the image to the center or frame edges for accurate positioning.
- Position: shifts the image horizontally or vertically within the frame.
- Scale: changes the image size so it becomes larger or smaller.
- Rotate: turns the image freely to any angle.
- Opacity: sets the image transparency level, from fully visible to fully transparent.

Use the Properties panel to change image settings such as position, size, opacity, and more.

The preview updates as you adjust the properties.
