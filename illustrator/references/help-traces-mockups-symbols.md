## Vectorize images using Image Trace

Use Image Trace when you want to turn raster artwork into vector graphics that can be edited.

### Trace an image with full tracing options

Select File > Place, choose the raster image, and place it on the canvas.

Select Window > Image Trace to display the Image Trace panel.

From the panel's Preset dropdown, choose Enhanced Presets or Legacy Presets.

Enhanced presets include built-in handling for Gradients, Shapes, Transparency, and Auto Grouping, with availability depending on the preset. With legacy presets, select those options yourself.

Create vector artwork from an image with Image Trace presets and customized settings.

Use Image Trace presets together with custom options to vectorize an image.

Choose a preset either with the top-row icon list or through the Preset dropdown. The traced output takes the place of the original image. Trace processing time depends on image resolution.

Change the panel's tracing options as needed to tailor the result.

### Trace an image quickly with limited tracing options

Image Trace can be started from faster controls when you want less setup than the full Image Trace panel provides:

Select the image to trace with the Selection tool.

Use any of these methods to trace the image:

- Select Image Trace in the Contextual Task Bar to start Image Trace immediately with the Default preset.
- Select Image Trace in the Properties panel to start Image Trace with any tracing preset.

Note

Even after starting Image Trace through one of these routes, you can refine the result later in the Image Trace panel.

### Release the trace

To remove a trace and return to the original image:

Select the trace result.

Select Object > Image Trace > Release.

## Edit tracing results

Use expand, ungroup, simplify, and color-editing steps to work with trace results.

A trace must be expanded before it can be edited like another vector object. After expansion, the tracing options are no longer adjustable:

Select the tracing result on the canvas with the Selection tool.

Select Expand in the Image Trace panel. Expand turns the result into grouped editable paths.

Use Expand to convert the trace result into editable paths.

Choose Expand when you need the result changed into editable paths.

Edit the paths as needed:

- Double-click the trace group to enter isolation mode, which lets you edit while keeping the group intact.
- Select Ungroup in the Contextual Task Bar when you want to edit paths one by one.

Tip

Select Object > Path > Simplify to reduce extra anchor points.

Select the paths, then select Object > Live Paint > Make to turn them into a Live Paint group.

## Save custom tracing presets

Save custom Image Trace presets so your preferred tracing settings are easy to apply again later.

Choose Window > Image Trace; the Image Trace panel opens.

Set the tracing options as needed.

Select Manage Presets next to the Preset dropdown, then select Save as New Preset.

Save tracing settings as custom presets for quick reuse.

Store tracing settings in custom presets so they can be applied again quickly.

Enter a preset name and select OK.

For deleting or renaming, first choose the preset in the Preset dropdown. Open Manage Presets, then select Delete or Rename.

Note

Default presets cannot be edited or deleted. They appear inside square brackets.

Create image mockups to preview how your design objects will look in context.

### Create a mockup with your own image

Note

Mockups can be built from your own raster image or from the free curated image templates available in the Mockup panel.

Select Window > Mockup to open the Mockup panel.

Use the Selection . to select the vector art and the image together.

Select Create Mockup in the Mockup panel to place the vector art onto the image and generate the mockup.

Tip

The Mockup panel also previews your vector art on its free image templates. To use a template, select the design, then choose Preview Mockup in the Mockup panel rather than proceeding with your own image.

Drag the vector art on the canvas and position it where you want it on the image. The art adjusts automatically to the object's geometry.

Click outside the image to keep the art fixed in its current position.

Tip

To reposition the art, select it, then select Window > Properties. In the Properties panel, select Edit Content and adjust the art again.

Drag the vector art and put it where you want it on the image. The art automatically adapts to the object's shape.

To lock the art at its current position, click outside the image. To move it later, select the art, and then select Edit Content in the Properties panel.

## Edit mockups

Edit mockups when you need to tailor the template placement and move artwork inside it.

A mockup can be changed as one grouped item, or you can work on the image or vector art separately.

Choose the mockup.

From the Properties panel, choose Edit Mockup Group, Edit Image, or Edit Content. Then choose the edit mockup option that fits the vector art change you want to make.

Choose the edit mockup option that fits the vector art change you want to make. Note

After a mockup is created, Illustrator turns the vector art into a symbol, which exposes additional editing choices.

For symbol-level edits to the vector art, double-click the mockup group to enter isolation mode, then double-click the artwork and edit the symbol.

To release a mockup, select it, then choose Release in the Mockup panel.

For quick feedback, choose Like it or Dislike it in the Mockup panel. For longer comments, choose Share Feedback.

## Save mockups as templates

Save mockups as templates so the same design setup can be reused easily in later projects.

The Mockup panel can store a mockup as a template for future use. The added template appears under Your Mockups in the panel drop-down, and the saved version includes a placeholder showing where the vector art was positioned.

Open Window > Mockup.

Choose the mockup to store as a template, then use the save control in the Mockup panel.

Note

Your Mockups can contain up to 20 mockup templates, and those templates are available across Illustrator documents. For mockups made in Illustrator 28.5 or earlier, release the mockup first, then create it again before adding it.

## Create and place symbols

Create and place symbols when a design element needs to be reused across artwork.

### Create a symbol

Open Window > Symbols to show the Symbols panel.

With the Selection tool, choose the object you want to turn into a symbol.

Move the object into the Symbols panel by dragging it there.

Tip

Unless you change the default behavior, the chosen object is converted into an instance of the new symbol. ,

In the Symbols panel, choose the Symbol Options icon. When the Symbol Options dialog box opens, set these options:

- Type the symbol name in the Name field.
- From the Export Type dropdown, choose one Export Type option: Movie Clip or Graphic.
- Choose one Symbol Type option: Dynamic Symbol or Static Symbol.
- Choose a registration point.
- Turn on Enable Guides for 9-slice Scaling.

Choose OK.

### Place a symbol in the artwork

Choose a symbol in the Symbols panel, or pick one from Symbol Libraries Menu icon.

Drag the symbol onto the artboard.

To create a new symbol without showing the Symbol Options dialog, hold Alt (Windows) or Option (macOS) while dragging the object onto the New Symbol icon in the Symbols panel. Illustrator assigns the symbol a default name. In the Symbols panel, a small plus sign in the lower-right corner marks dynamic symbols.

## Edit symbols

Edit, redefine, or replace symbols when you need to adjust artwork, refresh definitions, or exchange symbol instances.

A symbol can be edited by changing its artwork, or it can be redefined by substituting different artwork. Either action updates the symbol's preview in the Symbols panel and changes every instance of that symbol on the artboard.

### Edit a symbol

In the Symbols panel, double-click a symbol instance.

Change the object.

To leave isolation mode, choose the Exit Symbol Editing Mode icon at the workspace's upper-left.

### Redefine a symbol with another object

With the Selection tool, choose the object that will replace the definition of an existing symbol.

Tip

Select the original object itself, not an instance of a symbol.

In the Symbols panel, choose the symbol to redefine, then choose Redefine Symbol from the Symbols panel menu.

Choose Redefine Symbol to apply the new artwork to the symbol.

Choose Redefine Symbol when you are ready to update the symbol with the new artwork. Note

The selected object is converted into an instance of the redefined symbol. To avoid that conversion, hold Shift while choosing Redefine Symbol from the panel menu.

### Replace a symbol instance with a different symbol

With the Selection tool, choose the symbol instance in the artwork.

In the Control panel, open the Replace dropdown and choose the new symbol.

To select every instance of one symbol in a document, choose that symbol in the Symbols panel, then choose Select All Instances from the Symbols panel menu.

## Maintain proportions while scaling symbols

Use 9-slice scaling guides when symbol proportions need to hold up during scaling.

Selecting Enable Guides for 9-Slice Scaling conceptually splits the symbol with two horizontal and two vertical grid lines, creating nine sections. During scaling, the portions of the symbol outside the guides do not scale.

### Enable 9-slice guides

Choose Window > Symbols.

In the Symbols panel, choose the symbol, then choose Symbol Options from the panel menu.

In the Symbol Options dialog box, turn on Enable Guides for 9-Slice Scaling, then choose OK.

Use Enable Guides for 9-slice scaling guides to control how symbol transformation behaves.

Enable Guides for 9-slice scaling guides controls the way symbol transformations are handled. Tip

9-slice scaling is most useful for symbols such as buttons or frames, where corners or borders should stay undistorted while the object is resized.

### Adjust the 9-slice scaling guides

From the Symbols panel, drag the symbol you want onto the artboard.

On the artboard, double-click the symbol instance to enter Isolation Mode.

Move the pointer over any of the four guides; when the pointer changes, drag that guide until it is positioned as needed.

Press Esc to leave isolation mode.

## Transform symbols

Transform, expand, redefine, or reset a symbol instance. You can break links, use registration points, and modify artwork efficiently.

### Expand and modify a symbol instance

After expanding and editing a symbol instance, you can use the Symbols panel to redefine the original symbol. Choosing Redefine Symbol makes every existing symbol instance adopt the updated definition.

Open Window > Symbols.

Choose the symbol you want in the Symbols panel and place it on the artboard.

On the artboard, choose the symbol instance, then choose Break Link to Symbol in the Symbols panel.

Edit the object on the artboard.

To redefine the parent symbol, choose the edited object, choose the original symbol in the Symbols panel, then choose Redefine Symbol from the panel menu.

To make a new symbol instead, drag the edited object into the Symbols panel, adjust the settings in the Symbol Options dialog box, then choose OK.

### Use the registration point as a reference to transform symbol instances

While creating a symbol, you can choose one of nine registration points to determine how instances transform. When the instance is selected, that point is shown as a crosshair in both normal mode and isolation mode.

Open Window > Transform.

From the Transform panel menu, choose Use Registration Point for Symbol.

Note

With this setting, transformations use the symbol's registration point rather than the default Reference Point. The registration point is shown whenever the symbol instance is selected.

Use the Registration point as the transform reference for symbol instances.

Transform symbol instances from the Registration point.

Choose the symbol instance on the artboard and change it as needed.

### Reset transformations

Choose the symbol instance on the artboard.

In the Control panel, choose Reset.

Note

When a symbol is placed in perspective, Illustrator disables the controls for replacing a symbol instance with another symbol, breaking the link with the parent symbol, and resetting its transformations.
