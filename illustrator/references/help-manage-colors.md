## Color Guide panel overview

The Color Guide panel helps set up color variations, swatch groups, and harmony rules for Illustrator artwork.

Open Color Guide by choosing Window > Color Guide.

For faster artwork color decisions, use the Color Guide panel to adjust harmony rules and organize color groups.

Artwork color choices can be refined in the Color Guide panel by working with harmony rules and color groups.

### Color Guide menu options

From the Color Guide panel, choose the Color Guide panel menu icon.

Note

For spot colors, work with the Tints/Shades variation and choose colors on the right side of the variation grid. Every other variation changes spot colors into process colors.

## Create swatch groups in the Color Guide panel

Use the Color Guide panel to build, save, and organize a swatch group made from related color variations.

Choose Window > Color Guide to open the Color Guide panel.

In the Color Guide panel, choose a color variation, then choose the Set base color to the current color icon Set Base Color To The Current Color icon.

Choose a rule from the Harmony Rules dropdown menu.

To restrict the group to a swatch library, choose Limits the swatch group to colors in a swatch library, then choose a library from the list.

To store the color group or a single color in the Swatches panel, choose Save swatch group to Swatch panel icon.

For the new swatch group's name, use these steps:

- Select the group in the Swatches panel, open the Swatches panel menu, and choose Swatch Group Options.
- When the Swatch Group Options dialog box opens, type a name in the Name field and choose OK.

Enter the swatch group's name in the Swatch Group Options dialog.

Use the Swatch Group Options dialog to supply the swatch group name.

To apply a swatch-group color to artwork, select the artwork and choose any color in the Color Guide panel.

## About selecting colors

Adobe Illustrator provides several tools, panels, and dialog boxes for choosing artwork colors from its broad library.

In Illustrator, pick colors that fit the artwork's needs. When company-approved colors are required, use the company-approved swatch library.

Color selection can be handled through these features:

- Swatches panel and Swatch Libraries panels: Supplies individual colors and swatch groups, with choices from built-in libraries plus options for custom swatches or imported swatches.
- Color Picker: Gives you a visual color spectrum, value fields for exact color entry, and swatches for quick choices.
- Eyedropper tool: Samples a color from artwork when you click.
- Color panel: Includes a color spectrum, value sliders, and text boxes for defining Fill and Stroke colors. It can also create inverse or complementary colors and build swatches from selected colors.
- Color Guide panel: Uses harmony rules to build swatch groups from a selected base color, then lets you explore tints, shades, and warm or cool variations. The swatch group can be opened in the Edit Colors or Recolor Artwork dialog for additional adjustments.
- Edit Colors dialog box: Provides controls for accurately defining or adjusting colors in a swatch group or artwork.
- Recolor Artwork dialog box: Recolors artwork with colors from a swatch group, or reduces or converts colors for output.
- Add Selected Colors: Creates individual swatches through the option in the Swatches panel.
- New Swatch Group: Builds a swatch group from selected artwork colors through the option in the Swatches panel.

## Select colors using the Eyedropper and Color Picker tool

The Eyedropper and Color Picker tools in Illustrator support selecting, changing, and sampling colors.

Illustrator lets you apply colors with both the Eyedropper and Color Picker tools. Use the Eyedropper tool to pick a color already present in artwork or an image, such as one sampled from a logo or photo. Use the Color Picker tool for visual color choice by entering exact values or choosing from the spectrum, sliders, or swatches.

Review how the Eyedropper tool and Color Picker tool work in Adobe Illustrator, including the main differences between them.

### Select colors with the Eyedropper tool

Choose the object that should receive the sampled color.

From the Tools panel, select the Eyedropper tool, or press I.

Click artwork or an image to sample a color. For finer targeting, hold Shift to use the Sampling Ring.

### Preview and apply colors with the Color Picker tool

In the Tools panel, Double-Click Fill or Stroke to open the Color Picker dialog box.

Choose a color using one of these methods:

- Drag the circular color marker inside the Select Color column.
- Move the color slider, or choose a color in the Color spectrum bar.
- Type HSB, RGB, or CMYK values in the text boxes.
- From Color Swatches, choose one item in the Color Swatches column.
- With the Color Picker tool selected, move the cursor over the area to sample. A Sampling Ring appears with a color preview. Its upper half indicates the color that will be sampled, and its lower half shows the most recent sampled color. Alternatively, hold Shift with the Eyedropper tool to display the Sampling Ring.

Choose OK to apply the selected color to the object.

## Select colors using the Color panel

Color panel selections can be applied to artwork for consistent and accurate design colors.

Select the object, then choose Window > Color.

In the Color panel, open the Color panel menu icon, then use these choices:

- Choose Show Options.
- Choose Grayscale, RGB, HSB, CMYK, Web Safe RGB, Invert, or Complement as the color mode or command.

Note

- This choice affects only the Color panel display; the document's color mode stays unchanged.
- Illustrator reopens with the color model used most recently.

Apply the color to the object by dragging the slider, entering values in the color value input fields, or choosing from the Color Spectrum. Hold Shift while dragging a color slider to change tint or intensity while keeping a similar color; HSB sliders do not support this.

Use the Color panel's RGB sliders, Color Spectrum bar, or color value input fields to adjust colors.

Colors can also be tuned in the Color panel through RGB sliders, the Color Spectrum bar, or color value input fields.

### Use recent colors across your document

When colors are applied, Illustrator records them as Recent Colors. They appear in the Swatches panel and the Color panel. Illustrator keeps up to 30 recent colors, and they remain available across documents until newer colors replace them.

Apply a color to any object with the Swatches panel or Color Picker. After that application, the color shows in the Recent Colors section.

Recently used colors are available from the Color panel for maintaining visual consistency across artwork.

The Color panel provides direct access to recently used colors so artwork can stay visually consistent.

To save a recent color for later use, drag it into the Swatches panel.

To hide Recent Colors, turn off Show Recent Colors in the More Options menu.

## Convert color modes

In Illustrator, convert color modes when you need color display to stay accurate and consistent across different output formats.

### Convert colors to Grayscale

With the Selection tool, choose the object whose colors need conversion.

Select Edit > Edit Colors > Convert to Grayscale.

Use Adjust Color Balance option when you want the object converted to grayscale while also changing the gray shade mix.

Use Adjust Color Balance option when you want grayscale conversion and gray-shade adjustment in the same operation.

### Convert Grayscale vector objects to RGB or CMYK

Use the Selection tool to choose the Grayscale vector object.

Choose Edit > Edit Colors > Convert to CMYK or Convert to RGB according to the document’s current color mode.

### Colorize Grayscale or 1-bit images

In the document, choose the Grayscale image or 1-bit image with the Selection tool.

Click the Fill box in the Tools panel.

Select Window > Color.

From the Color panel, apply Black, White, a Process color, or a Spot Color to color the image.

Note

When a Grayscale image includes an alpha channel (transparency layer), Illustrator blocks use of a Process Color. Colorize that image with a Spot Color instead.

## Make colors printable or web safe

In Adobe Illustrator, make colors printable or web-safe so the artwork displays or prints as expected.

### Shift an out-of-gamut color to a printable color

RGB and HSB can contain colors, including neon colors, that CMYK has no printable equivalent for. After you choose an out-of-gamut color, the Color panel or Color Picker shows an alert triangle.

Select Window > Color..

Pick individual artwork colors and verify whether any fall outside gamut.

Select Out of Gamut Warning to move the color to its nearest CMYK match, shown in the small box beside the triangle. Use Out of Gamut Warning icon to make the colors printable.

Use Out of Gamut Warning icon to make the colors printable.

### Shift a color to a web-safe color

Browsers on all platforms share a 216-color web-safe palette. If the selected color falls outside that set, Illustrator shows an alert cube in the Color Picker, Color panel, Recolor Artwork dialog box, or Edit Colors.

Select Window > Color.

Choose individual colors in the artwork and check whether they are web safe.

Select Out of Web Color Warning to move the color to the closest web-safe match, shown in a small box next to the cube.

### Display web-safe colors

Web-safe colors are colors shared across web browsers on any platform.

## Change colors to their inverse or complement

In Adobe Illustrator, use the Color panel or Edit Colors options to invert colors or apply complementary colors in artwork.

Invert sends each color channel to its opposite value; Complement uses a formula to compute complementary RGB values. These options help build high-contrast artwork and visual effects.

### Change the inverse or complement of a single color

Choose the object’s color with the Direct Selection tool.

Select Window > Color.

From the Color panel menu, choose one option:

- Invert: changes every component to the opposite side of the scale. An R value of 100 becomes 155 (255 – 100 = 155).
- Complement: starts with the sum of the selected color’s highest and lowest RGB values, then derives a new value for each component. With RGB values (102, 153, 51), the total is 204 (153 + 51). The resulting RGB values are Red: 204 – 102 = 102, Green: 204 – 153 = 51, and Blue: 204 – 51 = 153

Choose Invert or Complement to apply the change.

Use Invert or Complement to apply the change.

### Invert multiple colors

Activate the Direct Selection tool, then Shift + click the objects whose colors should be inverted.

Select Edit > Edit Colors > Invert Colors.

## Get precise spot colors using lab values

Use Lab values when you need precise, consistent Spot Colors in designs.

Certain predefined Spot Colors in the TOYO, DIC, and HKS libraries use lab values for their definitions. To support older Illustrator versions, those same library colors also carry CMYK definitions. Through the Swatches panel, you decide whether Illustrator relies on Lab or CMYK values when displaying, exporting, and printing spot colors.

With the right device profiles, Lab values give the most accurate output across devices. For color-managed projects, Adobe recommends using Lab values for displaying, exporting, and printing Spot Colors.

Note

For better screen accuracy, enabling Overprint Preview makes Illustrator switch to Lab values automatically. Printing uses Lab values too when Simulate is selected for Overprints in the Print dialog box, Advanced area.

Choose Window > Swatches.

From the Swatches panel, choose More options > Spot Colors.

In the Spot Color Options dialog box, choose the option Use Lab values specified by the book manufacturer.

To match Spot Colors from earlier Illustrator versions, use the Spot Color Options dialog box and select Use CMYK values from the manufacturer’s process books.

When earlier Illustrator versions must be matched, use the Spot Color Options dialog box and select Use CMYK values from the manufacturer’s process books.

Select OK.

## Adjust color balance

Refine an artwork’s look and feel by changing its color balance.

With the Selection tool, choose the object whose color needs adjustment.

Open Edit > Edit Colors > Adjust Color Balance.

In the Adjust Colors dialog box, enable the Fill and Stroke checkboxes under Adjust Options.

In the Adjust Colors dialog box, make the needed adjustments:

- When any Global Process Color or Spot Color is selected, change color intensity with the Tint slider. Selected non-global process colors stay unchanged.
- In CMYK color mode, when non-global process colors are selected, use the sliders to change Cyan, Magenta, Yellow, and Black percentages.
- In RGB color mode, when non-global process colors are selected, use the sliders to change Red, Green, and Blue percentages.
- To convert the selected colors to Grayscale mode, choose Grayscale from the Color Mode dropdown list and enable the Convert checkbox. Then use the slider to change the Black percentage.

Note

When selected Global Process Color or Spot Color items need conversion to non-global process colors, choose CMYK or RGB from the Color Mode list according to the document Color Mode, then enable the Convert checkbox. After that, adjust the colors with the sliders.

Use the Adjust Colors dialog box to choose the Color Mode you want.

Use the Adjust Colors dialog box to choose the Color Mode you want.

## Blend colors

In Adobe Illustrator, Blend commands create smooth color transitions between three or more filled objects, using either stacking order or position.

Blend inserts intermediate colors between the selected objects. Use it for smooth, gradient-like color effects across several shapes. Blends work only on filled objects, not strokes or shapes without paint.

Choose the Selection tool from the toolbar.

Select three or more filled objects with Shift-click (Windows) or command-click (macOS).

Pick one of these actions depending on the blend direction you need:

- To blend gradually between the frontmost and backmost filled artworks through the intermediate artworks, select Edit > Edit Colors > Blend Front to Back.
- To blend gradually between the leftmost and rightmost filled artworks through the intermediate artworks, select Edit > Edit Colors > Blend Horizontally.
- To blend gradually between the topmost and bottommost filled artworks through the intermediate artworks, choose Edit > Edit Colors > Blend Vertically command.

## Change color tints

Change color tints in Illustrator when you need lighter or stronger versions of a color.

Select Window > Swatches.

In the Swatches panel, choose a Global Process Color or Spot Color, or choose an object that already uses one.

Select Window > Color.

In the Color panel, change the color’s intensity by dragging the T slider left or right, or by typing a value in the text box.

Note

When the T slider is missing, confirm that a Global Process Color or Spot Color is selected. If it still does not appear, open the More options dropdown list in the Color panel and select Show Options.

Tint values run from 0% to 100%; lower values produce a lighter Tint.

Use the Color panel to make Fill and Stroke active.

Use the Color panel to make Fill and Stroke active. Tip

To store the Tint as a swatch, drag the color into the Swatches panel or select New Swatch in the Swatches panel. Illustrator names the new swatch from the original color plus the Tint value. For example, if the base color is Sky Blue and the Tint is 50%, the swatch name becomes Sky Blue 50%.
