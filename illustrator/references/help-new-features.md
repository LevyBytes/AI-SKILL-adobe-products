## Performance enhancements in Adobe Illustrator on desktop

Review the latest Illustrator on desktop performance enhancements that help with complex files and design workflows.

### October 2025 (version 30.0)

Illustrator 30.0 includes these performance enhancements:

- Quicker save: Save complex artwork edits faster because Illustrator now saves only the changes you make, not the whole document every time.
- Better crash recovery: Restore your work quickly and reliably after an unexpected crash.
- Smoother editing: Edit on canvas in real time for lag-free move, scale, rotate, and duplicate operations.

Learn how to configure the quick save and recovery experience.

Noticed any performance improvements? Share your feedback.

### August 2025 (version 29.8.1)

Illustrator now opens faster, giving you quicker file access and a smoother, more responsive design-workflow experience.

### June 2025 (version 29.6)

Illustrator 29.6 includes these performance enhancements:

- Effects: Calligraphic Brushes and Art Brushes (Window > Brushes) render effects more quickly.
- Editing: Operations such as move, scale, rotate, and duplication feel smoother and faster.

Illustrator 29.5 includes these performance enhancements:

Menus:

- Top-level menus and context menus open faster and respond more quickly.
- Moving through Type > Font and the context Font menu is faster and smoother.

Links panel:

- Scrolling in the panel is faster.
- When you modify embedded and linked assets, including assets from network drives, the panel updates in real time.

Effects:

- Transform (Effect > Distort & Transform > Transform), Warp (Effect > Warp), and Blend (Object > Blend) are applied more quickly.
- Objects with multiple fills and strokes render effects faster.

Menus and menu items feel smoother and faster, making features easier to reach and workflows quicker to finish.

- File import: Open, place, and drag-and-drop PNG, JPEG, TIFF, and Photoshop files faster from your computer or network drives.
- Effects processing: Render the five most used effects more quickly: Drop Shadow, Inner Glow, Outer Glow, Blur, and Rasterize.
- Layers panel: Manage layers more smoothly and quickly, including hide/unhide, expand/collapse, and panel scrolling operations.

Image import, export, and embedding:

- Faster operations for JPEG and PNG files with File > Open, File > Place, and drag-and-drop
- JPEG and PNG file format export is faster
- Linked images convert to embedded images more quickly

Effects processing:

- Improved image performance for all Photoshop effects
- Faster object rasterization with Object > Rasterize

Layers panel:

Layer management is smoother and faster, including hide/unhide and expand/collapse operations, panel scrolling, and layer navigation.
