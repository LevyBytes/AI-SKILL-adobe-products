## Pattern overview

Patterns let you build repeating, consistent artwork that Adobe Illustrator can apply as fills or strokes.

In Adobe Illustrator, patterns are repeating designs used to fill an object's stroke or shape. They may be simple geometric tiles or detailed illustrations, giving you a fast way to add texture, decoration, or branding elements to artwork.

### About patterns in Illustrator

When you design with patterns in Illustrator, you can:

- Fill with recurring artwork instead of copying items by hand.
- Edit one pattern definition and have every object that uses it update.
- Mix patterns with colors, gradients, and effects to build distinctive designs.

### Types of patterns

- Predefined patterns: Illustrator provides built-in dots, stripes, textures, and other patterns in the Swatches panel.
- Custom patterns: Use the Pattern Options panel to build your own patterns and define tile size, spacing, overlap, and rotation.

## Create patterns

This section explains how to create patterns.

Choose the Rectangle tool from the toolbar to draw a rectangle, or hold it to reach additional live shapes: Rounded Rectangle, Ellipse, Polygon, Shaper, or Star tool.

Select the artwork that should become the pattern, then choose Object > Pattern > Make.

On the bar below the Control Panel, choose Save a Copy, Done, or Cancel.

Note

Creating a new pattern adds it to the Swatches panel. Editing an existing pattern automatically updates its definition in the Swatches panel.

## Edit patterns

This section covers editing patterns, including Tile type, Brick offset, and related settings.

In the Swatches panel, choose the existing pattern you need to edit.

When the Pattern Options dialog opens, enter a new name or revise the selected pattern's current name.

In the Pattern Options dialog box, you can adjust these settings:

- Tile Type: sets the tile layout method:
- Grid: places tiles in even horizontal and vertical alignment, similar to a checkerboard.
- Brick by Row: offsets rectangular tiles vertically in alternating columns, creating horizontal brick-style rows.
- Brick by Column: offsets rectangular tiles horizontally in alternating rows, creating vertical brick-style columns.
- Hex by Column: stacks hexagon tiles in vertical columns and shifts alternate columns sideways.
- Hex by Row: lays hexagon tiles in horizontal rows and shifts alternate rows up or down.
- Brick by Row: sets the vertical offset for tiles in alternate rows relative to their width.
- Brick by Column:. sets the horizontal offset for tiles in alternate columns relative to their height.
- Width: defines each tile's horizontal space; larger values create gaps, while smaller values can make tiles overlap.
- Height: defines each tile's vertical space; larger values create gaps, while smaller values can make tiles overlap.
- Size Tile to Art: use the checkbox to match the tile size automatically to the artwork.
- Move Tile with Art: use the checkbox so the tile moves together with the artwork.
- H Spacing: enter values for the horizontal gap between neighboring tiles.
- V Spacing: enter values for the vertical gap between neighboring tiles.
- Overlap: choose which tile is drawn in front when tiles overlap.
- Copies: enter values for the number of tile rows and columns shown while editing.
- Dim Copies to: enter a percentage that changes the opacity of tile previews during editing.
- Show Tile Edge: use the checkbox to show a border around each tile.
- Show Swatch Bounds: use the checkbox to highlight the pattern's repeat unit.

Adjust the pattern properties as needed in the Pattern Options dialog.

## Repeat patterns overview

Repeat patterns help build complex editable designs by copying objects into radial, grid, or mirror arrangements.

On the desktop, Illustrator provides a direct way to create and manage repeat patterns. After creating the object, choose Radial, Grid, or Mirror as the repeat type, and Illustrator updates every instance automatically when you modify the original object.

### Radial Repeat

Radial Repeat copies an object around a center point in a circular arrangement. You can change the repeat count and rotation angle to produce dynamic designs.

To open the Radial Repeat pattern, choose Object > Repeat > Radial.

Modify the Radial Repeat pattern with on-canvas controls.

### Grid Repeat

Grid Repeat places objects in an ordered row-and-column layout. Use this repeat type when patterns need consistent spacing and alignment.

To open the Grid Repeat pattern, choose Object > Repeat > Grid.

### Mirror Repeat

Mirror Repeat reflects objects across a central axis to create a symmetrical mirrored design. It is commonly used when artwork needs bilateral symmetry.

To open the Mirror Repeat pattern, choose Object > Repeat > Mirror.

## Create radial repeats

This section explains how to create and adjust radial repeats in Illustrator.

Using the Selection tool, select the object you want to repeat.

Choose Object > Repeat. Then choose Radial.

Tip

By default, Illustrator duplicates the selected object around a central axis, commonly with eight instances.

Use the on-canvas controls and adjust these settings:

- Use the instance handle to raise or lower the number of repeats.
- Pull the circular radius handle outward or inward to push objects away from the center or bring them back toward it.
- Use the circle splitter to remove some instances while leaving the repeated artwork unchanged.
- Drag a corner of the bounding area to resize the radial repeat overall.

## Set radial repeat options

For radial repeats in Adobe Illustrator, this section covers the available options.

With the Selection tool, choose the repeated artwork.

Choose Object > Repeat > Options.

Use the Repeat Options dialog box for these settings:

- Number of instances : set how many repeat instances appear in the repeated artwork. The default value is 8.
- Radius : set the circle radius used to create the radial repeat.

Enable the Reverse Overlap checkbox to switch the stacking order of objects in the Radial repeat.

Select OK.

## Create and modify a grid repeat

This section shows how one click can create artwork by repeating objects in an array.

### Create a grid repeat

Make the object that will be repeated.

Choose the object with the Selection tool.

Choose Object > Repeat > Grid.

### Modify grid repeat using on-canvas controls

Drag the handle at the bottom of the grid to add rows to the repeated artwork.

Drag the handle on the right side of the grid to add columns.

Drag from any corner to resize the grid repeat overall.

Drag the vertical or horizontal sliders inside the grid to adjust spacing between repeated objects.

## Set grid repeat options

This section explains how Repeat Options can adjust spacing and arrangement between objects in a grid.

Using the Selection tool, select the repeated artwork.

Choose Object > Repeat > Options.

In the Repeat Options dialog, open the Grid tab.

Set these options in the Repeat Options dialog box:

- Vertical spacing in grid : set the vertical gap between objects in the grid.
- Horizontal spacing in grid: set the horizontal gap between objects in the grid.
- Grid Type: select the grid type used to arrange objects in rows or columns.
- Flip Rows: flip rows vertically or horizontally.
- Flip Column: flip columns vertically or horizontally.

Adjust spacing, arrangement, and flipping settings for the repeated artwork.

### Modify grid repeat using on-canvas controls

With the Selection tool, select the artwork.

To add rows, pull the repeated artwork handle downward.

To add columns, pull the side handle.

To scale the whole grid larger or smaller, drag from a corner of the repeated artwork.

Adjust grid spacing by dragging the sliders positioned between repeated elements.

Use the horizontal slider for horizontal spacing, and use the vertical slider for vertical spacing.

## Create mirror repeats

Mirror repeats in Adobe Illustrator let you build symmetrical artwork from one side of a design.

Start with the first half of the symmetrical artwork, and Illustrator fills in the opposite half through mirror repeat.

Draw the first half of the artwork, then choose it with the Selection tool.

Choose Object > Repeat > Mirror. Illustrator converts the selected artwork into a mirror repeat.

## Set mirror repeat options

Mirror repeat options give you controls for changing symmetrical artwork.

Choose Object > Repeat > Options.

In the Repeat Options dialog box, open the Mirror tab.

Enter the needed value for Angle of mirror axis.

The Mirror tab of the Repeat Options dialog box controls the angle used for mirrored repeats.

The mirrored-repeat angle is set from the Mirror tab in the Repeat Options dialog box. Tip

To modify an individual shape or object inside the repeated pattern, select the artwork, then choose Object > Expand so the result becomes a group of editable shapes.

### Modify mirror repeat using on-canvas controls

Double-click the artwork.

Use these on-canvas controls to change a mirror repeat:

- To rotate or transform the mirrored part, drag the handles positioned above or below the original artwork.
- Move the symmetry axis between the two shapes to adjust both angle and spacing between the two artworks. When the edit is complete, double-click outside the objects to hide the control handles. Illustrator keeps both halves grouped so they can move as one object. To return to editing, double-click the artwork again.
