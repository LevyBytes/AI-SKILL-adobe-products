## Character panel overview

Learn which Character panel options adjust text appearance in artwork.

To open the Character panel, choose Window > Type > Character.

Initially, the Character panel displays only common options. To show everything, select the panel control in the panel, then choose Show Options.

## Transform text

Learn to transform text by scaling, rotating, or skewing it so it aligns better with a design.

### Selecting type for transformations

Select the type object with the Selection tool.

Use one of these methods:

- To transform the type together with its bounding path, select the Rotate tool, then rotate both the object and the text.
- To transform only the bounding path, drag the path with the touch type rotate icon that appears at the path corners.

Use the Path Rotate cursor to rotate the path without changing the text.

With the Path Rotate cursor, rotate the path while leaving the text unchanged.

### Adjust the scale of type

You can set the height-to-width relationship of type relative to the characters' original dimensions. Characters that have not been scaled use 100%. When possible, a font designed as condensed or expanded is usually the better choice.

Select the characters or type objects to scale.

Note

When no text is selected, the scale setting applies to text you create next.

Choose Window > Type > Character.

In the Character panel, set Vertical Scale or Horizontal Scale.

### Rotate type

Select the characters or type objects.

Use one of these methods:

- To rotate characters inside a type object by a specific number of degrees, choose Window > Type > Character, then set the Character Rotation value in the Character panel.
- To change type orientation, choose Type > Type Orientation > Horizontal or Type > Type Orientation > Vertical, depending on whether you need horizontal or vertical type.
- For the full type object, rotate the characters together with the object's bounding area. Use any of these controls: bounding box, Free Transform tool, Rotate tool, Rotate command, or Transform panel.
- For multiple characters in vertical Asian text, use Tate‑chu-yoko.

## Change case and capitalization styles

Learn to adjust case and capitalization so text reads better and fits the design flow.

### Apply All Caps and Small Caps formatting

Select the text or characters to modify.

Choose Window > Type > Character.

In the Character panel, select More options, then choose either option as needed:

- All Caps: changes the selected text to uppercase letters.
- Small Caps: changes the selected text to lowercase letters.

Font family, font style, and font size are controlled from the Character panel.

The Character panel is where you set font family, font style, or font size.

### Change capitalization styles

Choose the text or individual characters that need a case change.

Open Type > Change Case, then choose the command that fits:

- UPPERCASE: changes every character to uppercase.
- lowercase: changes every character to lowercase.
- Title Case: gives each word an initial capital.
- Sentence case: gives each sentence an initial capital.

## Adjust kerning and tracking

Use Illustrator kerning and tracking controls to refine character spacing.

Kerning adds or removes space for particular character pairs. Kerning and tracking values also affect Japanese text, though they are most often used when adjusting spacing for Roman characters.

### Adjust kerning

Choose the text to revise, or select the particular pair of characters.

Open Window > Type > Character.

In the Character panel, use whichever action matches the needed kerning change:

- Choose Auto or Metrics - Roman Only from the Set the kerning between two characters dropdown to use the font's built-in kerning data for the selected characters.
- Choose Optical from the Set the kerning between two characters dropdown so spacing is calculated automatically from the selected character shapes.
- Type a specific value in the Set the kerning between two characters dropdown when you want to set the spacing manually.
- Set the Set the kerning between two characters value to 0 when kerning should be disabled for the selected characters.

The Character panel also includes controls for baseline shift, font size, and additional settings.

The Character panel also includes controls for baseline shift, font size, and additional settings. Tip

For keyboard kerning between two characters, press Alt + Left or Right Arrow (Windows) or Option + Left or Right Arrow (macOS).

### Adjust tracking

Tracking loosens or tightens character spacing across selected text or a full text block.

Choose the text that needs tracking adjustment.

Open Window > Type > Character.

In the Character panel, change the tracking amount with the Set the tracking for the selected characters dropdown.

Tip

Type a positive value in the Set the tracking for the selected characters dropdown to add space across all characters in the selected text.

Type a negative value in the Set the tracking for the selected characters dropdown to reduce space between characters.

## Vary font height

Use font-height controls when text height needs to support the layout or visual emphasis.

Select a text frame using the Selection tool.

Open Window > Type > Character.

Choose More options > Show Font Height Options from the Character panel.

Choose the needed height metric from the Set font height reference dropdown in the Character panel:

- Em Box: bases font size on the font's complete em square.
- Cap Height: bases font size on the height of uppercase letters.
- x-Height: bases font size on the height of lowercase characters.
- ICF Box: bases font size on the ICF (Ideographic Character Face) Box, which is commonly used in CJK fonts.

The Character panel can vary font height, style, or size.

## Turn fractional character widths off or on

Review how Illustrator lets you enable or disable fractional character widths.

Illustrator normally applies fractional character widths, so spacing can vary and sometimes land on fractions of a pixel rather than whole pixels. Disable fractional widths when type spacing should use whole-pixel increments and small text needs to stay separated.

Note

The fractional character width setting applies to every character on a type layer; it cannot be assigned to single characters.

Select the text object whose character spacing needs modification using the Selection tool.

Open Window > Type > Character.

In the Character panel, choose More options > Fractional Widths.

Tip

Choose Fractional Widths again to turn it off.

Choose System Layout to apply whole-pixel type spacing across the full document.

Choose System Layout when the full document should use whole-pixel type spacing.

## Adjust word and letterspacing in justified text

Use the Paragraph panel to tune spacing between words and letters in text.

Spacing settings apply to a full paragraph. Character spacing can also be adjusted with Set the tracking for the selected characters in the Character panel.

Choose the Type tool from the tool panel and select the paragraph to edit.

Select Window > Type > Paragraph

In the Paragraph panel menu, choose Justification.

In the Justification dialog box, enter Minimum, Maximum, and Desired values for these options:

- Word Spacing: sets the gaps created by the spacebar between words. Allowed values are 0% through 1000%; 100% adds no extra space.
- Letter Spacing: sets gaps between letters, including kerning and tracking. Allowed values are -100% through 500%; 0% adds nothing, while 100% adds one full space width.
- Glyph Scaling: controls character width. A glyph means one font character. Allowed values for Glyph Scaling are 50% through 200%.

Note

Minimum and Maximum set the allowed spacing range for justified paragraphs only. Desired sets the intended spacing for both justified and unjustified paragraphs.

In the Justification dialog box, percentage values control spacingglyph scaling.

In the Justification dialog box, percentage values control spacingglyph scaling.

Enter a percentage value for Auto Leading to set automatic line spacing.

Tip

Use the Single Word Justification dropdown menu to choose how single-word paragraphs align, then select OK.

In narrow text columns, full justification can stretch single words too far. For better visual balance, set Single Word Justification to Align Left, Align Right, or Align Center.

## Indent text

Use the Paragraph and Tabs panels to create paragraph indents and hanging indents.

Indention is the space between text and a type object's boundary. Indention changes only the selected paragraph or selected paragraphs. Indents can be set with the Tabs panel, the Control panel, or the Paragraph panel. With the Area Type tool, indentation can also be adjusted through Inset Spacing for the type object.

Note

For Japanese type, Mojikumi Settings can define the first-line indent instead of the Paragraph panel indent controls. When both are used, Illustrator places the text inside the combined indent amount.

### Set indents using the Paragraph panel

Select the paragraph to indent using the Type tool from the tool panel.

Open Window > Type > Paragraph.

In the Paragraph panel, use actions such as these to set the relevant indent values:

- To indent the full paragraph by one pica, type 12 pt in the Left indent box.
- To indent from the paragraph's right side by one pica, type 12 pt in the Right indent box.
- To indent just the first line of a paragraph by one pica, type 12 pt in the First-line left indent box.

Set paragraph formatting with left, right, and first-line indents.

A. Left indent B. Front-line left indent C. Right indent

Set paragraph formatting with left, right, and first-line indents.

### Set an indent using the Tabs panel

Select the paragraph to indent using the Type tool from the tool panel.

Open Window > Type > Tabs.

In the Tabs panel, use the indent markers in one of these ways:

- Drag the top marker to indent the first line of text. Drag the bottom marker to indent every line except the first.
- To move both markers and indent the full paragraph, Ctrl + drag (Windows) or command + drag (macOS) the bottom marker.
- For a first-line indent, select the top marker and type a value for X. For the remaining lines, select the bottom marker and enter the X value that moves all but the first sentence.

### Create a hanging indent

A hanging indent leaves the first line flush while indenting every following line. Use this format for bulleted lists or when inline graphics begin a paragraph.

Select the paragraph to indent using the Type tool from the tool panel.

Choose Window > Type > Paragraph.

Set the Left indent box to a value greater than zero in the Paragraph panel.

Choose the paragraph's first line, then type a negative value in the First-line left indent box.

Tip

The Tabs panel can also create a hanging indent by placing indent markers manually. Open it with Window > Type > Tabs.

## Create bulleted or numbered lists

Use the Properties panel, Control panel, or context menu to apply, customize, and format bulleted or numbered lists.

In bulleted lists, each paragraph begins with a bullet character. In numbered lists, a number or letter starts each paragraph, followed by a separator such as a period or a parenthesis. Both formats help users identify key points as ordered or unordered text.

Choose the Type tool from the Tools panel and select the paragraphs that should become the list, or place the insertion point where the list should begin.

Use any of these methods to create bulleted or numbered lists:

- Open Window > Control to show the Control panel, then choose Bullets or the Numbered List option.

After selecting paragraphs, choose a style in the Bullets or Numbered List dropdown.

After selecting paragraphs, choose a style in the Bullets or Numbered List dropdown.

- In the Properties panel's Paragraph section, use the Paragraph More Options icon, then select the Bullets or the Numbered List option.
- From the text context menu, select Bullets and Numbering > Apply Bullets or Apply Numbers.
- From the top menu, select Type > Bullets and Numbering > Apply Bullets or Apply Numbers.
- Open Window > Type > Paragraph to show the Paragraph panel, then choose Bullets or Numbered List.

Note

Illustrator recognizes lists automatically when you type keyboard sequences such as 1. or 1) or A. or A).

Place the insertion point at the list end and press Enter (Windows) or return (macOS) to continue the list in the following paragraph.

To create custom bullets, type one of these characters followed by a space:

- - <Space>
- # <Space>
- > <Space>
- - <Space>

To preview and apply preset bullet or number types, open the dropdown beside Bullets or Numbered List and choose More Options. In the Bullets and Numbering dialog box, use the Bullets or Numbers tab, then choose the bullet character or number style you want to preview in the text.

After selecting the list, use these Bullets and Numbering dialog box controls for formatting:

- For list alignment, choose a position from the Alignment dropdown menu.
- To shift the whole paragraph away from the left margin, edit the point values in the Left Indent field.
- For First Line Indent, change the point values to reposition only the first line relative to Left Indent.

## Adjust text alignment and spacing on paths

Use path-text alignment and spacing controls to get tighter control over typographic layout on curved or shaped paths.

### Adjust alignment

Choose the path that already uses the Type on a Path Tool.

Open Type > Type on a Path > Type on a Path Options.

Use one of these Align to Path choices to control how characters sit relative to the path:

- Ascender: aligns text to the top edge of the font.
- Descender: aligns text to the bottom edge of the font.
- Center: places text on the path midway between the ascender and descender.
- Baseline: uses the baseline for alignment. This is the default setting.

### Adjust spacing

With the Selection tool, double-click the text on a path so it is selected.

Open Type > Type on a Path > Type on a Path Options.

Within Type on a Path Options, raise the Spacing value when characters need more separation or overlap needs to be reduced.

Select OK to apply the change.
