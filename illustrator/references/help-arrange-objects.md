## Overview

## Move objects

Illustrator offers several ways to move objects.

Objects can be repositioned by dragging with particular tools, using keyboard arrow keys, or typing exact values into a panel or dialog box.

### Move an object by dragging

With the Selection tool, choose one or more objects.

Drag the object to the new position.

### Move an object using the arrow keys

With the Selection tool, choose one or more objects.

Press the arrow key that matches the direction you want the object to move.

### Move an object using X and Y coordinates

With the Selection tool, choose one or more objects.

Select Window > Transform.

In the Transform panel, type values in the X text box, the Y text box, or both.

Use the Transform panel when you need to change Rotate and Shear settings.

The Transform panel also lets you adjust Rotate and Shear settings. Tip

Before entering values, change the Reference Point by selecting a white square on the Reference Point.

## Move multiple objects at once

Move several objects together in Illustrator.

With the Selection tool, choose one or more objects.

Select Object > Transform > Transform Each.

Under Move in the Transform Each dialog box, type the Horizontal and Vertical distances.

Set the Angle of rotation in the Transform Each dialog box.

The Transform Each dialog box includes the Angle of rotation setting.

Select OK.

Note

To randomize movement within the entered values, enable the Random checkbox. Then select OK.

## Move objects by specific distances

Move objects by exact distances in Illustrator.

With the Selection tool, choose one or more objects.

Select Object > Transform > Move.

Note

You can also open the Move dialog box by double-clicking the Selection, Direct Selection, or Group Selection tool.

In the Move dialog box, change any of these settings as needed:

- To shift the object horizontally, enter a negative value in the Horizontal text box for left movement or a positive value for right movement.
- To shift the object vertically, enter a negative value in the Vertical text box for upward movement or a positive value for downward movement.
- For Angle movement relative to the object's x-axis, type a positive angle for counterclockwise movement or a negative value for clockwise movement in the Angle text box.

In the Move dialog box, enable Transform Patterns when only the pattern should move and the object should stay in place.

Use Transform Patterns in the Move dialog box to move the pattern without moving the object. Tip

Values from 180 degrees through 360 degrees can also be entered. Illustrator converts those values to equivalent negatives; for example, 270 degrees becomes -90 degrees.

Select OK.

## Move or duplicate an object by pasting

Move or duplicate an object in Illustrator by pasting it.

With the Selection tool, choose one or more objects.

Select Edit > Cut to move the selection, or select Edit > Copy to duplicate it.

Choose any required command:

- Edit > Paste: places the object in the center of the active window.
- Edit > Paste in Front: puts the object ahead of the current selection.
- Edit > Paste in Back: puts the object behind the current selection.
- Edit > Paste in Place: puts artwork on the active artboard while keeping the coordinates from the artboard it was copied from.
- Edit > Paste on All Artboards: adds artwork to every artboard at the position it occupies on the current artboard.

Use Edit Colors in the Edit menu to adjust and modify artwork colors.

Artwork colors can also be adjusted and modified with the Edit Colors option in the Edit menu.

## Paste an object relative to other objects

In Illustrator, you can paste one object in relation to another object.

With the Selection tool, choose the object that will be copied.

Choose Edit > Copy.

Click the target object that should sit immediately in front of or behind the pasted object.

Use the paste command that matches the placement you need:

- Edit > Paste in Front: places the copied object directly ahead of the selected object.
- Edit > Paste in Back: places the copied object directly behind the selected object.

### Paste objects between layers

With the Selection tool, select the object or objects you plan to move.

Choose Edit > Copy.

Choose Window > Layers.

In the Layers panel, click the destination layer for the pasted object.

Choose Edit > Paste in Place.

## Align or distribute selected objects

Illustrator lets you align or distribute selected objects.

Choose Window > Align to open the Align panel, where selected objects can be aligned or distributed on the axis you specify.

The Align panel can place selected objects at the horizontal and vertical center of the artwork.

The Align panel also centers selected artwork horizontally and vertically.

### Align or distribute relative to the bounding box of all selected objects

With the Selection tool, select the objects that need alignment or distribution.

Choose Window > Align.

In the Align panel, choose Align to Selection.

In the Align panel, choose the alignment or distribution control that fits the design.

### Align or distribute relative to one anchor point

Choose the Direct Selection tool, hold Shift, and click the anchor points that need alignment or distribution.

Choose Window > Align.

In the Align panel, choose the alignment or distribution control that fits the design.

### Align or distribute relative to a key object

With the Selection tool, select the objects that need alignment or distribution.

Using the Selection tool again, click the object to make it the key object without holding Shift.

Note

The key object receives a blue outline, and Align To Key Object is selected automatically in the Align panel.

Choose Window > Align.

In the Align panel, choose the alignment or distribution control that fits the design.

### Align or distribute relative to an artboard

With the Selection tool, select the objects that need alignment or distribution.

Choose the Selection tool, then Shift-click the artboard you want to use.

Choose Window > Align.

In the Align panel, choose Align to Artboard.

In the Align panel, choose the alignment or distribution control that fits the design.

## Distribute objects by specific distances

Illustrator can distribute objects precisely by a specified distance.

With the Selection tool, select the objects to distribute.

Tip

Hold Shift when selecting more than one object.

Using the Selection tool again, click the object to make it the key object without holding Shift.

Choose Window > Align.

In the Align panel, choose More options > Show Options.

In the Align panel, choose one of these Distribute Spacing controls, then enter the exact object-to-object distance:

- Vertical Distribute Space: spaces objects evenly from top to bottom using the value you enter.
- Horizontal Distribute Space: spaces objects evenly from left to right using the value you enter.

Artwork objects can be aligned to a Selection, Key Object, or an Artboard.

Objects in the artwork can use Selection, Key Object, or Artboard as the alignment reference.

## Expand objects

Illustrator can expand objects.

Expanding converts an object's appearance attributes into separate objects. For instance, when a simple circle with a solid-color Fill and a Stroke is expanded, the Fill and Stroke become individual objects.

Select the object with the Selection tool.

Choose Object > Expand.

Note

When appearance attributes are applied to the object, Object > Expand is unavailable. In that situation, choose Object > Expand Appearance, and then choose Object > Expand.

In the Expand dialog box, configure these options as needed:

- Object: expands complex objects such as live blends, envelopes, symbol sets, and flares.
- Fill: turns Fill attributes into independent editable objects.
- Stroke: converts strokes into outlined paths.

Set the allowed color-stop value tolerance in the Expand dialog box.

Use the Expand dialog box to provide the color-stop value tolerance.

Tip

Press Alt (Windows) or Option (macOS) while choosing Object > Expand to expand a Gradient with the most recent Expand dialog box settings.

Under Export Gradient To in the Expand dialog box, choose Gradient Mesh to turn a Gradient into one mesh object.

Choose OK.

## Rotate objects

Use Illustrator rotation tools to position objects precisely in your designs.

### Rotate an object using the bounding box

Select one or more objects with the Selection tool.

Tip

Hold Shift when selecting more than one object.

Move the pointer just outside the bounding box near a bounding-box handle until it changes to the Rotate icon, then drag to rotate.

### Rotate an object with the Free Transform tool

Select one or more objects with the Selection tool.

Choose the Free Transform tool.

Move the pointer outside the bounding box until it changes to the Rotate icon, then drag to rotate.

### Rotate an object with the Rotate tool

Select one or more objects with the Selection tool.

Choose the Rotate tool.

Use the method that matches the rotation you need:

- To rotate around the object's center point, drag in a circular motion anywhere in the document window.
- To rotate around another reference point, click once in the document window to move the reference point. Then move the pointer away from that point and drag in a circular motion.
- To rotate a copy instead of the original object, begin dragging to rotate, then press Alt (Windows) or Option (macOS).

Note

For more exact control, start the drag farther away from the object's reference point.

### Rotate an object with the Transform panel

Select one or more objects with the Selection tool.

Choose Window > Transform.

In the Transform panel, use the method that matches the rotation you need:

- To rotate around the object's center point, enter a value in the Rotate field.
- To rotate around another reference point, choose a white square on the Reference Point, then enter a value in the Rotate field.

The Transform panel can define the Rotate or Shear angle.

You can set either Rotate or Shear angle values in the Transform panel.

## Rotate multiple objects individually

Adobe Illustrator can rotate multiple selected objects separately.

With the Selection tool, select the objects to rotate.

Choose Object > Transform > Transform Each.

In the Transform Each dialog box, type the rotation amount in the Angle field.

The Transform Each dialog box also provides Scale and Move controls.

Use the Transform Each dialog box when Scale or Move settings also need adjustment.

Choose OK.

## Rotate objects by specific angles

Illustrator lets you rotate objects by exact angle values.

### Rotate an object by a specific angle

Select one or more objects with the Selection tool.

Choose Object > Transform > Rotate.

In the Rotate dialog box, type the exact rotation value in the Angle text box.

Tip

Type a negative Angle value to rotate the object clockwise.

Use a positive Angle value in the Rotate dialog box for counterclockwise rotation.

For another counterclockwise rotation entry, provide a positive Angle value in the Rotate dialog box.

Choose OK.

Note

If the objects include a pattern fill, choose Transform Patterns checkbox to rotate that pattern.

To rotate the pattern only and leave the objects unchanged, deselect Transform Objects checkbox.

### Rotate the X and Y axes of a document

The X and Y axes normally run parallel to the document window's horizontal and vertical edges.

Choose Edit > Preferences > General (Windows) or Illustrator > Settings > General (macOS).

Type the wanted Constrain Angle in the text box of the General Preferences dialog box.

Note

Positive angle values rotate the axes counterclockwise; negative values rotate them clockwise.

In the General Preferences dialog box, type the Corner Radius you want.

In the General Preferences dialog box, enter the desired Corner Radius.

Choose OK.

## Reflect or flip objects

Adobe Illustrator can reflect or flip objects.

### Reflect an object with the Free Transform tool

Choose the object to reflect with the Selection tool.

In the Tools panel, choose the Free Transform tool.

Pull a bounding-box handle beyond the opposite side or handle until the reflection reaches the amount you want.

Tip

To keep the object's proportions unchanged, press Shift key while dragging a corner handle past the handle opposite it.

### Reflect or flip object with the Reflect tool

Choose the object to reflect with the Selection tool.

In the Tools panel, choose the Reflect tool.

Click a location on the artboard to place the first point for the hidden reflection axis.

Move the pointer elsewhere to establish the second axis point, then use whichever of these actions fits the result you need:

- Click to flip the selected object across the axis you defined.

Click to set one point of the axis (left), then click again to set the other axis point and reflect the object across the axis (right).

Click to set one point of the axis (left), then click again to set the other axis point and reflect the object across the axis (right).

- Press Alt (Windows) or Option (macOS) and click to place the second point of the hidden axis and create a reflected copy.
- To revise the reflection axis, drag rather than click; Shift-drag limits the angle to 45-degree increments.

Drag the second point of the reflect axis to rotate it.

Drag the second point of the reflect axis to rotate it. Note

While you drag, the hidden reflection axis turns around the first point you set in Step 3. Illustrator shows a reflected outline of the object; release the mouse button once that outline is where you want it.
