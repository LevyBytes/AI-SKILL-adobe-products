# Trace an image quickly with limited tracing options

Image Trace can be started from faster controls when you want less setup than the full Image Trace panel provides:

Select the image to trace with the Selection tool.

Use any of these methods to trace the image:

- Select Image Trace in the Contextual Task Bar to start Image Trace immediately with the Default preset.
- Select Image Trace in the Properties panel to start Image Trace with any tracing preset.

Note

Even after starting Image Trace through one of these routes, you can refine the result later in the Image Trace panel.
