# Save custom tracing presets

Save custom Image Trace presets so your preferred tracing settings are easy to apply again later.

Choose Window > Image Trace; the Image Trace panel opens.

Set the tracing options as needed.

Select Manage Presets next to the Preset dropdown, then select Save as New Preset.

Save tracing settings as custom presets for quick reuse.

Store tracing settings in custom presets so they can be applied again quickly.

Enter a preset name and select OK.

For deleting or renaming, first choose the preset in the Preset dropdown. Open Manage Presets, then select Delete or Rename.

Note

Default presets cannot be edited or deleted. They appear inside square brackets.
