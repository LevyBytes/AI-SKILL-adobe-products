# Apply the fonts organized in Creative Cloud Libraries

Find, preview, and apply Creative Cloud Libraries fonts from the font browser when styling text in Adobe Illustrator.

Select the text with the Selection tool.

Choose Window > Type > Character to open the Character panel.

Open the Set the font family dropdown to show the font browser, then go to the Libraries tab.

To sort the Libraries, choose Sort Font Libraries, then choose Date modified or Name.

Select the Library that contains the needed font.

Preview the font:

- The sample-text preview appears beside the font name. Change the sample text, change its size, or turn the preview off if needed.
- Hover over the font name to preview that font on the selected canvas text.

Before applying a font to selected canvas text, hover over its name and identify whether it is a local font (shown by one of the Font Technology icons), an added font, or a font not yet added (shown by Add). Then apply it as follows:

- For a local font or an added font, select the font.
- For a font that has not yet been added, select Add; after it is added, select the font.
