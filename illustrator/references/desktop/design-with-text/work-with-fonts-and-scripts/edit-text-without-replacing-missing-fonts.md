# Edit text without replacing missing fonts

Edit text that uses missing fonts without causing text to break.

Double-click the text with the missing fonts.

In the warning message, select OK.

Note

Illustrator replaces the missing fonts with the default font and highlights the affected text.

Edit the text.

To clear substitute-font highlighting, open Edit > Preferences > Type (Windows) or Illustrator > Settings > Type (macOS).

Within Preferences, deselect Highlight Substituted Fonts, and then select OK.

Clear substituted-font highlights in the Preferences dialog box.
