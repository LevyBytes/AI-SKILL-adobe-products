# Libraries tab

Creative Cloud Libraries are available from the font browser's Libraries tab for organizing fonts. You can work with existing Libraries there or create Libraries directly in that tab. For contextual font management, the Libraries tab:

- Lists every Library created inside the font browser, including Libraries that do not contain fonts.
- Lists only Libraries from the Libraries panel of Illustrator, from other apps, and from the Adobe Fonts website when they include at least one font. To make an empty Library appear in the Libraries tab, add fonts to it from the Adobe Fonts website.
- Displays only the fonts in each Library and suppresses any other assets.
