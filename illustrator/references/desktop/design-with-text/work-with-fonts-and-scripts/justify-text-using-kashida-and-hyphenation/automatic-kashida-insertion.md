# Automatic Kashida insertion

Arabic justification is handled by adding Kashidas; the spaces between characters stay unchanged.

With the Type tool, select the paragraph that contains Arabic text.

Choose Type > Convert To Area Type so the text flows inside the box.

Open Window > Type > Character, then open the Character panel menu.

From the Character panel menu, choose Kashidas.

Open Window > Type > Paragraph, then switch the paragraph alignment to any justified alignment.

Note

Paragraphs that already use alignment settings do not use this setting.

From the Insert Kashidas dropdown menu, choose one of these options:

- None: leaves the text unchanged.
- Short: places short Kashidas in the text.
- Medium: adds Kashidas of moderate length.
- Long: applies longer Kashidas.
- Stylistic: lets the font style determine Kashida changes automatically.
