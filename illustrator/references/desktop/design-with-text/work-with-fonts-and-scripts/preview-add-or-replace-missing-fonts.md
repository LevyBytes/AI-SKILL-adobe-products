# Preview, add, or replace missing fonts

Manage missing fonts so designs stay consistent and manual replacement work is reduced.

Opening a file with missing fonts in Adobe Illustrator displays the Missing Fonts dialog box and a font list. A selected checkbox with Available on Adobe Fonts means the font can be obtained from Adobe Fonts. A greyed-out checkbox with Preview only means Adobe Fonts cannot supply the font, though the file can still show a preview.

Use File > Open (Windows) or Illustrator > Open (macOS) to open the file.

Within the Missing Fonts dialog box, choose one of these actions:

- Choose Add Fonts to bring Adobe Fonts matches into Illustrator.
- Choose Replace Fonts when substituting another font from your file, recent fonts, or your computer.
- To preview the file while leaving missing fonts unadded and unreplaced, select Close.

Note

Add Fonts depends on Adobe Fonts being active in Creative Cloud Desktop. In Adobe Creative Cloud, go to Main Menu > File > Preferences > Services, and turn on Adobe Fonts.

Add, replace, or preview missing fonts to keep work moving.

Some fonts do not work with preview, so Illustrator substitutes the default font automatically and highlights those fonts.
