# Find and apply local or added fonts

From the font browser's Your Fonts tab, locate, preview, and apply fonts installed locally or added to your account from Adobe Fonts:

With the Selection tool, select the text, or the portion of text, that should receive the font. When you are only browsing or choosing a font for later use, omit this step.

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Note

Other entry points for Set the font family: Contextual Task Bar, Character section in the Properties panel, and Control panel. Fonts can also be found and applied through Type > Font.

In Your Fonts, review local fonts and fonts added from Adobe Fonts:

- Look through Recently used or Your fonts. Apply filters or quick filters if the list needs to be narrowed.
- Enter the font name in the Set the font family field.

Use filters when you need fonts from particular sources or with particular font properties.

Check the preview before applying a font to confirm that it fits the design:

- The sample-text preview appears beside the font name. By default, it uses the text selected on the canvas; when no text is selected, the preview uses Sample. Adjust the sample text, change its size, or turn the preview off as needed.
- Hover over the font name to preview that font on the selected canvas text.

Select a font to apply it to the selected text on the canvas. If no canvas text is selected when you choose a font, Illustrator applies that font automatically to the next text object you create.
