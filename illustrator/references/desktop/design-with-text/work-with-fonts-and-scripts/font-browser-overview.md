# Font browser overview

Use this overview to understand the font browser in Adobe Illustrator and how it helps with finding, previewing, and organizing fonts.

Illustrator can style text with fonts installed locally and with fonts added from Adobe Fonts. In the font browser, filters and related controls help you search and preview fonts from both sources, then arrange them through Creative Cloud Libraries.

To open the font browser, choose Window > Type > Character. In the Character panel, open the Set the font family dropdown. The same browser is also available in the Properties panel, the Control panel, and the Contextual Task Bar after you select text on the canvas.

Use the browser's controls to choose a font suited to the current design.
