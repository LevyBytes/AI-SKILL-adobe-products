# Set up automatic addition of missing fonts

When automatic addition is enabled and you open a file containing missing fonts, Illustrator can take these actions:

- Add fonts in the background when every missing font is available in Adobe Fonts.
- Open the Missing Fonts dialog box with a list of missing fonts and an add option when only some of them are available.
- Open the Missing Fonts dialog with a font-replacement list when Adobe Fonts has none of the missing fonts.

Open File Handling preferences through Edit > Preferences > File Handling (Windows) or Illustrator > Settings > File Handling (macOS).

Within Preferences, choose Auto-activate Adobe Fonts in the Fonts category.

Select OK.

After setup, Illustrator adds missing fonts in the background and does not display a notification. To check progress, select the spinner icon in the menu bar.
