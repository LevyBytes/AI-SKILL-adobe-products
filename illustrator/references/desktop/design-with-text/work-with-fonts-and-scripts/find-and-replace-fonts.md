# Find and replace fonts

Use find and replace fonts to update the look of selected text throughout the document.

Select Type > Find/Replace Font.

In the Find/Replace Font dialog box, choose the font from Fonts in Document.

Note

Illustrator highlights one continuous font occurrence in the document at a time. To find every occurrence of that font, use the Fonts in Document list.

From the Replace With Font From dropdown menu, choose one of these replacement sources:

- Document: Lists the fonts used in the document.
- Recent: Lists fonts used recently.
- System: Lists fonts installed on your computer.

Choose a new font to replace the current font.

In the list, pick the style that should replace the selected text.

For the current occurrence only, select Change. For every occurrence of that font in the document, select Change All.

Select Done to see the updates in the selected text.
