# Adjust paragraph spacing

Set paragraph before-and-after space to improve readability and text layout.

Select a paragraph with the Type tool, or select a type object when all of its paragraphs should change.

Note

When no text is selected, Illustrator applies the setting to text created afterward.

Open Window > Type > Paragraph.

In the Paragraph panel, set values for Space before paragraph and Space after paragraph.

Adjust spacing with Space before and Space after.

Adjust spacing with Space before and Space after. Tip

When a paragraph starts at the top, Illustrator adds no extra space before it. In that situation, increase the leading of the paragraph's first line or change the type object's inset spacing.
