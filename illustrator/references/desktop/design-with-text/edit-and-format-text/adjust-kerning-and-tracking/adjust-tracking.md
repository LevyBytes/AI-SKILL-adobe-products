# Adjust tracking

Tracking loosens or tightens character spacing across selected text or a full text block.

Choose the text that needs tracking adjustment.

Open Window > Type > Character.

In the Character panel, change the tracking amount with the Set the tracking for the selected characters dropdown.

Tip

Type a positive value in the Set the tracking for the selected characters dropdown to add space across all characters in the selected text.

Type a negative value in the Set the tracking for the selected characters dropdown to reduce space between characters.
