# Create bulleted or numbered lists

Use the Properties panel, Control panel, or context menu to apply, customize, and format bulleted or numbered lists.

In bulleted lists, each paragraph begins with a bullet character. In numbered lists, a number or letter starts each paragraph, followed by a separator such as a period or a parenthesis. Both formats help users identify key points as ordered or unordered text.

Choose the Type tool from the Tools panel and select the paragraphs that should become the list, or place the insertion point where the list should begin.

Use any of these methods to create bulleted or numbered lists:

- Open Window > Control to show the Control panel, then choose Bullets or the Numbered List option.

After selecting paragraphs, choose a style in the Bullets or Numbered List dropdown.

- In the Properties panel's Paragraph section, use the Paragraph More Options icon, then select the Bullets or the Numbered List option.
- From the text context menu, select Bullets and Numbering > Apply Bullets or Apply Numbers.
- From the top menu, select Type > Bullets and Numbering > Apply Bullets or Apply Numbers.
- Open Window > Type > Paragraph to show the Paragraph panel, then choose Bullets or Numbered List.

Note

Illustrator recognizes lists automatically when you type keyboard sequences such as 1. or 1) or A. or A).

Place the insertion point at the list end and press Enter (Windows) or return (macOS) to continue the list in the following paragraph.

To create custom bullets, type one of these characters followed by a space:

- `* <Space>`
- `# <Space>`
- `> <Space>`
- `+ <Space>`

To preview and apply preset bullet or number types, open the dropdown beside Bullets or Numbered List and choose More Options. In the Bullets and Numbering dialog box, use the Bullets or Numbers tab, then choose the bullet character or number style you want to preview in the text.

After selecting the list, use these Bullets and Numbering dialog box controls for formatting:

- For list alignment, choose a position from the Alignment dropdown menu.
- To shift the whole paragraph away from the left margin, edit the point values in the Left Indent field.
- For First Line Indent, change the point values to reposition only the first line relative to Left Indent.

Adjust alignment and indents

Adjust alignment and indents Tip

Use Tab to indent and create a sublist; use Shift + Tab to decrease the indent level.

For multi-level lists, select text and change the Level option in the Bullets and Numbering dialog box; Illustrator supports up to nine levels.

To turn bullets and numbered lists into plain text, select the paragraph that contains the bulleted or numbered list, then choose Type > Bullets and Numbering > Convert to text.
