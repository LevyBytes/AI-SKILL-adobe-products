# Underline or strikethrough text

Learn to apply Underline or Strikethrough formatting to text.

Select the text to underline or strike through.

Choose Window > Type > Character.

In the Character panel, choose one of these formatting options as needed:

- Underline : places an underline directly beneath the selected text; it is commonly used to emphasize or highlight important content.
- Strikethrough : draws a line through the center of the text and is often used to show content as deleted or irrelevant while leaving it visible.

Use the Character panel when you need to underline or strike through text.

The Character panel provides the controls for underlining text or applying strikethrough.
