# Rotate type

Select the characters or type objects.

Use one of these methods:

- To rotate characters inside a type object by a specific number of degrees, choose Window > Type > Character, then set the Character Rotation value in the Character panel.
- To change type orientation, choose Type > Type Orientation > Horizontal or Type > Type Orientation > Vertical, depending on whether you need horizontal or vertical type.
- For the full type object, rotate the characters together with the object's bounding area. Use any of these controls: bounding box, Free Transform tool, Rotate tool, Rotate command, or Transform panel.
- For multiple characters in vertical Asian text, use Tate‑chu-yoko.
