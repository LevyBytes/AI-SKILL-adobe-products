# Adjust the scale of type

You can set the height-to-width relationship of type relative to the characters' original dimensions. Characters that have not been scaled use 100%. When possible, a font designed as condensed or expanded is usually the better choice.

Select the characters or type objects to scale.

Note

When no text is selected, the scale setting applies to text you create next.

Choose Window > Type > Character.

In the Character panel, set Vertical Scale or Horizontal Scale.
