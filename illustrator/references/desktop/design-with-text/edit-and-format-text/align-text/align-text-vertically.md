# Align text vertically

Select the text frame using the Selection tool.

Open Type > Type Orientation > Vertical.

Open Type > Area Type Options.

In the Area Type Options dialog box, choose the needed Vertical alignment option:

- Right: places text along the right side of the frame.
- Center: places text in the frame's center.
- Left: places text along the left side of the frame.
- Justify: spreads text evenly from the top of the frame to the bottom.

In the Area Type Options dialog box, enter the needed row and column counts to split the text area.

In the Area Type Options dialog box, use the row and column counts to divide the text area. Tip

You can also choose the vertical alignment options from the Properties or Control panel.
