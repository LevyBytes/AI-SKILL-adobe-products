# Align objects with glyph bounds

Open Window > Align.

In the Align panel, choose More Options > Align to Glyph Bounds > Area Text.

Note

Depending on the text type, Point Text can also be chosen from the Align to Glyph Bounds dropdown menu.

Using the Selection tool, select both the object and the text.

From the Align Objects section in the Align panel, choose the desired alignment option.
