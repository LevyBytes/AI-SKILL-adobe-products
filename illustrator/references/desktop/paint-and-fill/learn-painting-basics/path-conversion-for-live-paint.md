# Convert objects to regular paths and create a Live Paint group

For items that cannot be converted directly into a Live Paint group, and for objects carrying complex appearance attributes, first change them into regular paths; after that, create the Live Paint group.

Select text, raster images, or objects with complex appearance attributes, then use the applicable command to convert them into regular paths:

- Text: choose Type > Create Outlines.
- Raster images: select them, then choose Object > Image Trace > Make.
- Objects with complex appearance attributes: choose Object > Expand.

Choose Object > Live Paint > Make to build a Live Paint group.
