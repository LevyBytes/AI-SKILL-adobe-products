# Expand or release a Live Paint group

Expanding a Live Group changes it into separate regular paths with fills and strokes while retaining how the painted faces and edges look. If you release a Live Paint group instead, the original objects come back with no fill and a black stroke set to 0.5 point.

Use the Selection tool to select the Live Paint group.

Choose the action that matches the result you need:

- For expansion, choose Object > Live Paint > Expand.
- For release, choose Object > Live Paint > Release.
