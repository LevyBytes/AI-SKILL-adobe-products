# Convert strokes to compound paths

Convert strokes into compound paths.

Turning a Stroke into a Compound Path makes the Stroke outline editable. For example, the Stroke can use a varied width or be divided into pieces.

Choose the object with the Selection tool from the Tools panel.

Choose Object > Path > Outline Stroke.

Note

The Compound Path that results remains grouped with the filled object.

With the outlined Stroke selected, choose Object > Compound Path > Make.
