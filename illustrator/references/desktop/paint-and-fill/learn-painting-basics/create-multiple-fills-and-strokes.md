# Create multiple fills and strokes

Create more than one Fill or Stroke on the same object.

With the Selection tool, choose one or more objects or groups.

Choose Window > Appearance.

In the Appearance panel, choose Add New Stroke or Add New Fill. Appearance panel overview

A. Add New Stroke B. Add New Fill C. Clear Appearance

Appearance panel overview Tip

To copy the selected Fill or Stroke, choose Duplicate Selected Item.

To remove the selected Fill or Stroke from the object, choose Delete Selected Item.

In the Appearance panel, set the color and other related properties for the new Fill or Stroke.
