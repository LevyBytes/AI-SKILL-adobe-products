# Modify Live Paint group components

Editing a path in a Live Paint group makes Illustrator color the changed or newly created faces and edges with the group's existing fills and strokes. If that result is not the one you need, apply the preferred colors again with the Live Paint Bucket tool.

Deleting paths or edges lets the fill spread through any face that becomes larger. For example, removing a path that splits a circle in half causes the circle to receive one of the fills that was already inside it. You can influence the outcome in some cases. Before removing a divider path in a circle, for example, move it so the fill to keep occupies more area than the fill to discard.
