# Blob Brush tool guidelines

Use the Blob Brush tool with these rules in mind:

- Paths can merge only when they sit next to each other in the stacking order.
- For Blob Brush paths to combine with existing artwork, the artwork must use the same Fill color and have no Stroke, because the Blob Brush tool produces paths with a Fill and no Stroke.
- Before drawing, apply attributes such as Effects or Transparency to the Blob Brush tool by selecting the brush and setting those attributes in the Appearance panel.
- When merging paths produced by other tools, first confirm that the current artwork has no Stroke. Next, configure the Blob Brush tool with the same Fill color, then draw a fresh path that crosses every path you intend to combine.
- If the goal is to merge new paths into the uppermost matching path the brush encounters, draw those paths with the Blob Brush tool. When a new path contacts several matching paths in one group or layer, every intersecting path is combined.
