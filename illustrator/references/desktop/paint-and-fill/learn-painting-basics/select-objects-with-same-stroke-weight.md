# Select objects with same Stroke Weight

Choose an object with the Stroke Weight you want to match.

Choose Select > Same > Stroke Weight.

Illustrator then selects every other object in the document whose Stroke Weight matches the selected object.

Note

Within a Live Paint group, Select > Same > Fill Color, Stroke Color, and Stroke Weight can be used after you select a face or edge with the Live Paint Selection tool. Other Select > Same commands are unavailable inside Live Paint groups. A single same-object selection also cannot span both inside and outside a Live Paint group at the same time.
