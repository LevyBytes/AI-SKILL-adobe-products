# Change brush options

Choose Brushes in panels. If Brushes is not visible in panels, choose Window > Brushes.

Open the Brushes panel to modify your strokes.

In the Brushes panel, double-click the brush.

Configure the brush options in the dialog box that opens, then select OK.

When the brush is already applied in the document, follow the onscreen instructions and choose one of these:

- Apply to Strokes: updates every stroke already using that brush.
- Leave Strokes: keeps current strokes as they are and uses the edits only for new strokes.
