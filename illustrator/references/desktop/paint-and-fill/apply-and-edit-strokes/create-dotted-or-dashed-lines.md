# Create dotted or dashed lines

Use the Stroke panel to make dotted or dashed lines with custom dash lengths and gaps.

Select the artwork object, then choose Stroke in panels.

Open the Stroke panel from Window > Stroke.

Turn on dash controls by selecting the Dashed Line checkbox.

For dash behavior at corners and path ends, choose one of these options:

- Preserve exact dash and gap lengths: leaves the entered dash and gap measurements alone, with no corner or path-end fitting.
- Align dashes to corners and path ends, adjusting lengths to fit: changes the pattern so dashes at corners and path ends look regular and controlled.

Enable Dashed Line to customize dash patterns and alignment on corners and path ends.

Enter dash and gap values to define the repeating dash sequence.

Note

After a dash pattern is set, Illustrator repeats the entered values automatically, so every text box does not need to be completed.
