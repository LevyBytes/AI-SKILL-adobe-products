# About brushes

Brushes in Adobe Illustrator let paths take on different styled appearances.

Illustrator provides several brush types for different effects:

- Calligraphic Brush: makes strokes centered on the path that resemble marks from a calligraphy pen. When applied with the Blob Brush tool, those strokes become filled shapes that merge with neighboring or overlapping same-color regions.
- Scatter Brush: places repeated object copies along the path; examples include a ladybug or a leaf.
- Art Brush: stretches a brush or object shape evenly along the path.
- Bristle Brush: creates strokes with the look of a natural bristle brush.
- Pattern Brush: builds repeating designs from separate tiles. Pattern brushes can use up to five tiles for sides, inner corner, outer corner, beginning, and end.

Brush strokes can be applied to paths that already exist, or the Paintbrush tool can draw paths while applying brush strokes in the same action.
