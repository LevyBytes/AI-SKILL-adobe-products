# Set radial repeat options

For radial repeats in Adobe Illustrator, this section covers the available options.

With the Selection tool, choose the repeated artwork.

Choose Object > Repeat > Options.

Use the Repeat Options dialog box for these settings:

- Number of instances : set how many repeat instances appear in the repeated artwork. The default value is 8.
- Radius : set the circle radius used to create the radial repeat.

Enable the Reverse Overlap checkbox to switch the stacking order of objects in the Radial repeat.

Select OK.
