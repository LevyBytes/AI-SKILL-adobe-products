# Symbols panel options

Review the Symbols panel options used to manage reusable artwork and customize it.

Use Window > Symbols to access the Symbols panel, which includes preset symbols and custom symbols. From there, you can add, organize, and change reusable artwork, and you can bring in symbol libraries to expand the available collection.

In the Symbols panel, manage reusable artwork by making symbols, editing them, or removing them.
