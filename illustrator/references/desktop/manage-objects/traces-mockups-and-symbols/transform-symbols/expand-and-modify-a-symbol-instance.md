# Expand and modify a symbol instance

After expanding and editing a symbol instance, you can use the Symbols panel to redefine the original symbol. Choosing Redefine Symbol makes every existing symbol instance adopt the updated definition.

Open Window > Symbols.

Choose the symbol you want in the Symbols panel and place it on the artboard.

On the artboard, choose the symbol instance, then choose Break Link to Symbol in the Symbols panel.

Edit the object on the artboard.

To redefine the parent symbol, choose the edited object, choose the original symbol in the Symbols panel, then choose Redefine Symbol from the panel menu.

To make a new symbol instead, drag the edited object into the Symbols panel, adjust the settings in the Symbol Options dialog box, then choose OK.
