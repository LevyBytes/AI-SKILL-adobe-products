# Place a symbol in the artwork

Choose a symbol in the Symbols panel, or pick one from Symbol Libraries Menu icon.

Drag the symbol onto the artboard.

To create a new symbol without showing the Symbol Options dialog, hold Alt (Windows) or Option (macOS) while dragging the object onto the New Symbol icon in the Symbols panel. Illustrator assigns the symbol a default name. In the Symbols panel, a small plus sign in the lower-right corner marks dynamic symbols.
