# Transform panel menu features

During transformations, the Transform panel menu provides controls for scaling behavior and for how objects, patterns, strokes, and symbols are handled.

| Option | Function |
| --- | --- |
| Show Options or Hide Options | Shows the scaling settings when hidden, or hides them when shown. |
| Show on Shape Creations | Displays the Transform panel automatically while new shapes are being drawn. |
| Flip Horizontally | Mirrors the object across the vertical axis, using the reference point. |
| Flip Vertically | Mirrors the object across the horizontal axis, using the reference point. |
| Scale Strokes & Effects | When resizing, also changes stroke widths and applied effects in proportion to the object. The same control appears in the Transform panel scaling settings. |
| Transform Object Only | Transforms the object while leaving its pattern fill as it was. |
| Transform Pattern Only | Transforms only the pattern fill, without changing the object itself. |
| Transform Both | Transforms the object and its pattern fill together. |
| Use Registration Point for Symbol | For symbol instances, transformations reference the defined Registration point rather than the default Reference Point. |
