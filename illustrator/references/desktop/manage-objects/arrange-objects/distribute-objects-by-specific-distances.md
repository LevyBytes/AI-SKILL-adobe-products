# Distribute objects by specific distances

Illustrator can distribute objects precisely by a specified distance.

With the Selection tool, select the objects to distribute.

Tip

Hold Shift when selecting more than one object.

Using the Selection tool again, click the object to make it the key object without holding Shift.

Choose Window > Align.

In the Align panel, choose More options > Show Options.

In the Align panel, choose one of these Distribute Spacing controls, then enter the exact object-to-object distance:

- Vertical Distribute Space: spaces objects evenly from top to bottom using the value you enter.
- Horizontal Distribute Space: spaces objects evenly from left to right using the value you enter.

Artwork objects can be aligned to a Selection, Key Object, or an Artboard.

Objects in the artwork can use Selection, Key Object, or Artboard as the alignment reference.
