# Create process color swatches

Create custom process color swatches in Adobe Illustrator to keep colors consistent across designs.

Choose Window > Color from the menu to open the Color panel.

Choose a color in the Color panel.

Pick colors in the Color panel

Pick colors in the Color panel Tip

You can also choose the color with the Color Picker, or select artwork that already uses the color.

Choose Window > Swatches to open the Swatches panel, then choose the New Swatch icon.

When the New Swatch dialog box appears, enable Global if the swatch should be global, then set any other swatch options you need.

Choose OK.
