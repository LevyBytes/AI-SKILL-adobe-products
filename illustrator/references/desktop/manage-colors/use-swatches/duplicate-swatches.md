# Duplicate swatches

Duplicate swatches when you need to reuse colors and keep design color choices consistent.

Choose Windows > Swatches.

In the Swatches panel, select one or more swatches to duplicate.

Open the Swatches panel menu and choose More > Duplicate Swatch.

Use Duplicate Swatch in Swatches panel menu to make a reusable copy of the selected color swatch.
