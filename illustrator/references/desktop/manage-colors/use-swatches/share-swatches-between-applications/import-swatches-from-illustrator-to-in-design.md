# Import Swatches from Illustrator to InDesign

Open InDesign.

Choose Window > Color > Swatches.

From the Swatches panel menu, choose Load Swatches.

Bring swatches from another application into InDesign by using Load Swatches in the Swatches panel.

Use the Swatches panel command Load Swatches when importing swatches from another application into InDesign.

In the Open a file dialog, choose the ASE file.

Select Open.
