# Import Swatches from Illustrator to Photoshop

Open Photoshop.

Choose Window > Swatches.

From the Swatches panel menu, choose Import Swatches.

Bring swatches from another application into Photoshop through Import Swatches in the Swatches panel.

Use the Swatches panel command Import Swatches to load swatches from another application into Photoshop.

In the Load dialog, choose the ASE file.

Select Open.
