# Move swatches from swatch libraries to the swatches panel

Move swatches out of swatch libraries and into the Swatches panel when you need custom Illustrator colors ready for use.

Open Windows > Swatches.

From the Swatch Libraries menu, choose the library that contains the swatches you want to transfer.

Choose one or more swatches to add, then use Add to Swatches from the swatch library's panel menu.

Use Add to Swatches in the Swatch Library panel menu when selected colors need to be placed in your Swatches panel.

The Swatch Library panel menu command Add to Swatches places the selected colors in the Swatches panel. Note

Apply the swatch to artwork in the document. Global swatches and spot-color swatches are added to the Swatches panel automatically when used.
