# About Swatches

Use swatches to organize colors, gradients, and patterns more effectively.

Named colors, tints, gradients, and patterns are swatches.

Document swatches are shown in the Swatches panel, either one by one or inside groups. The Swatches panel gives you one place to edit and manage document colors, gradients, and patterns. You can also name and save these items for quick reuse. If the selected object’s Fill or Stroke uses a color, gradient, pattern, or tint from the Swatches panel, that swatch is highlighted in the panel.

The Swatches panel also supports tint creation. A tint is a global Process Color or Spot Color whose intensity has been changed. Tints that come from the same color stay linked; editing a tint swatch’s color changes every related tint swatch and the objects using those swatches, while the tint values themselves do not change. In List view, percentages identify them.

In Illustrator, the Swatches panel includes these Swatches types:

- Process Color: combines the four-standard process inks cyan, magenta, yellow, and black. Illustrator defines new swatches as process colors by default.
- Global Process Color: updates automatically throughout the artwork after you edit it. Every spot color is global, while process colors may be global or local.
- Spot Color: uses a premixed ink in place of, or alongside, CMYK process inks.
- Gradient: creates a graduated blend between two or more colors, or between tints of either the same color or different colors. Gradient colors can be CMYK process colors, RGB colors, or a Spot color. When transparency is applied to a gradient stop, that transparency remains when the Gradient is saved as a Gradient swatch.

Note

Elliptical-gradient Aspect Ratio and Angle settings, made by modifying a Radial Gradient, are not stored with the Gradient swatch.

- Pattern: contains repeating tiled paths, compound paths, or text with solid fills or no Fill.
- None: removes the Stroke or Fill from an object. This swatch cannot be edited or removed.
- Registration: is a built‑in swatch that sends filled or stroked objects to each separation produced by a PostScript printer. Registration marks, for example, use the Registration color so press operators can align printing plates accurately. This swatch cannot be removed.

Tip

Using the Registration swatch for type can cause poor registration after separation and printing, and black ink may look muddy. Use only black ink for type to avoid that result.

- Swatch group: can hold process, spot, global process colors, patterns or gradients. Use the Swatches panel to build Swatch groups from harmonies. To add existing Swatches to a swatch group, choose the swatches, then select New Swatch Group in the Swatches panel.
