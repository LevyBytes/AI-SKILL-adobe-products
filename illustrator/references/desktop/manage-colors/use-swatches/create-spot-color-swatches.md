# Create spot-color swatches

Create spot color swatches in Adobe Illustrator when print output needs accurate color matching.

Choose Window > Color from the menu to open the Color panel.

Pick a color in the Color panel. Move the Color panel colors into the Swatches panel

Move the Color panel colors into the Swatches panel Tip

You can also choose the color with the Color Picker, or select artwork that already uses the color.

Choose Window > Swatches to open the Swatches panel, then choose the New Swatch icon.

Use Ctrl +drag (Windows) or command +drag (macOS) to move the color from the Color panel to the Swatches panel.

From the Color Type dropdown, choose Spot Color and change the settings as needed.

Choose OK
