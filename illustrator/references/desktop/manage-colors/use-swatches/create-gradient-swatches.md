# Create gradient swatches

Create and save custom gradient swatches for reuse in Adobe Illustrator.

Choose Window > Gradient to build a new gradient.

In the Gradient panel, choose the Type of gradient to apply.

To save the gradient, choose the New Swatch icon in the Swatches panel.

Note

To place a gradient in the Swatches panel, open the dropdown beside the Gradient box and choose Add to Swatches. Another method is to drag the fill shown in the Fill box, whether from the tool panel or the Color panel, into the Swatches panel.

In the New Swatch dialog, enter a value in the Swatch Name field and set the remaining options as needed.

Type a name to create a new color swatch.

Choose OK.
