# Edit swatch libraries

Edit swatch libraries in Illustrator.

Choose File > Open, then locate and open the swatch library file to edit.

Choose Window > Swatches.

Use the Swatches panel to add, remove, or change colors.

Choose File > Save to update the swatch library.

From the Swatches panel, use Swatch Libraries menu to make the edited swatch library available in any Illustrator project.
