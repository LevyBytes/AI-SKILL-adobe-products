# Delete swatch groups

Remove swatch groups from the Swatches panel in Illustrator when they are no longer needed.

Select the artwork with the Selection tool.

Open Window > Swatches.

In the Swatches panel, choose the swatch group to delete.

In the Swatches panel, choose Edit or Apply Swatch Group.

In the Recolor Artwork dialog box, choose a swatch group from the Swatch Groups list. Then choose Delete Swatch Group.

In the Recolor Artwork dialog box, open the Edit tab when you need Add New Color or Remove Color.

Use the Edit tab in the Recolor Artwork dialog box to reach Add New Color or Remove Color.

Choose OK.
