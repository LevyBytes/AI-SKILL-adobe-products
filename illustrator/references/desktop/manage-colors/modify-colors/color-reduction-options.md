# Color reduction options

Use Color Reduction Options in the Recolor Artwork dialog box when you need a simpler color set in your artwork.

Adobe Illustrator can simplify selected artwork by limiting its colors through Color Reduction Options. Open Edit > Edit Colors > Recolor Artwork, then choose Advanced Options to reach the Recolor Artwork dialog box, where custom controls let you reduce the colors in the selection.
