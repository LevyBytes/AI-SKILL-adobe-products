# Edit an individual color in color groups

Edit one color inside a color group when you need a custom color palette for a smoother workflow.

Colors are linked by default when a color group is created from a harmony rule. In a linked color group, changing one color updates the other colors according to that harmony rule. To change one color without affecting the rest, detach the color markers from the harmony rule.

Open Window > Color Guide.

In the Color Guide panel, choose Edit Colors or Edit or Apply Colors, depending on whether artwork is currently selected.

Choose the color group to edit, then choose Edit in the Recolor Artwork dialog box. To work on color groups, open the Edit tab in the Recolor Artwork dialog box.

For color-group editing, use the Edit tab in the Recolor Artwork dialog box.

Choose Link Unlink harmony colors.

In color wheel view or color bar view, use any of these actions:

- Drag the color handle you want to edit while using the color wheel to set a new color.
- Select the color bar or color handle you want to change, then edit the color values manually.
- Open the Color Picker dialog box by double-clicking the color wheel. You can also right-click the color bar or handle and choose the Color Picker option to open that dialog box. In the Color Picker, choose a new color.
- To choose a new shade, right-click a color handle or color bar, then choose Select Shade.

Choose the Link Harmony colors icon to link the colors again, so the markers once more follow the newly defined harmony rule.
