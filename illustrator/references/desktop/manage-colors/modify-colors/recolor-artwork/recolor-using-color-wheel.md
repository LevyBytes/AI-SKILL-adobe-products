# Recolor using color wheel

On the color wheel, color stops stand for every color found in the selected artwork. Adjust those stops to refine the artwork's colors.

Select the artwork on the canvas.

Choose Edit > Edit Colors > Recolor Artwork. The Recolor dialog opens.

Use one of these methods to change a color stop:

- Move the color stop by dragging it.
- Open Color Picker by double-clicking the color stop, then choose a color.
- Right-click the color stop, choose Select Shade, then choose a shade.

Make a color the base color by right-clicking its color stop and choosing Set as Base Color.

Remove a color by right-clicking its color stop and choosing Remove Color.

Add a color stop for another color by right-clicking the area of the color wheel that contains that color, then choosing Add New Color.

As needed, decide whether to keep the color harmony connected:

- Select . to break the harmony so color stops can move individually.
- Select . to retain the harmony so color stops move together.
