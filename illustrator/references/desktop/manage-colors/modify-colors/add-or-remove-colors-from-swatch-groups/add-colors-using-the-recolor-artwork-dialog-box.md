# Add colors using the Recolor Artwork dialog box

Select the artwork with the Selection tool.

Open Edit > Edit Colors > Recolor Artwork. In the Recolor panel, choose Advanced Options to display the Recolor Artwork dialog box.

In the Recolor Artwork dialog box, open the Edit tab.

Right-click the location on the color wheel where the new color should appear, then choose Add New Color.

Note

As another method, choose the Add Color tool, then add the color by clicking any location on the color wheel.

In the Recolor Artwork dialog box, choose Generative Recolor to build new color schemes for the artwork.

Use Generative Recolor in the Recolor Artwork dialog box when you want new color schemes for the artwork.

Choose OK.
