Colors can be assigned in these ways:

| Option | Function |
| --- | --- |
| Swatch Groups | Lists predefined and custom related-color sets available for applying to artwork. |
| Harmony Rules | Builds coordinated color schemes from the selected base color. |
| Reset | Returns the artwork to its original colors. |
| Set current color as the base color | Makes the current color the base for edits. |
| Save changes to swatch group | Stores recolor edits in the selected swatch group. |
| New Swatch Group | Builds a new swatch group from colors in the recolored artwork. |
| Delete Swatch Group | Deletes the selected swatch group from the Swatches panel. |
| Preset | Shows recolor presets such as Custom, Color Library, Single Color, Two Color, Three Color, and Color Harmony. |
| Colors | Controls how many colors appear for the artwork. |
| Current Colors | Lists the artwork's original colors that can be reassigned. |
| New | Shows the replacement colors assigned to the current colors. |
| Merge colors into a row | Places selected Current Colors column colors together in one row. |
| Separate colors into different rows | Breaks a merged row back out into separate colors. |
| Exclude selected colors so they will not be recolored | Keeps selected colors out of the recoloring process. |
| New Row | Adds an empty mapping row for pairing an original color with a replacement by hand. |
| Change color order randomly | Shuffles the wheel's color order. |
| Change saturation and brightness randomnly | Randomizes saturation and brightness values for the colors. |
| Click on colors above to find them in the artwork | Locates in the artwork the Current Colors selection clicked above. |
| Recolor Art | Shows a preview and applies recoloring to the selected artwork according to the active color group and the Current Colors/New assignments. |
| Generative Recolor | Applies generative AI to recolor artwork from a text prompt. |
