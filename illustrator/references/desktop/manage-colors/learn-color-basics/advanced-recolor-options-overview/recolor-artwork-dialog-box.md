# Recolor Artwork dialog box

To open the Recolor Artwork dialog box, select the artwork, choose Edit > Edit Colors > Recolor Artwork, and then choose Advanced Options.

Note

The Recolor Artwork dialog box is also available by choosing Edit or Apply Colors from Window > Color Guide. When no artwork is selected, Illustrator opens the Edit Colors dialog box instead, with the Assign tab greyed out.
