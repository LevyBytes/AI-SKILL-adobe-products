# Change the inverse or complement of a single color

Choose the object’s color with the Direct Selection tool.

Select Window > Color.

From the Color panel menu, choose one option:

- Invert: changes every component to the opposite side of the scale. An R value of 100 becomes 155 (255 – 100 = 155).
- Complement: starts with the sum of the selected color’s highest and lowest RGB values, then derives a new value for each component. With RGB values (102, 153, 51), the total is 204 (153 + 51). The resulting RGB values are Red: 204 – 102 = 102, Green: 204 – 153 = 51, and Blue: 204 – 51 = 153

Choose Invert or Complement to apply the change.
