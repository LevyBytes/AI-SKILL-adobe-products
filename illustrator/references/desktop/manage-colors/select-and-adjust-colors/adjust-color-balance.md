# Adjust color balance

Refine an artwork’s look and feel by changing its color balance.

With the Selection tool, choose the object whose color needs adjustment.

Open Edit > Edit Colors > Adjust Color Balance.

In the Adjust Colors dialog box, enable the Fill and Stroke checkboxes under Adjust Options.

In the Adjust Colors dialog box, make the needed adjustments:

- When any Global Process Color or Spot Color is selected, change color intensity with the Tint slider. Selected non-global process colors stay unchanged.
- In CMYK color mode, when non-global process colors are selected, use the sliders to change Cyan, Magenta, Yellow, and Black percentages.
- In RGB color mode, when non-global process colors are selected, use the sliders to change Red, Green, and Blue percentages.
- To convert the selected colors to Grayscale mode, choose Grayscale from the Color Mode dropdown list and enable the Convert checkbox. Then use the slider to change the Black percentage.

Note

When selected Global Process Color or Spot Color items need conversion to non-global process colors, choose CMYK or RGB from the Color Mode list according to the document Color Mode, then enable the Convert checkbox. After that, adjust the colors with the sliders.

Use the Adjust Colors dialog box to choose the Color Mode you want.

Select OK.
