# Select colors using the Color panel

Color panel selections can be applied to artwork for consistent and accurate design colors.

Select the object, then choose Window > Color.

In the Color panel, open the Color panel menu icon, then use these choices:

- Choose Show Options.
- Choose Grayscale, RGB, HSB, CMYK, Web Safe RGB, Invert, or Complement as the color mode or command.

Note

- This choice affects only the Color panel display; the document's color mode stays unchanged.
- Illustrator reopens with the color model used most recently.

Apply the color to the object by dragging the slider, entering values in the color value input fields, or choosing from the Color Spectrum. Hold Shift while dragging a color slider to change tint or intensity while keeping a similar color; HSB sliders do not support this.

Use the Color panel's RGB sliders, Color Spectrum bar, or color value input fields to adjust colors.

Colors can also be tuned in the Color panel through RGB sliders, the Color Spectrum bar, or color value input fields.
