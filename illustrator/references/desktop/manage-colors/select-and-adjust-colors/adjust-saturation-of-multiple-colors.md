# Adjust saturation of multiple colors

Adjust saturation across multiple colors to make artwork more consistent.

Use the Selection tool to choose the objects whose colors need adjustment.

Select Edit > Edit Colors > Saturate.

Drag the Intensity slider between –100% and 100% to lower or raise the color percentage.

Enable Preview to inspect the live changes applied to the artwork.

Enable Preview to inspect live artwork changes. Note

Enter a percentage value when you need exact control over the color or spot-color tint.
