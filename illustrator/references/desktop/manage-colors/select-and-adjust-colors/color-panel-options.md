# Color panel options

Use the Color panel to apply, revise, or customize artwork colors.

Open the Color panel with Window > Color. From the Color panel menu icon, you can show or hide Color panel options, switch the displayed color model among Grayscale, RGB, HSB, or CMYK, invert the current color, apply the complement, or make new swatches.

Fill and Stroke colors can be applied and adjusted on artwork.

A. Default Fill and Stroke B. Swap Fill and Stroke C. Panel menu D. Color value input field E. Hexadecimal color value F. Click to copy value G. Color slider H. Color spectrum bar I. Black or White color J. None K. In Web Color L. Out of Web Color Warning M. Stroke color N. Fill color

Artwork Fill and Stroke colors can be changed from this panel.

| Options | Functions |
| --- | --- |
| Default Fill and Stroke | Returns the object to white fill with black stroke. Use D for this option. |
| Swap Fill and Stroke | Exchanges the object's fill color with its stroke color. Use Shift + X for this option. |
| Color value input field | Provides exact color values for precise selection and control. |
| Hexadecimal color value | Shows the final color value produced from the adjusted color components. |
| Click to copy value | Copies the color value for reuse. |
| Color slider | Changes individual component values for the chosen color model. Drag the sliders to combine custom colors. |
| Color Spectrum bar | Shows a color gradient for the chosen color model. Pick a spectrum color to apply it to artwork. |
| None | Clears the active Fill or Stroke. |
| In Web Color | Provides a correction control when a color is not web safe. Use it to move to the closest web-safe color. |
| Out of Web Color Warning | Warns that the current color is not web safe, then automatically adjusts to the closest web-safe color. |
| Stroke | Sets or updates the artwork outline color. |
| Fill | Sets or updates the artwork interior color. Press X to toggle between Fill and Stroke. |
