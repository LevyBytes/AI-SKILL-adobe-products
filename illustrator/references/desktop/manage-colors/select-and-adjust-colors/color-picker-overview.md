# Color Picker overview

Create, manage, and apply Fill and Stroke colors from the Color Picker dialog box.

An object's fill or stroke color can be chosen in several ways from Color Picker. Open the Color Picker dialog box by double-clicking the Fill and Stroke tool.

Color Picker dialog box options are used to apply colors to artwork.

A. Select Color column B. Circular color marker C. Color Picker D. Color spectrum bar E. HSB color values F. RGB color values G. CMYK color values H. Color Swatches

Apply artwork colors through the options in the Color Picker dialog box.
