# Blend colors

In Adobe Illustrator, Blend commands create smooth color transitions between three or more filled objects, using either stacking order or position.

Blend inserts intermediate colors between the selected objects. Use it for smooth, gradient-like color effects across several shapes. Blends work only on filled objects, not strokes or shapes without paint.

Choose the Selection tool from the toolbar.

Select three or more filled objects with Shift-click (Windows) or command-click (macOS).

Pick one of these actions depending on the blend direction you need:

- To blend gradually between the frontmost and backmost filled artworks through the intermediate artworks, select Edit > Edit Colors > Blend Front to Back.
- To blend gradually between the leftmost and rightmost filled artworks through the intermediate artworks, select Edit > Edit Colors > Blend Horizontally.
- To blend gradually between the topmost and bottommost filled artworks through the intermediate artworks, choose Edit > Edit Colors > Blend Vertically command.
