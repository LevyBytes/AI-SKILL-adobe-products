# Shift a color to a web-safe color

Browsers on all platforms share a 216-color web-safe palette. If the selected color falls outside that set, Illustrator shows an alert cube in the Color Picker, Color panel, Recolor Artwork dialog box, or Edit Colors.

Select Window > Color.

Choose individual colors in the artwork and check whether they are web safe.

Select Out of Web Color Warning to move the color to the closest web-safe match, shown in a small box next to the cube.
