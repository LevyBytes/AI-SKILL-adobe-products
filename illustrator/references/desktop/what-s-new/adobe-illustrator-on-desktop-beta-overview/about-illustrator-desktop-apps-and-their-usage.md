# About Illustrator desktop apps and their usage

Adobe provides multiple app variations for creating artwork, testing early features that help us fix issues, and sharing feedback that influences future Adobe products. The beta app can run beside the public release app at any time.

Adobe provides beta-version access so you can try different apps and features before they reach general availability.

More answers are available on Creative Cloud beta apps.

For Illustrator, choose from these offerings depending on your needs.

- Illustrator public beta—Anyone with a subscription to an Adobe Creative Cloud app can access the public beta through the Illustrator (Beta) desktop app. Download Illustrator (Beta) from the Creative Cloud app.
- Illustrator private beta—Some beta programs are private and typically require an access application, followed by Adobe approval or an Adobe invitation to participate. This is available only to NDA-tied users.

- Illustrator Prerelease — Similar to the private beta app, the Illustrator prerelease app is limited to NDA users who join the invite-only pre-release program through Illustrator's prerelease installation. Complete the screening survey so you can receive a pre-release program invitation.
- Illustrator — This desktop app provides polished features and consistent stability for general public availability. Use it to create illustrations and artwork for commercial purposes. To get started with Illustrator, sign in to Creative Cloud and select Download or Install.

Note

To improve products and ensure the best experience, Adobe may collect some information about your devices, documents, and interaction patterns.
