# Use a graphic

Use one of these methods:

- Open the context menu for a graphic in the Libraries panel, then choose the Place Copy option.
- Open the context menu for a graphic in the Libraries panel, then choose the Place Linked option.
- With an Illustrator document active, drag an asset out of the Libraries panel and place it on the artboard with the Placegun tool. You can load several items into the Placegun tool and add them to the layout.
