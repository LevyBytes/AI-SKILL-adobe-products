# Use a text asset in a document

Use one of these methods:

- Open the context menu for a text asset in the Libraries panel, then choose Place Copy.
- To insert text without applying its styles, open the text asset context menu in the Libraries panel. Then choose Place Without Styles.
- Put the insertion point inside the text. In the Libraries panel, open the text asset context menu and choose Place Inline.
  - Add the text asset to a text object by clicking that object.
  - Place the text asset in its own text frame by clicking anywhere on the canvas.

Note

By default, Illustrator imports the text asset with its character/paragraph styles and attributes intact. For plain text without those associated styles, open the text asset context menu in the Libraries panel and choose Place Without Styles.
