# What are linked assets?

In Illustrator CC 2014 and earlier, a graphic asset stopped being connected to its library source after you dragged it from the Libraries panel into an Illustrator document. Later edits to the original item in the library therefore did not update the document copy. Illustrator treated library graphics placed this way as 'unlinked assets'.

Beginning with Illustrator CC 2015, the linked assets feature makes a library item placed into a document a 'linked asset'. That linking behavior is the default. Whenever the asset in the Library changes, every linked copy used in Illustrator document(s) reflects that change.

To place graphics from a library as an unlinked asset, hold Alt/Option while dragging the item out of the Libraries panel.

Note

Assets used in Illustrator CC 2014 stay unlinked assets. To apply linking to one of those items, place it again by dragging it out of the Libraries panel in Illustrator CC 2015.
