# Rearrange artboards

Rearrange artboards for smoother review and presentation by organizing designs.

Before you begin

Rearrange All Artboards requires a document with at least two artboards.

Choose Window > Artboards.

In the Artboards panel, choose Rearrange All Artboards.

In the Rearrange All Artboards dialog box, set these options as needed:

- Layout: chooses the artboard arrangement style. Available choices include Grid by Row, Grid by Column, Arrange by Row, and Arrange by Column.
- Layout order: sets the direction used to arrange artboards, such as Right-to-Left or Left-to-Right.
- Columns: sets how many columns are used in the artboard arrangement.
- Spacing: controls the amount of space placed between artboards.

In the Rearrange All Artboards dialog box, enable Move Artwork with Artboard when artwork should move with its artboard.

Use Move Artwork with Artboard in the Rearrange All Artboards dialog box to keep each artboard and its artwork moving together.

Choose OK.
