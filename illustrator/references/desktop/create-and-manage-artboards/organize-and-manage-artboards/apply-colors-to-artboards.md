# Apply colors to artboards

Set artboard background colors so individual artboards are easier to distinguish on the canvas.

Background colors can make complicated documents, especially documents with several artboards, easier to organize. Apply a solid color to an artboard when you need to preview work such as dark UIs, social media templates, or branded layouts against a particular background.

Using the toolbar's Artboard tool, select an artboard, or press Shift + O.

From the Properties panel, open Artboards > Fill, then select Artboard Color Swatch so the Color Picker appears.

Adjust the artboard background color to review the design for readability and contrast.

Use the changed artboard background color as another preview check for design contrast and legibility.

Pick a color or swatch, then select OK to apply it to the artboard.

Note

Each artboard can use a different background color.
