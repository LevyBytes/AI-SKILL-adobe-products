# Resize artboards

Use these controls when an artboard needs a different size.

Choose the artboard to resize, then drag its bounding box.

Note

Another route is the Artboard Options dialog box, where Width and Height values define the new dimensions.

To choose a reference point, open Artboards from panels and choose Artboard Options.

In the Reference Point grid, pick one of the nine reference points, then enter X and Y values.

Tip

Artboards, Properties, Control panel, and Artboard Options dialog box can resize artboards, set reference points, or rename the artboard.
