# Delete artboards

Remove unneeded artboards from an Illustrator document when you want the workspace to stay organized.

Open the Artboards panel with Window > Artboards.

Choose one or more artboards for deletion using any of these methods:

- In the Artboards panel, choose an artboard name when only one artboard should be selected.
- To select an entire range, Shift-click the first artboard and the last artboard.
- Use Ctrl + A (Windows) or Command + A (macOS) when every artboard should be selected.
- For nonsequential selections, hold Ctrl (Windows) or Command (macOS) while choosing individual artboards.

Choose the Delete Artboard icon.

Tip

Deletion is also available from the Properties or Control panel.

To remove every empty artboard in one action, use the Artboards panel menu icon in the Artboards panel, then choose Delete Empty Artboards.

Use Delete Empty Artboards from the more options menu in the Artboards panel to clear empty artboards.

Use the more options menu in the Artboards panel and choose Delete Empty Artboards when empty artboards should be removed.

Note

At least one artboard must remain in a document. If deletion would remove all artboards, Illustrator keeps artboard number 1.
