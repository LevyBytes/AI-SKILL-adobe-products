# JPEG export options

For JPEG artwork export, these options are available:

JPEG export options

JPEG export options

| Option | Description |
| --- | --- |
| Color Model | Sets the color model for the JPEG file. |
| Quality | Controls JPEG file quality and size. |
| Compression Method | - Select Baseline (Standard) for a format most web browsers recognize.<br>- Select Baseline Optimized to improve color handling while trimming file size slightly.<br>- Select Progressive to show increasingly detailed scans as the image downloads; you specify how many scans are used.<br><br>Not every web browser supports Baseline Optimized and Progressive JPEG images. |
| Resolution | Sets the resolution for the JPEG file. |
| Anti-aliasing | Smooths jagged artwork edges through supersampling. Turning this option off helps keep line-art edges hard after rasterization. |
| Imagemap | Creates image-map code. Select Client-side (.html) or Server-side (.map) to choose the generated file type. |
| Embed ICC Profiles | Stores ICC profiles inside the JPEG file. |

Note

Each time a file is saved as JPEG, artifacts such as wave-like patterns or blocky banding areas may be introduced. Save JPEG output from the original image rather than from a JPEG that was saved earlier.
