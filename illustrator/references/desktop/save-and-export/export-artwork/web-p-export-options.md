# WebP export options

For webp file export, these options are available:

WebP export options

WebP export options

| Option | Description |
| --- | --- |
| Lossless | Select this when all image details must be preserved. File size may increase. |
| Lossy | Select this to reduce file size, with some image detail lost. |
| Quality | With Lossy compression, use the Quality slider to set the trade-off between details and file size. Higher quality keeps more details and produces larger files. |
| Resolution | Sets the resolution of the rasterized image. |
| Anti-aliasing | Smooths jagged artwork edges through supersampling. Turning this option off helps keep line-art edges hard after rasterization. |
| Background Color | Sets the fill color used for transparent areas. |
| Embed ICC Profiles | Adds ICC profile information for color management. |
