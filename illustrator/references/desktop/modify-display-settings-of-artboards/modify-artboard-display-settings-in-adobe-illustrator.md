# Modify artboard display settings in Adobe Illustrator.

From the Tools panel, choose the Artboard tool.

Open the settings for the target artboard by double-clicking it.

In the Artboard Options dialog box, turn these Display settings on or off as needed:

- Show Center Mark: shows a point at the artboard center to help with object positioning.
- Show Cross Hairs: shows cross lines that run from each side of the artboard through the center.
- Show Video Safe Areas: shows guides for identifying the viewable area in video.

Set Video Ruler Pixel Aspect Ratio from the Artboard Options dialog box.

The Artboard Options dialog box also controls Video Ruler Pixel Aspect Ratio.

Choose OK.
