# Find and use templates from Adobe Stock website

In the New Document dialog box, enter the template name in the Find more templates on Adobe Stock field.

Browse the available template collection on the Adobe Stock website by selecting Go.

Enter the template name in the Find more templates on Adobe Stock field.

Select the image, then choose Download to license and download the template, or choose Buy to purchase and license it. The template is saved automatically in your default library or Adobe Stock library.

Use these steps to open the template in Illustrator:

- Select Window > Libraries.
- In the Libraries panel, select your default library name or Adobe Stock to view licensed templates.
- Right-click the template and select Open new document to begin working with it.
