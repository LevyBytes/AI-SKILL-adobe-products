# Move paths from Photoshop to Illustrator

Move paths from Photoshop into Illustrator.

In Adobe Photoshop, select the paths you want to transfer with the Path Selection tool.

Note

Any path or path segment shown in the Paths panel can be selected, including shape vector masks, work paths, and saved paths. See the Path Selection tool guidance for more about selecting and moving paths.

Use copy and paste commands to send the path to Illustrator.

In the Paste Options dialog box, choose whether the path should be pasted as a compound shape or as a compound path. Select Compound Path for transparent cutouts inside shapes, or select Compound Shape to combine objects in an editable, non-destructive form.

Tip

In Photoshop, use File > Export > Paths to Illustrator when you need every path, without pixels, from a Photoshop document; then open the resulting file in Illustrator.
