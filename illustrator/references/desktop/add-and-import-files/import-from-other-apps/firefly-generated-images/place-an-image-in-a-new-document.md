# Place an image in a new document

From the homescreen's left pane, select Generation history.

Illustrator can work with images generated on the Adobe Firefly website without leaving the app.

Select Favorites if you need to see the Firefly images you marked as favorites, then choose the image for further editing.

Note

Generation history lists only raster images created on the Firefly website, and Illustrator can place them only as embedded files.
