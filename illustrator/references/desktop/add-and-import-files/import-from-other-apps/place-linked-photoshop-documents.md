# Place linked Photoshop documents

Place linked Photoshop documents in Illustrator.

On the Adobe Illustrator homepage, select New file > any artboard > select Create.

Select File > Place. A dialog opens for browsing files on your computer or in cloud documents.

Select Open Cloud Document. Then select Place to bring the Photoshop file onto the Illustrator artboard.

Select Place to bring the Photoshop file onto the Illustrator artboard.

Choose your PSD cloud document, then select Place.

Click anywhere on the canvas to place the Photoshop document.

Note

In the Properties panel, select Linked File to review information about the linked file.
