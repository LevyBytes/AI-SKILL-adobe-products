# Data sets

Column, bar, line, scatter, pie, radar, and area graph types each map data sets and labels in their own way. To reach the choices, use the Column Graph tool and pick a graph type.

Choose a graph type so Illustrator builds the graph from your data.

Pick the graph type that matches how your data should be drawn.

| Graph type | Data representation | Values |
| --- | --- | --- |
| Column Graph | The value determines column height. | Values must all be positive or all be negative. Negative entries draw as inverted columns. |
| Stacked Column Graph | Column height carries the value, and each data set appears as a stacked segment. | Use only positive values together or only negative values together. |
| Bar Graph | Value is shown by bar length. | Use either all positive values or all negative values. Negative bars extend to the left. |
| Stacked Bar Graph | Bar length carries the values, and stacked segments correspond to each data set. | Use values that are all positive or all negative. |
| Line Graph | Each data column becomes its own line. | Use either positive values only or negative values only. |
| Area Graph | Each data row becomes one filled area. | Keep the values all positive or all negative. |
| Scatter Graph | Numerical values appear on both axes. Data from the first column supplies the Y axis, and data from the second column supplies the X axis. | Use positive values only or negative values only. |
| Pie Graph | Each row produces a pie graph sized by that row's total. A single row makes one pie; additional rows make additional pies. | Use values that are all positive or all negative. Category labels supply graph names. |
| Radar Graph | Each axis is a variable. Illustrator plots values along the axes and connects them into a web. | Use values that are all positive or all negative. |
