# Screen readers

Most non-text Illustrator elements do not provide correct text alternatives for screen readers, such as icons that visually show tool-option state and status. On macOS, you can use VoiceOver; on Windows, you can use JAWS Client or NVDA as the screen reader.

Screen readers support these items:

- Items on the Home screen.
- Toolbar, status bar, Properties panel, menu items, dialog boxes, and document names.
  Other panels have partial support.
