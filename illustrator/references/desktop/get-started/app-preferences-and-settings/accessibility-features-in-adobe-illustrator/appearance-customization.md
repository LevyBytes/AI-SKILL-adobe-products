# Appearance customization

You can change the canvas appearance and several UI elements.

To customize the user interface, select Illustrator > Settings > User Interface (macOS) or Edit > Preferences > User Interface (Windows):

For widget size and style, select Illustrator > Settings > Selection & Anchor Display (macOS) or Edit > Preferences > Selection & Anchor Display (Windows):

For black appearance, select Illustrator > Settings > Appearance of Black (macOS) or Edit > Preferences > Appearance of Black (Windows):
