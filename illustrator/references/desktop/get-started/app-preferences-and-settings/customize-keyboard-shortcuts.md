# Customize keyboard shortcuts

Set up custom shortcuts for text formatting options you use often.

Select Edit > Keyboard Shortcuts to open the Keyboard Shortcuts dialog.

Select Menu Commands from the dropdown above the shortcut list, then select Other Text.

Find the text formatting option you want to customize.

In the Shortcut and Symbol column, press the key combination you want to assign to the menu commands.

Select OK to save your changes.

Note

The custom keyboard shortcut you create should be unique and include a modifier key, such as Ctrl or Command.
