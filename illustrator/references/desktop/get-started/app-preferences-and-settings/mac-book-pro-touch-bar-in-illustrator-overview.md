# MacBook Pro Touch Bar in Illustrator overview

Get familiar with the MacBook Pro Touch Bar so Illustrator tools and controls are easier to access.

Illustrator supports Touch Bar, the multitouch display along the top of the new MacBook Pro keyboard. Touch Bar exposes Illustrator features and controls that match the task currently on the main screen, and it supports familiar gestures including select, drag, and slide.

Note

For more about Touch Bar fundamentals, see this Apple documentation page.
