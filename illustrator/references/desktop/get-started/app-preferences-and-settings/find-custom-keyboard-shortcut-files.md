# Find custom keyboard shortcut files

Learn how to find saved custom keyboard shortcut files in Adobe Illustrator. These files can be used to back up, transfer, or delete shortcuts.

Open the folder where keyboard shortcut files are stored:

- macOS: ~/Library/Preferences/Adobe Illustrator &lt;version&gt; Settings/&lt;locale&gt;/&lt;shortcut filename.kys&gt;
- Windows: C:\Users&lt;username&gt;\AppData\Roaming\Adobe\Adobe Illustrator &lt;version&gt; Settings&lt;locale&gt;\x64&lt;shortcut filename.kys&gt;

Find the file with the .kys extension. This is your custom shortcut file.

Copy, rename, or move this file to back up or share your shortcut set.
