# Set app preferences

Learn how to customize and save Adobe Illustrator app settings, including options for display, file saving, and performance.

Launch Illustrator.

In the Illustrator main menu, choose:

- macOS: Illustrator > Preferences > [preference category]
- Windows: Edit > Preferences > [preference category]

You can also select Preferences in the Control panel.

In the Preferences dialog box, choose a category and adjust settings as needed. You can move among multiple categories before saving.

Select OK to save changes.

To reset all preferences, select General > Reset Preferences > OK.
