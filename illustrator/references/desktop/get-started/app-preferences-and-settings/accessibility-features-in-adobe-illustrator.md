# Accessibility features in Adobe Illustrator

Learn about native accessibility-friendly Illustrator features and support for assistive technologies, including screen magnifiers and screen readers.

Application accessibility covers features that make an app easier to use for people with visual, auditory, speech, motor, cognitive, and mobility disabilities. Illustrator includes some native accessibility-friendly capabilities.

Illustrator is not accessibility-friendly for people with full vision loss. It provides partial support for people with limited vision.
