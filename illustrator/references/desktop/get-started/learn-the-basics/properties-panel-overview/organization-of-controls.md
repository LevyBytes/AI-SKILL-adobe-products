# Organization of controls

The Properties panel adapts to the current selection or active tool and shows two main control types:

Default controls: If no object is selected, the Properties panel shows document-level controls such as artboard settings, layout tools, and preferences.

Selection-based controls: Selecting an object updates the Properties panel with controls specific to that selection.

- Image object: controls for Crop, mask, embed or unembed, and image trace
- Text object: settings for Font, size, color, alignment, and paragraphs
- Multiple objects: properties shared by the selection that can be edited
- Artboard: settings for Size, orientation, and background color

Use the Properties panel to see contextual controls for the selected object, such as a rectangle.
