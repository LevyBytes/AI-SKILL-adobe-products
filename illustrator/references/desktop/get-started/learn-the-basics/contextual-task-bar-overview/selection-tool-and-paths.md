# Selection tool and paths

When a path is selected with the Selection tool, the Contextual Task Bar offers several editing options. Use Gen Shape Fill to fill the selection with vector graphics, and use Fill and Stroke to change colors.

Additional options appear based on the selected path type:

| Path type | Options |
| --- | --- |
| Open path | Use Join Path to connect the path ends, and Edit Path to switch to the Direct Selection tool for needed edits. |
| Shape (closed path) | Use Edit Path for needed edits, and Lock Object to avoid accidental changes. For a basic shape made with tools such as the Rectangle tool and the Star tool, property adjustment appears instead of Lock Object. |
| Multiple paths and shapes | Use Group to treat them as one shape, and Align to arrange them in different ways. If selected shapes use different colors, Recolor also appears for refining the color scheme. |
| Grouped paths and shapes | Use Ungroup to separate them, Isolate group to edit in isolation mode, and Recolor object to recolor them. |
