# Text

After text is added to the canvas with any Type tool, the Contextual Task Bar shows formatting options including Set the font family, Font Style, Set the Font size, and Fill.

Selecting text with the Selection tool shows additional options based on text type:

| Text type | Options |
| --- | --- |
| Point text | Use Area type to convert point text into area text. |
| Area text | Use Point type to convert area text into point text. |
| Text on a path | Use Type On Path to add an effect and rearrange the text. |

Use Outline the text so the text can be edited like other vector shapes.

Note

Selecting the Touch type tool hides the Contextual Task Bar so the tool's onscreen widgets are available.
