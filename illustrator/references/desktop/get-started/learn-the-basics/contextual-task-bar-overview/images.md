# Images

When an image is selected with the Selection tool, the Contextual Task Bar provides options for both vector and raster workflows. Image Trace helps vectorize the image. Retype lets you edit text inside the image with suggested fonts. Use Crop Image to remove unwanted image areas.

Different options appear for linked images and embedded images:

| Image type | Options |
| --- | --- |
| Linked image | Use Embed Image to disconnect from the source file, Relink to repair missing links, and Edit the image in Photoshop for advanced editing. |
| Embedded image | Use Relink to connect back to the source file. |

Edit text and an image with the Contextual Task Bar.
