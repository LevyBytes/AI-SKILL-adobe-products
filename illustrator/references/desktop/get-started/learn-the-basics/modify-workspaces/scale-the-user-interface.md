# Scale the user interface

Illustrator scales its user interface automatically based on screen resolution. With fresh preferences, Illustrator detects display settings and optimizes the interface scale for viewing.

Go to Edit > Settings > User Interface (Win) or Illustrator > Settings > User Interface (macOS).

Use the UI Scaling slider to increase or decrease UI scaling based on screen resolution.

Review the scaled UI preview shown next to the slider.

Review the scaled UI preview shown next to the slider. Tip

The number of stops in the slider depends on screen resolution. Higher-resolution screens show more stops.

When the scale factor is set to the fifth stop or higher, Illustrator scales annotations.

Select Scale Cursor Proportionately so cursor icons scale with the UI.

Relaunch Illustrator to apply updated settings. If you skip relaunching now, the changes apply the next time the application opens.
