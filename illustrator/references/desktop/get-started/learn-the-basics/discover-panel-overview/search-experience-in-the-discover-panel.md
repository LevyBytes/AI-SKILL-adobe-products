# Search experience in the Discover panel

Use the Discover panel search bar to reach the full collection of tools, in-app tutorials, and skill-building articles. Search includes auto-complete suggestions for suggested content, tool shortcuts, and quick links. Based on search queries, the Discover panel surfaces tools and menu items. Recommended content on the search results page is grouped into clear categories. Selecting a search result shows a floating blue coach mark that helps locate the tools or menu items.
