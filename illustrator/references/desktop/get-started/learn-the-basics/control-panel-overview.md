# Control panel overview

Learn about the Control panel and how it helps you edit artwork quickly.

The Control panel shows editing options for the selected tool and object, so specific panels do not have to be opened. By default, it is docked below the Application Bar on macOS or below the menu bar on Windows.

Use the Control panel to speed up regular tasks.
