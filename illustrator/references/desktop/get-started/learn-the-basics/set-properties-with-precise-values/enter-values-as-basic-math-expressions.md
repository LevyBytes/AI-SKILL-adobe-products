# Enter values as basic math expressions

On the canvas, select the object to modify.

In the value field for the panel or dialog box, choose one of these approaches:

- To replace the entire current value with a math expression, select the whole value.
- To include the current value in your math expression, place the cursor before or after it.

Enter a simple math expression with +, -, \*, / or %. For example:

- Typing 50+10 gives 60
- Typing 100\*0.5 gives 50
- Typing 3cm\*50% gives 1.50 cm
- Typing 50pt+25% gives 62.5 pt

Press Enter to calculate and apply the value.
