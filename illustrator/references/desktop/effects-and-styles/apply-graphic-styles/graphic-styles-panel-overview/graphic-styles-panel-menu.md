# Graphic Styles panel menu

Open the Graphic Styles panel menu for controls such as sorting, merging, and preview display choices.

Use this menu to work with style libraries, switch preview formats, and gather unused styles for cleanup.

| Option | Function |
| --- | --- |
| New Graphic Style | Builds a style from the selected object's current appearance. |
| Duplicate Graphic Style | Copies the selected style into both the panel and the artwork. |
| Merge Graphic Styles | Joins multiple selected graphic styles from the panel. |
| Delete Graphic Style | Removes the selected graphic style from the panel. Objects that already use it keep the appearance, but the style connection is removed. |
| Break Link to Graphic Style | Separates the selected object from the style stored in the panel. The object can then be edited independently. |
| Select All Unused | Highlights every style in the panel that is absent from the current artwork. This helps when cleaning up the panel. |
| Sort by Name | Orders the graphic styles in the panel alphabetically or numerically. |
| Use Square for Preview | Represents each graphic style preview with a square swatch. |
| Use Text for Preview | Uses the Type tool symbol, rather than a shape, for each style preview. This preview is closer to the final appearance when styles are applied to text. |
| Thumbnail View | Shows graphic styles as visual thumbnails, making appearances faster to recognize. |
| Small List View | Presents style names with small icons in a compact list, so more items fit in the panel. |
| Large List View | Uses a larger list layout with bigger icons and names to improve readability. |
| Override Character Color | Lets a new character color replace the character color specified by the graphic style. |
| Graphic Style Options | Change the selected graphic style's name in the Style Name text box. |
| Open Graphic Style Library | Loads predefined or custom style libraries. |
| Save Graphic Style Library | Stores the current group of styles as a library. |
