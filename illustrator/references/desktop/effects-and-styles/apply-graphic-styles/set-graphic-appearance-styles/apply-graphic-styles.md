# Apply Graphic Styles

Select the object, group, or layer, and then click a style thumbnail in the Graphic Styles panel.

Click a style thumbnail in the Graphic Styles panel to transfer that appearance to an object.

Use the steps below:

- To put a style on an object, choose one of the available styles in the Graphic Styles panel.
- To use one style on several objects, select all objects and choose the style.
- To assign a style to a group or layer, pick the group or layer in the Layers panel, and then apply the style.
- To combine a style with an object's current style attributes, or to stack more than one style on the same object, select the object and use Alt-click (Windows) or Option-click (macOS) on the target style thumbnail in the Graphic Styles panel.

Tip

When applying a graphic style while keeping type color unchanged, turn off Override Character Color in the Graphic Styles panel menu.
