# Adjust path smoothness

Use the Smooth tool in Illustrator when path smoothness needs adjustment.

Rough or uneven Illustrator paths can be cleaned up with the Smooth tool. It helps polish hand-drawn paths, remove irregularities, and make curves cleaner.

Open the Smooth tool options by double-clicking the Smooth tool.

In the Smooth Tool Options dialog box, choose one of these adjustments:

- Move the slider toward Accurate when the path should track cursor movement closely and keep more of its complexity.
- Move the slider toward Smooth when you want fewer anchor points and a simpler path.

Select OK.
