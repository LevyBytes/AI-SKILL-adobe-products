# Erase parts of a path using a stylus pen

A Wacom stylus pen eraser works on artwork areas such as paths, compound paths, clipping paths, and paths contained in Live Paint groups.

Turn the stylus over to switch on the Eraser tool.

Use the pen's back side and drag across the area where paths should be erased.

Open the Eraser Tool Options dialog box by double-clicking the Eraser tool.

Within the Eraser Tool Options dialog box, choose Pressure from the dropdown menu and enter the value.

Choose Pressure from the dropdown menu so the stylus pen can vary the erased path's width.

With Pressure chosen from the dropdown menu, use the stylus pen to make the erased path wider.

Press harder with the stylus when you need a wider eraser stroke.

Turn the pen back over to return to the tool that was active before.
