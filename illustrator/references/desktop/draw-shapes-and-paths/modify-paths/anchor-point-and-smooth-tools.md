# Refine paths in Illustrator using Anchor Point and Smooth tools

Use the Anchor Point and Smooth tools in Illustrator to reshape corners, clean up jagged paths, and build flowing curves.

Paths can be refined in Illustrator with the Anchor Point and Smooth tools. The Anchor Point tool converts or adjusts anchor points, for example turning a corner into a curve. The Smooth tool reduces path irregularities, including rough or uneven curves.

Get familiar with the Anchor Point tool and Smooth tool in Adobe Illustrator, including the main differences between them.
