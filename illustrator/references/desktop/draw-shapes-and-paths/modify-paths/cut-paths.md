# Cut paths

Use the Scissors tool or Control panel to split a path into separate pieces at any anchor point or along any segment.

Choose the path with the Direct Selection tool.

Choose the Scissors tool, then choose the path segment or anchor point where the cut should occur.

Note

New paths keep the original path's settings, including stroke weight and fill color, while stroke alignment changes back to center.

To cut a path at selected anchor points:

- Choose Window > Control to open the Control bar.
- Choose the anchor point with the Direct Selection tool.
- In the Control bar, choose Cut path at selected anchor points icon.

Adjust the result by dragging the new anchor point or path segment.

Move the new path with the Selection tool.
