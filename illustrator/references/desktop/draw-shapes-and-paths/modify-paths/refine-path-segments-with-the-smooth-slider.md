# Refine path segments with the Smooth slider

Use the Smooth slider or Auto-Smooth to clean up path segments.

With the Selection tool, choose the path.

Choose Object > Path > Smooth.

Move the slider toward Minimum smoothing or Maximum smoothing. For automatic cleanup, use the icon labeled Auto-Smooth.

Adjust the slider for smoothing.
