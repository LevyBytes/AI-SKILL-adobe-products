# Simplify paths manually to reduce anchor points and smooth curves.

Choose the object with the Selection tool, or choose a specific path region with the Direct Selection tool.

Choose Object > Path > Simplify.

Note

By default, Illustrator sets the Simplify slider to an auto-simplified value.

Adjust the slider to:

- Minimum anchor points: uses fewer anchor points, which creates small differences from the original path.
- Maximum anchor points: keeps the modified path nearer to the original curve and provides more control for later edits.

Drag the Simplify slider to adjust the number of anchor points on the path.
