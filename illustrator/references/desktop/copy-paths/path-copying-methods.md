# Copy paths by dragging, copy-paste actions, or keyboard shortcuts.

Choose a path or segment with the Selection tool.

Hold Alt (Windows) or Option (macOS), then drag the path to make a duplicate.

To move paths between documents or apps by copy and paste, press Ctrl + C (Windows) or Command + C (macOS) to copy, then Ctrl + V (Windows) or Command + V (macOS) to paste.
