# Move artboards in Adobe Illustrator.

Choose the Artboard tool.

Select the artboard that needs to move.

To place the artboard precisely, go to the Transform section of the Properties panel and enter X and Y values in the text boxes.

In the Properties panel, enable Move artwork with Artboard so the artwork travels with the artboard.

Use Move artwork with Artboard in the Properties panel whenever the move should include both the artboard and its artwork.

Repeat that move on the selected artboards with Ctrl + D (Windows) or Cmd + D (macOS).

Note

Ctrl + D (Windows) or Cmd + D (macOS) is available only while the Artboard tool is selected and artboard edit mode is active.
