## Font browser overview

Use this overview to understand the font browser in Adobe Illustrator and how it helps with finding, previewing, and organizing fonts.

Illustrator can style text with fonts installed locally and with fonts added from Adobe Fonts. In the font browser, filters and related controls help you search and preview fonts from both sources, then arrange them through Creative Cloud Libraries.

To open the font browser, choose Window > Type > Character. In the Character panel, open the Set the font family dropdown. The same browser is also available in the Properties panel, the Control panel, and the Contextual Task Bar after you select text on the canvas.

Use the browser's controls to choose a font suited to the current design.

Use those font browser choices to settle on the typeface that best fits the design.

### Your Fonts and Discover More tabs

Your Fonts and Discover More both provide ways to locate a font that suits the design requirements.

### Your Fonts

When the font browser opens, it starts on Your Fonts. This tab displays fonts installed on your computer plus fonts added from Adobe Fonts, grouped into sections.

### Discover More

Discover More contains the full Adobe Fonts catalog, organized by section.

### Filters

Filters, including quick filters, reduce the visible font list by selected criteria. Your Fonts and Discover More use the same filter set. If you filter in one tab and move to the other, the chosen filters stay on and the list updates with matching fonts from that tab. Restarting Illustrator clears the filters automatically.

Multiple filters can be active together. In that state, they intersect rather than act separately, so only fonts common to both criteria appear.

Hovering over a font in the Your Fonts or Discover More tab reveals details and font-specific options.

### Libraries tab

Creative Cloud Libraries are available from the font browser's Libraries tab for organizing fonts. You can work with existing Libraries there or create Libraries directly in that tab. For contextual font management, the Libraries tab:

- Lists every Library created inside the font browser, including Libraries that do not contain fonts.
- Lists only Libraries from the Libraries panel of Illustrator, from other apps, and from the Adobe Fonts website when they include at least one font. To make an empty Library appear in the Libraries tab, add fonts to it from the Adobe Fonts website.
- Displays only the fonts in each Library and suppresses any other assets.

Hover over any Library, or over a font inside one, to reveal details and options specific to that Library or font.

## Find and apply fonts

### Find, preview, and apply local fonts and Adobe Fonts entries when styling text in Adobe Illustrator.

### Find and apply local or added fonts

From the font browser's Your Fonts tab, locate, preview, and apply fonts installed locally or added to your account from Adobe Fonts:

With the Selection tool, select the text, or the portion of text, that should receive the font. When you are only browsing or choosing a font for later use, omit this step.

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Note

Other entry points for Set the font family: Contextual Task Bar, Character section in the Properties panel, and Control panel. Fonts can also be found and applied through Type > Font.

In Your Fonts, review local fonts and fonts added from Adobe Fonts:

- Look through Recently used or Your fonts. Apply filters or quick filters if the list needs to be narrowed.
- Enter the font name in the Set the font family field.

Use filters when you need fonts from particular sources or with particular font properties.

Check the preview before applying a font to confirm that it fits the design:

- The sample-text preview appears beside the font name. By default, it uses the text selected on the canvas; when no text is selected, the preview uses Sample. Adjust the sample text, change its size, or turn the preview off as needed.
- Hover over the font name to preview that font on the selected canvas text.

Select a font to apply it to the selected text on the canvas. If no canvas text is selected when you choose a font, Illustrator applies that font automatically to the next text object you create.

### Discover more fonts from Adobe Fonts

Use the font browser's Discover More tab to find and add fonts from Adobe Fonts:

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Open Discover More. Browse Explore Styles, Trending fonts, New releases, or Browse Adobe Fonts. Apply filters or quick filters if you need a shorter list.

For adding a font to the account, point to the font name, choose the Add icon, then wait for the control to change to Remove.

### Find similar fonts

In either Your Fonts or Discover More in the font browser, locate fonts similar to a selected font:

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Hover over the font, then choose Show similar fonts.

## Organize fonts using Creative Cloud Libraries

Use Creative Cloud Libraries in Adobe Illustrator to manage fonts more effectively.

The font browser can group and manage fonts through Creative Cloud Libraries. Add fonts to existing Libraries, or build font-specific Libraries directly in the font browser.

Add fonts to Creative Cloud Libraries to keep them organized and make them easy to reach across Creative Cloud apps.

### Add fonts to a new or existing Library

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

In Your Fonts or Discover More, hover over the font or font family to store in a Library, then choose Add font(s) to Library.

Choose one:

- For a new Library, choose Add to new Library.
- For an existing Library, hover over that Library, then select it.

Note

A single font can be added to more than one Library.

### Remove fonts from a Library

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Open the Libraries tab.

To order the Libraries, choose Sort Font Libraries, then choose Date modified or Name.

Choose the Library that contains the font or font family you want to remove.

Hover over the target font or font family, then choose Delete font from Library.

### Create and manage font Libraries

Manage font Libraries from the font browser's Libraries tab:

Choose Window > Type > Character to open the Character panel. Next, open the Set the font family dropdown to show the font browser.

Go to the Libraries tab.

Use New to create a Library, then enter its name.

For renaming, hover over the Library and choose Rename Library.

To remove a Library or all of its fonts in one action, hover over the Library, then choose Delete Library:

- When the Library contains only fonts, the Library is deleted no matter where it was created.
- When the Library also includes other assets, only the fonts are removed and the Library stays in place. If it was created in the font browser, it continues to appear in the Libraries tab.

To delete a Library that contains multiple asset types, use the Libraries panel.

Note

- Libraries shared with you cannot be renamed or deleted.
- Libraries cannot be shared from the Libraries tab. Use the Libraries panel to share a Library.

## Apply the fonts organized in Creative Cloud Libraries

Find, preview, and apply Creative Cloud Libraries fonts from the font browser when styling text in Adobe Illustrator.

Select the text with the Selection tool.

Choose Window > Type > Character to open the Character panel.

Open the Set the font family dropdown to show the font browser, then go to the Libraries tab.

To sort the Libraries, choose Sort Font Libraries, then choose Date modified or Name.

Select the Library that contains the needed font.

Preview the font:

- The sample-text preview appears beside the font name. Change the sample text, change its size, or turn the preview off if needed.
- Hover over the font name to preview that font on the selected canvas text.

Before applying a font to selected canvas text, hover over its name and identify whether it is a local font (shown by one of the Font Technology icons), an added font, or a font not yet added (shown by Add). Then apply it as follows:

- For a local font or an added font, select the font.
- For a font that has not yet been added, select Add; after it is added, select the font.

## Supported font file types in Adobe Illustrator

Review which font file formats Adobe Illustrator can use.

### Variable fonts

Variable fonts use the OpenType format and let you tune attributes such as weight, width, and slant for responsive web lettering and typography. Illustrator also works with Momochidori font, a Japanese variable font built for exact, flexible styling in artwork.

### SVG fonts

A single glyph in SVG fonts can contain several colors as well as gradients.

### COLR fonts

Use COLR fonts when you want emojis in text or gradient-rich lettering with smooth color changes. Because the color effects are built into the text, they add visual depth and dimension while keeping the type scalable.

## Edit fonts

Adjust font size and apply styles to refine how text looks.

### Change the font size

Use the Selection tool to select the text.

Open the Character panel by selecting Window > Type > Character.

In the Character panel, enter the needed value in the Set the font size field, or choose a font size from the dropdown menu.

Enter the font size in the Set the font size field.

Enter the font size in the Set the font size field. Tip

To switch the font-size unit, select Illustrator > Settings > Units (macOS) or Edit > Preferences > Units (Windows), then choose a unit from the Type dropdown menu.

### Change the font style

With the Selection tool, double-click the text on the canvas to activate the Type tool.

Inside the text box, highlight the text segment that should receive the style.

In the Character panel, use the Set the font Style dropdown menu to choose a style, or apply a shortcut:

- Bold: Shift + Command + B (macOS) or Shift + Ctrl + B (Windows).
- Italic: Shift + Command + I (macOS) or Shift + Ctrl + I (Windows).
- Underline: Shift + Command + U (macOS) or Shift + Ctrl + U (Windows).

Note

Bold and italic formatting cannot be used unless the chosen font family includes those styles and the styles are installed on your system.

When a requested regular style is unavailable in that font family, Illustrator switches to the nearest installed style, usually Myriad Pro Regular.

## Preview, add, or replace missing fonts

Manage missing fonts so designs stay consistent and manual replacement work is reduced.

Opening a file with missing fonts in Adobe Illustrator displays the Missing Fonts dialog box and a font list. A selected checkbox with Available on Adobe Fonts means the font can be obtained from Adobe Fonts. A greyed-out checkbox with Preview only means Adobe Fonts cannot supply the font, though the file can still show a preview.

Use File > Open (Windows) or Illustrator > Open (macOS) to open the file.

Within the Missing Fonts dialog box, choose one of these actions:

- Choose Add Fonts to bring Adobe Fonts matches into Illustrator.
- Choose Replace Fonts when substituting another font from your file, recent fonts, or your computer.
- To preview the file while leaving missing fonts unadded and unreplaced, select Close.

Note

Add Fonts depends on Adobe Fonts being active in Creative Cloud Desktop. In Adobe Creative Cloud, go to Main Menu > File > Preferences > Services, and turn on Adobe Fonts.

Add, replace, or preview missing fonts to keep work moving.

Add, replace, or preview missing fonts to keep work moving.

Some fonts do not work with preview, so Illustrator substitutes the default font automatically and highlights those fonts.

### Set up automatic addition of missing fonts

When automatic addition is enabled and you open a file containing missing fonts, Illustrator can take these actions:

- Add fonts in the background when every missing font is available in Adobe Fonts.
- Open the Missing Fonts dialog box with a list of missing fonts and an add option when only some of them are available.
- Open the Missing Fonts dialog with a font-replacement list when Adobe Fonts has none of the missing fonts.

Open File Handling preferences through Edit > Preferences > File Handling (Windows) or Illustrator > Settings > File Handling (macOS).

Within Preferences, choose Auto-activate Adobe Fonts in the Fonts category.

Select OK.

After setup, Illustrator adds missing fonts in the background and does not display a notification. To check progress, select the spinner icon in the menu bar.

## Identify fonts using Retype

Use Retype to identify fonts that appear in raster images and outlined text.

### Identify fonts

Choose the image or outlined text, then open Window > Retype.

You can also open Retype panel from the Type menu, the right-click menu, or Quick Actions in the Properties panel.

In the Retype panel, select Find Matching Fonts. Retype auto-detects words and places a dotted line around them. Adjacent words that share a font also share one border. The text with the largest border is highlighted by Retype, surrounded with a marquee, and matched fonts appear in the panel.

By default, the panel lists 10 matching fonts in order of visual closeness to the highlighted text. At the bottom, select Find more font matches to show five additional candidates.

Use Retype to find matching fonts for rasterized or outlined text.

Use Retype to find matching fonts for rasterized or outlined text.

If necessary, choose Roman or Japanese from the Choose Script And Match Font menu to define the script.

Under Apply Filter, deselect From Adobe Fonts or From your device to remove suggestions from either source.

Use any of these options for a clearer preview of suggested fonts:

- From the panel menu, choose one of the three text sizes.
- Use the Type your text to preview on card field for a custom sample.

For another area that needs font suggestions, select that text in the image or outlined text. Retype highlights every word using that font, even when the words are separated. If the text you want is not enclosed by a dotted line, drag the marquee over it.

Note

- Use the marquee only when no dotted line surrounds the text.
- Marquee works best when one font is arranged horizontally.

To bring a matching font from Adobe Fonts into Illustrator, hover over it, and select Click to add. Added fonts become available in all Creative Cloud apps.

To favorite a font, hover over it, and select Add to favorites.

Press Exit to leave Retype scan mode. After you exit, the Retype panel automatically displays the fonts marked as favorites. To show every suggested font from the most recent scan, select Clear Filter.

Select Reset Retype panel to clear suggested fonts from the panel.

### Use Retype on Japanese text

For Japanese text in a non-Japanese version of Illustrator, enable these Retype options:

Open Type preferences with Edit > Preferences > Type (Windows) or Illustrator > Settings > Type (macOS).

Turn on Show East Asian Options and Enable Japanese Font Preview in 'Find More'.

## About Adobe Asian composers

Adobe Asian composers help you create content in Middle Eastern and South Asian languages.

Adobe Illustrator supports document creation with Indic, Middle Eastern, and Southeast Asian languages. For many non-Western scripts, correct word shaping is provided by the Middle Eastern and South Asian Composer. Arabic, Hebrew, English, and other languages can be typed and mixed together. Files can also be saved with Arabic and Hebrew names.

Examples include Middle Eastern & South Asian Single-line Composer and Middle Eastern & South Asian Every-line Composer.

For information about additional Asian languages supported in Illustrator, refer to Composer for Asian scripts.

For Asian-language content, choose Middle Eastern & South Asian Single-line Composer from the Paragraph panel menu.

For Asian-language content, choose Middle Eastern & South Asian Single-line Composer from the Paragraph panel menu.

### Support for Arabic and Hebrew

- In some versions, Illustrator supports Arabic and Hebrew with complete RTL language handling and features for Arabic/Hebrew.
- Middle Eastern version with an English interface
- North African French (Français\*) version with a French interface
- In the Chinese, Japanese, and Korean versions of Illustrator, text direction, digit types, automatic Kashida insertion, and diacritical marks are unavailable.

## Justify text using Kashida and hyphenation

Arabic text can use automatic Kashidas to change how visible the text appears.

### Automatic Kashida insertion

Arabic justification is handled by adding Kashidas; the spaces between characters stay unchanged.

With the Type tool, select the paragraph that contains Arabic text.

Choose Type > Convert To Area Type so the text flows inside the box.

Open Window > Type > Character, then open the Character panel menu.

From the Character panel menu, choose Kashidas.

Open Window > Type > Paragraph, then switch the paragraph alignment to any justified alignment.

Note

Paragraphs that already use alignment settings do not use this setting.

From the Insert Kashidas dropdown menu, choose one of these options:

- None: leaves the text unchanged.
- Short: places short Kashidas in the text.
- Medium: adds Kashidas of moderate length.
- Long: applies longer Kashidas.
- Stylistic: lets the font style determine Kashida changes automatically.

Adjust Arabic text Kashidas as needed.

Set Arabic text Kashidas as needed.

### Hyphenation

When a sentence has too many words for one text line, it wraps to the next line automatically. Depending on the justification used during wrapping, extra spaces can appear and may look poor or conflict with language rules. Hyphenation splits a word at a line ending with a hyphen, causing the remaining sentence to continue on the next line.

### Mixed text

Kashida insertion changes hyphenation behavior in mixed text.

Open Window > Character.

To hyphenate text, use one of these choices:

- Turn on Kashidas to hyphenate Arabic and non-Arabic text.
- Turn off Kashidas to hyphenate non-Arabic text only.

Note

The feature is unavailable when Arabic is chosen as the Language in the Character panel.

### Hebrew text

From the Paragraph panel, open the Paragraph panel menu, then choose Hyphenation.

Set the options in the Hyphenation panel, then select OK.

Add hyphenation by adjusting settings in the Hyphenation panel.

Use the Hyphenation panel options to add hyphenation.

Note
