## About Swatches

Use swatches to organize colors, gradients, and patterns more effectively.

Named colors, tints, gradients, and patterns are swatches.

Document swatches are shown in the Swatches panel, either one by one or inside groups. The Swatches panel gives you one place to edit and manage document colors, gradients, and patterns. You can also name and save these items for quick reuse. If the selected object’s Fill or Stroke uses a color, gradient, pattern, or tint from the Swatches panel, that swatch is highlighted in the panel.

The Swatches panel also supports tint creation. A tint is a global Process Color or Spot Color whose intensity has been changed. Tints that come from the same color stay linked; editing a tint swatch’s color changes every related tint swatch and the objects using those swatches, while the tint values themselves do not change. In List view, percentages identify them.

In Illustrator, the Swatches panel includes these Swatches types:

- Process Color: combines the four-standard process inks cyan, magenta, yellow, and black. Illustrator defines new swatches as process colors by default.
- Global Process Color: updates automatically throughout the artwork after you edit it. Every spot color is global, while process colors may be global or local.
- Spot Color: uses a premixed ink in place of, or alongside, CMYK process inks.
- Gradient: creates a graduated blend between two or more colors, or between tints of either the same color or different colors. Gradient colors can be CMYK process colors, RGB colors, or a Spot color. When transparency is applied to a gradient stop, that transparency remains when the Gradient is saved as a Gradient swatch.

Note

Elliptical-gradient Aspect Ratio and Angle settings, made by modifying a Radial Gradient, are not stored with the Gradient swatch.

- Pattern: contains repeating tiled paths, compound paths, or text with solid fills or no Fill.
- None: removes the Stroke or Fill from an object. This swatch cannot be edited or removed.
- Registration: is a built‑in swatch that sends filled or stroked objects to each separation produced by a PostScript printer. Registration marks, for example, use the Registration color so press operators can align printing plates accurately. This swatch cannot be removed.

Tip

Using the Registration swatch for type can cause poor registration after separation and printing, and black ink may look muddy. Use only black ink for type to avoid that result.

- Swatch group: can hold process, spot, global process colors, patterns or gradients. Use the Swatches panel to build Swatch groups from harmonies. To add existing Swatches to a swatch group, choose the swatches, then select New Swatch Group in the Swatches panel.

## Add colors to swatches

Add colors to swatches in Adobe Illustrator so the same colors are available for later artwork.

### Add all document colors

Choose Window > Swatches.

With nothing selected on the artboard, open the Swatches panel menu and choose Add Used Colors. Adobe Illustrator finds document colors that are absent from the panel, changes process colors into global colors, and adds each result as a new swatch. Choose Add Used Colors when you want the document colors added as new swatches.

Choose Add Used Colors to add the document colors as new swatches.

### Add colors from selected artwork

Select the artwork that contains colors to include in the Swatches panel.

From the Swatches panel menu, choose Add Selected Colors.

In the Swatches panel, choose New Swatch Group.

In the dialog box that opens, set the options you need. Illustrator sorts and stores the colors with the Hue Forward rule.

## Reorder swatches

Reorder swatches in Illustrator to keep the color palette organized.

The Swatches panel lets you change the order of single Swatches and also manually rearrange Swatches within swatch groups.

Choose Window > Swatches.

In the Swatches panel, choose More options, then choose one of these sorting commands:

- Sort by Name: puts swatches in alphabetical order based on their names.
- Sort by Kind: groups swatches by type, such as Solid colors, Gradients, and patterns.

Note

Sorting commands affect only individual swatches in the Swatches panel; they do not sort swatches inside Swatch groups.

To reorder manually after sorting or at any other time, drag individual swatches to a new location in the Swatches panel.

To reorder manually after sorting or at any other time, drag individual swatches to a new location in the Swatches panel.

## Replace, merge, or delete swatches

Replace, merge, or delete swatches in Adobe Illustrator when you need to streamline and manage the color palette.

### Replace a swatch

Choose Windows > Swatches.

Hold Alt (Windows) or option (macOS), then drag a color or gradient from the Color panel or Gradient panel onto the Swatches panel, highlighting the swatch you intend to replace.

Turn on the Global option so edits stay consistent for all linked objects.

Turn on the Global option so edits stay consistent for all linked objects. Note

When an existing color, gradient, or pattern is replaced in the Swatches panel, Illustrator updates objects in the file that use that swatch color to the new color, gradient, or pattern. A process color is the exception when Global is not selected in the Swatch Options dialog box.

### Merge multiple swatches

Choose Windows > Swatches.

Select two or more swatches, then use the Swatches panel menu command Merge Swatches.

## Group swatches

Group swatches to organize colors and make the design workflow more efficient.

Use swatch groups in the Swatches panel when specific colors should stay together. For instance, colors selected in the Color Guide panel can become one group. Saving a swatch group in the Edit Colors dialog box also saves it automatically as a swatch group in the Swatches panel. Any collection of solid color swatches can be grouped manually as well.

Choose Windows > Swatches.

Select one or more swatches to include in the group.

In the Swatches panel, choose More > New Swatch Group.

Use New Swatch Group in the Swatches panel to place the selected colors into a custom group.

Use New Swatch Group in the Swatches panel to place the selected colors into a custom group. Note

Another route is the panel menu command New Swatch Group.

Use this option to create swatches:

- Selected Swatches: creates a color group from swatches you selected manually in the Swatches panel.
  - Convert Process to Global: changes process colors into global swatches, linking the swatch so edits update all artwork that uses that color.
  - Include Swatches for Tints: adds tint variations for colors in the selected artwork, supporting consistent color use at different opacities.

Type a name in the New Swatch Group dialog box, then choose OK.

## Share swatches between applications

Export and import swatch libraries when color assets need to move between Adobe applications.

To exchange solid swatches between Adobe Photoshop and InDesign, save a swatch library for exchange. With synchronized color settings, the colors stay visually consistent across the applications.

Note

The following swatch types are not shareable between applications: patterns, gradients, and the Registration swatch from Illustrator or InDesign. Photoshop swatches for book color references and HSB are also excluded, as are XYZ, duotone, monitorRGB, opacity, total ink, and webRGB. Saving swatches for exchange omits those swatch types automatically.
