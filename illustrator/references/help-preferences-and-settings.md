## Set app preferences

Learn how to customize and save Adobe Illustrator app settings, including options for display, file saving, and performance.

Launch Illustrator.

In the Illustrator main menu, choose:

- macOS: Illustrator > Preferences > [preference category]
- Windows: Edit > Preferences > [preference category]

You can also select Preferences in the Control panel.

In the Preferences dialog box, choose a category and adjust settings as needed. You can move among multiple categories before saving.

Select OK to save changes.

To reset all preferences, select General > Reset Preferences > OK.

### Search within Preferences

Use the Search Preferences bar to quickly find any setting.

Open the Preferences dialog box with Cmd + K (macOS) or Ctrl + K (Windows).

The Preferences dialog box opens with Search Preferences already active, so you can start typing immediately. Return to it anytime with Cmd + F (macOS) or Ctrl + F (Windows).

Press Enter or choose See all results to show every match. Select an option to jump to its matching section.

Use the Search Preferences bar to filter settings by keyword and quickly find what you need.

## Customize keyboard shortcuts

Set up custom shortcuts for text formatting options you use often.

Select Edit > Keyboard Shortcuts to open the Keyboard Shortcuts dialog.

Select Menu Commands from the dropdown above the shortcut list, then select Other Text.

Find the text formatting option you want to customize.

In the Shortcut and Symbol column, press the key combination you want to assign to the menu commands.

Select OK to save your changes.

Note

The custom keyboard shortcut you create should be unique and include a modifier key, such as Ctrl or Command.

## Find custom keyboard shortcut files

Learn how to find saved custom keyboard shortcut files in Adobe Illustrator. These files can be used to back up, transfer, or delete shortcuts.

Open the folder where keyboard shortcut files are stored:

- macOS: ~/Library/Preferences/Adobe Illustrator <version> Settings/<locale>/<shortcut filename.kys>
- Windows: C:\Users<username>\AppData\Roaming\Adobe\Adobe Illustrator <version> Settings<locale>\x64<shortcut filename.kys>

Find the file with the .kys extension. This is your custom shortcut file.

Copy, rename, or move this file to back up or share your shortcut set.

## Export keyboard shortcuts list as a text document

Export the keyboard shortcuts list and save it as a text document.

Select Edit > Keyboard Shortcuts.

In the Keyboard Shortcuts dialog box, choose Illustrator Defaults from the Set dropdown menu.

Select Export Text.

Enter the file name in the Save Key Set File As dialog box.

Select Save.

## Delete keyboard shortcuts

Learn how to delete the shortcut file from your system to remove Adobe Illustrator custom keyboard shortcuts.

Go to Edit > Keyboard Shortcuts.

Choose the custom shortcut set to delete from the Set dropdown menu.

Next to the Set name, select the Delete icon.

At the prompt, select OK to confirm.

## Accessibility features in Adobe Illustrator

Learn about native accessibility-friendly Illustrator features and support for assistive technologies, including screen magnifiers and screen readers.

Application accessibility covers features that make an app easier to use for people with visual, auditory, speech, motor, cognitive, and mobility disabilities. Illustrator includes some native accessibility-friendly capabilities.

Illustrator is not accessibility-friendly for people with full vision loss. It provides partial support for people with limited vision.

### Color contrast

Illustrator does not fully support Windows high contrast mode. It responds to high contrast mode only for title bars and menus.

### Text resize

Illustrator lets operating system display scaling resize text up to 200 percent without losing content or functionality for most functions. At that zoom level, however, video controls may disappear.

### Appearance customization

You can change the canvas appearance and several UI elements.

To customize the user interface, select Illustrator > Settings > User Interface (macOS) or Edit > Preferences > User Interface (Windows):

For widget size and style, select Illustrator > Settings > Selection & Anchor Display (macOS) or Edit > Preferences > Selection & Anchor Display (Windows):

For black appearance, select Illustrator > Settings > Appearance of Black (macOS) or Edit > Preferences > Appearance of Black (Windows):

### Wacom support

Enable Wacom tablets for Illustrator by selecting Enable Wacom from Illustrator > Settings > Devices (macOS) or Edit > Preferences > Devices (Windows).

### Screen magnifiers

Illustrator generally works with screen magnifiers.

### Screen readers

Most non-text Illustrator elements do not provide correct text alternatives for screen readers, such as icons that visually show tool-option state and status. On macOS, you can use VoiceOver; on Windows, you can use JAWS Client or NVDA as the screen reader.

Screen readers support these items:

- Items on the Home screen.
- Toolbar, status bar, Properties panel, menu items, dialog boxes, and document names.
  Other panels have partial support.

## MacBook Pro Touch Bar in Illustrator overview

Get familiar with the MacBook Pro Touch Bar so Illustrator tools and controls are easier to access.

Illustrator supports Touch Bar, the multitouch display along the top of the new MacBook Pro keyboard. Touch Bar exposes Illustrator features and controls that match the task currently on the main screen, and it supports familiar gestures including select, drag, and slide.

## Illustrator controls and contextual operations in MacBook Pro Touch Bar

Get familiar with contextual operations and controls available in Illustrator on the MacBook Pro Touch Bar.

### Contextual operations

Available context-specific operations change based on what you are working on in Adobe Illustrator.

- In the Start workspace, the Touch Bar offers document creation and opening controls.
- With nothing selected in the Illustrator workspace, the Touch Bar offers controls for creating and opening a document, placing a file, showing or hiding rulers, grids, and guides, and working with artboards.
- With a path object selected, the Touch Bar offers fill color, stroke color, opacity, alignment, and arrangement controls.
- With multiple path objects selected, the Touch Bar offers fill color, stroke color, opacity, alignment, and arrangement controls. Pathfinder effects and grouping for selected objects are also available.
- With a text object selected, the Touch Bar offers fill color, stroke color, opacity, alignment, arrangement, paragraph alignment, and font size controls.
- With multiple text objects selected, the Touch Bar offers fill color, stroke color, opacity, alignment, arrangement, and paragraph alignment controls. The selected text objects can also be grouped from the Touch Bar.
- When the selection includes a text object and a path object, the Touch Bar offers fill color, stroke color, opacity, alignment, and arrangement controls. The selected objects can also be grouped with the Touch Bar.
- With an image selected, the Touch Bar offers opacity, alignment, and arrangement controls. It also provides an option to crop or mask the image.
- With a grouped object selected, the Touch Bar offers controls for group opacity, alignment, and arrangement. The objects can also be ungrouped from the Touch Bar.
- With any other object selected, the Touch Bar offers opacity, alignment, and arrangement controls.
- With multiple other objects selected, the Touch Bar offers opacity, alignment, and arrangement controls. The objects can also be grouped from the Touch Bar.

## Use Microsoft surface dial in Illustrator

Learn how Microsoft Surface Dial in Illustrator can support efficient design workflows.

Adobe Illustrator supports Microsoft Surface Dial on Windows 10 Anniversary edition and later, and directly on Surface Studio. Use Surface Dial to adjust settings and parameters in Illustrator documents.

While using Illustrator, long-press Surface Dial to open these options:

- Undo or Redo: Runs Undo and Redo operations.

- Arrange: Moves the selected object one object forward or backward in a stack.

- Zoom: Zoom in or out while working on artwork.

- Artboard navigation: Move from one document artboard to another.

- Tools: Select one of these Illustrator tools: Rotate, Scale, Paintbrush, Blob Brush, and Eraser.

  - Select the Rotate tool, place a pivot point on the selected object, then rotate Surface Dial to transform the selected artwork around that pivot point in five-degree intervals.
  - Select the Scale tool, then rotate Surface Dial to uniformly scale the selected artwork in 5 % intervals.
  - Select the Paintbrush tool or the Blob Brush tool, then rotate Surface Dial to change brush size.
  - Select the Eraser tool, then rotate Surface Dial to change the eraser diameter.
