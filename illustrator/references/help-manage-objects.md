## Object selection methods and preferences

Explore object selection methods and selection preference customization in Adobe Illustrator.

### Object selection options

An object has to be selected before you can change it. After selection, the whole object or individual parts can be edited. Illustrator includes multiple tools and approaches for making object selections:

Note

For exact targeting, use the Layers panel to select individual objects, groups, or every object in a layer, including items nested inside other artwork.

### Selection preferences

For a specific document, adjust Selection & Anchor Display preferences to make choosing objects easier.

Open these preferences with Edit > Preferences > Selection & Anchor Display (Windows) or Illustrator > Settings > Selection & Anchor Display (macOS).

## Select objects

Select objects in Adobe Illustrator when you need to move, edit, or transform them efficiently.

Illustrator provides several selection tools for selecting and transforming artwork. The Selection tool handles complete objects, the Direct Selection tool changes object parts, and the Group Selection tool targets objects inside groups, including a single item within a grouped design.

Review how the Selection tool, Direct Selection tool, and Group Selection tool work in Adobe Illustrator, including the main differences among them.

### Select and move objects using the Selection tool

Switch to the Selection tool.

On the artboard, click one object, or draw a marquee over several objects to include them in the selection.

Scale the object by dragging a bounding box handle.

To rotate the object, place the pointer outside a corner handle, then drag.

### Adjust parts of objects with the Direct Selection tool

Switch to the Direct Selection tool.

Select an anchor point or a path segment.

Reposition the selected point or segment by dragging it.

### Select objects within groups with the Group Selection tool

Switch to the Group Selection tool.

Select an object inside a group.

Select again to add more objects from the same group.

Drag the selected objects to move them.

## Select objects by characteristics

Use characteristics such as fill, stroke, or appearance to select objects for faster editing of similar artwork elements.

Objects can be selected by several characteristics, such as formatting attribute, layer, or kind, including brush strokes and clipping masks.

To select every object in a file, choose Select > All.

To clear all selections, choose Select > Deselect.

To select every object sharing an attribute, select one object with the desired attribute, choose Select > Same, and then choose an attribute from the list. The list contains:

- Blending Mode
- Fill & Stroke
- Fill Color
- Opacity
- Stroke Color
- Stroke Weight
- Style
- Symbol Instance
- Link Block Series

Note

The Magic Wand tool can also gather objects that share the same color, stroke weight, stroke color, opacity, or blending mode.

For all objects of one kind, deselect the artwork, choose Select > Object, and then choose an object type such as:

- Brush Strokes
- Clipping Masks
- Stray Points
- Text Objects

### Select Same by text characteristics

All selected text boxes in a document can now have their properties changed together. Multiple text objects can be selected by text characteristics such as font size, text fill color, font style, font, and more.

To select every text object with a matching attribute, select text, choose Select > Same, and then pick one of these attributes:

- Font Family
- Font Family & Style
- Font Family, Style & Size
- Font Size
- Text Fill Color
- Text Stroke Color
- Test Fill & Stroke Color

The selection can be based on the available attributes under Select > Same.

Use attributes under Select > Same as the basis for selecting text.

Every text box with similar attributes becomes selected.

From the Character section of the Properties panel, change the font, size, and related settings. The edits apply to all selected text boxes.

Note

For each Select > Same text task based on an individual attribute, you can create keyboard shortcuts or create actions.

## Select objects enclosed in a marquee

Use the Selection tool to select only objects enclosed by the marquee, excluding objects that merely overlap it.

By default, marquee selection includes any object partly inside the marquee. Enclosed mode limits selection to objects completely inside the marquee.

Choose the Selection or Group Selection tool.

Drag a marquee around the objects to select.

While dragging, press E to move into enclosed mode.

Press E again to return to the default selection mode.

Note

With the Selection tool, grouped objects behave as one unit; with the Group Selection tool, individual objects can be selected even when they belong to a group.

## Select object groups and nested object groups

Learn a quick way to select grouped and nested objects in Adobe Illustrator so grouped design elements can be customized.

### Select objects and groups using the Group Selection tool

Hold the Direct Selection tool, then choose the Group Selection tool.

Select an object inside the group.

Select the object again to include its parent group.

Select the object a third time to include additional groups grouped with the selected group.

### Select one or more groups using the Selection tool

Choose the Selection tool.

Select an object inside the group, or drag over part or all of the group to create a selection.

To add a group to the selection or remove one from it, hold Shift and select the group.

### Select objects and nested groups with the Selection tool

Choose the Selection tool.

Enter isolation mode by double-clicking a group.

Inside isolation mode, select again to reach deeper objects or nested groups.

Double-click outside the group when you want to deselect it.

Tip

A single item inside a group can be targeted with the Group Selection tool, Lasso tool, or Direct Selection tool.

## Select faces and edges in Live Paint groups

Select faces and edges in Live Paint groups when fills or strokes need to be applied to particular artwork areas.

Faces, meaning the areas inside edges, and edges in a Live Paint group can be selected with the Live Paint Selection tool. To select the full Live Paint group, use the Selection tool.

Note

Before you begin: Create a Live Paint group first by choosing Object > Live Paint > Make.

Activate the Live Paint Selection Tool.

Hover over the Live Paint group until the target face or edge becomes highlighted.

Use any of these actions:

- Click the highlighted face or edge to select it.
- Draw a marquee around several faces or edges. The selection includes any face or edge fully or partly inside the marquee.
- Double-click a face or edge to select every connected face or edge with the same color.
- Triple-click a face or edge to select every face or edge with the same color.

Tip

When a small face or edge is hard to select, zoom in or configure the Live Paint Selection tool options so only fills or only strokes are selectable.

To add faces and edges to the selection, or remove them, hold Shift and select the faces or edges involved.

### Live Paint Selection tool options

In the tool panel, double-click the tool to open Live Paint Selection Options.

Use the Live Paint Selection Options dialog box to adjust fills, strokes, highlight color, and width when targeting and editing specific areas.

Fills, strokes, highlight color, and width are adjusted in the Live Paint Selection Options dialog box for targeting and editing specific areas.

- Select Fills: selects faces in Live Paint groups.
- Select Strokes: selects edges in Live Paint groups.
- Color: controls the highlight color. Choose a color from the menu, or use the paint swatch to define a custom color.
- Width: sets the thickness of the selection highlight.

## Group or ungroup objects

Group or ungroup objects when you need artwork to move, transform, or edit either as a combined set or as separate items.

### Group objects

Grouping lets selected objects move or transform as one unit while their attributes and relative positions stay unchanged.

With the Selection tool, choose the objects you want grouped.

Select Objects > Group.

Through the Object menu, Illustrator can combine multiple selected objects into one unit.

The Object menu also provides the command for turning several selected objects into a single unit.

### Ungroup objects

Ungrouping returns items to independent editing and movement. Grouped artwork is stacked behind the frontmost object and can move onto the top selected layer. In the Layers panel, groups are shown as <Group> entries, and items can be moved into or out of those groups there.

With the Selection tool, choose the grouped object.

To separate the objects, right-click and choose Ungroup; to clear every grouping, including nested groups, choose Ungroup All.

## Isolate objects

### Isolate selected objects, paths, or groups in Adobe Illustrator so precise edits do not change other artwork.

### Isolate paths, objects, or groups

Using the Selection tool, double-click the path, group, or object.

For a path inside a group, choose it with the Direct Selection tool, then use Isolate Selected Object in the Control panel.

To leave isolation mode, press Esc or choose Exit Isolation Mode in the Control panel.

After isolation mode closes, new or replacement art is placed at the same location as the original isolated artwork.

### Isolate layers or sublayers

In the Layers panel, choose the layer or sublayer, then pick Enter Isolation Mode from the Layers panel menu.

To leave isolation mode, press Esc or choose Exit Isolation Mode from the Layers panel menu.

When the isolated item is a sublayer, choose Exit Isolation Mode more than once until isolation mode is fully closed.

Note

When isolation mode ends, Illustrator lines up edits, deletions, and newly created objects with the original artwork.

## Save object selections

Save object selections that you have edited or changed so you can reuse them later.

You can select multiple objects and keep that selection available for later by using Save Selection, which helps move the objects together or adjust their appearance. Unlike grouping, Save Selection records the selected objects without moving them onto one layer.

With the Selection tool, choose one or more objects in the artwork.

Select Select > Save Selection.

Tip

Another route is the Layers panel > Save Selection > Save Selection command.

In the Save Selection dialog box, type a selection name and select OK.

Use the name field in the Save Selection dialog box to store the selection under that name.

Enter a name in the Save Selection dialog box name field to save the selection.

After a selection is saved, its name appears in the Select menu and in the Layers panel Save Selection menu. Choose that selection name from either menu, and the canvas shows the saved selection as selected.

### Update a saved selection

Objects can be added to or removed from a saved selection.

Choose the saved selection from the Select menu or from Layers panel > Save Selection.

Use Shift-click to add multiple objects to the selection or remove them from it.

Select Select > Update Selection.

Tip

You can also update a saved selection through Layers panel > Save Selection > Update Selection.

### Rename or delete a saved selection

Choose the saved selection from the Select menu or from Layers panel > Save Selection.

Select Select > Edit Selection.

Tip

Another way to edit a saved selection is Layers panel > Save Selection > Edit Selection.

In the Edit Selection dialog box, choose the saved selection, type a value in the Name field to rename it, or choose Delete.

Select OK.

## Select objects using layers and nested selection

Use advanced selection methods in Illustrator to choose grouped, nested, and layered objects.

### Select grouped or nested objects

The Layers panel can target objects that sit inside groups or nested structures.

Select Window > Layers.

In the Layers panel, scroll through and expand layers or groups until you find the object to select. Selection color boxes are displayed beside selected items in the panel.

Choose the Indicates Selected Art (click to select art) column located between the target button and the scroll bar.

To select or deselect several objects, Shift-click in the Indicates Selected Art (click to select art) column.

Click the Indicates Selected Art (click to select art) column beside a layer or group name to choose all artwork contained there.

After choosing an object in the Layers panel, use Select > Object > All on Same Layers to select every object on that layer.

## Select objects using the Magic Wand tool

Use the Magic Wand tool in Illustrator to select objects that share similar attributes.

In Illustrator, the Magic Wand tool can select multiple objects by matching shared properties. It is useful for quickly finding artwork with comparable fill colors, stroke colors, opacity values, or blending modes across the document.

### Select objects with similar attributes

The Magic Wand tool selects objects with comparable fill, stroke, opacity, or blending mode, and its tolerance settings control how exact the match must be.

Select the Magic Wand tool.

On the artboard, choose an object with the target attributes to select all similar objects.

Shift-click another object with similar attributes to extend the current selection.

To remove all objects with matching attributes, press Alt (Windows) or Option (macOS) while selecting an object.

### Customize the selection

Adjust the selection made by the Magic Wand tool more precisely.

Select Window > Magic Wand.

In the Magic Wand panel, set options that match objects by visual attributes such as color, stroke, and opacity.

Use the Magic Wand panel options to base object selection on visual attributes including color, stroke, and opacity.

For fill-color matching, enable Fill Color. Tolerance accepts 0 to 255 for RGB and 0 to 100 for CMYK; smaller numbers narrow the match, and larger numbers accept more variation.

From the Magic Wand panel menu, select Show Stroke Options, then configure these options:

- Stroke Color: use Tolerance values of 0 to 255 for RGB or 0 to 100 for CMYK.
- Stroke Weight: use a Tolerance range from 0 pt through 1000 pt.

From the Magic Wand panel menu, select Show Transparency Options, then configure these options:

- Opacity: set Tolerance anywhere from 0 through 100% for transparency matching.
- Blending Mode: match objects that use the same blending mode.

Tip

Use Select > Reselect to run the last selection command again, or Select > Inverse to invert the current selection and choose objects that were not selected.
