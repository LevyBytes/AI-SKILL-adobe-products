## Graphic Styles panel overview

The Graphic Styles panel lets you handle fills, strokes, effects, and transparency settings for objects, groups, and layers.

With graphic styles, appearance attributes such as fills, strokes, and effects can be reused on objects, groups, or layers through the Graphic Styles panel. When a style is assigned to a group or layer, every object inside takes on those appearance attributes. Open the panel with Window > Graphic Styles.

Note

When a graphic style is assigned to a group or layer but its fill color is not visible in the artwork, move the Fill attribute out of the Appearance panel.

### Graphic Styles panel

New documents show Illustrator's default graphic styles in the Graphic Styles panel. Any style stored in the current document is listed there while that document is the open, active one.

## Set graphic appearance styles

Use a graphic style when strokes, fills, effects, and transparency settings should be reused across artwork. Styles can come from the Graphic Styles panel or from another document, and appearance attributes can be used to create, update, or merge them.

### Work with graphic styles

Select Window > Graphic Styles.

In the Graphic Styles panel menu, use these commands:

- To make a graphic style, select New Graphic Style.
- To remove one, select the style, and then select Delete Graphic Style.
- To detach an object from a graphic style, choose the object, and then use Break Link to Graphic Style.
- To bring in every graphic style from another document, select Graphic Styles Libraries Menu, select Other Library, choose the file to import, and then select Open.
- To swap a graphic style's appearance, open Window > Appearance, choose the style being replaced in the Graphic Styles panel, select artwork whose attributes should become the replacement, and then use Redefine Graphic Style from the Appearance panel menu.

Note

The style being replaced retains its name, but its appearance changes everywhere it is used in the document.

- To build a graphic style from two or more current styles, select Merge Graphic Styles.
- To copy a graphic style, select Duplicate Graphic Style.
- To change a graphic style's name, select Graphic Style Options, enter the replacement name in the Style Name text box, and then select OK.

Tip

Imported graphic styles open in their own library panel.

### Apply Graphic Styles

Select the object, group, or layer, and then click a style thumbnail in the Graphic Styles panel.

Click a style thumbnail in the Graphic Styles panel to transfer that appearance to an object.

Use the steps below:

- To put a style on an object, choose one of the available styles in the Graphic Styles panel.
- To use one style on several objects, select all objects and choose the style.
- To assign a style to a group or layer, pick the group or layer in the Layers panel, and then apply the style.
- To combine a style with an object's current style attributes, or to stack more than one style on the same object, select the object and use Alt-click (Windows) or Option-click (macOS) on the target style thumbnail in the Graphic Styles panel.

Tip

When applying a graphic style while keeping type color unchanged, turn off Override Character Color in the Graphic Styles panel menu.

## Work with Graphic Style Libraries

Learn how to open, use, and maintain graphic style libraries.

Graphic style libraries store preset appearance styles for applying to objects. After a library is opened, it appears in a separate panel. You can preview and apply its styles as you would from the Graphic Styles panel, but library styles cannot be added, removed, or edited there.

Open Window > Graphic Styles.

From the Graphic Styles panel, open Graphic Styles Libraries Menu.

Access style presets and add them to the Graphic Styles panel.

In the Graphic Styles Libraries Menu, use these commands:

- To save a new graphic style in the library, choose Save Graphic Styles, enter the file name, and finish with Save.
- To move graphic styles from a library into the Graphic Styles panel, open the graphic style library, and then choose the style you want to add.
- To bring multiple styles from a library into the Graphic Styles panel, open the graphic style library, and then choose New Graphic Style from the library's panel menu.
