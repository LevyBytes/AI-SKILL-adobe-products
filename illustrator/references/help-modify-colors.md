## Recolor artwork

Use the Recolor dialog box options to replace or adjust the color palette used by your artwork.

### Recolor using Generative Recolor

Use text prompts in Generative Recolor when you want Illustrator to recolor artwork.

### Recolor using Color Library

For recoloring artwork, choose Document Swatches, a Swatch Group, or one of the curated color sets.

Select the artwork on the canvas.

Choose Edit > Edit Colors > Recolor Artwork. The Recolor dialog opens.

Inside the Recolor dialog, choose a color library from the Color Library dropdown.

### Recolor using Color Theme Picker

Color Theme Picker can sample a palette from images or vector objects on the canvas and use that palette to recolor artwork.

Select the artwork on the canvas.

Choose Edit > Edit Colors > Recolor Artwork. The Recolor dialog opens.

In the Recolor dialog, choose Color Theme Picker.

Use the option that matches what you need:

- Click an object to sample its complete color palette.
- Drag a marquee around part of an object when only that area should supply the palette.
- To collect colors from multiple objects, hold Shift while clicking objects or drawing marquees around them.

### Recolor using color wheel

On the color wheel, color stops stand for every color found in the selected artwork. Adjust those stops to refine the artwork's colors.

Select the artwork on the canvas.

Choose Edit > Edit Colors > Recolor Artwork. The Recolor dialog opens.

Use one of these methods to change a color stop:

- Move the color stop by dragging it.
- Open Color Picker by double-clicking the color stop, then choose a color.
- Right-click the color stop, choose Select Shade, then choose a shade.

Make a color the base color by right-clicking its color stop and choosing Set as Base Color.

Remove a color by right-clicking its color stop and choosing Remove Color.

Add a color stop for another color by right-clicking the area of the color wheel that contains that color, then choosing Add New Color.

As needed, decide whether to keep the color harmony connected:

- Select . to break the harmony so color stops can move individually.
- Select . to retain the harmony so color stops move together.

## Edit colors using Edit Colors dialog

Use the Recolor Artwork dialog box to make global color edits across selected artwork.

The Recolor Artwork dialog box offers a practical way to adjust selected artwork colors all at once. This is useful when the artwork was not originally built with global colors. After changing colors in the Recolor Artwork dialog box, apply the edits to the selected artwork or store the adjusted colors for a future workflow.

With the Selection tool, select the artwork.

Choose Window > Color Guide, then choose Edit or Apply Colors .

In the Recolor Artwork dialog box, choose the Edit tab.

Note

Keep harmony colors linked when you want the colors to move together and maintain their relationships during adjustment.

Select Recolor Art to preview the colors on the selected artwork.

Choose any of the following:

- Select Display smooth color wheel to view hue, saturation, and brightness in a continuous circular display.
- Select Display segmented color wheel to view the colors as separated color patches arranged in a wheel.
- Select Display color bars to show only the color group's colors as individual solid bars.

Choose a smooth color wheel, segmented color wheel, or color bars view for displaying and editing colors.

Display colors as a smooth color wheel, segmented color wheel, or color bars while editing them.

Adjust the colors with any of these methods:

- On the smooth or segmented color wheel, drag the color handles to change colors.
- With color bars, pick a color bar, then use the H, S, and B sliders to change color properties.

To save the result, choose Save changes to swatch group.

## Apply local or global changes to color properties

Apply color-property changes locally or globally in Illustrator.

### Randomly change color order or saturation and brightness

Select the artwork using the Selection tool.

Choose Edit > Edit Colors > Recolor Artwork. In the Recolor panel, use Advanced Options; Illustrator opens the Recolor Artwork dialog box.

Choose the Edit tab in the Recolor Artwork dialog box to reach the color wheel and advanced options.

On the Edit tab of the Recolor Artwork dialog box, choose Display color bars .

Choose whichever option fits the task:

- Randomly change color order : redistributes the existing colors across the selected objects while leaving Hue unchanged.
- Randomly changes saturation and brightness : creates varied visual effects by changing color intensity and lightness.

In the Recolor Artwork dialog box, choose Reset to restore the artwork to its original colors.

Use Reset in the Recolor Artwork dialog box when you need the artwork returned to its starting colors.

### Globally edit saturation, brightness, temperature, or luminosity

Select the artwork using the Selection tool.

Choose Edit > Edit Colors > Recolor Artwork. In the Recolor panel, use Advanced Options; Illustrator opens the Recolor Artwork dialog box.

Choose the Edit tab in the Recolor Artwork dialog box to reach the color wheel and advanced options.

Set Specifies the mode of the color adjustment sliders to Global Adjust in the Recolor Artwork dialog box.

In the Recolor Artwork dialog box, choose Generative Recolor to generate new artwork color schemes.

Use Generative Recolor in the Recolor Artwork dialog box when the artwork needs newly generated color schemes.

Move these sliders as needed to shift color properties globally:

- Saturation: raises or lowers the intensity across all colors.
- Brightness: makes the full artwork lighter or darker.
- Temperature: moves colors toward warmer reds/yellows or cooler blues.
- Luminosity: changes perceived lightness while leaving hue intact.

Select OK.

## Assign new colors to selected artworks

Assign new colors to selected artwork when you want to test different combinations and strengthen the visual result.

Select your artwork using the Selection tool.

Choose Edit > Edit Colors > Recolor Artwork, then choose Advanced Options.

Choose a swatch group from the Swatch Groups list, or choose a harmony rule option from the Harmony Rules dropdown to build a swatch group.

Note

After creating a swatch group, choose Edit to refine the colors and then choose Assign. When only a few selected-artwork colors need adjustment, choose the color to change and use the color sliders.

Turn on Recolor Art to preview artwork changes.

Use any of these actions to reassign colors to the current swatch group:

- To map a current color to another color, move it in the Current Colors column by dragging upward or downward until it sits beside the desired new color.
- When a row includes several colors and all should move together, drag the selector bar beside that row up or down.
- To connect a new color with a different current-color row, reposition it in the New column by dragging upward or downward.
- To add or remove a New column color, right-click in the list and choose Add New Color or Remove Color.
- To edit a color in the New column, double-click it and choose a color in the Color Picker.
- To keep a current-color row from being reassigned, select the arrow between the columns. Select the dash when the row should be included again.
- To keep one current color from being reassigned, choose the color, then choose the icon.
- To reassign colors randomly, select the Randomly change color order icon.
- To create another row in the Current Colors column, select the New Row icon.

To split or combine colors in the Current Colors row, use either action:

- To split colors into separate rows, select the color block to move and select the Separate colors into different rows icon.
- To combine colors into one row, Shift + click to select multiple colors, then select the Merge Colors into a row icon.

For changing tints or shades of new colors, select the triangle beside the new color and choose an option. Choose Apply To All when the same option should affect every new color in the swatch group. Tints and Shades and Hue Shift are available only when spot colors are not preserved.

Note

Tints and Shades and Hue Shift are available only when spot colors are not preserved.

Change new-color tints or shades through Apply To All in the Specify colorization method dropdown.

Use Apply To All from the Specify colorization method dropdown when adjusting tints or shades for new colors.

Select OK to recolor the artwork.

To stop the recolor operation, select Cancel, or deselect Recolor Artwork and select OK.

## View original colors in artworks

Find where original colors occur in Illustrator artwork while recoloring.

During recoloring, original colors are replaced by the new colors from the selected color group. When assigning replacements, it can help to see where each original color is used, especially in detailed artwork or artwork containing many colors.

Select the object in your artwork.

Choose Edit > Edit Colors > Recolor Artwork, then choose Advanced Options.

On the Assign tab of the Recolor Artwork dialog box, choose Click on colors above to find them in the artwork .

Locate the original colors used by different objects in the artwork.

Use the original-color locator to see where colors appear throughout the artwork.

In the Current Colors column, choose different colors to view where they appear in your artwork.

Note

The artboard shows the object using the selected color in full color, while the rest of the artwork is dimmed. To restore full color across the artwork, choose Click on colors above to find them in the artwork again.

## Limit colors in artworks

Reduce or control the number of colors used in Illustrator.

For artwork intended for different output media, you may need fewer colors, grayscale conversion, or restriction to a specific color library. The Recolor Artwork dialog box provides a straightforward way to lower the color count in artwork.

### Reduce colors with a preset

Using a preset is a fast way to reduce colors and constrain artwork to a chosen number of colors or to a swatch library.

Choose Edit > Edit Colors > Recolor Artwork, then choose Advanced Options.

Select an object in the artwork you want to recolor.

Choose Window > Color Guide, then choose Edit or Apply Colors .

On the Assign tab of the Recolor Artwork dialog box, choose a Preset from the Specifies a recoloring preset dropdown menu.

Tip

Turn on Recolor Art to see live artwork updates while assigning new colors to the existing ones. You can also choose Edit > Edit Colors > Recolor with Preset, then choose a preset option.

For Library, use Limits the swatch group to colors in a swatch library dropdown menu, then select OK.

Note

If colors should not be restricted to a swatch library, keep the Library selection set to None and select OK. The New column shows the number of colors chosen as the Preset, plus black. Those new colors come from the original artwork.

Select OK in the Recolor Artwork dialog box.

### Reduce colors with custom options

Open Edit > Edit Colors > Recolor Artwork, then choose Advanced Options.

Choose the object in the artwork whose colors need to change.

Open Window > Color Guide, then choose Edit or Apply Colors.

When you need to introduce other colors, use the Harmony Rules dropdown list on the Edit tab of the Recolor Artwork dialog box to choose a color group.

On the Assign tab, choose Color Reduction Options, set these options as needed, and choose OK:

- Preset: selects a preset color job, including the color count and the recommended settings for that job. After you choose a preset, changing another option switches the preset to Custom.
- Colors: sets how many new colors the existing colors are reduced into.
- Limit To Library: uses a swatch library as the source for all new colors.
- Sort: controls the ordering of original colors in the Current Colors column.

  - Exact: maps every current color to the specified new color.
  - Scale Tints: treats the darkest color as the base and turns lighter colors into tints. This option is selected by default.
  - Preserve Tints: for non-global colors, the darkest color becomes the base while lighter colors become tints. With spot or global colors, the tint from the current color is carried over to the new color.
  - Tints and Shades: replaces the current color with the specified new color based on average light and dark values.
  - Hue Shift: replaces the key color and adjusts the others by relative hue, saturation, and brightness.

- Combine Tints: places every tint of the same global color in one Current Colors row, even when the colors are not being reduced. Reserve this for selected art that contains Global or Spot color applied at tints below 100%. For the best outcome, pair it with the Preserve Tints colorization method.

Note

If Combine Tints is off, color reduction still combines tints of the same global color before combining different non-global colors.

- Preserve: controls whether White, Black, or Grays from the artwork remain unchanged in the final reduction. Preserved colors appear as excluded rows in the Current Colors column.

Choose the setting you want from the drop-down menu.

Use the drop-down menu to choose the required setting.

Choose OK in the Recolor Artwork dialog box.

## Edit an individual color in color groups

Edit one color inside a color group when you need a custom color palette for a smoother workflow.

Colors are linked by default when a color group is created from a harmony rule. In a linked color group, changing one color updates the other colors according to that harmony rule. To change one color without affecting the rest, detach the color markers from the harmony rule.

Open Window > Color Guide.

In the Color Guide panel, choose Edit Colors or Edit or Apply Colors, depending on whether artwork is currently selected.

Choose the color group to edit, then choose Edit in the Recolor Artwork dialog box. To work on color groups, open the Edit tab in the Recolor Artwork dialog box.

For color-group editing, use the Edit tab in the Recolor Artwork dialog box.

Choose Link Unlink harmony colors.

In color wheel view or color bar view, use any of these actions:

- Drag the color handle you want to edit while using the color wheel to set a new color.
- Select the color bar or color handle you want to change, then edit the color values manually.
- Open the Color Picker dialog box by double-clicking the color wheel. You can also right-click the color bar or handle and choose the Color Picker option to open that dialog box. In the Color Picker, choose a new color.
- To choose a new shade, right-click a color handle or color bar, then choose Select Shade.

Choose the Link Harmony colors icon to link the colors again, so the markers once more follow the newly defined harmony rule.
