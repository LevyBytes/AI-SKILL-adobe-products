## About brushes

Brushes in Adobe Illustrator let paths take on different styled appearances.

Illustrator provides several brush types for different effects:

- Calligraphic Brush: makes strokes centered on the path that resemble marks from a calligraphy pen. When applied with the Blob Brush tool, those strokes become filled shapes that merge with neighboring or overlapping same-color regions.
- Scatter Brush: places repeated object copies along the path; examples include a ladybug or a leaf.
- Art Brush: stretches a brush or object shape evenly along the path.
- Bristle Brush: creates strokes with the look of a natural bristle brush.
- Pattern Brush: builds repeating designs from separate tiles. Pattern brushes can use up to five tiles for sides, inner corner, outer corner, beginning, and end.

Brush strokes can be applied to paths that already exist, or the Paintbrush tool can draw paths while applying brush strokes in the same action.

## Brushes panel overview

Use the Brushes panel in Illustrator to manage brush choices.

Open the Brushes panel with Window > Brushes. For additional brush commands, use the Brushes panel menu icon.

Note

Drag a brush to another position when you need to reorder it, and arrange brushes within their own type groups. A calligraphic brush, however, cannot be placed in the scatter brush area.

## Draw paths with brush strokes

Use the Paintbrush tool when you want brush strokes to produce drawn paths.

Open the Brushes panel from Window > Brushes, or open a library through Window > Brush Libraries and choose the library you need.

Choose the Paintbrush tool.

Pick a brush in the Brushes panel or in the brush library.

On the artboard, drag to lay down the path.

For a closed path:

- Begin dragging, then press Alt (Windows) or Option (macOS).
- Let go of the mouse before releasing Alt (Windows) or Option (macOS) so the path closes.

For reshaping a path that already has a brush applied:

- Use the Selection tool to select the path.
- Choose the Paintbrush tool, then drag along the path until the shape matches what you need.

Open the Paintbrush tool settings by double-clicking the Paintbrush tool.

Tip

With the Blob Brush tool, calligraphic brushes turn strokes into filled shapes that combine with nearby or overlapping same-color areas.

## Add arrowheads to paths

Add arrowheads from the Stroke panel, then adjust their sizing and alignment.

Select the path that should receive an arrowhead.

Open the Stroke panel by choosing Window > Stroke.

From the Stroke panel menu, choose Show Options.

Use the Arrowheads dropdown menus to choose the arrowhead style for the path start point and end point. When the direction needs to be reversed, select Swap start and end arrowheads.

Note

To clear arrowheads from an object, choose None in the Arrowheads dropdown list.

Add and customize arrowheads in the Stroke panel.

Add and customize arrowheads in the Stroke panel.

In the Scale section, change the scale factor for the start arrowhead and end arrowhead when resizing is needed. Both values begin at 100%. To keep both scales identical, select Link start and end of arrowhead scales.

In the Align section, set how the arrowhead sits on the path by choosing Extend arrow tip beyond end of path or Place arrow tip at the end of path.

## Paintbrush tool options

### Adjust stroke behavior and appearance through the Paintbrush tool options.

Double-click the Paintbrush tool to display the Paintbrush Tool Options dialog box.

The Paintbrush Tool Options dialog box includes these controls:

Options

Functions

Fidelity

Determines the cursor or stylus movement distance required before Illustrator places another anchor point. The Fidelity slider runs from Accurate, which favors detailed paths, to Smooth, which produces cleaner curves.

Fill new brush strokes

Adds a fill to brush strokes. This is useful for closed paths because the enclosed area can be filled automatically while drawing.

Keep Selected

Keeps the newly drawn path selected after it is created.

Edit Selected Paths

Lets the Paintbrush tool reshape paths that are already selected.

Within

Defines how near the cursor or stylus must be to a selected path before the Paintbrush tool can edit it. The slider is available after Edit Selected Paths is selected.

## Create brushes

Make custom brushes for personalized strokes and textures in your artwork.

Your own artwork can become calligraphic, scatter, art, pattern, or bristle brushes. Before making a custom brush, prepare the artwork so it is compatible. Do not include unsupported content such as gradients, blends, brush strokes, mesh objects, bitmap images, graphs, placed files, or masks. For art brushes or pattern brushes, outline any text first.

Build the artwork that will become the brush. For scatter brushes and art brushes, select all of that artwork.

Open the Brushes panel from Window > Brushes.

Select the artwork, then use the New Brush icon in the Brushes panel.

Choose the brush type you want, then select OK.

In the brush options dialog box, add a name, configure the brush settings you want, and select OK. Brushes saved in the Brushes panel are tied to the active file only, so each Illustrator file carries its own Brushes panel contents.

Note

To limit visible seams in pattern brushes, disable Anti-aliased Artwork under Edit > Preferences > General (Windows) or Illustrator > Preferences > General (macOS).

## Create dotted or dashed lines

Use the Stroke panel to make dotted or dashed lines with custom dash lengths and gaps.

Select the artwork object, then choose Stroke in panels.

Open the Stroke panel from Window > Stroke.

Turn on dash controls by selecting the Dashed Line checkbox.

For dash behavior at corners and path ends, choose one of these options:

- Preserve exact dash and gap lengths: leaves the entered dash and gap measurements alone, with no corner or path-end fitting.
- Align dashes to corners and path ends, adjusting lengths to fit: changes the pattern so dashes at corners and path ends look regular and controlled.

Enable Dashed Line to customize dash patterns and alignment on corners and path ends.

Enable Dashed Line to customize dash patterns and alignment on corners and path ends.

Enter dash and gap values to define the repeating dash sequence.

Note

After a dash pattern is set, Illustrator repeats the entered values automatically, so every text box does not need to be completed.

Open the Brushes panel to modify your strokes.

Configure the brush options in the dialog box that opens, then select OK.

When the brush is already applied in the document, follow the onscreen instructions and choose one of these:

- Leave Strokes: keeps current strokes as they are and uses the edits only for new strokes.

Double-click the brush in the Brushes panel.

With the Direct Selection tool, select the artwork, then Alt-drag (Windows) or Option-drag (macOS) the revised brush onto the original brush in the Brushes panel.

Tip

To edit a brushed path without changing the associated brush, select the path and Options of Selected Object.

## Change the caps or joins of a line

Change stroke cap and join styles from the Stroke panel.

A Cap is the endpoint of an open line; a join is the point where a straight line changes direction or turns a corner. To alter a line's caps and corners, adjust the stroke attributes on the object.

Open the Stroke panel with Window > Stroke.

Select the object in the artwork.

In the Stroke panel, choose Show Options from the Stroke panel menu .

To change caps, choose from these options:

- Butt Cap: makes stroked lines end squarely.
- Round Cap: gives stroked lines semicircular ends.
- Projecting Cap: creates squared line ends that extend by half the line width beyond the line endpoint. With this option, the line weight extends evenly in every direction around the line.

To change joins, choose from these options:

- Miter Join: creates pointed corners on stroked lines. Enter a Limit between 1 and 500.
- Round Join: creates rounded corners on stroked lines.
- Bevel Join: creates squared corners on stroked lines.
