# Proofread Translate Rephrase Text

> Adobe Illustrator reference. Original prose; identifiers preserved verbatim.

Rewrite in Illustrator can generate, rephrase, proofread, translate, or resize text so it fits layouts.

Use Rewrite to create and refine text in Illustrator. It can produce marketing-copy variations, rephrase selected text, proofread grammar and spelling, translate content into supported languages, and resize text for a text box or layout.

Note

Rewrite workflows do not use generative credits, except Fit text, which uses 1 credit per generation.

## Generate or Rewrite selected text

Create an empty text box, or select a text box that contains Lorem Ipsum text.

Choose Type > Rewrite.

Other Rewrite access points are the right-click menu and the Quick Actions section of the Properties panel.

In the Contextual Task Bar that appears, choose Rewrite from the dropdown options.

Use Rewrite to create alternate wording that fits the tone and style of an invitation design.

Use Rewrite to create alternate wording that fits the tone and style of an invitation design.

In the prompt field, enter a prompt as needed to generate text. Leave the prompt field blank to automatically rephrase the selected text.

Tip

For better accuracy and layout fit, keep prompts short and specific.

Choose Generate.

In the Properties panel, review the generated variations, then choose one to replace the original text.

Choose Reset to restore the original text if needed.

Note

Rewrite does not use the surrounding artwork as context when it generates text.

## Translate text

Select a text box that contains text.

Choose Type > Rewrite.

In the Contextual Task Bar that appears, choose Translate.

Translate selected text into another language while keeping the original styling and formatting intact.

Translate selected text into another language while keeping the original styling and formatting intact.

Pick the target language.

Choose Generate.

In the Properties panel, review the generated variations, then choose one to replace the original text.

Choose Reset to restore the original text if needed.

Translated text uses the default font for the selected language.

## Proofread text

Choose a text box that already has text.

Open Type > Rewrite.

When the Contextual Task Bar appears, choose Proofread.

Inspect the proofread result and apply it.

Use Reset to return to the original text when needed.

Note

Translation, proofreading, and rephrasing workflows accept up to 4096 input characters and are limited to languages available in Illustrator.

## Resize text to fit layouts

Choose a text box that already has text.

Open Type > Rewrite.

When the Contextual Task Bar appears, choose Fit Text.

Use Generate to make the text shorter or longer so it fits the selected text box or layout more closely.

Check the revised text in the layout and apply it as needed.

Use Reset to return to the original text when needed.

### Give feedback on generated variations

After you inspect generated variations for your creations in the Properties panel, these controls let you send feedback:

- Good output: Upvote a variation you liked, then add detailed comments in the form that opens.
- Poor output: Downvote a variation you did not like, then add detailed comments in the form that opens.
