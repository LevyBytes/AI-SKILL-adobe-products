## About fills and strokes

Fills and strokes determine how objects look in Adobe Illustrator.

Illustrator gives you two main ways to paint artwork:

- Add a Fill, a Stroke, or both across a whole object.
- Turn the object into a Live Paint group, then apply a Fill and a Stroke to the individual path edges and faces inside that group.

### Fill

Inside an object, the Fill supplies color, a gradient, or a pattern. It gives vector shapes visual weight, depth, and texture. Apply a Fill to open paths, closed paths, and faces in the Live Paint group.

Fill can be one of three types:

- Solid: lays one consistent color across the shape.
- Gradient: blends gradually between two or more colors.
- Pattern: covers the shape with a repeating design or texture.

### Stroke

The Stroke provides the visible outline for an object or path. It marks the edge or contour, and it can either complement the Fill or contrast with it. Apply Stroke to open paths, closed paths, and edges of Live Paint groups. To tailor the Stroke, adjust Weight, Cap, Corner, and Align Stroke.

## Convert strokes to compound paths

Convert strokes into compound paths.

Turning a Stroke into a Compound Path makes the Stroke outline editable. For example, the Stroke can use a varied width or be divided into pieces.

Choose the object with the Selection tool from the Tools panel.

Choose Object > Path > Outline Stroke.

Note

The Compound Path that results remains grouped with the filled object.

With the outlined Stroke selected, choose Object > Compound Path > Make.

## Remove fills or strokes

## Select objects with same fill and stroke

Find objects that share Fill and Stroke attributes in Illustrator.

Illustrator can select matching objects by attributes such as Fill color, Stroke color, and Stroke weight.

### Select objects with same Fill and Stroke

With the Selection tool, choose one of the objects.

Choose Select > Same > Fill & Stroke.

### Select objects with same Fill or Stroke color

Choose an object that uses the Fill or Stroke color to match.

Choose Select > Same > Fill Color or Stroke Color.

### Select objects with same Stroke Weight

Choose an object with the Stroke Weight you want to match.

Choose Select > Same > Stroke Weight.

Illustrator then selects every other object in the document whose Stroke Weight matches the selected object.

Note

Within a Live Paint group, Select > Same > Fill Color, Stroke Color, and Stroke Weight can be used after you select a face or edge with the Live Paint Selection tool. Other Select > Same commands are unavailable inside Live Paint groups. A single same-object selection also cannot span both inside and outside a Live Paint group at the same time.

## Merge paths using the Blob Brush tool

Use the Blob Brush tool when paths need to be merged.

With the Blob Brush tool, you draw filled shapes; matching-color shapes that overlap or touch can combine.

Using the Selection tool, choose the existing path that should receive the new path.

Select Window > Appearance.

In the Appearance panel, open More options . Clear New Art Has Basic Appearance.

Tip

With that setting off, artwork made next with the Blob Brush tool takes on the selected path's appearance.

Choose the Blob Brush tool and confirm that its appearance matches the artwork already selected.

Draw new paths so they cross into the artwork.

Note

When paths fail to combine, check that the Blob Brush tool attributes match the current path attributes, and verify that neither path uses a Stroke.

### Blob Brush tool guidelines

Use the Blob Brush tool with these rules in mind:

- Paths can merge only when they sit next to each other in the stacking order.
- For Blob Brush paths to combine with existing artwork, the artwork must use the same Fill color and have no Stroke, because the Blob Brush tool produces paths with a Fill and no Stroke.
- Before drawing, apply attributes such as Effects or Transparency to the Blob Brush tool by selecting the brush and setting those attributes in the Appearance panel.
- When merging paths produced by other tools, first confirm that the current artwork has no Stroke. Next, configure the Blob Brush tool with the same Fill color, then draw a fresh path that crosses every path you intend to combine.
- If the goal is to merge new paths into the uppermost matching path the brush encounters, draw those paths with the Blob Brush tool. When a new path contacts several matching paths in one group or layer, every intersecting path is combined.

## About Live Paint

Live Paint in Adobe Illustrator lets path segments and enclosed regions be painted in a way that feels closer to working on paper or canvas.

After objects become a Live Paint group, their colors can be assigned freely. Each path segment can carry its own stroke color, and each enclosed region can receive a separate color, pattern, or gradient, even when the boundary is not fully closed.

Live Paint gives colored drawing a more direct workflow. You still use Illustrator's full vector drawing toolset, while the paths behave as if they lie on one flat surface. No path sits in front of another or behind another for paint assignment. Instead, paths split the drawing surface into colorable regions, whether a region is bounded by one path or by segments from several paths. Painting a Live Paint group is similar to filling a coloring book, or to adding watercolor after first sketching with pencil.

### Edges and faces of Live Paint groups

Within a Live Paint group, the paintable elements are edges and faces. An edge is the section of a path between intersection points with other paths. A face is a region enclosed by at least one edge. Edges can be stroked, and faces can be filled.

For instance, turning a circle crossed by a line into a Live Paint group makes that line an edge that splits the circle into two faces. With the Live Paint Bucket tool, you can fill each face separately and give each edge its own stroke color.

### Path editing within Live Paint groups

Paths inside a Live Paint group stay completely editable. After you reshape or move a path, previously assigned colors do not remain fixed in place as they would in natural-media artwork or image-editing applications. Illustrator instead applies those colors again to the new regions created by the changed paths.

### Live Paint limitations

In a Live Paint group, fill and paint attributes belong to faces and edges rather than to the underlying paths that create them, unlike standard Illustrator objects. As a result, some commands and features behave differently inside Live Paint groups, and others cannot be used on those paths.

## Create Live Paint groups

Create Live Paint groups when you want to paint object edges and faces.

After objects are converted into a Live Paint group, their edges and faces can be painted independently.

Some objects, including text and raster images, cannot become a Live Paint group directly. Objects with complex appearance attributes, including brushes, effects, transparency, and stroke alignment options, may lose some detail when converted straight into Live Paint. To keep most complex attributes while using text or raster images, convert those objects into regular paths first, then make the Live Paint group.

After objects are made into a Live Paint group, they cannot be directly ungrouped back to the exact original state. You can expand the Live Paint group into separate components; releasing it instead returns the original objects, which have no fill and a 0.5 pt black stroke.

### Create a Live Paint group

With the Selection tool, select one or more paths, compound paths, or a mix of both.

Choose Object > Live Paint > Make to build a Live Paint group.

Live Paint groups can also be made with the Live Paint Bucket tool.

### Convert objects to regular paths and create a Live Paint group

For items that cannot be converted directly into a Live Paint group, and for objects carrying complex appearance attributes, first change them into regular paths; after that, create the Live Paint group.

Select text, raster images, or objects with complex appearance attributes, then use the applicable command to convert them into regular paths:

- Text: choose Type > Create Outlines.
- Raster images: select them, then choose Object > Image Trace > Make.
- Objects with complex appearance attributes: choose Object > Expand.

Choose Object > Live Paint > Make to build a Live Paint group.

### Expand or release a Live Paint group

Expanding a Live Group changes it into separate regular paths with fills and strokes while retaining how the painted faces and edges look. If you release a Live Paint group instead, the original objects come back with no fill and a black stroke set to 0.5 point.

Use the Selection tool to select the Live Paint group.

Choose the action that matches the result you need:

- For expansion, choose Object > Live Paint > Expand.
- For release, choose Object > Live Paint > Release.

## Modify Live Paint groups

Select and edit Live Paint groups along with their individual components.

### Choose the appropriate selection tool

These tools handle selection and editing for a Live Paint group and its pieces:

- Selection tool: selects the complete Live Paint group.
- Direct Selection tool: targets one or more original paths within a Live Paint group.
- Live Paint Selection tool: targets one or more faces and edges.

In complex artwork, isolate a Live Paint group so the exact path, face, or edge is easier to target.

### Modify Live Paint group components

Editing a path in a Live Paint group makes Illustrator color the changed or newly created faces and edges with the group's existing fills and strokes. If that result is not the one you need, apply the preferred colors again with the Live Paint Bucket tool.

Deleting paths or edges lets the fill spread through any face that becomes larger. For example, removing a path that splits a circle in half causes the circle to receive one of the fills that was already inside it. You can influence the outcome in some cases. Before removing a divider path in a circle, for example, move it so the fill to keep occupies more area than the fill to discard.

### Modify faces and edges

Select the Live Paint Selection tool.

Move the tool over a face or edge in the Live Paint group. These cues indicate which item is targeted:

- For a focused face, its surrounding edges show a thick highlight color, and the pointer changes into a filled-bucket indicator.
- For a focused edge, the edge appears with a dull highlight color, and the pointer changes to the edge-painting indicator.

Select faces and edges as needed:

- Click a face or edge to select it.
- Drag a marquee around multiple faces and edges to select them. Faces or edges that the marquee only partly encloses are included too.
- Double-click one face to include every connected face unless a painted edge divides them.
- Triple-click a face or edge to capture matching-fill faces or matching-stroke edges. Another method is to click once, choose Select > Same, then choose Fill Color, Stroke Color, or Stroke Weight.
- Shift-click, or Shift-drag a marquee around items, to add them to or remove them from the current selection.

Apply or remove color according to the selected items:

- To color selected faces, choose a Fill color.
- To color selected edges, choose a Stroke color.
- To remove color from selected faces, press Delete.
- To remove selected edges, press Delete.
- To remove selected faces and edges, press Delete.

Tip

Store fill and stroke colors used by Live Paint groups in the Swatches panel. If an edit removes a color that should remain available, choose its swatch and use the Live Paint Bucket tool to apply that fill or stroke again.

### Add paths to a Live Paint group

After additional paths are added to a Live Paint group, the new faces and edges they create can receive fills and strokes.

Shift-select the Live Paint group together with the paths you want to add.

Choose Object > Live Paint > Merge.

You can also choose Merge Live Paint from the Control panel.

Another method uses isolation mode: double-click the Live Paint group, draw paths, then press Esc so those paths join the group. The Layers panel can also move paths into that Live Paint group.

Note

Similar or identical paths may not line up exactly when one is inside a Live Paint group and the other is outside it.

### Adjust or resize paths in a Live Paint group

With the Direct Selection tool, select the path to adjust or select one or more paths to resize.

Do one of the following:

- To change the path shape, drag a path segment or an anchor point.
- To resize the paths, use the Selection tool and drag the bounding-box points.

You can also double-click the Live Paint group with the Selection tool to enter isolation mode, then resize paths with the Selection tool or reshape them with the Direct Selection tool.

## Find and close gaps in Live Paint groups

Detect, control, and close gaps in Live Paint groups.

Gaps are narrow openings between paths. When paint passes through into faces you did not mean to color, the artwork probably contains a gap. You can close it by drawing a new path, by editing paths that already exist, or by changing the Live Paint group's gap options. When Live Paint groups that use different gap settings are merged, Adobe Illustrator applies these rules:

- If every selected group has Gap Detection off, Illustrator closes gaps and enables Gap Detection with Paint stops at set to Small Gaps.
- If every selected group uses the same Gap Detection setting, Illustrator closes gaps and keeps that gap setting.
- With mixed settings, Illustrator keeps the bottommost group's setting only when that group's Gap Detection is on. If it is off, Gap Detection is enabled and Paint stops at uses Small Gaps by default.

To prevent gaps in Live Paint artwork, overdraw paths so they extend beyond one another. Afterward, delete the resulting extra edges or set their Stroke to None.

### Highlight gaps in a Live Paint group

Select the Live Paint group in the artwork.

Choose View > Show Live Paint Gaps.

Based on the gap options set for the selected Live Paint group, this command marks the group's gaps.

### Set Live Paint gap options

Choose Object > Live Paint > Gap Options.

In the Gap Options dialog box, provide any of these settings:

- Paint stops at: defines the gap size that blocks paint from flowing through. Custom Gaps lets you enter a custom Paint stops at gap size.

- Gap Preview Color: chooses the color used to preview gaps in Live Paint groups. Pick a color from the dropdown menu, or use the swatch beside Gap Preview Color to define a custom color.
- Close gaps with paths: when enabled, Illustrator adds unpainted paths inside the Live Paint group to close gaps instead of only blocking paint flow through them. Because those added paths have no paint, the gaps can still look visible even after closure.
- Preview: shows the gaps currently detected in Live Paint groups as colored lines, using the preview color you chose.

Note

Turning on Gap Detection can make Illustrator slower with large, complex Live Paint groups. In that situation, choose Close gaps with paths to help restore speed.

## Paint with the Live Paint Bucket tool

Use the Live Paint Bucket tool to apply paint to faces and edges.

### Paint faces and edges

With the Live Paint Bucket tool, the current fill and stroke colors can be applied to Live Paint group faces and edges.

Select the Live Paint Bucket tool from the toolbar, or press K.

Choose the Fill or Stroke color to apply. When you pick a color in the Control panel, the Appearance section of the Properties panel, or the Swatches panel, the pointer displays three colored squares. The active color appears in the center, with adjacent colors on the left and right. Press the left or right arrow key to use one of those adjacent colors.

Move the mouse pointer over a face or edge:

- Over a face, Illustrator shows a thick colored highlight around that face, and the pointer becomes a filled paint bucket.
- Over an edge, Illustrator shows a thin colored highlight on that edge, and the pointer becomes a brush.

To paint faces, use one of these actions:

- Click a face to paint it.
- Drag across several faces to paint them together.
- Double-click a face to flood paint through unstroked edges into neighboring faces.
- Triple-click the focused face to paint all faces matching its color.

Tip

For Eyedropper sampling, use Option-click (macOS) on the desired fill or stroke; use Alt-click (Windows) for the same action.

For edge painting, double-click the Live Paint Bucket tool in the toolbar, then select Paint Strokes. As a temporary alternative, hold Shift while hovering over the Live Paint group to toggle Paint Strokes.

Then use any of these actions:

- Click an edge to stroke it.
- Drag across several edges to stroke them at the same time.
- Double-click an edge to flood paint from that edge to all connected edges with the same color.
- Triple-click an edge to paint every edge with that same color.

Note

Press Shift to quickly switch between painting only strokes and painting only fills. The Live Paint Bucket Options dialog box also lets you set these behaviors. If both Paint Fills and Paint Strokes are currently selected, pressing Shift changes the mode to Paint Fills only. This is useful when filling a small face surrounded by stroked edges.

### Live Paint Bucket tool options

Live Paint Bucket tool options control how the tool behaves. It can be configured to paint fills only, strokes only, or both fills and strokes. The options also control how faces and edges are highlighted as the pointer passes over them. Double-click the Live Paint Bucket tool to view these settings.
