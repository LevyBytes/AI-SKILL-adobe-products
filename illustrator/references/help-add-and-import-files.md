## New Document dialog overview

- Create documents from presets and adjust preset settings before opening them.
- Access Adobe Stock templates and create documents with them.
- Open files, templates, and documents recently viewed in the Recents tab.
- Open templates downloaded from Adobe Stock in the Saved tab.

### Use presets and templates

Presets and templates can be used and customized for design categories and devices including mobile, web, print, social media, and branding.

Blank Document Presets provide predefined dimensions and settings for design categories and devices, and they can be customized before you create a new document.

Templates provide rich, reusable, inspiring content for documents. Adobe Stock templates can be downloaded in Illustrator to quickly create documents that share settings plus design elements. In Illustrator, templates open as .ai files and usually contain several artboards. Illustrator also includes blank templates with ready-made sizes and setup values for common deliverables, such as business cards or brochures.

## Create and save custom document presets

Learn how to create, customize, and save document presets for later use.

Customize settings in the Preset Details pane before opening a document from a preset.

Open the New Document window with File > New.

In the Preset Details pane, enter a document name.

Specify these options for the selected preset:

- Width and Height: Specify the artboard size. Select the unit from the dropdown menu.
- Orientation: Set the document page orientation: Landscape or Portrait.
- Artboard: Set the number of artboards in the document.
- Bleed: Set the bleed position along each artboard side. Use the link icon when different side values are needed.
- Color Mode: Set a document color mode: RGB Color or CMYK Color.
- Raster Effects: Set the raster effects resolution for the document.
  - Default option shows artwork created in the document in full-color vector view. Curves remain smooth when you zoom in or out.
  - Pixel option shows artwork with a rasterized appearance.
  - Overprint option shows an ink preview that approximates blending, transparency, and overprinting in color-separated output.

Select More Settings for additional preset changes.

Use the View menu to change Preview mode while working on the file.

Select the download icon, then choose Save Preset for future use.

Select Create to open a document using the preset settings.

To use saved presets, select the Saved category tab in the New Document window.

## Create files with large canvases

Learn how Illustrator large canvas files support large-scale artwork.

Adobe Illustrator supports large artwork on a spacious 100x canvas that measures 2270 x 2270 inches. This large workspace keeps details clear while you create large-scale artwork.

Use a large canvas for artwork that exceeds the default canvas size, such as billboards, posters, or high-resolution exports.

Select File > New to open the New Document dialog box.

In the New Document dialog box, enter a width or height above 227 inches. For example, set Width to 500 inches and Height to 500 inches to create a large canvas for those dimensions.

Entering dimensions beyond the default size creates a large canvas. Illustrator displays a warning sign.

Entering dimensions beyond the default size creates a large canvas. Illustrator displays a warning sign. Note

Illustrator automatically creates a large canvas if any artboard is larger than 227 inches or if too many artboards exist to fit within the default canvas.

Adjust units, color mode, artboards, and other settings, then select Create. Illustrator automatically generates the new large canvas document.

Save or export documents that contain large-scale artwork. For large-document export, Illustrator currently supports only PDF, PNG, JPEG, PS, TIFF, and SVG formats.

Note

Large canvas files have zoom limits from 0.313% to 6,400% and may not support some features, such as Slices and Save for Web.

## Rotate canvas view

Turn the Illustrator canvas view to any angle while building logos, typography, packaging designs, or illustrations that are easier to edit from angled viewpoints.

In Illustrator, the Rotate View tool changes the canvas orientation so you can evaluate and edit artwork from another perspective.

Artboards and visible objects rotate along with the canvas view, which lets you keep editing comfortably from the chosen angle.

### Rotate the canvas using the Rotate View tool

Hold down the Hand tool, then choose the Rotate View tool, or press Shift + H.

Drag on any part of the canvas to set a different canvas orientation.

After rotating the canvas view, use the widget that appears to move between angles.

Rotate canvas view using the Rotate View tool.

For an exact rotation, choose the angle in the Rotate View dropdown menu in the status bar, or use View > Roate View.

To match the canvas view to rotated artwork, select the object or text, then choose View > Rotate View to Selection.

To store the rotated canvas view:

- Select View > New View.
- Enter a name for the view preset in the dialog box, then select OK.

When you need that preset again, open View and choose the saved preset from the menu.

### Rotate the canvas using a trackpad

Place the cursor anywhere on the canvas to define the reference point.

On the trackpad, use a two-finger rotation gesture; the cursor position acts as the pivot for the view.

Rotate the canvas using the two-finger rotation gesture.

To keep the rotated canvas view:

- Select View > New View.
- Enter a name for the view preset in the dialog box, then select OK.

When you want to reuse the preset, open View and choose the saved preset from the menu.

Tip

You can also hold Space + Shift while dragging to switch temporarily from the current tool to the Rotate View tool.

### Reset the rotated canvas

To bring the view back to its default angle, choose View > Reset Rotate View, or press Shift + Cmd + 1 (macOS) or Shift + Ctrl + 1 (Windows).

When another tool or feature is active, press Esc twice to reset the canvas.

Press Esc twice to leave the active tool or feature and return the canvas rotation to its default state.

Press Esc twice to leave the active tool or feature and return the canvas rotation to its default state.

## Organize, share, and collaborate using Projects

Use Projects to set up shared spaces for organizing files and collaborating with others.

Projects gives you a collaborative workspace in Adobe Home, Adobe Express, and Creative Cloud apps such as Adobe Illustrator and Adobe Photoshop. Use it to group creative work, control permissions, and simplify sharing.

### Create a project and invite collaborators

From the Illustrator homescreen's left pane, select Projects.

Projects can create shared spaces that are available across Creative Cloud apps.

Projects can create shared spaces that are available across Creative Cloud apps.

Select Create project, then enter a project name.

In Add people or groups, enter the names or email IDs for the people or groups who should work with you.

Choose the project permissions:

- Can comment: grants file viewing and feedback access without sharing access.
- Can edit: grants access to create, change, share, and organize files.

To notify collaborators, add an optional note in Message, then select Invite.

Select the control in the upper-right corner of the screen, then use any needed action:

- Share: Adds more people or groups to the project.
- Copy link: Generates a shareable project link.
- Rename: Changes the project name.
- Leave: Removes you from the project.
- Delete: Removes the project.

### Add and manage Illustrator cloud documents in a project

In the left pane of the Illustrator homescreen, select Projects, then select the target project.

Select Add, then select Create folder if you need a subfolder.

Select Add, then select Move files to move existing cloud documents into the project.

Note

Local files or assets cannot be uploaded to a project.

In Your files, choose the documents to add, then select Move. After the move, each document automatically uses the project's permissions.

Hover over a document, select the control, then use any needed action:

- Share: Adds people or groups directly to the document. Users with project-level permissions inherit the document permissions automatically.
- Copy link: Generates a shareable document link.
- Rename: Changes the document name.
- Duplicate: Makes a copy of the document.
- Move: Sends the document to Your files or to another project.
- Report abuse: Flags the document for possible violations.
- Delete: Removes the document.

Import PDF files into Adobe Illustrator and use the PDF import options when opening multipage files.

In Illustrator, use File > Open.

From the Open dialog box, choose one or more PDF files, then select Open. For a PDF with multiple pages, Illustrator displays the PDF Import Options dialog box.

In the PDF Import Options dialog box, choose one of these options:

- To open the page currently shown in the preview, select Previewed Page.
- To open chosen pages, select Range and enter the page numbers.
- To open every page, select All.

Adjust the PDF Import Options dialog box settings to control how Illustrator brings in PDF pages.

A. Preview PDF pages B. Specify page number to view thumbnail C. Import a range of pages D. Import all pages E. Import as a linked file

## Place Adobe PDF files

Place PDF files in Adobe Illustrator when you need control over page cropping, linking, and how imported pages appear in the artwork.

Choose File > Place, then enable Show Import Options in the file window.

Pick the PDF file on your device, then choose Place. Illustrator opens the Place PDF dialog box.

In the Place PDF dialog box, choose from the Crop to dropdown menu:

- Bounding Box: Limits the crop to the tightest area that contains all artwork on the page.
- Art: Places the PDF inside the author-defined rectangle for placeable artwork, such as clip art.
- Crop: Uses the page area that Adobe Acrobat displays or prints.
- Trim: Uses trim marks, when present, to indicate where the final printed page will be cut.
- Bleed: Keeps the bleed area in the crop so printed output can align correctly.

Note

Printed pages can still contain page marks outside the bleed area.

- Media: Shows the PDF page at its original paper size, including page marks.

The Crop to choices determine how PDF page content is cropped and positioned.

The Crop to choices determine how PDF page content is cropped and positioned.

Use the navigation controls in the Place PDF dialog box to choose which PDF page to place.

Select Preview to see the selected PDF page update live before you place it.

Choose OK to open the file for editing.

## Import AutoCAD files

Import DWG and DXF artwork into Adobe Illustrator when CAD drawings need to be edited or incorporated into a design.

Note

Illustrator can import and open AutoCAD files from version 2.5 through 2007.

Illustrator supports most AutoCAD content: text objects, raster, region objects, splines, external references, paths, shapes, and 3D objects.

For an AutoCAD file that contains external references, the DXF/DWG Options dialog box lets you place those references accurately on the Illustrator canvas.

In Illustrator, choose File > Open.

Choose an AutoCAD file in DWG or DXF format, then choose Open. The DXF/DWG Options dialog box appears.

In the DWG/DXF Options dialog box, configure these choices:

- Original Size: Brings in the file at the scale used in AutoCAD and keeps its real dimensions.
- Scale to Fit Artboard: Resizes the drawing so it fits within the Illustrator artboard.
- Scale by: Determines the imported DXF or DWG file size.
- Scale: Lets you enter the scale factor manually.
- Unit(s): Defines the measurement unit used to interpret the file geometry.
- Scale Lineweights: Changes stroke, or line weight, thickness according to the scaling applied during import.
- Layout: Chooses between the main drawing model and layout view for import.
- Center artwork: Places the imported content in the center of the artboard.
- Merge Layers: Combines the layers into one layer.

Use Scale, Units, and Layout in the DXF/DWG Options dialog box to control how the file is interpreted.

Use Scale, Units, and Layout in the DXF/DWG Options dialog box to control how the file is interpreted.

Choose OK to open the file for editing.

## Import monotone, duotone, and tritone images from Adobe PDF files

Bring non-native art with monotone, duotone, and tritone images from Adobe PDF files into Illustrator.

Artwork imported from an Adobe PDF file can contain data that Illustrator cannot create directly. That data is called non-native art, and examples include monotone, duotone, and tritone images. Preserving non-native art, including linked or embedded PDF content, helps Illustrator keep spot color information available for color separations.

Choose File > Place.

Pick a PDF whose image content is tritone, duotone, or monotone.

In the Place dialog box:

- Select Link when the original data should remain preserved.
- Select Show Import Options when page selection needs to be controlled.

After choosing Place, put the file or image on the artboard.

In the Layers panel, choose the Illustrator object named <Non-Native Art>.

Choose Object > Rasterize to turn non-native art into an editable Illustrator object.

To turn Illustrator artwork back into non-native artwork, choose Object > Flatten Transparency.

## Import DCS files

Use DCS files in print layouts when high-end, pre-separated raster images with spot colors or CMYK separations are required.

Desktop Color Separation (DCS) is one variant of the standard EPS format.

- DCS 1.0 handles only CMYK images.
- DCS 2.0 can include multiple spot colors and multichannel CMYK; linked files show those spot colors in the Swatches panel.
- Illustrator detects Photoshop-created clipping paths in DCS 1.0 and 2.0 files.

In Adobe Illustrator, choose File > Open, then pick the local DCS file.

Caution

DCS files can be linked in Illustrator, but they cannot be opened or embedded. For reliable output, use DCS only in workflows where the file stays linked and is sent through a print Raster Image Processor (RIP) that supports separations.

To inspect DCS transparency interactions, choose Window > Links. In the Links panel, open Panel Options from the Links panel menu, then enable Show DCS Transparency Interactions.
