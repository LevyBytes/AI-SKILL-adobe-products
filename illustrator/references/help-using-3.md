## Creative Cloud Libraries in Illustrator

### About Creative Cloud Libraries

A Creative Cloud Library is a design-asset collection. You can add several categories of assets to one. In Adobe Illustrator, supported asset types include Colors, Color Themes, Character Styles, Graphics, and Text. Those categories define what Illustrator can store there.

Try it in the app Get familiar with Creative Cloud Libraries in a few quick steps.

Open Illustrator

Creative Cloud Libraries make creative assets easier to organize, find, and use. For example, you might create a Creative Cloud Library that holds the components used most often for a particular project.

- Linked assets: Edit once - update everywhere. Linked assets let you use the newest iteration or version of an asset wherever it appears. When the library copy is edited, every project using that asset is updated. Adobe CreativeSync delivers the correct updated asset whenever assets are reused in desktop or mobile projects.

- Everywhere access. All the time. Your libraries are available inside Creative Cloud desktop apps such as Adobe Photoshop and Adobe Illustrator, plus Adobe InDesign, Adobe Premiere, and Adobe After Effects, along with Creative Cloud Assets and Adobe mobile apps such as Comp and Draw, even offline.

- Share and collaborate. Share library assets and components with other users. Let others work with items in shared libraries, or share those items onward. Common assets such as graphics, colors, character styling, and style guides help maintain project consistency.

- Adobe Stock integration The new Adobe Stock service gives access to 50 million high-quality, royalty-free images, videos, and graphics. From the Libraries panel in Illustrator, you can browse, license, and use images and graphics directly.

- Organize. Sort components into project- and workflow-specific libraries.

- The right asset. Every time. Use assets again in desktop and mobile projects without needing to worry about using an incorrect version or accidentally deleting or overwriting something.

- Easily save to Creative Cloud Libraries. Save assets straight into your libraries from Adobe Photoshop and Adobe Illustrator, from Adobe InDesign and Adobe Premiere, and from Adobe mobile apps and services such as Shape, Brush, Color, Comp, and Hue. Assets are converted automatically into formats suitable for desktop or mobile apps.

### What are linked assets?

In Illustrator CC 2014 and earlier, a graphic asset stopped being connected to its library source after you dragged it from the Libraries panel into an Illustrator document. Later edits to the original item in the library therefore did not update the document copy. Illustrator treated library graphics placed this way as 'unlinked assets'.

Beginning with Illustrator CC 2015, the linked assets feature makes a library item placed into a document a 'linked asset'. That linking behavior is the default. Whenever the asset in the Library changes, every linked copy used in Illustrator document(s) reflects that change.

To place graphics from a library as an unlinked asset, hold Alt/Option while dragging the item out of the Libraries panel.

Note

Assets used in Illustrator CC 2014 stay unlinked assets. To apply linking to one of those items, place it again by dragging it out of the Libraries panel in Illustrator CC 2015.

### Libraries panel overview

Illustrator shows Creative Cloud Libraries inside the Libraries panel. When you make libraries on multiple computers while signed in with the same Adobe ID, those libraries and their assets appear in the Libraries panel on each computer.

Open the Creative Cloud Library panel (Libraries panel) by choosing Window > Libraries. In the Libraries panel, you can:

- Create a Creative Cloud Library, inspect it, rename it, remove it, and use it.
- Add items to a Creative Cloud Library, remove items from it, revise them, and change their names.
- Sort Creative Cloud Library items and change how those items are viewed.

Choose one or more assets in a library.

### Collaborate with Creative Cloud users

Libraries can be shared with other users so they can view, edit, use, rename, move, or delete material inside the shared library. When another Creative Cloud subscriber shares a library with you, you may also pass that library on to other Creative Cloud users.

### Share a library

In the Libraries panel, choose a library from the drop-down menu.

Open the Libraries panel flyout menu, then choose Collaborate.

On the browser page that opens, enter an email address and choose the access level to grant:

- Can Edit: lets the invited user open the assets and change them.
- Can View: lets the invited user use Library assets only. Editing is unavailable. This access is read-only.

Include an optional message for the person receiving the library share.

Click Invite.

### Accept an invite

Open the Adobe Creative Cloud desktop app, then sign in with your Adobe ID credentials.

After someone shares a library with you, the Creative Cloud desktop app shows a notification. Open your notifications with the bell icon.

For each library collaboration invitation, click Accept.

### Cancel a share

In the Libraries panel, use the drop-down menu to choose the library that you no longer want to share.

Open the Libraries panel flyout menu, then choose Collaborate.

On the browser page that opens, remove every user name associated with the shared Creative Cloud Library.

### Leave a shared library

In the Libraries panel, use the drop-down menu to choose the library where you no longer want to collaborate.

Open the Libraries panel flyout menu, then click the Leave library option.

### Delete a shared library

Note: You can delete only a library that you own.

In the Libraries panel, use the drop-down menu to choose the library that you want to delete.

In the Libraries panel, click the flyout menu, then click the Delete library option.

Click Delete to confirm the action.

- Use the proxy to decide whether the color affects the object's fill properties or stroke properties.

### Graphics

Creative Cloud Library can hold objects and assets taken from your document. Assets stored there as a Graphic keep their vector form. When a Graphic from a Creative Cloud Library is reused in another Illustrator document, it remains vector artwork.

### Add a graphic

With an active Illustrator document open, use one of these methods:

- Drag and drop the art into the Libraries panel.
- Select the art, then select Add Elements in the Libraries panel. Next, choose Graphic from the drop-down menu.

In the Search Adobe Stock box in the Libraries panel, type a keyword for the image you need.

Select an image from the displayed results. You may buy the photo or save a preview of it to your current library. When a selected image is under the pointer, Illustrator displays the License and Save to downloads and Save Preview to Downloads icons. Choosing the license option opens a confirmation pop-up.

See Using Adobe Stock for more information about using Adobe Stock images with your libraries.

### Add and share text assets

You can add text objects from a document to Creative Cloud libraries, then share them with other users and across applications. A library text asset keeps the character/paragraph styles and other attributes it had when added. Those text assets can be reused from libraries in Illustrator or InDesign documents.

When a text objects includes effects and appearances, add it to the library as a graphics asset so those properties are preserved.

### Add a text asset

In an active Illustrator document, use one of these methods:

- After selecting a range of text or a text frame, select Add Elements in the Libraries panel. Next, pick Text.
- Highlight a text range or text frame. Open the text context menu, then choose Add To Library.
- Drag and drop the text object into the Libraries panel. By default, it is stored in the Creative Cloud library as a text asset.
- To store the text object as a graphics asset, drag the selection to the Libraries panel while holding Control (Windows) or Command (Mac).

### Use a text asset in a document

Use one of these methods:

- Open the context menu for a text asset in the Libraries panel, then choose Place Copy.
- To insert text without applying its styles, open the text asset context menu in the Libraries panel. Then choose Place Without Styles.
- Put the insertion point inside the text. In the Libraries panel, open the text asset context menu and choose Place Inline.
  - Add the text asset to a text object by clicking that object.
  - Place the text asset in its own text frame by clicking anywhere on the canvas.

Note

By default, Illustrator imports the text asset with its character/paragraph styles and attributes intact. For plain text without those associated styles, open the text asset context menu in the Libraries panel and choose Place Without Styles.

### Integration with InDesign

Text assets added to libraries are also visible in the Libraries panel in InDesign. You can work with and edit text assets in both applications. In List view within the Libraries panel, the icon beside the text asset identifies the application that created it.

See Rendition of shared text assets in Illustrator and InDesign for more information.

### Edit a text asset

Use these steps in the Libraries panel:

1. Open the context menu for the text asset, then choose Edit.
2. Change the component after it opens in an Illustrator document.
3. Save the document.

Alternatively, double-click the text asset to edit it in the application that created it.

The Creative Cloud Library receives the updated text asset, and its thumbnail refreshes automatically. The asset also updates in every location where it is used.

### Rename a text asset

In the Libraries panel, do the following:

- Open the context menu for the text asset, then choose Rename.
- Enter a new name for the image, then press Enter.

### Delete a text asset

In the Libraries panel, open the context menu for a text asset, then choose Delete.

- In the Libraries panel, open the context menu for an element, then select Find Similar.

## Composers for Asian scripts

Search Last updated on May 24, 2023

Illustrator supports Indic, Middle Eastern, and South East Asian languages. Documents can include text written in those languages. For many non-Western scripts, the additional Middle Eastern and South Asian Composer supplies the needed word shaping.

Note

Adobe applications do not always provide identical text features because each application may use a different text engine. Text feature behavior can also depend on the application's main purpose, such as image editing, page layout, illustration, and related workflows, so formatting, style, and editability preservation between applications may vary with the type treatments you apply.

South Eastern Asian (SEA) languages or scripts are not yet supported by every Adobe product. If you move SEA text from an Adobe app that supports SEA scripts to an application without that support, some or all text copy, formatting, and related information may be lost. In that situation, note the following:

- Before moving image files from Photoshop to other applications, you may need to flatten them.
- Before using text files from Adobe Illustrator in other applications, you may need to convert them to outlines.
- Moving converted text between applications can remove editability.

### Install relevant language and font packs (Windows)

On Windows, proper use of these languages requires installing the language and font packs for the language you plan to use.

For details, see Microsoft's Help documentation: Language Packs.

### Create documents using Asian languages

For a new document in a supported language:

1. Go to Edit > Preferences > Type.
2. Enable South East Asian Options or Show Indic Options.
3. Open your document.
4. Use the Type tool to create a type layer.
5. In the Character panel, set your Language to one of the new languages: Thai, Burmese, Lao, Sinhalese, or Khmer.
6. Set an appropriate font for the language you selected. For example, when Thai language is selected, choose Adobe Thai, Noto Sans Thai, or another Thai font.
7. Paste text written in the language you chose, or copy it in first. If a language-specific keyboard set-up is available, type the text directly.
