## Move live shapes

Reposition live shapes in Illustrator.

Hold the Rectangle tool to access other live-shape tools: Rounded Rectangle , Ellipse , Polygon , Shaper ,or, Star tool.

Drag the live shape's center point widget in the desired direction to move the shape.

Choose View > Show Bounding Box if the bounding box is hidden.

Note

To display the live shape's on-screen control widgets, choose Show Shape Widgets in the Control panel.

Precise live-shape scaling is available in the Transform panel. Open the panel by double-clicking any corner widget of the live shape, then edit the W and H values.

## Rotate live shapes

### Rotate live shapes in Illustrator.

Pick the Rectangle tool and hold it to choose other live-shape tools, including Rounded Rectangle , Ellipse , Polygon , Shaper ,or, Star tool.

Move the cursor near an anchor point until the rotate icon appears, then drag to turn the shape.

Choose View > Show Bounding Box if the Bounding box is hidden.

Note

To show the live shape's on-screen control widgets, enable Show Shape Widgets in the Control panel.

Use the Transform panel when you need exact rotation. To open the panel, use a double-click on any live-shape corner widget, then enter the rotation angle in the Rotate field.

## Scale live shapes

### Scale live shapes and use them in Adobe Illustrator projects.

Create a live shape by dragging with the Rectangle , Rounded Rectangle , Ellipse , Polygon , Shaper , or, Star tool. If it is not selected, select it with the Selection tool.

Resize the live shape by dragging the bounding-box handles.

Tip

For precise dimensions, use the Transform panel. Open it by double-clicking a corner widget on the live shape, then edit the W and H values.

## Change corner radius of live shapes

### Change a live shape's corner radius.

Choose the Rectangle tool from the toolbar to draw a rectangle, or hold it to choose additional live-shape tools: Rounded Rectangle , Ellipse , Polygon , Shaper ,or, Star tool.

Turn on View > Show Bounding Box, and in the Control panel set the on-screen control widgets to Show Shape Widgets so the number of sides on a live shape can be adjusted.

To change corners separately, choose the Direct Selection tool, then drag any corner widget. When the corner widgets reach their maximum rounding limit, the rounded-corner preview appears in red.

In the Corners dialog box, choose Corner, Radius, and Rounding styles, then apply the desired edits.

## Add or remove sides from stars

### Add sides to stars or remove them.

Choose the Star tool from the tool panel.

Click the intended location on the artboard to create the shape.

Before changing the side count on a star shape, make sure View > Show Bounding Box is enabled and the Control panel has on-screen control widgets set to Show Shape Widgets.

Tip

The side widget can set values from 3 through 20 by dragging. For values above 20, choose Shape in the Control panel; then either type a value in the field or drag the Star Slide Count slider.

Use the Star Properties icon to change these settings:

- Corner Types & Radius: controls sharp versus rounded star corners and applies roundness through a radius value.
- Side Count: defines how many points the star has by setting its side count. Move the slider to add or remove star sides.
- Ratio: controls spacing between inner points and outer points, which changes how sharp or full the star appears.

Use the Transform panel for more exact shape-property edits. Double-click any corner widget to open the Transform panel.

Double-click a corner widget to open the Transform dialog box; the drawn star shape's properties can be changed there.

Open the Transform dialog box by double-clicking a corner widget; use it to edit drawn star shape properties.

Note

To make the Transform panel appear every time a live shape is created, enable Show on Shape Creation in the panel menu. If the transform panel icon is not visible in panels, choose Window > Transform.

## Change inner and outer radii of stars

### Change star inner and outer radii.

Choose the Star tool from the tool panel.

Click the intended location on the artboard to create the shape.

In the Star dialog box, enter Radius 1, Radius 2, and Points, then click OK.

Before adjusting a star shape's inner or outer radius, ensure View > Show Bounding Box is enabled and the Control panel has on-screen control widgets set to Show Shape Widgets.

Drag the inner radius widget to change the star's inner points, or drag the outer radius widget to alter its outer points. For exact values, choose Shape in the Control panel, then set R1 for outer points and R2 for inner points.

Tip

Use the Properties or Transform panels for more precise shape-property changes.

## Add or remove sides from polygons

### Use onscreen control widgets to add polygon sides or remove them.

Choose the Polygon tool from the live shape tools in the tool panel.

Click the desired artboard location to create the shape.

With the Polygon shape selected on the artboard, enter Radius and Sides in the Polygon dialog box, then click OK.

To change the polygon side count, make sure View > Show Bounding Box is enabled and the Control panel has on-screen control widgets set to Show Shape Widgets.

Drag the side widget to alter the polygon side count. Dragging the side widget supports values from 3 through 11.

To use more than 11 sides, choose Shape in the Control panel and either type a value in the field or drag the Polygon Slide Count slider.

Note

Control, Properties, and Transform panels also provide more precise shape-property adjustments. To open the Transform panel, double-click any corner widget.

Use the Anchor Point and Smooth tools in Illustrator to reshape corners, clean up jagged paths, and build flowing curves.

Paths can be refined in Illustrator with the Anchor Point and Smooth tools. The Anchor Point tool converts or adjusts anchor points, for example turning a corner into a curve. The Smooth tool reduces path irregularities, including rough or uneven curves.

Choose the Anchor Point tool.

## Convert anchor points on a path

Convert anchor points between smooth and corner forms when refining curves or shaping paths precisely.

In Adobe Illustrator, anchor points define path shapes and may be either smooth or corner points. Smooth points produce curved segments; corner points produce sharp angles.

Use the Direct Selection tool to choose the object or path and show its anchor points.

Choose the Anchor Point tool, or press Shift + C.

To change a corner point into a smooth point, drag the anchor point slightly in any direction until its direction handles appear, then move those handles to shape the curve.

To make a smooth point into a corner point with no direction lines, choose the smooth point.

To make a smooth point into a corner point while keeping independent direction handles, drag either direction handle separately.

To reshape only one side of a curve, hold Alt (Windows) or Option (macOS) while dragging the direction handle.

Tip

The Control bar also provides Convert selected anchor points to corner icon and Convert selected anchor points to smooth icon for switching selected anchor points between smooth and corner points.

## Simplify path benefits

Simplifying paths can improve artwork handling and make workflows easier. The feature removes unnecessary anchor points and creates a simplified, optimized path while keeping the original shape largely unchanged. Simplify path benefits include:

- Easier and more accurate path editing
- Smaller file size
- Quicker file display and printing

When to Simplify Paths

- When using Image Trace, remove imperfections in the traced path.
- When only part of complex artwork needs editing, create sharper or smoother paths in the selected regions.
- When expanding shapes made with the Width tool, reduce the anchor-point count.
- When editing artwork imported from mobile drawing or sketching apps.

## Erase paths using the Eraser tool

With the Eraser tool, remove artwork areas such as paths, compound paths, clipping paths, plus paths inside Live Paint groups.

With the Selection tool, choose an object or group.

Open Eraser Tool Options dialog box by double-clicking the Eraser tool.

Within Eraser Tool Options dialog box, change these options:

- Angle: rotate the eraser angle with the slider.
- Roundness: change how round the eraser is with the slider.
- Size: set the eraser's overall size with the slider.

Tip

Press ] to enlarge the Eraser tool size, or press [ to make it smaller.

Customize the Eraser Tool Options for precise control.

Customize the Eraser Tool Options for precise control.

To control variations in the shape of Eraser tool, choose one of the options from the dropdown menu:

- Fixed: keeps the tool's Angle, Roundness, or Size unchanged regardless of stylus pressure or other input.
- Random: varies the tool's Angle, Roundness, or Size randomly. The Variation field sets the range for how much the brush characteristic can change. For example, Size of 15 with Variation of 5 makes the value vary randomly between 10 and 20.
- Pressure: changes the tool's Angle, Roundness, or Size according to stylus pressure. Use it with the Size option on a graphics tablet. The Variation field determines how far the brush property can move from its original value. For example, Roundness of 75% with 25% Variation produces strokes ranging from 50% to 100%. Lighter pressure creates more angular strokes.
- Stylus Wheel: controls Size through the stylus wheel.
- Tilt: changes the tool's Angle, Roundness, or Size according to stylus tilt. Use Tilt with Roundness on a graphics tablet that detects the direction in which the stylus is tilted.
- Bearing: changes the tool's Angle, Roundness, or Size according to drawing-stylus pressure. Use the option to control calligraphic brush angle on a graphics tablet that supports pen tilt detection.
- Rotation: changes the tool's Angle, Roundness, or Size according to rotation of the stylus pen tip. Use the option to adjust calligraphic brush angle with a stylus that supports rotation input.
