### Application Frame

The Application Frame places all workspace components inside one integrated window so the app can be handled as a single unit.

On macOS, the Application Frame can be turned on or off. When it is on, moving or resizing the app or any component makes all components respond to one another so they do not overlap. Panels remain visible when you switch apps or accidentally click outside the app. You can also place each app side by side on one monitor or across multiple monitors. If you prefer the traditional free-form macOS interface, turn off the Application Frame from the Window menu.

### Application Bar

The Application Bar runs across the top of the app and contains menus on Windows plus other options when a workspace is open. On macOS, when the Application Frame is off, the Window menu can turn the Application Bar on or off.

After you open a document and enter the workspace, these options appear in the upper-right area of the Application Bar:

### Document window

Created or opened documents are arranged as tabs in one document window by default. You can undock the document window, and you can also create a separate window for each document or for a document group.

### Toolbar

The toolbar provides tools for creating artwork, editing artwork, and navigating the canvas. By default, it is docked on the left side of the document window.

### Panels

Panels let you monitor and edit artwork. Use the Window menu to show or hide them. The Status bar is always visible and cannot be hidden.

## Properties panel overview

Learn about the Properties panel in Adobe Illustrator and the quick-editing options it provides.

In Illustrator, the Properties panel surfaces the key controls for the active selection or tool so text, images, and paths can be edited quickly. It is available in the Essentials workspace, or you can select Windows > Properties to show it.

### Organization of controls

The Properties panel adapts to the current selection or active tool and shows two main control types:

Default controls: If no object is selected, the Properties panel shows document-level controls such as artboard settings, layout tools, and preferences.

Selection-based controls: Selecting an object updates the Properties panel with controls specific to that selection.

- Image object: controls for Crop, mask, embed or unembed, and image trace
- Text object: settings for Font, size, color, alignment, and paragraphs
- Multiple objects: properties shared by the selection that can be edited
- Artboard: settings for Size, orientation, and background color

Use the Properties panel to see contextual controls for the selected object, such as a rectangle.

Use the Properties panel to see contextual controls for the selected object, such as a rectangle.

### Common categories of controls

The Properties panel always includes controls for the selected object and for general document settings.

- Transformation and Appearance controls: Basic settings such as width, height, fill, stroke, and opacity
- Dynamic controls: Additional options based on the selected object, such as text or image tools.
- Quick actions: Shortcuts for common tasks tied to your selection

Note

To open more expandable controls, select the ellipses in an area's lower-right corner or select an underlined option.

### Additional controls

Depending on the selected tools or objects, the Properties panel can show these additional contextual controls:

Shown after you select the Width tool or a path with variable width. Choose a width to update the width profile.

## Set properties with precise values

Learn how Adobe Illustrator supports precise adjustments through direct numeric entry, specific increments, and basic math expressions in panels and dialog boxes.

In Illustrator, you do not have to rely only on on-canvas adjustments. You can enter numeric values for properties to create and modify artwork accurately. Any panel or dialog box that accepts numeric property values supports the same value-entry methods.

### Enter values directly in supported measurement units

On the canvas, select the object to modify.

In the value field for the panel or dialog box, enter a value using the default measurement unit or another supported unit:

- Default unit: Remove any current value, then enter the required value. If you remove the default unit, Illustrator automatically restores it after the value is entered.
- Another unit: Remove the current value and the default unit. Then enter the required value followed directly by the unit abbreviation. Examples: 5in means 5 inches, 10mm means 10 millimeters, and 25pt means 25 points. Illustrator converts the value to the default unit and displays it.

Use the Transform section of the Properties panel to view and adjust selected artwork width and height.

Use the Transform section of the Properties panel to view and adjust selected artwork width and height.

Press Enter to apply the value.

### Adjust values in specific increments

On the canvas, select the object to modify.

Click the value field in the panel or dialog box where the adjustment should happen.

Use the Up or Down arrow key to raise or lower the current value by 1 unit.

Hold Shift while using the arrow keys for larger changes, typically 10 units.

Hold Cmd (macOS) or Ctrl (Windows) while using the arrow keys for fractional changes. Some fields may not support this, especially fields with percentage values.

Press Enter to apply the value.

### Enter values as basic math expressions

On the canvas, select the object to modify.

In the value field for the panel or dialog box, choose one of these approaches:

- To replace the entire current value with a math expression, select the whole value.
- To include the current value in your math expression, place the cursor before or after it.

Enter a simple math expression with +, -, \*, / or %. For example:

- Typing 50+10 gives 60
- Typing 100\*0.5 gives 50
- Typing 3cm\*50% gives 1.50 cm
- Typing 50pt+25% gives 62.5 pt

Press Enter to calculate and apply the value.

## Contextual Task Bar overview

Learn how the Contextual Task Bar helps you quickly reach the most frequently used options in Adobe Illustrator.

### Contextual Task Bar

The Contextual Task Bar is a floating canvas bar that offers the most relevant next actions for the selected object or tool. It helps keep your attention on the object you are editing.

Move the Contextual Task Bar to the location you prefer. Selecting More options lets you reset its position, pin it, or hide it. To show it again after hiding it, go to Window > Contextual Task Bar.

### Options shown for different objects and tools

### Blank canvas

Opening a new document shows Contextual Task Bar tools and features for starting quickly. Draw (Pencil) creates freeform drawings, Generate Vectors supports design ideation, and Place Image imports an image.

Note

Generative AI features are available in regions where Adobe provides services. Users in mainland China do not have access to them.

### Selection tool and paths

When a path is selected with the Selection tool, the Contextual Task Bar offers several editing options. Use Gen Shape Fill to fill the selection with vector graphics, and use Fill and Stroke to change colors.

Additional options appear based on the selected path type:

Path type

Options

Open path

Use Join Path to connect the path ends, and Edit Path to switch to the Direct Selection tool for needed edits.

Shape (closed path)

Use Edit Path for needed edits, and Lock Object to avoid accidental changes. For a basic shape made with tools such as the Rectangle tool and the Star tool, property adjustment appears instead of Lock Object.

Multiple paths and shapes

Use Group to treat them as one shape, and Align to arrange them in different ways. If selected shapes use different colors, Recolor also appears for refining the color scheme.

Grouped paths and shapes

Use Ungroup to separate them, Isolate group to edit in isolation mode, and Recolor object to recolor them.

### Selection tool and Compound Path

After creating a Compound Path and selecting it with the Selection tool, the Contextual Task Bar shows Gen Shape Fill, Edit Path, Fill, and Stroke. Release separates the shapes.

### Basic shape tools

When you add shapes to the canvas with the Rectangle tool, Rounded Rectangle tool, Ellipse tool, Polygon tool, or Star tool, the Contextual Task Bar shows Gen Shape Fill, Edit Path, Fill, and Stroke. You can also adjust properties for the shape you added.

With the Rectangle tool and the Rounded Rectangle tool, Generate Vectors is also available.

### Direct Selection tool and paths

Selecting a path with the Direct Selection tool makes the Contextual Task Bar show controls for editing the path and anchor points:

- Simplify lowers the path's anchor-point count, while Smooth adjusts curvature.
- Remove selected anchor points, Connect selected end points, Cut path at selected anchor points, Convert selected anchor points to corner, and Convert selected anchor points to smooth provide controls for specific anchor points.

### Images and vectors

When an image and a vector are selected together with the Selection tool, the Contextual Task Bar shows Clip Mask for creating a Clipping Mask, Create Mockup for fitting the vector onto an object in the image, plus Align and Group.

### Clipping Mask

After creating a Clipping Mask with vector objects, select it with the Selection tool to show Edit Mask for isolation-mode editing and Release for releasing it. Gen Shape Fill is also available.

### Mockup

Selecting a mockup group with the Selection tool makes Edit Content available for vector-object editing and Release available for releasing both the vector object and the image. While the vector object is being edited, Edit Symbol appears for editing the matching symbol.

### Other tools

When you use the Artboard tool, Smooth tool, Free Transform tool, Dimension tool, and Objects on Path tool, the Contextual Task Bar shows the relevant tool options.

## Learn faster with the Discover panel

Learn how to open and use the Discover panel for finding tools, tutorials, and quick actions that make Adobe Illustrator work more efficient.

### Use and manage the Discover panel

To open the discover panel, use the search icon in Illustrator's upper-right corner, select Help > Illustrator Help, or press F1.

Type a keyword in the Discover panel search bar to find tools, in-app tutorials, and articles that help build your skills. When you choose a tool or menu item from the results, a blue coach mark shows its location in the interface.

Return to the previous page with the arrow icon, or start over by selecting the home icon in the Discover panel.

To configure preferences for the Discover panel, use the settings icon in the panel's lower-right corner, then select Preferences to access these options:

- Location coach marks: Select to control whether interface tool locations are shown by the panel.
- Quick select: Select to decide whether pressing Enter selects the top result or shows all results.

To close the Discover panel, press Esc.
