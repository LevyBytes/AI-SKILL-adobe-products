## Introduction to artboards

### Learn about artboards in Adobe Illustrator.

Artboards help organize design work while you use Illustrator's infinite canvas. In Adobe Illustrator, an artboard functions like a sheet of white paper that gives artwork its base area. You can start from presets for common devices or define custom artboard dimensions for your own artwork. Artboards can also be exported or printed.

When you make a document or open a new file in Illustrator, artboard preset and size settings are available. For multiple designs, add or create several artboards. You can resize, rename, duplicate, and remove artboards as your project requires.

Before working with artboards, keep the Artboards, Properties, and Control panels within easy reach. After you create or open a document, use the Window menu to display those panels.

## Create and add new artboards

### Learn how to create and add new artboards.

Choose Artboards in the tool panel. If the Artboards icon is not visible, choose Window > Artboards.

Choose New Artboard in the Artboards panel.

Tip

You can also make an artboard by selecting the Artboard tool in the tool panel, then dragging the artboard icon in the workspace to the desired location. To select any artboard in your design, press Shift + O.

Choose Artboard Options in the Artboards panel.

In the Artboard Options dialog box, enter the Name for the artboard, then complete any of these settings:

- Choose a Preset from the drop-down list, or type Custom values in the Width and Height fields.
- Choose a Reference Point in the grid, then set X and Y positions to place the artboard.
- Set Orientation to Portrait or Landscape.
- Turn Constrain Proportions on or off to preserve the aspect ratio.

Enable these Display options as needed: Show Center Mark, Show Cross Hairs, and Show Video Safe Areas. For an accurate on-screen preview, you can also choose Video Ruler Pixel Aspect Ratio under Display.

Adjust Global options as needed, then choose OK, or press Esc when you do not need to apply changes.

## Use the artboard context menu

Use the artboard context menu when artboards need to be managed directly from the canvas.

Common artboard commands are gathered in the artboard context menu. With one right-click, you can handle creation, duplication, renaming, deletion, selection, rearrangement, locking, and export tasks without moving to another panel.

The context menu appears only while the Artboard tool is active.

Choose the Artboard tool from the toolbar or press Shift + O.

On the canvas, choose one or more artboards.

Right-click (Windows) or control-click (macOS) an artboard in the selection to display the artboard context menu.

Use any of these menu options to manage artboards:

- Cut: takes the selected artboard off the canvas.
- Copy: duplicates the selected artboard while leaving it on the canvas.
- Paste: inserts a copied or cut artboard at the cursor location or inside the visible canvas area.
- Undo Ungroup: reverses the previous ungroup action and restores grouped artboards.
- Redo: performs the most recently undone artboard action again, including actions such as move or resize.
- New Artboard: adds a new artboard to the canvas.
- Duplicate Artboards: creates copies of the selected artboard(s) along with artwork.
- Rename: changes the selected artboard(s) name.
- Delete Artboards: removes the selected artboard(s) from your document.
- Delete Empty Artboards: removes artboards that contain no artwork.
- Generate Expand: converts generative artwork on the selected artboard into editable vector shapes.
- Select All Artboards: selects every artboard in the document for document-wide operations.
- Lock Artboards: opens lock and unlock choices that protect artboards from accidental edits.
- Rearrange: opens the artboard rearrangement dialog for organizing artboards.
- Fit to Artwork Bounds: changes selected artboard size so it closely surrounds the artwork.
- Switch Orientation: changes an artboard between portrait and landscape orientation.
- Artboard Options: opens the options dialog for additional artboard settings, including background colors and size.
- Export: exports selected artboards using customizable export settings.

Open the context menu with a right-click on an artboard when you need to quickly create new artboards, duplicate or rename existing artboards, lock them against edits, or export them directly.

Right-click an artboard for quick context-menu access to creating, duplicating, renaming, locking, and direct export of artboards.

## Rearrange artboards

Before you begin

Rearrange All Artboards requires a document with at least two artboards.

Choose Window > Artboards.

- Layout order: sets the direction used to arrange artboards, such as Right-to-Left or Left-to-Right.
- Columns: sets how many columns are used in the artboard arrangement.
- Spacing: controls the amount of space placed between artboards.

In the Rearrange All Artboards dialog box, enable Move Artwork with Artboard when artwork should move with its artboard.

## Lock artboards

Lock objects on Illustrator artboards when accidental selection or edits need to be prevented.

In files with many artboards and layered content, locking an artboard protects its objects from unintended movement or editing while you work elsewhere in the design.

Press Shift + O or choose the Artboard tool from the toolbar.

Choose the artboard to lock.

After the target artboard is chosen, right-click or control-click (macOS), open Lock Artboards, then choose one of these options:

- Lock Selected
- Lock All Except Selected
- Lock All

Another method is to open the Artboards panel, select an artboard, and select the lock control to lock the artboard.

Locking artboards helps keep layouts intact while you edit other designs.

Keep layouts intact during edits to other designs by locking artboards.

To unlock an artboard, go to the Artboards panel and deselect the lock control.

Tip

The Artboards panel indicates whether an artboard is locked: an icon appears next to the artboard name when locked, and the space remains blank when editable.

- Show Center Mark: shows a point at the middle of the artboard for positioning objects.
- Show Cross Hairs: shows cross lines from each side of the artboard through the center.

Note

Most Illustrator artboard presets use square pixels, so Video Ruler Pixel Aspect Ratio (VPAR) is set to 1.0. When the Artboard Options dialog box uses a VPAR other than 1.0 (non-square pixels), Illustrator automatically updates the video rulers to match the changed pixel aspect ratio.

### Display video rulers

Choose View > Rulers > Show Video Rulers. The ruler values show the artboard dimensions in pixels.
