# Frames, grids, rulers, and guides — Override default measurement units

A unit of measurement can be entered that differs from the default.

In a panel or dialog box, select the existing value, then type the replacement value using one of the notations listed below:

| To specify: | Type these letters after the value: | Examples | Result |
| --- | --- | --- | --- |
| Q | q | 6q | 6 Q |
| Ha | h | 6h | 6 Ha |
| Inches | i<br>in<br>inch<br>" | 5.25i<br>5.25in<br>5.25inch<br>5.25" | 5 1/4 inches |
| Millimeters | mm | 48mm | 48 millimeters |
| Centimeters | cm | 12cm | 12 centimeters |
| Picas | p | 3p | 3 picas |
| Points | pt<br>p (before value) | 6pt<br>p6 | 6 points |
| American points | ap | 6ap | 6 American points |
| Picas and points | p (between values) | 3p6 | 3 picas, 6 points |
| Pixels | px | 5px | 5 pixels |
| Ciceros | c | 5c | 5 ciceros |
| Agates | ag | 5ag | 5 agates |
