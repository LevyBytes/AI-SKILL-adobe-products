# Editing text — Manage conditions

Use the following condition-management tasks as needed:

Delete a condition

For a single deletion, choose the condition first. At the bottom of the Conditional Text panel, click the Delete Condition icon, select the replacement condition, and click OK. Every text range that used the deleted condition receives the replacement.

For several deletions, Shift-click contiguous conditions, or Ctrl-click (Windows) or Command-click (Mac OS) non-contiguous conditions. Then click the Delete Condition icon.

Remove a condition from text

Clearing a condition tag from text differs from deleting that tag from the document. The tag remains available in the document for later reuse.

To clear a condition from text, select the range and click the box beside the condition so its check mark disappears. Click [Unconditional] to remove every condition from the selected text.

Load (import) conditions

From the Conditional Text panel menu, choose Load Conditions to import only conditions, or choose Load Conditions And Sets. Select the InDesign document that contains the conditions to import, then click Open. Any loaded condition or set replaces an existing condition or set with the same name.

InDesign cannot load conditions from an InCopy file, but both InDesign and InCopy can load conditions from an InDesign file.

Loaded sets do not use the current visibility settings shown in the Conditional Text panel.

Synchronize conditions in a book

To keep conditions consistent across every document in a book, create the desired conditions in the style source document. In the Synchronize Options dialog box, select Conditional Text Settings before synchronizing the book.

Show or hide condition indicators

In the Conditional Text panel, open the Indicators menu and choose Show or Hide to display or suppress condition indicators. When one version is visible and conditional areas need to be identified, show the condition indicators. If the indicators interfere with layout review, hide them. Choose Show And Print when condition indicators should be printed and output.

Change a condition name

To rename a condition, select it in the Conditional Text panel, pause, and click its name. Enter another name.

Edit condition indicators

To edit indicators, double-click a condition in the Conditional Text panel, or select one and choose Condition Options from the panel menu. Define the indicator settings, then click OK.
