# Editing text — Find and change conditional text

Use the Find/Change dialog box to locate text with one or more applied conditions and replace those conditions with one or more different conditions.

Show any conditional text that should be included in the search.

Hidden text is not searched.

Choose Edit > Find/Change. When Find Format and Change Format are hidden, click More Options to reveal them.

Use Find Format for the Find Format Settings dialog box. In Conditions, choose [Any Condition] when any applied condition should match, choose [Unconditional] when the target text should have no condition, or choose the specific condition or conditions for the search. Click OK.

This feature finds only text that exactly matches the selected conditions. For example, if Condition 1 and Condition 2 are both selected, text with only one of those conditions is not found, and text with those two conditions plus another condition is also not found.

Click the Change Format box to open the Change Format Settings dialog box. Choose the replacement formatting, such as a condition or character style, then click OK.

If the Conditions section is selected in the Change Format Settings dialog box, [Any Condition] leaves the found conditional text unchanged. Use this option when applying other formatting, such as a character style. Select [Unconditional] to clear all conditions from the found text. If you choose a specific condition, specify whether it replaces every condition currently applied to the found text or is added alongside them.

Start with Find, then use Change, Change/Find, or Change All as needed.
