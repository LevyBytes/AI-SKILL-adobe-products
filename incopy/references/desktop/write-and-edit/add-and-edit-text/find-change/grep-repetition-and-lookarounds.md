# GREP repetition, groups and lookarounds

Open when choosing Find/Change metacharacters for grep repetition, groups and lookarounds.

An empty cell means that the source lists no equivalent for that tab. “Find only” entries belong in Find What; “Change only” entries belong in Change To.

| Character or operation | Text tab | GREP tab | Availability |
| --- | --- | --- | --- |
| Zero or One Time |  | `?` | Find only |
| Zero or More Times |  | `*` | Find only |
| One or More Times |  | `+` | Find only |
| Zero or One Time (Shortest Match) |  | `??` | Find only |
| Zero or More Times (Shortest Match) |  | `*?` | Find only |
| One or More Times (Shortest Match) |  | `+?` | Find only |
| Marking Subexpression |  | `( )` | Find only |
| Non-marking Subexpression |  | `(?: )` | Find only |
| Character Set |  | `[ ]` | Find only |
| Or |  | `\|` | Find only |
| Positive Lookbehind |  | `(?<= )` | Find only |
| Negative Lookbehind |  | `(?<! )` | Find only |
| Positive Lookahead |  | `(?= )` | Find only |
| Negative Lookahead |  | `(?! )` | Find only |
| Case-insensitive On |  | `(?i)` | Find only |
| Case-insensitive Off |  | `(?-i)` | Find only |
| Multiline On |  | `(?m)` | Find only |
| Multiline Off |  | `(?-m)` | Find only |
| Single-line On |  | `(?s)` | Find only |
| Single-line Off |  | `(?-s)` | Find only |

Source: [Adobe InCopy Find/Change](https://helpx.adobe.com/uk/incopy/desktop/write-and-edit/add-and-edit-text/find-change.html).
