# Structuring documents for XML — Structure pane icons

These icons are used in the Structure pane:

| Icon | Name | Use |
| --- | --- | --- |
|  | Root element | Every document has one root element at the top; it can be renamed, but it cannot be moved or deleted. |
|  | Story element | Indicates tagged stories, including one or more linked frames. |
|  | Text element | Indicates tagged text inside a frame. |
|  | Graphic element | Indicates a tagged frame containing a placed image. Each graphic element carries an href attribute whose value points to the linked file's path or URL. |
|  | Unplaced text element | Not yet connected to any page item. |
|  | Unplaced graphic element | Not yet connected to any page item. |
|  | Table element | Indicates a table. |
|  | Header cell element | Indicates a table cell in the header row. |
|  | Body cell element | Indicates a table cell in the table body. |
|  | Footer cell element | Indicates a table cell in the footer row. |
|  | Empty element | This element is associated with an empty frame. |
|  | Attribute | Contains metadata, for example keywords or the location of a linked image (HREF attribute). |
|  | Comment | Contains comments that are present in the XML file but absent from the InDesign document. |
|  | Processing instruction | Contains a directive that causes an action in applications that can read processing instructions. |
|  | DOCTYPE element | Identifies the DTD file InDesign should use for XML file validation. |
