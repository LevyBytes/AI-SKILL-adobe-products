# Structuring documents for XML — Use the Structure pane

- To display the Structure pane, choose View > Structure > Show Structure.
- To hide the Structure pane, choose View > Structure > Hide Structure, or click the splitter button.
- To reveal or hide an element's child elements, click the triangle next to the element.
- To resize the Structure pane, drag the splitter button.
- To open or close an element together with every element inside it, hold down Ctrl (Windows) or Command (Mac OS) while clicking the triangle next to the element.
- To display or suppress text snippets, use the Structure pane menu command Show Text Snippets or Hide Text Snippets.
