# Workspace basics - Restore the default workspace

Choose Default or Essentials in the application-bar workspace switcher.

Note

In Dreamweaver, Designer is the default workspace.

For Fireworks (Windows), remove the following folders:

Windows Vista

\\Users&lt;username&gt;\AppData\Roaming\Adobe\Fireworks CS4\

Windows XP

\\Documents and Settings&lt;username&gt;\Application Data\Adobe\Fireworks CS4

(Photoshop, InDesign, InCopy) Select Window > Workspace > Reset [Workspace Name].
