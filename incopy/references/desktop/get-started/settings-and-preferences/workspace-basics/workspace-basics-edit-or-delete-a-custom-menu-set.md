# Workspace basics - Edit or delete a custom menu set

Choose Edit > Menus. In the Set menu, choose the menu set, and then perform one of these actions:

To edit a menu set, adjust menu-command visibility or color, click Save, and then click OK.

To remove a menu set, click Delete, and then click Yes. If the menu set has unsaved modifications, InCopy asks whether to save the current menu set. Click Yes to save it, or click No to discard the changes.
