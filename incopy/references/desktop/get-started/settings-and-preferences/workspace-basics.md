# Workspace Basics

> Adobe InCopy reference. Original prose; identifiers preserved verbatim.

When you work on documents and files, the interface is made from elements such as panels, bars, and windows; a saved arrangement of those elements is a workspace. Across Adobe® Creative Suite® 5, application workspaces use a shared look, making it easier to move among applications. Each application can also match your habits through preset workspaces or a custom workspace you create.

Default layouts differ by product, but the way you handle workspace elements is largely consistent across them.

At the top, the Application bar includes the workspace switcher, menus (Windows only), and other application controls. On Mac, some products let you show or hide it from the Window menu.

The Tools panel provides tools for creating and editing images, artwork, page elements, and similar content. Related tools appear together.

The Control panel shows settings for the active tool. In Illustrator, the Control panel shows settings for the selected object. In Adobe Photoshop® this area is called the Options bar. In Adobe Flash®, Adobe Dreamweaver®, and Adobe Fireworks®, it is called the Property Inspector and includes properties for the selected element.

The Document window shows the file currently in use. In some cases, Document windows can be tabbed, grouped, and docked.

Panels let you monitor and change the project. For instance, Flash has Timeline, Illustrator has Brush panel, Adobe Photoshop® has Layers panel, and Dreamweaver has CSS Styles panel. Panels can be arranged as groups, stacks, or docked sets.

The Application frame collects the workspace into one integrated window, so the application behaves like a single unit. When you move or resize the Application frame or one of its elements, the other elements adjust with it and avoid overlapping. Panels remain visible when you switch applications or click outside the application by accident. If you use two or more applications, place each application side by side on the screen or across multiple monitors.

If you use a Mac and want the traditional free-form interface, disable the Application frame. In Adobe Illustrator®, choose Window > Application Frame to switch it on or off. On Mac, Flash keeps the Application frame permanently enabled; Dreamweaver omits that frame.
