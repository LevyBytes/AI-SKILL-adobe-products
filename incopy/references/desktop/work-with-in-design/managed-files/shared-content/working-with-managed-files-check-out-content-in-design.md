# Working with managed files — Check out content (InDesign)

Use one of these methods:

Select the needed text or graphics frames in the layout, then choose Edit > InCopy > Check Out.

From the Assignments panel, select the files, then use the panel menu command Check Out.

After available content is checked out in InDesign, the Editing icon  is shown on the InDesign frame. In InCopy, the In Use icon  is displayed on the InCopy frame and in the Assignments panel when the assignment files reside on a local server.
