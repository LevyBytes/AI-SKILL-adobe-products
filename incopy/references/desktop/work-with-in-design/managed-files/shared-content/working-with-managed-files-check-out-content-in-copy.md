# Working with managed files - Check out content (InCopy)

Use one of these methods:

Select File > Open and choose the assignment file (.icma or .inca) when the content is part of an assignment.

If the material was exported as separate files, choose File > Open and select the InCopy file (.icml or .incx). For copyfitting with layout context, select the InDesign document.

Then use one of these checkout methods:

For a single InCopy content file, choose File > Check Out.

For every item in an assignment at the same time, select the assignment in the Assignments panel, then use the panel menu command Check Out.

For individual assignment items, expand the assignments list in the Assignments panel, select one or more items, then use the panel menu command Check Out.

The Editing icon  appears next to each selected item in the Assignments panel, showing that the content is checked out to you for exclusive use.

If InCopy asks to update the content with changes, click OK.

After available content is checked out in InCopy, the Editing icon  is visible on the InCopy frame and in the Assignments panel. InDesign shows the In Use icon  on the InDesign frame.
