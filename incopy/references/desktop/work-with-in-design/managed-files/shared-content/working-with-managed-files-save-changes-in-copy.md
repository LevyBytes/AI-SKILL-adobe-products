# Working with managed files - Save changes (InCopy)

Use one of these methods:

To keep the InCopy file in the same file-system name and location, choose File > Save Content. The file remains checked out to you.

To save the InCopy content file with a new name, choose File > Save Content As. The new content file is outside the managed workflow. Save Content As is available only when the InCopy content file (.icml or .incx) has been opened directly.

To create a copy of the active InCopy content file, choose File > Save Content Copy. You can assign the copy a new name and location. The saved copy is outside the managed workflow. Save Content Copy is available only when the InCopy content file (.icml or .incx) has been opened directly.

To save all open InCopy content files that are checked out, choose File > Save All Content. All files are saved to their current locations. Save All Content is available only when an assignment or InDesign file is open.
