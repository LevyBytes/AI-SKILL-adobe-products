# Workspace Basics

> Adobe InCopy reference. Original prose; identifiers preserved verbatim.

When you work on documents and files, the interface is made from elements such as panels, bars, and windows; a saved arrangement of those elements is a workspace. Across Adobe® Creative Suite® 5, application workspaces use a shared look, making it easier to move among applications. Each application can also match your habits through preset workspaces or a custom workspace you create.

Default layouts differ by product, but the way you handle workspace elements is largely consistent across them.

At the top, the Application bar includes the workspace switcher, menus (Windows only), and other application controls. On Mac, some products let you show or hide it from the Window menu.

The Tools panel provides tools for creating and editing images, artwork, page elements, and similar content. Related tools appear together.

The Control panel shows settings for the active tool. In Illustrator, the Control panel shows settings for the selected object. In Adobe Photoshop® this area is called the Options bar. In Adobe Flash®, Adobe Dreamweaver®, and Adobe Fireworks®, it is called the Property Inspector and includes properties for the selected element.

The Document window shows the file currently in use. In some cases, Document windows can be tabbed, grouped, and docked.

Panels let you monitor and change the project. For instance, Flash has Timeline, Illustrator has Brush panel, Adobe Photoshop® has Layers panel, and Dreamweaver has CSS Styles panel. Panels can be arranged as groups, stacks, or docked sets.

The Application frame collects the workspace into one integrated window, so the application behaves like a single unit. When you move or resize the Application frame or one of its elements, the other elements adjust with it and avoid overlapping. Panels remain visible when you switch applications or click outside the application by accident. If you use two or more applications, place each application side by side on the screen or across multiple monitors.

If you use a Mac and want the traditional free-form interface, disable the Application frame. In Adobe Illustrator®, choose Window > Application Frame to switch it on or off. On Mac, Flash keeps the Application frame permanently enabled; Dreamweaver omits that frame.

## Workspace basics — Hide or show all panels

(Illustrator, Adobe InCopy®, Adobe InDesign®, Photoshop, Fireworks) Press Tab to toggle every panel, including the Tools panel and Control panel.

(Illustrator, InCopy, InDesign, Photoshop) Press Shift+Tab to toggle all panels other than the Tools panel and Control panel.

Note

When Interface preferences has Auto-Show Hidden Panels selected, hidden panels can appear temporarily. Illustrator keeps this behavior enabled at all times. Move the pointer to the application-window edge (Windows®) or monitor edge (Mac OS®), then pause over the strip that appears.

- (Flash, Dreamweaver, Fireworks) Press F4 to hide or show all panels.

## Workspace basics — Display panel options

Click the panel menu icon at the panel's upper-right corner.

Note

A panel menu can still open while the panel is minimized.

Note

Photoshop lets you adjust the font size used for panel text and tool tips. In the Interface preferences, select a size from the UI Font Size menu.

## Workspace basics — (Illustrator) Adjust panel brightness

In User Interface preferences, adjust the Brightness slider. The setting applies across every panel, including the Control panel.

## Workspace basics — Reconfigure the Tools panel

The Tools panel can show tools in one column or arranged side by side as two columns. (Fireworks and Flash do not include this feature in the Tools panel.)

Note

InDesign and InCopy also let you change between single-column, double-column, and single-row layouts through Interface preferences.

Select the double arrow at the top of the Tools panel.

## Workspace basics — Manage windows and panels

Build a custom workspace by repositioning Document windows and panels, then save it and move between saved workspaces when needed. In Fireworks, changing the name of a custom workspace may produce unexpected behavior.

Note

These examples use Photoshop only as the demonstration product. The same workspace behavior applies across the products.

## Workspace basics — Rearrange, dock, or float document windows

When several files are open, Document windows appear as tabs.

- To reorder tabbed Document windows, drag a window's tab to another position within the group.
- To separate a Document window from its group so it floats or is untabbed, drag the window's tab outside the group.

Note

In Photoshop, Window > Arrange > Float in Window floats one Document window, and Window > Arrange > Float All In Windows floats every Document window at the same time. See tech note kb405298 for more information.

Note

Dreamweaver does not dock or undock Document windows. Use the Document window's Minimize button to make floating windows (Windows), or choose Window > Tile Vertically for side-by-side Document windows. Search "Tile Vertically" in Dreamweaver Help for details about this topic. Macintosh users follow a slightly different workflow.

To dock a Document window with a different Document-window group, drag the window into that group.

To build stacked or tiled document groups, drag the window onto a drop zone at the top, bottom, or side of another window. You can also choose a group layout with the Layout button on the Application bar.

Note

Some products do not include this functionality. Your product may still provide Cascade and Tile commands in the Window menu for arranging documents.

- While dragging a selection, switch to another document in a tabbed group by holding the selection over that document's tab briefly.

Note

Some products do not include this functionality.

## Workspace basics — Dock and undock panels

A dock groups panels or panel groups together, usually vertically. Move panels into a dock to dock them, and move them out to undock them.

To dock a panel, drag its tab into the dock at the top, bottom, or between existing panels.

For a panel group, drag the title bar (the solid blank strip above the tabs) into the dock.

A panel or panel group is removed by dragging it out of the dock with its tab or title bar. It can be placed in another dock or kept floating independently.

## Workspace basics — Move panels

As you drag panels, blue highlighted drop zones mark places where the panel can land. For instance, dragging to the slim blue zone above or below another panel moves a panel higher or lower in a dock. Dragging somewhere outside any drop zone leaves the panel floating in the workspace.

Note

The mouse position, not the panel position, activates the drop zone. If the drop zone is hard to see, move the pointer to where that zone should appear.

Move a single panel by dragging its tab.

Drag the group's title bar to move a panel group.

## Workspace basics — Add and remove panels

If every panel is removed from a dock, that dock vanishes. To create a dock, move panels toward the right edge of the workspace until a drop zone shows.

Remove a panel by right-clicking (Windows) or Control-clicking (Mac) its tab, then choose Close; alternatively, clear it in the Window menu.

To add a panel, choose it from the Window menu and dock it in the desired place.

## Workspace basics — Manipulate panel groups

Use the highlighted drop zone inside the group to add the panel by its tab.

To make a panel float independently from the group, drag it by the tab outside the group.

To move an entire group, drag the title bar, the area above the tabs.

## Workspace basics — Stack floating panels

When a panel is dragged out of a dock and not dropped on a drop zone, it remains free-floating. You can place a floating panel anywhere in the workspace. Floating panels or panel groups can be stacked so dragging the uppermost title bar moves them together.

Free-floating stacked panels

Free-floating stacked panels

Stack floating panels by dragging a panel's tab to the bottom drop zone of another panel.

To adjust the stack order, drag a panel upward or downward by its tab.

Note

Release the tab over the narrow drop zone between panels, not the broad drop zone in a title bar.

- To pull a panel or panel group out of the stack so it floats alone, drag it out by its tab or title bar.

## Workspace basics — Resize panels

Double-click a tab to minimize or maximize a panel, panel group, or panel stack. The tab area, meaning the empty space beside tabs, can also be double-clicked.

Drag any side of a panel to resize it. Some panels, including the Color panel in Photoshop, do not resize by dragging.

## Workspace basics — Collapse and expand panel icons

Panels can be reduced to icons to keep the workspace less crowded. Some default workspaces already show panels in icon form.

Panels collapsed to icons

Panels expanded from icons

- To collapse or expand every panel icon in a column, select the double arrow at the top of the dock.
- To open one panel icon, select that icon.
- To show only icons without labels, narrow the dock until the text is hidden. Widen the dock to show the icon text again.
- Use the panel tab, the icon itself, or the title-bar double arrow to collapse an expanded panel to icon form.

Note

When Auto-Collapse Icon Panels is enabled in Interface or User Interface Options preferences in some products, an expanded panel icon automatically collapses after you click elsewhere.

Add a floating panel or panel group to an icon dock by dragging it in with its tab or title bar. (When panels are added to an icon dock, they collapse to icons automatically.)

To reposition a panel icon or panel icon group, drag the icon. Panel icons can be moved up or down in the dock, into other docks where they take that dock's panel style, or outside the dock where they appear as floating icons.

## Workspace basics — Save and switch workspaces

Saving the current panel sizes and positions as a named workspace lets you return to that arrangement even after panels are moved or closed. Saved workspace names are shown in the workspace switcher in the Application bar.

## Workspace basics — Save a custom workspace

When the workspace is arranged the way you want to store it, use the appropriate command below:

(Illustrator) Use Window > Workspace > Save Workspace.

(Photoshop, InDesign, InCopy) Use Window > Workspace > New Workspace.

(Dreamweaver) Use Window > Workspace Layout > New Workspace.

(Flash) In the workspace switcher in the Application bar, choose New Workspace.

(Fireworks) In the workspace switcher in the Application bar, choose Save Current.

Enter a workspace name.

(Photoshop, InDesign) Under Capture, choose one or more of these options:

Stores the current panel positions (InDesign only).

Keyboard shortcuts

Stores the active keyboard shortcut set (Photoshop only).

Menus or Menu Customization

Stores the current menu set.

## Workspace basics — Change Interface preferences

Choose Edit > Preferences > Interface (Windows) or InCopy  > Preferences > Interface (Mac OS).

Adjust the needed settings, then click OK.

Tool Tips

Tool tips display when the mouse pointer rests on interface items, including toolbar tools and Control panel options. Choose None to disable tool tips.

Show Thumbnails On Place

During graphic placement, the loaded graphics cursor shows an image thumbnail. The loaded text cursor likewise shows a thumbnail containing the first few text lines. Clear this option if placing graphics or text should not show thumbnails.

Show Transformation Values

While an object is being created, resized, or rotated, the cursor shows [x,y] coordinates, width and height, or rotation details.

Enable Multi-Touch Gestures

Turn this on so Windows and Mac OS multi-touch mouse gestures function in InDesign. For example, with the Magic Mouse on Mac OS, swiping scrolls vertically or moves to the adjacent page or spread, while rotating turns the spread.

Highlight Object Under Selection Tool

Turn this on to show object frame edges when the direct selection tool passes over an object.

Floating Tools Panel

Set the toolbar layout to single column, double column, or single row.

Auto-Collapse Icon Panels

With this option enabled, clicking in the document window automatically closes the open panel.

Auto-Show Hidden Panels

After panels are hidden with Tab, this option temporarily reveals them when the mouse pointer is held over the side of the document window. If the option is off, press Tab again to show the panels.

Open Documents As Tabs

When this option is off, newly created or opened documents appear as floating windows instead of tabbed windows.

Enable Floating Document Window Docking

With this option on, floating documents can dock with one another as tabbed windows. If it is off, floating document windows do not dock with other document windows unless Ctrl (Windows) or Command (Mac OS) is held while dragging.

Hand Tool

To set how text and images are greeked while scrolling a document, drag the Hand Tool slider toward the preferred balance of performance and quality.

Live Screen Drawing

Choose an option for whether the image redraws during object dragging. Immediate redraws the image as the drag happens. Never moves only the frame while dragging, then moves the image after the mouse button is released. Delayed redraws the image only after a pause before dragging, matching the behavior in InDesign CS4.

## Workspace basics — Use toolbars

Basic toolbars provide buttons for frequently used tools and commands, including opening, saving, printing, scrolling, and zooming. Tool tips name each tool button.

## Workspace basics — Show or hide a toolbar

Choose the toolbar name from the Window menu. When the toolbar is visible, a check mark appears beside that toolbar name.

## Workspace basics — Customize a toolbar

Toolbar contents, toolbar direction, and toolbar grouping can all be adjusted: choose which tools show, change the orientation, and join or split toolbars.

Use whichever action you need:

To control the tools shown on a toolbar, open the triangle at the toolbar end, choose Customize, and then select the tools. That menu is tailored to the toolbar you opened.

To reposition a toolbar, drag its title bar.

To join toolbars, drag a toolbar by its gripper area onto another toolbar, or place it along the same application-window edge on Windows® or screen edge on Mac OS®.

## Workspace basics — View tool hints

Use the Tool Hints panel to see how modifier keys behave for the tool currently selected.

Choose Window > Utilities > Tool Hints to show the Tool Hints panel.

In the toolbox, select a tool to display information about that tool, including modifier keys and shortcuts.

## Workspace basics — Use context menus

Context-sensitive menus are different from the menus across the top of the screen because they expose commands tied to the current selection or active tool. They provide a fast route to commands you use often.

Place the pointer over a document, object, or panel, and then click the right mouse button. Note

(Mac OS) Without a two-button mouse, press Control while clicking with the mouse to open a context menu.

## Workspace basics — Customize menus

Reducing menu clutter is possible by hiding menu commands, and color can be applied to make frequently used commands stand out. Hiding a command only removes it from display; the feature itself remains available. Hidden commands can be revealed whenever needed by selecting Show All Menu Items at the bottom of a menu, or by choosing Window > Workspace > Show Full Menus to display every menu for the active workspace. Saved workspaces can include your customized menu setup.

The main menu, context menus, and panel menus can all be customized. Context menus open when you right-click on Windows or Control-click on Mac OS in an area. Panel menus open from the icon in the upper-right corner of a panel.

Note

Some commands are hidden when another workspace is selected, such as Getting Started. Use Show All Menu Items from the menu's bottom edge to reveal them, or switch to a different workspace such as Advanced.

## Workspace basics — Create a custom menu set

Choose Edit > Menus.

The default menu set cannot be edited.

Click Save As, enter a name for the menu set, and click OK. In the Category menu, choose Application Menus or Context & Panel Menus to decide which menus will be customized. Use the arrows beside menu categories to reveal subcategories or commands. For each command you plan to customize, click the eye icon under Visibility to show or hide that command; click None under Color to choose a color from the menu. Click Save, and then click OK.

## Workspace basics — Select a custom menu set

Choose Edit > Menus. From the Set menu, choose the menu set, and then click OK.

## Workspace basics — Edit or delete a custom menu set

Choose Edit > Menus. In the Set menu, choose the menu set, and then perform one of these actions:

To edit a menu set, adjust menu-command visibility or color, click Save, and then click OK.

To remove a menu set, click Delete, and then click Yes. If the menu set has unsaved modifications, InCopy asks whether to save the current menu set. Click Yes to save it, or click No to discard the changes.

## Workspace basics — Show hidden menu items

- Choose Window > Workspace > Show Full Menus. This turns on every menu for the current workspace. Resetting the workspace hides those menus again.
- Choose Show All Menu Items at the bottom of any menu that contains hidden commands.

Note

To temporarily show menu commands hidden through menu customization, hold Ctrl on Windows or Command on Mac OS while clicking a menu name.

## Workspace basics — Use keyboard shortcut sets

InCopy includes keyboard shortcuts for numerous menu commands, options, scripts, and controls. You can define custom keyboard shortcuts as well. In the Keyboard Shortcuts dialog box, you can:

Select the set to use.

Display commands that already have shortcuts.

Produce a full shortcut list.

Build your own shortcuts and shortcut sets.

Modify existing shortcuts.

Commands that support shortcuts but lack entries in the default shortcut set are also shown in the Keyboard Shortcuts dialog box.

## Workspace basics — Change the active shortcut set

Choose Edit > Keyboard Shortcuts. From the Set menu, select a shortcut set. Click OK.

## Workspace basics — View shortcuts

Choose Edit > Keyboard Shortcuts. For Set, choose a shortcut set. For Product Area, choose the area that contains the commands you need to inspect. Under Commands, choose a command. Its shortcut is shown in the Current Shortcuts section.

## Workspace basics — Generate a list of shortcuts

Choose Edit > Keyboard Shortcuts. From the Set menu, select a shortcut set. Click Show Set.

A text file opens and lists the current shortcuts plus undefined shortcuts for that set.

## Workspace basics — Create a new shortcut set

Choose Edit > Keyboard Shortcuts. Click New Set. Enter a name for the new set, choose a shortcut set from the Based On Set menu, and click OK.

## Workspace basics — Create or redefine a shortcut

Choose Edit > Keyboard Shortcuts. For Set, choose a shortcut set, or click New Set to make a new shortcut set. Note

Although the Default shortcut set can be changed, that approach is not recommended. Edit a duplicate of the Default shortcut set instead.

For Product Area, choose the area that contains the command you want to define or redefine. In the Commands list, choose the command to define or redefine. Click in the New Shortcut box, and press the keys for the new keyboard shortcut. If another command already uses that key sequence, InCopy shows that command under Current Shortcuts. You can also revise the original shortcut, or choose a different shortcut. Note

Single-key shortcuts assigned to menu commands can interrupt text entry. When an insertion point is active and you type a single-key shortcut, InCopy runs the command instead of entering the character.

Use one of these actions:

Click Assign to make a shortcut for a command that has none yet.

To attach an additional shortcut to that command, click Assign.

Click OK to close the dialog box, or click Save to leave it open and continue adding shortcuts.
