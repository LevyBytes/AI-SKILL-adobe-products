# Styles

> Adobe InCopy reference. Original prose; identifiers preserved verbatim.

In the Styles panel, open the context menu for a style or style group with right-click (Windows) or Control-click (Mac OS), and choose Duplicate Style.

The duplicated style or group is added to the Styles panel with the original name followed by "copy." When a style group is duplicated, the style names inside the new group stay unchanged.

Copying styles into another group is another way to duplicate them.

## Working with styles — Group styles

Use groups in these panels to organize styles: Character Styles, Paragraph Styles, Object Styles, Table Styles, and Cell Styles. Groups can be nested inside other groups. A style can remain at the panel root or be placed in a group; grouping is optional.

## Working with styles — Create a style group

In the Styles panel, prepare the target:

For a root-level group, make sure no styles are selected.

For a group inside another group, select and open the parent group.

To put existing styles into the group, select those styles first.

From the Styles panel menu, choose New Style Group. To create the new group from the selected styles, choose New Group From Styles instead. Enter the group name, then confirm with OK. Drag a style onto the style group to move it there; release the mouse button once the style group is highlighted.

## Working with styles — Copy styles to a group

Copied styles in another group are independent, even when they keep the same name. Changing one style does not alter the attributes of the other.

Select the style or group to copy. From the Styles panel menu, choose Copy To Group. Select the destination group, or [Root] level, for the copied styles or group, and then click OK.

If the destination already has identical style names, the incoming styles are renamed.

## Working with styles — Expand or collapse style groups

- To affect only one group, click the triangle icon next to it.
- To affect the group and all nested subgroups, Ctrl-click (Windows) or Command-click (Mac OS) the triangle icon.

## Working with styles — Delete style groups

Removing a style group also removes its contents: styles and any nested groups.

Select the target group. From the Styles panel menu choose Delete Style Group, then click Yes. For every style contained there, set a replacement style or choose [None], then click OK.

Note

To send all styles to one replacement, turn on Apply To All.

Canceling any style replacement stops the deletion, so the group remains. To restore deleted styles, choose Edit > Undo Delete Styles.

## Working with styles — Move and reorder styles

New styles normally land at the bottom of the current style group or, if no group is active, the style panel.

- To sort every group and the styles inside it alphabetically, choose Sort By Name from the Styles panel menu.
- To reposition one style, drag it where it belongs. A black insertion line marks the destination; when a group folder is highlighted, dropping the style adds it to that group.
