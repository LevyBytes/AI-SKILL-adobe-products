# Tube-modeled Compressor effect

Amplitude and Compression > Tube-modeled Compressor simulates the warmth associated with vintage hardware compressors. It can add mild distortion that colors audio pleasantly.

Tube-modeled Compressor adds warm analog-style compression and harmonic richness to audio.

Use Tube-modeled Compressor when audio needs analog-style warmth, compression, and harmonic richness.

Threshold slider

Sets the input level where compression starts. Values can be -60 to 0 dB. The best value depends on the audio and musical style. For more preserved dynamic range with only extreme peaks compressed, try thresholds around 5 dB below the peak input level; for heavy compression and a much smaller dynamic range, try about 15 dB below the peak input level.

Input Level meters

These meters, located left of the slider, show input amplitude. Double-click them to clear peak and clip indicators.

Gain Reduction meters

These meters, located right of the slider, show amplitude reduction with red bars running from top for minimal reduction to bottom for maximum reduction.

Output Gain

Raises or lowers amplitude after compression. Values can be -18 to +18 dB, with 0 as unity gain.

Ratio

Sets compression ratio from 1-to-1 through 30-to-1. For example, at 3.0, every 3 dB above the compression threshold produces 1 dB at output. Typical values run from 2.0 to 5.0; higher values create the compressed sound often heard in pop music.

Attack

Controls how quickly compression is applied when audio passes the threshold. Values can be 0 to 500 milliseconds. Many audio sources work well with the 10 milliseconds default. Faster values suit fast transients, but they may sound unnatural on less percussive material.

Release

Controls how quickly compression ends after audio drops below the threshold. Values can be 0 to 5000 milliseconds. The 100 milliseconds default works well for many audio types. Choose faster values for quick transients and slower values for material with softer attacks.
