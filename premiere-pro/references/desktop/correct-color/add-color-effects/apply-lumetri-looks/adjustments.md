# Adjustments

Use the Adjustments section in the Creative section when a clip needs color and lighting refinement.

In the Creative section, use Adjustments to refine the clip's color and lighting.

- Faded Film: creates a faded film treatment on the video. Move the sliders left or right until the vintage result looks right.
- Sharpen: changes edge definition for a crisper video image. Move the slider right for stronger edge definition and left for less. Higher edge definition makes video detail stand out more, so avoid pushing sharpening so far that the image appears unnatural.

Tip

Set the slider to zero (0) to disable sharpening.

- Vibrance: changes saturation while reducing clipping as colors approach full saturation. It affects lower-saturated colors more than highly saturated colors and helps keep skin tones from becoming oversaturated.
- Saturation: changes every color in the clip evenly across the range from 0 (monochrome) to 200 (double the saturation).
- Tint wheels: control tint values in shadows and highlights with the Shadow Tint and Highlight Tint wheels. Empty wheel centers show that no tint has been applied. To add tint, select the wheel center and drag the cursor until the wheel fills.
- Tint Balance: offsets excess magenta or green in the clip.
