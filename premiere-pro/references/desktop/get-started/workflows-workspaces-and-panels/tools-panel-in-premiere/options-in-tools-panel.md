# Options in Tools panel

Premiere's Tools panel collects the editing tools used while working in the Timeline panel.

A. Selection tool B. Track Select tool C. Ripple Edit tool D. Razor tool E. Slip tool F. Pen tool G. Shape tool H. Hand tool I. Text tool J. Generative Extend tool

The Tools panel in Premiere provides access to the application's main edit tools.

Activate a tool for timeline work by selecting it directly or by pressing its keyboard shortcut. Hover over a tool to display its tool name and the matching shortcut.

- Selection: The regular choice for selecting clips, menu items, and other interface objects. After finishing with a specialized tool, switching back to Selection is usually the safest default.
- Track Selection: Use this tool when you need every clip after the cursor position in a sequence. Selecting one clip targets that clip plus later clips on the same track. Shift-clicking a clip expands the selection to later clips across all tracks. Holding Shift changes Track Selection into the Multi-track Selection tool.
- Ripple Edit: Use this tool to adjust a clip's In or Out point in the timeline. Ripple Edit removes any gap created by the trim while keeping edits on the affected side of the trimmed clip intact.
- Razor: Use this tool to cut clips in the timeline at one or more points. Select a location inside a clip to split it exactly there. Shift-clicking a spot in any clip cuts clips on every track at the same location.
- Slip: Use this tool to alter a clip's In and Out points together in the timeline while preserving the clip duration between them. For example, after trimming a 10-second clip down to 5 seconds in the timeline, the Slip tool lets you choose which 5 seconds are shown.
- Pen: Use this tool to create or select keyframes, or to modify connector lines in the timeline. Drag a connector line up or down to change it. Ctrl-click (Windows) or Command-click (macOS) a connector line to create a keyframe. Shift-click separate keyframes to select noncontiguous keyframes. Drag a marquee around adjacent keyframes to select a contiguous group.
- Shape: Use this tool when adding shapes to the sequence and timeline.
- Hand: Use this tool to pan the visible timeline area left or right. Drag left or right anywhere within the viewing area.
- Text: Use this tool when adding text to the sequence and timeline.
- Generative Extend: Use this tool to extend video and audio clips with Adobe's Firefly Video Model.
