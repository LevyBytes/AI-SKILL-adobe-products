# Undock a panel in a floating window

A panel can be undocked into a floating window where panels can be added and changed, similar to the main application window. Floating windows are useful on a secondary monitor or when recreating layouts from earlier Adobe applications.

Choose the panel that should be undocked.

From the panel menu, select Undock Panel or Undock Panel Group.

Note

Another option is to hold Ctrl (Windows) or Command (macOS) while dragging the panel or group away from its current position. After you release the mouse button, the panel or group opens in a new floating window.
