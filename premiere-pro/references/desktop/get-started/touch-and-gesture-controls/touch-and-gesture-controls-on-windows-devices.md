# Touch and Gesture controls on Windows Devices

Use touch gestures on Microsoft Surface Pro and Windows devices to control Premiere for faster editing.

Premiere provides touch- and gesture-based editing for scrubbing, selecting, and arranging clips into rough cuts. The experience is tuned for touch, while thumbnail controls and Program Monitor drop-zones can also be used with a mouse. For best results, apply touch to assembly and rough-cut work, and switch to conventional mouse edits whenever needed.

On Microsoft Surface Pro and Windows multi-touch devices, control Premiere by touch. Combining gestures with keyboard work can speed up these activities:

- Build rough cuts
- Scrub through media
- Set in and out points
- Drag and drop clips onto timelines
- Edit clips
