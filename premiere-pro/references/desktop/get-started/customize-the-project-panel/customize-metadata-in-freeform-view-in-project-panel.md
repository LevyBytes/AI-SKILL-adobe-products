# Customize metadata in Freeform View in Project panel

Customize metadata in Freeform View so clips are easier to organize, identify, and sort.

In the Project panel, select the Freeform View icon.

Open the Project panel menu icon, then choose Freeform View Options.

In the Freeform View Options dialog box, choose the metadata type to show on lines 1 and 2.

Select the metadata and visual indicators that should appear in Freeform View when distinguishing and arranging media.

Freeform View can display chosen metadata and visual cues to make media easier to tell apart and organize.

Optionally, enable Label color and Badges to show visual markers such as color swatches and icons.
