# Create layouts in Freeform View in Project panel

Save and manage custom clip arrangements in Freeform View by using layouts in Adobe Premiere.

Once clips have been arranged, that arrangement can be saved as a layout.

Right-click an empty area in Freeform View and choose Save As New Layout.

Use Save As New Layout from the context menu to store the clip arrangement as a layout.

Selecting Save As New Layout from the context menu saves the current clip arrangement.

Enter a layout name and select OK.

Type the name that should be used for the new layout.

Provide a name for the layout being saved.

The saved layout appears in the context menu. To view that context menu, right-click an empty area in Freeform View.

The Freeform View context menu lists the newly saved layout.

Use the Freeform View context menu to access the layout that was just saved.

Continue arranging clips and adding new clips while working in Freeform View. As work continues, save updates through Save Layout in the context menu, or create a separate layout through Save As New Layout in the context menu.
