# Customize the Icon View in Project panel

Customize Icon View in the Project panel so clips appear as thumbnails for easier organization, preview, and editing.

The view mode icons change the media display and help arrange clips visually for quicker navigation.

View mode icons also let you choose the media presentation and keep clips organized for faster movement through the panel.

These asset actions are available in icon View:

Use the Zoom slider when increasing or decreasing icon size. Icons can be enlarged enough to make media contents easier to inspect.

Set a poster frame by dragging the playhead or shuttle to the desired frame, then pressing Shift + P (Windows) or Command + P (macOS). Clear that poster frame with Ctrl + Shift + P (Windows) or Option + P (macOS).

To check whether a clip is already used in a sequence, hover the mouse over the filmstrip icon and read the tool tip. The indicator also reports how many times the clip appears in the sequence.

To find that clip inside a sequence, select the filmstrip icon, then use the context menu to choose the target sequence and its timecode location. Premiere moves the playhead to the clip in that sequence.

To rearrange items in Icon View, drag an item to another grid position. During the drag, a vertical bar marks the destination. Dropping an item onto a bin places that item inside the bin.

Use either of these approaches to scrub clip contents:

Move the cursor across a clip thumbnail to scrub through the media without clicking; this behavior is Hover Scrub. Scrubbing left to right previews from the Media Start on the left through the Media End on the right.

Tip

Moving the cursor away from the thumbnail, or changing focus, returns the thumbnail to its poster frame. Audio is not played during Hover Scrub.

- Disable Hover Scrub from the Project panel menu, or press Shift + H.
- When Hover Scrub is off, hold Shift to enable it temporarily.
- While hover scrubbing, press I and O to set In and Out points.
- While hovering over a clip, double-click its icon to open it in the Source Monitor at the hovered frame for fast insert or overwrite edits to the timeline.

Scrub a clip by clicking and dragging the playhead across the slider.

- Clicking the slider on the thumbnail makes a clip playhead appear.
- Drag that playhead to inspect clip contents or monitor audio.
- Press J for reverse shuttle, K to pause, or L to play forward through the clip.
- During pause or shuttle playback, press I and O to define In and Out points; a yellow bar marks the selected section.

Note

On a MacBook Pro, the Multi-Touch trackpad can resize thumbnails in the Project panel and Media Browser with pinch and zoom.

Icon View can be used to put clips into storyboard order before sending that storyboard into a sequence with Automate To Sequence.
