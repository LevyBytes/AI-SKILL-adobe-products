# Customize List View columns

Project panel List View metadata columns describe the listed assets. Premiere can show selected XMP metadata fields as well as clip data fields. You can decide which metadata columns appear, add schema properties, and reorder columns. Those column choices are saved inside the project file, so reopening the project brings back the same Project panel column set.

From the Project panel menu, choose Metadata Display, then use any of these options:

- To show every column in a metadata schema in the Project panels, check the box beside the schema name.
- To show selected columns from one or more schemas, open the schema names with their triangles. Then check the boxes beside the column names to display.

Use Metadata Display to choose which metadata columns appear in the Project panels.

Metadata Display controls the metadata columns shown in the Project panels. Note

If a property cannot be found or changed in the Metadata Display dialog box, Adobe Premiere has locked it and prevents editing. For example, properties you created can be deleted, but built-in properties from the Premiere project metadata cannot be removed.

Select OK.
