# Customize Freeform view in Project panel

Customize Freeform View in the Project panel when clips need to be arranged, grouped, and compared visually with more flexibility.

Freeform View lets clips sit in a custom layout instead of forcing them into a grid or sort order. This view is useful for spatial thinking, stacking or grouping media files, and arranging clips as storyboards or assembly edits. A project can store multiple layouts and switch among them. Freeform View supports several related actions.
