# Learn how touch and gesture actions work with buttons

Navigate clips with touch gestures and buttons such as Frame Step, Shuttle, In/Out, speed drag controls, and drag-and-drop timeline edits, where Overwrite is the default.

Select the Frame Step button to move forward one frame; the arrow indicates the direction.

Drag to scrub at a slow rate, with speed increasing as high as 1x playback.

Select the Shuttle button during playback to double speed, up to 32x.

Drag to change speed between 1x and 32x; the arrow shows direction.

Select the In Point and Out Point buttons to set in/out points while playback is stopped or running.

Drag to scrub and set the point; the thumbnail updates.

Edit clips in the sequence.

Select-and-hold clip thumbnails, avoiding control buttons, then drag them to the Timeline or Program Monitor.

Note

Touch-only editing supports overwrite edits in the Timeline.
