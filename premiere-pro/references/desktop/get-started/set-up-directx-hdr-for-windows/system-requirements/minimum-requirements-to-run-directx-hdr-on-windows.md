# Minimum requirements to run Directx HDR on Windows

| Requirement type | Specification |
| --- | --- |
| Operating system | Windows 10, version 1709. |
| Display | Use a display that supports the HDR10 standard. For the best experience, choose a display that's VESA DisplayHDR certified. |
| GPU | - Nvidia GeForce 1000 series (Pascal) or newer.<br>- AMD Radeon RX 400 series (Polaris) or newer.<br>- Intel Core 7 series (Kaby Lake) or newer. |
