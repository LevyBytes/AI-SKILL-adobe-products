# Removing archived Team Projects that are no longer required.

Team Projects can be archived to clear space, and archived Team Projects that are no longer useful can also be deleted.

Choose File > Open Team Project.

In the Manage Team Project dialog box, open the Archive tab.

Choose the Team Projects to remove, then select Delete to permanently remove those Team Projects from the system.

Note

Deleting an archived Team Project is permanent. Verify that the project is no longer needed before you delete it.

Owner permission is required to archive, restore, or delete Team Projects.
