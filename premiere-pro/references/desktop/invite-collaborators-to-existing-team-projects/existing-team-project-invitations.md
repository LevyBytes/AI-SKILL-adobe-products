# Inviting collaborators into a Team Projects item that already exists

For an existing project, add collaborators by selecting the sign next to the collaborator image thumbnails.

Another route is the File menu: select File > Team Project Settings > Edit.

Type the names or email addresses of collaborators you want to invite to edit.

If people were invited earlier, a list of the most recently invited collaborators appears to speed up the invitation process. While you type, matching search results help locate the desired collaborators.

After all collaborators have been added, select Invite.

Note

Enterprise users should confirm that their IT administrator has enabled the Team Projects service for the account.
