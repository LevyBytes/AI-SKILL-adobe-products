# Playback preferences for devices, timing, and capture hardware

Playback preferences control media playback, including device choice, timing around edits, and capture card setup.

In the Playback panel, set the default audio and video player, change Preroll and Postroll timing, and configure third-party capture card devices. Premiere uses this player for previews in Effect Controls, Multi-Camera Monitor, Trim modes, Project panel, Program Monitor, and Source Monitor. The default computer player can be used, and some capture cards support third-party players.

These settings tune playback across editing views and external devices for smoother previews and better sync.

Playback behavior across editing views and external devices can be configured for smoother previews and better sync.

| UI option | Function |
| --- | --- |
| Preroll | Enter the number of seconds to play before the edit point during playback. |
| Postroll | Enter how long playback continues after the edit point, measured in seconds.. |
| Step forward/back Many | Enter how many frames are skipped. |
| Pause Media Encoder queue during playback | Pauses encoding in Adobe Media Encoder while sequences play. |
| Enable Mercury Transmit | Enables video output to external devices through Mercury Transmit. |
| Offset | Enter a millisecond value for adjusting audio timing offset. |
| Primary Audio Device | Select the audio output device used for playback. |
| Transmit Device Playback | Controls external playback devices.<br><br>- Device Name: shows the connected external output device used for playback, such as Adobe SRT.<br>- Video Stream: toggles the external device's video output on or off.<br>- Video Offset: accepts a value for syncing video timing with audio on external displays.<br>- Audio Stream: toggles audio output to the external device on or off.<br>- Settings: opens device-specific settings for customizing output format and additional playback choices. |
| Disable video output when in the background | Stops video from being sent to external devices while Premiere is not active. |
