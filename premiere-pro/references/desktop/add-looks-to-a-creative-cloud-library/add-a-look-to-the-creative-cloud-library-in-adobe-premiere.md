# Add a Look to the Creative Cloud library in Adobe Premiere.

After color grading is applied to a clip, that information can be saved as a Look. You can also upload it to the library.

In a sequence, select a clip or track item in the Timeline panel.

Make sure the Lumetri Color panel is focused and that the clip has a Lumetri effect applied.

Select the Add Look icon at the bottom of the Libraries panel.

Under Add elements, choose Look so the selected look is added to the Creative Cloud library.

Premiere creates a Look file using the selected clip's name. The Libraries panel shows the uploaded Look as a thumbnail.
