# Drag a Look to timeline

- Dragging a Look from the Libraries panel to a clip in the timeline adds a Lumetri Color effect to that timeline item. If that track already has a Lumetri Color effect, Premiere updates the existing effect with the new Look.
- When the track item is visible in the Program Monitor, Premiere renders the effect.
- The Effect Controls panel receives a Lumetri Color effect.

As another route, choose a sequence clip, right-click the library look, and choose Apply Look.
