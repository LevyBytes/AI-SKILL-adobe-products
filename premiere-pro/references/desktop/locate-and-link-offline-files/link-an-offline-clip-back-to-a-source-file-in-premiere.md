# Link an offline clip back to a source file in Premiere.

When a project opens with missing media, the Link Media dialog box shows which files have broken links and provides tools for finding and reconnecting them.

The Link Media dialog box lists the clip name used by the project and the media file's linked filename. It also shows the full folder path where the offline media was stored.

In the Project panel, select one or more clips that are offline.

Choose File > Link Media.

When a project contains offline media, the Link Media workflow can reconnect that media for the project.

For projects with offline media, use Link Media to bring the missing files back online.

Choose the needed search criteria and Match File Properties according to how the offline files should be handled.
