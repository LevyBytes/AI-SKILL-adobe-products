# Apply styles to a sub-selection of the text

After creating a style, link it to other titles or caption tracks in Adobe Premiere.

Select the portion of the text layer or caption that you want to edit.

Either set font, color, size, and other text properties, or choose the style thumbnail you want to apply.

Use the Properties panel to apply attributes to only selected portions of text.

Apply attributes only to chosen parts of the text with the Properties panel.

After you finish, the new style changes only the selected part of the text or caption. Next, use the plus icon in the Track style menu's upper-right corner and select Create style.

In the Track style dropdown list, the new style is displayed with thumbnails. Use that style afterward on other portions of the project's text layers.
