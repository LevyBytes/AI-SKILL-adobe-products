# Create Linked and Track Styles

Learn about creating and using styles for titles and captions so the project stays visually consistent.

Before you begin:

Begin by adding text or captions.

Then choose the text layer in the Program Monitor or the caption track in the timeline, and navigate to the Edit tab of the Properties panel.

Use Text and Appearance controls to style the text layer or caption.

Use the plus icon in the upper-right corner of the Linked style or Track style menu, then select Create style.

Name the style and save it where you want it. Select Save to Project to link the text layer or caption with the style; it appears in the dropdown and creates a project item in the Project panel. Select Local Folders to save the style to a local folder that can be reused in future projects through the style browser.

Save styles to Local Styles, then import them easily for use in other projects.

Keep styles in Local Styles for later import and easy application in other projects.

The Linked style or Track style dropdown list shows the new style with thumbnails. Apply that style afterward to additional text layers and caption tracks in your project.
