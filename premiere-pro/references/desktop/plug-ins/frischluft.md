# Frischluft

Flair

Flair adds eight premium effects for Adobe Premiere, After Effects, and Adobe Photoshop compatible programs. The set covers shine, glow, and sparkle treatments and includes 16-bit plus multi-CPU support.

FreshCurves

Curves is a flexible, accurate color correction tool. This plug-in gives more control and precision than the built-in curve tools in Adobe Premiere, helping users get more from that basic correction method.

Lenscare

Lenscare shifts depth-of-field and out-of-focus creation into post-production. For users who need high-quality camera blurs with 2D postprocessing flexibility, Lenscare is a useful option and can avoid long additional 3D render times. The filters were built to closely match real-world blur. Adobe Premiere, After Effects, and Photoshop-compatible programs can all host Lenscare as a plug-in.
