# FxFactory

FxFactory Pro

FxFactory Pro is a visual effects toolbox focused on broad features and performance. For Premiere and After Effects, the package contains 176 filters, generators, and transitions. FxFactory Pro effects use the graphics card for faster previewing and rendering. The plug-ins include many built-in presets so users can test looks quickly, and custom presets can be saved to disc for later reuse.

Photo Montage

Photo Montage creates slideshows. The basic workflow is to choose an animation style, select a few photos, and let the plug-in perform the remaining work. Photos can be reordered and each photo duration can be changed in seconds through an intuitive configuration UI. Ease of use does not remove depth: a full set of effect parameters lets expert users design custom animations.

Pan and Zoom

Create the Ken Burns-style photo animation look with polished results and no keyframes.

ParticleMetrix

Particle effects for explosions, shatters, builds, reveals, and transitions.

Volumetrix

Volumetric lighting effects and transitions that include glows, glints, and distortions.

SupaWipe

Transitions based on objects.
