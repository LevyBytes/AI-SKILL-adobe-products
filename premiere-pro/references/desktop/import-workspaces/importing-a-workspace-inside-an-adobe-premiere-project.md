# Importing a workspace inside an Adobe Premiere project.

By default, Premiere opens a project with the workspace that is currently active. You can instead have a project open with the workspace that was last used for that project, which helps when each project uses a different panel arrangement.

Launch Premiere.

Choose Window > Workspaces > Import Workspace from Projects.

Open the target project.

If an imported project opens with an empty workspace, close the project, turn off Import Workspace from Projects, import the project again, and then choose an existing workspace for that project.
