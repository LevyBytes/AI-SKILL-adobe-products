# When to use each workflow

- Ingest workflow: choose the ingest workflow when you want a highest-quality copy of the original media and also need editing-optimized files. This helps when storage space is not a major limitation and you want source footage backed up.
- Proxy workflow: choose the proxy workflow when smoother playback and faster editing are needed, especially for 4K or higher-resolution footage on less powerful hardware. It uses less storage and improves edit speed. After editing is finished, switch back to the original media for final export.

You can combine the two workflows as well. Ingest original media for backup, then create proxy files for smoother editing, which lets you move between them as needed during the edit.
