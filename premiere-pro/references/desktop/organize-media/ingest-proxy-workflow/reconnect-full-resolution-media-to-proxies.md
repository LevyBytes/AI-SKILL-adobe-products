# Reconnect full-resolution media to proxies

Before export or high-quality post-production work, reconnect full-resolution media when you have been editing with proxy files.

If the next stage involves extensive color correction, complex effects, compositing, or audio mixing, reconnecting full resolution files is preferable so those tasks use the best source material.

Before you begin

Finish timeline editing with proxies first. When reconnecting full-resolution media, remember that only these Project panel items are eligible: video-only, audio/video, and offline proxy clips. Unsupported file types include audio-only, still images, and image sequences.

In the Project panel, highlight the high-resolution media clips to associate with proxy files. For a multi-clip selection, press Ctrl (Windows) or Command (macOS) while choosing clips.

Choose Proxy > Reconnect Full Resolution Media.

Premiere opens the relink dialog.

The Reconnect Full Resolution Media dialog box is similar to Attach Proxies, but this command links the full resolution clips instead.

Use the command to find missing high-resolution files by choosing matching properties for Reconnect Full Resolution Media.

Reconnect Full Resolution Media helps Premiere find missing high-resolution files by matching the properties you choose.

Select the file properties that should be matched.

Premiere matches files by combining criteria such as file names, file extensions, tape names, and timecode. When those criteria identify a match between a high-resolution clip and a proxy file, Premiere links them.

Select Relink others automatically if Premiere should look through the project and attach proxies to other media clips that match the same properties as the clips currently being handled.

Select Use Media Browser to attach files if the Media Browser in Premiere should be used to browse to the matching full resolution clip.

Select Attach.

In the Media Browser, search for the correct clip and select it.

Select OK.

You can now continue with full resolution files, make further edits, and prepare the sequence for export.
