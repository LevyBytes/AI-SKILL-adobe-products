# Advanced filtering in the Search panel

Advanced filtering in the Search panel narrows results more precisely. Metadata-based filters help you find particular clips or assets faster when a project is large.

Open the Search panel, then type a term in the search field.

Select the filter button beside the search field to show advanced filtering options.

In the advanced filtering panel, choose Create New Filter.

Create metadata-based rules, such as File Type, Frame Rate, Status, Audio/Video, or Label Color, and stack up to eight filters as combined criteria.

For each category, choose the criteria that should be included or excluded.

Select Apply so the Search panel refreshes results using the chosen filters.

Use advanced filtering to narrow results and save time by showing only items relevant to the current task.

Advanced filtering can focus the result set and reduce time spent scanning unrelated items for the current task.
