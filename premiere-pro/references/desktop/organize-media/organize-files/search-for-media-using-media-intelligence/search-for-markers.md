# Search for markers

Marker metadata, including name, comments, and color, can be used in project searches. Matching markers appear as Search panel results so specific moments in media are easier to find.

Marker matches are grouped under Markers in the Search panel, with related metadata such as:

- Marker name
- Marker comments
- Marker color

Double-clicking a marker result sends the playhead to that marker in the Source Monitor or Timeline. With range markers, playback positioning starts at the beginning of the marked range. To add marker results to a timeline, select one or more results and drag them into a sequence.

Use the Search panel to find markers, then filter those results by marker metadata.

Marker searches can be run from the Search panel, with marker metadata available for filtering.
