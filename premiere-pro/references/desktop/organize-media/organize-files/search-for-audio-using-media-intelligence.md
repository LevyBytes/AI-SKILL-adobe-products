# Search for audio using media intelligence

Find particular sounds in footage with media intelligence in Adobe Premiere.

In Premiere on desktop, media intelligence can search across clips for described sounds. Assistive AI updates reduce manual review by letting you describe the sound effects you want.

Select the magnifying glass icon at the upper-right of the main Premiere workspace to open the Search panel.

In the Search field, type keywords describing the sound you want to locate.

From the dropdown menu beside the Search field, choose Audio instead of Everything. Visuals, Metadata, and Text remain available as other search categories.

Inspect the search results to find the track containing the described audio.

Preview the highlighted matches, then drag clips into the Timeline to add them to the project.

After previewing highlighted matches, drag the clips into the Timeline when you want to use them in the project.
