# Add and delete bins

Add or remove bins in Adobe Premiere so project files stay manageable and the workspace remains clean.

To create a bin, right-click the Project panel and select New Bin from the context menu. You can also use Control + / (Windows) or command + / (macOS).

Make a new bin when you need another place to organize media.

Add a new bin when your media needs a separate organizational container.

To remove bins, select one or more bins in the Project panel and press the Delete key.
