# Search options in Premiere

Find Adobe Premiere project assets through the available search methods.

When a project contains many clips, sequences, bins, and media files, Premiere provides search and filtering tools for finding particular assets quickly. Knowing which search option to use helps keep the project organized and supports faster editing.

Premiere can search by name, metadata, file type, label color, markers, and other attributes in the Project panel or the Media Browser. Certain tools narrow what is currently visible, while others locate items precisely even when they are stored elsewhere.
