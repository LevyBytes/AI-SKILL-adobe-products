# Use bins

Bins in the Project panel organize project content into folders, similar to a folder structure on your computer.r. A bin can hold source files, sequences, or additional bins.

As a project becomes larger, you can create more bins for those items. Bins are optional, particularly for short-form work, but they help keep project files organized.

You can use bins for these purposes:

- Hold offline clips for batch capture.
- Keep main sequences together with backup sequences.
- Sort files by type, including video, still images, and audio files.

Keep offline videos in bins from both the Project panel and the Media folder.

The Project panel and Media folder can both use bins for offline-video storage.
