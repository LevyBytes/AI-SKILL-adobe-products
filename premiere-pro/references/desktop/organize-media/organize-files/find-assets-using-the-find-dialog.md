# Find assets using the Find dialog

Search for clips, sequences, and other project items in Adobe Premiere with advanced find controls.

In larger projects, the Project panel Search box is useful for narrowing what is visible. For stricter control, including case-sensitive matching, bin-scoped searching, or more exact filtering, open the Find dialog instead.

Use the Find dialog box when you need criteria-based searching across the full project or within a selected bin.

In the Project panel, select the Find icon (magnifying glass).

Enter keywords in the search field. More specific scene descriptions usually improve visual search results.

The Search panel can display Visuals, Audio, Text, and Metadata results together. To limit the view to one result category, use the dropdown menu.
