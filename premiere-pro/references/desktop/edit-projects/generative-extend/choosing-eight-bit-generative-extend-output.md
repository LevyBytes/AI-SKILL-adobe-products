# Choosing eight-bit Generative Extend output

The right choice depends on the project and the final delivery destination.

Extend if:

- The content is intended for web, social media, or standard broadcast.
- Precise color is not essential for the project.
- Check the delivery requirements and inspect the converted footage before deciding whether 8-bit output is acceptable.

Consider alternatives if:

- The project is being professionally color graded.
- The clip contains critical color work that must not be compromised.

Adobe's FAQ gives a 90% estimate for 8-bit delivery without providing supporting measurements. Treat the actual project requirements and visible conversion results as the decision criteria; an 8-bit delivery target is not a guarantee of unchanged image quality.
