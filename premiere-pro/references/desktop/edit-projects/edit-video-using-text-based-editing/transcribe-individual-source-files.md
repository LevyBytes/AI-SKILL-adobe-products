# Transcribe individual source files

Transcribe individual source files before editing video with Text-Based Editing in Adobe Premiere.

Tip

Only videos that contain spoken dialogue require transcription. If every source file does not need a transcript, import the files as usual and transcribe selected files later.

Start a new project, choose the media to import, and enter the Text-Based Editing workspace.

Double-click the clips needing transcription in the Project panel.

In the Text panel, select Transcribe.

In the Create transcription for source media dialogue box, choose Language and Speaker labeling based on your needs, including whether Premiere should separate speakers.

Begin transcribing the source footage. When the process finishes, the dialogue appears in the Transcript window.

Start source-footage transcription; after completion, the Transcript window displays the dialogue.
