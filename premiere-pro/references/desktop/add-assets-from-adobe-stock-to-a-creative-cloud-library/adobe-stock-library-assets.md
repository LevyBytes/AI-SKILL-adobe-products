# Add Adobe Stock assets to a Creative Cloud library in Adobe Premiere.

Premiere can search Adobe Stock from inside the app, giving access to millions of high-quality, royalty-free photos, videos, illustrations, and graphics that can be saved into a Creative Cloud library.

Open the Libraries panel with Window > Libraries.

From the search options dropdown menu, show the available locations and choose Adobe Stock.

Type your terms in the Search Adobe Stock search bar. Matching results appear directly in the panel.

After you find an asset you want, either license it immediately and save it to your library in Premiere, or save an unlicensed preview (watermarked) copy now and license that item later.

For an immediate purchase, select the asset, select the License and save icon, and complete the purchase flow.

To store an unlicensed preview, select the asset and then select the Save preview to &lt;Library Name&gt; icon.

Preview assets in a library can be licensed later. Select the item, then use License Image for a still preview or License Video for a video preview. After licensing, every linked use of that asset in open files updates automatically to the licensed, high-resolution version with the watermark removed.

Tip

When Adobe Stock assets do not appear in the library automatically, select the Sync button at the lower-right corner of the panel to run a manual sync. The assets then show in the library.

After an asset is licensed, Premiere swaps any unlicensed copies in sequences for the full-quality version while keeping the edits intact.
