# Media mapping using Media Management

Another option is to choose Edit > Team Project > Media Management from the main menu, then use the media management dialog to map missing media.

Select Edit > Team Project > Media Management.

Select one missing media item and choose New Media Mapping.

Go to the folder location where the media is stored.

Select the correct media and choose Choose.

Continue the process for the remaining media across all other folders.

Note

When locally saved mapped media is moved, renamed, or deleted on the device, use the Relinking offline media feature.
