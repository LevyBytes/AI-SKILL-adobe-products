# Linked Team Projects for cloud collaboration with multiple remote collaborators

Linking Team Projects can make project management more effective. For example, a large effort can be divided into smaller, easier-to-manage Team Projects, and collaborators can attach those projects to their primary Team Projects as needed. With Linked Team Projects, collaborators work only with the required media or sequences instead of adding every media item or sequence to one project.

Menu path: File > New > Linked Team Project...

Create Linked Team Projects from the File menu when a collaboration needs to be split into manageable parts.

The File menu provides the command for creating Linked Team Projects for collaborative work.

Linked Team Projects can also be created from the context menu in the project panel. Right-click the project panel, then choose New item > Linked Team Project.

The context menu can create a Linked Team Project so collaborators work only with the required media or sequences.

Create a Linked Team Project from the context menu to limit collaboration to the needed media or sequences.

Note

Before making linked Team Projects, open an existing project or create a new one.

In the Manage Team Project dialog, choose the existing Team Projects to link, then select Link. At the same stage, selecting New Team Project creates a Team Projects item that can be attached elsewhere.

Create a Team Project from Manage Team Projects by choosing New Team Project.

In Manage Team Projects, select New Team Project to create the linked project item.
