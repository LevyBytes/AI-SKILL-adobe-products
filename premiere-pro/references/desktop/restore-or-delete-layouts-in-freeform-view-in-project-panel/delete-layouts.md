# Delete layouts

Projects can be tidied by reducing how many saved layouts they contain.

To remove layouts that are no longer needed:

Right-click a blank area in Freeform View and choose Manage Saved Layouts.

For each layout to remove, enable its Delete checkbox, then select OK.

Manage Presets dialog box used for deleting saved layouts.

Manage Presets dialog box used for deleting saved layouts. Note

Premiere removes the selected layout immediately; there is no extra confirmation and the deletion cannot be undone.
