# Tips for creating social videos

For web-bound video and audio, use these practices to keep playback smooth and quality high.

| Category | Guideline |
| --- | --- |
| Know your audience's data rate | For internet delivery, choose lower data rates. Fast connections can stream with little trouble, while dial-up viewers wait longer, so shorter clips download sooner. |
| Choose the correct frame rate | Reducing frame rate can help when bandwidth is limited. Footage with heavy motion gains the most from that reduction. Use whole-number divisors when lowering the frame rate. |
| Optimize for quality | Use the largest frame size and highest frame rate supported by the platform. For suggested settings, consult the web and device-specific presets in Adobe Media Encoder. |
| Pick a suitable frame size | At the same data rate, larger frames reduce visual quality. Keep the source aspect ratio matched so issues such as pillarboxing do not appear. |
| Plan for download times | Estimate whether the clip can load and play without stopping. For short clips, use this formula: Pause equals download time - play time + 10% of play time. |
| Clean the video | Improve encoding by removing noise and interlacing. Source material that is clean and high quality gives the encoder better input. |
| Mind display quality | Small playback windows still need enough quality. Computers reveal problems such as noise or artifacts about as clearly as HDTVs. |
| Apply the same rules to audio | Begin with clean audio. Use digital transfers from CDs when available. Skip analog input unless needed, and choose high-quality sound cards for analog sources. |
