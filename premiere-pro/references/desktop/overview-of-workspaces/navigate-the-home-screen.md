# Navigate the Home screen

The Home screen is the starting point in Premiere. From there, you can reach in-application tutorials, additional tutorials, and online documentation. The left panel lets you start a new project or open one that already exists.

Premiere Home Screen project creation and opening options.

Premiere adjusts the Home screen content over time. As you create more projects and gain experience, the screen can show more recent projects while reducing the amount of tutorial content.
