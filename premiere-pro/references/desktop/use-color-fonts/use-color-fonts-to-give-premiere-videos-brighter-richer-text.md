# Use color fonts to give Premiere videos brighter, richer text.

Color fonts add more than a single flat type color: individual letters can include color ranges, graphic detail, and texture, which can make text look more polished immediately.

Select the Type tool.

In the Program Monitor, click to create point text or draw a box to make paragraph text.

Change to the Selection Tool, then use the font picker in the Properties panel to choose the color font you want.

Move through any available style variations for that color font with the font styles picker.

Different color fonts can be used to make the text layer more visually engaging.
