# Archive Team Projects

Archiving Team Projects in Premiere helps reclaim space and keep completed work orderly.

After work has finished and the final output has been exported, you can archive Team Projects. Once a Team Project is archived, collaborators lose access to it. Archiving keeps finished projects available for later reference while removing them from the active project set, which supports storage management and a cleaner current-project list.

Before you begin

Confirm that you have permission to archive Team Projects, check with team members that the project is ready to archive, and, when necessary, save local backups of important project files.

Choose File > Open Team Project.

In the Manage Team Projects dialog box, choose the Team Projects that should be archived.

Select the Archive confirmation button. For the owner and collaborators, the project is removed from the Team Projects tab in the Manage Team Project dialog box.

Use search to find the Team Projects you plan to archive, then select Archive.
