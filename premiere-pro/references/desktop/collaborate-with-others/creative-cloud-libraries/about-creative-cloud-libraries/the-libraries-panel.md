# The Libraries panel

Premiere shows Creative Cloud Libraries in the Libraries panel.

- On the Premiere start screen, select Libraries to show Creative Cloud Libraries at launch.
- From the Start screen, download or sync a Creative Cloud Library to the desktop by selecting Libraries > [library-name], then choosing Sync to CC Libraries on the Library card at the bottom of the screen.
- Open the Creative Cloud Library (Libraries panel) by selecting Window > Libraries.
