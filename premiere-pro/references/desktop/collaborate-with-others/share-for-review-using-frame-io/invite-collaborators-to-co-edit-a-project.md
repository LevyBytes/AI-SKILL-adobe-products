# Invite Collaborators To Co Edit A Project

Invite collaborators to an Adobe Premiere project so they can co-edit video in real time.

Under Share options, use Invite to convert any Premiere project into a Team Project, invite collaborators, and give them immediate access for collaborative video editing.

Before you begin:

Open the Premiere project where collaborators should be invited for collaborative video editing.

Select the Share button, then choose Invite.

The Invite option lets you add a collaborator email address and send an invitation to collaborate on the project.

In the Convert to Team Projects and Invite dialog box, on the General tab, enter a name and description, then select Invite.

Before inviting collaborators, you can also configure other project-related settings.

- Options: choose the renderer for video rendering and playback, plus display formats for video, audio, and capture.
- Color: configure display color values including HDR Graphics White (Nits), 3D LUT Interpolation, Viewer Gamma, plus the enabled or disabled state of Auto Detect Log Video Color Space.
- Scratch Disks: choose where Premiere temporarily stores captured audio and video, previews, Creative Cloud Library, and Motion Graphics template media.
- Ingest Settings: turn on Ingest Settings, then define the ingest behavior, presets, primary destination, and proxy destination.

Add the collaborator's email address in the Edit Collaborators dialog box, then select Invite to send an invitation.

This dialog box also lists collaborators, invitation statuses, and an option for removing collaborators.

Select OK, and a dialog box appears with the invitation email progress.

A notification shows the invitation email progress for the collaborator.

Premiere creates a copy of the project, hosts it, and backs it up to the cloud.

Invitation notifications sent for Team Projects collaboration appear in both the Creative Cloud desktop application and the Premiere application.
