# Trim preferences in Adobe Premiere

Trimming behavior in Adobe Premiere can be adjusted for precision and a more efficient editing workflow.

Trim preference covers settings and configurations that affect clip trimming in Premiere.

Select Trim to change trimming preferences.

Choose Trim to adjust the trimming preference set.

| UI option | Function |
| --- | --- |
| Large Trim Offset | The Trim Monitor has Large Trim Offset buttons. When one is clicked, the trim point moves earlier or later. In the Trim section of the Preferences dialog box, enter the frame count used when Large Trim Offset buttons move the selected point. |
| Allow Selection tool to choose Roll and Ripple trims without modifier key | Turn this on to make ripple and rolling edits without a modifier key. |
| Shift clips that overlap trim point during ripple trimming | Turn this on during ripple deletes to move track items that overlap the trim. |
| Ripple trim adds edits to keep both sides of trim in sync | Turn this on to add edit points to clips that overlap a trim. Those new edit points are trimmed with the selected edit points so clip alignment is preserved on both sides of the edit. |
| Playhead position determines trim monitor loop playback | Turn this on so loop playback is based on the playhead position rather than the full edit point selection. |
