## Overview of Motion Graphics templates

### Motion Graphics templates can add dynamic, professional design elements to video projects.

A Motion Graphics template is a .mogrt file that can be authored in Adobe Premiere or Adobe After Effects. These packages expose simple controls for customization inside Premiere while bringing in the motion-graphics capabilities of After Effects.

Use Motion Graphics templates for animated elements such as titles, lower thirds, and buttons. The Graphics Templates panel is where Motion Graphics and Adobe Stock assets can be browsed.

Premiere can also import Motion Graphics templates from these locations:

- Local Templates Folder
- Creative Cloud Libraries
- Adobe Stock

Build motion graphics as templates, export them, install them, and add them to projects as needed.

## Add Motion Graphic templates to a sequence

### Place a Motion Graphics template from the Graphics Templates panel into an Adobe Premiere sequence.

Open the Graphics Templates panel, then switch to the My Templates tab.

Choose the template to use and drag it onto a video track in the sequence.

Once the template is in the sequence, use the Edit tab of the Properties panel to customize its appearance.

Tip

Premiere displays template media as offline after it is added to a sequence until loading finishes. If the template depends on fonts that are not installed, resolve the missing fonts.

## Organize Motion Graphics templates

### Create libraries and add Motion Graphics templates in Adobe Premiere.

Libraries can be created to organize assets, including Motion Graphics templates (MOGRT), which appear in the Libraries panel.

### Add a Motion Graphics template to a library

Right-click a MOGRT in the Graphics Templates panel, then choose Copy to Library from the context menu and select the library where it should be added.

Select the Motion Graphic template, then use Copy to Library to add it to a specific folder in the library.

Choose the Motion Graphic template and use Copy to Library to place it in the specific library folder.

### Move or copy your MOGRTs between different locations

Move MOGRTs between local folders on one disk by dragging them; when the folders live on separate disks, the same action copies them instead. A MOGRT can also be copied from a local folder into a library. After you choose a MOGRT in the Graphics Templates panel, its library location is shown with a blue outline, which makes the current placement easier to track.

### Manage MOGRTs on disk

For disk-based MOGRT management, use the plus icon at the upper right of the Graphics Templates panel. From there, choose a local folder, cloud drive, or shared network folder so it appears in the My Templates browser.

Tip

If you add a parent folder while the MOGRTs are actually inside subfolders, those templates will not appear in the Graphics Templates panel. Add the folder that directly contains the MOGRTs.

Inside the Graphics Templates panel, a context menu lets you manage MOGRT folder locations stored on disk with Rename, Remove, and Reveal in Finder or Explorer. Changing or deleting a location entry in the Graphics Templates panel does not rename, remove, or otherwise modify the folder on disk.

## Use data-driven Motion Graphics templates

### Use data-driven Motion Graphics templates in Adobe Premiere to customize charts and animations efficiently from spreadsheet data for dynamic project visuals.

With data-driven Motion Graphics templates, bar charts, line graphs, and similar graphics can be customized quickly and accurately without manual entry or advanced motion-graphics knowledge.

These data-driven mogrts can be created in After Effects, and free or premium mogrts are also available on Adobe Stock. Premiere provides direct access to them from the Graphics Templates panel.

Data-driven Motion Graphics templates can include three data types:

- Text
- Color
- Numbers

Note

In After Effects, the author defines each column's data type; Premiere cannot change those data types.

Without mapping, text data becomes a text string, number data appears as a hot text slider, and color data is represented by a hexadecimal value with a color swatch. Once mapped, the data is shown as labels and is disabled for manual entry.

Open the Graphics Templates panel, locate the Motion Graphics template you want, and drag it into a Premiere sequence.

Enter numbers for the template elements, then change colors, fonts, and other visual settings as needed.

Use the Properties panel to refine design details such as colors, fonts, and other visual settings so they fit the project.

Make additional Properties panel adjustments to colors, fonts, and related design settings until the visuals match the project.

## Media Replacement in Motion Graphics templates

### See how Media Replacement in Motion Graphics templates lets you swap media assets in predesigned animations while retaining the original structure.

Motion Graphics templates (MOGRTs) are a fast route for adding customized animations and graphics to videos without constructing them from the beginning. If a template supports Media Replacement, you can replace designated media items such as background videos, logos, or other graphics, gaining creative flexibility while keeping the template's intended design intact.

### What is Media Replacement?

Media Replacement lets a Motion Graphics template accept your own assets in place of particular media elements. A static template becomes reusable across projects while the same design system and animated behavior stay intact.

With Media Replacement, you can:

- Use your own graphics or photos instead of placeholder images
- Put your own footage in place of background videos
- Refresh logos and branding elements across multiple projects
- Keep animations and effects consistent while the visual content changes

## About Properties panel

### What the Properties panel is in Adobe Premiere and how it gives quick access to common controls for video, audio, text, and graphics.

Based on the item selected in the timeline or Project panel, the Properties panel gathers commonly used parameters and tools. It presents the controls most often needed for selected video, audio, text, or graphics. Use it for caption edits, video changes such as transform, position, scale, rotate, and clip opacity, and audio-volume adjustments.

To enhance and build a distinctive look, select the text, shape, or audio and use the options in the Properties panel.

Choose the text, shape, or audio, then use Properties panel options to build and refine a unique appearance.

In Premiere version 25.0 and later, many editing controls that previously appeared in the Essential Graphics panel moved to the Properties panel, creating a more unified place for clip properties and a simpler workspace.

A key benefit is multi-clip editing: select several clips at the same time and adjust shared properties together. Matching values are displayed normally; mixed values show a dash, which allows relative adjustments across all selected items.

The panel also provides access to related panels and tools based on context. For instance, selecting a graphic can surface quick actions for opening the Graphics Templates panel or linking to Stock Audio. Selecting audio displays controls such as pan and volume sliders.

Use the Properties panel in Adobe Premiere for these editing tasks.

## Create text styles

### Use the Properties panel in Adobe Premiere to define text properties including font, color, and size.

Styles store text properties such as font, color, and size as reusable formatting. With this feature, you can quickly apply matching styling across multiple layers in separate graphics on the timeline.

Before you begin:

On the timeline, create a sequence; in the Program Monitor, add the text.

Right-click the text in the Program Monitor, then select Edit Properties to show its settings in the Properties panel.

Edit the text properties:

- Text: Use the three-dots icon to open Text panel, reach advanced Effect Controls, or browse Graphics Templates.

  - Fill: Apply any desired color to the text fill.
  - Stroke: Add Outer, Inner, or Center strokes to text, including multiple strokes.
  - Shadow: Add one or more shadows to a shape to build varied effects.
  - Mask with Text: Make a text layer function as a mask, so underlying video or graphics are visible only inside the text shape.

- Align and Transform: Use top edges, vertical centers, bottom edges, left edges, horizontal centers, and right edges as text-alignment targets.
- Linked Style: For titles, use linked styles, and for captions, use track styles, so settings such as font choices and appearance stay preserved within a selected style.
- Responsive Design – Position: Build graphics that adjust automatically when the video-frame aspect ratio changes, or when another graphic layer's position or scale changes.

Note

Some parameters in the list above are not text styles. Only Text and Appearance are text styles. For more information, see the parameters used when applying a linked style or track style.

Change the appearance of text from the Properties panel.

Use the Properties panel to modify how the text looks.

When finished, use the plus icon in the Track style menu's upper-right corner, then select Create style.

Name and save the style. Select Save to Project to link the text layer with the style; the style appears in the dropdown and a project item is created in the Project panel. Select Save to Local styles to store the style in a local folder for reuse in later projects through the style browser.

In the Track style dropdown list, the new style is shown with thumbnails. Apply that style afterward to other project text layers.

Use the Redefine Style button to ripple style changes across all instances.

## Use emojis

### Add emojis while editing a Premiere project on macOS.

Emojis can bring clear expressive symbols into video edits. On macOS, Premiere renders them with the Apple Emoji Color font, keeping their appearance consistent throughout the project and similar to how they look on iPhones and other Apple devices.

Open the Emojis & Symbols picker from the main Edit menu, then place emojis directly inside text layers.

Select the Type tool.

In the Program Monitor, click to create point text or drag out a box for paragraph text.

From the Edit menu, select Emoji & Symbols.

From the compact Emoji & Symbols picker, single-click an emoji; from the expanded picker, double-click one to insert it into the text layer.
