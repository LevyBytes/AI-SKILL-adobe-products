## Ingest and Proxy workflow

### Premiere uses ingest and proxy workflows to manage and optimize video-editing projects, especially with high-resolution footage or complex media.

### Ingest workflow

In Premiere, ingesting means copying and transcoding media files from source storage, such as memory cards, external hard drives, or network drives, into the project's local storage or a designated media cache location.

The ingest workflow is mainly used to prepare optimized, consistent media files for editing. It preserves the original files while also creating working copies that can be better suited to the edit system.

During ingest, you can transcode media into a more editable format, such as a lower-resolution format or a codec the computer can process more easily. You can also consolidate media by copying it to the project's local storage so all required files are together. Premiere verifies the copy so corruption or data loss is not introduced while media is transferred.

### Proxy workflow

Proxy workflows in Premiere create lightweight, lower-resolution versions of high-resolution video files. These lower-resolution versions, called proxy files, are edited in place of the original high-res files.

The proxy workflow is intended to make editing faster and smoother, particularly with high-resolution footage or media that places heavy demands on computer hardware.

When using proxies, you create proxy files first, edit with those proxies, and later switch to full resolution media when the full resolution files are needed.

You can also use proxies made outside Premiere, such as proxies generated by cameras or other applications. In that case, attach the proxies to the full resolution media files before starting the edit.

### When to use each workflow

- Ingest workflow: choose the ingest workflow when you want a highest-quality copy of the original media and also need editing-optimized files. This helps when storage space is not a major limitation and you want source footage backed up.
- Proxy workflow: choose the proxy workflow when smoother playback and faster editing are needed, especially for 4K or higher-resolution footage on less powerful hardware. It uses less storage and improves edit speed. After editing is finished, switch back to the original media for final export.

You can combine the two workflows as well. Ingest original media for backup, then create proxy files for smoother editing, which lets you move between them as needed during the edit.

### Unsupported features in proxy workflows

- Premiere proxy functionality is not compatible with After Effects proxy functionality.
- Dynamic Link is unavailable for After Effects compositions or projects.
- Proxy workflows do not support editing audio in Adobe Audition.
- Modify audio channels and interpret footage are not supported options.

## Configure ingest settings

### Configure ingest settings to decide how media files are copied, transcoded, and organized during import.

Ingest settings control the way media files are copied, transcoded, and managed as they enter a project. They are especially useful for keeping media in an efficient editing format and storage location.

Before you begin:

Start by opening an existing project, or create a new project.

Select File > Project Settings > Ingest Settings.

Premiere opens the ingest controls.

When the Ingest Settings dialog box appears, pick one of the following operations to start automatically as files are imported into the project. Editing can continue while ingest finishes in the background.

Ingest Settings options available when setting up footage in a project.

Ingest Settings choices available for footage during project setup.

- Copy: copies the media unchanged to a new location. For example, this is commonly used to move camera footage from removable media to a local hard drive. The transfer path comes from the Primary Destination option in Ingest Settings. After copying, the clips in the project point to the copied files.
- Transcode: choose this when imported media files should be converted to another format. For example, this is commonly used to convert original camera footage into a format required by a post-production facility. After transcoding, the project clips point to those transcoded file copies.
- Create Proxies: creates and attaches proxies to the media. For example, this can generate lower-resolution clips for better editing performance, with the option to return to the original full resolution files for final output. Once the proxies are generated, Premiere automatically attaches them to the project clips.
- Copy and Create Proxies: copies media and creates proxies for that media too.

To add custom presets made in Adobe Media Encoder, select Add Ingest Preset and browse to the saved preset (.epr) file.

Add custom ingest presets created with Adobe Media Encoder.

Upload custom ingest presets made in Adobe Media Encoder.

After choosing the ingest option, select the Primary Destination and Proxy Destination when proxies are being created.

Select OK.

When media is imported into the project, Premiere applies the ingest settings you defined. It copies, transcodes, and manages media files according to those settings.

## Create proxies

### Create proxies in Adobe Premiere.

Proxies are low-resolution versions of high-resolution video files. Editing with these proxy files can improve performance and efficiency, especially for large media or files that require substantial processing.

Proxy creation is available only for video clips that do not have captions. Proxies are not supported for other file types or growing files. The media must be online.

Before you begin:

Import the high-resolution files into Premiere.

Use low-resolution media copies to reduce processing time and system load.

In the Project panel, right-click a media file. On the context menu, choose Proxy > Create Proxies.

Note

This option becomes available when the panel selection contains one or more items eligible for proxy creation. Premiere can make proxies for master clip project items when the item contains video, lacks captions, is not a growing file, and has online media.

In the Create Proxies dialog, keep the default frame size of Half and the default preset ProRes QuickTime Proxy, or choose another frame size and preset.

(Optional) You can also add presets made in Adobe Media Encoder by selecting Add Ingest Preset. Proxies can be created in a Proxies directory next to the original media or in a custom location.

To make proxy files easy to recognize in the Program Monitor, choose a watermark. Select None for no watermark, choose an icon that marks the file as a proxy, or upload a custom watermark of your own.

In the Destination section, choose one of these options:

- Next to Original Media, in Proxy Folder: with this choice, Premiere places each proxy clip in its own new folder alongside the original high res media. Because many high end cameras use complex file structures with each clip isolated in its own folder, this choice is usually inconvenient. Grouping the proxies for transfer to another drive, or deleting them at project completion, becomes harder.
- Choose Location : browse and choose a destination so all proxies are stored in the same folder.

Note

By default, Premiere adds "\_Proxy" to Proxy clip names, such as scene01_Proxy.mxf, and stores the on-disk Proxy clips in a Proxies folder beside the full resolution clips. That placement helps with clip reattachment. If you use a custom destination, add the Proxies folder to that destination.

Select OK.

Premiere shows a progress dialog box while preparing proxy creation jobs for Adobe Media Encoder.

Adobe Media Encoder then receives one proxy job for each selected project item that can be proxied, and Premiere attaches an offline proxy to each project item. Job progress can be monitored in the Premiere Progress panel or in Adobe Media Encoder.

While those jobs run, continue working in Premiere with the matching high-resolution project items.

## Attach proxies to full-resolution media

### Link existing proxies to full-resolution media when proxies were created outside Premiere, such as by a high-end camera or third-party software.

Before you begin:

Import the media into the project. Only these Project panel items can receive proxies: video-only, audio/video, and offline clips. Unsupported file types include audio-only, stills, and image sequences.

In the Project panel, highlight the high-resolution media clips to associate with proxy files. For a multi-clip selection, press Ctrl (Windows) or Command (macOS) while choosing clips.

Open the context menu from one selected clip, then select Proxy > Attach Proxies.

The Attach Proxies dialog opens with a list of the high-resolution media clips currently selected in the Project panel. It shows each clip name and current proxy status.

Attach externally created proxies to their full-resolution media counterparts.

Connect proxies made outside Premiere with matching full-resolution media.

In Attach Proxies, select the file properties that should be matched.

Premiere matches files by combining criteria such as file names, file extensions, tape names, and timecode. When those criteria identify a match between a high-resolution clip and a proxy file, Premiere links them.

Select Relink others automatically if Premiere should look through the project and attach proxies to other media clips that match the same properties as the clips currently being handled.

Select Use Media Browser to attach files if you want to navigate in Premiere with the Media Browser and choose the proxy files to pair with the high-resolution clips.

Select Attach.

In the Media Browser, search for the proxy files and specify the files to link.

Select OK.

The proxies are attached, so you can edit with those files. Timeline scrubbing, edits, effects, and other tasks can be performed with less lag than high-resolution media may cause.

When all edits are complete, reconnect the high-resolution files before exporting the video.

## Reconnect full-resolution media to proxies

### Before export or high-quality post-production work, reconnect full-resolution media when you have been editing with proxy files.

If the next stage involves extensive color correction, complex effects, compositing, or audio mixing, reconnecting full resolution files is preferable so those tasks use the best source material.

Before you begin

Finish timeline editing with proxies first. When reconnecting full-resolution media, remember that only these Project panel items are eligible: video-only, audio/video, and offline proxy clips. Unsupported file types include audio-only, still images, and image sequences.

In the Project panel, highlight the high-resolution media clips to associate with proxy files. For a multi-clip selection, press Ctrl (Windows) or Command (macOS) while choosing clips.

Choose Proxy > Reconnect Full Resolution Media.

Premiere opens the relink dialog.

The Reconnect Full Resolution Media dialog box is similar to Attach Proxies, but this command links the full resolution clips instead.

Use the command to find missing high-resolution files by choosing matching properties for Reconnect Full Resolution Media.

Reconnect Full Resolution Media helps Premiere find missing high-resolution files by matching the properties you choose.

Select the file properties that should be matched.

Premiere matches files by combining criteria such as file names, file extensions, tape names, and timecode. When those criteria identify a match between a high-resolution clip and a proxy file, Premiere links them.

Select Relink others automatically if Premiere should look through the project and attach proxies to other media clips that match the same properties as the clips currently being handled.

Select Use Media Browser to attach files if the Media Browser in Premiere should be used to browse to the matching full resolution clip.

Select Attach.

In the Media Browser, search for the correct clip and select it.

Select OK.

You can now continue with full resolution files, make further edits, and prepare the sequence for export.

## Detach proxies

### Detach proxies when you are ready to return to the original high-resolution media.

Detaching proxies in Adobe Premiere removes the relationship between proxy files and the high-resolution media clips in the project. This is useful when proxies are no longer needed or when you want to resume working from the original high-resolution media.

View the files in the Project panel and identify the files with attached proxies.

To add a proxy status column in the Project panel, open the context menu for a List view column header. Search for proxy-related fields and enable the fields you want displayed.

Add a proxy status column in the Project panel from a List view column header.

Use a List view column header to add proxy status information to the Project panel.

In the Project panel, open the clip's context menu and select Proxy > Detach Proxy.

Detach proxies from one selected clip or from multiple selected clips in one action.

Select one or more clips and detach their proxies together. Note

Premiere removes the proxy attachment, but it does not remove proxy files from disk so files or proxies referenced by another project are not accidentally deleted. You can choose whether to keep or delete those proxy files.

## Export proxies

### Export proxies to create standalone low-resolution media that can work without the original high-resolution files.

In Adobe Premiere, exporting proxy files creates independent lower-resolution copies of media that do not depend on the original high-resolution files. This can help when sharing work in progress with collaborators, reducing file size for archiving, or editing on a less powerful computer.

Before you begin:

Finish editing the project while using proxy files.

By default, Premiere exports from full resolution media even when proxies are enabled. To export proxies, explicitly enable the setting in the Export Settings dialog box during project export.

Select Export in the top header bar.

Set the export options as needed.

Under Media File > General, select Use Proxies.

(Optional) Enable Use Previews to speed export further.

When selected, this option lets Premiere use rendered previews for timeline sections that have both a rendered preview and proxy media.

Premiere renders and exports the selected clips or project quickly by using proxies instead of full resolution files.

## Create offline clips

### Use placeholder clips in Adobe Premiere to organize logged footage before capture or when source files are unavailable.

Offline clips are placeholders for media that has been logged but not captured yet, or for source files that are temporarily unavailable. They store metadata about the represented source files, which lets you organize projects and assemble sequences before the real media is available.

Create offline clips when organizing logged footage before batch capture, planning sequences with placeholder media, or preserving project structure while source files are unavailable. This workflow is especially useful for tape-based workflows with device control and for collaboration across multiple workstations. In the Project panel and Timeline, offline clips behave like captured clips and show Media Offline in the Program Monitor until they are linked to actual source files.

When an offline clip is created manually, you enter key metadata such as tape name, filename, timecode range, and media type. Premiere can later use that information to locate and capture the correct footage through batch capture operations.

### Create an offline clip for future capture

At the bottom-right of the Project panel, select the New Item icon and choose Offline File.

In the New Offline File dialog box, enter the video and audio settings for the offline file, including frame size, timebase, pixel aspect ratio, and sample rate, then select OK.

In the Contains menu, choose whether the offline clip contains Video, Audio, or Audio And Video.

Set whether the offline file has audio and video, audio only, or video only before entering the rest of the clip details.

Choose whether the offline file contains audio/video, audio only, or video only before filling in the remaining clip details.

For Audio Format, choose the matching source-footage format from Mono, Stereo, 5.1 or Multichannel.

Use the Tape Name field to enter the name of the tape that holds the source footage.

In the File Name field, enter the filename to use when the clip is captured to disk.

Enter timecode values for Media Start and Media End to set the clip's full duration. Include any handle frames required by transitions and editing in those values.

To create the offline clip, select OK.

The offline clip appears in the Project panel with an offline indicator. For batch capture eligibility, the clip needs three basics: tape name, filename, and valid Media Start and Media End timecode values. After the offline clip is captured or relinked to its source file, the actual media replaces the placeholder everywhere in the project.

Note

An offline merged clip cannot be created from scratch. Merged clips must start from existing online media.

## Edit offline clips

### Adjust offline-clip timecode, tape names, filenames, and audio formats inside an Adobe Premiere project.

Before batch capture or relinking, offline clips can be opened for setting changes. Editable details include start and end timecode, tape name, filename, audio format, and whether the clip is marked as video, audio, or both. Premiere applies those revised values to every sequence instance of the clip, and later batch capture uses them.

After an offline clip is already in a timeline, the Contains and Audio Format fields are no longer editable. Change those properties from the Project panel first, before the clip is used in sequences.

### Update offline clip settings

In the Project panel, choose the offline clip that needs updated settings.

Use Clip > Edit Offline, or open the offline clip by double-clicking it.

Inside the Edit Offline File dialog box, change the needed fields: Media Start, Media End, Tape Name, File Name, Contains, or Audio Format.

Update the offline file's content setting, Audio Format, Tape Name, File Name, and logging data.

Revise the same offline-file details again as needed: content, Audio Format, Tape Name, File Name, plus logging information.

Select OK to keep the edits.

Every sequence that uses the offline clip reflects the revised settings. During batch capture or relinking, Premiere relies on those values to find and capture the intended media.

Tip

For quicker access, assign Clip > Edit Offline to a shortcut in the keyboard shortcuts editor.

## Relink offline clips

### Reconnect missing source files with the Link Media dialog box so clips return to an Adobe Premiere project.

Clips turn into offline clips when their imported media is moved, renamed, or removed outside Premiere. In the Project panel they show the Offline Item icon, while Media Offline appears in the Timeline, Program Monitor, and related panels. The Link Media workflow is used to browse to those files and reconnect them so they can be used again. Offline clips can point back to the original source media or to replacement source files. If a different file is chosen, that source substitutes for the offline clip everywhere the project uses it.

When a project opens with offline media, Premiere first tries to restore the links automatically. If that attempt does not succeed, the Link Media dialog box lists the files requiring reconnection.

### Relink clips automatically when opening a project

Open a project that includes offline media.

In the Link Media dialog box, confirm that Relink others automatically is enabled.

Use Relink others automatically when you want Premiere to reconnect additional offline clips whose selected file properties match.

Enable Relink others automatically to have matching offline clips reconnect based on the chosen file properties.

Under Match File Properties, choose at least one property, for example File Name, File Extension, or Media Start.

For the first offline clip, select Locate so you can browse to its source file.

Go to the file's location and choose the matching file.

Premiere then reconnects other offline clips that satisfy the selected property matches.

Tip

Align Timecode is enabled by default so the source timecode in the media file is matched to the clip being relinked.

### Relink clips from the Project panel

In the Project panel, choose one or more offline clips.

Right-click the offline clip to reconnect, then select Link Media so you can locate and relink its source file.

With the offline clips highlighted in the Project panel, open the context menu and choose Link Media.

For the chosen offline clips, use the Project panel context menu's Link Media command to relink them.

In the Link Media dialog box, choose the offline clip that you want to relink.

Select Locate, then use the Locate File dialog to browse to the source file.

Check the Last Path field when you need a clue to the file's earlier location.

Choose the correct file, then select Select.

When several clips are being relinked and their folder structure matches the previous one, Premiere tries to reconnect the full selection after you identify the first file.

The Link Media dialog shows broken-link details, including the clip name used by the project and the original linked filename. In the Locate File dialog, switch between list and thumbnail views when a visual check of media files helps confirm the match.

## Convert online clips to offline clips

### Unlink clips from their source files while keeping edit decisions in Adobe Premiere.

Turning online clips into offline clips creates placeholders that keep editing data while disconnecting from the source media files.

Use this workflow to recapture clips with different settings, reduce disk use while keeping the edit, or prepare material for batch capture. Offline clips preserve the original clips' In and Out points, effects, and timeline positions. Later, when the clips are recaptured or relinked, the offline versions are replaced while the editing choices remain.

Offline conversion lets you continue working with logged clip metadata even when the real media files are not present on disk. It is especially useful for preparing higher-quality recapture or handling storage limits across multiple projects.

### Make clips offline in your project

In the Project panel, choose the clip or clips that should become offline.

Select Project > Make Offline.

Choose Media Files Remain On Disk to leave source files on the computer while only the project clips go offline, or choose Media Files Are Deleted to remove the source files from disk as the clips become offline.

Decide whether source files should stay on disk or be removed when the clips are made offline.

Select the disk-retention choice for source files when converting clips to offline. Alert

When recapture uses the same filenames as media that still remains on disk, Premiere overwrites the original files. Keep originals by moving them elsewhere or by entering different filenames during recapture.

Once clips are made offline, the Project panel shows them with an offline indicator. Sequences containing those clips show Media Offline in the Program Monitor. To bring the clips back, use Link Media to reconnect source files, or use batch capture to recapture clips that came from tape.
