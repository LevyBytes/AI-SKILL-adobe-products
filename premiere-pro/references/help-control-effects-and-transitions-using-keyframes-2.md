# Filter Properties In The Effect Controls Panel, Adjust Or Reset Controls In The Effect Controls Panel

> Adobe Premiere Pro reference. Original prose; identifiers preserved verbatim.

## Overview

Covers: Filter properties in the Effect Controls panel; Adjust or reset controls in the Effect Controls panel.

## Filter properties in the Effect Controls panel

### Narrow the visible properties while keyframes are being edited in Premiere.

Before you begin:

Apply effects to the clips, then add or edit keyframes from the Effect Controls panel.

At the lower-left corner of the Effect Controls panel, select the Filter properties icon.

Available filter choices are:

- Show All Properties: keeps every property visible by default.
- Show Only Keyframed Properties: limits the list to properties whose stopwatch is enabled.
- Show Only Edited Properties: limits the list to properties that have been modified.

Once the view is filtered by keyframes or recent edits, continue in the Effect Controls panel to add, delete, or edit keyframes for the animation workflow.

Tip

These property filters can be assigned keyboard shortcuts. To create them, select Premiere > Keyboard Shortcuts and search for the filter name. In addition to one shortcut per filter, a single shortcut can cycle through every filter. Search in the keyboard editor for Select Next Effect Controls Properties Filter, then assign a shortcut.

## Adjust or reset controls in the Effect Controls panel

### Adjusting or restoring controls in the Effect Controls panel in Premiere

Premiere offers several ways to change values or return them to defaults inside the Effect Controls panel.

- For an underlined value, hover the pointer over the value and drag left or right to edit it.

Dragging the underlined value horizontally lowers or raises the property's current setting.

Moving the pointer left or right on that value provides another direct way to decrease or increase it.

- Select the property value, type the replacement value, and press Enter (Windows) or Return (macOS).

Typing in the property field lets you set the value numerically instead of scrubbing it.

The same property field can also be used for direct value entry when you need to lower or raise the setting precisely.

- If the control is available, expand the property by selecting the icon beside the property name, then drag the slider or the angle control for that property.

The slider beneath the effect can be used to adjust the related property.

That effect slider provides another control for changing the property's value.

- For angle values, drag inside the angle control, scrub the underlined text, or select the underlined text and type a value. After clicking inside the angle control, you can drag outside the control to change values faster.
- To return effect settings to their defaults, select Reset Parameter next to the effect. Properties without keyframes go back to their default values. When a property has keyframes, only the current time is reset to the default value. Any keyframes at the current time are reset to the default. If the current time has no keyframes, Premiere creates new keyframes with the default values.

If the reset was unintended, select Edit > Undo to restore the previous settings.
