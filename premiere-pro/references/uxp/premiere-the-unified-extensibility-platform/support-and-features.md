# Support and Features

UXP is the current extensibility standard for Adobe Creative Cloud applications, and support continues to expand across hosts including **Premiere** (version 25.6), **Photoshop**, and **InDesign**.

A plugin can provide a **persistent User Interface that blends seamlessly** with the host application as a `panel`, or expose an **actionable command** that runs a predefined function as a `command`. Users trigger commands through menu items, and the choice depends on the interaction model you want. Native-code-heavy scenarios can use [Hybrid Plugins](../hybrid-plugins/reference-index.md), which combine the standard UXP plugin model with C++ libraries. Later sections cover those plugins in detail.

You can also [easily share UXP plugins](../distribution-overview.md) with other people. One route is [Adobe Creative Cloud Marketplace](../the-adobe-creative-cloud-marketplace.md), which can put the plugin in front of millions of Adobe users; other routes are [within your own organization](../distribution-overview.md) or [third-party channels](../distributing-uxp-plugins-independently.md).
