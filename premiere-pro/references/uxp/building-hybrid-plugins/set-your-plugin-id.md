# 4. Set your plugin ID

Before packaging, verify that `manifest.json` has the correct `id`. For **Creative Cloud Marketplace** publication, use the [Developer Distribution portal](https://developer.adobe.com/developer-distribution/creative-cloud/docs/guides/plugin-id#starting-from-adobe-developer-distribution) to obtain the ID, then confirm that the manifest contains that same value. See [Mind your Plugin's ID](../package-a-uxp-plugin/mind-your-plugin-s-id.md) for details.
