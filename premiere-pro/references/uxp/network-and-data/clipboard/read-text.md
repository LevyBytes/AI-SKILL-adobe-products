# navigator.clipboard - readText()

Retrieve clipboard text.

**Returns**: `Promise`  
**See**: [https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/readText)  
**Since**: v6.0  
**Example**

```js
navigator.clipboard.readText();
```
