# right

**Since** UXP v2.0

For relatively or absolutely positioned elements, this sets the right offset.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/right](https://developer.mozilla.org/en/docs/Web/CSS/right)

**Example**:

```css
.someElement {
  right: 0;
  position: absolute;
}
```
