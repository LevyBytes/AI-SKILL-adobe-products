# left

**Since** UXP v2.0

For a relatively or absolutely positioned element, this property controls the left offset.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/left](https://developer.mozilla.org/en/docs/Web/CSS/left)

**Example**:

```css
.someElement {
  left: 0;
  position: absolute;
}
```
