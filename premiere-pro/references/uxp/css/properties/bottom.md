# bottom

**Since** UXP v2.0

For relatively or absolutely positioned elements, this property supplies the bottom position.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/bottom](https://developer.mozilla.org/en/docs/Web/CSS/bottom)

**Example**:

```css
.someElement {
  bottom: 0;
  position: absolute;
}
```
