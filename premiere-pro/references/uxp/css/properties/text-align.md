# text-align

**Since** UXP v3.0

Within the containing element, sets horizontal text alignment. Values: `left`, `center`, `right`.

**See**: [https://developer.mozilla.org/en/docs/Web/CSS/text-align](https://developer.mozilla.org/en/docs/Web/CSS/text-align).

**Example**

```css
.someElement {
  font-style: left;
}
```
