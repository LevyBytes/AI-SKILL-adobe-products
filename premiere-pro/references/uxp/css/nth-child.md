# :nth-child

**Since** UXP v3.0

Selects the Nth child only; accepted selector inputs include an expression plus `even` and `odd`.

**See:** [https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-child](https://developer.mozilla.org/en-US/docs/Web/CSS/:nth-child)

**Example:** 

```css
.row:nth-child(even) {
  background-color: #E8E8E8;
  /* color even rows */
}
```
