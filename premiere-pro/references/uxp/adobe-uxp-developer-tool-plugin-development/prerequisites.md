# Prerequisites

Before using this material, complete three setup steps: the Adobe UXP Developer Tool (UDT v2.2 or later) is [installed](../essential-development-tools-for-uxp/uxp-developer-tool-udt.md), Developer Mode is enabled in UDT through [UDT first launch](../essential-development-tools-for-uxp/first-launch.md) and in Premiere through [Premiere prerequisites](../building-your-first-uxp-plugin/prerequisites.md), and your first plugin has been [scaffolded](../building-your-first-uxp-plugin/scaffold-your-plugin.md).
