# New

- [GUID](../user-info/user-id.md) can identify a Creative Cloud User uniquely; support currently exists only in `Photoshop`.
- For `fetch`, multipart `FormData` now works in [Request](../network-and-data/request/reference-index.md) and [Response](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro/main/src/pages/uxp-api/reference-js/global-members/data-transfers/response.md).
- [FormData](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro/main/src/pages/uxp-api/reference-js/global-members/data-transfers/form-data.md) adds these APIs:
  - delete()
  - get()
  - getAll()
  - has()
  - keys()
  - set()
  - values()
