# Static Analysis Tooling

When writing UXP plugins, **static analysis tools** such as [ESLint](https://eslint.org/) can detect common JavaScript mistakes. ESLint works well with continuous integration (CI) systems and many popular [code editors](../essential-development-tools-for-uxp/code-editor.md), helping you catch and correct issues earlier.

ESLint includes recommended rule sets for code analysis, and it also supports many plugins and configuration styles that can be added to your project. That flexibility is especially useful with web frameworks because it helps keep the plugin aligned with framework best practices.
