# userId()

**Read only**
Returns the user's plugin GUID.

**Since**: v7.3.0
**Example**

```js
let userId = require("uxp").userInfo.userId(); // Get the GUID of plugin user
console.log(userId); // e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855
```
