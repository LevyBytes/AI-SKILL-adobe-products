# Clipboard Operations

Connect a plugin to the system clipboard so it can read and write text data.

UXP clipboard APIs allow a plugin to **read from** and **write to** the system clipboard, so users can copy, paste, and share content between the plugin and other applications. This guide explains `Clipboard` API usage through the [clipboard reference](https://raw.githubusercontent.com/AdobeDocs/uxp-premiere-pro/55a2a2d3eb0c4a2453eb9d38e8d067f851fa6b6e/src/pages/uxp-api/reference-js/global-members/data-transfers/clipboard.md), permission declarations, and common use cases.
