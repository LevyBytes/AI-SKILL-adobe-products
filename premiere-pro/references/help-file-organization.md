## Overview of bins

### Use bins in Premiere to group media files and keep project material organized.

### Use bins

Bins in the Project panel organize project content into folders, similar to a folder structure on your computer.r. A bin can hold source files, sequences, or additional bins.

As a project becomes larger, you can create more bins for those items. Bins are optional, particularly for short-form work, but they help keep project files organized.

You can use bins for these purposes:

- Hold offline clips for batch capture.
- Keep main sequences together with backup sequences.
- Sort files by type, including video, still images, and audio files.

Keep offline videos in bins from both the Project panel and the Media folder.

The Project panel and Media folder can both use bins for offline-video storage.

## Add and delete bins

### Add or remove bins in Adobe Premiere so project files stay manageable and the workspace remains clean.

To create a bin, right-click the Project panel and select New Bin from the context menu. You can also use Control + / (Windows) or command + / (macOS).

Make a new bin when you need another place to organize media.

Add a new bin when your media needs a separate organizational container.

To remove bins, select one or more bins in the Project panel and press the Delete key.

## Open and close bins

### Open and close Adobe Premiere bins while navigating media and keeping the workspace orderly.

Double-click a bin to display it in its own dockable panel. To open several bins inside the Project panel, hold Alt and select the bins.

To close several bins already open in the Project panel, hold Alt and select them.

Closing a bin reduces visual clutter in the editing workspace.

Close bins you no longer need so the edit area stays easier to scan.

## Manage bins

### Create, nest, rename, and delete custom bins and preset bins.

Custom bins can collect favorite effects, transitions, and presets in one location. You may create as many custom and preset bins as needed. Those bins can also reorganize effects, transitions, and presets into categories that fit your preferences or the needs of the current project.

The Effects panel is where custom and preset bins are created and stored. Each new preset bin is placed inside the root Presets bin. You cannot drag preset bins out of the Presets bin, but you can create them there and arrange them in any hierarchy. Custom bins may sit at the top level of the Effects panel hierarchy or be nested inside other custom bins.

If the same item exists in multiple custom bins and you delete it from one bin, Premiere removes every occurrence of that item from the custom and preset bins and also removes each affected item from every clip that uses it.

### Create a custom bin

In the Effects panel, select the New Custom Bin button at the lower-right corner of the panel.

The Effects panel menu also includes a New Custom Bin option.

### Create a presets bin

Open the menu button in the Effects panel.

In the Effects panel menu, choose the New Presets Bin option.

Premiere places every newly created presets bin inside the root Presets bin.

### Nest a new custom or presets bin

In the Effects panel, select the bin that should contain the new bin.

Select the New Custom Bin button at the lower-right corner of the panel.

### Rename a bin

In the Effects panel, select the bin, then select its bin name.

Enter the replacement name and press Enter (Windows) or Return (macOS).

### Delete a bin

Before deleting, highlight either the bin itself or the bin item in the Effects panel.

Use the Delete Custom Items button at the lower-right corner of the Effects panel.

### Store a preset in a bin

Find the effect, transition, or preset you want to keep in the bin. Resize the panel if necessary so both the item and the bin are visible.

Drag the item onto the bin. Premiere adds a shortcut to that item.

## Change bin behaviors

### Customize Premiere bin behavior to organize footage in the way you prefer.

During editing, you may need a different bin-viewing style. The standard layout shows the entire project hierarchy, which is useful for broad navigation. In other situations, a bin may work better in its own tab or separate panel. That view can help you concentrate on the clips in one bin, place clips in storyboard order while using icon mode, or find clips in that bin by typing in the search field.

Some editors prefer a bin window that floats over the interface. Others would rather have bins open in place or appear as new tabs.

To open a bin as a floating panel, in place, or in a new tab, use these actions:

- For a new tab, double-click the bin. The resulting panel can be docked or grouped like other panels.

- For an in-place opening, Ctrl-double-click (Windows) or Command-double-click (macOS) the bin.

- For a separate floating panel, use Alt-double-click on Windows or Option-double-click on macOS.

Project panel bin defaults are set in the preferences area for Bins.

Open Edit > Preferences > General (Windows) or Premiere > Settings > General (macOS). Inside Premiere preferences, use the General panel's Bins section to control bin behavior.

The Bins section in the General panel of Premiere preferences is where those bin-behavior settings are changed.

Within Bins, choose menu settings for Double-click and for the modifier cases: + Ctrl (Windows) or + Cmd (macOS), plus + Alt (Windows) or + Opt (macOS).

Finish by selecting OK.

## Search options in Premiere

### Find Adobe Premiere project assets through the available search methods.

When a project contains many clips, sequences, bins, and media files, Premiere provides search and filtering tools for finding particular assets quickly. Knowing which search option to use helps keep the project organized and supports faster editing.

Premiere can search by name, metadata, file type, label color, markers, and other attributes in the Project panel or the Media Browser. Certain tools narrow what is currently visible, while others locate items precisely even when they are stored elsewhere.

### Search in the Project panel

The Project panel contains the imported media, sequences, and bins used by the current project. Use it for quick lookup based on an item name or metadata.

### Search box

The Search box sits at the top of the Project panel. Enter text there to filter the view to items whose names or searchable metadata contain that text.

Tip

Partial-name searches work. For example, typing "interview" displays every item with "interview" anywhere in its name.

### Filtering and columns

Metadata columns such as "Media Type," "Resolution," or "Comment" can be added and sorted to refine results. Use column sorting together with the search text field to bring up the exact assets you need.

### Search in the Media Browser

The Media Browser is used to browse storage drives and import assets. Enter text in the Search box at the top of the Media Browser to locate files on disk by name. This search is helpful while browsing external media, rather than only searching items already imported into the Project panel.

## Find assets using the Find dialog

### Search for clips, sequences, and other project items in Adobe Premiere with advanced find controls.

In larger projects, the Project panel Search box is useful for narrowing what is visible. For stricter control, including case-sensitive matching, bin-scoped searching, or more exact filtering, open the Find dialog instead.

Use the Find dialog box when you need criteria-based searching across the full project or within a selected bin.

In the Project panel, select the Find icon (magnifying glass).

Enter keywords in the search field. More specific scene descriptions usually improve visual search results.

The Search panel can display Visuals, Audio, Text, and Metadata results together. To limit the view to one result category, use the dropdown menu.

Tip

- Multi-word searches will often work better than single words.

Advanced filtering in the Search panel narrows results more precisely. Metadata-based filters help you find particular clips or assets faster when a project is large.

Open the Search panel, then type a term in the search field.

Select the filter button beside the search field to show advanced filtering options.

Use advanced filtering to narrow results and save time by showing only items relevant to the current task.

### Search for markers

Marker metadata, including name, comments, and color, can be used in project searches. Matching markers appear as Search panel results so specific moments in media are easier to find.

Marker matches are grouped under Markers in the Search panel, with related metadata such as:

- Marker name
- Marker comments
- Marker color

Double-clicking a marker result sends the playhead to that marker in the Source Monitor or Timeline. With range markers, playback positioning starts at the beginning of the marked range. To add marker results to a timeline, select one or more results and drag them into a sequence.

Use the Search panel to find markers, then filter those results by marker metadata.

Marker searches can be run from the Search panel, with marker metadata available for filtering.

### Privacy and data usage

Footage, analysis data, and search terms remain on your computer and are not viewed by Adobe. The AI models used for analysis and search are installed locally and can function without internet access. Adobe does not train on your footage or searches.

## Manage media intelligence metadata

### Manage Media Intelligence metadata in Adobe Premiere through the Media Analysis & Transcription preferences section.

The Media Analysis & Transcription section of Premiere preferences includes additional Transcription options for managing analysis.

Use Media Analysis & Transcription settings to decide how Premiere analyzes footage for visual search, speech-to-text, and metadata.

Media Analysis & Transcription settings control Premiere analysis for visual search, speech-to-text, and metadata.

Premiere caches analysis results so footage reused across projects or by other users does not always need to be processed again. Select the metadata storage method that best fits the workflow.

- In the Media Cache: Selected by default. Stores analysis results in the Media Cache location configured in Preferences > Media Cache. When a clip is imported into another project, Premiere skips analysis if a cache already exists for that clip. Because the Media Cache is local to each user, other computers cannot reuse that analysis.
- Next to the media as a sidecar file: Stores analysis results as sidecar files beside each analyzed or transcribed clip, using files with the .prmi extension. Media can be shared with those sidecar files on other computers, and Premiere uses the sidecar to avoid reanalyzing the footage. This preference is recommended for Production workflows.
- Do not cache: Saves the analysis results directly in project data or the project index. Importing the same clip into another project or onto another computer requires analysis to run again.

## Locate and link offline files

### Link an offline clip back to a source file in Premiere.

When a project opens with missing media, the Link Media dialog box shows which files have broken links and provides tools for finding and reconnecting them.

The Link Media dialog box lists the clip name used by the project and the media file's linked filename. It also shows the full folder path where the offline media was stored.

In the Project panel, select one or more clips that are offline.

Choose File > Link Media.

When a project contains offline media, the Link Media workflow can reconnect that media for the project.

For projects with offline media, use Link Media to bring the missing files back online.

Choose the needed search criteria and Match File Properties according to how the offline files should be handled.

### Match File Properties

Missing media can be located more effectively by selecting properties such as File Name, File Extension, Media Start, and Tape Name. Metadata properties, including Description, Scene, Shot, and Log Note, can also be selected.

After you select Locate, the Locate File dialog box shows matches based on the chosen Match File Properties. To match and link media, at least one property under Match File Properties must be selected.

Note

The selected combination of Match File Properties should uniquely identify every media file in the relink set.
