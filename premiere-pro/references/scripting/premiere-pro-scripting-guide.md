# Premiere Pro Scripting Guide

This reference collects public details about methods and members exposed through the ExtendScript API.

Through its ExtendScript-based API, Premiere Pro can be controlled broadly across the application. ExtendScript can reach and modify most project content, including metadata plus export and render settings.

Adobe invites questions, problem reports, and feature requests so integrations can work successfully.

## Scope

This guide is not a tutorial for ExtendScript, ExtendScript debugging, or general development methods. Its scope is the Premiere Pro ExtendScript API and the runtime context used by scripts.

The Premiere Pro ExtendScript API began as an incomplete interface meant only for internal testing and has expanded for many years. In 12.1.1, the release current when the source was written, it provides extensive access to, and often control of, project elements and application settings.
