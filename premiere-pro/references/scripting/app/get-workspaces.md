# app.getWorkspaces()

app.getWorkspaces()

### Description

Fetches the available workspaces as an array of Strings.

### Parameters

None.

### Returns

On success, returns an array of strings; on failure, returns null.

### Example

Workspace-list example.

```javascript
app.getWorkspaces();
/* [
    "All Panels",
    "Assembly",
    "Audio",
    "Color",
    "Editing",
    "Effects",
    "Graphics",
    "Learning",
    "Libraries",
    "Metalogging",
    "Production"
]; */
```
