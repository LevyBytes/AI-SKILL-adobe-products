# app.setSDKEventMessage()

app.setSDKEventMessage(message, decorator)

### Description

Adds a text entry to Premiere Pro's Events panel.

### Parameters

| Parameter | Type | Description |
| --- | --- | --- |
| message | String | Text that should appear. |
| decorator | String | Decorator value, chosen from: - info - warning - error |

### Returns

On success, returns true.
