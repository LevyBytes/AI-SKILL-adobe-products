# Marker.type

app.project.activeSequence.markers.getFirstMarker().type

app.project.rootItem.children[index].getMarkers().getFirstMarker().type

### Description

Marker type, one of:

- "Comment"
- "Chapter"
- "Segmentation"
- "WebLink"

Note

Import can bring in marker types that Premiere Pro itself cannot create.

### Type

String; read-only.
