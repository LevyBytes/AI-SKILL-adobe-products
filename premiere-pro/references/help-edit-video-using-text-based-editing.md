## Overview of Text-Based editing

### Build and revise video sequences from transcripts with Text-Based Editing in Adobe Premiere.

Text-Based Editing builds video sequences from a transcript of the footage. Selecting and moving transcript text automatically trims and adjusts the linked video clips on the timeline while preserving context. The visual changes can be reviewed as they happen. Timecode metadata is included in the transcript, and the transcript stays dynamically synced with timeline clips.

When you cut, copy, or paste text in the sequence transcript, the timeline updates to match those edits.

Timeline edits are reflected automatically when text is cut, copied, or pasted in the sequence transcript.

### Key features

- Auto-transcribe your source footage: Text-Based Editing can generate a transcript from video footage and align dialogue with timecodes, making the edit easier to navigate. The transcript can be searched, used for navigation, and used to select clips. Only videos that contain spoken dialogue can be transcribed. If full source-media transcription is unnecessary, import media normally and transcribe only the individual files you need.
- Rough-cut your videos according to the text: Build video sequences by selecting, cutting, and rearranging transcript text. Text edits cause the matching video clips to be trimmed and placed on the timeline automatically, which makes rough-cut work faster and more direct.
- Edit precisely: Make detailed cut refinements on the timeline. Clip timing, transitions, and video edits can be tuned so they line up closely with spoken-word timing, keeping the audio and visuals synchronized. Text-Based Editing also supports three-point edits for building a sequence on the timeline.
- Cost-effective: Text-Based Editing is available at no extra cost as part of the subscription.
- Generate accurate transcripts: Premiere uses Adobe Sensei's AI to auto-transcribe dialogue with reliable, industry-standard results that usually need little manual cleanup.
- Manage filler words and speaker dialogue: Find filler words such as uh and umm in transcripts and remove them in bulk. You can also filter the transcript by a specific speaker's dialogue and delete that dialogue from the video.

For the best Text-Based Editing results, use dialogue recordings with clear audio and little background noise.

## Add clips to the timeline using Text-Based Editing

### Use Text-Based Editing in Adobe Premiere to make three-point edits while building a sequence on the timeline.

Tip

Only video that contains spoken dialogue needs transcription. When not all source media requires transcripts, import the media normally and transcribe only selected files afterward.

Start Premiere and create a new project.

Choose the media to import, then open the Text-Based Editing workspace.

In the Project panel, double-click each clip that needs transcription.

From the Text panel, choose Transcribe.

If the clip still needs a transcript, use Transcribe in the Transcript window. Review the transcript text, or search for the material you want to use.

In the transcript panel, highlight the desired text and select Insert to add that selection to the sequence.

Keep adding clips from source media until every clip you plan to use appears on the Timeline.

## Transcribe video

### Transcribe source media during video editing with Text-Based Editing in Adobe Premiere.

Most video edits begin by choosing usable content and arranging it on the timeline into a rough cut. Text-Based Editing provides a fast way to perform that selection and arrangement.

Start Premiere and create a new project.

Choose the media you want to import.

In the upper-right Import settings panel, enable Automatic transcription and set Transcription preferences so imported clips are transcribed automatically. Language and Speaker labeling can also be changed to match your needs.

Turn on Automatic transcription and configure Transcription preferences to auto-transcribe all imported clips.

Use Automatic transcription with Transcription preferences configured for automatic transcription of imported clips.

Select Import.

After transcription finishes, open the Text-Based Editing workspace to review the transcripts.

## Edit transcripts using Text-Based Editing

### Correct transcript text while using Text-Based Editing in Adobe Premiere.

Create a new project, choose the import media, and switch to the Text-Based Editing workspace.

Double-click the clips that require transcription in the Project panel.

In the Text panel, select Transcribe.

Once the Text panel has transcribed the source clip, select the icon and then Export > Export to text file.

Apply the needed corrections in the source text.

Select Import > Import corrected transcript (txt).

Note

Premiere includes built-in spell check plus search and replace for fixing uncommon words or names. Use the text file only to correct spelling errors; deleting sections prevents the imported file from working.

## Detect and delete pauses in transcripts

### Detect pauses and remove fillers, text, or silences from transcripts in bulk with Text-Based Editing.

Text-Based Editing in Adobe Premiere can find speech pauses and bulk-delete fillers, text, or pauses from transcripts.

Create a new project, choose the media to import, and open the Text-Based Editing workspace.

In the Transcript panel, select the filter icon.

Choose Text, Filler words, Pauses, or Speakers as the material to remove.

Select Delete for one instance, or select Delete all to run a bulk delete action.

Removing text, filler words, pauses, or speakers can make dialogue in a clip sound cleaner.

Find those transcript elements and delete them to tighten the dialogue in the clip.

## Edit sequences using Text-Based Editing

### Edit a sequence from the Text-Based Editing workspace in Adobe Premiere.

When clips are added to the timeline, Adobe Premiere creates a new sequence transcript that can be used to shape the rough cut.

Create a new project, choose import media, and move into the Text-Based Editing workspace.

Double-click clips needing transcription in the Project panel.

In the Text panel, select Transcribe.

Select the Timeline panel to move into the sequence transcript and continue editing.

In the sequence transcript, select text and use copy or paste to move clips; the timeline receives those text edits automatically.

Cutting or deleting text can also remove clips from the sequence. Premiere applies a Ripple Edit in the Sequence automatically.

After the rough cut is in place, move to video editing tools for trimming, refinement, pacing, color grading, audio sweetening, titles, or graphics.

During the workflow, the sequence transcript can serve as a navigation aid or an editing surface for the sequence.

The sequence transcript remains useful both for moving around the sequence and for making edits.

## Remove all instances of one speaker in transcript

### Select every line from a particular speaker in a transcript and remove that dialogue from the video.

Go to the Transcript tab of the Text panel. In the top-left corner, select the Filter icon and then select Speakers.

In the speaker drop-down menu, choose the speaker whose dialogue should be removed.

Select Delete.

Text-Based Editing can remove irrelevant dialogue from the timeline, including interviewer audio or other off-camera conversation in unscripted content.

Use Text-Based Editing to clear unneeded dialogue from a timeline, especially interviewers or off-camera talk in unscripted material. Note

Only sequence or timeline dialogue can be deleted. Source transcriptions cannot have footage removed.

## Multichannel audio support in Text-Based Editing

### Understand multichannel audio support in Text-Based Editing.

Text-Based Editing can transcribe a selected channel from an audio file or use a mix of all channels when multichannel audio support is available.

Separate microphones may be recorded onto different channels within some audio files. With multichannel audio support in Text-Based Editing, transcription can use one chosen channel or a mix of every channel. The feature applies to audio files in a multichannel mono format.

Use the Channel selection option to choose the microphone channel where the audio was recorded, or choose Mix when two speakers were recorded on two different microphones.

While transcribing an audio file, choose the needed channel or the Mix option.

Pick among available channels or use Mix according to the transcription need for the audio file.
