## Import media from Firefly Boards to Premiere on desktop

Adobe Firefly Boards images and videos can be handed directly to Adobe Premiere on desktop for editing.

Firefly Boards supports early concept exploration, moodboard creation, storyboard development, and pitch-material preparation. When the work is ready to move into production, supported images and videos can be sent directly into Premiere, where they arrive as editable project assets.

Create a new project in Firefly Boards, or open an existing one.

Select one or more supported assets:

- One image or video.
- Several images.
- Several videos.
- A mix of images and videos.

Choose one action:

- Use the context menu on the selected assets and choose Open in Premiere desktop, or
- From the More options menu, select Open in Premiere desktop.

Use this action to move selected images or videos from Firefly Boards into Premiere for additional editing.

The selected image or video assets are transferred from Firefly Boards to Premiere so editing can continue.

If needed, Premiere opens and then imports the selected assets:

- With a project already open, the assets go into the Project panel > Firefly Downloads bin.
- With no project open, Premiere creates a new Untitled project and brings the assets into the Project panel.

Tip

By default, imported assets download to My Documents > Adobe > Premiere Pro > 26.0 > Cloud Media. In Premiere, this location can be changed by going to Preferences > Cloud Media Downloads and choosing a custom folder for Firefly downloads.

### Supported assets

These Firefly Boards asset types can open in Premiere:

- Generated video files: any Premiere-supported container or codec, including videos with audio generated by third-party models.
- Generated images: any container or codec that Premiere supports.
- User-uploaded video files: any Premiere-supported container or codec.
- Photoshop and Illustrator files: brought in as image files.

### Unsupported assets

These Firefly Boards asset types cannot be imported into Premiere:

- Text
- Graphics
- Artboards
- 3D objects

## Importing digital audio

### Learn how audio formats, sample rates, and conforming influence Adobe Premiere project quality and workflow.

Imported audio is handled by Premiere according to details such as file format, sample rate, and compression method. Knowing those technical variables helps you choose audio quality deliberately and predict how Premiere will prepare files when they enter a project.

Digital audio is stored as binary information on hard disks, audio CDs, or digital audio tape (DAT). For the cleanest transfer, move those files through a digital path instead of routing analog outputs through a sound card, which adds avoidable quality degradation.

### Audio source formats

Before Premiere can use audio from some sources, the files may need different preparation. Audio CD (CDA) files are not imported directly; convert them first with audio software such as Adobe Audition into a supported format, for example WAV or AIFF. That conversion keeps the original quality while making the media usable in the project.

Formats such as MP3 and WMA reduce file size by permanently discarding parts of the original audio data. On import, Premiere decompresses those files and, when needed, resamples them so they fit the sequence settings. Its resampling algorithms are high quality, but uncompressed or CD-quality sources give better results because removed audio detail cannot be restored.

### Native sample rate support

Internally, Premiere works with every audio item as 32-bit floating-point data at the sequence sample rate. Using that processing model helps preserve editing performance and audio fidelity across the workflow. These native rates are supported: 8000 Hz, 11025 Hz, 22050 Hz, 32000 Hz, 44100 Hz, 48000 Hz, and 96000 Hz.

### Audio conforming behavior

Conforming is the conversion Premiere performs when it prepares audio files for its internal working format. It happens during import, and it can influence both timeline responsiveness and how much disk space the project uses. The conformed audio is written as CFA (Conformed Audio) files in the scratch disk location chosen for audio previews.

For uncompressed files recorded at sample rates Premiere supports natively, no conforming is needed when the sequence uses the same sample rate. If the sample rates do not match, conforming is deferred until export or audio preview creation. Audio recorded at unsupported sample rates is raised to the closest supported rate; a 11024 Hz source, for example, becomes 11025 Hz.

Every compressed audio file is conformed during import at the source sample rate. For example, a 44100 Hz MP3 file is conformed at 44100 Hz and then plays at the sequence sample rate when the sequence differs, with no extra processing step. After a file has been conformed, Premiere reuses that conformed version in any sequence with the same sample rate as long as the original file has not been moved or renamed.

Premiere also generates PEK (peak) files for imported audio so waveforms can be drawn in the Timeline panel. Those files live in the Media Cache Files location and remain available across sessions.

### How Premiere processes audio

All audio channels in Premiere, including audio embedded in video clips, are processed as 32-bit floating-point data at the sequence sample rate. This processing keeps editing performance and audio quality consistent throughout the project.

### Audio conforming behavior

Some audio types are converted by Premiere to the 32-bit format and the sequence sample rate the first time the files are imported into a project. During conforming, a progress bar is shown in the lower-right corner, and the conformed audio is saved as CFA preview files in the Audio Previews scratch disk location you selected.

Effects and editing can still be applied to audio files before conforming has finished, but preview playback is limited to sections that are already conformed.

### Conforming rules by audio type

### Uncompressed audio

- No conforming: audio recorded at natively supported sample rates and placed in sequences that use matching sample rates
- Delayed conforming: audio placed in sequences with different sample rates; conforming happens only during export or audio preview file creation
- Immediate conforming: audio recorded at non-supported sample rates; Premiere raises it to a supported rate or to an even multiple, with 11024 Hz becoming 11025 Hz, for example

### Compressed audio

Premiere conforms every compressed audio format (MP3, WMA, MPEG, compressed MOV files) using each file's original sample rate. When conformed audio is placed in a sequence that uses another sample rate, playback uses the sequence rate and does not trigger another conforming pass.

Note

To prevent conforming delays, convert files with audio editing or transcoding software before import, using uncompressed formats at natively supported sample rates.

### Related files

When audio is imported, Premiere builds PEK files for waveform display. They are stored under Media Cache Files, configured in Preferences > Media, while conformed audio uses separate files.

## Audio conforming specifications

### Learn the technical specifications for audio conforming in Adobe Premiere projects.

Use this reference while importing audio to understand conforming behavior, estimate how long processing may take, or diagnose playback problems caused by sample-rate mismatches.

### Audio conforming overview

Premiere handles every audio channel as 32-bit floating-point data at the sequence sample rate. If imported audio does not already match that format, Premiere conforms it automatically on first import and creates CFA (Conformed Audio) preview files in the location set for Audio Previews in Project Settings.

The time and storage required for conforming scale with file duration. While conforming runs, a progress indicator is displayed in the lower-right corner of the application window. Audio files remain editable before the process finishes, but preview playback works only for portions that have already been conformed.

### Conformed file management

As long as source files have not been moved or renamed, Premiere can reuse conformed files in sequences that share the same audio sample rate. For every imported audio item, the Media Cache Database records the conform-file path.

Storage locations:

- CFA files: Audio Previews scratch disk location (Project Settings > Scratch Disks)
- PEK waveform files: Media Cache Files location (Preferences > Media)

PEK files are generated for every imported file that contains audio, and Timeline panels use them to draw waveforms.

### Avoiding conforming

To avoid conforming work:

- Convert files to uncompressed formats (WAV, AIFF) with audio editing software.
- Export at one of the natively supported sample rates.
- When practical, match the target sequence sample rate.

For compressed formats, decompress to uncompressed formats before import instead of depending on Premiere to decompress them.

## Import projects as project shortcuts

### Learn what project shortcuts are and how to use them in Adobe Premiere.

Note

Starting with Premiere 14.1, Shared Projects are now called Project Shortcuts. Older shared projects in Premiere can still be used through Project Shortcuts. For new collaboration work with other people, consider the Production workflow.

Project Shortcuts act as fast links for opening other projects. Premiere lets you import projects as project shortcuts.

Choose File > Import, then choose the project (.prproj) file to import.

In the Import Project dialog box, choose Import as Project Shortcut, then choose OK.

The Import as Project Shortcut option adds another Premiere project to the current project as a linked shortcut.

You can use Import as Project Shortcut to place another Premiere project in the current project as a linked shortcut.

After import, the project appears in the Project panel with an indication that it links to the other project.

## Import and export presets

### Learn how to move presets between devices by importing and exporting them in Adobe Premiere.

Custom presets can be moved from one computer to another, including an offline computer, by exporting them manually and then importing them. In the preset list, select more than one preset with Shift + click (Windows) or Cmd/Ctrl + click (macOS).

### Source device

On the source computer that contains the presets you want to move, follow these steps:

Open Preset Manager.

Select Export Presets.

Choose the presets you want, then select Export.

Choose the folder where the presets will be exported. Use a folder that can be transferred with a USB drive, network, or online sharing service.

Select Save.

### Target device

On the target computer that will receive the imported settings, follow these steps:

Open Preset Manager.

Select Import Presets.

Choose the presets to import, then select Open.

Note

Presets created in Adobe Media Encoder are added automatically to the Preset Manager in Premiere. To make them appear in the Preset menu, mark them as favorites.

## Import selected Premiere sequences

### Import selected sequences and clips from other Adobe Premiere projects

Premiere can bring in material from projects created by earlier Premiere versions on macOS or Windows. On Windows, projects from older Premiere releases can also be imported. After import, the project's clips and sequences appear in the Project panel inside a bin that uses the imported project's name. The original bin nesting is kept inside that new bin, but obsolete transitions and effects are not preserved. Be careful when the destination project uses a different time base or audio sample rate, since those mismatches can change edit placement or reduce audio quality.

To carry over the full sequence and clip data from one project into another, import the project itself. You can also choose one or more specific sequences from a different Premiere project.

Premiere for macOS can open Premiere for Windows projects, including content that those projects previously imported from older versions.

Note

Older Adobe Premiere releases stored storyboards as files separate from project files. Current Premiere keeps the storyboard-related workflow inside the Project panel. On Windows, storyboard files from earlier versions can be brought in with File > Import.

Before importing a sequence and its media, consolidate the source project with the Project Manager so the files are collected and copied into a new location.

Choose File, browse to the project file that contains the sequence or sequences you need, and select that project.

Select Open.

When the Import Project dialog box appears, choose whether Premiere should bring in the full project or only selected sequences, then select OK.

In the Import Premiere Pro Sequence dialog box, select every sequence to import, then select OK.

## Import XML files from Final Cut Pro X

Premiere supports moving projects, selected clips, or selected sequences out of Final Cut Pro X only after they are converted into a format Premiere can read.

Final Cut Pro X writes .fcpxml files, and Premiere does not import that format directly. Convert the Final Cut Pro X project with the XtoCC conversion tool so the result is a standard XML file that Premiere recognizes.

Before you begin:

Confirm that XtoCC is available and that your Final Cut Pro X project has already been exported as a .fcpxml file.

### Import the converted XML into Premiere

Export the FCP X project as an XML file.

For additional details, check the Final Cut Pro documentation.

Use XtoCC to turn the XML file into a version Premiere can interpret.

In Premiere, choose File > Import.

Browse to the folder that contains the converted XML file.

Select the XML file, then select Open.

If Premiere displays import settings, choose the appropriate settings, then select OK.

Some Final Cut Pro X project elements will not map cleanly into Premiere. Complex effects, transitions, and third-party plugins may fail to transfer exactly. Review the supported and unsupported element list so linked media, edit points, and translated content can be checked.

## Import Avid Media Composer project files

Use an AAF file when moving an Avid Media Composer export into Premiere.

Premiere cannot open native Avid Media Composer (.avf) project files. Export an AAF file from Avid Media Composer first, and then import that AAF file into Premiere.

Open an existing Premiere project or make a new one.

Go to the Project panel and choose File > Import.

Find the AAF file that was exported earlier, then select Import.

Premiere adds a sequence named for the AAF file to the Project panel and creates a bin containing the media used by that sequence.

When translation problems occur, Premiere places an FCP Translation Results file in the main bin.

Open the sequence and scrub through it to verify that the edit behaves as expected.

To inspect the report, double-click FCP Translation Results in the bin.

On Mac, the report opens in TextEdit; on Windows devices, it opens in Notepad. The report explains how Premiere handled effects, titles, or transitions that could not be translated.
