## About Creative Cloud Libraries

### Creative Cloud Libraries provide assets you can access from Adobe Premiere.

Creative Cloud Libraries can collect assets from Creative Cloud desktop apps, mobile apps, or Adobe Stock downloads so those assets can be used in projects.

### The Libraries panel

Premiere shows Creative Cloud Libraries in the Libraries panel.

- On the Premiere start screen, select Libraries to show Creative Cloud Libraries at launch.
- From the Start screen, download or sync a Creative Cloud Library to the desktop by selecting Libraries > [library-name], then choosing Sync to CC Libraries on the Library card at the bottom of the screen.
- Open the Creative Cloud Library (Libraries panel) by selecting Window > Libraries.

Libraries can be accessed in these ways:

### Across projects

Assets saved in the Libraries panel are available in any Premiere project you work on.

### Across computers

Libraries sync to Creative Cloud. Your Library is available on any computer where you sign in with your Creative Cloud ID.

### Across apps

Items saved in the Libraries panel automatically become available in desktop and mobile apps that support Creative Cloud Libraries. For example, Libraries can be opened from desktop apps such as After Effects and Photoshop.

## Add a Creative Cloud library

### Create and add a Creative Cloud library in Adobe Premiere.

Create as many libraries as needed to organize assets. Premiere lists those created libraries in the Library panel.

From the Libraries panel menu, select Create new library.

Type a library name, then select Create.

## Add Looks to a Creative Cloud Library

### Add a Look to the Creative Cloud library in Adobe Premiere.

After color grading is applied to a clip, that information can be saved as a Look. You can also upload it to the library.

In a sequence, select a clip or track item in the Timeline panel.

Make sure the Lumetri Color panel is focused and that the clip has a Lumetri effect applied.

Select the Add Look icon at the bottom of the Libraries panel.

Under Add elements, choose Look so the selected look is added to the Creative Cloud library.

Under Add elements, choose Look so the selected look is added to the Creative Cloud library.

Premiere creates a Look file using the selected clip's name. The Libraries panel shows the uploaded Look as a thumbnail.

## Add assets from Adobe Stock to a Creative Cloud library

### Add Adobe Stock assets to a Creative Cloud library in Adobe Premiere.

Premiere can search Adobe Stock from inside the app, giving access to millions of high-quality, royalty-free photos, videos, illustrations, and graphics that can be saved into a Creative Cloud library.

Open the Libraries panel with Window > Libraries.

From the search options dropdown menu, show the available locations and choose Adobe Stock.

Type your terms in the Search Adobe Stock search bar. Matching results appear directly in the panel.

After you find an asset you want, either license it immediately and save it to your library in Premiere, or save an unlicensed preview (watermarked) copy now and license that item later.

For an immediate purchase, select the asset, select the License and save icon, and complete the purchase flow.

To store an unlicensed preview, select the asset and then select the Save preview to <Library Name> icon.

Preview assets in a library can be licensed later. Select the item, then use License Image for a still preview or License Video for a video preview. After licensing, every linked use of that asset in open files updates automatically to the licensed, high-resolution version with the watermark removed.

Tip

When Adobe Stock assets do not appear in the library automatically, select the Sync button at the lower-right corner of the panel to run a manual sync. The assets then show in the library.

After an asset is licensed, Premiere swaps any unlicensed copies in sequences for the full-quality version while keeping the edits intact.

## Use assets stored in Creative Cloud Libraries

### Use assets and Looks from Libraries in Adobe Premiere projects.

The Libraries panel in Premiere gives projects direct access to stored creative assets. You can drag a saved graphic element into a timeline, or apply a custom Look to shape footage, so library content can move into the edit without a separate import workflow.

### Graphic element

To place a graphic from a library, drag the graphic element out of the Libraries panel into either the Project panel or the Timeline panel. You can also right-click the graphic and choose Add to Project. Premiere brings the graphic element in as a project item and, when placed in the timeline, makes it a default-duration still-image clip.

### Look

To use a saved Look, drag the Look from the Libraries panel onto an item in the Project panel or Timeline panel.

### Drag a Look to timeline

- Dragging a Look from the Libraries panel to a clip in the timeline adds a Lumetri Color effect to that timeline item. If that track already has a Lumetri Color effect, Premiere updates the existing effect with the new Look.
- When the track item is visible in the Program Monitor, Premiere renders the effect.
- The Effect Controls panel receives a Lumetri Color effect.

As another route, choose a sequence clip, right-click the library look, and choose Apply Look.

### Drag a Look to the Project panel

- Dragging a Look from the Libraries panel onto a project item in the Project panel applies a Lumetri Color effect to the master clip.
- When the track item is visible in the Source Monitor, Premiere renders the effect.
- The master clip gets a Lumetri Color effect in the Effect Controls panel.

Note

- For a Look with the .cube filename extension, Premiere sets the Input LUT field in the Basic Correction section of the Lumetri Color panel to that Look.
- For a Look with the .look filename extension, Premiere sets the Look field in the Creative section of the Lumetri Color panel to that Look.

## Collaborate with Creative Cloud users

### Share libraries with other Creative Cloud users so they can view, edit, or use shared-library contents.

Note

When another Creative Cloud subscriber shares a library with you, you may also share that library onward with additional Creative Cloud users.

### Share a library

In the Libraries panel, open the pop-up menu and choose Collaborate.

On the browser page that opens, enter the email address for the person receiving access, and add an optional message if needed.

### Join a shared library

Open the Adobe Creative Cloud desktop app and sign in with your Adobe ID credentials.

If someone shares a library with you, the Creative Cloud desktop app shows a notification. Select the bell icon to open notifications.

For each library collaboration invitation, select Accept.
