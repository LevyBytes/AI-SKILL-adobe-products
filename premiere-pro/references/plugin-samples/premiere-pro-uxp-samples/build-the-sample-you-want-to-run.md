# 2. Build the sample you want to run

Build expectations vary by sample, including samples that do not require a build step.

**[`premiere-api`](../premiere-api/reference-index.md) — TypeScript; build required**
For complete setup and build steps, use the [`premiere-api` README](../premiere-api.md).

**[`metadata-handler`](../metadata-handler-panel.md) — JavaScript; no build required**
This sample needs no install or build command. Setup details are in the [`metadata-handler` README](../metadata-handler-panel.md).

**[`oauth-workflow-sample`](../how-to-integrate-with-o-auth/overview-of-the-o-auth-workflow.md) — JavaScript; uses a local Node.js server**
Before the first run, use the [`oauth-workflow-sample` README](../how-to-integrate-with-o-auth/reference-index.md) to configure credentials and the local server.
