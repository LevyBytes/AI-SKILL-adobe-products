# Beta APIs (preview of upcoming surface) - Linting

In `premiere-api`, frequent Premiere UXP API mistakes are caught with Adobe's [`@adobe/eslint-plugin-premierepro`](https://www.npmjs.com/package/@adobe/eslint-plugin-premierepro) plugin. Add that plugin to your own projects when the same lint coverage is useful.

```bash
cd sample-panels/premiere-api
npm run lint
```
