- Freeform View

## Customize the Icon View in Project panel

### Customize Icon View in the Project panel so clips appear as thumbnails for easier organization, preview, and editing.

The view mode icons change the media display and help arrange clips visually for quicker navigation.

View mode icons also let you choose the media presentation and keep clips organized for faster movement through the panel.

These asset actions are available in icon View:

Use the Zoom slider when increasing or decreasing icon size. Icons can be enlarged enough to make media contents easier to inspect.

Set a poster frame by dragging the playhead or shuttle to the desired frame, then pressing Shift + P (Windows) or Command + P (macOS). Clear that poster frame with Ctrl + Shift + P (Windows) or Option + P (macOS).

To check whether a clip is already used in a sequence, hover the mouse over the filmstrip icon and read the tool tip. The indicator also reports how many times the clip appears in the sequence.

To find that clip inside a sequence, select the filmstrip icon, then use the context menu to choose the target sequence and its timecode location. Premiere moves the playhead to the clip in that sequence.

To rearrange items in Icon View, drag an item to another grid position. During the drag, a vertical bar marks the destination. Dropping an item onto a bin places that item inside the bin.

Use either of these approaches to scrub clip contents:

Move the cursor across a clip thumbnail to scrub through the media without clicking; this behavior is Hover Scrub. Scrubbing left to right previews from the Media Start on the left through the Media End on the right.

Tip

Moving the cursor away from the thumbnail, or changing focus, returns the thumbnail to its poster frame. Audio is not played during Hover Scrub.

- Disable Hover Scrub from the Project panel menu, or press Shift + H.
- When Hover Scrub is off, hold Shift to enable it temporarily.
- While hover scrubbing, press I and O to set In and Out points.
- While hovering over a clip, double-click its icon to open it in the Source Monitor at the hovered frame for fast insert or overwrite edits to the timeline.

Scrub a clip by clicking and dragging the playhead across the slider.

- Clicking the slider on the thumbnail makes a clip playhead appear.
- Drag that playhead to inspect clip contents or monitor audio.
- Press J for reverse shuttle, K to pause, or L to play forward through the clip.
- During pause or shuttle playback, press I and O to define In and Out points; a yellow bar marks the selected section.

Note

On a MacBook Pro, the Multi-Touch trackpad can resize thumbnails in the Project panel and Media Browser with pinch and zoom.

Icon View can be used to put clips into storyboard order before sending that storyboard into a sequence with Automate To Sequence.

### Sort icons in the Icon View

To sort icons in the Icon View, select the Sort Icons icon in the Project panel. The sort menu includes:

- User Order: arrange icons yourself by dragging them into the preferred order.
- List View Sort: reuse the sorting choice from List View; for example, a Media Duration sort in List View also applies after switching to the Icon View.
- Metadata Sort: order icons by common metadata fields such as Name, Label, or Media Type, with ascending or descending direction available.

Icon View clips can be sorted by manual placement, List View sorting, or metadata values such as name and media type.

Manual order, list-view criteria, and metadata fields such as name and media type are all supported for sorting clips in Icon View.

## Customize Freeform view in Project panel

Customize Freeform View in the Project panel when clips need to be arranged, grouped, and compared visually with more flexibility.

### Customize Freeform View in the Project panel when clips need to be arranged, grouped, and compared visually with more flexibility.

Freeform View lets clips sit in a custom layout instead of forcing them into a grid or sort order. This view is useful for spatial thinking, stacking or grouping media files, and arranging clips as storyboards or assembly edits. A project can store multiple layouts and switch among them. Freeform View supports several related actions.

### Zoom in and out of clips

Change clip zoom with any of these controls:

- Scroll the mouse wheel while holding Option (macOS) or Alt (Windows)
- Use a trackpad pinch gesture
- Press the + and - keyboard shortcuts
- Adjust the zoom slider control; double-clicking it restores default zoom

Snap the edges of a clip to another: Hold Alt (Windows) or Option (macOS) during the drag so the clip edge snaps against another clip edge.

This places one clip directly beside another so the two connect without a gap.

Align all or selected clips to grid: Select the clips, open the context menu with right-click, then choose Align to Grid.

Selected clips are arranged neatly and lined up automatically to an even grid.

Adjust the size of clips: Select clips, right-click, choose Clip Size, and then select a size option. Medium is the default clip size.

Changing clip size makes clips larger or smaller in the workspace, which can improve visibility or fit more clips into the view.

Hover scrub the clips: Scrub by moving the mouse pointer left and right over a clip. Use I and O to mark the In point and Out point.

Moving the cursor over a clip gives a quick preview and lets you set editing start and end points.

### Customize List View columns

Project panel List View metadata columns describe the listed assets. Premiere can show selected XMP metadata fields as well as clip data fields. You can decide which metadata columns appear, add schema properties, and reorder columns. Those column choices are saved inside the project file, so reopening the project brings back the same Project panel column set.

From the Project panel menu, choose Metadata Display, then use any of these options:

- To show every column in a metadata schema in the Project panels, check the box beside the schema name.
- To show selected columns from one or more schemas, open the schema names with their triangles. Then check the boxes beside the column names to display.

Use Metadata Display to choose which metadata columns appear in the Project panels.

Metadata Display controls the metadata columns shown in the Project panels. Note

If a property cannot be found or changed in the Metadata Display dialog box, Adobe Premiere has locked it and prevents editing. For example, properties you created can be deleted, but built-in properties from the Premiere project metadata cannot be removed.

Select OK.

### Rearrange columns

In the Project panel's List View, move a column by dragging its column header horizontally to the desired position.

To resize a column, place the mouse over the divider between column headings. Drag horizontally after the Column Resize icon appears.

To sort by a column, select that column name; each selection toggles between ascending and descending order for that column's contents.

### Add columns

Choose Metadata Display from the Project panel menu.

Select Add Property.

Enter a column name.

Choose a type:

- Integer: permits whole-number values only.
- Real: permits decimal values up to two digits.
- Text: accepts any text that you enter.
- Boolean: provides a Boolean-term option for the column.

Custom data columns can be created to organize project details.

Use custom data columns when project details need additional organization.

Select OK, then select OK again.

## Customize the position of the Project panel

### Adjust the Project panel position to better fit the workspace.

When a Project panel is opened for a particular project and binned into a workspace for the first time, Premiere chooses its default location using these rules:

- If any project panels are already open in the workspace, Premiere places the new Project panel in the same workspace frame as those project panels.
- If no project panels are open, Premiere uses the workspace frame that contains the Media Browser.
- If no Media Browser panels are open, Premiere uses the workspace frame that contains the Effects panel.
- If the Effects Panel isn't open, Premiere uses the workspace frame that contains the Effect Controls panel.

The Project panel location can still be adjusted to match the workflow.

Move the Project panel by selecting it and dragging it to the desired location.

The Project panel can also be docked or left floating. Use the docking and undocking panel guidance to learn how to dock, group, or float panels.

Drag and drop the selected Project panel into the preferred position in the workflow.

Move the selected Project panel by dragging and dropping it where the workflow needs it. Tip

When a Project panel is docked by itself without any other tabs beside it, Premiere might not always retain its position. Include another panel, such as the Media Browser, with it to avoid this issue.

## Restore or delete layouts in Freeform View in Project panel

### Restore or remove saved Freeform view layouts in Adobe Premiere.

### Restore layouts

Saved layouts can be returned to an earlier state.

To restore an older saved layout, right-click a blank area in Freeform View, then choose Restore Layout from the context menu.

From that context menu, choose the layout to bring back.

### Delete layouts

Projects can be tidied by reducing how many saved layouts they contain.

To remove layouts that are no longer needed:

Right-click a blank area in Freeform View and choose Manage Saved Layouts.

For each layout to remove, enable its Delete checkbox, then select OK.

Manage Presets dialog box used for deleting saved layouts.

Manage Presets dialog box used for deleting saved layouts. Note

Premiere removes the selected layout immediately; there is no extra confirmation and the deletion cannot be undone.
