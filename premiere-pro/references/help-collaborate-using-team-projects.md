## When to use Team Projects and when to use Productions

### Understand how Team Projects and Productions differ, and when each workflow fits.

Team Projects support collaboration by multiple users while keeping the project file in the cloud. Productions are intended for long-form work where splitting the project into smaller pieces improves collaboration and media management. In a Production, everyone must be able to reach the same media through mirrored drives, shared local storage, or shared cloud storage.

### Team Projects

Availability: Adobe Premiere and After Effects.

- Team Projects lets teammates edit inside one shared project.
- Add the people you want, then collaborate directly in the timeline.
- Cloud saving distributes updates to the team so everyone can keep working together.
- The workflow suits small teams, businesses, and individual collaborators.

### Productions

- Availability: Adobe Premiere.
- Split a large project into smaller projects to improve performance.
- Use the Production panel to arrange the large project into bins.
- Keep primary clips in one project, then reference them from the other projects to help performance.
- Bin locking lets larger teams work in different project files for the same shared feature.
- See teammates' activity without creating conflicts.
- Keep ownership of your timeline, or pass it to teammates once it is ready.
- Best suited to larger features.

## Collaboration using Team Projects

### More on Team Projects and collaborative editing in Premiere

Premiere uses Team Projects as its collaborative editing workflow. With Team Projects, collaborators can be added so editors work together in one shared timeline from anywhere.

Note

Every Creative Cloud subscription, including Creative Cloud Individual, includes Team Projects for Premiere and After Effects.

To turn a Premiere project into a Team Projects project, choose Edit > Team Project > Convert to Team Project. After conversion, collaborators can be added.

All collaborators need access to the same media. Some customers still send hard drives, while cloud media-sharing and storage services are becoming more common. Frame.io is commonly used for cloud media transfer. Adobe also invests in LucidLink, which many customers use for media storage and sharing. After each collaborator can reach the media, they can link it to the shared project the same way they do in Team Projects and begin editing.

### System requirements for Team Projects

Team Projects has no separate system requirements. For the video applications that support it, check the current system requirements for Adobe Premiere, Adobe After Effects, and Adobe Media Encoder.

Note

To use the cloud-based service, stay connected to the internet and sign in to the Creative Cloud Desktop application with your Creative Cloud Adobe ID and password. Enterprise customers should confirm that their IT administrator has enabled Team Projects on the account.

## Add media

### Sharing media and importing it from shared storage solutions

Team Projects stores metadata and media references in a database hosted by Adobe Creative Cloud. Media used by Team Projects can live in several places, including network shared storage, a local hard drive, or cloud storage synced to desktops, such as LucidLink, Dropbox, Google Drive, or OneDrive.

Place media files in cloud storage synced to desktops, such as OneDrive, and add those files directly to Team Projects.

### Decide where to share your media

Adobe's guidance is to use a shared location that every team member can access.

- Cloud-based file-sharing options are convenient for remote access.
- Shared storage, such as a NAS, works when everyone can reach it remotely. Note that VPN is slow for media access.
- Sending each collaborator an external drive containing a media copy is also supported.

### Import media from that agreed upon shared storage

Choose File > Import or use the Media Browser panel. Import sources can include a local drive, network drive, or shared cloud storage solution such as LucidLink, Dropbox, Google Drive, or OneDrive.

Browse to the folder, mark the media for addition, and use the context menu's Import command.

Browse and import media files through the Media Browser panel.

The Media Browser panel lets you locate media and bring it into the project.

### Each team member accesses the shared media and maps them to the project

Every Team Projects collaborator must be able to reach the media. Share those media assets with the team by using these options:

- Creative Cloud files and network shared storage let collaborators access the media, download it locally, and map it to the project.
- Other cloud storage options, including LucidLink, Dropbox, Google Drive, and OneDrive, handle media mapping automatically.

## Manage media

### Relinking Premiere media in Team Projects and mapping media with Media Management

### Relink media in Premiere with Team Projects

When media goes missing, use the same relink workflow (Link Media) in Team Projects that you use in a Premiere project. This workflow changes only the local system and is not handled as a project edit, so no collaborator sharing is required.

Note

Enterprise users should confirm that their IT administrator has enabled the Team Projects service for the account.

### Invite groups to collaborate

Enterprises can invite synced groups created with Adobe Admin console Active Directory. In the invitations field, type the group name. When a group is selected for invitation, every member of that group receives an invitation to collaborate.

Group invitations do not update dynamically. If membership changes after the invitation is sent, new members do not receive an invitation automatically, and former members are not removed. Members can be added or removed individually from the Team Projects.

Note

Group size is limited. A group with 150 or more members cannot be invited.

## Visual cues during collaboration

### Visual cues that support collaboration between the current editor and other collaborators.

Premiere provides several visual signals for the active editor and for collaborators while they share a sequence. These status indications help teammates coordinate in the same timeline and avoid editing conflicts.

### Active collaborator

When you are the active collaborator currently changing a sequence, the sequence is locked so only you can edit it.

### Publish Status

When a different active collaborator is editing the sequence, you are prevented from changing that sequence. Until you update to the latest version, you can only view an older sequence state and cannot edit it or see collaborator changes made afterward.

### Other collaborators

If you are the active collaborator editing a sequence, other team members receive view-only access and see separate visual cues.

### Update Status

When another active collaborator edits the sequence in the Team Projects, you cannot make changes to that sequence. Status notifications and visual cues also appear in the Project and Timeline panels.

## Offline editing and cloud sync status

### Offline editing and cloud sync status while using Team Projects in Premiere.

When you collaborate in Team Projects, the cloud icon in the Premiere header bar shows online or offline status. It gives a quick readout of internet connectivity while you work in a shared project. If the connection drops, edits are saved locally and sync after connectivity returns.

Hovering over the cloud icon displays a tooltip with the most recent sync time for locally saved changes, or whether sync is pending.

Depending on connection state, the cloud icon tooltip may show these status strings:

- Project saved. Locally saved [Time]. Sync Pending.
- Project saved and synced. Last synced [Time].
- Disconnected. We will save your work until you reconnect. Locally saved [Time].

The Cloud icon shows that the project is online and recently synced.

The same icon can indicate an online state with the latest sync time.

Team Projects supports offline editing so work can continue during a temporary internet interruption. While offline, you cannot publish changes or retrieve the latest updates from collaborators, but edits continue to be saved locally. After reconnection, the Update and Publish buttons return.

Caution

Avoid using Team Projects for long periods while disconnected from the internet. Offline editing is intended as a safety measure for intermittent internet interruptions only.
