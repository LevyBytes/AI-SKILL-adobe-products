## Accessibility overview

### Accessibility features in Premiere

Use Premiere accessibility support when preparing videos that include audiences with visual, auditory, motor, and mobility needs.

Premiere includes accessibility features for people with visual, auditory, motor, and mobility special needs. It also provides tools for building videos that meet accessibility standards, helping more people use the content.

### User accessibility features

Premiere includes accessibility-focused capabilities that can make editing easier to navigate and use.

### Built-in accessibility features

Premiere provides features intended for people with different access needs, including users who rely on assistive technology. Software accessibility commonly includes items such as:

- Compatibility with screen readers
- Text alternatives for graphic content
- Keyboard shortcuts
- Display options with high contrast

Several of these areas are covered in Premiere through a mix of operating system support and Premiere-specific additions.

### Accessibility support for editors

Editors who work with assistive technologies can use these Premiere-related supports:

- Support for screen magnifiers (varies by OS)
- Keyboard access across key functions
- Works with most OS-level accessibility tools

Actual coverage can vary with the operating system, setup, and configuration in use.

### Create accessible video content

Premiere can also support accessibility in the videos you deliver. Built-in tools help you prepare content aligned with common accessibility guidance:

- Keep visuals from flashing, blinking, or updating automatically
- Apply strong contrast between text and backgrounds
- Provide captions for spoken content
- Add audio descriptions for information conveyed only visually

## Accessibility Support for Screen Readers and Magnifiers

### How Premiere works with screen readers, magnifiers, and OS-level accessibility features on macOS and Windows.

### Support for screen readers and screen magnifiers

Premiere has limited compatibility with assistive technologies such as screen readers and screen magnifiers. A screen reader reads aloud text shown on the computer display. It may also report non-text interface content, including button labels and image descriptions, when those elements include the right accessibility attributes. These tools can reach some parts of Premiere, especially alongside operating system-level accessibility settings, but complete functionality is not guaranteed. For current support details, see Accessibility Conformance Reports.

### Support for operating system accessibility features

On macOS, Premiere responds to several accessibility features built into the operating system. Changes made under System Settings > Accessibility, such as display contrast or text size adjustments, are reflected in the Premiere workspace.

Note

Windows coverage is narrower. Premiere does not fully support Windows High Contrast Mode. High contrast settings affect only title bars and menus; the rest of the interface does not change.

## Navigate Premiere using the keyboard

### Keyboard shortcuts in Adobe Premiere help you move among panels, reach tools, and speed up editing tasks.

With Keyboard shortcuts, Adobe Premiere navigation and editing can be handled more efficiently. Shortcuts let you change panels, open tools, and run commands without depending on a mouse device. Learning them helps keep attention on the edit instead of on interface navigation.

### Navigate panels in Premiere

Press Ctrl+Shift+. (period) on Windows or Ctrl+Shift+. (period) on macOS to move through panels clockwise.

Press Ctrl+Shift+, (comma) on Windows or Ctrl+Shift+, (comma) on macOS to move through panels anticlockwise.

When a panel has focus, Premiere shows a blue line around it.

After focus is on a panel, use shortcuts to run tasks inside that panel.

In the Timeline panel, for example:

- Press the Spacebar to start or stop playback.
- Press the Left and Right keys to step frame by frame.

Press Ctrl+Alt+K (Windows) or Cmd+Opt+K (macOS) to view every shortcut for a panel. Panel shortcuts apply only while that panel is active.

Choose Keyboard Shortcuts from the Edit menu (Windows) or the Premiere menu (macOS).

Press the Tilde key to expand the keyboard panel.

### Explore commonly used keyboard shortcuts in Premiere

- Audio Clip Mixer panel: Shift-6
- Effect Controls panel: Shift-5
- Effects panel: Shift+7
- Media Browser panel: Shift+8
- Projects panel: Shift+1

Use the shortcut list to locate the command you need more quickly.

### Navigate dialog boxes in Premiere

Press Tab to advance through options in a dialog box.

Press the Arrow keys to move among choices for the current option.

When a dialog box includes a category list, such as the Keyboard Shortcuts dialog, press Ctrl+Tab (Windows and macOS) to put focus on that list. Then press the Arrow keys to move upward or downward.

Press Enter to accept the selected item and close the dialog box.

Use the mouse device for tasks that keyboard shortcuts do not cover.

- Use the New Project dialog box tabs or navigate the tree control in the New Sequence dialog box.
- Work in the Lumetri Color, Effects, and Project panels.
- Do tasks such as drawing with the Pen tool or layering clips.
